## 🔴 高优先级问题

### 2. 测试隐式依赖问题

#### 问题描述

某些测试用例之间存在隐式依赖，测试执行顺序可能影响结果：

- "删除单个部门"依赖 "批量删除多个部门" 未删除的数据
- 后续测试依赖 beforeAll 中共享的测试数据
- 修改测试顺序会导致失败

#### 当前代码示例

```typescript
// dept.test.ts - 问题代码
describe("DELETE /api/v1/dept/{ids} - 删除部门", () => {
  let testDeptIds: number[] = [];
  
  beforeAll(async () => {
    // 创建 3 个测试部门
    for (let i = 0; i < 3; i++) {
      const deptId = await DeptAPI.add(form) as number;
      testDeptIds.push(deptId);
    }
  });
  
  test("删除单个部门", async () => {
    const deptId = testDeptIds[0]; // ← 依赖 beforeAll
    await DeptAPI.deleteByIds(deptId!.toString());
  });
  
  test("批量删除多个部门", async () => {
    const ids = testDeptIds.slice(1); // ← 依赖前一个测试未删除 [0]
    await DeptAPI.deleteByIds(ids.join(","));
  });
});
```

#### 改进方案

**方案：每个测试用例独立创建所需数据**

```typescript
// dept.test.ts - 改进后
describe("DELETE /api/v1/dept/{ids} - 删除部门", () => {
  
  test("删除单个部门", async () => {
    // Arrange: 独立创建测试数据
    const deptId = await DeptAPI.add({
      name: `测试部门_${Date.now()}`,
      parentId: 0,
      status: 1
    }) as number;
    
    // Act: 执行删除
    await DeptAPI.deleteByIds(deptId.toString());
    
    // Assert: 验证删除成功
    const result = await DeptAPI.getList({});
    const exists = result.some(dept => dept.id === deptId);
    expect(exists).toBe(false);
  });
  
  test("批量删除多个部门", async () => {
    // Arrange: 独立创建多个测试部门
    const deptIds: number[] = [];
    for (let i = 0; i < 3; i++) {
      const id = await DeptAPI.add({
        name: `测试部门_${Date.now()}_${i}`,
        parentId: 0,
        status: 1
      }) as number;
      deptIds.push(id);
    }
    
    // Act: 批量删除
    await DeptAPI.deleteByIds(deptIds.join(","));
    
    // Assert: 验证所有部门都被删除
    const result = await DeptAPI.getList({});
    const anyExists = result.some(dept => deptIds.includes(dept.id));
    expect(anyExists).toBe(false);
  });
});
```

#### 预期效果

- ✅ 测试用例完全独立，可任意顺序执行
- ✅ 测试失败不影响其他测试
- ✅ 支持并发执行测试

#### 改进方案

**创建测试数据工厂**

```typescript
/**
 * 测试数据工厂 - 用于生成测试数据
 */
export class TestDataFactory {
  private static timestamp = Date.now();
  
  /**
   * 获取时间戳（每次调用递增，确保唯一性）
   */
  static getTimestamp(): number {
    return Date.now() + this.timestamp++;
  }
  
  /**
   * 生成唯一名称
   */
  static generateName(prefix: string): string {
    return `${prefix}_${this.getTimestamp()}`;
  }
  
  /**
   * 创建数据集表单数据
   */
  static createDatasetForm(overrides?: Partial<DatasetAddForm>): DatasetAddForm {
    return {
      parentId: 0,
      name: this.generateName('测试数据集'),
      type: "用户数据集",
      status: 1,
      ...overrides,
    };
  }
  
  /**
   * 创建用户表单数据
   */
  static createUserForm(overrides?: Partial<UserForm>): UserForm {
    const username = this.generateName('testuser');
    return {
      username,
      nickname: this.generateName('测试用户'),
      email: `${username}@test.com`,
      status: 1,
      ...overrides,
    };
  }
  
  /**
   * 创建部门表单数据
   */
  static createDeptForm(overrides?: Partial<DeptForm>): DeptForm {
    return {
      name: this.generateName('测试部门'),
      parentId: 0,
      status: 1,
      sort: 1,
      ...overrides,
    };
  }
  
  /**
   * 创建角色表单数据
   */
  static createRoleForm(overrides?: Partial<RoleForm>): RoleForm {
    return {
      roleName: this.generateName('测试角色'),
      roleCode: this.generateName('ROLE_TEST'),
      status: 1,
      ...overrides,
    };
  }
  
  /**
   * 创建字典类型表单数据
   */
  static createDictTypeForm(overrides?: Partial<DictTypeAddForm>): DictTypeAddForm {
    return {
      name: this.generateName('测试字典类型'),
      status: 1,
      remark: "测试备注",
      ...overrides,
    };
  }
  
  /**
   * 创建查询参数
   */
  static createQueryParams(overrides?: any): any {
    return {
      pageNum: 1,
      pageSize: 10,
      ...overrides,
    };
  }
}
```

#### 预期效果

- ✅ 减少重复代码
- ✅ 提高测试数据可维护性
- ✅ 统一测试数据格式
