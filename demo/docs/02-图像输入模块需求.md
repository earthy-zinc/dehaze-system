## 一、模块概述



### 1.1 模块定位

图像输入模块是用户使用系统的第一个接触点，负责提供多种图像输入方式，满足不同场景下的图像采集需求。

### 1.2 核心价值

- **多样化输入**：支持上传、拍照、样例、历史记录4种输入方式
- **便捷体验**：快速体验流程，10秒内完成样例选择
- **智能优化**：自动压缩大图片，优化上传体验
- **历史管理**：保存最近20次处理记录，支持快速重新处理

## 二、功能需求

### 2.1 图像上传功能 (F-M01-001)

#### 2.1.1 功能描述

支持用户从本地相册选择图片上传到系统。

#### 2.1.2 触发方式

- 主界面"上传图片"按钮
- 拖拽上传（平板设备）
- 快捷操作菜单

#### 2.1.3 支持格式

| 格式     | 说明             | 优先级 |
| -------- | ---------------- | ------ |
| JPG/JPEG | 最常用格式       | P0     |
| PNG      | 支持透明通道     | P0     |
| WEBP     | 现代格式，体积小 | P1     |
| HEIC     | iOS默认格式      | P1     |

#### 2.1.4 文件限制

- **单张图片大小**：最大20MB
- **分辨率限制**：最大8000×8000像素
- **最小分辨率**：建议≥640×480像素

#### 2.1.5 上传体验优化

**进度显示**

- 显示上传进度条（0-100%）
- 显示已上传大小/总大小
- 显示预估剩余时间

**取消与重试**

- 支持取消上传操作
- 失败自动重试（最多3次）
- 重试间隔：2秒、5秒、10秒

**智能压缩**

- 自动检测图片大小

- >5MB的图片自动压缩

- 压缩质量：85%

- 压缩后预览确认

#### 2.1.6 错误处理

| 错误类型   | 错误提示                                        | 处理方式     |
| ---------- | ----------------------------------------------- | ------------ |
| 文件过大   | "图片大小超过20MB，请选择较小的图片"            | 阻止上传     |
| 格式不支持 | "不支持该图片格式，请选择JPG/PNG/WEBP/HEIC格式" | 阻止上传     |
| 网络异常   | "网络连接失败，请检查网络后重试"                | 提供重试按钮 |
| 上传失败   | "上传失败，已自动重试(X/3)"                     | 自动重试     |

---

### 2.2 拍照功能 (F-M01-002)

#### 2.2.1 功能描述

支持用户使用设备相机实时拍摄图片。

#### 2.2.2 相机能力

**基础功能**

- 前后摄像头切换
- 闪光灯控制（自动/开启/关闭）
- 对焦点选择（点击屏幕对焦）
- 网格线辅助（九宫格）

**拍照模式**

| 模式     | 说明         | 适用场景           |
| -------- | ------------ | ------------------ |
| 标准模式 | 普通拍照     | 日常使用           |
| HDR模式  | 提升动态范围 | 逆光、高对比度场景 |
| 连拍模式 | 快速拍摄3张  | 移动物体、抓拍     |

#### 2.2.3 预览功能

**实时预览**

- 显示取景框
- 显示网格线（可开关）
- 显示对焦框
- 显示曝光补偿

**拍照后操作**

- 预览拍摄结果
- 确认使用/重新拍摄
- 简单裁剪调整
- 旋转调整

#### 2.2.4 权限处理

**相机权限**

- 首次使用时申请权限
- 说明权限用途："用于拍摄需要去雾的图片"
- 权限被拒绝时，提供跳转设置的引导

---

### 2.3 样例图片库 (F-M01-003)

#### 2.3.1 功能描述

提供预置的样例图片，该样例图片从模块【数据集管理】中存在的图片中选择，方便用户快速体验系统功能。详细说明见数据集管理模块需求分档

#### 2.3.3 展示方式

**布局设计**

- 网格/瀑布流式布局
- 缩略图预览
- 显示分类标签
- 显示场景类型和难度标识

**交互设计**

- 点击缩略图放大查看
- 长按显示详细信息
- 滑动浏览同类别图片
- 一键选择使用

#### 2.3.4 快速体验流程

```
点击"快速体验"
    ↓
进入样例图片库
    ↓
选择样例图片
    ↓
自动加载到处理区
    ↓
自动应用推荐算法
    ↓
直接查看对比结果
```

**预计用时**：<10秒

#### 2.3.5 样例图片信息

每张样例图片包含以下信息：

- 图片名称
- 场景类型（城市/风景/建筑等）
- 雾霾程度（轻度/中度/重度）
- 难度等级（⭐⭐⭐⭐⭐）
- 推荐算法
- 图片尺寸

---

### 2.4 历史记录 (F-M01-004)

#### 2.4.1 功能描述

保存用户最近的处理记录，支持快速重新处理。

#### 2.4.2 记录内容

**基本信息**

- 原始图片缩略图
- 处理结果缩略图
- 处理时间
- 使用的算法名称
- 处理参数

**存储策略**

- 保存最近20条记录
- 超过20条自动删除最早的记录
- 本地存储，不占用云端空间

#### 2.4.3 展示方式

**列表布局**

- 时间倒序排列（最新在前）
- 显示原图和结果图对比
- 显示处理时间和算法
- 显示处理状态（成功/失败）

**分组显示**

- 今天
- 昨天
- 最近7天
- 更早

#### 2.4.4 快速操作

| 操作     | 说明                         | 触发方式           |
| -------- | ---------------------------- | ------------------ |
| 重新处理 | 使用相同图片和算法重新处理   | 点击"重新处理"按钮 |
| 更换算法 | 使用相同图片，更换算法处理   | 点击"更换算法"按钮 |
| 查看详情 | 查看完整的处理信息和对比结果 | 点击记录卡片       |
| 删除记录 | 删除该条历史记录             | 左滑显示删除按钮   |
| 分享结果 | 分享处理结果                 | 点击"分享"按钮     |

#### 2.4.5 数据管理

**清理策略**

- 手动清理：提供"清空历史记录"功能
- 自动清理：超过20条自动删除最早记录
- 选择性清理：支持多选删除

**数据同步**

- 本地存储为主
- 可选云端同步（需登录）
- 跨设备同步（需登录）
