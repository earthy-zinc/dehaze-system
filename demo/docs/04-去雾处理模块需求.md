## 一、模块概述

### 1.1 模块定位

去雾处理模块是系统的核心处理引擎，负责调用算法对图像进行去雾处理，并管理处理过程和结果。

### 1.2 核心价值

- **高效处理**：优化的处理流程，快速完成去雾
- **批量支持**：支持批量处理多张图片
- **参数可调**：高级用户可调节算法参数
- **结果管理**：完善的结果保存和管理功能

## 二、功能需求

### 2.1 单张处理功能 (F-M03-001)

#### 2.1.1 功能描述

对单张图片进行去雾处理，支持实时进度监控和结果预览。

#### 2.1.2 处理流程

```
确认图片和算法
    ↓
点击"开始去雾"
    ↓
图片预处理
    ↓
调用算法处理
    ↓
显示处理进度
    ↓
处理完成
    ↓
自动进入对比页面
```

#### 2.1.3 处理控制

**开始处理**

- 显示处理确认对话框
- 显示预估处理时间
- 显示算法名称和参数
- 确认后开始处理

**暂停/恢复**

- 支持暂停处理（仅部分算法支持）
- 显示暂停状态
- 支持恢复处理

**取消处理**

- 支持取消正在进行的处理
- 取消确认对话框
- 释放资源

#### 2.1.4 进度显示

**进度信息**

- 进度条（0-100%）
- 当前处理阶段
- 已用时间/预估剩余时间
- 实时预览（可选）

**处理阶段**

1. 图片预处理（10%）
2. 算法初始化（20%）
3. 去雾处理（20%-90%）
4. 后处理优化（90%-95%）
5. 结果保存（95%-100%）

---

### 2.2 批量处理功能 (F-M03-002)

#### 2.2.1 功能描述

支持一次性处理多张图片，提高处理效率。

#### 2.2.2 批量处理流程

```
选择多张图片（最多20张）
    ↓
选择算法
    ↓
设置处理参数（可选）
    ↓
点击"批量处理"
    ↓
逐张处理
    ↓
显示整体进度
    ↓
处理完成
    ↓
查看批量结果
```

#### 2.2.3 批量处理策略

**处理模式**

| 模式     | 说明                 | 适用场景       |
| -------- | -------------------- | -------------- |
| 串行处理 | 逐张处理，稳定可靠   | 内存有限的设备 |
| 并行处理 | 同时处理多张，速度快 | 高性能设备     |
| 智能模式 | 根据设备性能自动选择 | 推荐模式       |

**失败处理**

- 单张失败不影响其他图片
- 记录失败原因
- 支持重试失败的图片
- 生成处理报告

#### 2.2.4 批量进度显示

**整体进度**

- 总进度条
- 已完成/总数量
- 成功/失败数量
- 预估剩余时间

**单张进度**

- 当前处理的图片
- 单张进度条
- 缩略图预览

---

### 2.3 参数调节功能 (F-M03-003)

#### 2.3.1 功能描述

为高级用户提供算法参数调节功能，实现个性化处理效果。

#### 2.3.2 参数类型

**通用参数**

| 参数名称   | 类型 | 范围  | 默认值 | 说明           |
| ---------- | ---- | ----- | ------ | -------------- |
| 去雾强度   | 滑块 | 0-100 | 50     | 控制去雾程度   |
| 色彩饱和度 | 滑块 | 0-200 | 100    | 调整色彩鲜艳度 |
| 对比度     | 滑块 | 0-200 | 100    | 调整明暗对比   |
| 锐化程度   | 滑块 | 0-100 | 30     | 增强细节清晰度 |

**算法特定参数**

不同算法有不同的可调参数：

**DCP算法**

- ω值（0.85-0.95）
- 窗口大小（3-15）
- 引导滤波半径（20-60）

**深度学习算法**

- 推理精度（FP16/FP32）
- 批处理大小（1-4）

#### 2.3.3 参数调节界面

**布局设计**

- 折叠式高级设置面板
- 参数分组显示
- 实时预览效果
- 重置为默认值按钮

**交互设计**

- 滑块调节
- 数值输入
- 预设方案选择
- 保存自定义方案

---

### 2.4 处理结果管理 (F-M03-004)

#### 2.4.1 功能描述

管理处理结果，支持保存、分享、导出等操作。

#### 2.4.2 结果保存

**自动保存**

- 处理完成自动保存到应用目录
- 保存原图和处理结果
- 保存处理参数和元数据

**手动保存**

- 保存到相册
- 自定义保存位置
- 选择保存格式（JPG/PNG）
- 选择保存质量（60%-100%）

**文件命名**

```
格式：原文件名_算法名_时间戳.jpg
示例：IMG_20250121_AODNet_143024.jpg
```

#### 2.4.3 结果分享

**分享方式**

- 分享到社交平台（微信、QQ、微博等）
- 生成分享链接
- 生成二维码
- 发送到邮箱

**分享内容**

- 处理后的图片
- 对比图（原图+处理后）
- 处理信息（算法、参数、时间）

#### 2.4.4 结果导出

**导出格式**

- 单张图片（JPG/PNG）
- 对比图（并排/上下）
- PDF报告（包含详细信息）
- 批量打包（ZIP）

**导出选项**

- 选择分辨率
- 选择质量
- 是否包含水印
- 是否包含元数据

---

### 2.5 处理队列管理 (F-M03-005)

#### 2.4.1 功能描述

管理处理任务队列，支持任务优先级和并发控制。

#### 2.4.2 队列功能

**任务管理**

- 查看队列中的任务
- 调整任务优先级
- 暂停/恢复任务
- 取消任务
- 清空队列

**队列状态**

- 等待中
- 处理中
- 已完成
- 已失败
- 已取消

#### 2.4.3 并发控制

**并发策略**

- 根据设备性能自动调整
- 最大并发数：1-3
- 优先处理高优先级任务
- 失败任务自动重试（最多3次）

---

### 2.6 错误处理与恢复 (F-M03-006)

#### 2.6.1 错误类型

| 错误类型     | 错误提示                                 | 处理方式               |
| ------------ | ---------------------------------------- | ---------------------- |
| 内存不足     | "设备内存不足，请关闭其他应用后重试"     | 释放资源，提示用户     |
| 算法加载失败 | "算法加载失败，请检查网络连接"           | 重试加载，提供离线算法 |
| 处理超时     | "处理超时，建议更换算法或降低图片分辨率" | 取消处理，提供建议     |
| 图片损坏     | "图片文件损坏，无法处理"                 | 跳过该图片             |
| 存储空间不足 | "存储空间不足，请清理后重试"             | 提示清理空间           |

#### 2.6.2 恢复机制

**断点续传**

- 保存处理进度
- 应用重启后恢复
- 支持手动恢复

**自动重试**

- 网络错误自动重试
- 最多重试3次
- 重试间隔递增（2s、5s、10s）

## 三、交互流程

### 3.1 单张处理流程

```
【用户操作】              【系统响应】
    ↓
选择图片和算法
    ↓                    加载图片预览
调整参数（可选）
    ↓                    实时预览效果
点击"开始去雾"
    ↓                    显示确认对话框
确认处理
    ↓                    开始处理
                         ├─ 显示进度条
                         ├─ 显示处理阶段
                         ├─ 显示预估时间
                         └─ 实时预览（可选）
    ↓
处理完成
    ↓                    显示完成提示
                         自动进入对比页面
```

### 3.2 批量处理流程

```
【用户操作】              【系统响应】
    ↓
选择多张图片
    ↓                    显示图片列表
选择算法
    ↓                    显示算法信息
设置参数（可选）
    ↓                    预览参数效果
点击"批量处理"
    ↓                    显示确认对话框
确认处理
    ↓                    开始批量处理
                         ├─ 显示整体进度
                         ├─ 显示单张进度
                         ├─ 显示成功/失败数
                         └─ 显示预估时间
    ↓
处理完成
    ↓                    显示处理报告
                         查看批量结果
```
