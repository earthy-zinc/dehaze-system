## 二、图片上传与管理功能

### 2.7 数据项（图片）增删改查 (F-M06-007)

#### 2.7.1 功能描述

支持数据集内部数据项（图片）的完整增删改查操作。

#### 2.7.2 单张图片上传

**上传方式**

- 点击上传
- 拖拽上传

**上传时自动处理**

- 自动解析图片宽高并存储
- 自动生成缩略图
- 自动计算文件MD5

**上传时可选编辑/标注**

- 场景类型（用户自定义）
- 雾霾程度（light/medium/heavy）
- 图片描述
- 图片类型（有雾图/清晰图）

#### 2.7.3 配对图片上传（Image Pair）

**功能描述**

支持同时上传配对的有雾图像和清晰图像，系统自动校验并建立配对关系。

**配对结构说明**

- **清晰图像（Ground Truth）**：每个数据项只有一张清晰图像
- **有雾图像**：每个数据项可以有多张有雾图像，每张有不同的雾气程度
- 所有配对图片必须分辨率一致

**上传流程**

```
┌─────────────────────────────────────────────────────────────────┐
│  配对图片上传                                                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  清晰图像 (Ground Truth) - 必须上传一张                         │
│  ┌──────────────────┐                                          │
│  │                  │                                          │
│  │   清晰图像       │                                          │
│  │   (Clear/GT)     │                                          │
│  │  [点击上传]      │                                          │
│  └──────────────────┘                                          │
│                                                                 │
│  有雾图像 - 支持上传多张（至少一张）                            │
│  ┌──────────────────┐ ┌──────────────────┐ ┌────────────┐      │
│  │                  │ │                  │ │            │      │
│  │   有雾图-轻度    │ │   有雾图-中度    │ │  [+ 添加]  │      │
│  │   (Light)        │ │   (Medium)       │ │            │      │
│  │  [点击上传]      │ │  [点击上传]      │ │            │      │
│  │  雾霾程度: [轻度▼]│ │  雾霾程度: [中度▼]│ │            │      │
│  └──────────────────┘ └──────────────────┘ └────────────┘      │
│                                                                 │
│  配对校验状态：                                                 │
│  ○ 分辨率一致性：未校验（所有图片必须分辨率相同）              │
│  ○ 文件格式：未校验                                            │
│                                                                 │
│  [取消]                                      [确认上传]         │
└─────────────────────────────────────────────────────────────────┘
```

**配对校验规则**

| 校验项 | 规则 | 错误提示 |
|-------|------|---------|
| 清晰图必填 | 必须上传一张清晰图 | "请上传清晰图像" |
| 有雾图必填 | 至少上传一张有雾图 | "请至少上传一张有雾图像" |
| 分辨率一致性 | 所有图片宽高必须完全相同 | "配对图片分辨率不一致，清晰图：1920×1080，有雾图1：1280×720" |
| 文件格式 | 必须为支持的图片格式 | "仅支持 jpg/png/gif 格式" |
| 文件大小 | 单张不超过 10MB | "文件大小不能超过 10MB" |
| 雾霾程度 | 每张有雾图必须标注雾霾程度 | "请为有雾图选择雾霾程度" |

**配对关系存储**

- 所有配对图片属于同一个数据项（DatasetItem）
- 清晰图类型标记为 `clear`
- 有雾图类型标记为 `hazy`
- 有雾图的 `hazeLevel` 字段记录雾霾程度（light/medium/heavy）
- 通过 `itemId` 关联

**配对上传可选标注**

- 场景类型（应用于整个配对/数据项）
- 雾霾程度（每张有雾图单独标注，必填）
- 配对描述

#### 2.7.4 批量上传

**支持的批量上传模式**

1. **普通批量上传**：一次选择多张图片上传
2. **配对批量上传**：按文件名自动匹配配对
   - 命名规则示例：
     - `xxx_clear.jpg` / `xxx_gt.jpg` → 清晰图
     - `xxx_hazy.jpg` / `xxx_hazy_light.jpg` → 有雾图（轻度）
     - `xxx_hazy_medium.jpg` → 有雾图（中度）
     - `xxx_hazy_heavy.jpg` → 有雾图（重度）
   - 同一前缀的图片自动归为一个配对组

**批量上传流程**

```
选择多张图片
    ↓
系统自动识别配对关系（根据文件名）
    ↓
显示配对预览列表（每组显示清晰图+多张有雾图）
    ↓
用户确认/调整配对关系和雾霾程度
    ↓
批量校验分辨率一致性（同组内所有图片）
    ↓
开始上传（显示进度）
    ↓
上传完成，显示结果统计
```

**配对预览列表示例**

```
┌─────────────────────────────────────────────────────────────────┐
│  配对预览                                                       │
├─────────────────────────────────────────────────────────────────┤
│  配对组 1：scene_001                                            │
│  ├── 清晰图：scene_001_clear.jpg ✓                              │
│  ├── 有雾图：scene_001_hazy_light.jpg [轻度▼] ✓                 │
│  ├── 有雾图：scene_001_hazy_medium.jpg [中度▼] ✓                │
│  └── 有雾图：scene_001_hazy_heavy.jpg [重度▼] ✓                 │
│                                                                 │
│  配对组 2：scene_002                                            │
│  ├── 清晰图：scene_002_gt.jpg ✓                                 │
│  └── 有雾图：scene_002_hazy.jpg [请选择▼] ⚠                     │
│                                                                 │
│  未配对文件：                                                   │
│  └── random_image.jpg [作为独立图片上传]                        │
└─────────────────────────────────────────────────────────────────┘
```

#### 2.7.5 修改图片

**可修改内容**

- 图片文件（重新上传时自动重新解析宽高）
- 场景类型
- 雾霾程度
- 图片描述
- 图片类型（清晰图/雾霾图等）

**配对图片修改**

- 修改单张图片时，若为配对图片，显示配对信息（包括同组的其他图片）
- 支持解除配对关系
- 支持重新建立配对关系
- 支持向已有配对组添加新的有雾图
- 支持修改有雾图的雾霾程度

#### 2.7.6 删除图片

- 单张删除
- 批量删除（列表模式下）
- 删除时同时删除缩略图
- 删除配对图片时，提示是否同时删除配对的另一张
