## 一、模块概述

### 1.1 模块定位

数据集管理模块负责管理系统中的图像数据集，包括样例图片、测试数据、用户上传图片等，提供浏览、搜索、分类等功能。

### 1.2 核心价值

- **集中管理**：统一管理所有图像数据
- **高效浏览**：瀑布流展示，流畅浏览体验
- **智能分类**：按类型、场景自动分类
- **快速搜索**：多维度搜索和筛选

- 上级文档：[01-产品概述和总体架构.md](./01-产品概述和总体架构.md)

## 二、功能需求

### 2.1 数据集列表展示 (F-M06-001)

#### 2.1.1 功能描述

展示所有数据集的列表，支持查看数据集基本信息和统计数据。

#### 2.1.2 数据集分类

| 数据集类型 | 说明                     | 数量  |
| ---------- | ------------------------ | ----- |
| 样例数据集 | 系统预置的样例图片       | 40张  |
| 测试数据集 | 用于算法测试的标准数据集 | 100张 |
| 用户数据集 | 用户上传的图片           | 不限  |
| 处理结果集 | 去雾处理后的结果图片     | 不限  |

#### 2.1.3 列表信息

**基本信息**

- 数据集名称
- 数据集类型
- 图片数量
- 总大小
- 创建时间
- 最后更新时间

**统计信息**

- 场景分布（城市/风景/建筑等）
- 雾霾程度分布（轻度/中度/重度）
- 分辨率分布
- 使用次数

---

### 2.2 数据集详情查看 (F-M06-002)

#### 2.2.1 功能描述

查看数据集的详细信息和图片列表。

#### 2.2.2 详情信息

**数据集信息**

- 数据集名称
- 数据集描述
- 数据集类型
- 创建时间
- 创建人
- 图片总数
- 总大小

**统计分析**

- 场景类型分布图
- 雾霾程度分布图
- 分辨率分布图
- 文件格式分布图

---

### 2.3 图片瀑布流展示 (F-M06-003)

#### 2.3.1 功能描述

使用瀑布流布局展示数据集中的所有图片，提供流畅的浏览体验。

#### 2.3.2 瀑布流设计

**布局参数**

- 列数：竖屏2列，横屏3-4列
- 间距：8px
- 图片宽度：自适应
- 图片高度：保持原始宽高比

**加载策略**

- 首屏加载：20张
- 滚动加载：每次加载20张
- 预加载：提前加载下一屏
- 懒加载：可见区域才加载

#### 2.3.3 图片卡片信息

**缩略图显示**

- 图片缩略图（200×200px）
- 图片名称
- 图片大小
- 上传时间

**悬浮信息**

- 完整文件名
- 分辨率
- 文件格式
- 雾霾程度
- 场景类型

---

### 2.4 图片类型切换 (F-M06-004)

#### 2.4.1 功能描述

支持按图片类型快速切换显示内容。

#### 2.4.2 类型分类

**按场景分类**

**按雾霾程度分类**

**按处理状态分类**

- 全部
- 未处理

#### 2.4.3 切换交互

**Tab切换**

```
┌─────────────────────────────┐
│ [全部] [城市] [风景] [建筑] │
├─────────────────────────────┤
│  [图片瀑布流展示区域]        │
│                              │
└─────────────────────────────┘
```

**筛选面板**

- 底部弹出筛选面板
- 多维度筛选
- 实时预览结果数量
- 应用筛选条件

## 三、交互流程

### 3.1 浏览图片流程

```
进入数据集管理页面
    ↓
选择数据集
    ↓
查看数据集详情
    ↓
瀑布流浏览图片
    ↓
切换类型/搜索（可选）
    ↓
点击图片查看大图
    ↓
左右滑动浏览
    ↓
执行操作（下载/分享/处理）
```
