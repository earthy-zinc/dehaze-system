## 二、图片展示与浏览功能

### 2.3 图片展示模式 (F-M06-003)

#### 2.3.1 功能描述

提供多种图片展示模式，满足不同使用场景的需求：
- **列表模式**：注重数据管理，支持批量操作
- **图片模式**：注重图片预览，提供流畅浏览体验

#### 2.3.2 展示模式切换

**模式切换按钮**

```
┌─────────────────────────────────────────────────────┐
│ [列表] [纵向瀑布流] [横向瀑布流] [网格]             │
└─────────────────────────────────────────────────────┘
```

用户可在四种模式间自由切换，系统记住用户偏好设置。

#### 2.3.3 列表模式

**功能定位**：注重数据集图片的管理，适合批量操作和详细信息查看

**表格列设计**

| 列名 | 宽度 | 说明 |
|-----|------|------|
| 多选框 | 50px | 支持全选/单选 |
| 缩略图 | 80px | 小尺寸预览图 |
| 文件名 | 200px | 可点击查看大图 |
| 分辨率 | 120px | 宽×高 |
| 文件大小 | 100px | 格式化显示 |
| 雾霾程度 | 100px | 轻度/中度/重度/未标注 |
| 场景类型 | 120px | 用户自定义 |
| 图片类型 | 100px | 有雾图/清晰图/去雾图 |
| 上传时间 | 160px | 格式化日期 |
| 操作 | 200px | 下载/编辑/删除按钮 |

**批量操作**

- 批量选择：支持 Shift 连续选择、Ctrl 多选、点击方框选择
- 批量删除：选中后显示"删除选中项"按钮
- 批量下载：选中后显示"下载选中项"按钮，打包下载所选图片
- 全选/取消全选：表头多选框控制

**单张下载**

- 操作栏新增"下载"按钮
- 点击直接下载原图
- 如果是配对图片，弹窗询问下载哪张或全部下载

**交互设计**

- 点击文件名：打开大图查看
- 点击下载：下载图片（配对图片轻量 popover 弹窗选择）
- 点击编辑：打开图片信息编辑弹窗
- 点击删除：二次确认后删除

#### 2.3.4 纵向瀑布流模式

**功能定位**：适合浏览不同高度的图片，充分利用垂直空间

**布局参数**

- 列数：竖屏2列，横屏3-4列
- 间距：8px
- 高度固定
    - 图片宽度：自适应列宽
    - 图片高度：保持原始宽高比
- 宽度固定
    - 图片高度：自适应列宽
    - 图片宽度：保持原始宽高比

**图片卡片信息**

- 图片缩略图
- 图片名称（底部悬浮显示）
- 点击查看大图

#### 2.3.5 横向瀑布流模式

**功能定位**：适合浏览不同宽度的图片，横向滚动浏览

**布局参数**

- 行数：2-3行
- 间距：8px
- 图片高度：固定（200px）
- 图片宽度：按比例自适应

**交互设计**

- 横向滚动浏览
- 支持鼠标滚轮横向滚动
- 支持触摸滑动

#### 2.3.6 网格模式

**功能定位**：整齐划一的展示方式，适合快速浏览大量图片

**布局参数**

- 列数：自适应（根据容器宽度计算）
- 卡片尺寸：固定 200×200px
- 间距：8px
- 图片填充：居中裁剪（cover）

**图片卡片信息**

- 图片缩略图（居中裁剪）
- 底部信息栏：文件名、雾霾程度标签
- 悬浮显示：分辨率、文件大小

#### 2.3.7 通用加载策略

**分页加载**

- 首屏加载：20张
- 滚动加载：每次加载20张
- 预加载：提前加载下一屏
- 懒加载：可见区域才加载

**性能优化**

- 虚拟滚动（列表模式）
- 图片懒加载（所有模式）
- 缩略图缓存

### 2.3.8 大图查看

**触发方式**

- 列表模式：点击文件名
- 图片模式：点击图片

**大图信息展示**

- 图片原图
- 文件名
- 分辨率
- 文件大小
- 雾霾程度
- 场景类型
- 上传时间
- 使用次数

**配对图片切换**

当前图片如果有配对图像，显示配对切换区域。配对结构说明：
- **清晰图像（Ground Truth）**：每个数据项只有一张清晰图像
- **有雾图像**：每个数据项可能有多张有雾图像，每张有不同的雾气程度

切换功能设计：
- 显示配对状态标识（如"有N张配对图像"）
- 提供切换按钮/下拉选择，支持在清晰图和多张有雾图之间切换
- 有雾图显示对应的雾霾程度标签（轻度/中度/重度）
- 切换时平滑过渡，显示当前查看的图片类型

```
┌─────────────────────────────────────────────────────┐
│  [清晰图]  [有雾图-轻度]  [有雾图-中度]  [有雾图-重度]│
│     ○           ●              ○              ○     │
└─────────────────────────────────────────────────────┘
```

或使用下拉选择方式：

```
┌─────────────────────────────────────────────────────┐
│  当前显示：[有雾图-轻度 ▼]                          │
│  ├── 清晰图                                         │
│  ├── 有雾图-轻度 ✓                                  │
│  ├── 有雾图-中度                                    │
│  └── 有雾图-重度                                    │
└─────────────────────────────────────────────────────┘
```

**操作按钮**

- 下载：点击弹出下载选项弹窗（见下方说明）
- 编辑信息
- 删除
- 上一张/下一张：切换到不同的数据项（不同图片对）

**下载选项弹窗**

当图片有配对时，点击下载按钮弹出选择弹窗：

```
┌─────────────────────────────────────────────────────┐
│  下载图片                                           │
├─────────────────────────────────────────────────────┤
│                                                     │
│  请选择要下载的图片：                               │
│                                                     │
│  ○ 仅下载当前图片                                   │
│  ○ 仅下载清晰图                                     │
│  ○ 下载所有有雾图（打包下载）                       │
│  ○ 下载全部图片（打包下载）                         │
│                                                     │
│  [取消]                              [确认下载]     │
└─────────────────────────────────────────────────────┘
```

- 无配对图片时直接下载，不弹窗
- 选择打包下载时生成 ZIP 文件下载

**上一张/下一张切换**

- 切换的是不同的数据项（ImageItem），而非同一数据项内的配对图片
- 切换后默认显示该数据项的第一张图片（通常是有雾图）
- 显示当前位置（如 "3/50"）

### 2.4 图片类型切换 (F-M06-004)

#### 2.4.1 功能描述

支持按图片类型快速切换显示内容。

#### 2.4.2 类型分类

**按场景分类**

- 全部
- 用户自定义场景类型（系统记录用户输入过的场景类型，提供搜索建议）

**按雾霾程度分类（人工标注）**

- 全部
- 轻度雾霾
- 中度雾霾
- 重度雾霾
- 未标注

**按处理状态分类**

- 全部
- 未处理
- 已处理
- 处理失败

#### 2.4.3 切换交互

**Tab切换**

```
┌─────────────────────────────────────────┐
│ [全部] [轻度] [中度] [重度] [未标注]    │
├─────────────────────────────────────────┤
│  [图片瀑布流展示区域]                    │
│                                          │
└─────────────────────────────────────────┘
```

**筛选面板**

- 底部弹出筛选面板
- 多维度筛选
- 实时预览结果数量
- 应用筛选条件

### 2.5 图片搜索功能 (F-M06-005)

#### 2.5.1 功能描述

支持多种方式搜索图片，搜索结果按相关度和时间排序。

#### 2.5.2 搜索方式

**关键词搜索**

- 按文件名搜索
- 按描述搜索
- 按场景类型搜索（用户自定义）
- 按上传时间搜索

**高级搜索**

- 按分辨率范围搜索（基于图片宽高）
- 按文件大小范围搜索
- 按雾霾程度搜索（人工标注）
- 按处理状态搜索

**智能搜索**

- 相似图片搜索
- 以图搜图
- 智能推荐

#### 2.5.3 搜索结果

**结果展示**

- 瀑布流展示
- 高亮匹配关键词
- 显示匹配度
- **排序规则：按相关度降序，相关度相同时按时间降序**

**相关度计算规则**

- 文件名完全匹配：权重 100
- 文件名包含关键词：权重 50
- 描述包含关键词：权重 30
- 场景类型匹配：权重 20

**搜索历史**

- 保存最近10条搜索
- 快速重复搜索
- 清空搜索历史

### 2.8 无限滚动加载 (F-M06-008)

#### 2.8.1 功能描述

支持无限滚动加载，提供流畅的浏览体验。

#### 2.8.2 加载策略

**分页加载**

- 每页20张图片
- 滚动到底部自动加载下一页
- 显示加载进度
- 加载失败重试

**性能优化**

- 虚拟滚动
- 图片懒加载
- 缩略图缓存
- 内存管理

#### 2.8.3 加载状态

**加载中**

- 显示加载动画
- 显示"加载中..."提示

**加载完成**

- 显示"已加载X张图片"
- 继续滚动加载更多

**全部加载完成**

- 显示"已加载全部图片"
- 显示总数量

**加载失败**

- 显示"加载失败"提示
- 提供重试按钮
