# Go 后端测试规范化改造计划

Go 端测试基建与其运行方式的现行口径见 [测试架构](../02-系统架构/05-测试架构.md) 与 [02-Go架构文档](../04-项目实现/后端/02-Go架构文档.md)，此处只维护未落地的门禁项。

## 覆盖率与工具链门禁

| 项         | 口径                                                                 |
| ---------- | -------------------------------------------------------------------- |
| 覆盖率门禁 | 新增代码 ≥ 80%、整体 ≥ 60%，阈值对齐 [测试架构](../02-系统架构/05-测试架构.md) 的代码提交门禁 |
| 并发检查   | `go test -race ./...` 纳入门禁                                       |
| 运行入口   | Makefile `test` / `test-integration` / `cover` targets               |

验收：CI 门禁生效，覆盖率或 `-race` 未达标即阻断合并。

- Java 与 Python 端测试规范：Python 见 [测试架构](../02-系统架构/05-测试架构.md)，Java 见 `clarity-java/src/test/README.md`
- SDK 与前端测试：见 [测试架构](../02-系统架构/05-测试架构.md) 范围表
