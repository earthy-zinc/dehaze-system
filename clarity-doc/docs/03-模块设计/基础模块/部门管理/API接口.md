# 部门管理模块 API 接口

## 文档概述

- 基础路径：`/api/v1/depts`
- 接口详细参数与响应结构由代码定义，可通过 API 文档 MCP 查询。

## 接口清单

| 路径                          | 方法   | 功能描述                         | 权限标识          | 关联功能点 |
| ----------------------------- | ------ | -------------------------------- | ----------------- | ---------- |
| `/api/v1/depts`               | GET    | 获取部门列表（树形结构）         | -                 | F-DM-001   |
| `/api/v1/depts`               | POST   | 新增部门                         | `sys:dept:add`    | F-DM-002   |
| `/api/v1/depts/{deptId}/form` | GET    | 获取部门表单数据                 | -                 | F-DM-003   |
| `/api/v1/depts/{deptId}`      | PUT    | 修改部门                         | `sys:dept:edit`   | F-DM-003   |
| `/api/v1/depts/{ids}`         | DELETE | 删除部门（支持批量）             | `sys:dept:delete` | F-DM-004   |
| `/api/v1/depts/options`       | GET    | 获取部门下拉选项（树形结构）     | -                 | F-DM-008   |

## 权限标识汇总

| 权限标识          | 说明                                                     |
| ----------------- | -------------------------------------------------------- |
| -                 | 登录用户可访问（部门列表、表单数据、下拉选项）           |
| `sys:dept:add`    | 新增部门                                                 |
| `sys:dept:edit`   | 编辑部门（含状态切换、排序设置）                         |
| `sys:dept:delete` | 删除部门                                                 |

## 业务错误码

| 错误码  | 说明             | 触发场景                                                                                 |
| ------- | ---------------- | ---------------------------------------------------------------------------------------- |
| `A0400` | 用户请求参数错误 | 删除路径 ids 非法、必填参数缺失/越界                                                     |
| `A0401` | 请求资源不存在   | 编辑/删除不存在的部门、父部门不存在                                                      |
| `A0501` | 数据已存在       | 新增/编辑时同一上级部门下名称重复（含逻辑删除记录，删除后名称不可复用）                  |
| `A0502` | 数据状态不允许   | 删除部门时该部门下有子部门或关联用户                                                     |
| `A0503` | 操作不允许       | 循环引用检测失败；根部门不可删除、不可修改上级（内置保护，三端统一口径）                 |
| `A0504` | 业务校验失败     | 部门层级超过 5 级限制                                                                    |
