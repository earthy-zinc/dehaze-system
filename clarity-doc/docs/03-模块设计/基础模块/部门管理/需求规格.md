# 部门管理模块需求规格

## 模块概述

### 模块定位

部门管理模块维护系统组织架构，提供部门树形层级管理能力，为用户管理提供部门归属信息，为角色管理的数据权限控制提供组织基础数据。

### 核心价值

| 价值维度 | 具体内容                                       |
| -------- | ---------------------------------------------- |
| 统一入口 | 企业组织架构的唯一管理入口，覆盖部门全生命周期 |
| 层级结构 | 多层级树形结构，适应不同企业组织形态           |
| 数据支撑 | 为用户归属与角色数据权限提供组织基础数据       |

### 业务目标

#### 功能目标

- 部门统一管理（新增、编辑、删除、查询）
- 多层级树形部门结构（最多 5 级）
- 为用户管理提供部门归属，为角色数据权限提供组织基础
- 保障组织架构数据完整性（根部门保护、循环引用检测）

#### 性能目标

| 指标                 | 目标值    | 说明                             |
| -------------------- | --------- | -------------------------------- |
| 树形列表查询响应     | &lt;500ms | 部门树形结构查询响应时间         |
| 表单提交响应         | &lt;1s    | 新增、编辑部门操作响应时间       |
| 部门容量             | ≥1000     | 系统支持的最大部门数量           |
| 下拉选项查询响应     | &lt;300ms | 部门下拉选项（树形）查询响应时间 |

## 用户角色分析

### 主要用户角色

| 角色           | 描述                                 | 主要职责                                                     |
| -------------- | ------------------------------------ | ------------------------------------------------------------ |
| 系统管理员     | 拥有部门管理模块的所有操作权限       | 部门增删改查、状态管理、排序设置                             |
| 部门管理员     | 拥有对部门及其下级部门的有限管理权限 | 查看部门、新增下级部门、编辑本部门及下级部门、管理状态和排序 |

### 权限矩阵

| 功能点               | 系统管理员 | 部门管理员            | 普通用户 |
| -------------------- | ---------- | --------------------- | -------- |
| 查看所有部门         | 支持       | 不支持                | 不支持   |
| 查看本部门及下级部门 | 支持       | 支持                  | 不支持   |
| 新增部门             | 支持       | 支持（仅下级部门）    | 不支持   |
| 编辑部门             | 支持       | 支持（本部门及下级部门） | 不支持 |
| 删除部门             | 支持       | 不支持                | 不支持   |
| 状态管理             | 支持       | 支持（本部门及下级部门） | 不支持 |
| 排序设置             | 支持       | 支持（本部门及下级部门） | 不支持 |
| 查看部门下拉选项     | 支持       | 支持（本部门及下级部门） | 不支持 |

删除部门权限仅限系统管理员，确保组织架构稳定性；部门管理员仅可操作本部门及下级部门范围内的数据。

### 根部门保护规则

| 规则         | 说明                                                          |
| ------------ | ------------------------------------------------------------- |
| 不可删除     | 系统内置根部门（id=1）不可删除                                |
| 不可修改上级 | 根部门不可修改 parentId，防止破坏树形结构根节点               |

## 功能需求

### 部门列表查询 (F-DM-001)

#### 功能描述

提供部门信息的树形展示和多条件筛选能力，支持管理员快速定位目标部门。

#### 查询条件

| 条件类型 | 字段     | 说明           | 匹配方式    |
| -------- | -------- | -------------- | ----------- |
| 部门名称 | keywords | 部门名称关键字 | LIKE        |
| 状态     | status   | 部门状态       | =（启用、禁用） |

部门列表默认不展示逻辑删除部门；部门管理员仅返回本部门及下级部门。

#### 列表展示字段

| 字段       | 显示名称 | 宽度  | 说明                    |
| ---------- | -------- | ----- | ----------------------- |
| name       | 部门名称 | 自动  | 树形结构展示，支持展开、收起 |
| status     | 状态     | 100px | 启用、禁用标签          |
| sort       | 排序     | 100px | 部门显示顺序            |
| createTime | 创建时间 | 180px | 部门创建时间            |
| -          | 操作     | 220px | 新增下级、编辑、删除    |

#### 业务规则

1. 树形结构展示，支持节点展开、收起
2. 逻辑删除部门不展示

### 部门新增 (F-DM-002)

#### 功能描述

支持创建新部门，包括基本信息设置、上级部门分配和排序设置。

#### 表单字段

| 字段     | 显示名称 | 类型       | 必填 | 默认值  | 校验规则                 |
| -------- | -------- | ---------- | ---- | ------- | ------------------------ |
| parentId | 上级部门 | 树形选择器 | 是   | -       | 不能为空                 |
| name     | 部门名称 | 输入框     | 是   | -       | 不能为空，同一层级下唯一 |
| sort     | 排序     | 数字输入框 | 是   | 1       | 必须为正整数             |
| status   | 状态     | 单选框组   | 是   | 启用(1) | 不能为空                 |

#### 业务规则

1. 部门名称唯一性：同一 parentId 下部门名称必须唯一（含逻辑删除记录校验）
2. 上级部门：必须选择一个上级部门（根部门除外）
3. 层级深度限制：新增后部门层级不超过 5 级
4. 权限控制：系统管理员可在任意部门下新增子部门；部门管理员仅可在本部门及下级部门下新增子部门

### 部门编辑 (F-DM-003)

#### 功能描述

支持修改现有部门的基本信息、上级部门和状态。

#### 可编辑字段

| 字段     | 是否可编辑 | 说明                       |
| -------- | ---------- | -------------------------- |
| name     | 是         | 可随时修改（需检查唯一性） |
| parentId | 是         | 支持部门层级调整           |
| sort     | 是         | 可修改排序值               |
| status   | 是         | 可启用、禁用               |

#### 业务规则

1. 部门名称：修改时需检查同一层级下名称是否唯一（排除自身）
2. 上级部门：不能选择自身或其子部门作为上级部门，防止循环引用
3. 根部门保护：根部门不可修改上级
4. 层级深度限制：移动部门后层级不超过 5 级
5. 权限控制：系统管理员可编辑所有部门；部门管理员仅可编辑本部门及下级部门

### 部门删除 (F-DM-004)

#### 功能描述

支持删除部门，包括单个删除。

#### 删除方式

| 方式     | 触发操作           | 说明         |
| -------- | ------------------ | ------------ |
| 单个删除 | 点击操作列删除按钮 | 删除单个部门 |

#### 业务规则

1. 二次确认：删除操作需弹窗确认
2. 关联用户检查：部门下存在关联用户时禁止删除
3. 子部门检查：部门下存在子部门时禁止删除，不级联删除，需先删除子部门
4. 根部门保护：根部门不可删除
5. 逻辑删除：数据保留可追溯，不做物理删除
6. 权限控制：仅系统管理员可删除部门

#### 确认提示

- 存在关联用户：`该部门下存在用户，无法删除。`
- 存在子部门：`该部门下存在子部门，请先删除子部门。`
- 无关联数据：`确认删除部门「{deptName}」吗？`

### 新增下级部门 (F-DM-005)

#### 功能描述

支持在当前部门下快速新增子部门。

#### 操作流程

点击新增下级按钮 → 打开部门表单弹窗 → 上级部门自动填充当前部门 → 用户填写信息 → 提交保存

#### 业务规则

1. 上级部门预设：表单中的上级部门自动设置为当前选中部门
2. 层级限制：当前部门已达 5 级时，新增下级按钮禁用

### 部门状态管理 (F-DM-006)

#### 功能描述

支持启用或禁用部门，控制部门的可用状态。

#### 状态说明

| 状态值 | 显示             | 说明         |
| ------ | ---------------- | ------------ |
| 1      | 启用（绿色标签） | 部门正常使用 |
| 0      | 禁用（灰色标签） | 部门暂停使用 |

#### 业务规则

1. 状态切换：可通过编辑表单或状态开关切换状态，变更后立即生效
2. 不级联子部门：禁用部门不影响子部门状态，子部门保持各自独立状态
3. 不影响用户登录：部门下用户的登录由用户账户状态控制，与部门状态独立
4. 权限控制：系统管理员可管理所有部门状态；部门管理员仅可管理本部门及下级部门的状态

### 部门排序设置 (F-DM-007)

#### 功能描述

支持设置部门的显示顺序，控制部门树中的排列顺序。

#### 排序规则

按 sort 整数升序排列：同一层级内 sort 值越小越靠前，新增部门默认 1，支持任意调整且修改后立即生效。

#### 业务规则

1. 权限控制：系统管理员可设置所有部门的排序；部门管理员仅可设置本部门及下级部门的排序

### 部门下拉选项 (F-DM-008)

#### 功能描述

提供部门树形下拉选项，供用户管理等模块使用。

#### 数据要求

选项为树形结构，节点包含部门 ID、部门名称与子部门列表。

#### 使用场景

1. 用户新增、编辑时选择所属部门
2. 角色数据权限配置时选择数据范围
3. 其他需要按部门筛选的场景

#### 业务规则

1. 状态过滤：可配置是否仅返回启用状态的部门
2. 权限过滤：按用户数据权限过滤可访问的部门（部门管理员仅返回本部门及下级部门）
3. 删除过滤：逻辑删除部门不返回

## 界面交互规范

### 页面布局

部门管理页面采用单栏布局，包含搜索条件区域、操作按钮区域和部门树形数据表格。

### 交互规则

#### 本模块特有交互

| 场景         | 行为                                    |
| ------------ | --------------------------------------- |
| 打开新增表单 | 清空表单数据，默认值：状态=启用，排序=1 |
| 打开编辑表单 | 加载部门详情                            |
| 新增下级部门 | 上级部门自动填充为当前选中部门          |
| 树形结构     | 默认展开所有节点，支持展开、收起操作    |
| 第 5 级部门  | 新增下级按钮禁用                        |

#### 确认提示文案

- 根部门保护：`根部门不可删除/修改上级。`

## 安全设计

### 权限控制

部门管理员仅可操作本部门及下级部门范围内的数据，不可删除部门。

### 数据安全

部门数据按用户数据权限范围隔离，关键操作需鉴权并记录操作日志。

### 输入校验

部门名称唯一性、上级部门合法性与循环引用由服务端校验。

## 多端需求

| 端                         | 部门管理入口 | 说明                                                 |
| -------------------------- | ------------ | ---------------------------------------------------- |
| Web Vue/React              | 后台管理页面 | 完整部门管理功能                                     |
| Electron 桌面端            | 后台管理页面 | 复用 Web 端管理能力                                  |
| Android/Flutter/小程序     | -            | 不开放后台部门管理入口，仅作为用户归属与数据权限依据 |

各端查询返回一致数据；部门下拉选项用于各端用户管理场景。
