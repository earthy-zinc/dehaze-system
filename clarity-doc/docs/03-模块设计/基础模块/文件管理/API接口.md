# 文件管理模块 API 接口

## 文档概述

- 基础路径：`/api/v1/files`
- 文件管理是基础能力模块，不提供独立前端界面，主要为其他业务模块提供 API 服务。
- 接口详细参数与响应结构由代码定义，可通过 API 文档 MCP 查询。

## 接口清单

| 路径                                  | 方法   | 功能描述                         | 权限标识      | 关联功能点 |
| ------------------------------------- | ------ | -------------------------------- | ------------- | ---------- |
| `/api/v1/files`                       | POST   | 文件上传                         | `file:upload` | F-FM-001   |
| `/api/v1/files/download/{objectName}` | GET    | 文件下载                         | -             | F-FM-002   |
| `/api/v1/files?fileId={fileId}`       | DELETE | 文件删除（fileId 为 query 参数） | `file:delete` | F-FM-003   |
| `/api/v1/files/check`                 | GET    | MD5 校验（秒传预检）             | -             | F-FM-004   |
| `/api/v1/files/page`                  | GET    | 文件分页查询                     | -             | F-FM-005   |
| `/api/v1/files/{fileId}`              | GET    | 文件详情查询                     | -             | F-FM-006   |

## 权限标识汇总

| 权限标识      | 说明                     |
| ------------- | ------------------------ |
| `file:upload` | 文件上传                 |
| `file:delete` | 文件删除                 |
| -             | 其他接口登录用户即可访问 |

## 业务错误码

| 错误码  | 说明           | 触发场景                                                                     |
| ------- | -------------- | ---------------------------------------------------------------------------- |
| `B0401` | 文件不存在     | 下载、删除、查询不存在的文件（含已软删文件）                                 |
| `B0402` | 文件过大       | 上传文件超过大小限制（100MB）                                                |
| `B0403` | 文件类型不支持 | 图片扩展名与文件内容不符（文件头魔数校验）                                   |
| `B0404` | MD5 格式无效   | MD5 校验接口参数格式错误                                                     |
| `B0405` | 文件存储失败   | 对象存储服务异常                                                             |
| `B0406` | 文件已损坏     | 文件元数据存在但物理文件丢失                                                 |
| `B0407` | 无权访问该文件 | 普通用户越权访问、下载、删除他人文件（管理员全量；check 秒传预检豁免归属校验） |
