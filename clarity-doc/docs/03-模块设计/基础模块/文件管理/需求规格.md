# 文件管理模块需求规格

## 模块概述

### 模块定位

文件管理模块是 AI 图像处理平台的 BFF 层基础服务模块，负责提供通用的文件上传、下载、删除、查询和去重等基础能力，作为数据集图片管理、算法模型文件管理、图像处理结果存储等业务模块的底层支撑。该模块不提供独立前端界面，由业务模块调用上传、下载接口。

### 核心价值

| 价值维度   | 具体内容                                                                 |
| ---------- | ------------------------------------------------------------------------ |
| 统一存储   | 提供统一的文件存储抽象层，支持对象存储、本地存储等多种存储后端           |
| 物理去重   | 基于 MD5 指纹实现物理文件去重（MD5 相同复用同一物理文件），节省存储空间 |
| 元数据独立 | 每次上传创建独立文件元数据记录，多业务引用同一物理文件各自维护元数据     |
| 通用能力   | 为业务模块提供标准化的文件上传、下载、删除接口                           |

### 业务目标

#### 功能目标

- 提供通用的文件上传能力（物理文件去重 + 元数据独立）
- 提供文件下载能力（登录鉴权 + 归属校验 + 流式传输）
- 提供文件删除能力（元数据先标记删除，物理文件由定时对账任务清理）
- 提供文件指纹校验能力，实现物理文件去重与秒传
- 支持文件分页查询与关键字筛选

#### 性能目标

| 指标             | 目标值    | 说明                                           |
| ---------------- | --------- | ---------------------------------------------- |
| 上传响应时间     | &lt;3s    | 单个文件上传接口响应时间（含 MD5 计算，≤10MB） |
| 下载响应时间     | &lt;500ms | 文件下载请求响应时间（不含传输时间）           |
| 查询响应时间     | &lt;300ms | 文件分页查询响应时间                           |
| 去重校验时间     | &lt;100ms | MD5 校验接口响应时间                           |
| 并发上传数       | ≥50       | 支持的最大并发上传请求数                       |

## 功能需求

### 文件上传 (F-FM-001)

#### 功能描述

文件写入存储服务并记录文件元数据，采用物理文件去重 + 元数据独立策略：MD5 相同的文件复用同一物理文件，每次上传创建独立的文件元数据记录。

#### 业务规则

1. MD5 唯一去重：同一内容全系统仅一条元数据记录（同一文件标识），重复上传相同内容命中秒传并复用既有记录；已软删记录重新上传时复活（deleted 归 0，新文件信息覆盖）。物理文件按内容寻址命名，天然幂等。
2. 文件类型限制：支持的文件类型由业务模块控制，本模块不做白名单限制；仅图片类型（jpg/jpeg/png/gif/bmp/webp）在上传时校验文件头魔数与扩展名一致，不符则拒绝。
3. 文件大小限制：单文件上限 100MB（三端统一），超限拒绝。
4. 归属校验：普通用户仅可见、可操作本人上传的文件，管理员（ROOT/ADMIN）可操作全部，越权访问被拒绝。MD5 秒传预检不涉及归属，请求方持有完全相同内容才命中，无保密性泄露。

### 文件下载 (F-FM-002)

#### 功能描述

支持下载文件，下载需登录并通过归属校验，请求经流式传输返回文件内容。

#### 业务规则

1. 登录鉴权：下载接口需登录，普通用户仅可下载本人上传的文件，管理员可下载全部，越权访问被拒绝。
2. 文件名编码：下载文件名需正确编码，避免中文乱码。
3. 路径安全：防止路径遍历攻击，拒绝 `..`、绝对路径、反斜杠。

### 文件删除 (F-FM-003)

#### 功能描述

支持删除文件：元数据先标记删除（逻辑删除），物理文件由定时对账任务清理，元数据保留可追溯。

#### 业务规则

1. 删除语义：元数据软删除，物理文件立即删除（失败仅记录日志，残留文件由定时对账任务兜底清理）。
2. 归属校验：普通用户仅可删除本人上传的文件，管理员可删除全部，越权访问被拒绝。
3. 关联检查：删除前是否被其他业务数据引用的检查由调用方（业务模块）负责。
4. 逻辑删除：元数据逻辑删除，数据保留可追溯。

#### 删除确认

- 调用方（业务模块）在删除文件前应弹窗确认
- 确认文案："确认删除该文件吗？"

### 文件校验（MD5 去重检查） (F-FM-004)

#### 功能描述

提供文件 MD5 校验能力，用于在上传前检查物理文件是否已存在，实现秒传。该接口不做归属校验：请求方持有完全相同的内容（md5 命中）才返回文件信息，无保密性泄露。

#### 业务规则

1. MD5 格式校验：校验 MD5 是否为有效的 32 位十六进制字符串。
2. 秒传场景：前端在上传前先调用该接口，物理文件已存在则跳过文件流上传，仅传 MD5 创建元数据。
3. 命中时返回文件信息，未命中时返回空。

### 文件分页查询 (F-FM-005)

#### 功能描述

提供文件列表的分页查询能力，支持关键字搜索，便于系统管理员查看和管理已上传的文件。

#### 列表展示字段

编号、文件名、文件类型、文件大小（字节，前端格式化显示）、存储路径、文件指纹、创建时间。

#### 分页配置

默认每页 10 条，可选 10、20、50、100。

#### 业务规则

1. 关键字匹配：支持按文件名或文件类型模糊匹配。
2. 排序规则：默认按创建时间倒序排列（最新上传的在前）。
3. 数据权限：系统管理员可查看所有文件，其他角色由调用方控制权限。

### 文件详情查询 (F-FM-006)

#### 功能描述

按文件标识获取文件完整元数据信息。

#### 业务规则

1. 文件不存在：文件标识不存在时返回文件不存在错误。
2. 访问控制：业务模块需自行控制文件详情查询权限。

## 界面交互规范

文件管理模块不提供独立前端界面，以下错误提示文案供调用方（业务模块）参考。

| 错误场景         | 提示文案                                             |
| ---------------- | ---------------------------------------------------- |
| 文件过大         | "文件大小超过限制（图像最大 100MB，模型最大 500MB）" |
| 文件类型不支持   | "不支持的文件类型"                                   |
| 文件指纹校验失败 | "文件指纹格式不正确"                                 |
| 文件不存在       | "文件不存在或已被删除"                               |
| 删除失败         | "删除失败，请重试"                                   |

2. 文件保留期限：文件元数据与物理文件是否需要设置过期清理策略（当前仅清理孤儿文件，无主动过期）？图像处理结果文件的保留期限与任务结果保留期（7 天）如何协同？
3. 文件类型白名单：是否需要配置文件类型白名单限制可上传的文件类型？
4. 临时文件管理：处理过程中的临时文件是否需要独立管理策略？
