# 图像输入模块 API 接口

## 文档概述

- 基础路径：`/api/v1/image-input`（本模块历史记录接口）；图片上传与样例图片查询复用数据集管理模块接口（`/api/v1/dataset-items`、`/api/v1/item-files`）
- 需求规格：[需求规格.md](./需求规格.md)

## 接口清单

### 图片上传接口（复用数据集管理 / 文件管理）

| 路径                           | 方法 | 功能描述                                                                             | 权限标识           | 关联功能点 |
| ------------------------------ | ---- | ------------------------------------------------------------------------------------ | ------------------ | ---------- |
| `/api/v1/files`                | POST | 单图上传（图像输入页/拍照的实际上传入口），MD5 去重+文件头魔数校验，复用文件管理模块 | 登录即可           | F-M01-001  |
| `/api/v1/files/check`          | GET  | MD5 秒传预检（前端上传前调用），复用文件管理模块                                     | 登录即可           | F-M01-001  |
| `/api/v1/dataset-items/upload` | POST | 上传配对图片（清晰图+有雾图），复用数据集管理模块                                    | `sys:dataset:edit` | -          |
| `/api/v1/item-files`           | POST | 向数据项挂载图片文件，复用数据集管理模块                                             | `sys:dataset:edit` | -          |

### 样例图片库接口（复用数据集管理）

样例图片库来源于数据集管理模块中标记为"公开展示"的数据项。

| 路径                         | 方法 | 功能描述                                     | 权限标识 | 关联功能点 |
| ---------------------------- | ---- | -------------------------------------------- | -------- | ---------- |
| `/api/v1/dataset-items`      | GET  | 查询公开数据项（样例库），复用数据集管理模块 | -        | -          |
| `/api/v1/dataset-items/{id}` | GET  | 获取样例图片详情，复用数据集管理模块         | -        | -          |

### 历史记录管理接口（本模块新增）

| 路径                                | 方法   | 功能描述         | 权限标识       | 关联功能点 |
| ----------------------------------- | ------ | ---------------- | -------------- | ---------- |
| `/api/v1/image-input/history`       | GET    | 分页查询历史记录 | -              | F-M01-004  |
| `/api/v1/image-input/history/{id}`  | GET    | 获取历史记录详情 | -              | F-M01-004  |
| `/api/v1/image-input/history`       | POST   | 创建历史记录     | -              | F-M01-004  |
| `/api/v1/image-input/history/{id}`  | DELETE | 删除单条历史记录 | `image:delete` | F-M01-004  |
| `/api/v1/image-input/history/batch` | DELETE | 批量删除历史记录 | `image:delete` | F-M01-004  |
| `/api/v1/image-input/history/clear` | DELETE | 清空历史记录     | `image:delete` | F-M01-004  |

收藏状态通过收藏管理模块 `/api/v1/favorites` 统一管理，历史记录接口不维护收藏字段。

## 权限标识汇总

| 权限标识           | 说明                                                                                                                                                                        |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `sys:dataset:edit` | 数据集图片写操作（dataset-items 上传/挂载 item-files，与数据集管理模块共用）                                                                                                |
| -                  | 登录态接口：单图上传 `/api/v1/files`、样例查询、历史记录全部接口（历史记录通过 user_id 自动隔离，本人可删，无需独立权限码） |

## 业务错误码

历史记录接口（本模块实现）实际返回：

| 错误码  | 说明               | 触发场景                                                                          |
| ------- | ------------------ | --------------------------------------------------------------------------------- |
| `A0400` | 用户请求参数错误   | status 越界、inputSource 非法、字段超长、modelParams 非法 JSON、批量删除 ids 非法 |
| `A0401` | 请求资源不存在     | 查询/删除不存在或非本人的历史记录（同一语义，不泄露存在性）                       |
| `A0230` | token 无效或已过期 | 未认证访问                                                                        |

上传链路（由文件管理/数据集管理模块返回，详见各自 API 文档）：

| 错误码  | 说明                              | 触发场景                             |
| ------- | --------------------------------- | ------------------------------------ |
| `B0402` | 文件大小超限                      | 超过 `MAX_UPLOAD_SIZE`               |
| `B0403` | 不支持的文件类型 / 内容与类型不符 | 伪装扩展名（文件头魔数校验失败）     |
| `B0404` | MD5 格式无效                      | `/api/v1/files/check` 传入非法 MD5   |
| `A0301` | 权限不足                          | 无 `sys:dataset:edit` 操作数据集图片 |

历史记录不存在语义统一为 `A0401`（不使用 `B0300`、`B0301` 错误码）；超配额行为为自动清理最旧记录（见 [后端实现.md](./后端实现.md)），不报错。
