# 效果对比模块 API 接口

## 文档概述

- **基础路径**：
  - 效果评估：`/api/v1/evaluation`
  - 对比报告：`/api/v1/compare`
- **需求规格**：[需求规格.md](./需求规格.md)

评估与报告生成均为计算密集型异步任务，POST 立即返回任务 ID 与处理中状态，前端通过 GET 轮询直至终态。

## 接口清单

### 效果评估接口

| 路径                          | 方法 | 功能描述                                                                                         | 权限标识             | 关联功能点 |
| ----------------------------- | ---- | ------------------------------------------------------------------------------------------------ | -------------------- | ---------- |
| `/api/v1/evaluation`          | POST | 提交效果评估（结果图 + 参考图 + 模型ID，异步）                                                   | `evaluation:execute` | F-M02-005  |
| `/api/v1/evaluation/{taskId}` | GET  | 查询评估任务状态（1 处理中 / 2 已完成 / 3 失败），仅任务归属用户可访问                           | -                    | F-M02-005  |
| `/api/v1/evaluation/metrics`  | GET  | 获取评估指标历史（当前用户，仅已完成的效果评估记录，`task_type='evaluation'`，不混入对比报告行） | -                    | F-M02-005  |
| `/api/v1/evaluation/logs`     | GET  | 获取评估日志列表（当前用户，分页，支持模型ID筛选）                                               | -                    | F-M02-005  |

评估指标：PSNR、SSIM、LPIPS 需参考图；NIQE、NIMA、BRISQUE 为无参考指标。

评估响应字段为 camelCase：`logId`、`status`（1 处理中、2 已完成、3 失败）、`metrics`、`predMd5`、`gtMd5`、`time`（秒）、`errorMessage`。`metrics` 在已完成时返回，`errorMessage` 在失败时返回。`predMd5`、`gtMd5` 是图像任务图与参考图的内容 MD5，由编排侧下载图片时计算（调用方只有 URL，算不出内容 MD5），Java/Go 据此写入各自 `sys_eval_log` 的 `pred_md5`、`gt_md5` 列，不得用 URL 的 MD5 冒充。


### 对比报告接口

| 路径                              | 方法 | 功能描述                                                                                  | 权限标识             | 关联功能点 |
| --------------------------------- | ---- | ----------------------------------------------------------------------------------------- | -------------------- | ---------- |
| `/api/v1/compare/report`          | POST | 生成对比报告（异步），请求体仅含 `logId`（格式固定为 HTML），logId 须为当前用户的处理记录 | `evaluation:execute` | F-M02-008  |
| `/api/v1/compare/report/{taskId}` | GET  | 查询报告状态（返回 JSON）；`?download=true` 时返回 HTML 报告文件流，仅报告归属用户可访问  | -                    | F-M02-008  |

## 权限标识汇总

| 权限标识             | 说明                                                                                         |
| -------------------- | -------------------------------------------------------------------------------------------- |
| `evaluation:execute` | 提交效果评估、生成对比报告                                                                   |
| -                    | 登录态接口：查询评估任务状态、评估指标历史、评估日志、查询报告状态（评估为免费能力，不计费） |

## 业务错误码

| 错误码  | 说明              | 触发场景                                                     |
| ------- | ----------------- | ------------------------------------------------------------ |
| `A0401` | 请求资源不存在    | 评估任务不存在、对比报告不存在、处理记录不存在、报告内容为空 |
| `A0500` | 业务异常          | 处理任务尚未完成，无法生成报告                               |
| `B0001` | 系统执行出错      | 报告生成失败                                                 |
| `A0230` | token无效或已过期 | 未登录访问                                                   |
