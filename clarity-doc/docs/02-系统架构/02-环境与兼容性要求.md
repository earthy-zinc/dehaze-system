# 澄莹智能图像处理平台 - 环境与兼容性要求

## 技术栈全景

```mermaid
mindmap
  root((AI 图像处理平台))
    前端
      Vue3 + TypeScript
      React + TypeScript
      Flutter + Dart
      UniApp / Taro
    后端
      Java + Spring Boot 3
      Go + Gin
      Python + FastAPI
    算法服务
      Python + PyTorch（内嵌于 Python 业务后端）
    数据存储
      MySQL 8.0
      Redis 6.0+
      MongoDB
      RabbitMQ
      Elasticsearch
      MinIO
```


## 硬件环境要求

### 开发环境

| 组件 | 最低配置   | 推荐配置                 |
| ---- | ---------- | ------------------------ |
| CPU  | 4 核       | 8 核+                    |
| 内存 | 8 GB       | 16 GB+                   |
| 存储 | 100 GB SSD | 256 GB SSD               |
| GPU  | -          | NVIDIA GPU（开发算法时） |

本项目采用 dev / pre（preview）双环境：dev 用于开发自测与热更新，pre 只测不开发。两环境对硬件的需求一致（均复用同一组中间件实例），数据层隔离与环境变量差异见 [10-多环境部署实践](./10-多环境部署实践.md)。

### 算法服务生产环境

| 项目       | 要求                                    |
| ---------- | --------------------------------------- |
| 操作系统   | Ubuntu 18.04+ / Windows 10+ / CentOS 7+ |
| CPU        | 8 核+                                   |
| 内存       | ≥ 16 GB（推荐 32 GB）                   |
| GPU        | NVIDIA GPU，显存 ≥ 8 GB（推荐 16 GB+）  |
| GPU Driver | 450+                                    |
| CUDA       | 10.1+ / 11.x / 12.x                     |

### 业务服务生产环境

| 服务类型   | CPU   | 内存  | 存储       |
| ---------- | ----- | ----- | ---------- |
| 业务服务   | 4 核+ | 8 GB+ | 50 GB SSD  |
| 数据库服务 | 4 核+ | 8 GB+ | 200 GB SSD |
| Redis 服务 | 2 核+ | 4 GB+ | 20 GB SSD  |
| MinIO 存储 | 2 核+ | 4 GB+ | 500 GB+    |
