## 文档说明

本文档为图片查看与标注功能的后端代码设计方案，包含图片详情查看、信息编辑、人工标注、配对图片管理等核心功能。

**设计原则**：
1. **功能合并**：将图片信息修改与标注功能合并为统一接口
2. **自动解析**：上传时自动解析图片宽高，减少人工输入
3. **缓存优化**：场景类型列表使用 Redis 缓存，提升搜索建议响应速度

### 3.1 图片上传接口现状说明

#### 3.1.1 当前实现

**接口**：`POST /api/v1/dataset/image`

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| file | MultipartFile | 是 | 图片文件 |
| datasetId | Long | 是 | 所属数据集ID |
| datasetItemId | Long | 是 | 所属数据项ID |
| type | String | 是 | 图片类型（clear/hazy/dehazed） |
| description | String | 否 | 图片描述 |
| sceneType | String | 否 | 场景类型（用户自定义） |
| hazeLevel | String | 否 | 雾霾程度（light/medium/heavy） |

**响应结构**：

```json
{
  "code": "00000",
  "data": {
    "id": 1,
    "datasetItemId": 100,
    "fileId": 200,
    "type": "hazy",
    "description": "城市街道",
    "url": "http://xxx/image.jpg"
  }
}
```

**实现特性**：
- 上传时自动解析图片宽高，存入 `sys_item_file` 表
- 自动生成缩略图（400x400）
- 支持可选的标注信息（sceneType、hazeLevel）
- 新增场景类型时自动更新 Redis 缓存

### 3.7 数据流说明

#### 3.7.1 图片详情查询流程（已实现）

```
前端请求 GET /api/v1/dataset/image/{id}
    ↓
SysItemFileController.getImageDetail(id)
    ↓
SysItemFileService.getImageDetail(id)
    ↓
1. 查询 sys_item_file（含 width、height、scene_type、haze_level、usage_count）
2. 关联查询 sys_file 获取文件信息
3. 关联查询 sys_dataset_item 获取数据项信息
4. 关联查询 sys_dataset 获取数据集信息
5. 组装 ImageDetailVO
    ↓
返回 Result<ImageDetailVO>
```

#### 3.7.2 图片信息修改流程（已实现）

```
前端请求 PUT /api/v1/dataset/image
    ↓
SysItemFileController.updateImageById(form)
    ↓
SysItemFileService.updateImageInfo(form)
    ↓
1. 根据 itemFileId 查询 SysItemFile
2. 更新 type、scene_type、haze_level、description 字段
3. 如果 scene_type 是新值，调用 DatasetCacheService.addSceneType()
4. 执行 updateById 操作
5. 清除所属数据集的统计缓存
    ↓
返回 Result<Void>
```

#### 3.7.3 数据项详情查询流程（建议方案）

```
前端请求 GET /api/v1/dataset/item/{id}
    ↓
SysDatasetItemController.getItemDetail(id)
    ↓
SysDatasetItemService.getItemDetail(id)
    ↓
1. 查询 sys_dataset_item 获取基本信息
2. 调用 sysItemFileService.getImageUrlVOs(itemId) 获取所有图片
3. 按 type 分离：
   - type='clear' → clearImage
   - type='hazy' → hazyImages（按 haze_level 排序）
4. 组装 DatasetItemDetailVO
    ↓
返回 Result<DatasetItemDetailVO>
```

## 4. 异常处理与边界情况

### 4.1 数据不存在

| 触发条件 | 调用方可见行为 |
|---------|--------------|
| 数据项ID不存在 | 返回错误码 A0400，提示"数据项不存在" |
| 图片文件ID不存在 | 返回错误码 A0400，提示"图片不存在" |

### 4.2 参数校验异常

| 触发条件 | 调用方可见行为 |
|---------|--------------|
| itemFileId 为空 | 返回错误码 A0001，提示"数据项文件ID不能为空" |
| 批量标注数量超限（> 50） | 返回错误码 A0001，提示"单次最多标注50张图片" |
| hazeLevel 不在字典范围内 | 返回错误码 A0001，提示"雾霾程度参数无效" |

### 4.3 业务校验异常

| 触发条件 | 调用方可见行为 |
|---------|--------------|
| 清晰图重复上传 | 返回错误码 A0001，提示"该数据项已存在清晰图" |
| 有雾图缺少雾霾程度 | 返回错误码 A0001，提示"请为有雾图指定雾霾程度" |

## 5. 安全与性能注意事项

### 5.1 安全方面

| 安全项 | 措施 |
|-------|------|
| 权限控制 | 图片查看、修改接口需要登录认证 |
| 文件访问 | 文件URL通过后端代理访问，不直接暴露存储路径 |
| 输入校验 | sceneType 长度限制64字符，description 长度限制255字符 |
| 枚举校验 | hazeLevel 必须在 light/medium/heavy 范围内 |

### 5.2 性能方面

| 性能项 | 措施 |
|-------|------|
| 关联查询优化 | 确保 item_id、file_id 字段有索引 |
| 缓存策略 | 场景类型列表缓存30分钟（Redis Set） |
| 批量操作 | 批量标注使用批量更新SQL，避免循环单条更新 |
