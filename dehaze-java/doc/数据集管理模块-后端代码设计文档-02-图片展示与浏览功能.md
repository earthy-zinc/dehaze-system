## 文档说明

本文档为图片展示与浏览功能的后端代码设计方案，包含图片列表查询、多模式展示支持、图片搜索筛选、大图查看、配对图片下载等核心功能。

**设计原则**：
1. **增量改造**：在现有接口基础上扩展，保持向后兼容
2. **分页优先**：所有列表接口必须分页，支持无限滚动加载
3. **性能优化**：合理使用缓存、索引，避免N+1查询问题

---

## 1. 修改目标与范围定位

### 1.1 核心目标

本次改动的核心目标：
- 完善图片列表查询接口，支持多种展示模式（列表、瀑布流、网格）所需的数据结构
- 实现图片多条件搜索与筛选功能，支持相关度排序
- 实现大图查看详情接口，支持配对图片切换
- 实现配对图片下载功能（单张/打包下载）
- 支持批量操作（批量删除、批量下载）

#### 3.3.2 【建议方案】配对图片下载接口

**接口设计**：

```
POST /api/v1/dataset/item/file/download/paired

功能：下载配对图片（支持多种下载模式）

请求体：
{
  "itemFileId": 123,          // 当前图片ID

- 单张下载：直接返回文件流
- 打包下载：返回 ZIP 文件流
```

**实现步骤**：
1. 新增 `PairedDownloadForm.java` 表单类
2. 在 `SysItemFileController` 中新增 `downloadPairedImages(PairedDownloadForm form, HttpServletResponse response)` 方法
3. 实现逻辑：
   - 根据 downloadType 确定需要下载的图片列表
   - 单张图片直接返回文件流
   - 多张图片打包成 ZIP 后返回

### 3.6 数据流说明

#### 3.6.1 图片列表查询流程

```
前端请求 GET /api/v1/dataset/{id}/images?pageNum=1&pageSize=20
    ↓
SysDatasetController.getImageItem()
    ↓
SysDatasetItemService.getPagedImageItemVOs(datasetId, pageNum, pageSize)
    ↓
1. 调用 getLeafDatasetId(datasetId) 获取叶子节点ID列表
2. 分页查询 sys_dataset_item 表
3. 对每个数据项，调用 sysItemFileService.getImageUrlVOs() 获取图片URL
4. 填充配对图片数量、文件大小等扩展字段
5. 组装 ImageItemVO 列表
    ↓
返回 PageResult<ImageItemVO>
```

#### 3.6.2 配对图片下载流程

```
前端请求 POST /api/v1/dataset/item/file/download/paired
    ↓
SysItemFileController.downloadPairedImages(form, response)
    ↓
SysItemFileService.downloadPairedImages(form, response)
    ↓
1. 根据 itemFileId 获取 itemId
2. 根据 downloadType 确定下载范围：
   - current: 查询当前图片
   - clear: 查询 type='clear' 的图片
   - hazy_all: 查询 type='hazy' 的所有图片
   - all: 查询该 itemId 下所有图片
3. 获取文件列表
4. 单张直接返回，多张打包成 ZIP
    ↓
返回文件流
```

## 4. 异常处理与边界情况

### 4.1 参数校验异常

| 触发条件 | 调用方可见行为 |
|---------|--------------|
| 分页参数非法（pageNum <= 0） | 返回错误码 A0001，提示"页码必须大于0" |
| 每页数量超限（pageSize > 100） | 自动限制为100，不返回错误 |
| 批量删除数量超限（> 50） | 返回错误码 A0001，提示"单次最多删除50条" |
| 批量下载数量超限（> 100） | 返回错误码 A0001，提示"单次最多下载100张" |
| 筛选参数不在字典范围内 | 忽略该筛选条件，不返回错误 |

### 4.2 业务异常

| 触发条件 | 调用方可见行为 |
|---------|--------------|
| 图片不存在 | 返回错误码 A0002，提示"图片不存在" |
| 数据项不存在 | 返回错误码 A0002，提示"数据项不存在" |
| 文件存储服务不可用 | 返回错误码 B0001，提示"文件服务暂不可用，请稍后重试" |
| 下载的图片无配对清晰图 | 返回错误码 A0003，提示"该图片无配对清晰图" |

### 4.3 空数据处理

| 触发条件 | 调用方可见行为 |
|---------|--------------|
| 搜索无结果 | 返回空列表，total=0 |
| 数据项无配对图片 | 配对图片列表返回空，hasPairedImages=false |
| 批量操作列表为空 | 返回错误码 A0001，提示"请选择要操作的项目" |

## 5. 安全与性能注意事项

### 5.1 安全方面

| 安全项 | 措施 |
|-------|------|
| 关键词参数 | 长度限制100字符，过滤特殊字符防止SQL注入 |
| 分页参数 | pageSize 最大限制100，防止大量数据查询 |
| 枚举参数 | hazeLevel、processStatus 必须在字典白名单内 |
| 批量操作 | 限制单次操作数量，防止恶意大批量请求 |
| 文件下载 | 校验文件归属权限，防止越权下载 |

### 5.2 性能方面

| 性能项 | 措施 |
|-------|------|
| 索引优化 | 确保 scene_type、haze_level、process_status 字段有索引 |
| 分页查询 | 所有列表接口必须分页，禁止全量查询 |
| 批量查询 | 避免N+1查询，使用 IN 批量查询替代循环查询 |
| 缓存策略 | 场景类型列表缓存30分钟，减少数据库查询 |
| 文件下载 | 大文件使用流式传输，避免内存溢出 |
| ZIP打包 | 使用流式压缩，边压缩边传输 |

### 7.1 需求确认事项

| 事项 | 状态 | 说明 |

### 7.2 技术确认事项

| 事项 | 状态 | 说明 |
|-----|------|-----|
| 文件存储服务 | ✅ 已确认 | 使用 MinIO 对象存储 |
| ZIP 打包方案 | ✅ 已确认 | 使用 Java ZipOutputStream 流式压缩 |

### 7.3 潜在风险

| 风险 | 影响 | 建议措施 |
|-----|-----|---------|
| 多条件搜索SQL复杂度高 | 搜索性能下降 | 添加合适索引，后续可考虑引入 ES |
| 大批量下载占用服务器资源 | 服务器负载过高 | 限制并发下载数，大批量下载改为异步任务 |
| 配对图片数量过多 | 下载时间过长 | 限制单次下载图片数量，超过限制提示分批下载 |
