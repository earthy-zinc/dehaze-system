## 文档说明

本文档为图片上传与管理功能的后端代码设计方案，包含单张图片上传、配对图片上传、批量上传、图片下载等核心功能。

**设计原则**：
1. **自动解析**：上传时自动解析图片宽高、生成缩略图、计算MD5
2. **配对校验**：配对上传时严格校验分辨率一致性
3. **流式处理**：下载功能使用流式处理，避免内存溢出

### 3.2 【建议方案】配对图片上传

#### 3.2.1 新增 PairedUploadForm

**文件路径**：`model/form/PairedUploadForm.java`

**字段设计**：

| 字段 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| datasetId | Long | 是 | 所属数据集ID |

| hazeLevels | List\<String\> | 是 | 对应每张有雾图的雾霾程度 |

#### 3.2.2 新增配对上传接口

**接口设计**：

```
POST /api/v1/dataset/image/paired

功能：上传配对图片（一张清晰图+多张有雾图）

请求参数（multipart/form-data）：
- datasetId: 数据集ID（必填）
- itemName: 数据项名称（可选）
- sceneType: 场景类型（可选）
- description: 配对描述（可选）
- clearImage: 清晰图文件（必填）
- hazyImages: 有雾图文件列表（必填，至少1张）
- hazeLevels: 雾霾程度列表（必填，与hazyImages一一对应）

响应结构：
{
  "code": "00000",
  "data": {
    "itemId": 123,
    "itemName": "scene_001",
    "clearImageId": 100,
    "hazyImageIds": [101, 102, 103],
    "totalCount": 4
  }
}
```

**配对校验规则**：

| 校验项 | 规则 | 错误提示 |
|-------|------|---------|
| 清晰图必填 | clearImage 不能为空 | "请上传清晰图像" |
| 有雾图必填 | hazyImages 至少1张 | "请至少上传一张有雾图像" |
| 分辨率一致性 | 所有图片宽高必须完全相同 | "配对图片分辨率不一致" |
| 文件格式 | 必须为 jpg/png/gif | "仅支持 jpg/png/gif 格式" |
| 文件大小 | 单张不超过 10MB | "文件大小不能超过 10MB" |
| 雾霾程度必填 | 每张有雾图必须指定雾霾程度 | "请为有雾图选择雾霾程度" |
| hazeLevels数量 | 必须与hazyImages数量一致 | "雾霾程度数量与有雾图数量不匹配" |

**实现步骤**：
1. 在 `SysItemFileController` 中新增 `uploadPairedImages(PairedUploadForm form)` 方法
2. 在 `SysItemFileService` 中新增 `savePairedImages(PairedUploadForm form)` 方法
3. 实现逻辑：
   - 校验所有图片的分辨率一致性
   - 创建新的数据项（DatasetItem）
   - 保存清晰图（type='clear'）
   - 循环保存有雾图（type='hazy'，设置对应的hazeLevel）
   - 返回上传结果

### 3.4 【建议方案】图片下载功能

#### 3.4.1 单张图片下载接口

**接口设计**：

```
GET /api/v1/dataset/image/{id}/download

功能：下载单张图片原图

路径参数：
- id: ItemFile ID

响应：
- Content-Type: image/jpeg 或 image/png
- Content-Disposition: attachment; filename="xxx.jpg"
```

2. 实现逻辑：

### 3.6 数据流说明

#### 3.6.1 配对图片上传流程

```
前端请求 POST /api/v1/dataset/image/paired
    ↓
SysItemFileController.uploadPairedImages(form)
    ↓
SysItemFileService.savePairedImages(form)
    ↓
1. 解析所有图片的宽高
2. 校验分辨率一致性
3. 创建数据项（DatasetItem）
4. 保存清晰图：
   - 调用 saveItemFile(itemId, clearImageBO)
   - type='clear'
5. 循环保存有雾图：
   - 调用 saveItemFile(itemId, hazyImageBO)
   - type='hazy'，hazeLevel=对应值
6. 组装返回结果
    ↓
返回 Result<PairedUploadResultVO>
```

#### 3.6.2 单张图片下载流程

```
前端请求 GET /api/v1/dataset/image/{id}/download
    ↓
SysItemFileController.downloadImage(id, response)
    ↓
1. 根据 id 查询 sys_item_file
2. 关联查询 sys_file 获取 objectName
3. 调用 FileService.downLoadFile(objectName)
4. 设置响应头（Content-Type, Content-Disposition）
5. 流式写入响应
6. 调用 incrementUsageCount(id)
    ↓
返回文件流
```

#### 3.6.3 配对图片打包下载流程

```
前端请求 GET /api/v1/dataset/image/item/{itemId}/download
    ↓
SysItemFileController.downloadItemImages(itemId, response)
    ↓
1. 根据 itemId 查询所有关联的 ItemFile
2. 批量查询对应的 SysFile
3. 创建 ZipOutputStream
4. 遍历文件列表：
   - 获取文件流
   - 创建 ZIP 条目
   - 写入 ZIP
5. 设置响应头
6. 关闭流
    ↓
返回 ZIP 文件流
```

## 4. 异常处理与边界情况

### 4.1 上传异常

| 触发条件 | 调用方可见行为 |
|---------|--------------|
| 文件为空 | 返回错误码 A0001，提示"请选择要上传的文件" |
| 文件格式不支持 | 返回错误码 A0001，提示"仅支持 jpg/png/gif 格式" |
| 文件大小超限（> 10MB） | 返回错误码 A0001，提示"文件大小不能超过 10MB" |
| 配对分辨率不一致 | 返回错误码 A0001，提示"配对图片分辨率不一致" |
| 清晰图重复上传 | 返回错误码 A0001，提示"该数据项已存在清晰图" |
| 有雾图缺少雾霾程度 | 返回错误码 A0001，提示"请为有雾图选择雾霾程度" |

### 4.2 下载异常

| 触发条件 | 调用方可见行为 |
|---------|--------------|
| 文件不存在 | 返回错误码 A0400，提示"文件不存在" |
| 文件存储服务不可用 | 返回错误码 B0001，提示"服务暂时不可用，请稍后重试" |
| 批量下载数量超限（> 500） | 返回错误码 A0001，提示"单次下载不能超过500张图片" |
| 数据集过大 | 返回错误码 A0001，提示"数据集过大，请使用异步下载" |

### 4.3 删除异常

| 触发条件 | 调用方可见行为 |
|---------|--------------|
| 图片不存在 | 返回错误码 A0400，提示"图片不存在" |
| 批量删除数量超限（> 100） | 返回错误码 A0001，提示"单次最多删除100张图片" |

## 5. 安全与性能注意事项

### 5.1 安全方面

| 安全项 | 措施 |
|-------|------|
| 文件类型校验 | 仅允许 jpg/png/gif 格式，通过文件头校验 |
| 文件大小限制 | 单张图片最大 10MB，批量上传总大小最大 100MB |
| 文件名处理 | 过滤特殊字符，防止路径遍历攻击 |
| 下载权限 | 校验用户对数据集的访问权限 |
| 批量操作限制 | 限制单次操作数量，防止恶意请求 |

### 5.2 性能方面

| 性能项 | 措施 |
|-------|------|
| 流式处理 | 上传下载使用流式处理，避免内存溢出 |
| 缩略图生成 | 上传时异步生成缩略图，不阻塞主流程 |
| ZIP 打包 | 使用流式压缩，边压缩边传输 |
| 并发控制 | 限制同时下载的并发数 |
| 大文件处理 | 大数据集下载使用异步任务 |

## 7. 待确认事项与风险

### 7.1 需求确认事项

| 事项 | 状态 | 说明 |
|-----|------|-----|
| 配对图片分辨率校验 | ✅ 已确认 | 同一配对组内所有图片分辨率必须一致 |
| 批量上传文件名规则 | ✅ 已确认 | 支持 _clear/_gt/_hazy/_hazy_light 等后缀 |
| 下载目录结构 | 待确认 | 支持按数据项或按图片类型两种组织方式 |

### 7.2 技术确认事项

| 事项 | 状态 | 说明 |
|-----|------|-----|
| 文件存储方式 | ✅ 已确认 | 支持本地存储和 MinIO |
| 图片宽高解析 | ✅ 已实现 | 使用 ImageIO 解析 |
| 缩略图生成 | ✅ 已实现 | 400x400 尺寸 |

### 7.3 潜在风险

| 风险 | 影响 | 建议措施 |
|-----|-----|---------|
| 大数据集打包下载内存溢出 | 下载失败 | 使用流式处理，限制单次下载数量 |
| 打包下载耗时过长 | 用户体验差 | 大数据集采用异步打包，完成后通知用户 |
| 并发上传压力 | 服务器负载过高 | 限制并发上传数，使用队列处理 |
| 配对校验失败回滚 | 数据不一致 | 使用事务，失败时回滚已上传的文件 |
