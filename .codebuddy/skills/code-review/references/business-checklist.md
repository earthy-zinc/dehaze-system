# 业务契合度评审清单

## 需求覆盖度

- 核心功能是否全部实现
- 需求文档中的细节要求是否遗漏
- 数据字段是否与需求定义一致
- 交互流程是否符合设计稿

## 边界条件处理

| 场景 | 检查点 |
|------|--------|
| 空数据 | 是否有空状态展示 |
| 异常输入 | 是否有校验和提示 |
| 权限不足 | 是否有降级处理 |
| 网络异常 | 是否有重试/提示机制 |
| 并发操作 | 是否有冲突处理 |

## 业务流程完整性

- 操作前置条件校验
- 操作成功/失败反馈
- 状态流转符合业务规则
- 数据联动更新正确

## 用户体验

- 加载状态展示
- 危险操作确认提示
- 错误信息用户友好
- 国际化支持（如需要）

## 常见问题模式

1. **Happy Path Only**：只处理正常流程，忽略异常分支
2. **字段遗漏**：后端返回字段未完全使用
3. **状态不同步**：操作后未刷新关联数据
4. **缺少防重**：表单重复提交未限制
