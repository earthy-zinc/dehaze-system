# 明细：语言栈与工具链坑
> `dehaze-project-knowledge` skill 的参考文件（按需 read_file）。收录：JVM/Spring/MyBatis-Plus、Go/GORM/gin、Python/FastAPI/SQLAlchemy/推理库、TS/SDK/各前端栈、环境与工具链。
> 收录判据：**静默错数据 / 级联失败 / 编译通过但运行炸** 三类高复发坑；"读代码即知"的实现细节不收。

## 1. JVM / Maven / Spring
- **"单测全绿≠能启动"**：bean 歧义（同接口多实现无 `@Primary`）只在 `spring-boot:run` 暴露 ⇒ 改配置/新增实现/改注入点后须真启动。
- 编译前 `touch` 源文件防增量 class 陈旧（判据 `javap -v -p` 的 `RuntimeVisible*Annotations`，**勿用常量池 grep 计数**——同一注解只记一条）；mvn 须串行；编译错集中在 Lombok 生成成员 ⇒ 上游一条真错致注解处理中止，**先看第一条 `[ERROR]`**（重复注解 `@Valid @Valid` 即此因）；`target/surefire-reports/` 跨成员共享被覆盖。
- **Boot 3.5 升级坑**：okhttp 5.x 的 `okhttp` 工件是 KMP 伞包**不含 JVM class** ⇒ 必须显式依赖 `okhttp-jvm`；minio 9.0.3（`objectSize/partSize` int→Long、异常统一 `MinioException`）；redisson 3.24.3 的 `redisson-spring-data-31` 与 spring-data-redis 3.5 的 `pExpire` 默认实现**无限自递归 → StackOverflowError**（登录失败 count==1 时必炸）。
- Spring/Web：`DispatcherServlet.checkMultipart` 先于 handler ⇒ multipart 转发须以 `@Component("multipartResolver")` 覆盖 Boot 自动配置；`LocalDateTime` 需 `@DateTimeFormat("yyyy-MM-dd HH:mm:ss")`（ISO 绑定失败）、`LocalDate` 收 datetime → 400；`@RequestParam` vs `@RequestBody`（PATCH visible 必须 body）；正则 `.` 不匹配 CRLF 需 `(?s)`；`AccessDeniedException` → `@ResponseStatus(FORBIDDEN)` → 403 + A0301。
- **MyBatis-Plus 3.5.5**：`@TableLogic` 的 `delval` 原样拼接进 SQL（非参数绑定）⇒ `deleted` 字段**必须非 CharSequence**（String 会生成 `deleted='id'` 错误）；`yml` 的 `global-config.logic-delete-value` 覆盖一切（`GlobalConfig` bean 不被消费，删死代码 bean）；**`.like().or()` 会逃逸 `@TableLogic`**（经典坑，用 `.and(...)` 包裹）；`.eq(condition, col, val)` 的 val **总是被求值**（`getEnumByValue(null)` 抛 NPE → B0001 级联整文件挂）；软删查重需原生 SQL 绕 `@TableLogic`；纯 Mockito 单测对 `LambdaQueryWrapper.select(...)` 需 `TableInfoHelper.initTableInfo(...)`（否则 `can not find lambda cache`）。
- **非 `<script>` 注解 SQL 不解码 XML 实体**：`@Select` 里写 `&gt;=`/`&lt;=` 会原样进 SQL（只有 `<script>` 包裹的才经 XML 解码）⇒ JSQLParser 抛 `Failed to process, Error SQL` → 接口 500。判据：报错 SQL 文本里出现 `&gt;`。
- **SQL 关键字列名 + MP 自动列清单**：`input/output` 等列未加反引号 ⇒ JSQLParser `Encountered unexpected token`，整表 SELECT 全挂；实体须 `@TableField(value = "`input`")`（MySQL 允许裸关键字，JSQLParser 不允许）。
- **手写 `SELECT *` 返回实体时 typeHandler 不生效**：JSON 列（`List<String>` + `JacksonTypeHandler`）→ MP 自动 resultMap 只作用于生成 SQL，手写 select 读出 null ⇒ 加 `@Results(@Result(column=..., property=..., typeHandler=JacksonTypeHandler.class))`。
- **`Map.of(...)` 上 `containsKey(null)` 抛 NPE**（不可变 MapN + `Objects.requireNonNull`）⇒ 场景默认值判断须先判 null。

## 2. Go / GORM / gin
- **GORM 零值/默认值陷阱**：`default:1` 标签会让 Create 时零值字段被跳过（显式 `status=0` 落库变 1 ⇒ 禁用券/下架活动失效）⇒ 移除模型 default 标签（DB 列默认值不受影响）；`string` 型 JSON 列零值 `''` → `Error 3140: document is empty` ⇒ 补 `;default:null`（零值省略该列→落 NULL）；`time.Time` 零值 `'0000-00-00'` 撞 STRICT + NO_ZERO_DATE → `Error 1292`（**列有 DEFAULT 不等于不报错**）⇒ 补 `;autoCreateTime`/`;autoUpdateTime`；`Updates(map)` 不跳零值（`default:null` 无效）需 `jsonColumnValue`；NOT NULL 无默认的 JSON 列用 `;not null;default:'{}'`。
- **负 `Limit` ＝不写 LIMIT 返回全量**（GORM `*Limit>=0` 才写），最危险 ⇒ 须显式 400。
- 时间精度：列 DATETIME(0) 秒精度 ⇒ `NowFunc: time.Now().Truncate(time.Second)`（写入值≡回显值）、显式赋值一律 `.Truncate(time.Second)`。
- 本仓 **未开 `TranslateError`**：唯一键冲突须 `errors.As(&mysql.MySQLError{})` 判 1062（不能依赖 `gorm.ErrDuplicatedKey`）。
- **gin**：同一路径位置只允许一个通配符名（`/ai/agents/:id` 与 `/ai/agents/:agent_id/test` 共存会 panic）⇒ 全仓统一 `:id`；静态段与参数段同级 OK；`@Valid` 类重建后静态路径须注册在 `/:id` 之前。
- 启动：`setsid nohup`（普通 `nohup &` 被会话回收）；接口加方法后跑 `make mocks`，**禁 `--name/--dir` CLI**。

## 3. Python / FastAPI / 持久层 / 推理栈
- **pydantic-settings：dotenv 优先于类默认值** ⇒ 测试环境必须提前 `os.environ` 覆盖（判据：conftest 若 DROP 开发库即此因）；pydantic 默认 `extra="ignore"`（未知字段静默忽略，非报错）；**严格类型拒绝 None**（实体新字段未显式赋值时内存为 None，`VO: int` 会 ValidationError ⇒ 创建路径必须显式默认赋值如 `market_shared=0`）。
- **FastAPI 路由顺序**：静态段（`/market`、`/{module}/template|_export|_import`、`config-defaults`）必须声明在带路径参数（`/{id}`）之前，否则被吞掉；`require_permission` 装饰函数的**用户参数名必须为 `user`**（否则注入 `TypeError: missing 'user'` → 500 B0001）、必须 `return success(...)` 信封、勿声明与 `Result` 冲突的返回类型标注（ResponseValidationError 500）。
- **中间件注册顺序**：`ApiKeyAuthMiddleware` 必须**先注册（即后执行）**，否则 `request.state.db` 恒 None ⇒ 所有 `Bearer dhak_*` 请求 401「认证服务不可用」。
- **SQLAlchemy**：JSON 列**禁手动 `json.dumps`**（写入绑定再序列化＝双重编码字符串标量，新行也复现）⇒ 写入直传 dict，读取统一走 parse 函数；`with_loader_criteria` 对列级 `select` 同样生效（查软删行需 `include_deleted=True`）；`Core UPDATE` `synchronize_session=False` 不同步 identity map（勿用 `expire_all`，触发 MissingGreenlet）；`text() IN :models` 必须 `bindparam(expanding=True)`；Declarative 的 **`metadata` 是保留属性名**（字段须 `skill_metadata` 映射列名）；实体继承 BaseModel 含 `create_by/update_by` ⇒ DDL 必须带这两列。
- **异步/事务**：`get_db_session` 走真实引擎直接 commit ⇒ **无 db fixture 的用例禁止触发 `settle()`/`bypass_span` 落库**（会泄漏并污染测试库），要么挂 `db` fixture 走同源事务回滚，要么手动 `_settled=True`；真实 motor client 的 io loop 首次使用即绑定永久缓存 ⇒ `mongo_db` fixture 须 autouse；**签名与调用方/函数体不一致＝运行时炸弹**（漏参数只有全量回归能抓到）。
- **langchain/langgraph**：`StructuredTool.from_function` 对闭包 async 函数**误判为 sync**（ainvoke 返回未 await 的 coroutine）⇒ 显式传 `coroutine=`；`Command(goto="end")` 被忽略 ⇒ 用 `jump_to="end"`；`ainvoke` 的 ContextVar 副本上下文不可见 ⇒ 图路径读 `response_metadata`。
- **推理/文本**：**tiktoken cl100k_base 是字节级 BPE** ⇒ token 可跨多字节字符边界，按 token 硬切窗口 decode 产生 `U+FFFD`（对策：窗口首尾遇 `�` 借相邻 token 对齐字符边界）；`len(enc.encode(head))` 孤立编码 ≠ 上下文编码 token 数（必须二分映射）；**尾部小窗口必须整窗收尾不句切**（否则净前进→0，碎块被并成巨块）。**流式逐 chunk 做标签剥离是反模式**（标签可跨 chunk 拆分）⇒ 状态化解析放跨 chunk 消费端（`_ThinkSplitter`），本地只做无状态剥离；`try 内 return + finally 无条件 finish(aborted)` 会把所有正常调用标失败 ⇒ 用 `done` 标志 + `for 后 if not done`。
- **llama.cpp rerank**：`create_completion(logprobs=)` 需 `logits_all=True`（16k×15 万词表≈10GB）不可行 ⇒ 用 `reset()+eval()+llama_get_logits_ith(-1)` 取末位 logits 做 yes/no softmax；**Qwen3-Reranker 官方 assistant 后缀必须含空思考块 `<think>\n\n</think>`**，缺失则 top-1 是 `<think>`、打分全错；rerank 模型不自动下载（600MB），首次缺模型 → 后台 fcntl 跨进程互斥下载 + 503 稍后重试自愈。
- 其它：`fakeredis` 命令不产生 I/O ⇒ 并发竞态须用"每条命令前 `sleep(0)`"的代理客户端；`fakeredis`+`lupa` 支持 Lua eval；`strptime("%Y-%m")` 接受非零填充月份 `"2026-1"`（java `ofPattern("yyyy-MM")` 拒收 ⇒ 解析另用 `yyyy-M`，**格式化仍用 `yyyy-MM`**）；macOS `resource.setrlimit(RLIMIT_AS)` 抛 `ValueError` 须逐个 try/except 跳过；pymupdf 用内置 CJK 字体 `fontname="china-s"`（别硬编码 Noto 路径）；python 不在 PATH，脚本须用 `dehaze-python/.venv/bin/python`。
- **缓存**：`redis_operation_with_fallback` 首参必须是无参 async 函数；ES standard 分词器**下划线不切分**（全文检索测试数据须空格分隔/自然语言）。
- **uvicorn reload 会经 pdeathsig 连带杀掉本地 LLM 子进程（8992）**，需重新拉起。
- **mcp 两端必须同一条版本线（1.24.x）**：dehaze-python 的上下界由客户端依赖 `langchain-mcp-adapters`（METADATA 写死 `mcp<2.0.0,>=1.24.0`）决定，故 dehaze-mcp-gateway（uv 项目）也用 `mcp>=1.24.0,<1.25.0`；2.0 把服务端 `mcp.server.fastmcp.FastMCP` 改名为 `mcp.server.mcpserver.MCPServer`、客户端 `streamablehttp_client` 改名为 `streamable_http_client`。降级到 1.x 时网关只需三处改动：`FastMCP(name, host=...)`、`streamable_http_app()`（**1.x 不接受 host 参数**，host 在构造时给出并据此决定 localhost 的 DNS rebinding 白名单）。

## 4. TS / SDK / front-vue
- **`dehaze-sdk-js` 是跨端类型契约**（前端 `workspace:*` 消费 `dist/index.d.ts`）⇒ **改类型后必须 `pnpm build`**；收紧契约（改必填/改名/删字段）前先 `grep -rln` 全仓消费方并用 `vue-tsc --noEmit` 复核（IDE ts-plugin 会缓存旧 dist 报幽灵错 ⇒ **以命令行 vue-tsc 为准**，hover/goToDefinition 看行号是否偏移即可判定）。
- `exactOptionalPropertyTypes` 下可选属性**禁显式传 `undefined`**（用条件展开 `...(cond && {...})`）、「可选源→必填目标」必报错（正解通常是后端恒有值字段改必填）；类型断言靠 `npx tsc --noEmit`（**vitest 不做类型检查**；嵌套字面量每处只报首个错，需迭代）；`expectTypeOf` 负向断言（`not.toHaveProperty`）有假绿风险 ⇒ 须用"故意写旧键名让 tsc 报错"自证。
- **wire→SDK 请求体 camelCase 映射（如 `planEdit`→`plan_edit`）在 `src/api/ai-conversation/index.ts` 显式剥离，勿指望后端别名**；SDK 静态方法**重载更具体签名必须放前面**；上传 FormData 必须 `headers: {"Content-Type": undefined}`（否则 axios 保留 `application/json` → 后端 400 field required）。
- Vue：模板不支持 `as` 类型断言、不支持嵌套反引号模板字符串；`ref(ElForm)` 应改 `ref<FormInstance>()`；**禁止用 watch 值变化当打开事件**（mode 初值即等于目标值 → 永不触发），改显式 open 函数；递归 VNode 渲染函数需显式返回类型避免类型循环；`let msg = s.message ?? findMessage(...)` 会丢 null 推断 ⇒ 显式标注 `let msg: X | null = ... ?? null`。
- 前端流式占位消息（负数 id）依赖 `findMessage` 会被并发 `fetchMessages` 整体覆盖丢失 ⇒ `StreamSession` 持有 `message` 对象引用，`flush/onEnd/failMessage` 写引用而非数组查找；思考流段生命周期必须由 `content_block.start/stop(index=1)` 驱动（store 每帧整体搬走 + "兼容无 start"分支 = 每 rAF 帧切一段的碎片根因）。
- **Element Plus**：`el-table` 树形选择只需 `:tree-props="{ checkStrictly: false }"`（2.8.0+ 原生父子联动+半选）；`el-switch` 只有二态，用于 >2 态枚举会因归一化触发 `@change` → 请求失败回滚 → 再触发，形成**无限请求循环** ⇒ 多状态一律用 `el-tag`/`el-select`。
- 构建/验证：前端构建验证用 `npx vite build --outDir <临时目录>`（`pnpm build` 会被 IDE safe-delete shim 拦 dist 清理）；`markdown-it-texmath` 无类型 ⇒ `shims-vue.d.ts` 补 `declare module`。

## 5. RN / Flutter / Harmony / Taro / uniapp
- **依赖同步**：RN 用 yarn v1 `file:../dehaze-sdk-js` 是**复制** ⇒ SDK 改后必须 `npx tsup` 重建 dist + **手动 `cp -R dist` 到 node_modules** + `npx react-native start --reset-cache`；taro/uniapp 走 **pnpm workspace 软链**，`npx tsup` 后自动生效。`dehaze-react-native` 实际用 pnpm（`node-linker=hoisted`）且**不在根 `pnpm-workspace.yaml` packages 列表**，仓库残留 `package-lock.json`/`yarn.lock`（历史混用）。
- **RN 环境判别**：**不能用 `typeof window !== "undefined"`**（RN 有 window===globalThis 但无 `window.location`）⇒ 用 `navigator.product === "ReactNative"`（RN 无 userAgent）；全局错误 handler 内部必须防御式判断（handler 崩溃会掩盖原始错误）；Logger 覆盖 `ErrorUtils.setGlobalHandler` 必须链式调用 `originalHandler?.(error, isFatal)`。
- **RN 版本/构建**：react / react-test-renderer 必须与 react-native 锁定的 renderer **精确同版本**（0.81.4 → 19.1.0）；Xcode 26 下 `fmt@11.0.2` consteval 编译失败（facebook/react-native#55601）⇒ Podfile `post_install` 把 fmt target 的 `CLANG_CXX_LANGUAGE_STANDARD` 改 `c++17`（fmt base.h 无 `#if !defined` 守卫，**宏覆盖无效**）；错误输出里的 Yoga 命令是干扰项，grep `In file included from` 定位真源头。
- **zustand persist**：`onRehydrateStorage` 回调里直接 mutation `state.x` 不触发通知 ⇒ 必须 `useAuthStore.setState({...})`（否则永久 loading）。
- **Flutter**：`runZonedGuarded` 必须包裹 `WidgetsFlutterBinding.ensureInitialized()`（binding zone 与 runApp zone 必须一致）；设置 `FlutterError.onError` 后框架不再自动 `dumpErrorToConsole`（调用 `FlutterError.presentError` 会与 ConsoleTransport 双重输出）；macOS App Sandbox 默认禁出站 ⇒ **DebugProfile.entitlements 与 Release.entitlements 都要加 `com.apple.security.network.client`**，改后需 `flutter clean` + 重新 build（Hot Reload 不重编 native）；`Column` 默认 `crossAxisAlignment: start` 是塌缩首因（桌面端显式 `stretch`）、`GridView.childAspectRatio` 按子内容实际高度算、可变高度 Text 用 `Flexible`/`Expanded`、Row 每项加 right margin 用 `isLast` 判断（N-1 个间距）。
- **Harmony**：网络用 `@kit.NetworkKit` http（非 fetch）、存储用 `@kit.ArkData` preferences（非 localStorage），须在 `EntryAbility.onCreate` `await TokenManager.initialize(context)`；后端地址必须 `127.0.0.1`。
- **Taro/uni-app 工具链**：`@dcloudio/uni-h5` 硬锁 vue 3.4.21 ⇒ pinia 只能用 ≤2.2.4（更高版本要求 vue ^3.5.11）；`npx @dcloudio/uvm@latest` 强制交互不可非交互运行（改查 npm registry `vue3` dist-tag）；Taro/Webpack tsconfig 用 `module: ESNext` + `moduleResolution: bundler`；TS5.9+ 弃用 `baseUrl`（配了要带 `ignoreDeprecations`）；pnpm 不提升 transitive dep（Pinia 依赖 `@vue/devtools-api` 须显式装为直接依赖并清 `node_modules/.vite`）；node 22 自带全局 `navigator`（单测模拟裸小程序需 `vi.stubGlobal("navigator", undefined)`）。
- **Android**：全局状态铁律 **ViewModelProvider + Activity scope**（禁塞 Fragment scope 或绑 `getViewLifecycleOwner()`）；AAPT2 **单个 XML 编码声明错误（`encoding="utf8"` 缺连字符）会导致整个 drawable 目录被跳过**；本地日志 `files/logs/{yyyy-MM-dd}/{info,error}.log` NDJSON。
- **React 安全**：CVE-2025-55182（RSC 预认证 RCE，CVSS 10.0）修复版本 19.0.1/19.1.2/19.2.1；受影响包仅 `react-server-dom-*`；本仓仅 `dehaze-react-native`（react 19.1.0）曾受影响。

## 6. 环境与工具链
- **`rm`/`rmdir` 被 safe-delete shim 劫持**（实为移入 `~/.local/share/Trash/files/` + 写 `.trashinfo`，"删了又出现"，且不真正释放空间、对 Trash 目录操作 fail-closed）⇒ 真删用 `/usr/bin/rm`。
- **`search_content` 搜不到被 gitignore 的目录**（如 `dehaze-python/logs`）⇒ 须命令行 grep；**磁盘治理偏好＝迁移而非删除**（mv 到 `/data/root/` + 原位 symlink）；`/var/log/messages` 无 logrotate 会涨到 7.9G。
- **JDK 工具链**：`/usr/local/java/jdk25`（Temurin 25.0.4.1）编译运行 dehaze-java，字节码目标仍 17（`maven.compiler.release=17`）；`/usr/local/java/jdk21` 仅供 VS Code jdt.ls；构建 `JAVA_HOME=/usr/local/java/jdk25 mvn test`。
- macOS 用 `lsof -iTCP:<port> -sTCP:LISTEN` 替代 `run.py ps`（后者用 Linux `ss`）；`git filter-branch` 重写历史后 `format-patch` 不可用（hash 全变）⇒ 生成可应用 patch 用 `git diff <base> -- . ':!path'`，用 `git worktree` 隔离验证可应用性。
- 调试辅助：`.codebuddy/scripts/login_helper.py [go|python|java|all]`。
- **Python 类型检查范围/导入搜索根单点＝仓库根 `pyrightconfig.json`**：本 IDE 的 pyright 确实读它（日志 `Loading configuration file at ...`），存在时 `.vscode/settings.json` 的 `python.analysis.*` 被**整体忽略**（故不保留副本）。按目录区分环境只能用 `executionEnvironments`——**无 venv 字段**，只能追加 `extraPaths`，且 **extraPaths 不支持 glob**（venv 路径须写死 `lib/pythonX.Y/site-packages`，Windows 为 `Lib/site-packages`）；`executionEnvironments` 命中的文件其 env 级 extraPaths 会**替换**顶层 extraPaths（漏写会把原本能解析的模块打成 unresolved）。单根工作区**不读子目录 `.vscode/settings.json`**（folder settings 仅多根；`ms-pyright` 的 `python.pythonPath` scope=resource，多根时可按文件夹换解释器）。
