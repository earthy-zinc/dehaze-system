# 明细：跨端契约与一致性
> `dehaze-project-knowledge` skill 的参考文件（按需 read_file）。收录：parity 判据、错误码与响应信封、参数校验与分页、命名与类型、共享存储与缓存、鉴权与安全、各域契约细目。

## 1. parity 判据与验收口径
- **parity 判据**：逐参数对 python——**python 有界而它端无界＝缺口（修）、它端反向加界＝主动偏离（两端同改）**；默认值也逐端点对；"service 层等价拦截且错误码/文案一致"**不算缺口**。
- **同名参数跨端点口径常不同** ⇒ 跨端点类推必错（`status`：agents/endpoints `[0,1]`、refunds `[1,3]`、conversations 无界）。
- **清查"某模式的全部实现"须按实现形态穷举**：逐参解析 / `ShouldBindQuery`+`Normalize()` / service 归一化 / DTO 自持分页字段（绕过分页 helper）；只按特征串 grep 会整类漏掉。核 python 分页必须追 `Depends()` 模型继承链（系统模块 router 内联 `Query(default=N,...)`、AI 域 schema 继承 `BasePageQuery`）——「router 里 grep 不到 ≠ 无分页」。
- **字段约束验收＝可观测行为**（非"注解存在"）：**注解 + 触发条件（使用处 `@Valid`/`@Validated`）+ 兜底 + 必填性**四层同核；补触发条件须单列验收项并做**摘除反证**；`@RequestBody List<T>` 元素校验须 `@Valid List<@Valid T>`。
- **参数校验两档测法不可互抄**：字段级（DTO+`@Valid`）→ standalone MockMvc + `LocalValidatorFactoryBean`；方法级（裸 `@RequestParam`+类级 `@Validated`）→ 须 `MethodValidationPostProcessor` 包装代理，否则全绿却未验任何东西。
- 举证要求：负向用例断 `$.code` + `verifyNoInteractions(mapper/service)`；范围/计数声明必须实测并附"计数基 + 时间戳"；判"缺口/丢失"前先自问检索式是否漏（`grep -nE 'status|Min|Max'` 匹配不到 `@NotNull`）+ 输出是否被 `| head` 截断。
- 跨端脚本**只断 `code + status`，不断 msg**（java 中文注解文案 vs python 英文 pydantic 文案）。

## 2. 错误码与响应信封
- **响应信封**：`code` 定义处＝`dehaze-sdk-js/src/enums/ResultEnum.ts`；响应含 `traceId/timestamp/errors`（trace_id 全链路：请求头 `X-Trace-Id` → 响应头回写 → 响应体 `traceId`）。
- **HTTP 状态**：python/java 校验失败 = **HTTP 400**，go 全 200（`pkg/common/response.go` 全 `StatusOK`；日志里的 `status 400` 只是字段）。**python 校验失败 = 400 + `A0400`，不是 FastAPI 默认 422**（`RequestValidationError` handler；全仓 python 422 无真实返回路径）。
- **错误码口径表**：
  - `A0210` 登录用户不存在（防枚举）｜`A0213` 验证码 Key 不存在/已消费 vs `A0214` 比对错｜`A0230` 凭证无效（TOKEN_INVALID）｜`A0231` MCP 鉴权失败｜`A0301` 未带凭证/无权限（go 权限中间件原 A0300 已废；HTTP 403）
  - `A0400` 参数校验失败｜`A0401` 资源不存在/越权（**防枚举，禁止泄露存在性**）｜`A0500` 通用业务错误｜`A0501` 唯一重复（含软删语义已废止）｜`A0502` 删除已发布算法/状态版本不可用/未知中断子类型｜`A0503` 预置/超管/只读/根部门保护（原 `A0233`/`A0234` 作废）｜`A0504` 层级/绑定超限｜`A0505` ROOT_USER_PROTECTED｜`A0510~A0514` 会员域（NOT_FOUND/FROZEN/SIGN_IN_ALREADY/GROWTH_INSUFFICIENT/BENEFIT_CONFIG_INVALID）｜`A0530~A053F` 订单计费段（`A0531` 取消/退款中/已退、`A0533` 重复支付、`A053A` 合法、`A053B` 余额不足）｜`A0540~A0546` 反馈域｜`A0680/A0681/A0682` 已入段位表｜`A0700/A0709` 导出、`A0701` 文件类型｜`B0001` 500 通用、`B0301` 导出任务不存在｜`B0401/B0402` 文件参数、`B0403` 魔数、`B0404`、`B0405` MD5 唯一冲突、`B0407` 归属越权。
  - **错误码规范＝纯数字编号 + 中文语义，不带英文标识**（`A0510（MEMBER_NOT_FOUND）` 形式违规）。
- **java 陷阱**：全局 `IllegalArgumentException` handler 用单参 `Result.failed(msg)` → 返回 **B0001 而非 A0400**；期望 A0400 必须显式抛 `BusinessException(PARAM_ERROR)`。Spring `AccessDeniedException` → 403 + A0301。`C0300` 被误用为系统错误。
- **空字段的实现与例外**：python `NonNullJSONResponse`（`app/main.py` 默认响应类 + 全部异常处理器，渲染层递归剔 None，机制走 `TypeAdapter.dump_python`；`api_key_auth` 中间件用原生 `JSONResponse` 为例外）、`Result.model_dump(exclude_none)` 是冗余防御、**java `spring.jackson.default-property-inclusion: non_null`（dev 与 prod 必须一致）**、go `omitempty` `serialization_alias` 可改写出参名（如 `metadata_`→`metadata`）。
- **python 响应字段形态**：裸 dict `success({...})` **不转 camel**、只有 `OrmResult`/Pydantic 模型统一 camelCase ⇒ 同一响应可并存两套键名（**不得为"统一"合并**）。键名**按端点自定**：协议/内容面向者 camel（`imageUrl`/`processingStatus`/`presetId`/A2A card `defaultInputModes`），镜像 DB 列者 snake（`version_no`、评测 `run_id/judge_passed`）⇒ **判据＝以 python 实际输出为准**，勿按"三端应统一 camel"直觉改。**JSON 列内部键原样 snake_case**（`OrmResult` 只转顶层）⇒ 取快照内部值写 `provider_id`/`system_content`。
- `sys_message/*` 空结果 list 必须 `[]` 非 null。

## 3. 分页与筛选参数
- **分页三层**：①python `BasePageQuery`（`pageNum ge=1`、`pageSize 1..100`，越界 A0400）②java `@Valid` + `@Max(100)`（查询对象使用处须带 `@Valid`；`MybatisConfig.setMaxLimit(200)` 兜底，**是静默 clamp，与 python 的 A0400 语义不同**）③go `parsePaginationWithSize(c, defaultSize)`（`parsePagination` ＝默认 10 委托）handler 校验（`<1` 或 `>100` → A0400）。
- **`limit`/`pageSize` 无上界是既定口径**（`limit=100000` 三端放行），补 `le`/`@Max` 即过度收紧；唯一上界是 `pageSize le=100`。**负 `limit` 三端均不接受**：python/java 500、go 原静默返回全量 → 已改显式 400（方向一致的显式化）。
- **默认值逐端点对 python**：计费 20、可观测 10；非 AI 域 29 个默认 10 + 5 个默认 20（favorite/message.GetPage/message.Search/messageTemplate/datasetItem）；`HistoryQuery` java 20 vs python 10 曾反向分叉。选项加载惯例 `pageSize:100`。
- **空串差异已裁决"维持不统一"（前端不发空串）**：`limit=` py 400/java·go 200；`pageNum=`/`pageSize=` py·java 400 / **go 200**；`status=` py 400/java·go 200。**禁止写"java 与 go 同构(含空串)"这类概括句**。
- 校验顺序须与 python 一致（字面量非法 A0400 先于业务拒绝）；`pydantic` 默认 `extra="ignore"` ⇒ 未知字段静默忽略（可选字段名拼错＝静默丢弃）。

## 4. 值域 / 类型 / 命名契约
- **金额跨端表示**：跨端表示不一（python `Decimal` → 字符串、java `BigDecimal` → 数字），读写 DTO 双向兼容（`billCacheDTO`/`cachedDecimalText`）；java 金额 VO 需 `ToStringSerializer`（对齐 python 字符串），但 `KbVO.hybridWeight/scoreThreshold` 的 `ToStringSerializer` 是多余的（python 为数字）。
- **积分**：整数语义（`sys_ai_credit_log.amount/balance_after` 用 bigint；java 若用 `Integer`+Jackson 默认 `ACCEPT_FLOAT_AS_INT` 会把 1.5 截成 1 静默成功，应 `BigDecimal` + `stripTrailingZeros().scale()>0` 拒绝）。
- **列宽对齐**：dataset/item/algorithm `name` 64、`type` 100、`description` 2048、URL ≤500、`algorithmName` ≤100、`algorithmParams` 必须合法 JSON；`sys_dict` name/code 50/50。
- **时间**：三端格式不一致（Java `HH:mm` / Go RFC3339 / Python ISO，全局口径应 `HH:mm:ss`）——**专项遗留**；MySQL `DATETIME(0)` 秒精度且对微秒**四舍五入（非截断）**⇒ 断言上界留 1s 容差、seeder 幂等检查前须截微秒；Go 时间列显式赋值一律 `.Truncate(time.Second)`。
- **软删语义统一**：python `SoftDeleteMixin` 全局过滤 `deleted=0`；uk 含 `deleted`（方案 A）⇒ 软删行不占唯一键位；java `@TableLogic delval=id`、go `gorm.Expr("id")`。判"改测试还是改实现"时一律以"仅活跃行查重"为准。
- **审计字段硬约定**：所有表（含支付流水 `sys_payment_record`、价格/成本 detail 表）均带 `deleted/create_time/update_time/create_by/update_by`，**不得以"版本快照不可变"豁免**。
- **内置角色编码大写**：`ROOT/ADMIN/GUEST/DEPT_ADMIN/USER`（种子 `sys_role.sql`）；内置角色不可删/不可禁用。菜单权限惯例：`sys_menu` 中 `type=1/2`（菜单/目录）节点 `perm` 一律 NULL，权限码只挂按钮。
- **权限标识**（新增须三处同步：`config/sql/data/sys_menu.sql` + `sys_role_menu.sql` + `mock/menu.mock.ts`）：`ai:model:manage`、`ai:billing:cost|stat`、`ai:conversation:audit`、`ai:mcp:manage`、`ai:skill:manage`、`kb:manage`（用户端）/`kb:audit`（管理端，普通用户持 kb:manage 访问审计接口返 403 A0301）、`voice:engine:manage`、`voice:service:monitor`、`sys:auth:session:list|kick`、`sys:role:import|export`、`package:promotion:add|edit|delete`、`image` 域实际用 `sys:dataset:edit`。

## 5. 共享存储与缓存（跨端互认）
- **跨端共享 Redis 必须存裸 JSON**：java `RedisTemplate<String,Object>`（GenericJackson2Json + default typing）自写自读格式不一致且 python/go 读不了 ⇒ `dict:data:*` 已改 `StringRedisTemplate` 存 `[{value,label}]`（解析失败删 key 回源自愈）；java 内部 `task:*` 前缀自写自读可保留。
- **缓存键风格（勿改错方向）**：`ai:model:list`/`ai:provider:list`/`ai:bill:{uid}:{yyyy-MM}`/`ai:provider:{id}:health*`＝snake_case（`model_dump` 无 by_alias）；`kb:list:{uid}`/`kb:detail:{id}`＝camelCase（`by_alias=True`）；`ai:balance/arrears/quota:*`＝纯整数/标记字符串；`dict:data:{typeCode}`（三端统一，原 `dict:options:*` 作废）；`role:perms:*`、`menu:routes`/`menu:options`、`role:options`、`user:level:{id}`、`ai:agent:{id}:published`、`package:onsale:{type|all}`（在售列表**必须带维度**）。**改对外 camel 契约时禁复用同一结构体写缓存，须单定 snake DTO**。
- **自写自读单测（miniredis）会掩盖断裂**：共享缓存须有"另一端写入的夹具 → 本端读"互认测试。
- **Mongo 共享集合键名必须 snake_case**：`login_log`（`user_id/create_time/device_type`）、`audit_log`（`operator_id/target_type/target_id/before_value/after_value/create_time`）、`ai_api_call_log` —— java 实体须 `@Field` 逐键对齐，go bson 必须 snake（**camel 会让 python 读取端静默得到全 None 不报错**）；`target_id` 查询需 int32/int64 双类型 `$in`；同字段范围条件须挂**同一 Criteria 链**（双 `and(k)` 抛 `InvalidMongoDbApiUsageException`）。TTL：`ai_api_call_log` 30 天，`login_log`/`audit_log` 无 TTL。
- **跨端副作用须显式同步**：①ES 记忆向量删除＝索引 `ai_memory` + `_id`=记忆 id + `?refresh=true` + 失败仅 warning（漏清＝已删记忆仍被召回，隐私缺陷）②图缓存失效广播 `cache:invalidation`，消息 `{type:"ai_graph_invalidate", senderId}`（无 key），三端 MCP 变更后广播。
- **L1 进程内缓存滞留＝外部清 Redis 无效的经典根因**（`role:perms`、feedback/rating 日限计数器两案例）：python 必须 `CacheService.delete`（裸 `redis.delete` 只清 L2）；java 场景须纯 redis 注入（`GetL2Cache()`）。

## 6. 鉴权与安全
- **会话/token**：三端共享 `JWT_SECRET_KEY`；`authorities` = `ROLE_`+roles 与 perms 合并，`UserContext.permissions` 由 authorities 拆非 ROLE_ 前缀项得来 ⇒ **共享会话里 java 登录必须同时写 perms**，否则代理到 python 的端点 `@require_permission` 一律 A0301、java 自身 `SecurityUtils.getPerms()` 恒空（7 处权限判定被架空）。
- **鉴权失败码**：未带凭证 `A0301`；凭证无效 `A0230`；`NoAuth` —— go 返回 **200** 非 401。登录失败 5 次锁 30 分钟（`login:fail:*`）。
- **captcha**：三端统一存 **Redis db0 纯文本**（Java 已改 `StringRedisTemplate`；原 db3 + Jackson 引号序列化作废）；Go `config.test.yaml`(db4) 属测试隔离、不动。验证码错误/过期用 `VERIFY_CODE_ERROR`/`VERIFY_CODE_TIMEOUT`（原 `A0230/A0231` 语义已改）。
- **文件模块按 API 规范不做权限控制、仅需登录态**（Go 曾要求 `sys:file:add`/`sys:file:delete` 已移除）。
- **Redisson 限流双坑**：配置 key 只在**首次初始化**写入（改 `@RateLimit maxRequests` 后必须删 `rate:limit:login:{ip}` 配置 key 才生效）；清理登录限流**只删计数子 key**（`{rate:limit:login:*`），误删配置 key → "RateLimiter is not initialized" HTTP 500。
- **SSRF**：三端 IPv4 映射地址（`::ffff:127.0.0.1`）判定一致（Go `To4()` / JDK 规范化 Inet4Address / python `ipaddress`）；python 覆盖 TEST-NET 1/2/3 与 `198.18/15`，Go `IsPrivate()` 不含 ⇒ 须声明式前缀表；残余 TOCTOU（校验与拨号各解析一次域名）三端同窗口，本轮不做。**内网拒绝不是缺陷**（java→python 算法链路、python prediction 对 127.0.0.1 内网图同样拒绝）；`imageUrl` 支持本地路径＝任意文件读取漏洞，已删除。
- **上传校验顺序（跨端统一）**：类型枚举 → 扩展名白名单（jpg/jpeg/png/gif/bmp/webp）→ 魔数一致性，**全 A0400**（魔数不符 `B0403`）；**禁止"非图片扩展名直接放行"（存储型 XSS）**；`MAX_UPLOAD_SIZE` + PIL 解析校验；文件名校验＝basename 化剥路径前缀 + 拒 `/ : * ? " < > |` 与 `\x00-\x1f` + name≤100/ext≤20。报告 HTML 必须 `html.escape`（以 text/html 同源返回）。
- **加密互认**：供应商凭据 `sha256(env AI_PROVIDER_KEY_ENCRYPTION_KEY)` → AES-256-CBC/PKCS7 → `base64(iv||ct)`（java `AiCredentialCipher` / go `pkg` / python `aes_cipher` 同构）。**密钥一律 env-only**。

## 7. 各域契约细目
- **AI 计费**：`BillingRecordVO.refundStatus` 4 态（0无/1待审核/2已通过/3已驳回）；`CostStatVO` 双口径（revenue/cost/profit/profitRate + `metric: overall|ai`）；`UsageStatsVO` 含供应商健康（successRate/rate429/p95LatencyMs/circuitOpen）+ 模型用量 + `downgradeFrequency`/`keyFailoverCount`；`BillingSummaryVO` = trend + modelDistribution + savings；计费记录字段驼峰（`inputTokens`）。**消息发送 `POST messages` 必须带 `Idempotency-Key`（uuid hex）否则 A0400**。`sys_ai_billing.model`=实际使用模型（降级即降级模型）、`actual_model`=用户原选模型（仅降级非空）；异常表 `sys_ai_billing_anomaly`（`detail(str)/status(int 0待/1已/2忽略)/trigger_at`，四类 `single_high/burst/consecutive_quota_fail/empty_high_output`）。计费触发：rerank 按 token、检索 query 向量化计费（`bill_type=embedding`）、local **完全跳过不落 0 记录**、单价读 `sys_ai_model_price`（未配置 warn 回退 0）；先 `ensure` 后 `charge`，失败不扣、异常路径 `restore_quota`（`quota_deducted` 门控防 m2m 误还）；**`QUOTA_INSUFFICIENT` 在检索路径必须透传拒绝，不可降级空结果**。
- **会话与消息**：`GET /api/v1/ai/conversations/{id}/messages?before=<int,≥1>&limit=<默认50,1..100>&view=admin` → `{list,total,hasMore}`；排序 `id DESC`；越界 400+A0400；**已移除 `pageNum/pageSize`（无兼容分支）**；`total`＝会话消息总数（不受 before 影响）；`hasMore` 用 `limit+1` 探测。java `before` 须 `Long`（BIGINT 主键，Integer 会溢出）。`exportConversation` 参数 `format ∈ markdown|json`，**默认 markdown**；`compat/calls` 为登录用户自审计。会话列表排序 pinned desc → pinned_at desc → last_message_at desc → id desc。历史消息接口默认 `order="asc"`（ES 同步/调度依赖），`list_messages` 显式 `desc` ⇒ **前端所有消费点必须 reverse**（更早页插到列表之前）。
- **可观测/审计契约**：timeline `summary` **恒单形状纯计数**（inputSnapshot 仅 `messages{counts,tokens}` + 可选 `tool_count/user_id`，outputSnapshot 仅 `text`），无降级分支；`raw_request/raw_response` 是审计原文唯一通道（`_wire_guard` 256KB 上限，超限 `{"_truncated":true,"_original_bytes":N}`，失败存 `{"error":{code,message}}`）；`ts` **仅取 `start_time`**，NULL 沉底，禁止 create_time−duration 近似。状态码双轨易混：`sys_ai_message.status` 1流式中/2已完成/3失败/4已取消；`llm_call.status` 1成功/2失败/3超时；`attempt.status` 1成功/2失败/3熔断跳过。
- **会员/订单**：`packageType ∈ vip|credit`（会员卡/积分卡），创建后不可改；`sys_package.level_code/period/period_days` 对 credit 允许 NULL；`completePayment` 按 `package_type` 分流、**同事务调用（非事件）**；成长值按实付 1:1（`consume`，入 `ai_consume`）；支付 `PayRequest` 补 `channel`（组合支付必填 wechat/alipay）+ `balanceAmount`，流水渠道直写真实渠道。`BenefitOverrides` 全集 **17 字段**（java 权威，三端须全等，护栏用例：读回→保存 map 全等；key 统一 camelCase）。`admin` 密码 bcrypt 固化在 `sys_user.sql`（`ADMIN_PASSWORD` 变量仅供测试登录声明）。
- **文件/导出**：批量删除返回 `{total,succeeded,failed,results}`（不存在 ID 计 failed，succeeded 按请求 ID 计、级联不计；空数组返回 0，禁 `len(ids)` 假计数）；fileId 解析须走 service 层 `resolveImageUrl`（禁拼 `/api/v1/files/download/{fileId}`）；图片 URL 白名单用**多存储后端 baseUrl** 收集。
- **算法/预测/评估**：算法 6 态（0 草稿 / 3 PUBLISHED / 4、5 终态），options 只出 `status=3`、新建默认 0；三端统一 `ALLOWED_TRANSITIONS` 白名单 + `DELETABLE_STATUSES`（草稿/已停用/已归档）；prediction/evaluation 更新用 `status=processing` 条件更新（CAS）防终态复活。预测入参 `algorithmId`/`imageUrl`（`params` 为 JSON 字符串），出参 `resultUrl`/`resultThumbnailUrl`/`time`；`/compare/report` 入参是 `pred_log.logId`（`sys_eval_log` 无 `pred_log_id`）。指标口径：PSNR/SSIM/MSE/FSIM/LPIPS，雷达图固定上限 PSNR=100/SSIM=1/LPIPS=1/NIQE=10/NIMA=10/BRISQUE=100（PSNR=inf 钳制 100.0，NaN → 任务 failed）。归属校验统一按 `create_by`，越权一律 A0401；跨端 list 必须带 `create_by/user_id` 过滤。
- **其它**：`tree_path` 格式 java `"0,1,2"`（root="0"，层级=段数）vs python `",1,2,"`（含自身 id）⇒ **层级算法不同不可互搬**；菜单 `type 1=MENU / 2=CATALOG`（python 实体注释曾写反）、`tree_path` 格式 `,1,2,`。
