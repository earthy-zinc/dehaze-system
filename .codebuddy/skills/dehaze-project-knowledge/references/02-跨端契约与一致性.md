# 明细：跨端契约与一致性

> **边界**：本文件只收程序性知识（判据 / 坑与禁区 / 实测口径 / 操作纪律）；陈述性知识以 `dehaze-doc/docs/` 为唯一权威源，不重复转述；冲突时以磁盘代码 + 实测为准。

## 1. parity 判据与验收口径

- **parity 判据**：逐参数对 python——**python 有界而它端无界＝缺口（修）、它端反向加界＝主动偏离（两端同改）**；默认值也逐端点对；"service 层等价拦截且错误码/文案一致"**不算缺口**；同名参数跨端点口径常不同（`status`：agents/endpoints `[0,1]`、refunds `[1,3]`、conversations 无界）⇒ 跨端点类推必错。
- 其余验收方法论（清查须按实现形态穷举、字段约束四层同核 + 摘除反证、两档校验测法、举证要求、脚本只断 `code + status`、枚举校验留 service 层）见 `02-系统架构/05-测试架构.md`。

## 2. 错误码与响应信封（只留反直觉口径与易错锚点；完整段位表/映射见 `dehaze-doc/docs/02-系统架构/04-API规范.md`）

- 成功码是**字符串 `"00000"`（既不是 200 也不是 0）**；`trace_id` 全链路＝请求头 `X-Trace-Id` → 响应头回写 → 响应体 `traceId`（`code` 定义处＝`dehaze-sdk-js/src/enums/ResultEnum.ts`，规范见 `02-系统架构/04-API规范.md`）。
- **HTTP 状态反直觉**：python/java 校验失败 = **HTTP 400**，但 **go 全 200**（`pkg/common/response.go` 全 `StatusOK`；日志里的 `status 400` 只是字段）。**python 校验失败 = 400 + `A0400`，不是 FastAPI 默认 422**（`RequestValidationError` handler；全仓 python 422 无真实返回路径）。
- **易错锚点（写错就出事故）**：
  - `A0401` 资源不存在/越权＝**防枚举，禁止泄露存在性**；`A0210` 登录用户不存在（防枚举）。
  - `A0501` 唯一重复；`A0503` 预置/超管/只读/根部门保护（**勿用 `A0233`/`A0234`**）；go 权限中间件**不用 `A0300`**（权限不足 = `A0301` + **HTTP 200**（go 错误响应经 `common.result()` 恒 `StatusOK`）；仅"未认证/会话无效"由 auth 中间件返回 **HTTP 401 + `A0230`**，不是 403）。
  - `A0002` 防重复提交（**三端已统一**，键格式与白名单的权威源＝`dehaze-doc/docs/02-系统架构/04-API规范.md`，设计见 `05-改造计划/防重复提交三端统一改造计划.md`）：参与端点＝**8 条显式白名单且三端集合完全一致**（由 `dehaze-python/tests/test_anti_repeat_contract.py` 源码级对拍 java 注解 / go 路由挂载）；键 `anti_repeat:{identity}:{METHOD}:{path}:{sortedQuery}:{bodyHash}`（identity＝`user:{userId}`，退化 `ip:{clientIp}`——**不得**用 sessionId/jti；query 按 (key,value) 全排序；multipart 不进摘要）、窗口 5s。**超限 HTTP 状态码分端不同**（python 429 / java 400 / go 200，业务码统一 `A0002`）⇒ 跨端脚本分端断言状态码、只对 `code` 统一断言。**`A0002` 会遮蔽精确业务码**——唯一性/重复类负向用例必须用差异化 body 绕过防重（否则命中的是 A0002 而非 A0501）。**验证陷阱（勿把拦截当业务空结果）**：做「改配置前后」对比时用同一 query/body 快速连打同一 POST/PUT/DELETE，第 2 次起被拦截、响应体是错误码而非业务数据（若只看「results 为空」会误判成「阈值把数据过滤掉了」）⇒ 对比验证须让每次 body 不同（如递增可选参数 `topK`）或间隔 > 5s，并**先看响应 `code`（`00000` 才是业务结果）**。
- **java 陷阱**：全局 `IllegalArgumentException` handler 用单参 `Result.failed(msg)` → 返回 **B0001 而非 A0400**；期望 A0400 必须显式抛 `BusinessException(PARAM_ERROR)`。Spring `AccessDeniedException` → 403 + A0301。`C0300` 被误用为系统错误。
- **空字段配置锚点（勿改，dev 与 prod 必须一致）**：python `NonNullJSONResponse`（`app/main.py` 默认响应类 + 全部异常处理器）、**java `spring.jackson.default-property-inclusion: non_null`**、go `omitempty`；`serialization_alias` 可改写出参名（如 `metadata_`→`metadata`）。
- **python 响应键名以 python 实际输出为准**：裸 dict 不转 camel、JSON 列内部键原样 snake_case（取快照内部值写 `provider_id`/`system_content`），**勿按"三端应统一 camel"直觉改**（全口径见 `核心模块/AI对话/API接口.md`）。
- `sys_message/*` 空结果 list 必须 `[]` 非 null。

## 3. 分页与筛选参数

- **分页三层语义不同**：①python `BasePageQuery`（`pageNum ge=1`、`pageSize 1..100`，越界 A0400）②java `@Valid` + `@Max(100)`（查询对象使用处须带 `@Valid`；`MybatisConfig.setMaxLimit(200)` 兜底，**是静默 clamp，与 python 的 A0400 语义不同**）③go `parsePaginationWithSize(c, defaultSize)`（`parsePagination` ＝默认 10 委托）handler 校验（`<1` 或 `>100` → A0400）。
- **`limit`/`pageSize` 无上界是既定口径**（`limit=100000` 三端放行），补 `le`/`@Max` 即过度收紧；唯一上界是 `pageSize le=100`。**负 `limit` 三端均不接受**：python/java 500、go 显式 400（方向一致的显式化）。
- **默认值逐端点对 python**：计费 20、可观测 10；非 AI 域 29 个默认 10 + 5 个默认 20（favorite/message.GetPage/message.Search/messageTemplate/datasetItem）；`HistoryQuery` 默认 10。三端默认值由 `dehaze-python/tests/test_pagination_default_contract.py` 源码级对拍（python router ↔ java Query 字段 ↔ go handler）。选项加载惯例 `pageSize:100`。
- **空串差异已裁决"维持不统一"（前端不发空串）**：`limit=` py 400/java·go 200；`pageNum=`/`pageSize=` py·java 400 / **go 200**；`status=` py 400/java·go 200。**禁止写"java 与 go 同构(含空串)"这类概括句**。
- 校验顺序须与 python 一致（字面量非法 A0400 先于业务拒绝）；`pydantic` 默认 `extra="ignore"` ⇒ 未知字段静默忽略（可选字段名拼错＝静默丢弃）。

## 4. 值域 / 类型 / 命名契约（只留易错点）

- **金额单位跨端统一为「分」**：`sys_order` / `sys_package` / `sys_coupon` / `sys_balance*` / `sys_payment_record` 等金额列单位均为分；前端展示与表单必须双向换算（`/100` 显示、`×100` 提交，对齐 package 模块 `yuan()` 模式）——漏换算是**静默 100 倍错**（不报错、编译与 lint 全过），凡展示/提交金额必须双向换算。
- **金额/积分跨端表示**：金额一律**字符串下发**（python `Decimal`→str；java 金额 VO 用 `ToStringSerializer`，守卫 `AiBillingControllerAmountContractTest`；例外 `KbVO` 不加——python 侧为数字），读写 DTO 须双向兼容（`billCacheDTO`/`cachedDecimalText`）。**积分＝整数语义**：`sys_ai_credit_log.amount/balance_after` 用 bigint；java 用 `BigDecimal` + `stripTrailingZeros().scale()>0` 拒非整数（守卫 `AiBillingServiceTest`；勿退回 `Integer`——Jackson 默认会静默截断 1.5→1）。
- **时间精度坑**：MySQL `DATETIME(0)` 秒精度且对微秒**四舍五入（非截断）**⇒ 断言上界留 1s 容差、seeder 幂等检查前须截微秒；Go 时间列显式赋值一律 `.Truncate(time.Second)`。三端主流输出格式均为 `yyyy-MM-dd HH:mm:ss`（java `@JsonFormat`、go `aidomain/common.go` 的 `timeFormat`、python `strftime("%Y-%m-%d %H:%M:%S")`）。
- **软删判据**：uk 含 `deleted`（方案 A）⇒ 软删行不占唯一键位；判"改测试还是改实现"时一律以**"仅活跃行查重"**为准。（各端软删机制见 `docs/02-系统架构/03-数据库设计.md`。）
- **权限标识语义差异（不可机器化的部分）**：`kb:manage`＝用户端、`kb:audit`＝管理端（普通用户持 `kb:manage` 访问审计接口返 403 `A0301`）；`image` 域实际用 `sys:dataset:edit`（事实源＝`sys_menu.sql`）；已退役的 `voice:engine:manage` **勿再引用**。新增/改动权限码的种子↔mock↔可授一致性由 `dehaze-go/internal/router/permission_seed_contract_test.go`（mock↔种子一致 / 代码所用码可授 / 孤儿授权行）守卫。

## 5. 共享存储与缓存（跨端互认）

- **跨端共享 Redis 必须存裸 JSON**：java `RedisTemplate<String,Object>`（GenericJackson2Json + default typing）自写自读格式不一致且 python/go 读不了 ⇒ 字典缓存 `dict:data:*` 与 `dict:value:*` 用 `StringRedisTemplate` 存 `[{value,label}]`（解析失败删 key 回源自愈；双前缀失效契约由 `dehaze-python/tests/test_dict_cache_invalidation_contract.py` 守卫）；java 内部 `task:*` 前缀自写自读可保留。
- **缓存键风格依据（勿改错方向）**：取决于写缓存结构体是否带 `by_alias`（无 ⇒ snake_case 键；`by_alias=True` ⇒ camelCase 键），两侧并存是既定事实；**改对外 camel 契约时禁复用同一结构体写缓存，须单定 snake DTO**——键名与三端声明由 `tests/test_cache_key_contract.py`（23 条 + 格式对拍 + 变异自证）守卫。
- **自写自读单测（miniredis）会掩盖跨端断裂**：共享缓存 / 集合须有"另一端写入的夹具 → 本端读"互认测试（见 `02-系统架构/05-测试架构.md`）。
- **Mongo 共享集合**（`login_log`/`audit_log`/`ai_api_call_log`）：键名必须 snake_case（**camel 会让 python 端静默读到全 None**）、整数归属字段（`user_id`/`key_id`/`operator_id`/`target_id`）用 int32/int64 双类型 `$in`（java `MongoBsonUtils.int32Int64Candidates`，禁 `is(Long)` 单类型静默空列表）、同字段范围条件须挂**同一 Criteria 链**——均由 `MongoLogKeyMappingTest`、`test_mongo_log_int64_interop.py` 等守卫；TTL：`ai_api_call_log` 30 天，其余无 TTL。
- **跨端副作用须显式同步**：①ES 记忆向量删除＝索引 `ai_memory` + `_id`=记忆 id + `?refresh=true` + 失败仅 warning（漏清＝已删记忆仍被召回，隐私缺陷）②图缓存失效广播 `cache:invalidation`，消息 `{type:"ai_graph_invalidate", senderId}`（无 key），三端 MCP 变更后广播。
- **L1 进程内缓存滞留＝外部清 Redis 无效的经典根因**（`role:perms`、feedback/rating 日限计数器两案例）：python 必须 `CacheService.delete`（裸 `redis.delete` 只清 L2）；java 场景须纯 redis 注入（`GetL2Cache()`）。

## 6. 鉴权与安全

- **会话载荷**：认证以 Redis 会话为准（`session:{sessionId}`，Cookie/Header 仅携带会话标识）；`authorities`＝`ROLE_`+roles 与 perms 合并，`UserContext.permissions` 由非 `ROLE_` 前缀项拆得 ⇒ **共享会话里各端登录都必须写 perms**（java 已修；缺则代理到 python 的 `@require_permission` 一律 A0301、java 自身 `getPerms()` 恒空）。
- **鉴权失败码（分端）**：未带凭证 / 会话无效（go）= HTTP 401 + `A0230`（不是 403、也不是 200）；**权限不足：python/java = HTTP 403 + `A0301`，go = HTTP 200 + `A0301`**（go 错误响应经 `common.result()` 恒 `StatusOK`，勿把 go 口径当通则）。`NoAuth`（`internal/router/auth.go` 的 `RegisterNoAuthRoutes`）是**免鉴权路由注册**，不是鉴权失败码。登录失败 5 次锁 30 分钟（`login:fail:*`）。
- **captcha**：三端统一存 **Redis db0 纯文本**（java `StringRedisTemplate`）；Go `config.test.yaml`(db4) 属测试隔离、不动。验证码错误/过期用 `VERIFY_CODE_ERROR`/`VERIFY_CODE_TIMEOUT`（**不是** `A0230`/`A0231`）。
- **文件模块按 API 规范不做权限控制、仅需登录态**（无 `sys:file:add`/`sys:file:delete`）。
- **Redisson 限流双坑**：配置 key 只在**首次初始化**写入（改 `@RateLimit maxRequests` 后必须删 `rate:limit:login:{ip}` 配置 key 才生效）；清理登录限流**只删计数子 key**（`{rate:limit:login:*`），误删配置 key → "RateLimiter is not initialized" HTTP 500。
- **SSRF**：三端 IPv4 映射地址（`::ffff:127.0.0.1`）判定一致（Go `To4()` / JDK 规范化 Inet4Address / python `ipaddress`）；python 覆盖 TEST-NET 1/2/3 与 `198.18/15`，Go `IsPrivate()` 不含 ⇒ 须声明式前缀表；残余 TOCTOU（校验与拨号各解析一次域名）三端同窗口，刻意不修。**内网拒绝不是缺陷**（java→python 算法链路、python prediction 对 127.0.0.1 内网图同样拒绝）；`imageUrl` 支持本地路径＝任意文件读取漏洞 ⇒ 不得支持。
- **上传校验顺序（跨端统一）**：类型枚举 → 扩展名白名单（jpg/jpeg/png/gif/bmp/webp）→ 魔数一致性，**全 A0400**（魔数不符 `B0403`）；**禁止"非图片扩展名直接放行"（存储型 XSS）**；`MAX_UPLOAD_SIZE` + PIL 解析校验；文件名校验＝basename 化剥路径前缀 + 拒 `/ : * ? " < > |` 与 `\x00-\x1f` + name≤100/ext≤20。报告 HTML 必须 `html.escape`（以 text/html 同源返回）。
- **加密互认**：供应商凭据 `sha256(env AI_PROVIDER_KEY_ENCRYPTION_KEY)` → AES-256-CBC/PKCS7 → `base64(iv||ct)`（java `AiCredentialCipher` / go `pkg` / python `aes_cipher` 同构）。**密钥一律 env-only**。
- **文件 URL 直链本身无鉴权**：存储桶（MinIO public read）与 nginx-static 直链不做鉴权，安全性依赖 `object_name` 含 MD5 不可枚举——**"接口层已补归属校验（B0407）"不等于"直链受保护"**，两者不可混淆；local 存储后端在下载接口收登录态后直链也需登录态（仅开发环境）。
- **前端会话失效收敛只纳 token 类码**（HTTP `401` / `A0230` / `A0231`），**不纳**"目标用户不存在 / 被锁 / 无效"类（管理端查他人会正常出现，纳入会误登出）——落地形态见 `基础模块/认证管理/前端实现.md`。

## 7. 各域契约细目（陷阱与差异锚点）

- **默认对话模型解析链（含 Agent 级；改默认模型行为须三端同步）**：生产对话解析优先级链＝`请求显式 model > 会话已存 conv.model > 用户偏好 default_model > Agent 配置模型 > 平台默认`（平台默认＝`sys_dict` `ai_model.default_model`），**全无则 A0500、不回落代码常量**。**Agent 级**取该会话锚定 Agent 的「**已发布版本快照 `model_id`**」（无已发布版本回退主表可编辑态），**排在用户偏好之后**（用户显式偏好优先于系统预置 Agent 配置）；**切换 Agent 且未显式指定模型时 `conv.model` 按新 Agent 重解析**。后台派生推理（标题/建议/记忆抽取）仍取平台默认，**不读偏好与 Agent**。存量 `sys_ai_conversation.model` **创建时冻结**——平台/Agent 模型后续变更不回流旧会话。**评测口径**：评测按**被评测版本的 Agent 模型**执行（评测无请求/会话/用户上下文），与生产的剩余差异只有「用户偏好/会话覆盖」两层，属固有限制 ⇒ 勿指望评测复现线上会话模型（此前 Agent `model_id` 不被生产链路读取，表现为「切 Agent 不切模型」、评测结论对不上生产）。三端同步点：python `model_defaults.resolve_default_chat_model` / Go `UserPreferenceService.ResolveChatModel` / Java `AiDefaultModelResolver.resolveForUser`；**「仅平台默认」场景须用 `resolve_platform_default_model` / `PlatformDefaultChatModel`**（默认 Agent 自举必须用它，否则解析自身 Agent 配置形成自引用）。
- **AI 计费**：**消息发送 `POST messages` 必须带 `Idempotency-Key`（uuid hex）否则 A0400**。`sys_ai_billing.model`=实际使用模型（降级即降级模型）、`actual_model`=用户原选模型（仅降级非空）；异常表 `sys_ai_billing_anomaly` 四类 `single_high/burst/consecutive_quota_fail/empty_high_output`。计费触发：rerank 按 token、检索 query 向量化计费（`bill_type=embedding`）、local **完全跳过不落 0 记录**、单价读 `sys_ai_model_price`（未配置 warn 回退 0）；先 `ensure` 后 `charge`，失败不扣、异常路径 `restore_quota`（`quota_deducted` 门控防 m2m 误还）；**`QUOTA_INSUFFICIENT` 在检索路径必须透传拒绝，不可降级空结果**。
- **会话与消息**：`GET /api/v1/ai/conversations/{id}/messages?before=<int,≥1>&limit=<默认50,1..100>&view=admin` → `{list,total,hasMore}`；排序 `id DESC`；越界 400+A0400；**无 `pageNum/pageSize`（无兼容分支）**；`total`＝会话消息总数（不受 before 影响）；`hasMore` 用 `limit+1` 探测。java `before` 须 `Long`（BIGINT 主键，Integer 会溢出）。`exportConversation` 参数 `format ∈ markdown|json`，**默认 markdown**；`compat/calls` 为登录用户自审计。会话列表排序 pinned desc → pinned_at desc → last_message_at desc → id desc。历史消息接口默认 `order="asc"`（ES 同步/调度依赖），`list_messages` 显式 `desc` ⇒ **前端所有消费点必须 reverse**（更早页插到列表之前）。
- **可观测/审计契约**：timeline `summary` 恒单形状纯计数、`raw_request/raw_response` 是审计原文唯一通道（`_wire_guard` 256KB 上限）、`ts` 取 `start_time`；`sys_ai_message` / `sys_ai_llm_call` / `attempts` 三套 status 值域易混——细目见 `核心模块/AI对话/可观测性/` 与 `02-系统架构/03-数据库设计.md`。
- **会员/订单契约**：`packageType ∈ vip|credit` 创建后不可改、`completePayment` 按 `package_type` 同事务分流、成长值按实付 1:1、支付 `channel`/`balanceAmount`、`BenefitOverrides` 三端须全等——细目见 `基础模块/套餐管理/后端实现.md`、`订单管理/后端实现.md`、`会员管理/后端实现.md`。
- **文件/导出**：批量删除空数组必须返回 0（禁 `len(ids)` 假计数）；fileId 解析须走 service 层 `resolveImageUrl`（禁拼 `/api/v1/files/download/{fileId}`）、URL 白名单收集**多存储后端 baseUrl**——细目见 `基础模块/文件管理/后端实现.md`。
- **数据集**：`sys_dataset.path` **不接受用户输入**——java `DatasetConverter` 新增/更新均 `@Mapping(ignore, target = "path")`，python `DatasetAddForm/DatasetUpdateForm` 不带 `path`（加上即回归）；存储路径由服务端按数据集/数据项不可变标识生成（路径遍历防护）。数据集图片契约 `ImageUrlVO` **无 `originUrl`**（java VO 与 `sys_item_file` 列都没有，只有 `url`＋`thumbnailUrl`，`url` 即原图；原图字段只在 `sys_pred_log`/`ImageTaskVO` 上有）；android SDK `ImageUrl.originUrl` 与 Flutter `dataset_model.originUrl` 是从不返回的**幽灵字段**，勿据此给 SDK-JS 补 `originUrl` 或恢复前端用法。
- **算法/预测/评估**：prediction/evaluation 更新用 `status=processing` 条件更新（CAS）防终态复活；预测入参 `algorithmId`/`imageUrl`（`params` 为 JSON 字符串），出参 `resultUrl`/`resultThumbnailUrl`/`time`；`/compare/report` 入参是 `pred_log.logId`（`sys_eval_log` 无 `pred_log_id`）。指标雷达图固定上限 PSNR=100/SSIM=1/LPIPS=1/NIQE=10/NIMA=10/BRISQUE=100（PSNR=inf 钳制 100.0，NaN → 任务 failed）。归属校验统一按 `create_by`，越权一律 A0401；跨端 list 必须带 `create_by/user_id` 过滤。
- **图像域（AI 图像 / 去雾）**：①**默认模型标记（勿再按"取不到"推理）**：`GET /api/v1/ai/models/enabled` 每项带 `isDefault`——按 `model_type` 分键读字典 `ai_model.default_model`（chat）/`default_model.{type}`（`status=0` 视同未配置），值等于 `model_id` 的行 true；**读取时计算、不写入共享缓存 `ai:model:list`**，**管理端 `/ai/models` 不返回该键**（键缺失 ≠ false）；三端同源（python `model_defaults.resolve_platform_default_model_id` / java `AiDefaultModelResolver.dictKeyFor` / go `platformDefaultDictKey`），前端预选＝历史最近使用 → `isDefault`，**字典未配置时不下选**（禁"启用列表首项"兜底）；守卫 `AiModelEnabledDefaultFlagTest` + python `tests/service/ai/service/test_model_defaults.py`。②**任务取消范式**：`AiImageAPI.submitAndWait(form, { onPoll: (status, taskId) => … })` 在 POST 后立即回调一次以回填在途 `taskId`，用户取消时调 `AiImageAPI.cancelImageTask(taskId)`（幂等）；`pollImageTask` 是私有方法，页面不要重写轮询（否则拿不到 taskId，服务端仍执行并计费）。③ `FileAPI.upload` 的 WPX 上传期映射**已废弃（方案 A，2026-10-04）**：java 分支 / SDK `modelId` 参数 / 前端调用点均清理完毕，SDK 现签名为 `upload(file, onUploadProgress?)`；WPX 能力只保留**预测期拦截器**（python+java 有、go 无）。
- **语音（dehaze-voice）**：①**运行时工件由服务端自解析，编排侧不下发**——tts 的 `onnx/size/urls`、asr 的 ModelScope id 由 `dehaze-voice` 按 `model_id` 自解析并经 `GET /v1/models` 暴露（`catalog` 项），`voice_params` 仅作顶层**可选调试覆盖**；用户可见音色清单从**模型注册表**派生，不从字典/旧表取。②**HTTP 与 WS 参数名刻意不对称（勿统一）**：HTTP `/v1/audio/*` 用 `model`、WS `/v1/asr/stream` query 仍用 `model_id`，两者取值都是**统一 model_id**（`sensevoice`/`paraformer`/`huayan`），未登记 → `PARAM_ERROR`（WS 关闭码 4400），**不静默回退**。③`response_format` 收窄为 **`mp3|wav|pcm`**（OpenAI Audio 子集；opus/aac/flac 一律 `PARAM_ERROR`），默认 mp3 / 22050；`Content-Type` 随格式（mp3→`audio/mpeg`、wav→`audio/wav`、pcm→`audio/L16`）。
