# 明细：架构与模块定案
> `dehaze-project-knowledge` skill 的参考文件（按需 read_file）。收录：系统与工程架构、AI 域模块定案、AI 推理机制、其它模块定案、文档架构。

## 1. 系统与工程架构
- 单 git 仓、无 submodule；根 `docker-compose.yml` 为唯一编排；基础设施配置**真源＝根 `config/`**（`sql/schema/*.sql`、`sql/data/*.sql`、redis/prometheus/logstash），三端共享；Java 测试由 `maven-resources-plugin` 构建期复制 `config/sql`（**禁止手维护 `src/test/resources/db/` 副本**；H2 方言 SQL 例外，独立保留在 `src/test/resources/db/h2/`）。
- 开发模式固定命令：Go `go run ./cmd/main.go`（**必须在 `dehaze-go` 目录启动**，viper 按 CWD 找 config）、Python `uvicorn --reload --host 0.0.0.0`、Java `mvn spring-boot:run -DskipTests`。
- **日志策略**：仅按日期切割、无大小切割；级别仅 info/error 两档（warn 并入 info）；`run.py` 控制台日志**追加模式**（勿改回 `"w"`）。Python 已删 `LOG_FILE/LOG_MAX_BYTES/LOG_BACKUP_COUNT/LOG_ROTATION_TYPE`、新增 `LOG_RETENTION_DAYS=30`。前端日志：SDK **不上报 user_id**（后端从会话注入）、`url` 由 `attachRouter` 全局注入、Flutter `error_stack` 用 `FlutterErrorDetails.toString()`、ERROR 按 `message+errorStack` hash 10s 去重、transport 必须输出 method/path/status/duration。
- **后端路由权威源＝dehaze-go `internal/router/*.go`**：统一前缀 `/api/v1`；资源路径复数（`/algorithms`、`/datasets`、`/dataset-items`、`/item-files`、`/files`、`/prediction`、`/evaluation`、`/image-input/history`）；认证五件套 `login/captcha/logout/me/refresh`（refresh 从 Authorization Header 读 token）；数据集图片走 nginx `/dataset-api/` 9000（Java 用 `file.datasetBaseUrl` 转绝对 URL）。
- **A/B 类分工**：A 类纯 CRUD 三端原生；B 类运行时端点（deepagents/LLM/向量检索/评测/流式/上传/语音）转发 python（java `AiProxyRoutes` 白名单 **40 条** + `AiProxyController`；go `internal/router/ai_proxy.go` + `pkg/aiclient`）。同一「方法+路径」原生与白名单**只登记一处**（测试双向锁定），"两处都没有"＝404 空洞。java 鉴权豁免由 `AiProxyRoutes.authExemptRoutes()` 派生，改白名单须同步 `SecurityConfig`。
- **AI 域自带鉴权**：python `ApiKeyAuthMiddleware` 是**全局**中间件 ⇒ `POST /chat/completions`、`POST /messages`(Claude)、`GET /models`、`POST /a2a`、`GET /.well-known/agent.json` 须在根引擎注册，java 侧需 `AuthenticationFilter.shouldNotFilter` + `SecurityConfig.permitAll` 双豁免。
- **熔断口径**：只计"服务不可用"＝连接层/超时/5xx；业务 4xx（A0401/A0410 等）按成功处理（`protection.MarkBusiness`；python 无熔断器，属 go 增强）。测试须落在被保护路径：客户端级 httptest（400×N 不熔断 + 502×N 必熔断），只测 breaker 层挡不住单侧漏包。
- **代理转发四形态**：JSON / multipart（java 须以 `@Component("multipartResolver")` 覆盖 Boot 自动配置，跳过 Spring multipart 解析）/ 二进制响应（禁当 JSON 解包）/ WebSocket（go `pkg/aiclient.ForwardWebSocket`）。
- **项目根/仓根定位＝标记文件向上查找**（Go `go.mod`、Python `pyproject.toml`，**不用 `.env`**——精简部署可能缺失），禁止 `os.path.join(dirname(__file__),"..","..")` 数层数；Java 走 classpath 天然规避。
- 配置真源与派生：`useMultiPoint`＝Java `system.use-multi-point:false`(dev)/true(prod)、Python `USE_MULTI_POINT`、Go `use-multi-point: false`；JWT 三端共享 `JWT_SECRET_KEY`，claims `jti/sub/userId/authorities(ROLE_*+perms)/deptId/dataScope/exp/iat`。

## 2. AI 域模块定案
- **AI 域只存在于 python**：33 张 `sys_ai_*` 表（模型/供应商/对话/知识库/计费/可观测/评测/MCP/Skill）全在 python，java/go 无 AI 模块（nginx `/py-api/` → python）⇒ AI 域改动**无需三端同步**；java/go 的 AI 端点走转发（publish 转发、rollback 原生；原生 publish 在"配了含考题回归集"时 100% 失败）。
- **AI 模型管理＝独立基础模块**（`03-模块设计/基础模块/AI模型管理/`）：供应商（API Key/健康容错/限速隔离/用户身份透传）+ 模型注册表（`model_type`=chat/embedding/rerank、`dimension` 建后不可改）；选模型走 `GET /api/v1/ai/models/enabled?model_type=`；页 `/admin/ai-models`（`ai:model:manage`）。**不拆"供应商/模型"两模块**；AI 对话保留会话内模型选择，AI 知识库消费 embedding/rerank。
- **AI 对话＝单一模块**（`核心模块/AI对话/`）：根 4 篇总览 + 11 功能域子目录，子目录统一 `需求规格/后端实现/测试用例/前端实现.md`；含可观测性 F-M08-013（`sys_ai_trace` + `sys_ai_llm_call`）、Agent 评测 F-M08-014（`sys_ai_agent_eval_*`、页 `/admin/ai-eval-center`）。LLM 用量记录**必须带 user_id**。
- **AI 对话前端只在 front-vue**（taro/flutter/react-native/uniapp/react 均无 `ai/conversations` 消费）⇒ SSE 契约改动影响面仅 front-vue + SDK。
- **MCP 双通道术语不可混用**（单一信息源 `核心模块/MCP/需求规格.md` §1.0）：①**内部 MCP 能力网关**＝dehaze-mcp-gateway（独立服务 `127.0.0.1:8082/mcp`，启动一次性加载 OpenAPI，**无定时同步，新增 API 需重启网关**）、`X-MCP-Key` 鉴权（`hmac.compare_digest`，缺失/错 401 + `A0231`，未配 `MCP_GATEWAY_KEY` 拒绝启动）、写工具白名单 `_DEFAULT_WRITE_TOOLS={"post_api_v1_prediction"}`（`MCP_WRITE_TOOLS` env 扩充）；②**MCP Server 管理**＝外部能力进口（`sys_ai_mcp_server/tool/namespace/call` 四表、凭据 AES、探测带凭据、周期巡检、`McpToolFetcher`）；外部工具装载走 `mcp_external_tool_loader` + `deep_agent_builder`，受图缓存影响须联动 invalidate。客户端 `_McpSessionContext.__aenter__` 必须 `await session.initialize()`（缺失则静默失效）。
- **MCP 四表要点**：`sys_ai_mcp_server`（name 唯一不可复用、credentials JSON 存 AES 密文、health online/offline、tool_count 冗余）/`sys_ai_mcp_tool`（随 Server 覆盖式重建）/`sys_ai_mcp_namespace`（**无独立 name 列**，namespace 列即 VO.name，tool_names JSON 数组）/`sys_ai_mcp_call`（AppendOnly，user_id/server_id/server_name 快照/tool_name/latency_ms）；`app/router/ai_mcp.py` 14 端点统一 `ai:mcp:manage`。
- **SKILL＝业界 Agent Skills 目录规范**：目录 + `SKILL.md`（frontmatter 必填 `name`≤64 小写/数字/连字符且与目录名一致、`description` 1-1024；可选 license/compatibility/metadata/allowed-tools）+ zip 上传；**方案 A**：SKILL.md 正文入 `sys_ai_skill.instruction`，其余文件入 MinIO（key=`skills/{name}/{path}`），`sys_ai_skill_file` 只存清单；容量上限 2MB。Skill 契约：`instruction`（非 content）、`status 0|1`、`market_shared 0|1`、详情含 `agentCount`；路由顺序 `GET /market` 必须先于 `GET /{skill_id}`。
- **知识库（KB）定案**：父子分块——parent = Markdown 小节（虚拟化不物化，逻辑分组键 `(document_id, section_index)`），child = 节内装箱；检索 Top-2K child → ES 按 `(document_id, section_index)` 分组 → 组内 max 为节代表分 → 节排序 top_k → MySQL 拉节内容注入，锚点 `【文档名 > 节路径】`；`sys_knowledge_chunk` +`section_index/section_path`，ES mapping +`section_index(keyword)`；**不引入 LangChain ParentDocumentRetriever**。分块层格式无关（Markdown 是中间表示，docx Heading 1-9 → `#` 在**解析层**补）。`parse_sections` 四级降级：标题树（行扫描带围栏跟踪，防代码注释 `# 注释0` 误判）→ 段落聚类 → 句子贪心聚类（原文区间切片，split+join 会吃句间空格）→ 单节；`_SECTION_TARGET_TOKENS=1500`。`searchStrategy ∈ {vector,keyword,hybrid}`、`chunking_strategy ∈ {fixed,semantic,recursive,qa,table}`。KB embedding provider 由模型行 `provider_id` 反查推导（schema 已删 `embedding_provider`）。**Embedding 迁移面板永久下线**（无存量数据；替代路径＝删库重建）。ES 索引 `kb_chunks_{kbId}`（ik_max_word/ik_smart）；KB 写路径（create/delete/index-stats/文档 PUT·DELETE）必须转发 python（ES 索引生命周期），库级编辑与读路径 java 原生。
- **RAG 优化路线**（`基础模块/AI知识库/RAG质量优化路线.md`）：四阶段（评估扩展 → 规则版自适应 → 数据驱动 → C-MTEB/BEIR 锚点）；原则 数据先行/证据边界/成本纪律/不变量沉淀；**基线只升不降红线（回退 >0.02 必须定位）**。kb_eval **两阶段铁律**：collect（唯一有成本，raw 落 `reports/raw/{strategy}.jsonl`，raw 完整即断点跳过）+ evaluate（离线重放，`--threshold` 参数化，~0.5s）；**调参只重跑 evaluate，严禁重新 collect**。
- **语音域**：python 唯一实现（FunASR ASR/Piper TTS 进程内懒加载 + `/ws/asr`），go/java 纯代理（`voice_proxy.go` 27 HTTP + `pkg/aiclient.ForwardWebSocket`）。语音引擎注册表 `sys_voice_provider/_key/_model` 三表（`engine_type` asr/tts 不拆表，`uk_provider_engine(provider_code, engine_type)` 联合唯一）；local 是内置 provider，由 `voice_engine_seeder.ensure_local_engines` **运行时幂等播种（非 SQL 种子）**；默认引擎缓存 `voice:engine:{asr|tts}`（TTL 60s），改 is_default/status/删除须 `invalidate_default_cache`；本地引擎模型走 Provider 从 `sys_voice_model.params` 注入（取代写死常量）。语音是**输入/输出模态**（基础能力），不设独立用户页面，以公共组件嵌入 AI 对话（VoiceInput/VoicePlayback）；入口仅系统设置 + 管理端。TTS/ASR 模型目录由 `settings.MODEL_CACHE_DIR` 决定（＝workspace 根 `/data/workspace/dehaze-system/models/`）。
- **可观测性自建**（不引 Langfuse/Phoenix）：双粒度 `sys_ai_trace`（消息级）+ `sys_ai_llm_call`（span 级）；`trace_type`（conversation/summary/memory_extraction/suggestion/step_summary）+ `bypass_span` 旁路链路；`attempts` JSON 逐 Key 物理路由（status 1成功/2失败/3熔断跳过）；`error_detail`（message[:500]/stack[:4000]，中断收尾不传）。
- **Agent 评测自研**（不引 DeepEval）：判分用本地 qwen3-0.6b 温度 0；**pass@k**（门禁 pass@1、稳定性 pass@8，取代"可复现≥98%"）；门禁三档＝绝对阈值 + 相对退化 >5% 阻断 + 高风险硬阻断；judge 需一致性验证 ≥90% 才启用、顺序打乱 + 多模型交叉、人工复核 1%；`run_regression` 保持**同步返回契约**。
- **提示词优化＝建议 + 人工审批**：LLM 只能基于**非安全类**负反馈生成建议，管理员审批后应用到模板（新会话生效）；`harmful` 等安全类直接告警人工介入——安全护栏绝不交用户反馈自动改写。
- **上下文压缩**：校验对象是**组装后实际上下文 token**（非消息累计）；软阈值 70% 摘要化、硬阈值 90% 强制驱逐；输出预留 `输入 ≤ max_context − max_tokens`；summary ≤ max_context×15%；显著性分级（Pinned 豁免）+ 压缩不可逆。摘要取链走 `get_chain_by_id` 沿 `current_branch_message_id` 分支链（非 `list_for_summary`）。

## 3. AI 推理机制（LangGraph / SSE / 中断 / plan）
- 推理循环用 deepagents 内部循环（`react_loop` 已废弃），工具装载走 `before_model` 钩子；`RedisSaver` 自定义实现（单层 Redis、30 天 TTL 为唯一回收路径，archive/软删/purge 均不碰）；checkpoint 三类键 `ai:checkpoint:{tid}:{ns}:{cid}` / `:latest:{tid}:{ns}` / `:writes:{tid}:{ns}:{cid}`。
- **钩子体系**：`deepagents` AgentMiddleware 仅 4 入口（`abefore_agent`/`awrap_model_call`/`awrap_tool_call`/`aafter_agent`），dehaze 六点 AgentHooks 由 `DehazeHooksMiddleware` 桥接；python 已实现 `before_tool` 写冲突仲裁（`agent_hooks._write_conflict_hook`：文件按 `file_path`、MCP 按 `post_/put_/patch_/delete_`，低优先级让行 30s，同 run 重入不弹确认，中断 `confirm_kind=dangerous_op`+`action=write_conflict`）。
- **LangGraph 细节**：`Command(goto="end")` 被忽略 ⇒ 用 `jump_to="end"`（`abefore_agent` 标 `__can_jump_to__=["end"]`）;`ainvoke` 的 ContextVar 副本上下文**不可见** ⇒ 图路径必须走最终 AIMessage 的 `response_metadata`（`astream` 的 set 对调用方可见）；langgraph 4.2.0 CheckpointTuple 无 `pending_sends`、`aput_writes` 按 (task_id,idx) upsert；shell 沙箱白名单不含解释器、弱隔离；**langgraph v2 事件 ns**：主图 `ns=()`，子图 ns 非空、段格式 `父图节点名:task_id`（嵌套多段）⇒ 判定"ns 非空即子 Agent"，`agent_code` = 末段 `split(":")[0]`（以实测为准，文档描述不符）。
- **中断协议**：`data.confirmKind ∈ {algorithm_recommend, tool_permission, dangerous_op}`（全 camel），未知子类型显式 `A0502`（不静默兜底）；`interrupt()` 在 resume 轮直接返回载荷不挂起；中断点仅 resume 成功后清理。**SSE `interrupt.data` 全 camelCase**：`confirmKind`/`previousWriter`/`upgradeTip`/`usedDaily`/`dailyLimit`/`usedMonthly`/`monthlyLimit`/`quotaDataError`/`taskId`/`taskType`/`estDuration`/`imageCount`。
- **plan 形状（契约唯一定义＝`dehaze-doc/03-模块设计/核心模块/AI对话/API接口.md` §2.2）**：对外 `PlanTask{id,description,dependsOn?,status?,paradigm?,toolHint?,result?}`、`PlanRevision{revisionNo,reason,changedTaskIds: string[]}`、`Plan{tasks,status?,revisions,phase?（仅事件）}`；SDK：`Plan` + `PlanPayload = Omit<Plan,"phase">`（中断 `data.plan` 用 `PlanPayload`），**`PlanEvent` 全域已不存在**（历史别名，再现即回退）。`plan.status ∈ pending|executing|revised|done`、`task.status ∈ pending|done|failed`。**分层口径**：对外（SSE 下行 + resume 上行 `plan_edit.add` 的 `dependsOn`/`toolHint`/`paradigm`）一律 camel；python **内部**（LLM 产出、Redis 中断点 `ai:interrupt:{thread_id}`、执行器）任务项保持 snake `depends_on`/`tool_hint`；**唯一归一出口 `plan_execute.to_wire_plan()`**（plan 事件与 plan_approve 中断两条路径共用，`phase` 仅 record_plan 补）；上行入口 `apply_plan_edit`（读 camel、写内部 snake）。`前端实现-公共.md` §7 与 SDK 类型仅为引用方，不得另起口径。
- **SSE 定案**：**空闲超时只断流不停推理**（心跳直连 yield、不入队列，否则超时永不触发）；error 事件唯一出口 `send_error()`（`public_error` 脱敏，BusinessException 透业务码、其余 A0600）；幂等键 `pending:{stream_session_id}`（TTL＝`AI_MESSAGE_STREAM_TIMEOUT+60=180s`，推理期 TTL/3 续期，完成/释放走 Lua CAS）；思考流 thinking 块固定 `content_block index=1`，converter `finish()` 必发 `stop(1)`，**direct 路径必须把 chunk 无条件交 converter**（`if chunk.content:` 会丢弃 content="" 的思考块）；start 幂等防重连重放。
- **usage 传递与计费单出口**：范式内所有 LLM usage 汇总进最终 AIMessage 的 `response_metadata`，由 `after_agent._billing_settle_hook` 一次预扣差额退补；`precharge_batch` 仅派发前余量预留、批结束 `settle_batch` 全额退回（`try/finally` 释放）。
- **子智能体粒度用量**：`message.end.usage.subAgents?: [{agentCode,inputTokens,outputTokens,cachedInputTokens,credits}]`，仅当存在子智能体 LLM 调用时下发；归属口径＝**运行期 ContextVar**（`run_context.subagent_scope`，在子 Agent 自身 `DehazeHooksMiddleware.awrap_model_call` 期间绑定），**否决 DB join 事后推断**；覆盖本地 deepagents 子 Agent（`task`）+ Team 本地成员（`transfer_to_*`）；**远程 A2A 成员为外部账单不计入**。`agentCode` 取值＝子 Agent 名称。
- **本地 LLM（零外部依赖）**：Qwen3-0.6B Q4_K_M(378MB) + Qwen3-Embedding-0.6B Q8_0(610MB、1024 维与 bge-m3 同维)，自动下载（hf-mirror 回退 + 断点续传 + fcntl 锁）+ 懒启动子进程 `127.0.0.1:8992`（`local_llm_server.py` 提供 `/v1/chat/completions` 流式与 `/v1/embeddings`，local provider、`AI_DEFAULT_MODEL=qwen3-0.6b`）；**全端点 async + `asyncio.Lock` 串行推理**（排队可取消），流式工作线程独占锁逐 token 投递 + stop 事件，客户端断连即停；子进程 stdout/stderr 落盘到 `logs/{日期}/local_llm.log`（manager 持句柄、shutdown 关闭；建文件失败会 warning 后才退回 DEVNULL）；uvicorn reload 经 pdeathsig 连带杀掉 8992，需重新拉起。部署形态：本地 LLM 是**唯一独立常驻子进程**，ASR/TTS 是**进程内懒加载引擎**；三端 `/ready` 统一（liveness `/health` 不变，本地 LLM 进 ready 且阻断、ASR/TTS 只读附带）；**ES 仅 python 用**，Mongo/Redis/MinIO 三端共用。
- **本地推理数值坑**：llama.cpp 流式**无 usage** ⇒ prompt 按 tokenize 计数 + completion 按 chunk 数累计，并在 `[DONE]` 前发 usage-only chunk，payload 须带 `stream_options.include_usage`；`<think>` 可能内嵌 content 且被流式分块拆开 ⇒ 状态机 `_ThinkSplitter`（尾部不完整标签前缀缓冲 + flush 兜底）放**跨 chunk 消费端**，逐 chunk 剥离是反模式；direct 路径 usage 键名须规范化（OpenAI `prompt/completion_tokens` ↔ 内部 `input/output_tokens`）。

## 4. 其它模块与数据机制定案
- **键级治理执行点只在 python**：`sys_api_key` 四治理字段由兼容层 `compatible_governance.py` 在兼容 API 入口预检（超限 429 `rate_limit_error`、白名单外 403 `permission_error`）；java/go 只做 CRUD（创建时校验白名单模型存在且启用 → A0400），转发即受治，**禁本地建执行点**（双重计数）。`model_whitelist` NULL/空数组同义＝继承用户可见模型。M2M key 的 sha256 须等于 `config/sql/data/sys_api_key.sql` 的 `key_hash`；M2M 调用方跳过配额扣减（`skip_quota_check=user.is_m2m`）。
- **软删唯一键治理（方案 A，2026-09-11）**：`deleted` = **删除时的行 id**（bigint），唯一键追加 `deleted` 列（索引名不变）⇒ 软删行可复用（重建同名/同码不再冲突），活跃行重复仍拒 `A0501`；白名单保留"永久不可复用"＝`sys_user.username`、`sys_ai_provider.provider_code`（应用层查全表判重）。Java `@TableLogic(value="0", delval="id")`、Go `gorm.Expr("id")`（`Update("deleted",1)` 已废）。python `SoftDeleteMixin` 全局 `do_orm_execute` 对 ORM select 自动追加 `deleted=0` ⇒ **查重/唯一性一律以"仅活跃行"为准**。
- **事务边界 ＝ 请求边界**：commit 在 `DBSessionMiddleware`（`app/middleware/db.py`）；读模型/CQRS/ES 同步必须走 `defer_after_commit` / `defer_conversation_sync`（`db.info[...]` 登记，commit 成功后、响应发出前执行；rollback 跳过、单条失败记 warning）。Service 层内联新开 session 必读到未提交数据。
- **缓存三层**：python `CacheService`＝L1（进程内 TTLCache）+ L2（Redis）+ Pub/Sub 广播；凡经其写入的键**失效必须走 `CacheService.delete`**；失效时机 afterCommit；Java `TransactionSynchronizationManager.runAfterCommit`、Go 事务在 repository 内提交（缓存天然在提交后）。跨端失效广播 `cache:invalidation` **只维护同端多实例 L1 一致性，跨后端不互听**；java/go 广播时绕过自家 L1 直连 L2，消息体 `${type:"key",key,senderId}`（AI 域另有 `{type:"ai_graph_invalidate",senderId}`，无 key）。
- **会话设备数上限（三端共库）**：索引 `session:user:{userId}` ZSet（member=sessionId、score=登录 epoch 秒，Go 显式 Truncate）；登录 ZADD → ZCARD 超限 → ZRANGE 升序踢最早（**须排除本次新会话**，防同秒平局误踢自己）→ 删 `session:{sid}` + ZREM。上限＝ROOT/ADMIN 固定 10，否则 `sys_member_benefit.max_devices`（int NOT NULL DEFAULT 1，种子 1/3/5/10），无档案按 level_0=1；`USE_MULTI_POINT=false` 不控制。踢会话保护 ROLE_ROOT（A0503）、不存在 A0401；**SCAN `session:*` 须排除 `session:user:*`**。
- **任务 module 推导**：三端导出/导入在 `params.module` 为空时从 `taskType` 推导（Java `TaskConstants.getModuleByType` / Python `rsplit("_",1)[0]` / Go `strings.TrimSuffix`）。
- **java 文件存储＝多后端共存（勿按 `file.type` 条件化）**：三 `FileService` bean 并存是设计（`StorageServiceFactory.get(storage)` 供历史文件按记录取后端、`getDefault()`＝`file.type` 为新上传默认；Rating/Feedback 遍历 `List<FileService>` 收集全后端 baseUrl 做 URL 白名单）。条件化会让非默认后端消失；单实现注入点（如 `AiSkillServiceImpl`）注入 Factory 用 `getDefault()`；守卫测试 `FileStorageBackendActivationTest`。
- **前端文档范式（已定型）**：公共 / 用户端 / 管理端三文档，公共承载共用视图层，数据范围由 `scope` 驱动（`self`=本人 / `admin`=指定用户）。已应用于 AI计费、AI知识库、AI模型管理、AI对话（6 文档）、语音。
- **front-vue AI 对话＝无状态通用组件库** `src/components/ai-chat/`（`types.ts` VM 契约源 / `vm/` 纯归约 / `adapters/fromSdk.ts` 唯一 wire→VM 翻译处 / `components/` 纯 props+emit）；**红线**：组件层零 store、零 `dehaze-sdk-js`、零 vue-router、零 ElMessage。状态在 `store/modules/chat/`（index 门面 + shared/conversation/messages/stream/feedback），宿主绑定 `src/composables/useChatVmBinding.ts`。
- **front-vue 枚举规范**：≥3 处消费须单源常量数组 `{label,value,tag}` + `TagType` 别名（`src/enums/TagType.ts`）、页面 `.find()` 派生；禁 Label/TagType 成对函数与双份映射（`EnumOption.tag` 必填）。
- **dehaze-test 定位＝开发工作台**（人工触发、产物是数据报告非 pass/fail，不承载 CI/回归/SDK 契约测试）；复用 `dehaze-python/.venv`；一次性脚本用完即删；**评估发现的硬性不变量必须沉淀回各端 pytest**。
