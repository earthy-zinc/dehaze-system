## 密码统一为 12345678 (2026-07-11 凌晨)

MinIO 要求密码 >= 8 位，`123456` 太短。将 `DEHAZE_PASSWORD` 统一改为 `12345678`。

### 操作步骤
1. 四个 .env 文件（根、go、python、java）全部改为 `DEHAZE_PASSWORD=12345678`
2. Java `application-dev.yml` MinIO secret-key 改回 `${DEHAZE_PASSWORD}`（统一变量引用）
3. 停止并删除所有旧容器
4. docker-compose.yml 中 mysql/redis/mongo/minio volumes 添加 `external: true`（复用旧数据）
5. `docker compose --env-file .env up -d` 重建容器
6. MySQL 旧数据密码为 `123456`，执行 `ALTER USER` 改为 `12345678`
7. Redis/MongoDB/MinIO/PostgreSQL 均直接用 `12345678` 验证通过
