# 2026-07-11

## 三端（Java/Go/Python）API 一致性规范（长期约定，MEMORY.md 未覆盖部分）
- 统一响应：`code=00000`、`msg="一切ok"`；token 失效统一 `HTTP 401 + A0230`
- null 字段不序列化：Java `non_null` / Go `omitempty` / Python `NonNullJSONResponse`
- `PageResult` 仅 `{list, total}`（无 `pageNum`/`pageSize`）
- 批量删除统一 `RequestBody {ids:[...]}`（非 Query）；删除参数统一 Query 而非 Path
- 端点尾斜杠 `/` 会导致 Python 307 重定向，写端点用 `@router.post("")` 而非 `("/")`
- `@require_permission` 装饰器要求函数签名含 `user: UserContext = Depends(get_current_user)` 参数

## Java 开发注意
- devtools 热重载 XML 需手动复制到 `target/classes/mapper/`
- MapStruct 编译时生成转换代码；`isRoot` 从 JWT `authorities` 检查 `ROLE_ROOT`，admin 的 authorities 为 `["ROLE_ADMIN"]`
- login 用 `@RequestBody` JSON body（之前已修复，非表单参数）

## JS SDK 参数/返回值一致性修复
- **Auth login**: FormData→JSON body（后端全部用 JSON body）
- **Auth logout**: DELETE→POST（后端全部用 POST）
- **Auth 补**: `getCurrentUser()` (`GET /me`)、`refreshToken()` (`POST /refresh`)
- **Dept delete**: 拆分为 `deleteById(id)` (单个) + `batchDelete(ids[])` (Body 批量)
- **Role**: `updateRoleMenus` PUT→PATCH + 新增 `updateStatus()`；data 改为 `{menuIds}`
- **User**: `getPage` 返回类型修复 + 新增 `updateStatus()`
- **DTS 修复**: auth model 的 `UserInfo` 重命名为 `LoginUser`（与 user model 冲突）
