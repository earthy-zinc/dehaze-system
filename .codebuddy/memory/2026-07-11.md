- 小程序/App 平台使用完整 URL `http://127.0.0.1:8989/api/v1`，H5 使用 vite proxy `/api/v1`
- 路由守卫白名单：login、home（首页可访问但不展示用户数据）
- 验证码登录后自动刷新
