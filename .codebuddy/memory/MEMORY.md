# Dehaze 项目记忆

> **定位**：本文件是**始终注入**的一层，只放"每次开工都要用"的基础口径与协作铁律（**≤100 行**）；项目细节知识一律在 skill **`dehaze-project-knowledge`**（`.codebuddy/skills/`）—— 动手写代码、评审、排查、做计划**前先调用该 skill**。
> **同一事实只存一处**：已属 `.codebuddy/rules/` 的行为规范（编码/注释/文档撰写/SDK 测试流程/python 单测/设计稿/同步清单）不在本文件重复，也不写跨文件的"详见 X"式引用（**普通文档互引对模型基本无效**，只是噪声）；但 **skill 内 `SKILL.md` → 自身 `references/` 的路由引用是加载机制，必须保留**。
> **本目录写入纪律**：①仅 lead 写入，其他成员只提报事实；②**禁整体重写**，只增量插入/定点替换（并发整体重写会因旧快照写回**静默删事实**）；③同文件多次编辑串行 + 落盘后另起命令 grep 复核；④自动记忆与 MEMORY.md 是两套存储，**不可互当副本**。

## 0. 三层职责（唯一事实源）

| 层 | 放什么 | 生效方式 |
|---|---|---|
| `rules/`（含 always-applied `01-common-rules`） | **行为规范**（怎么做事的强制约束） | 强制 / 按描述触发 |
| `memory/MEMORY.md`（本文件） | **每会话都要用的基础口径** + 协作铁律 + 边界表 | 始终注入 |
| `skills/dehaze-project-knowledge/` | **其余项目事实与坑**（架构定案 / 契约细节 / 数据配置 / 测试基建 / 语言栈 / 待裁决） | 调用后按需读 `references/` |

冲突优先级：**rules > 本文件 > skill 事实记录**。

## 1. 基础口径（跨端交互只用这几条）

- 三端后端 **java 8989 / go 8990 / python 8991**；基础设施 MySQL 3306 / Redis 6379 / Mongo 27017 / MinIO 9100·9190 / RabbitMQ 5672·15672，**远程不开放需 `ssh -L` 转发**；另有 MCP 网关 8082、内置本地 LLM 8992、数据集 nginx 9000。
- **日志**：`logs/{yyyy-MM-dd}/{console,info,error}.log`（仅按日期切割、保留 30 天、无大小切割）。
- **python 是三端唯一行为事实源**；`sys_ai_*`（AI 域）只存在于 python，java/go 的 B 类端点（LLM/向量/流式/评测/上传/语音）转发 python。
- **账号**：root = user_id 1 / admin = user_id 2；dev admin 密码 `Dehaze2026`；密码只在根 `.env`。
- **响应**：`code:"00000"`（字符串，非 200）+ `msg`；**HTTP 状态三端本就不同，只认 body code**；分页 `pageNum/pageSize`（`pageSize ≤ 100`）；**空字段三端均不下发** ⇒ SDK/前端类型用 `field?: T`；后端金额单位为**分**（前端表单元、显示 `/100`）。

## 2. 协作铁律（违反即事故）

1. **文件写入**：同文件多处编辑串行或整体重写；落盘后另起命令 **grep 复核**；被旧快照写回即重放。本环境**高发且含子代理**（单日曾复现 4 次"回执成功却丢改动"）⇒ **以磁盘 grep/编译为唯一裁决依据，自述与报告口径一律作废**。
2. **改 schema/实体必须写幂等迁移并手工跑开发库**：pytest 重建的是 `dehaze_test`，**CI 绿 ≠ 开发库可用**（缺列直接 500）；**新列/新表先落 DDL 再重启后端**。
3. **共享工作区禁 `git stash`/`reset`/`checkout`**（会卷走队友未提交改动）；越界改动宁可留 diff 噪音；域内非本人改动按"团队在途中间态"排查，**上报不擅自恢复**。
4. **全量验证前确认无并发构建/测试**：pytest 与前端 vitest 并发会假失败；`mvn test` 会重写 `target/classes`，与运行中的 `spring-boot:run` 冲突（先 `run.py stop java`）；重型与跨端套件串行执行。
5. **批量/格式化须显式枚举文件清单**（如 `git diff --name-only -- '*.go' | xargs -r gofmt -w`），禁目录级扫描写入。
6. **范围/计数类结论必须实测并附"计数基 + 时间戳"**；判断"缺口/丢失"前先自检检索式是否漏项、输出是否被截断。
7. **测试不放水**：禁"环境未就绪型"skip（须失败暴露），仅"功能未实现（规划中）/设计上不存在"可 skip；"注解/配置存在"不算验收，须行为级断言 + 摘除反证。
8. **多 agent 并行**：同一文件禁并行编辑；重启只动自己负责的后端；改共享文件（doc/测试/SDK）前先说明范围并广播。
