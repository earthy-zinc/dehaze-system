## Spring Boot 3.5 升级（用户指令的最后一项，已完成）
- **升级链**：parent 3.3.11 → 3.5.16（3.3 OSS 支持已结束）；mockito 5.23.0/byte-buddy 1.18.14 覆盖保留；okhttp 显式钉 4.12.0（Boot 3.5 不再管理 okhttp，传递依赖解析到 5.x 会让 minio 炸 NoClassDefFoundError）；**redisson 3.24.3 → 3.52.0**
- **重大根因（耗时最长的坑）**：redisson 3.24.3 的 redisson-spring-data-31 与 spring-data-redis 3.5 的 `DefaultedRedisConnection.pExpire` 默认实现（`keyCommands().pExpire` 返回自身视图）**无限自递归 → StackOverflowError**。触发条件：登录失败计数 count==1 时的 expire 调用——所以"新用户名首次登录失败/重置密码后旧密码登录"必炸，已有失败记录的用户反而正常（count>1 不调 expire）。表象：B0001 "Handler dispatch failed: java.lang.StackOverflowError"
- **排查工具链（值得复用）**：SOE 堆栈为空（栈耗尽时 fillInStackTrace 失败）；TRACE 日志被 logback-spring.xml 自定义 appender 挡住；JFR 抓不到 Error 类事件；**jdb 远程调试是终局方案**：`-Dspring-boot.run.jvmArguments="-agentlib:jdwp=...,address=127.0.0.1:5099"` + `jdb -attach` + `catch java.lang.StackOverflowError` + `where`——直接看到 8200 帧 pExpire 自递归
- **权限聚合空串缺陷**：`SysRoleMenuMapper.getRolePermsList` 缺 deleted=0/perm 非空过滤（真正的登录权限来源，SysMenuMapper.listRolePerms 是另一条），已对齐 python get_role_perms 双重过滤
- **增量编译陷阱**：改 parent 版本后 `mvn spring-boot:run` 不重编译未变更源文件 → 陈旧类的 NoSuchMethodError（ExchangeBuilder.durable），必须 `mvn clean`
- 最终验证：mvn test 296/296；SDK 全量 1219 过/127 挂（126=未实现 AI 模块、1=member-edge 脏语料偶发竞态）
