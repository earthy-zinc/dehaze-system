# 2026-08-01

## Git 历史清理：移除 Go 编译产物

- 问题：`git format-patch gitee/master --stdout > add.patch` 生成的 patch 达 165MB（261 万行），原因是历史中有两个 Go 二进制文件：`dehaze-go/main`（84.4MB）和 `dehaze-go/dehaze-go`（84.37MB）
- 解决：使用 `git filter-branch --index-filter` 从 52 个提交历史中移除这两个二进制文件
- 结果：patch 缩至 4.4MB（106,086 行），缩减 97.3%
- 原分支已备份为 `backup-before-clean`，确认无误后可删除
- 后续执行 `git reflog expire + git gc --aggressive --prune=now` 清理孤立 object，.git 从 520MB 降到 434MB
- filter-branch 重写历史后，`format-patch` 无法在 gitee/master 上应用（commit hash 全变，历史分叉）
- 尝试 `git rebase gitee/master` 失败：47 个提交逐个 rebase 冲突过多，`-X theirs` 也处理不了 delete/modify 类型冲突
- 最终方案：用 `git diff gitee/master -- . ':!dehaze-go/main' ':!dehaze-go/dehaze-go' > add.patch` 生成单一 diff（2.7MB）
- 用 `git worktree` 隔离验证：patch 在 gitee/master 上 `git apply` 成功，应用后与 master 仅 1 行差异（排除二进制文件后完全一致）
- 教训：filter-branch 重写历史后，format-patch 不再可用；要保留提交历史应直接 force push，要生成可应用 patch 应用 `git diff`
