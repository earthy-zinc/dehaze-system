## 文档说明

本文档为图像去雾系统数据集管理模块的前端代码设计方案，覆盖图片展示模式、图片搜索筛选、大图查看、配对图片切换、批量操作、无限滚动加载等功能。

### 设计原则

1. **组件化设计**：将筛选面板、搜索栏、展示模式切换、大图查看等功能拆分为独立组件，便于复用和维护
2. **性能优先**：采用虚拟滚动、懒加载、防抖节流等策略优化大数据量场景
3. **用户体验**：提供流畅的浏览体验，支持用户偏好设置存储
4. **增量改造**：在现有 `LongitudinalWaterfall` 组件基础上扩展，复用已有的瀑布流算法

## 2. 现有实现概览

### 2.1 页面结构

#### DataItem.vue

- **职责**：展示数据集详情和图片瀑布流
- **当前功能**：
  - 图片类型切换（清晰图/雾霾图）
  - 关键词搜索
  - 无限滚动加载（IntersectionObserver）
  - 大图查看（v-viewer 库）
- **数据流**：
  1. 通过路由参数获取 `datasetId`
  2. 调用 `DatasetAPI.getDatasetInfoById()` 获取数据集信息
  3. 调用 `DatasetAPI.getImageItem()` 分页获取图片列表
- **当前状态**：`datasetId`、`queryParams`、`images`、`imageData`、`imageTypes`

### 2.2 组件结构

#### LongitudinalWaterfall（`src/components/LongitudinalWaterfall/index.vue`）

- **职责**：纵向瀑布流布局
- **Props**：
  - `list`: `ViewCard[]` - 图片列表
  - `width`: `number` - 列宽（默认300）
  - `breakpoints`: `Object` - 响应式断点配置
  - `gutter`: `number` - 间距（默认10）
  - `lazyload`: `boolean` - 懒加载开关
- **Events**：
  - `click-item`: 点击图片
  - `after-render`: 渲染完成
- **特性**：
  - 使用 `useCalculateCols` 计算列数
  - 使用 `useLayout` 计算布局位置
  - 支持懒加载和动画效果

#### ViewCard 类型（`src/components/Waterfall/types.ts`）

```typescript
interface ViewCard {
  src: any;
  id?: string | number;
  name?: string;
  star?: boolean;
  backgroundColor?: string;
  [attr: string]: any;
}
```

#### 3.2.3 HorizontalWaterfall 组件

**文件路径**：`src/views/dataset/components/HorizontalWaterfall.vue`

**Props**：

| 属性 | 类型 | 默认值 | 说明 |
|-----|------|-------|------|
| `images` | `ImageItem[]` | `[]` | 图片列表 |
| `rowHeight` | `number` | `200` | 行高 |

**Emits**：

|-----|------|------|
| `click-image` | `ImageItem` | 点击图片 |

**布局算法**：

1. 固定行高（默认200px）
2. 图片宽度按原始宽高比计算：`width = rowHeight * (originalWidth / originalHeight)`
3. 按行填充，每行图片宽度之和不超过容器宽度
4. 支持横向滚动

**交互设计**：

- 支持鼠标滚轮横向滚动（wheel 事件转换）
- 支持触摸滑动（touch 事件）
- 滚动到右侧边缘时触发加载更多

### 3.6 Composables 封装

#### 3.6.1 useImageSearch

**文件路径**：`src/composables/useImageSearch.ts`

**功能**：封装图片搜索逻辑

**导出接口**：

| 名称 | 类型 | 说明 |
|-----|------|------|
| `filterParams` | `Ref<ImageItemQuery>` | 筛选参数 |
| `searchHistory` | `Ref<string[]>` | 搜索历史 |
| `sceneTypes` | `Ref<string[]>` | 场景类型列表 |
| `search` | `(keywords: string) => void` | 执行搜索（防抖300ms） |
| `applyFilter` | `(params: ImageItemQuery) => void` | 应用筛选 |
| `resetFilter` | `() => void` | 重置筛选 |
| `clearHistory` | `() => void` | 清空历史 |
| `loadSceneTypes` | `() => Promise<void>` | 加载场景类型 |

**实现要点**：

- 搜索历史存储在 localStorage，最多保留10条
- 搜索输入防抖300ms

### 3.8 数据流说明

#### 3.8.1 展示模式切换流程

```
用户点击模式切换按钮
    ↓
useDisplayMode.setDisplayMode(newMode)
    ↓
保存到 localStorage
    ↓
displayMode 状态更新
    ↓
v-if 切换展示组件
    ↓
新组件接收 images 数据渲染
```

#### 3.8.2 筛选搜索流程

```
用户设置筛选条件或输入搜索关键词
    ↓
useImageSearch.applyFilter(params) 或 useImageSearch.search(keywords)
    ↓
防抖处理（300ms）
    ↓
重置分页参数（pageNum = 1）
    ↓
调用 DatasetAPI.searchImages(query)
    ↓
更新图片列表，重置无限滚动状态
    ↓
各展示组件重新渲染
```

#### 3.8.3 大图查看流程

```
用户点击图片
    ↓
设置 currentViewImage = clickedImage
    ↓
设置 showImageViewer = true
    ↓
ImageViewer 组件显示
    ↓
调用 DatasetAPI.getPairedImages(id) 获取配对信息
    ↓
渲染图片详情和配对切换区域
```

#### 3.8.4 批量下载流程

```
用户选择多张图片
    ↓
点击"批量下载"按钮
    ↓
调用 DatasetAPI.batchDownload(selectedIds)
    ↓
后端返回 ZIP 文件流
    ↓
浏览器触发下载
```

## 4. 异常处理与边界情况

### 4.1 网络异常

| 触发条件 | 前端行为 |
|---------|---------|
| 图片列表请求超时 | 显示"请求超时，请重试"，提供重试按钮 |
| 图片列表请求失败 | 显示错误信息，保留当前数据 |
| 图片加载失败 | 显示占位图，提供重新加载按钮 |
| 下载请求失败 | 显示"下载失败，请重试"提示 |

### 4.2 数据异常

| 触发条件 | 前端行为 |
|---------|---------|
| 图片列表为空 | 显示"暂无图片"空状态组件 |
| 搜索无结果 | 显示"未找到匹配结果"，建议调整筛选条件 |
| 配对图片不存在 | 配对切换区域不显示，直接下载当前图片 |
| 图片详情获取失败 | 显示错误提示，关闭大图查看器 |

### 4.3 批量操作异常

| 触发条件 | 前端行为 |
|---------|---------|
| 批量删除部分失败 | 显示"删除完成，成功X项，失败Y项" |
| 批量下载数量超限 | 提示"单次最多下载100张图片" |
| 批量操作未选择项 | 按钮禁用状态 |

### 4.4 状态预留

| 状态 | 说明 | 使用场景 |
|-----|------|---------|
| `loading` | 加载中 | 数据请求时 |
| `error` | 错误 | 请求失败时 |
| `empty` | 空数据 | 无数据时 |
| `loadingMore` | 加载更多中 | 无限滚动加载时 |
| `finished` | 加载完成 | 所有数据加载完毕 |

## 5. 安全与性能注意事项

### 5.1 安全方面

#### 输入校验

| 搜索关键词 | 限制长度100字符，过滤特殊字符 |

#### XSS 防护

- 所有用户输入使用 `v-text` 或模板插值
- 文件名展示时进行转义

### 5.2 性能方面

#### 图片加载优化

| 策略 | 说明 |
|-----|-----|
| 懒加载 | 使用 IntersectionObserver，仅加载可见区域图片 |
| 缩略图 | 列表使用缩略图URL，大图查看时加载原图 |
| 预加载 | 预加载下一屏图片（可选） |
| 错误重试 | 图片加载失败时自动重试一次 |

#### 展示模式优化

| 模式 | 优化策略 |
|-----|---------|
| 列表模式 | 使用 el-table 内置虚拟滚动或 vue-virtual-scroller |
| 纵向瀑布流 | 现有实现已支持懒加载和动画 |
| 横向瀑布流 | 仅渲染可见区域，按需加载 |
| 网格模式 | 使用 CSS Grid + 懒加载 |

#### 请求优化

| 策略 | 说明 |
|-----|-----|
| 分页加载 | 每次加载20条 |
| 防抖搜索 | 搜索输入防抖300ms |
| 节流滚动 | 滚动事件节流100ms |
| 缓存 | 场景类型列表缓存5分钟 |
