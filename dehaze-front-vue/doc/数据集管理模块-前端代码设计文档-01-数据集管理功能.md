## 文档说明

本文档为图像去雾系统数据集管理模块的前端代码设计方案，覆盖数据集列表展示、详情查看、统计分析、数据集下载等功能。

### 设计原则

1. **增量改造**：在现有 `DatasetList.vue` 和 `DataItem.vue` 基础上进行扩展，复用已有组件和 SDK
2. **组件化设计**：将统计信息、下载进度等功能拆分为独立组件，便于复用和维护
3. **性能优先**：采用懒加载、防抖节流、缓存等策略优化大数据量场景
4. **用户体验**：提供清晰的加载状态、错误提示和操作反馈

## 2. 现有实现概览

### 2.1 页面结构

#### DatasetList.vue

- **职责**：展示数据集树形列表页面
- **数据流**：直接使用 `DataList` 组件，传入 `listType="dataset"`
- **当前实现**：仅作为容器组件，业务逻辑在 `DataList` 中

#### DataItem.vue

- **职责**：展示数据集详情和图片瀑布流
- **数据流**：
  1. 通过路由参数获取 `datasetId`
  2. 调用 `DatasetAPI.getDatasetInfoById()` 获取数据集信息
  3. 调用 `DatasetAPI.getImageItem()` 分页获取图片列表
- **当前字段**：name、type、description
- **当前功能**：图片类型切换、关键字搜索、瀑布流展示、无限滚动加载

### 2.2 组件结构

#### DataList（`src/components/DataList/index.vue`）

- **职责**：通用数据列表组件，支持数据集和算法模型
- **Props**：`listType`（dataset/algorithm）
- **当前列**：name、type、description、size、total/importPath、path、status
- **当前操作**：查看、新增、编辑、删除
- **列设置**：支持通过下拉框选择显示的列

#### EditDialog（`src/components/DataList/EditDialog/index.vue`）

- **职责**：数据集/模型新增和编辑弹窗
- **当前字段**：name、type、description、size、total、path、status
- **缺失字段**：样例图片（img）、父数据集选择

### 3.3 数据集下载功能

#### 3.3.1 DownloadProgress 组件

**文件路径**：`src/views/dataset/components/DownloadProgress.vue`

**Props**：

| 属性 | 类型 | 说明 |
|-----|------|------|
| `visible` | `boolean` | 组件显示状态 |
| `taskId` | `string` | 下载任务ID |

**Emits**：

| 事件 | 说明 |
|-----|------|
| `update:visible` | 关闭组件 |
| `completed` | 下载完成 |
| `failed` | 下载失败 |

**状态展示**：

| 状态 | 展示内容 |
|-----|---------|
| `processing` | 进度条 + "正在打包中..." |
| `completed` | 下载链接 + "打包完成，点击下载" |
| `failed` | 错误信息 + "重试"按钮 |

**轮询逻辑**：

1. 组件挂载后，每2秒调用 `DatasetAPI.getDownloadTaskStatus(taskId)` 查询状态
2. 状态为 `processing` 时继续轮询，更新进度
3. 状态为 `completed` 时停止轮询，显示下载链接
4. 状态为 `failed` 时停止轮询，显示错误信息
5. 组件卸载时清除定时器

#### 3.3.2 下载流程

**用户操作流程**：

```
点击"下载数据集"按钮
    ↓
调用 DatasetAPI.createDownloadTask(datasetId)
    ↓
返回 taskId，显示 DownloadProgress 组件
    ↓
轮询查询任务状态
    ↓
状态为 completed → 显示下载链接
    ↓
用户点击下载 → 浏览器下载文件
```

#### 3.3.3 Store 扩展

**dataset.ts 新增方法**：

| 方法 | 说明 |
|-----|------|
| `createDownloadTask(datasetId)` | 创建下载任务 |
| `getDownloadTaskStatus(taskId)` | 查询下载任务状态 |

#### 3.3.4 SDK 扩展

**【建议方案】DatasetAPI 新增方法**：

| 方法 | 请求 | 说明 |
|-----|------|------|
| `createDownloadTask(id, options?)` | `POST /api/v1/dataset/{id}/download` | 创建下载任务 |
| `getDownloadTaskStatus(taskId)` | `GET /api/v1/dataset/download/{taskId}` | 查询任务状态 |

**类型定义**：

```typescript
// 下载任务状态
interface DownloadTaskVO {
  taskId: string;
  status: 'processing' | 'completed' | 'failed';
  progress?: number;
  downloadUrl?: string;
  expireTime?: string;
  errorMessage?: string;
}

// 下载选项
interface DownloadOptions {
  organizeByItem?: boolean;  // 是否按数据项分目录
}
```

### 3.5 数据流说明

#### 3.5.1 数据集列表加载流程

```
进入 /dataset 路由
    ↓
DatasetList.vue 渲染
    ↓
DataList 组件 onMounted
    ↓
调用 DatasetAPI.getList(queryParams)
    ↓
渲染树形表格（含 imageCount、usageCount 列）
```

#### 3.5.2 数据集详情页加载流程

```
进入 /dataset/:id 路由
    ↓
DataItem.vue onMounted
    ↓
并行请求：
├── DatasetAPI.getDatasetInfoById(id) → 数据集详情（含统计）
└── DatasetAPI.getImageItem(id, query) → 图片列表
    ↓
渲染 DatasetHeader（基本信息）
    ↓
渲染图片瀑布流
```

#### 3.5.3 统计分析弹窗流程

```
点击"统计分析"按钮
    ↓
设置 showStatistics = true
    ↓
StatisticsDialog 组件显示
    ↓
使用 dataset.sceneDistribution 等数据渲染图表
```

#### 3.5.4 数据集下载流程

```
点击"下载数据集"按钮
    ↓
调用 DatasetAPI.createDownloadTask(datasetId)
    ↓
返回 { taskId, status: 'processing' }
    ↓
显示 DownloadProgress 组件
    ↓
每2秒轮询 DatasetAPI.getDownloadTaskStatus(taskId)
    ↓
status === 'completed'
    ↓
显示下载链接，用户点击下载
```

## 4. 异常处理与边界情况

### 4.1 数据异常

| 触发条件 | 前端行为 |
|---------|---------|
| 数据集不存在（404） | 显示错误提示，3秒后跳转到列表页 |
| 数据集详情获取失败 | 显示错误提示，提供重试按钮 |
| 统计数据为空 | 图表区域显示"暂无数据"占位 |
| 图片列表为空 | 显示空状态组件 |

### 4.2 下载任务异常

| 触发条件 | 前端行为 |
|---------|---------|
| 创建下载任务失败 | 显示错误提示，关闭进度组件 |
| 任务状态查询失败 | 重试3次后显示错误，提供重试按钮 |
| 任务状态为 failed | 显示后端返回的错误信息，提供重试按钮 |
| 下载链接过期 | 提示"链接已过期，请重新下载" |

### 4.3 网络异常

| 触发条件 | 前端行为 |
|---------|---------|
| 请求超时 | 显示"网络超时，请稍后重试" |
| 网络断开 | 显示"网络连接失败，请检查网络" |
| 服务器错误（500） | 显示"服务器异常，请稍后重试" |

### 4.4 状态预留

| 状态 | 说明 | 使用场景 |
|-----|------|---------|
| `loading` | 加载中 | 数据请求时 |
| `error` | 错误 | 请求失败时 |
| `empty` | 空数据 | 无数据时 |
| `downloading` | 下载中 | 下载任务进行中 |

## 5. 安全与性能注意事项

### 5.1 安全方面

#### 输入校验

| 字段 | 校验规则 |
|-----|---------|
| 数据集名称 | 必填，1-64字符 |
| 数据集描述 | 选填，最大2048字符 |
| 样例图片 | 仅允许 jpg/png/gif，最大2MB |

#### XSS 防护

- 所有用户输入内容使用 `v-text` 或模板插值渲染，避免 `v-html`
- 文件名展示时进行转义处理

### 5.2 性能方面

#### 请求优化

| 策略 | 说明 |
|-----|-----|
| 数据集列表缓存 | 使用 Store 缓存列表数据，避免重复请求 |
| 详情页数据复用 | 从列表页跳转时携带基础信息，减少等待时间 |
| 防抖搜索 | 搜索输入使用 300ms 防抖 |

#### 渲染优化

| 策略 | 说明 |
|-----|-----|
| 图表懒加载 | 统计弹窗打开时才初始化图表 |
| 图表销毁 | 弹窗关闭时销毁图表实例，释放内存 |
| 虚拟滚动 | 大数据集列表使用虚拟滚动（如需要） |

#### 下载优化

| 策略 | 说明 |
|-----|-----|
| 轮询间隔 | 初始2秒，任务时间较长时逐步增加到5秒 |
| 轮询上限 | 最多轮询300次（10分钟），超时提示 |
| 组件卸载清理 | 离开页面时清除轮询定时器 |

| 下载任务接口未实现 | 下载功能无法使用 | 前端先完成UI，接口联调时对接 |
| 大数据集下载时间过长 | 用户等待时间长 | 增加预估时间提示，支持后台下载 |
| 图表库体积较大 | 首屏加载变慢 | 使用动态导入，按需加载图表组件 |
| 场景类型过多 | 饼图展示不清晰 | 超过10种时使用标签云或分组展示 |
