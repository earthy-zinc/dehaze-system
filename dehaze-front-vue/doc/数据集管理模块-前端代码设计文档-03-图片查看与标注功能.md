## 文档说明

本文档为图像去雾系统数据集管理模块的前端代码设计方案，旨在满足《07-数据集管理模块需求-03-图片查看与标注功能.md》中定义的图片查看与标注功能需求。

### 设计原则

1. **组件化设计**：将图片详情、标注表单、配对切换等功能拆分为独立组件
2. **用户体验优先**：提供流畅的图片切换、标注编辑体验，大图加载 <2s
3. **复用现有架构**：基于现有 `DataItem.vue` 和 `v-viewer` 进行扩展

```typescript
function showBigPicture(itemId: number) {
  let curSelectedImages = () => {
    let curImageItem = imageData.find((item) => item.id === itemId);
    let result = [] as string[];
    if (curImageItem) {
      curImageItem.imgUrl.map((item) => {
        item.originUrl
          ? result.push(changeUrl(item.originUrl))
          : result.push(changeUrl(item.url));
      });

    return result;
```

### 3.7 Composables 封装

#### 3.7.1 useImageNavigation

**文件路径**：`src/composables/useImageNavigation.ts`

**导出接口**：

| 名称 | 类型 | 说明 |
|-----|------|------|
| `currentIndex` | `Ref<number>` | 当前数据项索引 |
| `total` | `Ref<number>` | 数据项总数 |
| `hasPrev` | `ComputedRef<boolean>` | 是否有上一张 |
| `hasNext` | `ComputedRef<boolean>` | 是否有下一张 |
| `goPrev` | `() => void` | 切换到上一张 |
| `goNext` | `() => void` | 切换到下一张 |
| `positionText` | `ComputedRef<string>` | 位置文本（如 "3/50"） |

**实现逻辑**：

```typescript
export function useImageNavigation(
  items: Ref<ImageItem[]>,
  initialIndex: Ref<number>
) {
  const currentIndex = ref(initialIndex.value);
  const total = computed(() => items.value.length);
  
  const hasPrev = computed(() => currentIndex.value > 0);
  const hasNext = computed(() => currentIndex.value < total.value - 1);
  
  const goPrev = () => {
    if (hasPrev.value) currentIndex.value--;
  };
  
  const goNext = () => {
    if (hasNext.value) currentIndex.value++;
  };
  
  const positionText = computed(() => `${currentIndex.value + 1}/${total.value}`);
  
  return { currentIndex, total, hasPrev, hasNext, goPrev, goNext, positionText };
}
```

#### 3.7.2 useImageDownload

**文件路径**：`src/composables/useImageDownload.ts`

**导出接口**：

| 名称 | 类型 | 说明 |
|-----|------|------|
| `downloadSingle` | `(url: string, filename: string) => void` | 下载单张图片 |
| `downloadPaired` | `(itemId: number, option: DownloadOption) => Promise<void>` | 下载配对图片 |
| `hasPairedImages` | `(imageItem: ImageItem) => boolean` | 判断是否有配对图片 |
| `isDownloading` | `Ref<boolean>` | 下载中状态 |

**下载选项类型**：

```typescript
type DownloadOption = 'current' | 'clear' | 'hazy_all' | 'all';
```

**实现逻辑**：

```typescript
export function useImageDownload() {
  const isDownloading = ref(false);
  
  const downloadSingle = (url: string, filename: string) => {
    const link = document.createElement('a');
    link.href = url;
    link.download = filename;
    link.click();
  };
  
  const downloadPaired = async (itemId: number, option: DownloadOption) => {
    isDownloading.value = true;
    try {
      if (option === 'current' || option === 'clear') {
        // 单张下载
        const response = await DatasetAPI.downloadImage(itemId, option);
        // 处理下载
      } else {
        // 打包下载
        const response = await DatasetAPI.downloadPairedImages(itemId, option);
        // 处理 ZIP 下载
      }
    } finally {
      isDownloading.value = false;
    }
  };
  
  const hasPairedImages = (imageItem: ImageItem) => {
    return imageItem.imgUrl && imageItem.imgUrl.length > 1;
  };
  
  return { downloadSingle, downloadPaired, hasPairedImages, isDownloading };
}
```

### 3.9 数据流说明

#### 3.9.1 大图查看与配对切换流程

```
用户点击瀑布流中的图片
    ↓
DataItem.showBigPicture(itemId)
    ↓
设置 selectedItemIndex, 打开 ImageDetailDialog
    ↓
ImageDetailDialog.onMounted()
    ↓
调用 DatasetAPI.getDatasetItemDetail(itemId)
    ↓
获取数据项详情（含 clearImage, hazyImages）
    ↓
├── 只有一张图片 → 隐藏 PairedImageSwitch
└── 有配对图片 → 显示 PairedImageSwitch
    ↓
默认显示第一张图片，调用 DatasetAPI.getImageDetail(imageId)
    ↓
显示图片详情信息
    ↓
用户点击配对切换按钮
    ↓
更新 currentPairedIndex
    ↓
调用 DatasetAPI.getImageDetail(newImageId)
    ↓
更新图片详情显示
```

#### 3.9.2 上一张/下一张切换流程

```
用户点击"下一张"按钮
    ↓
useImageNavigation.goNext()
    ↓
检查 hasNext
    ↓
├── false → 提示"已是最后一张"
└── true → currentIndex++
    ↓
触发 watch(currentIndex)
    ↓
获取新数据项 imageItems[currentIndex]
    ↓
调用 DatasetAPI.getDatasetItemDetail(newItemId)
    ↓
重置 currentPairedIndex = 0
    ↓
调用 DatasetAPI.getImageDetail(firstImageId)
    ↓
更新显示
```

#### 3.9.3 标注保存流程

```
用户点击"编辑"按钮
    ↓
isEditing = true，显示 AnnotateForm
    ↓
用户修改表单字段
    ↓
用户点击"保存"
    ↓
AnnotateForm 表单校验
    ↓
├── 校验失败 → 显示错误提示
└── 校验通过 → emit('save', form)
    ↓
ImageDetailDialog 调用 DatasetAPI.updateImageInfo(form)
    ↓
├── 失败 → 显示错误提示
└── 成功 → 
    ├── 重新获取图片详情
    ├── isEditing = false
    └── emit('annotate-saved')
```

#### 3.9.4 下载流程

```
用户点击"下载"按钮
    ↓
useImageDownload.hasPairedImages(imageItem)
    ↓
├── false → 直接调用 downloadSingle(url, filename)
└── true → 打开 DownloadOptionsDialog
    ↓
用户选择下载选项
    ↓
DownloadOptionsDialog emit('confirm', option)
    ↓
├── option === 'current' → downloadSingle(currentUrl, filename)
├── option === 'clear' → DatasetAPI.downloadImage(itemId, 'clear')
├── option === 'hazy_all' → DatasetAPI.downloadPairedImages(itemId, 'hazy_all')
└── option === 'all' → DatasetAPI.downloadPairedImages(itemId, 'all')
    ↓
下载完成，关闭弹窗
```

## 4. 异常处理与边界情况

### 4.1 网络异常

| 触发条件 | 前端行为 |
|---------|---------|
| 图片详情加载失败 | 显示"加载失败"，提供重试按钮 |
| 数据项详情加载失败 | 显示错误信息，关闭弹窗 |
| 标注保存失败 | 显示错误提示，保留表单数据 |
| 下载请求失败 | 显示"下载失败，请重试" |

### 4.2 数据异常

| 触发条件 | 前端行为 |
|---------|---------|
| 图片不存在（404） | 显示"图片不存在"，关闭弹窗 |
| 配对数据为空 | 隐藏配对切换组件 |
| 场景类型列表为空 | 允许用户自由输入 |

### 4.3 边界情况

| 场景 | 处理方式 |
|-----|---------|
| 第一张图片点击"上一张" | 按钮禁用或提示"已是第一张" |
| 最后一张图片点击"下一张" | 按钮禁用或提示"已是最后一张" |
| 批量标注超过50张 | 提示"单次最多标注50张图片" |
| 批量标注表单全为空 | 提示"请至少填写一个字段" |

## 5. 安全与性能注意事项

### 5.1 安全方面

| 安全项 | 措施 |
|-------|------|
| 输入校验 | 场景类型最大64字符，描述最大255字符 |
| XSS 防护 | 使用 Vue 模板语法自动转义 |
| 文件下载 | 下载 URL 使用后端代理，不直接暴露存储路径 |

### 5.2 性能方面

| 性能项 | 措施 |
|-------|------|
| 图片加载 | 大图使用渐进式加载，显示加载进度 |
| 预加载 | 预加载上一张/下一张数据项的缩略图 |
| 接口缓存 | 场景类型列表缓存到 Store，避免重复请求 |
| 防抖处理 | 上下张切换添加防抖，避免快速点击 |

### 5.3 用户体验

| 体验项 | 措施 |
|-------|------|
| 加载状态 | 显示骨架屏或 loading 动画 |
| 切换动画 | 配对切换和上下张切换使用平滑过渡 |
| 键盘支持 | 支持左右箭头键切换，ESC 关闭弹窗 |
