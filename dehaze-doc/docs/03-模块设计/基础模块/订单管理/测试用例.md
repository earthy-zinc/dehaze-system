## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **套餐数据** | 在售套餐各若干（不同等级/周期） | 用于下单测试 |
| **用户数据** | 各等级会员用户、普通用户 | 用于不同场景下单 |
| **优惠券** | 不同类型可用券 | 用于订单抵扣测试 |
| **支付配置** | 微信/支付宝沙箱配置、平台余额充值用户 | 用于支付测试 |
| **订单数据** | 各状态订单样本（待支付/已支付/已完成/已取消/退款中/已退款） | 用于列表查询与状态流转 |

### 3.2 数据清理策略

- 测试订单使用统一前缀 `DHTEST` 标识订单号
- 测试结束按前缀清理订单、支付流水、退款记录
- 支付沙箱数据每日重置
- 测试优惠券使用专用批次，便于回收

### 3.3 测试范围

**包含的功能点：**
- 订单创建与支付对接
- 支付回调处理与幂等
- 订单超时取消
- 退款申请、审核、执行
- 自动续费
- 后台订单管理与统计

**不包含的功能点：**
- 套餐定义与定价（套餐模块测试）
- 会员等级变更（会员模块测试）
- 支付渠道接口细节（渠道沙箱测试）

## 5. 关键边界与异常场景

| 场景 | 测试点 | 期望行为 |
|------|--------|---------|
| **订单数量边界** | 订单达到万级 | 列表查询响应时间仍&lt;500ms |
| **支付回调并发** | 同一订单多次回调 | Redis 锁保护，仅一次执行业务 |
| **优惠券并发使用** | 多订单同时使用同一券 | 唯一约束或乐观锁阻止 |
| **余额并发扣减** | 同一用户并发支付 | Redis 原子操作 + 异步落库 |
| **自动续费并发** | 同一用户并发扣款 | 用户维度串行处理 |
| **状态机非法流转** | cancelled → paid 等非法流转 | 校验失败，拒绝流转 |
| **金额边界** | 订单金额为0或负数 | 校验失败 |
| **时间边界** | 套餐到期当天续费 | 从支付时间开始计算 |

## 7. 安全性测试

| 测试项 | 验证方式 | 预期结果 |
|--------|---------|---------|
| **支付签名验证** | 伪造支付回调 | 签名校验失败，拒绝处理 |
| **金额校验** | 篡改回调金额 | 与订单金额不一致时记录告警 |
| **幂等处理** | 重复回调 | 幂等键唯一约束，仅一次处理 |
| **防重复下单** | 同一用户同一套餐5秒内重复 | 拒绝重复下单 |
| **敏感信息脱敏** | 支付流水号展示 | 脱敏显示 |
| **权限控制** | 无权限用户审核退款 | 返回403 |
| **数据隔离** | 用户查看他人订单 | 返回 ORDER_NOT_FOUND |
| **SQL注入** | 订单号参数注入 | 参数化查询转义 |
| **传输安全** | 抓包分析请求 | HTTPS加密传输 |
