# 部门管理模块需求规格

## 1. 模块概述

### 1.1 模块定位

部门管理模块是 AI 图像处理平台后台管理系统的核心基础模块之一，负责维护和管理系统中的组织架构部门结构。平台支持去雾/去雨/去雪/低光增强/超分辨率/去噪/图像修复等多任务图像处理，覆盖 Web（Vue/React）、Android、Flutter、Taro/UniApp 小程序、Electron 桌面端等多端，落地 VIP 会员商业化体系。部门管理模块为系统提供完整的部门树形层级管理能力，为用户管理提供部门归属信息，并为角色管理模块的数据权限控制提供组织基础数据。

> **三后端契约**：Java/Go/Python 三后端 API 契约完全一致，Java 为权威来源，Go/Python 对齐。

### 1.2 核心价值

| 价值维度 | 具体内容 |
|---------|---------|
| **组织管理** | 提供企业组织架构的统一管理入口，实现部门全生命周期管理 |
| **层级结构** | 支持多层级树形部门结构，适应不同企业组织形态 |
| **数据支撑** | 为用户管理和角色数据权限提供组织基础数据 |
| **灵活配置** | 支持部门排序、状态控制等灵活配置选项 |
| **高效管理** | 提供直观的树形管理界面，快速定位和操作部门 |

### 1.3 业务目标

#### 功能目标

- 实现系统部门的统一管理（CRUD 操作，逻辑删除）
- 支持多层级树形部门结构管理（最多 5 级深度）
- 为用户管理提供部门归属信息，为角色数据权限提供组织基础
- 保障组织架构数据的完整性与稳定性（根部门保护、循环引用检测）

#### 性能目标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| **树形列表查询响应** | &lt;500ms | 部门树形结构查询响应时间 |
| **表单提交响应** | &lt;1s | 新增/编辑部门操作响应时间 |
| **部门容量** | ≥1000 | 系统支持的最大部门数量 |
| **下拉选项查询响应** | &lt;300ms | 部门下拉选项（树形）查询响应时间 |

## 2. 用户角色分析

### 2.1 主要用户角色

| 角色 | 描述 | 主要职责 |
|------|------|---------|
| **系统管理员** | 拥有部门管理模块的所有操作权限 | 部门增删改查、状态管理、排序设置 |
| **部门管理员** | 拥有对部门及其下级部门的有限管理权限 | 查看部门、新增下级部门、编辑本部门及下级部门、管理状态和排序 |

### 2.2 权限矩阵

| 功能点 | 系统管理员 | 部门管理员 | 普通用户 |
|--------|-----------|-----------|---------|
| 查看所有部门 | ✅ | ❌ | ❌ |
| 查看本部门及下级部门 | ✅ | ✅ | ❌ |
| 新增部门 | ✅ | ✅ (仅下级部门) | ❌ |
| 编辑部门 | ✅ | ✅ (本部门及下级部门) | ❌ |
| 删除部门 | ✅ | ❌ | ❌ |
| 状态管理 | ✅ | ✅ (本部门及下级部门) | ❌ |
| 排序设置 | ✅ | ✅ (本部门及下级部门) | ❌ |
| 查看部门下拉选项 | ✅ | ✅ (本部门及下级部门) | ❌ |

> **说明**：删除部门权限仅限系统管理员，确保组织架构稳定性。部门管理员仅可操作本部门及下级部门范围内的数据。

### 2.3 根部门保护规则

| 规则 | 说明 |
|------|------|
| 不可删除 | 系统内置根部门（id=1）不可删除，返回 `A0234` 错误 |
| 不可修改上级 | 根部门不可修改 parentId，防止破坏树形结构根节点 |

## 3. 功能需求

### 3.1 部门列表查询 (F-DM-001)

#### 3.1.1 功能描述

提供部门信息的树形展示和多条件筛选能力，支持管理员快速定位目标部门。

#### 3.1.2 查询条件

| 条件类型 | 字段 | 说明 | 匹配方式 |
|---------|------|------|---------|
| **部门名称** | keywords | 部门名称关键字 | LIKE |
| **状态** | status | 部门状态 | = (启用/禁用) |

> **默认过滤**：部门列表默认仅展示未删除部门（`deleted = 0`）；部门管理员仅返回本部门及下级部门。

#### 3.1.3 列表展示字段

| 字段 | 显示名称 | 宽度 | 说明 |
|------|---------|------|------|
| name | 部门名称 | 自动 | 树形结构展示，支持展开/收起 |
| status | 状态 | 100px | 启用/禁用标签 |
| sort | 排序 | 100px | 部门显示顺序 |
| createTime | 创建时间 | 180px | 部门创建时间 |
| - | 操作 | 220px | 新增下级/编辑/删除 |

#### 3.1.4 业务规则

1. 部门列表以树形结构展示，支持多级层级
2. 树形结构支持最多 5 级深度
3. 支持节点的展开和收起操作
4. 已逻辑删除的部门不在列表展示

### 3.2 部门新增 (F-DM-002)

#### 3.2.1 功能描述

支持创建新部门，包括基本信息设置、上级部门分配和排序设置。

#### 3.2.2 表单字段

| 字段 | 显示名称 | 类型 | 必填 | 默认值 | 校验规则 |
|------|---------|------|------|--------|---------|
| parentId | 上级部门 | 树形选择器 | ✅ | - | 不能为空 |
| name | 部门名称 | 输入框 | ✅ | - | 不能为空，同一层级下唯一 |
| sort | 排序 | 数字输入框 | ✅ | 1 | 必须为正整数 |
| status | 状态 | 单选框组 | ✅ | 启用(1) | 不能为空 |

#### 3.2.3 业务规则

1. **部门名称唯一性**：同一 parentId 下部门名称必须唯一（含已删除记录校验）
2. **上级部门**：必须选择一个上级部门（根部门除外）
3. **排序默认值**：新部门排序默认为 1
4. **状态默认值**：新部门默认为启用状态
5. **层级深度限制**：新增后部门层级不超过 5 级
6. **快速新增**：支持在现有部门下快速新增下级部门
7. **权限控制**：系统管理员可在任意部门下新增子部门；部门管理员仅可在本部门及下级部门下新增子部门

### 3.3 部门编辑 (F-DM-003)

#### 3.3.1 功能描述

支持修改现有部门的基本信息、上级部门和状态。

#### 3.3.2 可编辑字段

| 字段 | 是否可编辑 | 说明 |
|------|-----------|------|
| name | ✅ | 可随时修改（需检查唯一性） |
| parentId | ✅ | 支持部门层级调整 |
| sort | ✅ | 可修改排序值 |
| status | ✅ | 可启用/禁用 |

#### 3.3.3 业务规则

1. **部门名称**：修改时需检查同一层级下名称是否唯一（排除自身）
2. **上级部门**：不能选择自身或其子部门作为上级部门，防止循环引用
3. **即时生效**：修改保存后立即生效，并刷新部门缓存
4. **根部门保护**：系统内置根部门（id=1）不可修改 parentId
5. **层级深度限制**：移动部门后层级不超过 5 级
6. **权限控制**：系统管理员可编辑所有部门；部门管理员仅可编辑本部门及下级部门

### 3.4 部门删除 (F-DM-004)

#### 3.4.1 功能描述

支持删除部门，包括单个删除。

#### 3.4.2 删除方式

| 方式 | 触发操作 | 说明 |
|------|---------|------|
| **单个删除** | 点击操作列删除按钮 | 删除单个部门 |

#### 3.4.3 业务规则

1. **二次确认**：删除操作需弹窗确认
2. **关联用户检查**：删除前需检查部门下是否存在关联用户，存在则禁止删除
3. **子部门检查**：删除前需检查是否存在子部门，存在子部门则禁止删除（不级联删除，需先删除子部门）
4. **根部门保护**：系统内置根部门（id=1）不可删除，返回 `A0234`
5. **逻辑删除**：执行逻辑删除（标记 `deleted = 1`），数据保留可追溯，不物理删除
6. **权限控制**：仅系统管理员可删除部门

#### 3.4.4 确认提示

- 存在关联用户：`该部门下存在用户，无法删除。`
- 存在子部门：`该部门下存在子部门，请先删除子部门。`
- 无关联数据：`确认删除部门「{deptName}」吗？`

### 3.5 新增下级部门 (F-DM-005)

#### 3.5.1 功能描述

支持在当前部门下快速新增子部门。

#### 3.5.2 操作流程

点击新增下级按钮 → 打开部门表单弹窗 → 上级部门自动填充当前部门 → 用户填写信息 → 提交保存

#### 3.5.3 业务规则

1. **上级部门预设**：表单中的上级部门自动设置为当前选中部门
2. **层级限制**：当前部门已达 5 级时，新增下级按钮禁用
3. **规则继承**：其他业务规则与普通新增部门一致

### 3.6 部门状态管理 (F-DM-006)

#### 3.6.1 功能描述

支持启用或禁用部门，控制部门的可用状态。

#### 3.6.2 状态说明

| 状态值 | 显示 | 说明 |
|--------|------|------|
| 1 | 启用（绿色标签） | 部门正常使用 |
| 0 | 禁用（灰色标签） | 部门暂停使用 |

#### 3.6.3 业务规则

1. **状态切换**：可通过编辑表单或状态开关切换状态
2. **即时生效**：状态变更后立即生效，并刷新部门缓存
3. **不级联子部门**：禁用部门**不级联禁用**子部门，子部门保持各自独立状态
4. **不影响用户登录**：禁用部门**不影响**该部门下用户的登录（用户登录由用户账户状态控制，与部门状态独立）
5. **下拉选项过滤**：禁用状态的部门在"仅启用"模式下的部门下拉选项中不展示
6. **权限控制**：系统管理员可管理所有部门状态；部门管理员仅可管理本部门及下级部门的状态

### 3.7 部门排序设置 (F-DM-007)

#### 3.7.1 功能描述

支持设置部门的显示顺序，控制部门树中的排列顺序。

#### 3.7.2 排序规则

1. **排序字段**：整数类型
2. **排序依据**：按 sort 字段升序排列
3. **同级排序**：同一层级下按 sort 值排序
4. **默认值**：新增部门默认排序为 1

#### 3.7.3 业务规则

1. **实时生效**：排序修改后立即生效
2. **灵活调整**：支持任意排序值调整
3. **自动排序**：同部门下按 sort 值自动排序
4. **权限控制**：系统管理员可设置所有部门的排序；部门管理员仅可设置本部门及下级部门的排序

### 3.8 部门下拉选项 (F-DM-008)

#### 3.8.1 功能描述

提供部门树形下拉选项，供用户管理等模块使用。

#### 3.8.2 数据格式

| 字段 | 说明 |
|------|------|
| value | 部门 ID |
| label | 部门名称 |
| children | 子部门数组（递归） |

#### 3.8.3 使用场景

1. 用户新增/编辑时选择所属部门
2. 角色数据权限配置时选择数据范围
3. 其他需要按部门筛选的场景

#### 3.8.4 业务规则

1. **树形结构**：返回完整的部门树形结构
2. **状态过滤**：可配置是否仅返回启用状态的部门
3. **权限过滤**：根据用户数据权限过滤可访问的部门（部门管理员仅返回本部门及下级部门）
4. **删除过滤**：已逻辑删除的部门不返回

## 5. 安全设计

> **权限标识**：详见 [API接口.md - 权限标识汇总](./API接口.md)

### 5.1 权限控制

| 规则 | 说明 |
|------|------|
| **新增/编辑部门** | 需 `sys:dept:add`/`sys:dept:edit` 权限 |
| **删除部门** | 仅系统管理员可操作，需 `sys:dept:delete` 权限 |
| **部门管理员权限边界** | 部门管理员仅可操作本部门及下级部门范围内的数据，不可删除部门 |
| **根部门保护** | 根部门（id=1）不可删除、不可修改 parentId，返回 `A0234` |
| **数据权限过滤** | 查询/选项接口根据用户数据权限自动过滤可访问的部门范围 |
| **接口鉴权** | 所有部门管理接口后端依据接口权限标识（`sys:dept:*`）鉴权 |

### 5.2 数据安全

| 安全措施 | 说明 |
|---------|---------|
| **权限验证** | 基于 RBAC 模型实现细粒度权限控制 |
| **数据权限** | 通过数据权限范围控制用户可访问的部门数据 |
| **传输加密** | HTTPS 加密传输 |
| **防重复提交** | 使用 Token 机制防止重复提交 |
| **操作日志** | 记录关键操作日志 |

### 5.3 输入校验

| 校验类型 | 说明 |
|---------|---------|
| **前端校验** | 表单实时校验，提升用户体验 |
| **后端校验** | 服务端进行参数校验 + 业务校验（名称唯一性、上级部门合法性、循环引用检测） |
| **唯一性校验** | 同一层级下部门名称唯一性校验（含已删除记录） |

## 6. 多端需求

| 端 | 部门管理入口 | 说明 |
|----|-------------|------|
| **Web Vue/React** | 后台管理页面 | 完整部门管理功能 |

## 8. 待确认事项

### 8.1 已定论事项

| 事项 | 定论 |
|------|------|
| **删除策略** | 逻辑删除（deleted=1），数据保留可追溯；存在关联用户或子部门时禁止删除 |
| **级联删除** | 不级联删除子部门，需先删除子部门方可删除父部门 |
| **状态级联影响** | 禁用部门不级联禁用子部门；不影响用户登录（用户登录由账户状态控制） |
| **根部门保护** | 根部门（id=1）不可删除、不可修改 parentId，返回 `A0234` |
| **层级深度** | 部门树最大 5 级 |
| **导入导出** | 由通用导入导出框架统一实现，树形导出为扁平结构 |

1. **部门负责人**：增加部门负责人字段及相关管理功能（远期规划）

3. **部门描述**：增加部门描述字段（远期规划）
4. **部门复制功能**：支持部门复制以便快速创建相似部门结构（远期规划）
5. **拖拽排序**：支持部门树拖拽排序（远期规划）
6. **虚拟部门**：支持创建虚拟部门用于组织架构展示（远期规划）
