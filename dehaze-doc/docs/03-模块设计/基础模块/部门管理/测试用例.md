## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **部门数据** | 至少5级部门树结构（根部门→3级→4级→5级） | 用于层级限制、树形结构测试 |
| **部门数据** | 同一层级下多个部门 | 用于名称唯一性测试 |
| **用户数据** | 关联到不同部门的用户账户 | 用于关联用户检查测试 |
| **角色数据** | 系统管理员、部门管理员角色 | 用于权限验证测试 |

### 3.2 数据清理策略

- 测试部门数据使用统一前缀 `test_dept_` 标识
- 测试结束后按前缀批量删除测试部门
- 保留系统默认根部门不做删除操作
- 测试后清理部门-用户关联表数据（测试用户）

### 3.3 测试范围

**包含的功能点：**
- 部门列表查询（树形结构、筛选）
- 部门新增、编辑、删除
- 新增下级部门
- 部门状态管理
- 部门排序设置
- 部门下拉选项

**不包含的功能点：**
- 用户管理功能（独立测试）
- 角色管理功能（独立测试）
- 权限验证中间件（系统架构层测试）

## 5. 关键边界与异常场景

| 场景 | 测试点 | 期望行为 |
|------|--------|---------|
| **部门数量边界** | 系统部门达到1000+ | 列表查询响应时间仍&lt;500ms |
| **层级限制** | 创建第6级部门 | 拒绝创建，提示"部门层级不能超过5级" |
| **循环引用** | 部门A→B→C，C的上级改为A | 拒绝修改，提示"循环引用" |
| **关联用户检查** | 删除有用户的部门 | 拒绝删除，提示"该部门下存在用户" |
| **根部门保护** | 删除或修改根部门上级 | 操作失败，提示"根部门不可删除/修改" |
| **并发新增** | 同时新增同级同名部门 | 只有一个成功，另一个提示名称已存在 |
| **并发编辑** | 同一部门被多人同时编辑 | 乐观锁保护，冲突时提示重新加载 |
| **缓存一致性** | 修改部门信息后查询 | 缓存立即更新，返回最新数据 |

## 8. 安全性测试

| 测试项 | 验证方式 | 预期结果 |
|--------|---------|---------|
| **权限控制** | 无权限用户调用新增/编辑/删除接口 | 返回403 |
| **数据权限** | 部门管理员访问其他部门数据 | 返回403或数据过滤 |
| **SQL注入** | 参数中包含 `admin'--` | 被参数化查询转义，无SQL注入风险 |
| **XSS攻击** | 部门名称注入 `&lt;script&gt;alert(1)&lt;/script&gt;` | 输出时编码，不执行脚本 |
| **传输安全** | 抓包分析请求 | HTTPS加密传输 |
| **防重复提交** | 快速连续点击提交 | Token机制防护，仅执行一次 |
| **权限绕过** | 修改部门ID为其他部门ID | 数据权限校验，拒绝越权操作 |
| **缓存安全** | 部门数据缓存是否可被篡改 | 缓存与数据库一致，无法绕过 |

## 9. 数据一致性测试

### 9.1 缓存一致性测试

| 场景 | 验证点 | 期望行为 |

### 11.2 事务回滚测试

| 场景 | 触发条件 | 验证点 |
|------|---------|--------|
| **数据库错误** | 模拟DB连接断开 | 操作回滚，数据不变 |

### 9.3 数据完整性测试

| 场景 | 验证点 | 期望行为 |
|------|--------|---------|
| **逻辑删除过滤** | 查询部门列表 | 不返回已删除部门 |
| **唯一性约束** | 检查同级部门名称重复 | 包含已删除记录的校验（根据规则） |
| **用户关联检查** | 删除部门前检查 | 有用户关联则禁止删除 |
