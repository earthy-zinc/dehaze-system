# 文件管理模块测试用例

## 1. 测试目标

验证文件管理模块的核心功能符合 [需求规格.md](./需求规格.md) 定义：

- **文件上传**：通用上传、MD5 去重（秒传）、分片上传与断点续传（F-FM-001）
- **文件下载**：签名 URL 机制、流式传输（F-FM-002）
- **文件删除**：最终一致性、孤儿文件清理（F-FM-003）
- **MD5 校验**：物理文件去重检查（F-FM-004）
- **文件查询**：分页查询、详情查询（F-FM-005/F-FM-006）
- **场景覆盖**：正常流程、边界条件、异常分支、权限控制
- **非功能验证**：并发场景（并发上传/删除）、存储策略（MinIO/本地）、性能指标、安全性（恶意文件检测、路径遍历防护、签名 URL 安全）

## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **测试文件** | 不同大小、类型的文件 | 用于上传测试 |
| **重复文件** | MD5 相同的文件 | 用于去重测试 |
| **大文件** | 接近上限的文件（如 90MB、490MB 模型文件） | 用于边界与分片上传测试 |
| **超限文件** | 超过上限的文件（如 110MB 图像、510MB 模型） | 用于异常测试 |

### 3.2 数据清理策略

- 测试上传的文件使用统一前缀标识
- 测试结束后清理测试创建的文件元数据（物理文件由对账任务异步清理）
- MinIO 测试桶与生产桶隔离

### 3.3 测试范围

**包含的功能点**：§1 列出的全部功能点，覆盖正常流程、边界条件、异常分支与并发场景。

**不包含的功能点：**
- 业务模块的文件权限控制（各业务模块独立测试）
- WPX 格式转换（不在本模块范围）
