## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **测试文件** | 不同大小、类型的文件 | 用于上传测试 |
| **重复文件** | MD5 相同的文件 | 用于去重测试 |
| **大文件** | 接近上限的文件（如 90MB、490MB 模型文件） | 用于边界与分片上传测试 |
| **超限文件** | 超过上限的文件（如 110MB 图像、510MB 模型） | 用于异常测试 |

### 3.2 数据清理策略

- 测试上传的文件使用统一前缀标识
- 测试结束后清理测试创建的文件元数据（物理文件由对账任务异步清理）
- MinIO 测试桶与生产桶隔离

### 3.3 测试范围

**包含的功能点：**
- 文件上传（含 MD5 去重、分片上传/断点续传、按业务类型差异化大小限制、后端 MD5 二次校验）
- 文件下载（含签名 URL 安全机制）
- 文件删除（最终一致性：元数据标记删除 + 物理文件对账清理）
- MD5 校验
- 文件分页查询
- 文件详情查询

**不包含的功能点：**
- 业务模块的文件权限控制（各业务模块独立测试）
- WPX 格式转换（可选扩展功能，当前未实现）

## 8. 安全性测试

| 测试项 | 验证方式 | 预期结果 |
|--------|---------|---------|
| **路径遍历防护** | objectName 包含 `../` | 请求被拒绝 |
| **文件名注入** | 文件名包含特殊字符 | 正确处理，无安全风险 |
| **MIME 类型校验** | 伪装文件类型 | 按实际内容判断（若配置） |
| **文件大小校验** | 超大文件上传（按业务类型） | 上传被拒绝 |
| **签名 URL 防篡改** | 篡改签名 URL | 签名校验失败，下载被拒绝 |
| **签名 URL 时效** | 使用过期签名 URL | 下载被拒绝 |
| **签名 URL 归属校验** | 越权使用他人签名 URL | 归属校验失败，下载被拒绝 |
| **后端 MD5 二次校验** | 上传内容与 md5 不符 | 校验失败，拒绝创建元数据 |
| **访问控制** | 未登录访问接口 | 返回 401 |
