# 文件管理模块 API 接口

## 1. 文档概述

本文档定义 **文件管理** 模块的 HTTP API 规范，是该模块 API 契约的**唯一权威来源**。

- **基础路径**：`/api/v1/files`
- **公共约定**：参见 [02-系统架构/04-API规范.md](../../../02-系统架构/04-API规范.md)
- **需求规格**：[需求规格.md](./需求规格.md)

> **重要**：
> - 文件管理模块是基础能力模块，**不提供独立的前端界面**，主要为其他业务模块提供 API 服务。
> - 接口详细参数/响应结构可通过 API 文档 MCP 查询。

## 2. 接口清单

| 路径 | 方法 | 功能描述 | 权限标识 | 关联功能点 |
|------|------|---------|---------|-----------|
| `/api/v1/files` | POST | 文件上传 | `file:upload` | F-FM-001 |
| `/api/v1/files/download/{objectName}` | GET | 文件下载 | - | F-FM-002 |
| `/api/v1/files/{fileId}` | DELETE | 文件删除 | `file:delete` | F-FM-003 |
| `/api/v1/files/check` | GET | MD5 校验（秒传预检） | - | F-FM-004 |
| `/api/v1/files/page` | GET | 文件分页查询 | - | F-FM-005 |
| `/api/v1/files/{fileId}` | GET | 文件详情查询 | - | F-FM-006 |

## 3. 权限标识汇总

| 权限标识 | 说明 |
|---------|------|
| `file:upload` | 文件上传 |
| `file:delete` | 文件删除 |
| - | 其他接口登录用户即可访问 |

> **响应字段**：文件上传、MD5 校验、详情、分页等返回的文件信息均含 `size`（字符串格式）与 `sizeBytes`（字节整数）字段；`GET /files/check` 的 `md5` 参数须为 32 位十六进制，否则返回 `B0404`。

## 4. 业务错误码

| 错误码 | 说明 | 触发场景 |
|--------|------|---------|
| `B0401` | 文件不存在 | 下载/删除/查询不存在的文件 |
| `B0402` | 文件过大 | 上传文件超过大小限制（默认 100MB） |
| `B0403` | 文件类型不支持 | 上传不允许的文件类型（由业务模块配置） |
| `B0404` | MD5 格式无效 | MD5 校验接口参数格式错误 |
| `B0405` | 文件存储失败 | 对象存储服务异常 |
| `B0406` | 文件已损坏 | 文件元数据存在但物理文件丢失 |
