# 文件管理模块需求规格

## 1. 模块概述

### 1.1 模块定位

文件管理模块是图像去雾系统的基础能力模块之一，负责提供通用的文件上传、下载、删除、查询和去重等基础功能。该模块为系统提供统一的文件存储服务，作为数据集图片管理、算法模型文件管理等业务模块的底层支撑，不直接面向终端用户，而是为其他业务模块提供文件操作能力。

### 1.2 核心价值

| 价值维度       | 具体内容                                                       |
| -------------- | -------------------------------------------------------------- |
| **统一存储**   | 提供统一的文件存储抽象层，支持 MinIO/本地存储等多种存储后端    |
| **MD5 去重**   | 基于 MD5 指纹实现文件去重，避免重复存储相同内容的文件          |
| **通用能力**   | 为业务模块提供标准化的文件上传、下载、删除接口                 |
| **元数据管理** | 集中管理文件元数据（大小、类型、路径、MD5 等），便于查询和统计 |
| **性能优化**   | 通过去重机制和对象存储支持，提升文件传输和存储效率             |

### 1.3 业务目标

#### 功能目标

- 实现通用的文件上传功能，支持文件元数据记录
- 提供文件下载能力，支持流式传输
- 实现文件删除功能，支持元数据和物理文件同步删除
- 提供 MD5 校验接口，实现文件去重机制
- 支持文件分页查询和多条件筛选
- 提供 WPX 格式转换能力（可选扩展）

#### 性能目标

| 指标             | 目标值 | 说明                                    |
| ---------------- | ------ | --------------------------------------- |
| **上传响应时间** | &lt;3s    | 单个文件上传接口响应时间（含 MD5 计算） |
| **下载响应时间** | &lt;500ms | 文件下载请求响应时间（不含传输时间）    |
| **查询响应时间** | &lt;300ms | 文件分页查询响应时间                    |
| **去重校验时间** | &lt;100ms | MD5 校验接口响应时间                    |
| **并发上传数**   | ≥50    | 支持的最大并发上传请求数                |

## 2. 用户角色分析

### 2.1 主要用户角色

| 角色           | 描述                           | 主要职责                                     |
| -------------- | ------------------------------ | -------------------------------------------- |
| **系统管理员** | 拥有文件管理模块的所有操作权限 | 上传、下载、删除文件，查询所有文件记录       |
| **业务模块**   | 其他业务模块（数据集、算法等） | 调用文件管理接口完成业务文件操作             |
| **普通用户**   | 通过业务模块间接使用文件管理   | 上传数据集图片、下载模型文件等（业务场景中） |

### 2.2 权限矩阵

| 功能点           | 系统管理员 | 业务模块 | 普通用户           |
| ---------------- | ---------- | -------- | ------------------ |
| 文件上传         | ✅         | ✅       | ✅（通过业务模块） |
| 文件下载         | ✅         | ✅       | ✅（通过业务模块） |
| 文件删除         | ✅         | ✅       | ❌                 |
| 文件查询（列表） | ✅         | ✅       | ❌                 |
| 文件详情查询     | ✅         | ✅       | ✅（有权限的文件） |
| MD5 校验         | ✅         | ✅       | ✅                 |

> **说明**：文件管理模块主要面向业务模块和系统管理员提供 API 服务，普通用户通过业务模块间接使用文件管理功能，不直接操作文件管理模块接口。

## 3. 功能需求

### 3.1 文件上传 (F-FM-001)

#### 3.1.1 功能描述

支持通用文件上传功能，将文件存储到对象存储（MinIO/本地存储），并记录文件元数据到数据库。支持 MD5 去重，相同内容的文件只存储一次。

#### 3.1.2 请求参数

| 参数名  | 类型          | 必填 | 说明                             |
| ------- | ------------- | ---- | -------------------------------- |
| file    | MultipartFile | ✅   | 上传的文件对象                   |
| modelId | Long          | ❌   | 模型 ID，可选参数，用于 WPX 处理 |

#### 3.1.3 响应数据

| 字段       | 类型          | 说明                                |
| ---------- | ------------- | ----------------------------------- |
| id         | Long          | 文件 ID                             |
| name       | String        | 文件原始名称                        |
| type       | String        | 文件类型（扩展名）                  |
| size       | String        | 文件大小（格式化显示，如 "2.44MB"） |
| sizeBytes  | Long          | 文件大小（原始字节数）              |
| url        | String        | 文件访问 URL                        |
| path       | String        | 文件存储路径                        |
| objectName | String        | 文件存储对象名                      |
| md5        | String        | 文件 MD5 值                         |
| createTime | LocalDateTime | 创建时间                            |

#### 3.1.4 业务规则

1. **MD5 去重**：上传文件时计算 MD5 值，如果已存在相同 MD5 的文件，则直接返回已存在的文件记录，不重复存储物理文件
2. **存储路径规则**：默认存储路径为 `upload/{yyyyMMdd}/`，按日期分层存储
3. **文件类型限制**：支持的文件类型由业务模块控制，文件管理模块本身不做限制
4. **文件大小限制**：默认最大文件大小 100MB（可配置）
5. **WPX 处理**：当提供 `modelId` 参数时，系统会对上传的文件进行 WPX 格式转换处理，返回处理后的文件信息
6. **元数据记录**：无论是否去重，都会在数据库中记录文件元数据（包括文件名、大小、路径、MD5 等）

#### 3.1.5 上传流程

```
用户选择文件 → 前端调用上传接口 → 后端接收文件 → 计算 MD5 值
→ 校验 MD5 是否已存在 → 已存在：返回旧文件记录
                    → 不存在：存储到对象存储 → 写入数据库 → 返回新文件记录
```

### 3.2 文件下载 (F-FM-002)

#### 3.2.1 功能描述

支持通过文件路径下载文件，采用流式传输方式，支持大文件下载。

#### 3.2.2 请求方式

| 方式         | 说明                                      |
| ------------ | ----------------------------------------- |
| **URL 模式** | GET `/api/v1/files/download/{objectName}` |
| **请求头**   | 无特殊要求                                |

#### 3.2.3 响应方式

| 字段                | 说明                                                |
| ------------------- | --------------------------------------------------- |
| Content-Type        | 根据文件类型自动设置                                |
| Content-Disposition | `attachment; filename="{filename}"`，触发浏览器下载 |
| 响应体              | 文件二进制流                                        |

#### 3.2.4 业务规则

1. **流式传输**：使用 `InputStreamResource` 实现流式传输，避免内存溢出
2. **文件名编码**：响应头中的文件名需进行 URL 编码，防止中文乱码
3. **路径安全**：根据 `objectName` 从对象存储读取文件，防止路径遍历攻击
4. **访问控制**：业务模块需自行控制文件下载权限，文件管理模块不鉴权

### 3.3 文件删除 (F-FM-003)

#### 3.3.1 功能描述

支持删除文件，包括物理文件和元数据的同步删除。

#### 3.3.2 请求参数

| 参数名 | 类型 | 必填 | 说明    |
| ------ | ---- | ---- | ------- |
| fileId | Long | ✅   | 文件 ID |

#### 3.3.3 业务规则

1. **删除顺序**：先删除数据库元数据，再删除对象存储中的物理文件
2. **关联检查**：删除前需检查文件是否被其他业务数据引用（由调用方控制）
3. **删除失败处理**：如果物理文件删除失败，建议记录日志并标记数据库记录（由调用方决定是否回滚）
4. **批量删除**：业务模块需要批量删除时，应循环调用删除接口

#### 3.3.4 删除确认

- 调用方（业务模块）在删除文件前应弹窗确认
- 确认文案："确认删除该文件吗？删除后不可恢复。"

### 3.4 文件校验（MD5 去重检查） (F-FM-004)

#### 3.4.1 功能描述

提供文件 MD5 校验接口，用于在上传前检查文件是否已存在，实现秒传功能。若文件已存在则返回完整文件信息，前端可直接复用已有文件 ID，无需重复上传。

#### 3.4.2 请求参数

| 参数名 | 类型   | 必填 | 说明                               |
| ------ | ------ | ---- | ---------------------------------- |
| md5    | String | ✅   | 文件 MD5 值（32 位十六进制字符串） |

#### 3.4.3 响应数据

| 字段 | 类型     | 说明                                         |
| ---- | -------- | -------------------------------------------- |
| data | FileInfo | 文件已存在时返回完整文件信息；不存在时为 null |

> 返回完整文件信息（而非简单的 Boolean）使前端可直接获取文件 ID 和 URL，实现秒传。

#### 3.4.4 业务规则

1. **MD5 格式校验**：校验 MD5 是否为有效的 32 位十六进制字符串
2. **秒传场景**：前端可在上传前先调用该接口，如果文件已存在，直接跳过上传
3. **性能优化**：该接口仅查询数据库，性能应 &lt;100ms

### 3.5 文件分页查询 (F-FM-005)

#### 3.5.1 功能描述

提供文件列表的分页查询能力，支持关键字搜索，便于系统管理员查看和管理已上传的文件。

#### 3.5.2 请求参数

| 参数名   | 类型    | 必填 | 说明                                   |
| -------- | ------- | ---- | -------------------------------------- |
| pageNum  | Integer | ❌   | 页码，默认 1                           |
| pageSize | Integer | ❌   | 每页数量，默认 10                      |
| keywords | String  | ❌   | 关键字，支持按文件名或文件类型模糊匹配 |

#### 3.5.3 列表展示字段

| 字段       | 显示名称 | 说明                    |
| ---------- | -------- | ----------------------- |
| id         | 编号     | 文件唯一标识            |
| name       | 文件名   | 原始文件名              |
| type       | 文件类型 | 文件扩展名              |
| size       | 文件大小 | 格化显示（如 "2.44MB"） |
| path       | 存储路径 | 文件在对象存储中的路径  |
| md5        | MD5 值   | 文件 MD5 指纹           |
| createTime | 创建时间 | 上传时间                |

#### 3.5.4 分页配置

| 配置项   | 默认值 | 可选值       |
| -------- | ------ | ------------ |
| 每页条数 | 10     | 10/20/50/100 |

#### 3.5.5 业务规则

1. **关键字匹配**：支持按文件名（`name`）或文件类型（`type`）进行模糊匹配
2. **排序规则**：默认按创建时间倒序排列（最新上传的在前）
3. **数据权限**：系统管理员可查看所有文件，其他角色由调用方控制权限

### 3.6 文件详情查询 (F-FM-006)

#### 3.6.1 功能描述

根据文件 ID 获取文件完整元数据信息。

#### 3.6.2 请求参数

| 参数名 | 类型 | 必填 | 说明    |
| ------ | ---- | ---- | ------- |
| fileId | Long | ✅   | 文件 ID |

#### 3.6.3 响应数据

响应完整的 `SysFile` 对象，包含所有元数据字段（参见 3.1.3 响应数据）。

#### 3.6.4 业务规则

1. **文件不存在**：如果文件 ID 不存在，返回 404 错误
2. **访问控制**：业务模块需自行控制文件详情查询权限

## 4. 界面交互规范

### 4.1 使用场景说明

> 文件管理模块是基础能力模块，**不提供独立的前端界面**，以下交互规范供调用方（业务模块）参考。

### 4.2 交互流程示例

#### 4.2.1 标准上传流程

```
1. 前端：用户选择文件
2. 前端：调用 MD5 校验接口（F-FM-004），判断是否已存在
3. 前端：如果文件不存在，调用上传接口（F-FM-001）
4. 后端：存储文件，返回文件信息
5. 前端：展示上传结果，保存 fileId 到业务表
```

#### 4.2.2 秒传流程

是标准上传流程的特例

```
1. 前端：用户选择文件
2. 前端：计算本地文件 MD5
3. 前端：调用 MD5 校验接口（F-FM-004）
4. 后端：返回 true（文件已存在）
5. 前端：展示上传结果，保存 fileId 到业务表
```

#### 4.2.3 文件删除流程

```
1. 前端：点击删除按钮
2. 前端：弹窗确认
3. 前端：调用删除接口（F-FM-003）
4. 后端：删除数据库记录和物理文件
5. 前端：刷新列表，显示删除成功提示
```

### 4.3 错误处理

| 错误场景       | 提示文案                         | 处理方式       |
| -------------- | -------------------------------- | -------------- |
| 文件过大       | "文件大小超过限制（最大 100MB）" | 阻止上传       |
| 文件类型不支持 | "不支持的文件类型"               | 由业务模块控制 |
| MD5 校验失败   | "MD5 格式不正确"                 | 阻止上传       |
| 文件不存在     | "文件不存在或已被删除"           | 提示用户       |
| 删除失败       | "删除失败，请重试"               | 记录日志       |

## 5. 安全设计

### 5.1 数据安全

| 安全措施     | 说明                               |
| ------------ | ---------------------------------- |
| **MD5 去重** | 避免重复存储相同文件，节省存储空间 |
| **路径隔离** | 按日期分层存储，防止路径冲突       |
| **传输加密** | HTTPS 加密传输，防止中间人攻击     |
| **访问控制** | 业务模块控制文件访问权限           |
| **操作日志** | 记录关键操作日志（上传、删除）     |

### 5.2 输入校验

| 校验类型         | 说明                                |
| ---------------- | ----------------------------------- |
| **文件大小校验** | 限制最大文件大小 100MB              |
| **MD5 格式校验** | 校验 MD5 是否为 32 位十六进制字符串 |
| **文件名校验**   | 防止文件名包含特殊字符或路径遍历    |
| **参数校验**     | 使用 Validation 注解校验请求参数    |

### 5.3 存储安全

| 安全措施         | 说明                               |
| ---------------- | ---------------------------------- |
| **对象存储鉴权** | MinIO/OSS 配置访问密钥             |
| **路径规范化**   | 防止路径遍历攻击（如 `../`）       |
| **文件类型校验** | 基于文件扩展名和 MIME 类型双重校验 |

## 6. 依赖关系

### 6.1 依赖模块

| 模块             | 依赖说明                                 |
| ---------------- | ---------------------------------------- |
| **对象存储服务** | MinIO 或阿里云 OSS，用于文件物理存储     |
| **数据库服务**   | MySQL，用于存储文件元数据（sys_file 表） |
| **配置中心**     | 读取文件存储配置（baseUrl、存储类型等）  |

### 6.2 被依赖模块

| 模块                 | 依赖说明                           |
| -------------------- | ---------------------------------- |
| **数据集管理模块**   | 使用文件管理上传和管理数据集图片   |
| **算法模型模块**     | 使用文件管理上传和管理算法模型文件 |
| **图片去雾处理模块** | 使用文件管理存储原图和处理结果图   |
| **系统所有业务模块** | 依赖文件管理提供通用文件存储能力   |

### 6.3 数据库依赖

文件管理模块依赖 `sys_file` 表，数据库设计参见 [../../02-系统架构/03-数据库设计.md](../../../02-系统架构/03-数据库设计.md#426-文件表-sys_file)。

## 7. 待确认事项

1. **文件大小限制**：当前默认 100MB，是否需要根据文件类型（图片/模型/其他）设置不同的上限？
2. **删除关联检查**：文件删除时是否需要自动检查引用关系（如数据集项、算法模型等）？还是由业务模块控制？
3. **批量删除**：是否需要提供批量删除接口？
4. **文件预览**：是否需要提供图片预览接口（缩略图生成）？
5. **临时文件管理**：是否需要支持临时文件上传和自动清理机制？
6. **文件访问控制**：文件下载是否需要增加访问权限控制（如 Token 验证）？
7. **WPX 处理逻辑**：当前支持 WPX 格式转换，该功能的具体业务场景和实现细节待确认。
8. **文件类型白名单**：是否需要配置文件类型白名单，限制可上传的文件类型？
