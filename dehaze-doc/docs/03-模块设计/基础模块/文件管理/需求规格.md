# 文件管理模块需求规格

## 1. 模块概述

### 1.1 模块定位

文件管理模块是 **AI 图像处理平台**的 BFF 层基础服务模块，负责提供通用的文件上传、下载、删除、查询和去重等基础能力。该模块为系统提供统一的文件存储服务，作为数据集图片管理、算法模型文件管理、图像处理结果存储等业务模块的底层支撑。**文件管理为 BFF 层基础服务，不提供独立前端界面，由业务模块调用上传/下载接口**。

### 1.2 核心价值

| 价值维度 | 具体内容 |
|---------|---------|
| **统一存储** | 提供统一的文件存储抽象层，支持对象存储/本地存储等多种存储后端 |
| **物理去重** | 基于 MD5 指纹实现物理文件去重（MD5 相同复用同一物理文件），节省存储空间 |
| **元数据独立** | 每次上传创建独立文件元数据记录，多业务引用同一物理文件各自维护元数据 |
| **通用能力** | 为业务模块提供标准化的文件上传、下载、删除接口 |
| **多端适配** | 支持分片上传/断点续传，适配移动端/小程序弱网环境 |

### 1.3 业务目标

#### 功能目标

- 实现通用的文件上传功能，支持文件元数据记录（物理文件去重 + 元数据独立）
- 提供文件下载能力，支持签名 URL 与流式传输
- 实现文件删除功能，采用最终一致性（元数据先标记删除，物理文件由定时对账任务清理）
- 提供文件指纹校验接口，实现物理文件去重与秒传
- 支持文件分页查询和多条件筛选
- 支持分片上传与断点续传（≥50MB 启用）

#### 性能目标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| **上传响应时间** | &lt;3s | 单个文件上传接口响应时间（含 MD5 计算，≤10MB） |
| **下载响应时间** | &lt;500ms | 文件下载请求响应时间（不含传输时间） |
| **查询响应时间** | &lt;300ms | 文件分页查询响应时间 |
| **去重校验时间** | &lt;100ms | MD5 校验接口响应时间 |
| **并发上传数** | ≥50 | 支持的最大并发上传请求数 |

## 3. 功能需求

### 3.1 文件上传 (F-FM-001)

#### 3.1.1 功能描述

支持通用文件上传功能，将文件写入存储服务并记录文件元数据。采用**物理文件去重 + 元数据独立**策略：MD5 相同的文件复用同一物理文件，每次上传创建独立的文件元数据记录。

#### 3.1.2 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| file | 文件对象 | ✅ | 上传的文件（分片上传时为分片数据） |
| business_type | String | ❌ | 业务类型（image/model/等），用于区分文件大小上限 |
| md5 | String | ❌ | 前端预计算的 MD5（秒传场景：物理文件已存在时仅传 MD5 复用物理文件） |

#### 3.1.3 响应数据

| 字段 | 类型 | 说明 |
|------|------|------|
| id | 文件 ID | 本次上传创建的独立文件元数据记录 ID |
| name | 字符串 | 文件原始名称 |
| type | 字符串 | 文件类型（扩展名） |
| sizeBytes | 数值 | 文件大小（原始字节数，前端自行格式化显示） |
| url | 字符串 | 文件访问 URL（签名 URL，有时效） |
| objectName | 字符串 | 文件存储对象名 |
| md5 | 字符串 | 文件指纹值 |
| createTime | 日期时间 | 创建时间 |

> `size` 字段统一返回字节数（`sizeBytes`），格式化显示（如 "2.44MB"）由前端处理，后端不返回格式化字符串。

#### 3.1.4 业务规则

1. **物理文件去重**：上传时计算文件 MD5，若已存在相同 MD5 的物理文件，则复用该物理文件（同一 object_name），不重复存储物理文件
2. **元数据独立**：无论物理文件是否去重，每次上传都创建独立的文件元数据记录（独立 ID），关联同一物理文件；多业务引用同一物理文件各自维护元数据
3. **文件类型限制**：支持的文件类型由业务模块控制，文件管理模块本身不做白名单限制（仅做内容嗅探安全校验）
4. **文件大小限制（按类型）**：图像文件（business_type=image）默认上限 100MB，模型文件（business_type=model）上限 500MB，其他类型默认 100MB，可配置
5. **文件指纹一致性**：文件指纹由上传方计算，服务端需校验其与文件内容一致

#### 3.1.5 分片上传与断点续传

- **触发条件**：文件 ≥ 50MB 启用分片上传
- **分片策略**：前端按固定大小切片逐片上传，后端合并
- **断点续传**：支持已上传分片记录，中断后可从断点继续上传，适配移动端/小程序弱网
- **秒传**：MD5 校验物理文件已存在时，跳过文件流上传，仅创建元数据记录

### 3.2 文件下载 (F-FM-002)

#### 3.2.1 功能描述

支持下载文件，下载采用**签名 URL 机制**：生成有时效、含归属校验的下载链接，支持大文件下载。

#### 3.2.2 请求方式

| 方式 | 说明 |
|------|------|
| **签名 URL 下载** | 业务模块请求生成签名 URL（含时效与归属校验），前端用签名 URL 直接下载 |

#### 3.2.3 响应方式

响应为文件二进制流，按文件类型设置 Content-Type，并通过 Content-Disposition 携带文件名触发浏览器下载。

#### 3.2.4 业务规则

1. **签名 URL 时效**：下载链接有时效（默认 30 分钟，可配置），含签名校验，防止篡改
2. **归属校验**：签名 URL 生成时校验调用方对该文件的访问权限
3. **文件名编码**：下载文件名需正确编码，避免中文乱码
4. **路径安全**：防止路径遍历攻击

### 3.3 文件删除 (F-FM-003)

#### 3.3.1 功能描述

支持删除文件，采用**最终一致性**策略：元数据先标记删除（逻辑删除），物理文件由定时对账任务（每日）清理孤儿文件。元数据不物理删除。

#### 3.3.2 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| fileId | Long | ✅ | 文件 ID |

#### 3.3.3 业务规则

1. **最终一致性**：元数据先标记删除，物理文件由定时对账任务（每日）清理孤儿文件
2. **物理文件清理**：定时对账任务检查物理文件是否仍被未删除元数据引用，无引用时清理物理文件（适配物理文件去重场景：多元数据引用同一物理文件时，仅当所有引用均删除后才清理物理文件）
3. **关联检查**：删除前需检查文件是否被其他业务数据引用（由调用方/业务模块控制）
4. **逻辑删除**：元数据逻辑删除，数据保留可追溯

#### 3.3.4 删除确认

- 调用方（业务模块）在删除文件前应弹窗确认
- 确认文案："确认删除该文件吗？"

### 3.4 文件校验（MD5 去重检查） (F-FM-004)

#### 3.4.1 功能描述

提供文件 MD5 校验接口，用于在上传前检查物理文件是否已存在，实现秒传功能。若物理文件已存在，前端可跳过文件流上传，仅调用上传接口创建独立元数据记录。

#### 3.4.2 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| md5 | String | ✅ | 文件 MD5 值（32 位十六进制字符串） |

#### 3.4.3 响应数据

| 字段 | 类型 | 说明 |
|----|--------|------------|
| exists | Boolean | 物理文件是否已存在 |
| md5 | String | 文件 MD5 值 |

#### 3.4.4 业务规则

1. **MD5 格式校验**：校验 MD5 是否为有效的 32 位十六进制字符串
2. **秒传场景**：前端在上传前先调用该接口，物理文件已存在则跳过文件流上传，仅传 MD5 创建元数据

### 3.5 文件分页查询 (F-FM-005)

#### 3.5.1 功能描述

提供文件列表的分页查询能力，支持关键字搜索，便于系统管理员查看和管理已上传的文件。

#### 3.5.2 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| pageNum | Integer | ❌ | 页码，默认 1 |
| pageSize | Integer | ❌ | 每页数量，默认 10 |
| keywords | String | ❌ | 关键字，支持按文件名或文件类型模糊匹配 |

#### 3.5.3 列表展示字段

与 3.1.3 响应数据一致：编号、文件名、文件类型、文件大小（字节，前端格式化）、存储路径、文件指纹、创建时间。

#### 3.5.4 分页配置

| 配置项 | 默认值 | 可选值 |
|--------|--------|--------|
| 每页条数 | 10 | 10/20/50/100 |

#### 3.5.5 业务规则

1. **关键字匹配**：支持按文件名（`name`）或文件类型（`type`）进行模糊匹配
2. **排序规则**：默认按创建时间倒序排列（最新上传的在前）
3. **数据权限**：系统管理员可查看所有文件，其他角色由调用方控制权限

### 3.6 文件详情查询 (F-FM-006)

#### 3.6.1 功能描述

根据文件 ID 获取文件完整元数据信息。

#### 3.6.2 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| fileId | Long | ✅ | 文件 ID |

#### 3.6.3 响应数据

返回完整文件元数据，字段同 3.1.3 响应数据。

#### 3.6.4 业务规则

1. **文件不存在**：如果文件 ID 不存在，返回 404 错误
2. **访问控制**：业务模块需自行控制文件详情查询权限

## 4. 界面交互规范

### 4.1 使用场景说明

> 文件管理模块是 BFF 层基础服务，**不提供独立的前端界面**，以下交互规范供调用方（业务模块）参考。

### 4.2 交互流程示例

#### 4.2.1 标准上传流程

```
1. 前端：用户选择文件
2. 前端：流式计算文件 MD5
3. 前端：调用 MD5 校验接口（F-FM-004），判断物理文件是否已存在
4. 前端：物理文件不存在时调用上传接口（F-FM-001）上传文件流；≥50MB 启用分片上传
5. 后端：存储物理文件（或复用已存在物理文件），创建独立元数据记录
6. 前端：展示上传结果，保存 fileId 到业务表
```

#### 4.2.2 秒传流程

```
1. 前端：用户选择文件
2. 前端：流式计算本地文件 MD5
3. 前端：调用 MD5 校验接口（F-FM-004）
4. 后端：返回 exists=true（物理文件已存在）
5. 前端：调用上传接口仅传 MD5（跳过文件流上传）
6. 后端：复用物理文件，创建独立元数据记录
7. 前端：展示上传结果，保存 fileId 到业务表
```

#### 4.2.3 文件删除流程

```
1. 前端：点击删除按钮
2. 前端：弹窗确认
3. 前端：调用删除接口（F-FM-003）
4. 后端：元数据标记删除，物理文件由定时对账任务清理
5. 前端：刷新列表，显示删除成功提示
```

### 4.3 错误处理

| 错误场景 | 提示文案 | 处理方式 |
|---------|---------|---------|
| 文件过大 | "文件大小超过限制（图像最大 100MB，模型最大 500MB）" | 阻止上传 |
| 文件类型不支持 | "不支持的文件类型" | 由业务模块控制 |
| 文件指纹校验失败 | "文件指纹格式不正确" | 阻止上传 |
| 文件不存在 | "文件不存在或已被删除" | 提示用户 |
| 删除失败 | "删除失败，请重试" | 记录日志 |
| 签名 URL 过期 | "下载链接已过期，请重新获取" | 重新生成签名 URL |

### 4.4 页面布局（调用方参考）

| 区域 | 布局要点 |
|------|---------|
| 文件列表 | 支持网格/列表视图切换，网格展示缩略图与文件名，列表展示完整元数据；按创建时间倒序分页加载 |
| 上传区域 | 提供拖拽上传区与"选择文件"按钮，支持剪贴板粘贴上传；上传中展示进度条、已传大小与预估剩余时间 |
| 预览抽屉 | 点击文件打开侧边抽屉，展示图像预览与完整元数据（文件名/类型/大小/指纹/创建时间） |

### 4.5 上传交互反馈

| 场景 | 反馈行为 |
|------|---------|
| 上传中 | 展示进度条与已传大小，支持取消上传 |
| 上传完成 | 刷新列表，新文件置顶，提示"上传成功" |
| 秒传命中 | 直接展示文件信息，提示"文件已存在，已快速完成上传" |
| 分片上传中断 | 提示"上传已暂停"，提供"继续上传"按钮从断点恢复 |

## 5. 安全设计

### 5.1 数据安全

| 安全措施 | 说明 |
|---------|------|
| **路径隔离** | 文件存储路径相互隔离，防止冲突 |
| **传输加密** | 数据传输需加密，防止中间人攻击 |
| **操作日志** | 强制记录关键操作日志（上传、删除） |

### 5.2 输入校验

| 校验类型 | 说明 |
|---------|------|
| **文件名校验** | 防止文件名包含特殊字符或路径遍历 |
| **参数校验** | 服务端进行请求参数校验 |

### 5.3 存储安全

| 安全措施 | 说明 |
|---------|------|
| **存储服务鉴权** | 存储服务访问需鉴权 |
| **路径遍历防护** | 需防止路径遍历攻击（如 `../`） |
| **文件类型校验** | 需校验文件内容类型，防止恶意文件伪装 |
| **下载链接防篡改** | 下载链接需防篡改，防止越权下载 |

## 7. 待确认事项

1. **用户存储容量限制**：单用户的总存储容量是否需要限制（当前仅限制单文件大小，无用户总量上限）？
2. **文件保留期限**：文件元数据与物理文件是否需要设置过期清理策略（当前仅清理孤儿文件，无主动过期）？图像处理结果文件的保留期限与任务结果保留期（7 天）如何协同？
3. **文件类型白名单**：是否需要配置文件类型白名单限制可上传的文件类型？
4. **签名 URL 有效期**：下载链接有效期（当前 30 分钟）是否需要按文件类型或业务场景差异化？
5. **临时文件管理**：处理过程中的临时文件是否需要独立管理策略？
