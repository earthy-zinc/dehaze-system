# 文件管理模块需求规格

## 1. 模块概述

### 1.1 模块定位

文件管理模块是 **AI 图像处理平台**（远期演进为「AI 工作平台」）的 BFF 层基础服务模块，负责提供通用的文件上传、下载、删除、查询和去重等基础能力。该模块为系统提供统一的文件存储服务，作为数据集图片管理、算法模型文件管理、图像处理结果存储等业务模块的底层支撑。**文件管理为 BFF 层基础服务，不提供独立前端界面，由业务模块调用上传/下载接口**。

> **三后端契约**：Java/Go/Python 三后端 API 契约完全一致，Java 为权威来源，Go/Python 对齐。

### 1.2 核心价值

| 价值维度 | 具体内容 |
|---------|---------|
| **统一存储** | 提供统一的文件存储抽象层，支持对象存储（MinIO）/本地存储等多种存储后端 |
| **物理去重** | 基于 MD5 指纹实现物理文件去重（MD5 相同复用同一物理文件），节省存储空间 |
| **元数据独立** | 每次上传创建独立文件元数据记录，多业务引用同一物理文件各自维护元数据 |
| **通用能力** | 为业务模块提供标准化的文件上传、下载、删除接口 |
| **多端适配** | 支持分片上传/断点续传，适配移动端/小程序弱网环境 |

### 1.3 业务目标

#### 功能目标

- 实现通用的文件上传功能，支持文件元数据记录（物理文件去重 + 元数据独立）
- 提供文件下载能力，支持签名 URL 与流式传输
- 实现文件删除功能，采用最终一致性（元数据先标记删除，物理文件由定时对账任务清理）
- 提供文件指纹校验接口，实现物理文件去重与秒传
- 支持文件分页查询和多条件筛选
- 支持分片上传与断点续传（≥50MB 启用）

#### 性能目标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| **上传响应时间** | &lt;3s | 单个文件上传接口响应时间（含 MD5 计算，≤10MB） |
| **下载响应时间** | &lt;500ms | 文件下载请求响应时间（不含传输时间） |
| **查询响应时间** | &lt;300ms | 文件分页查询响应时间 |
| **去重校验时间** | &lt;100ms | MD5 校验接口响应时间 |
| **并发上传数** | ≥50 | 支持的最大并发上传请求数 |

## 3. 功能需求

### 3.1 文件上传 (F-FM-001)

#### 3.1.1 功能描述

支持通用文件上传功能，将文件存储到对象存储（MinIO/本地存储），并记录文件元数据到数据库。采用**物理文件去重 + 元数据独立**策略：MD5 相同的文件复用同一物理文件，每次上传创建独立的文件元数据记录。

#### 3.1.2 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| file | 文件对象 | ✅ | 上传的文件（分片上传时为分片数据） |
| business_type | String | ❌ | 业务类型（image/model/等），用于区分文件大小上限 |
| md5 | String | ❌ | 前端预计算的 MD5（秒传场景：物理文件已存在时仅传 MD5 复用物理文件） |

> `modelId` 参数为远期规划（WPX 格式转换），当前未实现，不在核心上传流程中。

#### 3.1.3 响应数据

| 字段 | 类型 | 说明 |
|------|------|------|
| id | 文件 ID | 本次上传创建的独立文件元数据记录 ID |
| name | 字符串 | 文件原始名称 |
| type | 字符串 | 文件类型（扩展名） |
| sizeBytes | 数值 | 文件大小（原始字节数，前端自行格式化显示） |
| url | 字符串 | 文件访问 URL（签名 URL，有时效） |
| objectName | 字符串 | 文件存储对象名 |
| md5 | 字符串 | 文件指纹值 |
| createTime | 日期时间 | 创建时间 |

> `size` 字段统一返回字节数（`sizeBytes`），格式化显示（如 "2.44MB"）由前端处理，后端不返回格式化字符串。

#### 3.1.4 业务规则

1. **物理文件去重**：上传时计算文件 MD5，若已存在相同 MD5 的物理文件，则复用该物理文件（同一 object_name），不重复存储物理文件
2. **元数据独立**：无论物理文件是否去重，每次上传都创建独立的文件元数据记录（独立 ID），关联同一物理文件；多业务引用同一物理文件各自维护元数据
3. **存储路径规则**：默认存储路径为按日期分层存储（`upload/{yyyyMMdd}/{md5}.{ext}`）
4. **文件类型限制**：支持的文件类型由业务模块控制，文件管理模块本身不做白名单限制（仅做内容嗅探安全校验）
5. **文件大小限制（按类型）**：图像文件（business_type=image）默认上限 100MB，模型文件（business_type=model）上限 500MB，其他类型默认 100MB，可配置
6. **MD5 多端计算**：前端计算 MD5；移动端/小程序采用流式分片计算 MD5；后端对上传文件二次校验 MD5 一致性
7. **元数据记录**：每次上传都记录文件元数据（文件名、大小、路径、MD5、business_type 等）

#### 3.1.5 上传流程

```
前端计算 MD5（流式分片计算）→ 调用 MD5 校验接口判断物理文件是否已存在
  → 物理文件已存在：上传请求仅传 MD5 + 元数据（复用物理文件，后端创建新元数据记录）
  → 物理文件不存在：
      → 文件 < 50MB：直接上传文件流 → 后端存储物理文件 + 创建元数据
      → 文件 ≥ 50MB：分片上传（支持断点续传）→ 后端合并存储物理文件 + 创建元数据
后端二次校验 MD5 一致性 → 返回新文件元数据记录
```

#### 3.1.6 分片上传与断点续传

- **触发条件**：文件 ≥ 50MB 启用分片上传
- **分片策略**：按固定大小切片（默认 5MB/片），前端分片上传，后端合并
- **断点续传**：支持已上传分片记录，中断后可从断点继续上传，适配移动端/小程序弱网
- **秒传**：MD5 校验物理文件已存在时，跳过文件流上传，仅创建元数据记录

### 3.2 文件下载 (F-FM-002)

#### 3.2.1 功能描述

支持通过文件标识或 objectName 下载文件，采用流式传输方式，支持大文件下载。下载采用**签名 URL 机制**，生成有时效的下载链接，含归属校验。

#### 3.2.2 请求方式

| 方式 | 说明 |
|------|------|
| **签名 URL 下载** | 业务模块请求生成签名 URL（含时效与归属校验），前端用签名 URL 直接下载 |
| **请求头** | 无特殊要求（签名 URL 自带鉴权信息） |

#### 3.2.3 响应方式

| 字段 | 说明 |
|------|------|
| Content-Type | 根据文件类型自动设置 |
| Content-Disposition | `attachment; filename="{filename}"`，触发浏览器下载 |
| 响应体 | 文件二进制流 |

#### 3.2.4 业务规则

1. **签名 URL 机制**：生成有时效的下载链接（默认有效期 30 分钟，可配置），链接含签名校验，防止篡改
2. **归属校验**：objectName 下载需校验用户归属或权限（签名 URL 生成时校验调用方对该文件的访问权限）
3. **流式传输**：实现流式传输，避免内存溢出
4. **文件名编码**：响应头中的文件名需进行编码，防止中文乱码
5. **路径安全**：根据文件标识从对象存储读取文件，防止路径遍历攻击

> 文件管理模块通过签名 URL 机制实现下载鉴权，删除"不鉴权"描述。业务模块在生成签名 URL 时完成归属校验。

### 3.3 文件删除 (F-FM-003)

#### 3.3.1 功能描述

支持删除文件，采用**最终一致性**策略：元数据先标记删除（逻辑删除，`deleted=1`），物理文件由定时对账任务（每日）清理孤儿文件。删除方式为逻辑删除，禁止物理删除元数据。

#### 3.3.2 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| fileId | Long | ✅ | 文件 ID |

#### 3.3.3 业务规则

1. **删除权限**：文件删除权限由业务模块控制（业务模块判断文件归属），文件管理模块提供删除能力
2. **最终一致性**：元数据先标记删除（`deleted=1`，事务内），物理文件由定时对账任务（每日）清理孤儿文件
3. **物理文件清理**：定时对账任务检查物理文件是否仍被未删除元数据引用，无引用时清理物理文件（适配物理文件去重场景：多元数据引用同一物理文件时，仅当所有引用均删除后才清理物理文件）
4. **关联检查**：删除前需检查文件是否被其他业务数据引用（由调用方/业务模块控制）
5. **逻辑删除**：元数据执行逻辑删除（`deleted=1`），数据保留可追溯

#### 3.3.4 删除确认

- 调用方（业务模块）在删除文件前应弹窗确认
- 确认文案："确认删除该文件吗？"

### 3.4 文件校验（MD5 去重检查） (F-FM-004)

#### 3.4.1 功能描述

提供文件 MD5 校验接口，用于在上传前检查物理文件是否已存在，实现秒传功能。若物理文件已存在，前端可跳过文件流上传，仅调用上传接口创建独立元数据记录。

#### 3.4.2 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| md5 | String | ✅ | 文件 MD5 值（32 位十六进制字符串） |

#### 3.4.3 响应数据

| 字段 | 类型 | 说明 |
|----|--------|------------|
| exists | Boolean | 物理文件是否已存在 |
| md5 | String | 文件 MD5 值 |

> 返回物理文件是否存在（而非特定文件记录），因为元数据独立——每次上传创建独立元数据记录。前端据 exists 判断是否跳过文件流上传。

#### 3.4.4 业务规则

1. **MD5 格式校验**：校验 MD5 是否为有效的 32 位十六进制字符串
2. **秒传场景**：前端在上传前先调用该接口，物理文件已存在则跳过文件流上传，仅传 MD5 创建元数据
3. **性能优化**：该接口仅查询数据库（MD5 索引），性能应 &lt;100ms

### 3.5 文件分页查询 (F-FM-005)

#### 3.5.1 功能描述

提供文件列表的分页查询能力，支持关键字搜索，便于系统管理员查看和管理已上传的文件。

#### 3.5.2 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| pageNum | Integer | ❌ | 页码，默认 1 |
| pageSize | Integer | ❌ | 每页数量，默认 10 |
| keywords | String | ❌ | 关键字，支持按文件名或文件类型模糊匹配 |

#### 3.5.3 列表展示字段

| 字段 | 显示名称 | 说明 |
|------|---------|------|
| id | 编号 | 文件唯一标识 |
| name | 文件名 | 原始文件名 |
| type | 文件类型 | 文件扩展名 |
| sizeBytes | 文件大小 | 字节数（前端格式化显示） |
| objectName | 存储路径 | 文件在对象存储中的对象名 |
| md5 | 文件指纹 | 文件 MD5 |
| createTime | 创建时间 | 上传时间 |

#### 3.5.4 分页配置

| 配置项 | 默认值 | 可选值 |
|--------|--------|--------|
| 每页条数 | 10 | 10/20/50/100 |

#### 3.5.5 业务规则

1. **关键字匹配**：支持按文件名（`name`）或文件类型（`type`）进行模糊匹配
2. **排序规则**：默认按创建时间倒序排列（最新上传的在前）
3. **数据权限**：系统管理员可查看所有文件，其他角色由调用方控制权限

### 3.6 文件详情查询 (F-FM-006)

#### 3.6.1 功能描述

根据文件 ID 获取文件完整元数据信息。

#### 3.6.2 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| fileId | Long | ✅ | 文件 ID |

#### 3.6.3 响应数据

响应完整的 `SysFile` 对象，包含所有元数据字段（参见 3.1.3 响应数据）。

#### 3.6.4 业务规则

1. **文件不存在**：如果文件 ID 不存在，返回 404 错误
2. **访问控制**：业务模块需自行控制文件详情查询权限

## 4. 界面交互规范

### 4.1 使用场景说明

> 文件管理模块是 BFF 层基础服务，**不提供独立的前端界面**，以下交互规范供调用方（业务模块）参考。

### 4.2 交互流程示例

#### 4.2.1 标准上传流程

```
1. 前端：用户选择文件
2. 前端：流式计算文件 MD5
3. 前端：调用 MD5 校验接口（F-FM-004），判断物理文件是否已存在
4. 前端：物理文件不存在时调用上传接口（F-FM-001）上传文件流；≥50MB 启用分片上传
5. 后端：存储物理文件（或复用已存在物理文件），创建独立元数据记录
6. 前端：展示上传结果，保存 fileId 到业务表
```

#### 4.2.2 秒传流程

```
1. 前端：用户选择文件
2. 前端：流式计算本地文件 MD5
3. 前端：调用 MD5 校验接口（F-FM-004）
4. 后端：返回 exists=true（物理文件已存在）
5. 前端：调用上传接口仅传 MD5（跳过文件流上传）
6. 后端：复用物理文件，创建独立元数据记录
7. 前端：展示上传结果，保存 fileId 到业务表
```

#### 4.2.3 文件删除流程

```
1. 前端：点击删除按钮
2. 前端：弹窗确认
3. 前端：调用删除接口（F-FM-003）
4. 后端：元数据标记删除（deleted=1），物理文件由定时对账任务清理
5. 前端：刷新列表，显示删除成功提示
```

### 4.3 错误处理

| 错误场景 | 提示文案 | 处理方式 |
|---------|---------|---------|
| 文件过大 | "文件大小超过限制（图像最大 100MB，模型最大 500MB）" | 阻止上传 |
| 文件类型不支持 | "不支持的文件类型" | 由业务模块控制 |
| 文件指纹校验失败 | "文件指纹格式不正确" | 阻止上传 |
| 文件不存在 | "文件不存在或已被删除" | 提示用户 |
| 删除失败 | "删除失败，请重试" | 记录日志 |
| 签名 URL 过期 | "下载链接已过期，请重新获取" | 重新生成签名 URL |

| 区域 | 布局要点 |

## 5. 安全设计

### 5.1 数据安全

| 安全措施 | 说明 |
|---------|------|
| **物理文件去重** | MD5 相同复用物理文件，节省存储空间 |
| **元数据独立** | 每次上传独立元数据，多业务引用各自维护 |
| **路径隔离** | 按日期分层存储，防止路径冲突 |
| **传输加密** | 数据传输需加密，防止中间人攻击 |
| **签名 URL** | 下载采用签名 URL 机制（有时效 + 归属校验），防止越权下载 |
| **操作日志** | 强制记录关键操作日志（上传、删除） |

### 5.2 输入校验

| 校验类型 | 说明 |
|---------|------|
| **文件大小校验** | 按业务类型限制最大文件大小（图像 100MB，模型 500MB） |
| **指纹格式校验** | 校验文件指纹格式有效性 |
| **文件名校验** | 防止文件名包含特殊字符或路径遍历 |
| **参数校验** | 服务端进行请求参数校验 |

### 5.3 存储安全

| 安全措施 | 说明 |
|---------|------|
| **对象存储鉴权** | 对象存储配置访问密钥 |
| **路径规范化** | 防止路径遍历攻击（如 `../`） |
| **文件类型校验** | 基于文件扩展名和内容类型双重校验 |
| **签名 URL 防篡改** | 下载链接含签名，防止篡改与越权 |

## 6. 依赖关系

### 6.1 依赖模块

| 模块 | 依赖说明 |
|------|---------|
| **对象存储服务** | 对象存储或云存储，用于文件物理存储 |
| **数据库服务** | 用于存储文件元数据 |
| **配置中心** | 读取文件存储配置（基础 URL、存储类型、大小限制等） |

### 6.2 被依赖模块

| 模块 | 依赖说明 |
|------|---------|
| **数据集管理模块** | 使用文件管理上传和管理数据集图片 |
| **算法模型模块** | 使用文件管理上传和管理算法模型文件 |
| **图像处理模块** | 使用文件管理存储原图和处理结果图（去雾/去雨/去雪/低光/超分/去噪/修复） |
| **任务管理模块** | 使用文件管理存储任务结果文件 |
| **系统所有业务模块** | 依赖文件管理提供通用文件存储能力 |

### 6.3 数据库依赖

## 7. 远期规划（非本期实现）

以下能力不在本期实现，列为远期规划，待平台演进至「AI 工作平台」阶段按需评估：

1. **WPX 格式转换**：WPX 格式转换功能，modelId 参数当前未实现，远期按需评估
2. **文件预览**：图片预览接口（缩略图生成）
3. **临时文件管理**：临时文件上传与自动清理机制
4. **文件类型白名单**：配置文件类型白名单，限制可上传的文件类型
5. **批量删除接口**：提供批量删除接口（当前由业务模块循环调用）

> 本期已定论事项：去重语义（物理文件去重 + 元数据独立）；删除一致性（最终一致性，元数据先标记删除，物理文件定时对账清理）；下载签名 URL 机制；文件大小按业务类型限制；分片上传/断点续传（≥50MB）。
