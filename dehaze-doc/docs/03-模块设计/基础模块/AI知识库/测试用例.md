## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **测试知识库** | 创建 3 个知识库（不同分块策略：fixed/semantic/recursive + 不同 embedding 模型） | 用于检索策略对比测试 |
| **测试文档** | PDF（电子档1份 + 扫描件1份）、Word(.docx)1份、Excel(.xlsx)1份、PPT(.pptx)1份、Markdown(.md)1份、TXT1份、图片(.png)1份、网页URL1份 | 覆盖全部支持格式 |
| **大文档** | 10万字长文档（用于分块上限和性能测试） | 验证分块数准确性和向量化性能 |
| **边界文档** | 空文档、纯图片无文字文档、含嵌套表格文档、含中英混杂文档 | 验证解析边界处理 |
| **嵌入模型** | text-embedding-3-small (1536维) + bge-m3 (1024维) | 验证多模型切换 |

### 3.2 测试基础设施

| 组件 | 说明 |
|------|------|
| ES 8.x 集群 | 向量 + 关键词混合检索、dense_vector (cosine) |
| Embedding API | text-embedding-3-small / bge-m3（或 Mock） |
| 文件存储 | 通过 FileService Mock 返回测试文件 |
| 任务队列 | 异步文档处理流水线 |

### 3.3 数据清理策略

- 测试知识库使用统一前缀 `test_kb_` 标识，测试结束后软删除
- ES 测试索引使用 `kb_chunks_test_` 前缀，测试结束后删除
- 测试文档通过 FileService Mock 管理，无需真实文件存储读写

### 3.4 测试范围

**包含的功能点：**
- F-KB-001 知识库管理（创建/编辑/删除/列表/配置不可变校验）
- F-KB-002 文档管理（上传/批量上传/URL导入/自定义文本/解析/列表/删除/重新处理/进度/版本管理）
- F-KB-003 分块与索引（5种分块策略/向量化/ES索引/索引更新/Embedding模型下线迁移）
- F-KB-004 检索引擎（向量/关键词/RRF混合/Rerank/MMR/元数据过滤/引用溯源/RAG效果度量）
- F-KB-005 知识图谱增强（远期，仅验证设计合理性）
- F-KB-007 MCP 网关协同（kb_search tool 调用与 API Key 认证）

**不在本次测试范围：**
- F-KB-006 经验复用闭环为远期功能，不在本次测试范围
