# AI 模型管理模块 - 前端实现设计（模型管理）

## 1. 文档概述

本文档描述 AI 模型管理模块**模型管理页**的 Web 端（React）前端实现方案，聚焦模型注册表管理（类型筛选、类型专属配置、价格档位、生命周期、降级链）与用量成本运营视图。功能需求见 [需求规格.md](./需求规格.md) §2.8（模型管理）与 §2.9.3（页面设计），接口契约见 [API接口.md](./API接口.md) §2.2。供应商接入与容错见 [前端实现-供应商管理.md](./前端实现-供应商管理.md)。Android / Flutter / Taro 等多端参考本 Web 端组件结构与状态管理方案按各自技术栈适配。

> 边界：本页承载**模型资产与定价**（注册表、类型配置、价格档位、生命周期、降级链、用量成本）；供应商接入/Key/健康看板见供应商管理页；消费方（AI 对话会话内选择、AI 知识库创建向导）消费 `GET /api/v1/ai/models/enabled?model_type=`，消费方前端实现分别见 [AI对话/前端实现-用户端.md](../../核心模块/AI对话/前端实现-用户端.md)、[AI知识库/前端实现-用户端.md](../AI知识库/前端实现-用户端.md)。

## 2. 组件树设计

```mermaid
flowchart TD
    ModelPage --> ModelListSection
    ModelPage --> ModelFormDialog
    ModelPage --> OperationView
    ModelListSection --> ModelTypeFilter
    ModelListSection --> ModelTable
    ModelFormDialog --> ModelTypeFields
    ModelFormDialog --> PriceMatrixEditor
    ModelFormDialog --> LifecycleActions
    OperationView --> UsageCostTab
    OperationView --> DegradationTab
    ModelTypeFields --> EmbeddingDimensionField
    ModelTypeFields --> ChatCapabilityFields
```

| 组件 | 职责 |
|------|------|
| ModelPage | 模型管理页容器与路由入口，编排模型列表/表单/生命周期/运营视图 |
| ModelListSection | 模型列表区：类型筛选 + 分页表格 + 新增/编辑/禁用/下线操作 |
| ModelTypeFilter | 模型类型筛选（全部/chat/embedding/rerank），驱动列表与消费方展示 |
| ModelTable | 模型列表：类型/名称/供应商/状态/积分单价/上下文长度/速度档位/降级标识；禁用模型显著标识"即将下线" |
| ModelFormDialog | 模型表单弹窗：`model_type` 选择 + 类型专属字段（ModelTypeFields）+ 价格档位编辑（PriceMatrixEditor）+ 生命周期操作（LifecycleActions） |
| ModelTypeFields | 类型专属字段：chat（能力标识/上下文/计费档位/VIP 门槛/降级链）、embedding（`dimension` 维度创建后不可改）、rerank（启用配置） |
| EmbeddingDimensionField | embedding 维度输入框（仅 `model_type=embedding` 展示），创建后禁用 + "变更需重建索引"提示 |
| ChatCapabilityFields | chat 能力字段（多模态/工具调用/流式/Prompt Caching/结构化输出标识） |
| PriceMatrixEditor | 价格档位矩阵编辑：token 类型 × 上下文分段 × 时段，保存生成新价格版本（历史版本可追溯） |
| LifecycleActions | 生命周期操作：启用/禁用（"即将下线"+推送替换推荐）/下线（校验无活跃会话）/替换迁移（推荐 fallback 模型） |
| OperationView | 运营视图区：用量成本与降级统计 Tab |
| UsageCostTab | 用量与成本分析：供应商健康看板、模型用量分布、成本归因 |
| DegradationTab | 降级与故障统计：各模型降级频率、Key 失败切换次数 |

## 3. 状态管理

### 3.1 Store 模块划分

| Store 模块 | 职责 | 生命周期 |
|-----------|------|---------|
| 模型管理 Store（adminModelStore） | 模型列表/类型筛选/表单（含价格档位）/生命周期/运营视图 | 页面级，进入模型管理页初始化，离开销毁 |

### 3.2 核心状态

| 状态 | 说明 |
|------|------|
| `models` | 模型分页列表（含类型/状态/单价） |
| `modelTypeFilter` | 当前类型筛选（all/chat/embedding/rerank） |
| `modelForm` | 模型表单状态（`{model, visible}`），`model_type` 决定字段集合 |
| `priceMatrix` | 当前模型价格档位矩阵（token 类型 × 上下文分段 × 时段），保存生成新版本 |
| `lifecycle` | 生命周期操作状态（禁用前活跃会话校验、替换迁移目标推荐） |
| `operationView` | 运营视图数据（用量分布/健康看板/降级统计） |

### 3.3 核心操作

| 操作 | 说明 |
|------|------|
| `fetchModels` | 按 `model_type` 筛选拉取模型列表 |
| `saveModel` | 新增/编辑模型（embedding `dimension` 创建后不可改；`model_id` 不可复用查重） |
| `disableModel` | 禁用模型（"即将下线"，向活跃会话推送替换推荐） |
| `deleteModel` | 下线模型（校验无活跃会话；软删除，model_id 不可复用） |
| `configureFallback` | 配置降级链（fallback 模型，供应商熔断自动兜底） |
| `savePriceMatrix` | 保存价格档位矩阵（生成新价格版本，历史可追溯） |
| `fetchOperationView` | 拉取运营视图数据（用量分布/健康看板/降级统计） |

## 4. 路由设计

| 路由路径 | 页面 | 权限控制 |
|---------|------|---------|
| `/admin/ai-models/models` | 模型管理页 | 管理员（`ai:model:manage`） |

> 父路由 `/admin/ai-models` 默认重定向至供应商管理子页；供应商与模型管理为兄弟子路由（见 [前端实现-供应商管理.md](./前端实现-供应商管理.md) §4）。

## 5. 数据流

| 区块 | 数据来源 | 获取时机 | 缓存策略 |
|------|---------|---------|---------|
| 模型列表 | `GET /api/v1/ai/models`（管理端，`model_type` 筛选） | 进入页面 + 类型筛选/分页变更 | 当前筛选结果缓存；保存/生命周期操作后失效 |
| 模型表单 | `GET /api/v1/ai/models/{model_id}`（编辑回显）+ 启用供应商列表（下拉） | 打开弹窗时 | 弹窗会话级缓存 |
| 价格档位 | `POST/PUT /api/v1/ai/models`（含价格档位参数） | 保存时提交 | 版本化存储，历史版本可查询 |
| 生命周期 | 启用/禁用/下线/替换迁移接口 | 用户触发 | 操作后刷新列表 |
| 启用模型列表（消费方） | `GET /api/v1/ai/models/enabled?model_type=` | 消费方（对话/知识库）挂载时 | 消费方侧缓存（TTL 1h，服务端模型列表缓存） |
| 运营视图 | `GET /api/v1/ai/usage/stats`（`ai:model:manage`，时间范围 + 粒度聚合） | 切换运营视图 Tab 时 | 当前时间范围结果缓存 |

## 6. 交互设计决策

| 交互点 | 技术选型 | 理由 |
|--------|---------|------|
| 类型化表单 | `model_type` 决定字段集合（chat 能力标识/embedding 维度/rerank 配置） | 三类模型配置差异大，类型化表单避免配错字段（如给 chat 模型配维度）；embedding 维度创建后不可改（ES 索引依赖，需求规格 §2.9.3） |
| 价格档位矩阵编辑 | PriceMatrixEditor 按"token 类型 × 上下文分段 × 时段"矩阵填写，保存生成新价格版本 | 价格体系维度多，矩阵化编辑直观；版本化保证历史计费可追溯（§2.8.3/§2.7.7） |
| 生命周期引导 | 禁用=“即将下线"+推送替换推荐；下线前校验活跃会话并引导切换；替换迁移推荐同能力 fallback | 模型演进不能打断活跃用户，页面提供状态可见 + 替换引导闭环（§2.8.4） |
| 降级链配置内联 | ModelFormDialog 内 configureFallback | 降级链与模型配置同表单完成，供应商熔断时自动兜底，无需另找入口 |
| 运营视图 Tab 承载 | OperationView 挂于模型管理页（含供应商健康看板） | 用量成本分析聚焦"花得对不对"的定价与轮换决策，与模型配置同页闭环；供应商页健康看板仅聚焦接入容错，两处入口分层不重复实现 |
| 消费方状态联动 | 模型状态（启用/禁用/已下线）显著标识，禁用模型在消费方不可选 | 管理端配置结果直接决定消费方可用性（对话模型选择、知识库创建向导），状态可见防"配了不可用" |

## 7. 公共组件使用

| 公共组件 | 配置要点 |
|---------|---------|
| 分页表格 | 模型列表、运营视图明细表 |
| 弹窗（Dialog） | 模型表单（ModelFormDialog）、下线确认 |
| 标签页（Tabs） | 运营视图（用量成本 / 降级统计）切换 |
| 表单校验组件 | `model_id` 查重、embedding 维度必填校验、价格矩阵数值校验 |
| 状态标签 | 模型状态（启用/禁用/已下线）、模型类型（chat/embedding/rerank） |
| 图表组件 | 用量分布饼图/柱图、健康看板指标卡 |
