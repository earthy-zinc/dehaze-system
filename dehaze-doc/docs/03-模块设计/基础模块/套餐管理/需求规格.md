# 套餐管理模块需求规格

## 1. 模块概述

### 1.1 模块定位

套餐管理模块负责管理系统中所有 VIP 套餐的定义、定价、上下架及权益包配置。该模块是会员商业化体系的商品中心，为订单管理模块提供商品数据，为会员管理模块提供权益生效依据。

### 1.2 核心价值

| 价值维度 | 具体内容 |
|---------|---------|
| **多样化方案** | 提供包月/季/年等多种周期套餐，匹配不同用户付费意愿 |
| **灵活定价** | 支持原价、促销价、限时折扣等多种价格策略 |
| **权益组合** | 套餐权益可灵活配置，支持功能解锁与次数配额的组合 |
| **运营管控** | 套餐上下架、库存管理、销售数据统计一站式管理 |

### 1.3 业务目标

#### 功能目标

- 建立覆盖四个会员等级的套餐方案矩阵
- 支持多种计费周期（月/季/年）和价格策略
- 提供套餐 CRUD 和上下架管理
- 支持促销活动和优惠券管理

#### 性能目标

| 指标 | 目标值 | 说明 |
|-----|--------|------|
| 套餐列表查询 | <200ms | 用户端套餐列表加载时间 |
| 套餐详情查询 | <100ms | 单个套餐详情响应时间 |
| 后台套餐列表 | <500ms | 后台分页查询响应时间 |

### 1.4 模块依赖关系

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  套餐管理    │────▶│  订单管理    │────▶│  会员管理    │
│   模块      │     │    模块     │     │    模块     │
└─────────────┘     └─────────────┘     └─────────────┘
       │
       ▼

└─────────────┘
```

## 2. 套餐方案设计

### 2.1 套餐矩阵 (F-PM-001)

#### 2.1.1 标准套餐

| 套餐名称 | 会员等级 | 计费周期 | 原价 | 促销价 | 节省 |
|---------|---------|---------|------|--------|------|
| VIP1 月卡 | VIP1 | 1 个月 | ¥10 | ¥8 | ¥2 |
| VIP1 季卡 | VIP1 | 3 个月 | ¥30 | ¥25 | ¥5 |
| VIP1 年卡 | VIP1 | 12 个月 | ¥120 | ¥96 | ¥24 |
| VIP2 月卡 | VIP2 | 1 个月 | ¥20 | ¥16 | ¥4 |
| VIP2 季卡 | VIP2 | 3 个月 | ¥60 | ¥50 | ¥10 |
| VIP2 年卡 | VIP2 | 12 个月 | ¥240 | ¥192 | ¥48 |
| SVIP 月卡 | SVIP | 1 个月 | ¥50 | ¥42 | ¥8 |
| SVIP 季卡 | SVIP | 3 个月 | ¥150 | ¥128 | ¥22 |
| SVIP 年卡 | SVIP | 12 个月 | ¥600 | ¥480 | ¥120 |

#### 2.1.2 套餐权益包定义

每个套餐关联一个权益包，权益包定义购买后生效的具体权益：

| 权益项 | VIP1 套餐 | VIP2 套餐 | SVIP 套餐 |
|--------|----------|----------|----------|
| 会员等级 | VIP1 | VIP2 | SVIP |
| 月度去雾次数 | 100 | 500 | 3000 |
| 月度评估次数 | 100 | 500 | 3000 |
| 历史记录保留 | 50 条 | 100 条 | 500 条 |
| 批量处理上限 | 10 张 | 15 张 | 20 张 |
| 处理优先级 | 优先 | 高优先 | 最高 |
| 高级参数调节 | ✅ | ✅ | ✅ |
| 高清图导出 | ✅ | ✅ | ✅ |
| 对比报告导出 | ❌ | ✅ | ✅ |
| 批量打包下载 | ❌ | ✅ | ✅ |

#### 2.1.3 套餐有效期计算

| 计费周期 | 有效期 | 到期时间计算 |
|---------|--------|------------|
| 月卡 | 30 天 | 支付成功时间 + 30 天 |
| 季卡 | 90 天 | 支付成功时间 + 90 天 |
| 年卡 | 365 天 | 支付成功时间 + 365 天 |

**续费叠加规则**：套餐未到期时续费，新套餐有效期在原到期时间基础上叠加。套餐已到期时续费，从支付时间开始计算。

### 2.2 升级与差价 (F-PM-002)

#### 2.2.1 升级规则

用户在套餐有效期内可升级到更高等级套餐：

| 场景 | 处理方式 |
|------|---------|
| VIP1 升级 VIP2 | 按剩余天数比例退还差价，抵扣新套餐费用 |
| VIP1 升级 SVIP | 按剩余天数比例退还差价，抵扣新套餐费用 |
| VIP2 升级 SVIP | 按剩余天数比例退还差价，抵扣新套餐费用 |

#### 2.2.2 差价计算公式

```
退还金额 = (原套餐日均价 × 剩余天数) - (新套餐日均价 × 剩余天数) × 0.8
```

退还金额按 80% 折算（20% 为手续费），直接抵扣新套餐费用。若退还金额大于新套餐费用，差额以平台余额形式退回。

### 2.3 促销活动 (F-PM-003)

#### 2.3.1 活动类型

| 活动类型 | 说明 | 示例 |
|---------|------|------|
| 限时折扣 | 指定时间段内套餐降价 | 年卡限时 8 折 |
| 新用户专享 | 首次购买用户享受特价 | 首月 ¥1 体验 VIP1 |
| 节日促销 | 节假日期间专属活动 | 春节 SVIP 年卡 5 折 |
| 满减活动 | 订单金额满足条件减价 | 满 ¥200 减 ¥30 |

#### 2.3.2 活动规则

- 限时折扣与优惠券可叠加使用
- 新用户专享活动每用户仅可参与一次
- 活动套餐不支持退款（特价套餐）
- 活动结束后价格自动恢复原价
- 活动开始前和结束后各保留 1 小时缓冲期

### 2.4 优惠券管理 (F-PM-004)

#### 2.4.1 优惠券类型

| 类型 | 说明 | 使用限制 |
|------|------|---------|
| 满减券 | 订单金额满 X 元减 Y 元 | 指定套餐可用 |
| 折扣券 | 订单金额打 X 折 | 指定等级套餐可用 |
| 无门槛券 | 直接抵扣固定金额 | 任意套餐可用 |
| 体验券 | 免费体验指定等级 N 天 | 每用户限用一次 |

#### 2.4.2 优惠券规则

- 优惠券有有效期，过期自动失效
- 每笔订单仅可使用一张优惠券
- 优惠券支持批量发放（按用户等级、注册时间筛选）
- 退款时优惠券不退回（已使用）
- 体验券不产生订单记录，直接激活权益

## 3. 用户端功能

### 3.1 套餐展示页 (F-PM-005)

#### 3.1.1 功能描述

展示所有在售套餐，支持用户比较和选择。

#### 3.1.2 页面布局

| 区域 | 内容 |
|------|------|
| 顶部横幅 | 当前促销活动信息（如有） |
| 套餐卡片 | 按等级分组展示（VIP1/VIP2/SVIP），每个等级展示月/季/年三种周期 |
| 权益对比表 | 各等级权益对比，当前等级高亮 |
| 底部说明 | 套餐说明、退款政策、自动续费协议 |

#### 3.1.3 套餐卡片信息

| 信息项 | 说明 |
|--------|------|
| 套餐名称 | 如"VIP2 年卡" |
| 会员等级标识 | 等级图标和颜色 |
| 价格 | 促销价（大字）+ 原价（删除线） |
| 日均价格 | 促销价 / 天数，如"¥0.53/天" |
| 核心权益 | 3-5 条关键权益列表 |
| 购买按钮 | "立即开通" / "升级至此" |

#### 3.1.4 交互规则

- 当前用户等级以下的套餐按钮显示"续费"
- 当前用户等级的套餐按钮显示"续费"
- 当前用户等级以上的套餐按钮显示"升级至此"
- 点击套餐卡片展开完整权益列表
- 有促销活动时顶部横幅自动展示，可关闭

### 3.2 套餐购买流程 (F-PM-006)

#### 3.2.1 购买流程

```
用户选择套餐
    ↓
展示订单确认页（套餐信息、价格明细、优惠券选择）
    ↓
选择优惠券（可选）
    ↓
选择支付方式（微信/支付宝/平台余额）
    ↓
勾选同意《会员服务协议》
    ↓
点击"确认支付"
    ↓
跳转支付页面 → 完成支付
    ↓
支付回调 → 权益即时生效 → 跳转会员中心
```

#### 3.2.2 订单确认页信息

| 信息项 | 说明 |
|--------|------|
| 套餐信息 | 名称、等级、有效期 |
| 价格明细 | 原价、促销折扣、优惠券抵扣、应付金额 |
| 优惠券选择 | 可用优惠券列表，默认不选 |
| 支付方式 | 微信支付、支付宝、平台余额（余额不足时置灰） |
| 协议勾选 | 《会员服务协议》《自动续费协议》（如支持） |
| 到期时间 | 支付后预计到期时间（续费叠加场景展示叠加后到期时间） |

### 3.3 自动续费 (F-PM-007)

#### 3.3.1 功能描述

用户可开启自动续费，套餐到期前自动扣款续费。

#### 3.3.2 续费规则

- 自动续费在套餐到期前 24 小时发起扣款
- 扣款失败时连续重试 3 次（间隔 2 小时）
- 3 次均失败则取消自动续费，套餐正常到期
- 自动续费可随时关闭，不影响当前套餐有效期
- 自动续费享受 95 折优惠（相比手动续费）

#### 3.3.3 管理入口

- 购买时勾选"开启自动续费"
- 个人中心 → 会员设置 → 自动续费管理
- 支持查看自动续费记录和关闭自动续费

## 4. 后台管理功能

### 4.1 套餐列表查询 (F-PM-008)

#### 4.1.1 功能描述

提供套餐信息的分页展示和多条件筛选。

#### 4.1.2 查询条件

| 条件类型 | 字段 | 说明 |
|---------|------|------|
| 套餐名称 | 模糊匹配 | LIKE |
| 会员等级 | 精确匹配 | = |
| 计费周期 | 精确匹配 | = |
| 上下架状态 | 精确匹配 | = |
| 创建时间 | 范围匹配 | BETWEEN |

#### 4.1.3 列表展示字段

| 字段 | 显示名称 | 说明 |
|------|---------|------|
| name | 套餐名称 | 套餐显示名称 |
| levelName | 会员等级 | 关联的会员等级 |
| period | 计费周期 | 月/季/年 |
| originalPrice | 原价 | 标准价格 |
| salePrice | 促销价 | 当前销售价格 |
| status | 上下架状态 | 在售/下架 |
| salesCount | 销量 | 累计销售份数 |
| sort | 排序 | 展示排序值 |
| createTime | 创建时间 | 套餐创建时间 |
| - | 操作 | 编辑/上架/下架/删除 |

### 4.2 套餐新增/编辑 (F-PM-009)

#### 4.2.1 功能描述

创建或修改套餐信息，包括基本信息、价格、权益配置。

#### 4.2.2 表单字段

| 字段 | 显示名称 | 类型 | 必填 | 校验规则 |
|------|---------|------|------|---------|
| name | 套餐名称 | 输入框 | ✅ | 2-32 字符，系统唯一 |
| levelCode | 会员等级 | 下拉选择 | ✅ | 关联会员等级配置 |
| period | 计费周期 | 下拉选择 | ✅ | 月/季/年 |
| periodDays | 有效期天数 | 数值输入 | ✅ | 1-365 |
| originalPrice | 原价 | 数值输入 | ✅ | >0，精确到分 |
| salePrice | 促销价 | 数值输入 | ✅ | >0 且 ≤ 原价 |
| description | 套餐描述 | 文本域 | ❌ | 最多 256 字符 |
| sort | 排序值 | 数值输入 | ✅ | 0-999 |
| status | 状态 | 单选 | ✅ | 上架/下架 |

#### 4.2.3 权益配置区域

套餐编辑页包含权益配置区域，可配置该套餐生效的权益项。默认从会员等级配置继承，支持覆盖：

| 配置项 | 继承来源 | 是否可覆盖 |
|--------|---------|-----------|
| 月度去雾次数 | 会员等级配置 | ✅ |
| 月度评估次数 | 会员等级配置 | ✅ |
| 历史记录保留 | 会员等级配置 | ✅ |
| 批量处理上限 | 会员等级配置 | ✅ |
| 处理优先级 | 会员等级配置 | ✅ |
| 功能解锁项 | 会员等级配置 | ✅ |
| 额外加成 | - | ✅（如限时双倍次数） |

#### 4.2.4 业务规则

1. 已有订单的套餐不可删除，仅可下架
2. 价格修改不影响已生成的订单
3. 套餐名称全局唯一
4. 新建套餐默认为下架状态，需手动上架

### 4.3 套餐上下架 (F-PM-010)

#### 4.3.1 功能描述

控制套餐在用户端的展示和购买状态。

#### 4.3.2 业务规则

- 下架后：用户端不再展示该套餐，已购买用户的权益不受影响
- 上架后：用户端立即可见可购买
- 上下架操作记录操作日志
- 促销活动期间不允许下架活动套餐

### 4.4 优惠券管理 (F-PM-011)

#### 4.4.1 优惠券列表

展示所有优惠券的名称、类型、面值、有效期、发放数量、已使用数量、状态。

#### 4.4.2 优惠券创建

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| couponName | 输入框 | ✅ | 优惠券名称 |
| couponType | 下拉选择 | ✅ | 满减/折扣/无门槛/体验券 |
| faceValue | 数值输入 | ✅ | 面值（满减金额/折扣率/抵扣金额） |
| threshold | 数值输入 | ❌ | 使用门槛（满减券必填） |
| validType | 单选 | ✅ | 固定时间段/领取后 N 天 |
| validStart | 日期选择 | ❌ | 有效期开始（固定时间段时必填） |
| validEnd | 日期选择 | ❌ | 有效期结束（固定时间段时必填） |
| validDays | 数值输入 | ❌ | 领取后有效天数（领取后 N 天时必填） |
| totalQty | 数值输入 | ✅ | 发放总量（-1 为不限） |
| perUserLimit | 数值输入 | ✅ | 每人限领数量 |
| applicableScope | 多选 | ✅ | 适用套餐（全部/指定套餐） |

#### 4.4.3 优惠券发放

| 发放方式 | 说明 |
|---------|------|
| 主动领取 | 用户在优惠券页面主动领取 |
| 定向发放 | 管理员选择用户群体批量发放 |
| 活动赠送 | 促销活动自动发放（如新用户注册） |
| 客服补偿 | 客服手动发放给指定用户 |

### 4.5 销售统计 (F-PM-012)

#### 4.5.1 功能描述

展示套餐销售数据，支撑运营决策。

#### 4.5.2 统计维度

| 维度 | 指标 |
|------|------|
| 按套餐 | 销量、销售额、退款率、续费率 |
| 按等级 | 各等级套餐销售占比 |
| 按周期 | 月/季/年套餐销售占比 |
| 按时间 | 日/周/月销售趋势 |
| 优惠券使用率 | 发放量 vs 使用量 vs 核销率 |

## 5. 非功能需求

### 5.1 性能需求

| 指标 | 要求 |
|-----|------|
| 套餐列表缓存 | Redis 缓存，TTL 5 分钟，修改时主动刷新 |
| 价格计算 | <100ms，优惠券校验与折扣计算实时完成 |
| 销量统计 | 异步聚合，T+1 数据准实时 |

### 5.2 安全需求

| 方面 | 措施 |
|-----|------|
| 价格防篡改 | 订单创建时后端重新校验套餐价格，不信任前端传入金额 |
| 优惠券防刷 | 领取频率限制（每用户每分钟 ≤5 次） |
| 并发控制 | 优惠券库存扣减使用乐观锁或 Redis 原子操作 |
| 权限控制 | 后台管理仅管理员可操作 |

### 5.3 可用性需求

| 方面 | 要求 |
|-----|------|
| 套餐展示降级 | 缓存不可用时降级为 DB 查询 |
| 支付幂等 | 同一套餐重复支付请求做幂等处理 |
| 活动自动切换 | 促销活动到点自动开始/结束，无需人工干预 |

## 7. 待确认事项

1. **企业套餐**：是否需要支持企业版套餐（多人共享、统一计费）？当前设计仅支持个人套餐。
2. **免费试用**：是否提供免费试用期（如 VIP1 试用 3 天）？若提供，试用转付费的流程如何设计？
3. **跨等级续费**：用户当前是 VIP1 年卡，是否可以直接购买 VIP2 月卡？升级差价如何计算？
4. **退款政策**：套餐退款是全额退还是按使用天数折算？促销套餐是否支持退款？
5. **多端价格统一**：Web 端、移动端、小程序的套餐价格是否需要完全一致？是否需要平台专属价？
