# 套餐管理模块测试用例

## 1. 测试目标

- [x] 验证商品定义符合需求规格（会员卡 / 积分卡两类商品类型、类型创建后不可修改）
- [x] 验证商品 CRUD、上下架、价格计算、权益覆盖与可得积分配置
- [x] 验证优惠券管理（创建/发放/领取/状态流转，适用于任意商品类型）
- [x] 验证促销活动联动（折扣计算、下架保护、可关联任意商品类型）
- [x] 验证销售统计正确性（含按商品类型维度）
- [x] 验证权限控制与安全性（优惠券防刷、库存并发、类型锁定）

---

## 2. 测试前置

### 2.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **会员卡商品** | 各等级（level_1/2/3）、各周期（月/季/年）套餐若干（含在售/下架状态） | 用于 CRUD 与上下架测试 |
| **积分卡商品** | 多档位积分卡若干（可得积分不同，含在售/下架状态） | 用于积分卡商品测试 |
| **促销活动** | 进行中/未开始/已结束活动若干，分别关联会员卡与积分卡 | 用于折扣计算与下架保护测试 |
| **优惠券模板** | 各类型券（满减/折扣/无门槛/体验券），含不同库存状态，含限定商品类型（vip/credit）的券 | 用于券测试 |
| **用户优惠券** | 不同状态（未使用/已使用/已过期/已锁定） | 用于价格计算与领取测试 |
| **用户/会员** | 普通用户、管理员、各等级会员 | 用于权限与批量发放测试 |
| **订单数据** | 已支付/已完成/待支付/退款订单（含会员卡与积分卡订单） | 用于删除校验与销售统计测试 |

### 2.2 数据清理策略

- 测试套餐使用统一前缀 `test_pkg_` 标识，测试结束按前缀清理
- 测试优惠券使用统一前缀 `测试券-` 标识，测试结束按前缀清理模板与实例
- 测试促销活动测试后清理

### 2.3 测试范围

**包含的功能点：**

- 套餐列表/详情（用户端在售、分类 Tab、后台分页）
- 套餐 CRUD 与上下架（两类商品类型）
- 会员卡权益覆盖配置、积分卡可得积分配置
- 价格计算（促销折扣 + 优惠券抵扣 + 价格快照）
- 优惠券管理（创建/发放/领取/查询/删除）
- 促销活动管理（创建/修改/上下架/关联套餐）
- 销售统计（含按商品类型维度）

**不包含的功能点（订单模块/会员模块/AI计费模块测试）：**

- 订单创建与支付（订单模块测试）
- 优惠券锁定/核销/释放/退款退回（订单模块测试）
- 购买后会员等级变更与成长值累积（会员模块测试）
- 积分卡履约（积分到账/流水）与积分消耗（AI 计费模块测试）

**不包含的功能点（远期规划/已定论不实现）：**

- 升级差价折算（已定论维持续费叠加）
- 续费率/按时间销售趋势统计（订单模块提供）
- 企业套餐（远期规划）

## 4. 关键边界与异常场景

| 场景 | 测试点 | 期望行为 |
|------|--------|---------|
| **商品类型锁定** | 修改请求携带不同 packageType | 忽略该字段，类型不变（创建后不可修改） |
| **商品类型非法** | packageType 非 vip/credit | 拒绝创建 |
| **积分卡可得积分** | creditAmount=0 / 负数 | 拒绝创建（必须大于0） |
| **积分卡无周期/有效期** | 积分卡配置 period/periodDays | 恒为 NULL，不参与续费叠加 |
| **套餐名称查重** | 含软删行同名 | 拒绝创建（防历史占用） |
| **套餐字段边界** | 名称2-32/有效期1-365/原价>0/排序0-999/描述≤256 | 越界值校验失败 |
| **权益覆盖JSON解析** | benefit_overrides 格式错误 | 返回业务错误，不静默降级 |
| **促销下架保护** | 进行中活动套餐（含积分卡）下架 | 拒绝下架 |
| **订单关联删除** | 已有订单套餐删除 | 拒绝删除 |
| **优惠券库存并发** | 并发领取超量 | 乐观锁保证不超发 |
| **优惠券限频** | 高频领取 | 限流拦截 |
| **价格防篡改** | 前端传入自定义金额 | 后端重算价格，不信任前端 |

## 6. 安全性测试

| 测试项 | 验证方式 | 预期结果 |
|--------|---------|---------|
| **未登录访问** | 未登录调用套餐接口 | 返回 A0230 token无效 |
| **非管理员后台操作** | 普通用户调用 CRUD/统计接口 | 返回 A0301 访问未授权 |
| **商品类型篡改** | 编辑请求携带与原类型不同的 packageType | 字段被忽略，类型不变 |
| **优惠券越权使用** | 使用他人优惠券 ID 计算价格 | 提示"优惠券不存在"，不暴露归属 |
| **价格篡改** | 订单创建时篡改金额参数 | 后端按套餐价格重算，不生效（订单模块校验） |
| **库存超发** | 并发领取超量 | 乐观锁拦截，不超发 |
| **SQL 注入** | 参数包含恶意字符 | 参数化查询防护 |
