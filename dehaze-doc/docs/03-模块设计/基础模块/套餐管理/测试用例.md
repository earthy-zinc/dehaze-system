# 套餐管理模块测试用例

## 1. 测试目标

- [x] 验证套餐功能符合需求规格（套餐 CRUD、上下架、价格计算、权益覆盖）
- [x] 验证优惠券管理（创建/发放/领取/状态流转）
- [x] 验证促销活动联动（折扣计算、下架保护）
- [x] 验证销售统计正确性
- [x] 验证权限控制与安全性（优惠券防刷、库存并发）

---

## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **套餐数据** | 各等级、各周期套餐若干（含在售/下架状态） | 用于 CRUD 与上下架测试 |
| **促销活动** | 进行中/未开始/已结束活动若干，关联套餐 | 用于折扣计算与下架保护测试 |
| **优惠券模板** | 各类型券（满减/折扣/无门槛/体验券），含不同库存状态 | 用于券测试 |
| **用户优惠券** | 不同状态（未使用/已使用/已过期/已锁定） | 用于价格计算与领取测试 |
| **用户/会员** | 普通用户、管理员、各等级会员 | 用于权限与批量发放测试 |

### 3.2 数据清理策略

- 测试套餐使用统一前缀 `test_pkg_` 标识，测试结束按前缀清理
- 测试优惠券使用统一前缀 `测试券-` 标识，测试结束按前缀清理模板与实例
- 测试促销活动测试后清理

### 3.3 测试范围

**包含的功能点：**

- 套餐列表/详情（用户端在售、后台分页）
- 套餐 CRUD 与上下架
- 权益覆盖配置
- 价格计算（促销折扣 + 优惠券抵扣 + 价格快照）
- 优惠券管理（创建/发放/领取/查询/删除）
- 促销活动管理（创建/修改/上下架/关联套餐）
- 销售统计

**不包含的功能点（订单模块/会员模块测试）：**

- 订单创建与支付（订单模块测试）
- 优惠券锁定/核销/释放/退款退回（订单模块测试）
- 购买后会员等级变更与成长值累积（会员模块测试）

**不包含的功能点（远期规划/已定论不实现）：**

- 升级差价折算（已定论维持续费叠加）
- 续费率/按时间销售趋势统计（订单模块提供）
- 企业套餐（远期规划）

## 5. 关键边界与异常场景

| 场景 | 测试点 | 期望行为 |
|------|--------|---------|
| **套餐名称查重** | 含软删行同名 | 拒绝创建（防历史占用） |
| **套餐字段边界** | 名称2-32/有效期1-365/原价>0/排序0-999/描述≤256 | 越界值校验失败 |
| **权益覆盖JSON解析** | benefit_overrides 格式错误 | 返回业务错误，不静默降级 |
| **促销下架保护** | 进行中活动套餐下架 | 拒绝下架 |
| **订单关联删除** | 已有订单套餐删除 | 拒绝删除 |
| **优惠券库存并发** | 并发领取超量 | 乐观锁保证不超发 |
| **优惠券限频** | 高频领取 | 限流拦截 |
| **价格防篡改** | 前端传入自定义金额 | 后端重算价格，不信任前端 |

## 7. 安全性测试

| 测试项 | 验证方式 | 预期结果 |
|--------|---------|---------|
| **未登录访问** | 未登录调用套餐接口 | 返回 A0230 token无效 |
| **非管理员后台操作** | 普通用户调用 CRUD/统计接口 | 返回 A0301 访问未授权 |
| **优惠券越权使用** | 使用他人优惠券 ID 计算价格 | 提示"优惠券不存在"，不暴露归属 |
| **价格篡改** | 订单创建时篡改金额参数 | 后端按套餐价格重算，不生效（订单模块校验） |
| **库存超发** | 并发领取超量 | 乐观锁拦截，不超发 |
| **SQL 注入** | 参数包含恶意字符 | 参数化查询防护 |
