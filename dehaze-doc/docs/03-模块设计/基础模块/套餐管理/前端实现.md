# 套餐管理模块 - 前端实现设计

## 1. 文档概述

本文档描述套餐管理模块的前端实现方案（dehaze-front-vue），聚焦页面结构、数据流、关键交互决策与权限控制。

---

## 2. 页面结构

### 2.1 页面清单

| 页面 | 路径 | 角色 | 说明 |
|------|------|:----:|------|
| 套餐商城 | `views/package/shop/index.vue` | 用户 | 在售套餐卡片 + 权益对比表 + 购买入口 |
| 套餐管理 | `views/package/list/index.vue` | 管理员 | 套餐分页管理 + 新增/编辑/上下架/删除 + 销售统计 |
| 优惠券管理 | `views/package/coupon/index.vue` | 管理员 | 优惠券分页管理 + 新增/编辑/删除/批量发放 |

> **说明**：早期设计稿中的 PackageDetail（独立套餐详情页）、CouponCenter（优惠券领取中心）、PromotionManagement（促销管理页）、PackageList（用户端列表页）等**均不存在**——用户端为 `package/shop` 单页，后台为 `package/list` + `package/coupon` 两页。

### 2.2 套餐商城（shop/index.vue）

| 区域 | 内容 |
|------|------|
| 顶部横幅 | 会员推广文案（可关闭，transition 动画） |
| 套餐卡片 | 等级图标/名称/促销价（大字）/原价（删除线）/日均价/有效期标签/权益列表/购买按钮 |
| 权益对比表 | 跨套餐权益对比（当前等级列高亮），表头合并单元格 |

**卡片关键逻辑**：

| 项目 | 说明 |
|------|------|
| 价格展示 | 促销价 `salePrice.toFixed(2)`，原价删除线，日均价 `¥X.XX/天` + 周期标签 |
| 权益展示 | 遍历 `pkg.benefits`（等级权益 ⊕ 覆盖项），中文标签映射 + 数值格式化（次数显示"X次"、功能开关显示"解锁/支持"） |
| 购买按钮 | 文案按当前等级与套餐等级比较：同等级"续费"、更高等级"升级至此"、其余"立即开通"；加载中显示 loading |
| 购买行为 | 点击后调用价格计算（携带 packageId），再跳转订单确认/创建流程（订单模块） |
| 对比表数据 | 从在售套餐列表派生（按权益项聚合），静态配置权益标签，当前等级列高亮 |

### 2.3 套餐管理（list/index.vue）

| 区域 | 内容 |
|------|------|
| 筛选区 | 套餐名/等级/计费周期/状态/创建时间范围（重置按钮） |
| 操作栏 | 新增套餐（`package:add`）、批量删除（`package:delete`，多选时可用）、销售统计（`package:sales`，抽屉展示） |
| 表格 | 套餐名/等级/周期/原价/促销价/日均价/销量/状态（switch 上下架）/创建时间/操作（编辑、删除） |
| 新增/编辑弹窗 | 表单（名称/等级/周期/有效期天数/原价/促销价/描述/权益覆盖配置/排序） |
| 销售统计抽屉 | 总销量/总营收 + 按套餐/等级/周期统计表格 |

**表单关键逻辑**：

| 项目 | 说明 |
|------|------|
| 价格单位 | 输入以元为单位，提交时转换 `元 × 100 = 分` |
| 权益覆盖配置 | 复选框勾选覆盖项 + 数值输入，未勾选项继承等级权益 |
| 状态处理 | 新增时表单可设状态（默认下架）；**编辑时隐藏状态字段**（上下架走表格 switch） |
| 上下架 switch | 直接调用上下架接口，成功后刷新列表（促销中套餐下架失败时提示后端错误） |

### 2.4 优惠券管理（coupon/index.vue）

| 区域 | 内容 |
|------|------|
| 筛选区 | 名称/类型（满减/折扣/无门槛/体验券）/状态 |
| 操作栏 | 新增优惠券（`package:coupon:add`）、批量发放（`package:coupon:distribute`） |
| 表格 | 名称/类型标签/面值/门槛/有效期/发放量/已用量/状态/操作（编辑、删除） |
| 新增/编辑弹窗 | 表单（名称/类型/面值/门槛/有效期类型/发放总量/每人限领/适用套餐多选/启用状态），字段按类型联动显隐 |
| 批量发放弹窗 | 发放对象单选（全部用户/指定等级/指定用户），按对象展示对应选择器，提交后展示成功/失败数量 |

**表单字段联动**：

| 类型 | 联动 |
|------|------|
| 满减券 | 使用门槛必填 |
| 固定有效期 | 起止时间必填 |
| 领取后 N 天 | 有效天数必填（隐藏起止时间） |

## 3. 数据流

### 3.1 套餐商城

```
进入页面 → 加载在售套餐列表（含生效权益）
    ↓
渲染卡片 + 权益对比表（当前等级高亮）
    ↓
点击购买 → 计算价格（packageId + 可选优惠券）→ 跳转订单创建/确认
```

### 3.2 套餐管理

```
进入页面 → 分页查询
    ↓
筛选（名称/等级/周期/状态/时间）→ 重新查询
    ↓
操作：
  - 新增/编辑 → 弹窗 → 提交（元转分）→ 刷新列表
  - 上下架 → switch → 提交 → 刷新列表
  - 删除 → 确认 → 提交 → 刷新列表
  - 销售统计 → 抽屉 → 加载统计接口
```

### 3.3 优惠券管理

```
进入页面 → 分页查询优惠券模板
    ↓
新增/编辑 → 弹窗（类型联动校验）→ 提交 → 刷新列表
    ↓
批量发放 → 弹窗（选择对象）→ 提交 → 提示成功/失败数量
```

### 3.4 模块间数据交互

| 交互方向 | 数据 | 说明 |
|---------|------|------|
| 套餐商城 → 订单管理 | packageId + 价格计算结果 | 购买流程跳转订单创建 |
| 套餐管理 → 会员管理 | levelCode | 权益覆盖配置的等级下拉与等级名称展示 |
| 后台 → 前台 | 上下架状态 | 下架套餐用户端不可见 |

---

## 4. 状态管理

套餐模块**无独立 Store**，状态在页面组件内局部管理（loading/分页数据/弹窗显隐/表单数据等）。

---

## 5. 关键交互决策

| 决策点 | 实现方式 |
|--------|---------|
| 购买按钮文案 | 按当前等级与套餐等级比较：同等级"续费"、更高等级"升级至此"、其余"立即开通" |
| 价格单位转换 | 输入为元，提交前 ×100 转为分；展示时 /100 保留 2 位小数 |
| 权益展示 | benefits Map 遍历，中文标签映射 + 数值格式化（次数/开关） |
| 编辑状态隐藏 | 编辑弹窗不展示状态字段，上下架仅通过表格 switch 操作 |
| 批量删除 | 表格多选（选择框），至少选 1 条方可删除 |
| 发放对象联动 | 全部用户/指定等级/指定用户三种模式切换选择器 |
| 表单类型联动 | 满减券显示门槛、固定有效期显示起止时间、领取后 N 天显示天数 |

## 6. 权限控制

| 操作 | 权限标识 | 无权限时 |
|------|---------|---------|
| 新增套餐 | package:add | 按钮隐藏 |
| 编辑套餐 | package:edit | 按钮隐藏 |
| 删除套餐 | package:delete | 按钮隐藏 |
| 销售统计 | package:sales | 按钮隐藏 |
| 新增优惠券 | package:coupon:add | 按钮隐藏 |
| 批量发放 | package:coupon:distribute | 按钮隐藏 |
| 编辑优惠券 | package:coupon:edit | 按钮隐藏 |
| 删除优惠券 | package:coupon:delete | 按钮隐藏 |

---

## 7. 性能优化

| 优化项 | 实现方式 |
|--------|---------|
| 搜索触发 | 输入回车 / 点击搜索触发查询 |
| 分页查询 | 后端分页，前端仅当前页渲染 |
| 购买 loading | 单卡片 loading 防重复点击 |
| 销售统计抽屉 | 打开时按需加载 |
