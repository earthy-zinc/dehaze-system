# 套餐管理模块 - 前端实现设计

## 1. 文档概述

本文档描述套餐管理模块的前端实现方案，聚焦组件架构、状态管理、数据流等架构决策。

## 2. 组件架构设计

### 2.1 用户端套餐展示组件

```
套餐展示页面 (PackageList/index.vue)
├── 促销横幅 (PromotionBanner)
│   └── 可关闭的活动信息
├── 套餐卡片列表 (PackageCards)
│   └── 套餐卡片 (PackageCard)
│       ├── 等级图标与名称
│       ├── 价格区域（促销价+原价删除线）
│       ├── 日均价格
│       ├── 核心权益
│       └── 按钮区域（续费/升级至此）
└── 权益对比表 (BenefitsCompare)
    └── 各等级权益对比表格
```

### 2.2 套餐详情组件

```
套餐详情页面 (PackageDetail/index.vue)
├── 套餐信息卡片
│   ├── 基本信息
│   ├── 价格明细
│   └── 权益列表
└── 底部购买栏
    ├── 实付金额
    ├── 优惠券选择
    └── 立即购买按钮
```

### 2.3 优惠券模块组件

```
我的优惠券 (MyCoupons/index.vue)
├── 状态标签页 (StatusTabs)
│   └── 未使用/已使用/已过期
└── 优惠券卡片列表
    └── 优惠券卡片 (CouponCard)

优惠券领取中心 (CouponCenter/index.vue)
└── 可领取优惠券列表
```

### 2.4 后台管理组件结构

```
套餐管理页面 (PackageManagement/index.vue)
├── 搜索容器
└── 数据展示区域
    ├── 套餐表格 (PackageTable)
    └── 分页组件

弹窗组件 (PackageDialog)
├── 套餐表单弹窗 (PackageFormDialog)
└── 上下架确认弹窗 (StatusConfirmDialog)

促销管理页面 (PromotionManagement/index.vue)
└── 促销活动表格

优惠券管理页面 (CouponManagement/index.vue)
├── 优惠券模板表格
└── 发放记录弹窗 (DistributeDialog)
```

### 2.5 组件职责划分

| 组件名称 | 职责描述 | 复用性 |
|---------|---------|--------|
| **PackageCard** | 套餐卡片，展示价格与权益 | 用户端专用 |
| **BenefitsCompare** | 权益对比表，跨等级对比 | 用户端专用 |
| **CouponCard** | 优惠券卡片，含使用按钮 | 用户端专用 |
| **PackageFormDialog** | 套餐表单弹窗 | 后台专用 |
| **CouponDistributeDialog** | 优惠券发放弹窗 | 后台专用 |

## 3. 组件详细设计

### 3.1 套餐卡片组件

#### 组件属性

| 属性 | 类型 | 说明 |
|------|------|------|
| package | Object | 套餐数据 |
| currentLevel | String | 当前用户等级（用于按钮文案） |
| promotions | Array | 进行中的促销活动 |

#### 按钮文案逻辑

| 用户当前等级 | 套餐等级 | 按钮文案 |
|-------------|---------|---------|
| level_0 | level_1 | 立即开通 |
| level_0 | level_2/3 | 立即开通 |
| level_1 | level_1 | 续费 |
| level_1 | level_2/3 | 升级至此 |
| level_2 | level_1/2 | 续费 |
| level_2 | level_3 | 升级至此 |

#### 价格展示逻辑

- 显示促销价（大字号）
- 原价加删除线（小字号灰色）
- 显示日均价格（"¥0.26/天"）

### 3.2 权益对比表组件

| 月度评估次数 | 1 | 20 | 80 | 不限 |
| 历史保留 | 7天 | 30天 | 90天 | 永久 |
| 批量上限 | 1 | 5 | 20 | 50 |
| 高级参数 | × | × | ✓ | ✓ |
| 高清导出 | × | × | ✓ | ✓ |
| 对比报告 | × | × | × | ✓ |
| 批量下载 | × | × | × | ✓ |

当前等级列高亮显示。

### 3.3 优惠券卡片组件

#### 状态展示

| 状态 | 样式 |
|------|------|
| 未使用 | 彩色卡片，面值突出 |
| 已使用 | 灰色，左上角"已使用"印章 |
| 已过期 | 灰色，左上角"已过期"印章 |
| 已锁定 | 灰色，提示"订单使用中" |

#### 卡片内容

- 左侧：面值（满减/无门槛显示"¥X"，折扣显示"X折"）

### 3.4 套餐表单弹窗（后台）

| 属性 | 新增模式 | 编辑模式 |
|------|---------|---------|
| 标题 | 新增套餐 | 修改套餐 |
| 宽度 | 800px | 800px |

#### 表单字段

| 字段 | 类型 | 必填 | 校验规则 |
|------|------|------|---------|
| name | 输入框 | ✅ | 2-32字符，唯一 |
| levelCode | 下拉选择 | ✅ | VIP1/VIP2/SVIP |
| period | 下拉选择 | ✅ | 月/季/年 |
| periodDays | 数值输入 | ✅ | 1-365 |
| originalPrice | 价格输入 | ✅ | ≥0，单位元 |
| salePrice | 价格输入 | ✅ | ≤originalPrice |
| description | 文本域 | ❌ | 最多256字符 |
| benefitOverrides | 权益配置区 | ❌ | 复选框+数值输入 |
| sort | 数值输入 | ❌ | ≥0 |
| status | 开关 | ❌ | 默认下架 |

#### 权益覆盖配置区域

- 复选框勾选要覆盖的权益项
- 勾选后展开数值输入框
- 未勾选项使用等级默认值

### 3.5 优惠券发放弹窗

## 5. API 调用设计

### 5.1 API 接口封装

使用 `dehaze-sdk-js` 提供的 PackageAPI：

| 方法 | 功能 | 参数 |
|------|------|------|
| PackageAPI.listOnSale | 在售套餐列表 | - |
| PackageAPI.getDetail | 套餐详情 | id |
| PackageAPI.getPage | 后台分页查询 | queryParams |
| PackageAPI.getForm | 获取表单数据 | id |
| PackageAPI.add | 新增套餐 | formData |
| PackageAPI.update | 修改套餐 | id, formData |
| PackageAPI.deleteByIds | 删除套餐 | ids |
| PackageAPI.updateStatus | 上下架 | id, status |
| PackageAPI.calculatePrice | 价格计算 | packageId, couponId |

### 5.2 优惠券 API

| 方法 | 功能 | 参数 |
|------|------|------|
| CouponAPI.listMy | 我的优惠券 | status |
| CouponAPI.listAvailable | 下单可用券 | packageId |
| CouponAPI.receive | 领取优惠券 | couponId |
| CouponAPI.getPage | 后台分页查询 | queryParams |
| CouponAPI.add | 创建优惠券 | formData |
| CouponAPI.update | 修改优惠券 | id, formData |
| CouponAPI.deleteByIds | 删除优惠券 | ids |
| CouponAPI.batchDistribute | 批量发放 | couponId, userIds |

### 5.3 请求错误处理

| 错误类型 | 处理方式 |
|---------|---------|
| PACKAGE_NOT_FOUND | 提示"套餐不存在" |
| DATA_EXISTS | 提示"套餐名称已存在" |
| PARAM_ERROR | 提示"促销价不能高于原价" |
| PACKAGE_HAS_ORDERS | 提示"已有订单的套餐不可删除" |
| PACKAGE_IN_PROMOTION | 提示"活动期间不允许下架" |
| COUPON_STOCK_EMPTY | 提示"优惠券已领完" |
| COUPON_LIMIT_EXCEEDED | 提示"已达限领数量" |
| COUPON_EXPIRED | 提示"优惠券已过期" |
| COUPON_NOT_APPLICABLE | 提示"优惠券不适用此套餐" |

## 6. 交互流程设计

### 6.1 套餐购买流程

1. 用户进入套餐列表，加载套餐与促销数据
2. 查看权益对比表，选择合适套餐
3. 点击"立即开通"/"续费"/"升级至此"
4. 跳转订单确认页（携带 packageId）
5. 选择优惠券（可选）
6. 调用价格计算接口实时显示实付金额
7. 选择支付方式
8. 提交订单

### 6.2 关键流程说明

| 流程 | 关键点 |
|------|--------|
| 套餐新增 | 填写表单 → 权益覆盖配置 → 价格校验 → 提交 → 刷新列表 |
| 套餐上下架 | 状态切换 → 确认弹窗 → 提交 → 刷新列表 |
| 优惠券领取 | 查询可领券列表 → 点击领取 → 频率限制 → 成功提示 → 刷新列表 |
| 批量发放 | 选择对象 → 确认数量 → 异步发放 → 完成通知 |

## 7. 表单校验设计

### 7.1 套餐表单校验

| 字段 | 规则 | 错误提示 |
|------|------|---------|
| name | 必填，2-32字符 | "请输入2-32字符的套餐名称" |
| periodDays | 必填，1-365 | "有效期天数1-365" |
| originalPrice | 必填，≥0 | "请输入有效原价" |
| salePrice | 必填，≤originalPrice | "促销价不能高于原价" |

### 7.2 价格输入组件

- 输入单位为元，传参单位为分
- 组件内部转换：`元 × 100 = 分`
- 显示保留2位小数

## 9. 性能优化设计

### 9.1 请求优化

| 优化项 | 实现方式 |
|--------|---------|
| 防抖处理 | 搜索输入防抖 300ms |
| 节流处理 | 优惠券领取节流 3000ms |
| 并行请求 | 套餐列表与促销活动并行加载 |
| 请求缓存 | 套餐列表缓存 5 分钟 |

### 9.2 渲染优化

| 优化项 | 实现方式 |
|--------|---------|
| 权益对比表 | 静态配置，无请求 |
| 套餐卡片 | CSS Grid 响应式布局 |
| 优惠券列表 | 虚拟滚动优化大量数据 |
| 骨架屏 | 数据加载时显示骨架屏 |

### 9.3 缓存策略

| 数据类型 | 缓存位置 | 过期策略 |
|---------|---------|---------|
| 套餐列表 | Pinia Store | 5 分钟 |
| 权益对比数据 | 静态配置 | 永久 |
| 用户优惠券 | 组件状态 | 领取/使用时刷新 |
