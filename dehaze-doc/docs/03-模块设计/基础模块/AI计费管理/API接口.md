# AI计费管理模块 - API接口

## 1. 文档概述

本文档定义 **AI计费管理** 模块的 HTTP API 规范，是该模块 API 契约的**唯一权威来源**。

- **基础路径**：`/api/v1/ai-billing`
- **公共约定**：参见 [02-系统架构/04-API规范.md](../../../02-系统架构/04-API规范.md)
- **需求规格**：[需求规格.md](./需求规格.md)

## 2. 接口清单

### 2.1 用户端接口

| 路径 | 方法 | 功能描述 | 权限标识 | 关联功能点 |
|------|------|---------|---------|-----------|
| `/api/v1/ai-billing/balance` | GET | 用户余额查询（返回余额、配额使用情况） | - | F-MB-001, F-MB-005 |
| `/api/v1/ai-billing/records` | GET | 计费明细查询（分页查询自己的计费记录） | - | F-MB-009 |
| `/api/v1/ai-billing/credit-logs` | GET | 流水查询（分页查询余额变动流水） | - | F-MB-001 |
| `/api/v1/ai-billing/bills/{month}` | GET | 账单查询（查询月结账单） | - | F-MB-009 |
| `/api/v1/ai-billing/bills/{month}/download` | GET | 账单下载（下载月结账单） | - | F-MB-009 |
| `/api/v1/ai-billing/refunds` | POST | 退款申请（用户申请误扣退款） | - | F-MB-003 |

### 2.2 管理员接口

| 路径 | 方法 | 功能描述 | 权限标识 | 关联功能点 |
|------|------|---------|---------|-----------|
| `/api/v1/ai-billing/stats` | GET | 管理员统计查询（按多维度统计） | ai:billing:stat | F-MB-009 |
| `/api/v1/ai-billing/adjust` | POST | 管理员手动调整（手动调整用户积分） | ai:billing:adjust | F-MB-002 |
| `/api/v1/ai-billing/refunds/{id}/audit` | POST | 管理员退款审核（审核退款申请） | ai:billing:refund | F-MB-003 |

## 3. 权限标识汇总

| 权限标识 | 说明 |
|---------|------|
| ai:billing:stat | 管理员计费统计查询 |
| ai:billing:adjust | 管理员手动调整用户积分 |
| ai:billing:refund | 管理员退款审核 |

> 用户侧查询接口（余额/计费明细/流水/账单查询/账单下载/退款申请）均为登录态访问，仅可查询/操作本人数据。积分充值走订单管理模块，不在本模块定义。

## 4. 业务错误码

| 错误码 | 说明 | 触发场景 |
|--------|------|---------|
| A0401 | 资源不存在 | 账单/计费记录不存在 |
| A0403 | 无权限 | 访问他人余额/账单/记录 |
| A0503 | 配额不足/欠费熔断 | 配额超限或欠费状态调用 AI 能力 |
| A0700 | 退款申请已存在 | 同一计费记录重复申请退款 |
| A0701 | 退款审核失败 | 原计费记录已退款或不存在 |
