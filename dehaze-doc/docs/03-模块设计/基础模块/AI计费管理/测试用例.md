# AI 计费管理模块测试用例

## 1. 测试目标

- [x] 验证积分计量换算正确性（Token->credits，按模型计费比例，含缓存折扣、降级计费、bill_type 分离、子智能体计费）
- [x] 验证积分余额账户（余额扣减/回补、余额 vs 限额、积分卡到账/VIP 赠送/试用/管理员调整/退款回退/误扣补偿）
- [x] 验证配额管理的原子性和准确性（预扣+实扣+退差额、日/月限额、并发不超扣）
- [x] 验证计费预估算法的合理性
- [x] 验证异常检测规则的触发与告警
- [x] 验证成本核算与毛利口径（收入=订单实收、成本=Σcost、毛利预警、成本数据权限隔离）
- [x] 验证计费查询与管理 API（余额查询、计费明细（含申诉状态）、消耗汇总、异常清单、退款申请/审核、管理员调整）
- [x] 覆盖正常流程、边界条件、异常分支

---

## 2. 测试前置

### 2.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **VIP 等级用户** | 4 个测试用户（普通/VIP1/VIP2/SVIP），前缀 `test_billing_` | 各等级已分配对应日/月限额 |
| **模型配置数据** | 3 个模型（含不同输入/输出/缓存计费比例，含降级链配置） | 用于计费比例与降级计费测试 |
| **配额初始值** | 按测试用例需要预置日/月配额已用值 | 每次测试前设置初始值 |
| **订单履约调用数据** | 模拟订单管理同事务触发的到账/回退调用（含订单号、credit_amount、未消耗积分） | 用于积分卡到账/回退履约测试 |

### 2.2 数据清理策略

- 测试用户前缀 `test_billing_` 标识，测试结束后按前缀清理计费记录与配额缓存
- 不退还不清理配额（数据由定时任务处理）
- 测试消息在测试结束后级联删除

### 2.3 测试范围

**包含的功能点：**
- F-MB-001：积分余额账户（余额扣减/回补、余额 vs 限额）
- F-MB-002：积分来源与到账（积分卡到账/VIP 赠送/试用/管理员调整）
- F-MB-003：积分回退与补偿（积分卡退款回退、误扣补偿）
- F-MB-004：积分计量（基本换算、高峰/空闲时段定价、缓存折扣、降级计费、bill_type 分离、子智能体计费）
- F-MB-005：配额管理（日/月限额、预扣实扣、差额退补、并发扣减、配额重置、配额不足三分支）
- F-MB-006：计费预估
- F-MB-007：异常检测与告警
- F-MB-009：计费记录与统计（余额查询、计费明细、账单、退款 API）
- F-MB-010：模型调用成本管理（成本单价管理、成本核算、成本-利润分析、供应商账单对账）

**不包含的功能点：**
- 积分卡商品定义与定价（属套餐管理模块）
- 积分卡购买支付流程与退款审核（属订单管理模块）
- VIP 配额字段的配置管理界面（属会员管理模块权益配置）
