# 认证管理模块需求规格

## 1. 模块概述

### 1.1 模块定位

认证管理模块是图像去雾系统后台管理系统的安全入口模块，负责用户身份认证、会话管理和访问控制。该模块通过用户名密码验证、图形验证码校验、JWT Token 生成与验证等机制，确保系统访问的安全性，是整个系统安全体系的第一道防线。

### 1.2 核心价值

| 价值维度 | 具体内容 |
|---------|---------|
| **身份验证** | 提供安全可靠的用户登录认证机制，防止未授权访问 |
| **会话管理** | 基于 JWT Token 实现无状态会话管理，支持分布式部署 |
| **安全防护** | 集成图形验证码、Token 黑名单等多重安全机制 |
| **登录审计** | 记录用户登录行为，支持安全事件追溯 |

### 1.3 业务目标

#### 功能目标
- 实现基于用户名密码的安全登录认证
- 提供图形验证码生成与校验能力
- 支持用户注销及 Token 失效处理
- 记录登录日志，支持安全审计
- 提供 API Key 长期凭证的创建、查询与吊销能力，支持机器对机器调用

#### 性能目标
| 指标 | 目标值 | 说明 |
|------|--------|------|
| **登录响应** | &lt;1s | 完整登录流程（含认证+Token生成）响应时间 |
| **验证码生成** | &lt;200ms | 图形验证码生成响应时间 |
| **Token验证** | &lt;50ms | 每次请求的 Token 校验时间 |
| **并发登录** | ≥100 QPS | 登录接口支持的并发处理能力 |

## 3. 功能需求

### 3.1 用户登录 (F-AM-001)

#### 3.1.1 功能描述

提供基于用户名密码的登录认证功能，支持图形验证码校验，登录成功后返回 JWT Token。

#### 3.1.2 输入参数

| 字段 | 显示名称 | 类型 | 必填 | 校验规则 |
|------|---------|------|------|---------|
| username | 用户名 | 输入框 | ✅ | 不能为空 |
| password | 密码 | 输入框 | ✅ | 不能为空 |
| captchaKey | 验证码Key | 隐藏域 | ✅ | 从验证码接口获取，通过 HTTP 请求参数传递，在 Filter 层校验 |
| captchaCode | 验证码 | 输入框 | ✅ | 不区分大小写，通过 HTTP 请求参数传递，在 Filter 层校验 |

#### 3.1.3 输出结果

| 字段 | 说明 |
|------|------|
| tokenType | Token 类型，固定值 "Bearer" |
| accessToken | JWT 访问令牌 |
| expires | Token 有效期（毫秒，预留字段） |
| refreshToken | 刷新令牌（预留字段） |

#### 3.1.4 业务规则

1. **用户名校验**：登录时用户名自动转换为小写并去除首尾空格
2. **密码验证**：使用 BCrypt 算法验证密码哈希值
3. **验证码校验**：验证码必须正确且未过期
4. **用户状态检查**：禁用状态的用户无法登录
5. **登录日志记录**：记录登录成功/失败事件
6. **Token 生成**：登录成功后生成包含用户 ID、角色信息的 JWT Token

#### 3.1.5 错误处理

| 场景 | 错误提示 |
|------|---------|
| 用户名不存在 | 用户名或密码错误 |
| 密码错误 | 用户名或密码错误（统一提示） |
| 验证码错误 | 验证码错误 |
| 验证码过期 | 验证码已过期，请重新获取 |
| 用户已禁用 | 账户已被禁用，请联系管理员 |

---

### 3.2 用户注销 (F-AM-002)

#### 3.2.1 功能描述

支持用户主动退出登录，将当前 Token 加入黑名单，使其失效。

#### 3.2.2 操作流程

点击退出登录 → 调用注销接口 → Token 加入黑名单 → 清空本地存储 → 跳转至登录页

#### 3.2.3 业务规则

1. **Token 黑名单**：将当前 JWT ID（jti）加入 Redis 黑名单
2. **黑名单过期**：黑名单记录随 Token 原始过期时间自动清理
3. **即时失效**：注销后 Token 立即失效，无法再访问受保护资源
4. **上下文清理**：清空 Spring Security 上下文
5. **日志记录**：记录用户主动登出事件

---

### 3.3 获取验证码 (F-AM-003)

#### 3.3.1 功能描述

生成图形验证码并返回 Base64 编码的图片数据，用于登录时的人机识别。

#### 3.3.2 验证码类型

| 类型 | 显示名称 | 说明 |
|------|---------|------|
| LINE | 线段干扰 | 基础线条干扰验证码 |
| CIRCLE | 圆圈干扰 | 圆圈干扰验证码 |
| SHEAR | 扭曲干扰 | 文字扭曲验证码 |
| GIF | 动态验证码 | GIF 动态验证码 |

#### 3.3.3 输出结果

| 字段 | 说明 |
|------|------|
| captchaKey | 验证码唯一标识，登录时需提交 |
| captchaBase64 | 验证码图片的 Base64 编码数据 |

#### 3.3.4 业务规则

1. **验证码缓存**：验证码文本存储在 Redis，默认有效期 5 分钟
2. **一次有效**：验证码校验成功后立即失效
3. **随机生成**：验证码字符随机生成，支持配置长度和字符集
4. **图片配置**：支持配置图片宽度、高度、干扰元素数量

---

### 3.4 刷新令牌 (F-AM-004)

#### 3.4.1 功能描述

使用刷新令牌获取新的访问令牌，延长用户会话有效期。

#### 3.4.2 输入参数

| 字段 | 说明 |
|------|------|
| refreshToken | 刷新令牌 |

#### 3.4.3 业务规则

1. **刷新令牌验证**：验证刷新令牌的有效性
2. **新 Token 生成**：生成新的访问令牌和刷新令牌
3. **旧 Token 失效**：刷新后原访问令牌失效
4. **刷新限制**：单次刷新后原刷新令牌失效（防止重复刷新）

---

### 3.5 获取权限信息 (F-AM-005)

#### 3.5.1 功能描述

获取当前登录用户的权限信息，包括用户基本信息、角色列表和菜单权限。

#### 3.5.2 输出结果

| 字段 | 说明 |
|------|------|
| user | 用户基本信息（ID、用户名、昵称等） |
| roles | 角色列表（仅启用状态的角色） |
| perms | 权限标识列表 |
| menus | 菜单树（前端路由渲染使用） |

#### 3.5.3 业务规则

1. **角色过滤**：自动过滤禁用状态的角色
2. **菜单过滤**：自动过滤禁用状态的菜单
3. **权限计算**：基于用户角色计算所有权限标识

---

### 3.6 创建 API Key (F-AM-006)

#### 3.6.1 功能描述

为当前登录用户创建一个长期身份凭证（API Key），用于脚本调用、定时任务、第三方系统集成等机器对机器场景。API Key 默认永不过期，可选设置过期时间。

#### 3.6.2 输入参数

| 字段 | 显示名称 | 类型 | 必填 | 校验规则 |
|------|---------|------|------|---------|
| name | 名称 | 输入框 | ✅ | 不能为空，用于标识 Key 用途 |
| expiresAt | 过期时间 | 日期时间 | ❌ | ISO 日期时间格式；不传则默认永不过期 |

#### 3.6.3 输出结果

| 字段 | 说明 |
|------|------|
| id | API Key 唯一标识 |
| name | API Key 名称 |
| apiKey | API Key 明文（前缀 `dhak_`，仅创建时返回一次） |
| expiresAt | 过期时间（未设置时为空，表示永不过期） |
| createTime | 创建时间 |

#### 3.6.4 业务规则

1. **凭证生成**：生成带 `dhak_` 前缀的随机字符串作为 API Key 明文
2. **哈希存储**：服务端仅存储 API Key 的 SHA-256 哈希值，不存储明文
3. **明文仅展示一次**：明文仅在创建成功响应中返回一次，之后无法再查询
4. **归属绑定**：API Key 绑定到创建者，记录所属用户 ID
5. **过期时间**：`expiresAt` 可选，未设置时默认永不过期

#### 3.6.5 错误处理

| 场景 | 错误提示 |
|------|---------|
| 缺少名称 | 用户请求参数错误 |
| 未登录 | 访问未授权 |

---

### 3.7 查询 API Key 列表 (F-AM-007)

#### 3.7.1 功能描述

查询当前登录用户创建的全部 API Key，用于查看和管理已有凭证。

#### 3.7.2 输出结果

| 字段 | 说明 |
|------|------|
| id | API Key 唯一标识 |
| name | API Key 名称 |
| keyPrefix | API Key 前缀（仅用于辨识，不含明文） |
| expiresAt | 过期时间（永不过期时为空） |
| createTime | 创建时间 |

#### 3.7.3 业务规则

1. **归属隔离**：仅返回当前登录用户创建的 API Key
2. **明文脱敏**：列表仅返回 Key 前缀，不返回明文
3. **过期标识**：可根据 `expiresAt` 判断 Key 是否已过期

---

### 3.8 删除/吊销 API Key (F-AM-008)

#### 3.8.1 功能描述

删除（吊销）当前登录用户指定的 API Key，删除后该 Key 立即失效。

#### 3.8.2 输入参数

| 字段 | 显示名称 | 类型 | 必填 | 校验规则 |
|------|---------|------|------|---------|
| id | API Key ID | 路径参数 | ✅ | 必须存在且属于当前用户 |

#### 3.8.3 业务规则

1. **归属校验**：仅允许删除当前用户自己创建的 API Key
2. **立即失效**：删除后该 Key 立即失效，后续使用该 Key 的请求被拒绝
3. **不可恢复**：删除操作不可恢复，需重新创建新 Key

#### 3.8.4 错误处理

| 场景 | 错误提示 |
|------|---------|
| Key 不存在或不属于当前用户 | 请求资源不存在 |
| 未登录 | 访问未授权 |

## 5. 安全设计

### 5.1 认证安全

| 安全措施 | 说明 |
|---------|------|
| **密码加密** | 使用 BCrypt 算法加密存储，每次加盐 |
| **Token 签名** | JWT Token 使用密钥签名，防止篡改 |
| **Token 有效期** | 访问令牌默认有效期 2 小时（可配置） |
| **黑名单机制** | 注销后将 Token 加入 Redis 黑名单 |
| **验证码防护** | 登录时强制校验图形验证码 |
| **API Key 安全** | 明文仅创建时展示一次，服务端以 SHA-256 哈希存储，支持随时吊销 |

### 5.2 输入校验

| 校验类型 | 说明 |
|---------|------|
| **前端校验** | 表单非空校验、格式校验 |
| **后端校验** | Validation 注解进行参数校验 |
| **密码强度** | 建议密码长度不少于 6 位（待确认） |
| **防暴力破解** | 建议增加登录失败次数限制（待确认） |

### 5.3 传输安全

| 安全措施 | 说明 |
|---------|------|
| **HTTPS 传输** | 生产环境强制使用 HTTPS |
| **敏感数据** | 密码等敏感信息不记录日志 |

### 5.4 会话安全

> 详细安全设计参见 [02-系统架构/安全架构文档.md](../../../02-系统架构/01-总体架构设计.md)（待补充）

| 安全措施 | 说明 |
|---------|------|
| **无状态会话** | 基于 JWT Token，服务端不存储会话状态 |
| **Token 携带** | Token 通过 HTTP Header 传递（Authorization: Bearer {token}） |
| **Token 存储** | 前端建议存储在内存中，避免 XSS 风险 |
| **自动刷新** | Token 过期前 5 分钟自动刷新（前端实现） |

## 7. 待确认事项

1. **密码强度策略**：是否强制要求密码复杂度（长度、字符类型）？
2. **登录失败限制**：是否需要增加登录失败次数限制和账户锁定机制？
3. **验证码开关**：是否允许配置验证码是否启用？
4. **Token 有效期**：访问令牌和刷新令牌的有效期配置值？
5. **并发登录控制**：是否限制同一账户的并发登录数量？
6. **记住密码功能**：是否需要"记住密码"功能（前端持久化 Token）？
7. **登录日志查看**：是否需要提供用户登录日志查看功能？
8. **第三方登录**：是否需要支持微信、钉钉等第三方登录方式？
9. **多因子认证**：是否需要支持 MFA 多因子认证（如短信验证码 + 密码）？
10. **单点登录（SSO）**：是否需要集成 SSO 单点登录？
