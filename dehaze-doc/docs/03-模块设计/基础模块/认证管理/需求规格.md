# 认证管理模块需求规格

## 1. 模块概述

### 1.1 模块定位

认证管理模块是平台的安全入口模块，负责用户身份认证、会话管理、访问控制与登录审计。通过用户名密码验证、图形验证码校验、会话管理、API Key 凭证等机制保障系统访问安全，覆盖 Web（Vue/React）、Android、Flutter、Taro/UniApp 小程序、Electron 桌面端等多端。

> **三后端契约**：Java/Go/Python 三后端 API 契约完全一致，Java 为权威来源，Go/Python 对齐。本文档所述功能需求与接口契约三端共同遵守。

### 1.3 业务目标

#### 性能目标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| **登录响应** | &lt;1s | 完整登录流程（含认证+会话创建）响应时间 |
| **验证码生成** | &lt;200ms | 图形验证码生成响应时间 |
| **会话验证** | &lt;50ms | 每次请求的会话校验时间 |
| **并发登录** | ≥100 QPS | 单后端指标，Java/Go/Python 三后端独立可达 |

## 3. 功能需求

### 3.1 用户登录 (F-AM-001)

#### 3.1.1 功能描述

提供基于用户名密码的登录认证功能，支持图形验证码校验与登录失败锁定，登录成功后按设备类型创建独立会话。

#### 3.1.2 输入参数

| 字段 | 显示名称 | 类型 | 必填 | 校验规则 |
|------|---------|------|------|---------|
| username | 用户名 | 输入框 | ✅ | 不能为空 |
| password | 密码 | 输入框 | ✅ | 不能为空 |
| captchaKey | 验证码Key | 隐藏域 | ✅ | 从验证码接口获取，与验证码一同提交校验 |
| captchaCode | 验证码 | 输入框 | ✅ | 不区分大小写 |
| rememberMe | 记住我 | 复选框 | ❌ | 勾选后延长登录状态保持时间 |
| deviceType | 设备类型 | 隐藏域 | ❌ | 标识登录端类型，用于多端会话隔离，默认 `web` |

**deviceType 枚举**：`web`（Web Vue/React、Electron 桌面端）、`android`、`flutter`、`miniprogram`（Taro/UniApp 小程序）。

#### 3.1.3 输出结果

| 字段 | 说明 |
|------|------|
| sessionId | 会话标识 |
| user | 用户信息（id、username、nickname） |

#### 3.1.4 业务规则

1. **用户名校验**：登录时用户名自动转换为小写并去除首尾空格
2. **验证码校验**：验证码必须正确且未过期，校验后立即失效
3. **用户状态检查**：禁用状态、已逻辑删除的用户无法登录
4. **登录失败锁定**：同一用户名连续 5 次登录失败锁定 30 分钟，锁定期内拒绝登录（含正确密码）；中途成功登录则失败计数清零；非凭证类异常（如服务不可用）不计入失败次数
5. **会话生成**：登录成功后生成会话，承载用户身份与权限信息
6. **登录日志记录**：记录登录成功/失败事件（用户名、IP、时间、状态、deviceType）

#### 3.1.5 错误处理

| 场景 | 错误提示 |
|------|---------|
| 用户名不存在 | 用户名或密码错误 |
| 密码错误 | 用户名或密码错误（统一提示） |
| 验证码错误 | 验证码错误 |
| 验证码过期 | 验证码已过期，请重新获取 |
| 用户已禁用 | 账户已被禁用，请联系管理员 |
| 账户已锁定 | 账户已被锁定，请30分钟后再试 |

### 3.2 用户注销 (F-AM-002)

#### 3.2.1 功能描述

支持用户主动退出登录，删除当前端会话，使其失效。

#### 3.2.2 操作流程

点击退出登录 → 调用注销接口 → 删除服务端当前会话数据 → 清空本地登录凭证 → 跳转至登录页

#### 3.2.3 业务规则

1. **会话删除**：仅删除当前端会话对应的服务端会话数据，不影响该账号其他端的在线会话
2. **即时失效**：注销后会话立即失效，无法再访问受保护资源
3. **日志记录**：记录用户主动登出事件

### 3.3 获取验证码 (F-AM-003)

#### 3.3.1 功能描述

生成图形验证码并返回 Base64 编码的图片数据，用于登录与注册时的人机识别。

#### 3.3.2 验证码类型

| 类型 | 显示名称 | 说明 |
|------|---------|------|
| LINE | 线段干扰 | 基础线条干扰验证码 |
| CIRCLE | 圆圈干扰 | 圆圈干扰验证码 |
| SHEAR | 扭曲干扰 | 文字扭曲验证码 |
| GIF | 动态验证码 | GIF 动态验证码 |

#### 3.3.3 输出结果

| 字段 | 说明 |
|------|------|
| captchaKey | 验证码唯一标识，登录/注册时需提交 |
| captchaBase64 | 验证码图片的 Base64 编码数据 |

#### 3.3.4 业务规则

1. **随机生成**：验证码字符随机生成，支持配置长度和字符集
2. **图片配置**：支持配置图片宽度、高度、干扰元素数量
3. **验证码开关**：支持通过系统配置 `captcha.enabled` 控制是否启用验证码，默认启用
4. **一次性有效**：校验通过后立即失效，不可重复使用

### 3.5 创建 API Key (F-AM-006)

#### 3.5.1 功能描述

为当前登录用户创建一个长期身份凭证（API Key），用于脚本调用、定时任务、第三方系统集成等机器对机器场景。API Key 默认永不过期，可选设置过期时间。

#### 3.5.2 输入参数

| 字段 | 显示名称 | 类型 | 必填 | 校验规则 |
|------|---------|------|------|---------|
| name | 名称 | 输入框 | ✅ | 不能为空，用于标识 Key 用途 |
| expiresAt | 过期时间 | 日期时间 | ❌ | ISO 日期时间格式；不传则默认永不过期 |

#### 3.5.3 输出结果

| 字段 | 说明 |
|------|------|
| id | API Key 唯一标识 |
| name | API Key 名称 |
| apiKey | API Key 明文（前缀 `dhak_`，仅创建时返回一次） |
| expiresAt | 过期时间（未设置时为空，表示永不过期） |
| createTime | 创建时间 |

#### 3.5.4 业务规则

1. **凭证生成**：生成带固定前缀 `dhak_` 的随机字符串作为 API Key 明文
2. **归属绑定**：API Key 绑定到创建者，记录所属用户 ID
3. **过期时间**：`expiresAt` 可选，未设置时默认永不过期

#### 3.5.5 API Key 与计费/配额关系

1. **配额限制**：API Key 调用 AI 能力受所属用户的 VIP 配额限制，与 AI 计费管理模块挂钩
2. **积分计量**：API Key 调用 AI 能力按积分计量，扣减所属用户配额；普通用户与 VIP1/VIP2/SVIP 配额规则与会员管理模块一致
3. **凭证优先级**：API Key 与会话凭证并存时，以 API Key 优先（机器调用场景）

#### 3.5.6 错误处理

| 场景 | 错误提示 |
|------|---------|
| 缺少名称 | 用户请求参数错误 |
| 未登录 | 访问未授权 |

#### 3.7.1 功能描述

删除（吊销）当前登录用户指定的 API Key，删除后该 Key 立即失效。

#### 3.7.2 输入参数

| 字段 | 显示名称 | 类型 | 必填 | 校验规则 |
|------|---------|------|------|---------|

#### 3.7.4 错误处理

|------|---------|
| Key 不存在或不属于当前用户 | 请求资源不存在 |
| 未登录 | 访问未授权 |

### 3.8 用户注册 (F-AM-009)

#### 3.8.1 功能描述

提供用户自注册功能，用户通过用户名、密码、昵称和验证码完成注册，注册成功后自动登录系统。

> **职责边界**：认证管理负责注册流程（表单提交、验证码校验、创建用户记录、自动登录）；用户的全生命周期管理（查询/编辑/禁用/删除/分配角色）由用户管理模块负责。

#### 3.8.2 输入参数

| 字段 | 显示名称 | 类型 | 必填 | 校验规则 |
|------|---------|------|------|---------|
| username | 用户名 | 输入框 | ✅ | 3-32 位，仅字母、数字、下划线，不区分大小写 |
| password | 密码 | 密码框 | ✅ | 8-20 位，至少包含字母和数字 |
| nickname | 昵称 | 输入框 | ✅ | 1-64 位，不允许纯空格 |
| captchaKey | 验证码Key | 隐藏域 | ✅ | 从验证码接口获取 |
| captchaCode | 验证码 | 输入框 | ✅ | 不区分大小写 |

#### 3.8.3 输出结果

与登录响应一致，返回 `sessionId` 和 `user` 基本信息，同时写入会话凭证。

#### 3.8.4 业务规则

1. **验证码校验**：验证码必须正确且未过期，使用后立即失效
2. **用户名唯一**：用户名不区分大小写，全局唯一
3. **默认角色**：自动分配访客角色（`guest`，仅可见自己的数据）
4. **默认状态**：启用，注册后可立即使用
5. **自动登录**：注册成功后直接创建会话，无需再次登录
6. **IP 限流**：60 秒内最多 10 次注册请求/IP

#### 3.8.5 错误处理

| 场景 | 错误提示 |
|------|---------|
| 用户名已存在 | 用户名已被注册 |
| 验证码错误 | 验证码错误 |
| 验证码过期 | 验证码已过期，请重新获取 |
| 密码强度不足 | 密码必须包含字母和数字，8-20位 |
| 用户名格式错误 | 用户名只能包含字母、数字、下划线，3-32位 |
| 请求过于频繁 | 注册请求过于频繁，请60秒后再试 |

### 3.9 登录日志查询 (F-AM-010)

#### 3.9.1 功能描述

提供登录日志的查询、筛选与导出能力，支持管理员查看全量登录日志、普通用户查看本人登录日志，用于安全审计与事件追溯。

#### 3.9.2 查询条件

| 条件类型 | 字段 | 说明 | 匹配方式 |
|---------|------|------|---------|
| **用户名** | username | 精确/模糊匹配 | LIKE |
| **时间范围** | loginTime | 开始时间~结束时间 | BETWEEN |
| **IP 地址** | ip | 精确匹配 | = |
| **登录状态** | status | 成功/失败 | = |
| **设备类型** | deviceType | web/android/flutter/miniprogram | = |

#### 3.9.3 列表展示字段

| 字段 | 显示名称 | 说明 |
|------|---------|------|
| username | 用户名 | 登录账号 |
| ip | IP 地址 | 登录来源 IP |
| loginTime | 登录时间 | 登录发生时间 |
| status | 状态 | 成功/失败标签 |
| message | 提示信息 | 失败原因等 |
| deviceType | 设备类型 | 登录端类型 |

#### 3.9.4 业务规则

1. **数据权限**：管理员可查看全量日志；普通用户仅可查看本人日志
2. **导出**：支持按当前筛选条件导出 Excel
3. **保留策略**：登录日志保留 180 天，超期归档

### 3.10 多端会话管理 (F-AM-011)

#### 3.10.1 功能描述

提供在线会话查询与踢出能力，管理员可查看指定用户的在线会话列表，并手动踢出指定会话。

#### 3.10.2 查询在线会话

| 输入字段 | 说明 |
|---------|------|
| username | 用户名（精确匹配） |

**输出字段**：

| 字段 | 说明 |
|------|------|
| sessionId | 会话标识 |
| deviceType | 设备类型 |
| loginTime | 登录时间 |
| ip | 登录 IP |
| lastAccessTime | 最后访问时间 |

#### 3.10.3 踢出会话

| 输入字段 | 说明 |
|---------|------|
| sessionId | 待踢出的会话标识 |

#### 3.10.4 业务规则

1. **多端共存**：同一账号多端会话互不踢出，登录时不删除其他端会话，各端会话按 deviceType 区分
2. **踢出生效**：踢出后目标会话立即失效，被踢端下次访问被拒绝
3. **权限控制**：仅具备 `sys:auth:session:kick` 权限的管理员可踢出会话

## 5. 安全设计

### 5.1 认证安全

| 安全措施 | 说明 |
|---------|------|
| **密码安全** | 密码不可明文存储，验证时不可逆比对 |
| **API Key 安全** | 明文仅创建时返回一次，服务端不保存明文，支持随时吊销 |

### 5.2 输入校验与密码策略

| 校验类型 | 说明 |
|---------|------|
| **密码强度** | 8-20 位且必须包含字母和数字（注册与登录一致） |
| **首次登录强制改密** | 管理员创建/导入的用户使用系统默认密码（`default_password` 可配置），首次登录强制修改密码；自注册用户已自行设置密码，不强制改密 |

### 5.3 传输安全

| 安全措施 | 说明 |
|---------|------|
| **传输加密** | 生产环境需加密传输 |
| **敏感数据** | 密码等敏感信息不记录日志 |

### 5.4 会话安全

| 安全措施 | 说明 |
|---------|------|
| **会话标识保护** | 会话标识不可被前端脚本读取，也不在前端持久化存储 |
| **会话时效** | 默认 7 天，剩余不足 24 小时自动续期；连续 7 天无操作自然失效 |
| **会话强制失效** | 管理员可踢出指定会话，被踢端立即下线；超级管理员会话不可被踢出 |

## 6. 多端需求

| 端 | 会话传递 | deviceType | 说明 |
|----|---------|-----------|------|
| **Web Vue** | Cookie（X-Session-Id） | `web` | 自动携带 Cookie |
| **Web React** | Cookie（X-Session-Id） | `web` | 自动携带 Cookie |
| **Electron 桌面端** | Cookie / 请求头 | `web` | 基于 React，复用 Web 会话 |
| **Android 原生** | 请求头 X-Session-Id | `android` | 手动设置请求头 |
| **Flutter** | 请求头 X-Session-Id | `flutter` | 手动设置请求头 |
| **Taro/UniApp 小程序** | 请求头 X-Session-Id | `miniprogram` | 手动设置请求头 |

**会话隔离**：各端会话独立，互不影响；同账号在不同端登录生成不同 sessionId，均有效。**权限申请**：各端登录后获取的权限信息一致，前端按端能力渲染菜单与按钮。
