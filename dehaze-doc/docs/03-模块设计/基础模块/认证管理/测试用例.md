# 认证管理模块测试用例

## 1. 测试目标

验证认证管理模块的核心功能符合 [需求规格.md](./需求规格.md) 定义：

- **认证与会话**：用户登录（F-AM-001）、用户注销（F-AM-002）、获取验证码（F-AM-003）、获取权限信息（F-AM-005）
- **API Key 管理**：创建（F-AM-006）、查询（F-AM-007）、删除/吊销（F-AM-008）
- **用户注册**：注册并自动登录（F-AM-009）
- **登录审计**：登录日志查询与导出（F-AM-010）
- **多端会话管理**：在线会话查询与踢出（F-AM-011）
- **场景覆盖**：正常流程、边界条件、异常分支、权限控制
- **非功能验证**：暴力破解防护、Session 劫持防护、并发场景、性能指标

---

## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **测试用户** | 启用状态用户、禁用状态用户 | 用于登录测试 |
| **角色数据** | 系统管理员、普通用户角色 | 用于权限获取测试 |
| **菜单数据** | 系统基础菜单树 | 用于权限信息返回测试 |

### 3.2 数据清理策略

- Redis 验证码缓存自动过期清理（5 分钟）
- Redis Session TTL 自动过期清理
- 测试结束后清理测试创建的用户数据

### 3.3 测试范围

**包含的功能点：**
- 用户登录（用户名密码验证、验证码校验、登录失败锁定）
- 用户注册（用户名唯一性、密码强度、验证码校验、自动登录）
- 用户注销（Session 删除）
- 验证码生成与校验
- 权限信息获取
- 登录日志查询
- API Key 管理（创建/查询/删除/吊销）
- 多端会话管理（在线会话查询/踢出）

**不包含的功能点：**
- 用户管理功能（独立测试）
- 角色权限配置（独立测试）
- 操作日志记录（依赖模块测试）

## 5. 关键边界与异常场景

| 场景 | 测试点 | 期望行为 |
|------|--------|---------|
| **多端并发登录** | 同一账号在 Web + 移动端 + 小程序 + 桌面端同时登录 | 多端会话共存（不互踢），各端独立 Session，按 deviceType 区分存储，均有效 |
| **会话踢出** | 管理员踢出指定会话 | 被踢端 Session 立即删除，下次请求返回 401；其他端会话不受影响 |
| **Session 伪造** | 使用无效 Session ID | 返回 TOKEN_INVALID |
| **Session 过期** | 超过 TTL 的 Session | 返回 TOKEN_INVALID |
| **验证码一次性** | 同一验证码使用两次 | 第二次校验失败（校验后立即删除缓存键） |
| **验证码有效期** | 验证码超过 5 分钟 | 返回"验证码已过期" |
| **暴力破解防护** | 连续错误登录 | 5 次失败锁定 30 分钟（三端实现）；非凭证类异常不计入失败次数 |
