## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **测试用户** | 启用状态用户、禁用状态用户 | 用于登录测试 |
| **角色数据** | 系统管理员、普通用户角色 | 用于权限获取测试 |
| **菜单数据** | 系统基础菜单树 | 用于权限信息返回测试 |

### 3.2 数据清理策略

- Redis 验证码缓存自动过期清理（120 秒）
- Redis Session TTL 自动过期清理
- 测试结束后清理测试创建的用户数据

### 3.3 测试范围

**包含的功能点：**
- 用户登录（用户名密码验证、验证码校验）
- 用户注册（用户名唯一性、密码强度、验证码校验、自动登录）
- 用户注销（Session 删除）
- 验证码生成与校验
- 权限信息获取

**不包含的功能点：**
- 用户管理功能（独立测试）
- 角色权限配置（独立测试）
- 操作日志记录（依赖模块测试）

## 5. 关键边界与异常场景

| 场景 | 测试点 | 期望行为 |
|------|--------|---------|
| **并发登录** | 同一账号多处同时登录 | 三端均通过 `use-multi-point` 开关控制（踢旧或保留）；开发环境默认 `false` 允许多端，生产环境 Java 为 `true` 踢旧 |
| **Session 伪造** | 使用无效 Session ID | 返回 TOKEN_INVALID |
| **Session 过期** | 超过 TTL 的 Session | 返回 TOKEN_INVALID |
| **验证码一次性** | 同一验证码使用两次 | 第二次校验失败（代码已实现 `redisTemplate.delete(cacheKey)`，校验后立即删除） |
| **暴力破解防护** | 连续错误登录 | 5 次失败锁定 30 分钟（Java/Go 已实现）；Go 额外支持 IP 纬度计数 |

## 7. 安全性测试

| 测试项 | 验证方式 | 预期结果 |
|--------|---------|---------|
| **密码加密存储** | 查询数据库密码字段 | BCrypt 加密，非明文 |
| **Session 伪造验证** | 使用无效 Session ID | 验证失败，返回 TOKEN_INVALID |
| **Session 失效** | 注销后使用 Session | 请求被拒绝 |
| **验证码防护** | 无验证码登录 | 登录失败或跳过校验（兼容模式） |
| **错误信息脱敏** | 用户名不存在/密码错误 | 统一提示"用户名或密码错误" |
| **HTTPS 传输** | 抓包分析请求 | 敏感信息加密传输 |
| **SQL 注入** | username 参数注入 | 被参数化查询转义 |
| **XSS 攻击** | username 注入脚本 | 输出时编码 |
