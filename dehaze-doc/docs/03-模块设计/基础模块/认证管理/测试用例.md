## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **测试用户** | 启用状态用户、禁用状态用户 | 用于登录测试 |
| **角色数据** | 系统管理员、普通用户角色 | 用于权限获取测试 |
| **菜单数据** | 系统基础菜单树 | 用于权限信息返回测试 |

### 3.2 数据清理策略

- Redis 验证码缓存自动过期清理（120 秒）
- Redis Token 黑名单自动过期清理（Token TTL）
- 测试结束后清理测试创建的用户数据

### 3.3 测试范围

**包含的功能点：**
- 用户登录（用户名密码验证、验证码校验）
- 用户注销（Token 黑名单）
- 验证码生成与校验
- Token 刷新（预留功能）
- 权限信息获取

**不包含的功能点：**
- 用户管理功能（独立测试）
- 角色权限配置（独立测试）
- 操作日志记录（依赖模块测试）

## 5. 关键边界与异常场景

| 场景 | 测试点 | 期望行为 |
|------|--------|---------|
| **并发登录** | 同一账号多处同时登录 | 均可登录成功（当前无并发限制） |
| **Token 签名篡改** | 修改 Token 内容 | 返回 TOKEN_INVALID |
| **Token 过期** | 超过 TTL 的 Token | 返回 TOKEN_EXPIRED |
| **验证码一次性** | 同一验证码使用两次 | 第二次校验失败（依赖实现） |
| **暴力破解防护** | 连续错误登录 | 验证码机制防护，未实现锁定 |

## 6. 性能与并发测试

### 6.1 性能指标

> 性能目标参见 [需求规格.md](./需求规格.md) 第 1.3 节

| 指标 | 目标值 | 测试方法 |
|------|--------|---------|
| **登录响应时间** | &lt;1s | 完整登录流程（含认证+Token生成） |
| **验证码生成响应时间** | &lt;200ms | 验证码接口响应 |
| **Token 验证响应时间** | &lt;50ms | 每次请求的 Token 校验 |
| **注销响应时间** | &lt;200ms | 注销接口响应 |

### 6.2 并发场景

| 场景 | 并发数 | 验证点 |
|------|--------|--------|
| **并发登录** | 100 用户 | 响应时间稳定，无错误 |
| **并发获取验证码** | 50 请求 | 响应时间稳定，验证码唯一 |
| **并发 Token 验证** | 200 请求 | 响应时间 &lt;50ms |

## 7. 安全性测试

| 测试项 | 验证方式 | 预期结果 |
|--------|---------|---------|
| **密码加密存储** | 查询数据库密码字段 | BCrypt 加密，非明文 |
| **Token 签名验证** | 篡改 Token 内容 | 验证失败，返回 TOKEN_INVALID |
| **黑名单机制** | 注销后使用 Token | 请求被拒绝 |
| **验证码防护** | 无验证码登录 | 登录失败或跳过校验（兼容模式） |
| **错误信息脱敏** | 用户名不存在/密码错误 | 统一提示"用户名或密码错误" |
| **HTTPS 传输** | 抓包分析请求 | 敏感信息加密传输 |
| **SQL 注入** | username 参数注入 | 被参数化查询转义 |
| **XSS 攻击** | username 注入脚本 | 输出时编码 |
