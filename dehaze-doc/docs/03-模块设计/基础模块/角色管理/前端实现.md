# 角色管理模块 - 前端实现设计

## 1. 文档概述

本文档描述角色管理模块的前端实现方案，聚焦组件架构、状态管理、权限分配等架构决策。

## 2. 组件架构设计

### 2.1 组件层次结构

```
角色管理页面 (RoleManagement/index.vue)
├── 搜索容器
│   ├── 搜索表单 (SearchForm)
│   │   ├── 角色名称输入框
│   │   ├── 搜索按钮
│   │   └── 重置按钮
│   └── 操作按钮区域 (ActionButtons)
│       └── 新增按钮
└── 数据展示区域
    ├── 角色表格 (RoleTable)
    └── 分页组件 (Pagination)
```

### 2.2 弹窗组件结构

```
弹窗组件 (RoleDialog)
├── 角色表单弹窗 (RoleFormDialog)
│   └── 角色表单 (RoleForm)
│       ├── 角色名称输入框
│       ├── 角色编码输入框
│       ├── 数据权限选择器
│       ├── 状态单选框
│       └── 排序输入框
└── 权限分配弹窗 (PermissionDialog)
    └── 菜单权限树 (MenuTree)
```

### 2.3 组件职责划分

| 组件名称 | 职责描述 | 复用性 |
|---------|---------|--------|
| **SearchForm** | 角色搜索条件输入与提交 | 页面内部组件 |
| **ActionButtons** | 操作按钮区域，统一管理权限控制 | 页面内部组件 |
| **RoleTable** | 角色数据表格展示与行操作 | 页面内部组件 |
| **RoleFormDialog** | 角色新增/编辑表单弹窗 | 页面内部组件 |
| **PermissionDialog** | 权限分配弹窗，菜单树展示 | 页面内部组件 |

## 3. 页面布局设计

### 3.1 整体布局

角色管理页面采用**单栏布局**：

| 区域 | 高度 | 说明 |
|------|------|------|
| **搜索区域** | 自适应 | 搜索表单 + 操作按钮 |
| **表格区域** | 自适应填充 | 角色数据表格 |
| **分页区域** | 固定 | 分页组件 |

## 4. 组件详细设计

### 4.1 搜索表单组件

| 字段 | 类型 | 占位符 | 说明 |
|------|------|--------|------|

|------|------|------|------|
| 搜索 | 主要按钮 | 搜索 | 触发查询，重置到第一页 |

### 4.2 操作按钮区域

#### 按钮配置

| 按钮 | 类型 | 图标 | 权限标识 | 状态控制 |
|------|------|------|---------|---------|
| 新增 | 成功按钮 | + | sys:role:add | - |

### 4.3 角色表格组件

#### 列定义

| 字段 | 列名 | 宽度 | 对齐 | 特殊处理 |
|------|------|------|------|---------|
| - | 选择 | 55px | 居中 | 复选框 |
| name | 角色名称 | 150px | 居中 | - |
| code | 角色编码 | 150px | 居中 | - |
| dataScope | 数据权限 | 120px | 居中 | 字典翻译 |
| status | 状态 | 80px | 居中 | Switch 开关 |
| sort | 排序 | 80px | 居中 | - |

**交互规则**：
- 点击 Switch 开关直接切换状态
- 状态切换需要 `sys:role:edit` 权限

#### 操作列按钮

| 按钮 | 类型 | 图标 | 权限标识 |
|------|------|------|---------|
| 分配权限 | 链接按钮 | 权限 | sys:role:edit |
| 编辑 | 链接按钮 | 编辑 | sys:role:edit |
| 删除 | 链接按钮 | 删除 | sys:role:delete |

### 4.4 角色表单弹窗

| 属性 | 新增模式 | 编辑模式 |
|------|---------|---------|
| 标题 | 新增角色 | 修改角色 |
| 宽度 | 600px | 600px |
| code 字段 | 可编辑 | 只读 |

表单采用单列布局，必填字段标记红色星号。默认值：状态=启用，排序=1，数据权限=本部门。

### 4.5 权限分配弹窗

#### 弹窗配置

| 属性 | 值 |
|------|---|
| 标题 | 分配权限 |
| 宽度 | 600px |
| 关闭按钮 | 显示 |

#### 菜单权限树组件

| 属性 | 说明 |
|------|------|
| 展示方式 | 树形结构 |
| 选择方式 | 复选框，支持父子关联 |
| 父子关系 | 选中父节点自动选中子节点 |
| 数据回显 | 自动勾选角色已有的菜单权限 |

#### 树节点说明

- 菜单节点：显示菜单名称
- 按钮节点：显示按钮名称（权限标识）
- 支持全选/取消全选
- 支持展开/收起所有节点

## 6. API 调用设计

### 6.1 API 接口封装

使用 `dehaze-sdk-js` 提供的 RoleAPI 进行接口调用：

| 方法 | 功能 |
|------|------|
| RoleAPI.getPage | 分页查询角色 |
| RoleAPI.getOptions | 获取角色下拉选项 |
| RoleAPI.add | 新增角色 |
| RoleAPI.getFormData | 获取角色表单数据 |
| RoleAPI.update | 修改角色 |
| RoleAPI.deleteByIds | 删除角色 |
| RoleAPI.updateStatus | 修改角色状态 |
| RoleAPI.getRoleMenuIds | 获取角色菜单ID集合 |
| RoleAPI.assignMenus | 分配菜单权限 |

### 6.2 辅助 API

| 方法 | 功能 | 说明 |
|------|------|------|
| MenuAPI.getTree | 获取菜单树 | 用于权限分配 |

### 6.3 请求错误处理

全局拦截器统一处理 API 请求错误，前端只需关注错误展示。

| 错误类型 | 处理方式 |
|---------|---------|
| 网络错误 | 提示"网络连接失败，请检查网络" |
| 401 未授权 | 跳转登录页 |
| 403 无权限 | 提示"无操作权限" |
| 业务错误 | 提示后端返回的错误信息 |
| 服务器错误 | 提示"服务器异常，请稍后重试" |

## 7. 交互流程设计

### 7.1 页面初始化流程

1. 进入页面，显示加载状态
2. 请求角色分页列表数据
3. 数据加载完成，渲染角色列表

### 7.2 关键流程说明

| 流程 | 关键点 |
|------|--------|
| 角色新增 | 初始化默认值（状态=启用，排序=1，数据权限=本部门）→ 表单校验 → 提交 → 刷新列表 |
| 角色编辑 | 加载详情 → 角色编码只读 → 提交 → 刷新列表 |
| 角色删除 | 确认对话框 → 关联检查 → 删除 → 刷新列表 |
| 状态切换 | Switch 开关 → 调用状态修改接口 → 更新表格 |
| 权限分配 | 并行加载菜单树和已有权限 → 回显 → 勾选 → 保存 |

## 8. 表单校验设计

### 8.1 格式校验规则

| 字段 | 校验规则 | 说明 |
|------|---------|------|
| code | `/^[A-Z_]+$/` | 只能包含大写字母和下划线 |
| sort | `type: 'number'` | 必须为数字类型 |

### 8.2 业务校验规则

角色名称和编码的唯一性校验由后端执行，前端显示后端返回的错误信息。

## 9. 权限控制设计

### 9.1 按钮级权限

使用 `v-hasPerm` 指令控制按钮显示：

| 按钮 | 权限标识 | 无权限时 |
|------|---------|---------|
| 新增按钮 | sys:role:add | 隐藏 |
| 编辑按钮 | sys:role:edit | 隐藏 |
| 删除按钮 | sys:role:delete | 隐藏 |
| 分配权限按钮 | sys:role:edit | 隐藏 |
| 状态切换 | sys:role:edit | 禁用 |

## 10. 用户体验设计

加载状态和操作反馈遵循全局 UI-UX 设计规范。
