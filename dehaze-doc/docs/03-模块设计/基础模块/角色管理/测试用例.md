## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **菜单数据** | 完整的菜单权限树结构 | 用于权限分配测试 |
| **部门数据** | 至少3级部门树结构 | 用于数据权限测试 |
| **用户数据** | 不同角色的用户账户 | 用于角色关联检查测试 |
| **角色数据** | 各状态角色（启用/禁用） | 用于列表查询、状态管理测试 |

### 3.2 数据清理策略

- 测试角色数据使用统一前缀 `test_role_` 标识
- 测试结束后按前缀批量删除测试角色
- 保留系统默认角色（如超级管理员角色）不做删除操作
- 测试后清理角色-菜单关联表数据

### 3.3 测试范围

**包含的功能点：**
- 角色列表查询（分页、搜索）
- 角色新增、编辑、删除
- 状态管理（启用/禁用）
- 菜单权限分配
- 数据权限配置

**不包含的功能点：**
- 菜单管理功能（独立测试）
- 用户角色关联（用户管理模块测试）
- 权限验证中间件（系统架构层测试）

## 5. 关键边界与异常场景

| 场景 | 测试点 | 期望行为 |
|------|--------|---------|
| **角色数量边界** | 系统角色达到1000+ | 列表查询响应时间仍&lt;500ms |
| **并发新增** | 同时新增相同角色编码 | 只有一个成功，另一个提示编码已存在 |
| **并发编辑** | 同一角色被多人同时编辑 | 乐观锁保护，冲突时提示重新加载 |
| **并发权限分配** | 同时为同一角色分配权限 | 最后一个分配操作生效 |
| **缓存一致性** | 修改角色权限后查询 | 缓存立即更新，返回最新权限 |
| **事务完整性** | 菜单分配失败 | 事务回滚，数据保持一致 |
| **批量操作限制** | 批量删除100+角色 | 按配置限制或分批处理 |
| **权限继承** | 用户拥有多个角色 | 取最大数据权限范围 |

## 7. 安全性测试

| 测试项 | 验证方式 | 预期结果 |
|--------|---------|---------|
| **权限控制** | 无权限用户调用新增/编辑/删除接口 | 返回403 |
| **SQL注入** | 参数中包含 `admin'--` | 被参数化查询转义，无SQL注入风险 |
| **XSS攻击** | 角色名称注入 `&lt;script&gt;alert(1)&lt;/script&gt;` | 输出时编码，不执行脚本 |
| **传输安全** | 抓包分析请求 | HTTPS加密传输 |
| **防重复提交** | 快速连续点击提交 | Token机制防护，仅执行一次 |
| **缓存安全** | 权限缓存是否可被绕过 | 缓存与数据库一致，无法绕过 |


## 8. 数据一致性测试

### 8.1 缓存一致性测试

| 场景 | 验证点 | 期望行为 |
|------|--------|---------|
| **创建角色后** | 查询角色列表 | 新角色立即出现在列表中 |
| **修改角色编码后** | 查询权限缓存 | 新编码对应的缓存正确加载 |
| **修改角色状态后** | 用户权限查询 | 状态变更立即反映到用户权限 |
| **删除角色后** | 查询权限缓存 | 相关缓存立即清除 |
| **分配菜单后** | 用户权限查询 | 权限缓存立即更新 |

### 8.2 事务回滚测试

| 场景 | 触发条件 | 验证点 |
|------|---------|--------|
| **数据库错误** | 模拟DB连接断开 | 操作回滚，数据不变 |
| **业务异常** | 校验失败抛异常 | 事务回滚，数据一致 |
| **Panic触发** | 代码运行时错误 | 事务回滚，数据恢复 |
| **多表操作** | 同时更新角色表和关联表 | 全部成功或全部回滚 |

### 8.3 数据完整性测试

| 场景 | 验证点 | 期望行为 |
|------|--------|---------|
| **逻辑删除过滤** | 查询角色列表 | 不返回已删除角色 |
| **唯一性约束** | 检查角色编码重复 | 包含已删除记录的校验 |
| **用户角色关联** | 删除角色前检查 | 有用户关联则禁止删除 |
