# 角色管理模块需求规格

## 1. 模块概述

### 1.1 模块定位

角色管理模块定义并管理系统中的角色及其权限，提供角色全生命周期管理能力，是平台 RBAC 权限控制与数据权限控制的基础。

> **三后端契约**：Java/Go/Python 三后端 API 契约完全一致，Java 为权威来源，Go/Python 对齐。

### 1.2 功能目标

- 角色统一管理（CRUD，逻辑删除）
- 菜单权限分配（页面权限、按钮权限、接口权限）
- 数据权限配置（全部数据/本部门及子部门/仅本部门/仅本人）
- 系统预置角色（root/admin/user/vip/guest）

### 1.3 性能目标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| **列表查询响应** | &lt;500ms | 角色列表分页查询响应时间 |
| **表单提交响应** | &lt;1s | 新增/编辑角色操作响应时间 |
| **权限分配响应** | &lt;1s | 权限分配操作响应时间 |
| **角色容量** | ≥1000 | 系统支持的最大角色数量 |

## 2. 用户角色分析

### 2.1 主要用户角色

| 角色 | 描述 |
|------|------|
| **超级管理员** | 拥有角色管理模块的全部操作权限 |
| **系统管理员** | 拥有角色增删改查与权限分配的操作权限 |
| **部门管理员** | 仅可查看角色列表并为本部门用户分配已有角色 |

### 2.2 权限矩阵

| 功能点 | 超级管理员 | 系统管理员 | 部门管理员 |
|--------|-----------|-----------|-----------|
| 查看角色列表 | ✅ | ✅ | ✅ |
| 新增角色 | ✅ | ✅ | ❌ |
| 编辑角色 | ✅ | ✅ | ❌ |
| 删除角色 | ✅ | ✅ | ❌ |
| 启用/禁用角色 | ✅ | ✅ | ❌ |
| 分配菜单权限 | ✅ | ✅ | ❌ |
| 配置数据权限 | ✅ | ✅ | ❌ |
| 为本部门用户分配角色 | ✅ | ✅ | ✅ |

### 2.3 预置角色

系统预置角色初始化时创建，超级管理员角色不可删除，其余预置角色可编辑但不可删除编码：

| 角色 | 编码（code） | 数据权限 | 说明 |
|------|------|---------|------|
| 超级管理员 | `root` | 0 全部数据 | 拥有系统全部权限，不可删除、不可禁用 |
| 系统管理员 | `admin` | 0 全部数据 | 系统管理权限，可管理用户/角色/部门等 |
| 普通用户 | `user` | 3 仅本人 | 注册用户基础角色，可使用图像处理功能 |
| VIP 会员 | `vip` | 3 仅本人 | 按等级细分权限由会员管理模块驱动（VIP1/VIP2/SVIP） |
| 访客 | `guest` | 3 仅本人 | 注册默认分配，仅可见自己的数据 |

## 3. 功能需求

### 3.1 角色列表查询 (F-RM-001)

#### 3.1.1 功能描述

提供角色信息的分页展示和关键字筛选能力，支持管理员快速定位目标角色。

#### 3.1.2 查询条件

| 条件类型 | 字段 | 说明 | 匹配方式 |
|---------|------|------|---------|
| **关键字搜索** | 角色名称 | 模糊匹配 | LIKE |

> **默认过滤**：角色列表默认仅展示未删除角色。

#### 3.1.3 列表展示字段

| 字段 | 显示名称 | 宽度 | 说明 |
|------|---------|------|------|
| id | 编号 | 100px | 角色唯一标识 |
| name | 角色名称 | 150px | 角色显示名称 |
| code | 角色编码 | 150px | 角色唯一编码 |
| dataScopeLabel | 数据权限 | 180px | 数据权限范围标签 |
| status | 状态 | 80px | 启用/禁用标签 |
| sort | 排序 | 100px | 角色排序 |
| createTime | 创建时间 | 180px | 角色创建时间 |
| - | 操作 | 280px | 状态切换/分配权限/编辑/删除 |

### 3.2 角色新增 (F-RM-002)

#### 3.2.1 功能描述

支持创建新角色，包括基本信息设置、数据权限配置。

#### 3.2.2 表单字段

| 字段 | 显示名称 | 类型 | 必填 | 校验规则 |
|------|---------|------|------|---------|
| name | 角色名称 | 输入框 | ✅ | 必填，2-30 字符 |
| code | 角色编码 | 输入框 | ✅ | 小写字母+下划线，3-32 位，系统唯一（含已删除记录），创建后不可修改 |
| dataScope | 数据权限 | 下拉选择器 | ✅ | 不能为空 |
| status | 状态 | 单选框组 | ✅ | 默认启用(1) |
| sort | 排序 | 数字输入框 | ✅ | 必须为数字，默认 1 |

### 3.3 角色编辑 (F-RM-003)

#### 3.3.1 功能描述

支持修改现有角色的基本信息、数据权限等。

#### 3.3.2 可编辑字段

| 字段 | 是否可编辑 | 说明 |
|------|-----------|------|
| name | ✅ | 可随时修改 |
| code | ❌ | 角色编码创建后不可修改 |
| dataScope | ✅ | 支持数据权限变更 |
| status | ✅ | 支持状态变更 |
| sort | ✅ | 可修改 |

#### 3.3.3 业务规则

修改保存后立即生效。

### 3.4 角色删除 (F-RM-004)

#### 3.4.1 功能描述

支持删除角色，包括单个删除和批量删除。

#### 3.4.2 删除方式

| 方式 | 触发操作 | 说明 |
|------|---------|------|
| **单个删除** | 点击操作列删除按钮 | 删除单个角色 |
| **批量删除** | 勾选多个后点击批量删除 | 删除选中的所有角色 |

#### 3.4.3 业务规则

1. **二次确认**：删除操作需弹窗确认
2. **关联检查**：检查角色是否有关联的用户，如存在则提示无法删除，需先解绑或转移用户角色
3. **超级管理员保护**：超级管理员角色（`root`）不可删除
4. **逻辑删除**：执行逻辑删除，数据保留可追溯

### 3.5 状态管理 (F-RM-005)

#### 3.5.1 功能描述

支持启用或禁用角色，控制用户是否可以使用该角色对应的权限。

#### 3.5.2 状态说明

角色状态取值为启用（1）与禁用（0），列表以标签展示并支持直接切换。

#### 3.5.3 业务规则

1. **状态切换**：可通过状态标签快速切换
2. **即时生效**：状态变更后立即生效
3. **超级管理员保护**：超级管理员角色（`root`）不可禁用

### 3.6 菜单权限分配 (F-RM-006)

#### 3.6.1 功能描述

支持为角色分配菜单权限。

#### 3.6.2 权限分类

| 权限类型 | 说明 | 控制维度 |
|---------|------|---------|
| **菜单权限** | 页面可见性，控制前端路由与菜单渲染 | 页面级 |
| **按钮权限** | 操作可见性，控制页面内按钮/操作元素显示 | 元素级 |
| **接口权限** | 后端接口访问的鉴权依据 | 接口级 |

#### 3.6.3 操作流程

点击分配权限 → 打开权限分配弹窗 → 加载菜单权限树 → 回显已分配权限 → 勾选权限 → 保存 → 提示成功

#### 3.6.4 业务规则

1. **树形结构**：菜单权限以树形结构展示，支持展开/收起
2. **全选支持**：支持父节点选择时自动勾选所有子节点
3. **即时保存**：点击确定后立即保存权限分配
4. **权限覆盖**：每次分配时覆盖原有权限

### 3.7 数据权限配置 (F-RM-007)

#### 3.7.1 功能描述

支持配置角色的数据访问范围，实现数据级别的权限控制。

#### 3.7.2 数据权限选项

| 权限值 | 名称 | 说明 |
|-------|------|------|
| 0 | 全部数据 | 可访问系统所有数据 |
| 1 | 本部门及子部门 | 可访问本部门及下级部门数据 |
| 2 | 仅本部门 | 仅可访问本部门数据（默认） |
| 3 | 仅本人 | 仅可访问自己的数据 |

#### 3.7.3 业务规则

1. **默认值**：新建角色默认为"仅本部门"（2）
2. **取最大范围**：用户拥有多个角色时取最大权限范围。范围大小排序：0 > 1 > 2 > 3（数值越小优先级越高），多角色取数值最小者（即范围最大者）
3. **生效机制**：在查询业务数据时根据数据权限范围自动过滤

### 3.8 角色导入导出 (F-RM-008)

#### 3.8.1 功能描述

角色支持通过通用导入导出框架进行批量导入/导出，便于角色在环境间迁移与批量初始化：

| 能力 | 说明 |
|------|------|
| 模板下载 | 下载角色导入模板（含 name/code/sort/status 等字段与枚举说明，Excel/CSV） |
| 导出 | 按查询条件导出角色列表（同步导出返回文件流，超阈值走异步任务返回 taskId） |
| 导入 | 上传 Excel/CSV 批量创建角色（同步导入返回结果，超阈值走异步任务） |

#### 3.8.2 业务规则

1. **编码唯一**：导入时角色编码重复（含软删历史）→ 整行失败并提示"角色编码已存在"
2. **超级管理员保护**：导出不含超级管理员角色；导入不可创建/修改超级管理员角色
3. **导入语义**：导入为新增语义，不做覆盖更新；重复导入同编码 → 报错
4. **行数与文件限制**：单次导入行数 ≤ 10 万、文件 ≤ 20MB（通用框架限制）

## 4. 界面交互规范

### 4.1 页面布局

角色管理页面采用**单栏布局**，包含搜索条件区域、操作按钮区域、角色数据表格和分页组件。

### 4.2 交互规则

#### 4.2.1 本模块特有交互

| 场景 | 行为 |
|------|------|
| 打开新增表单 | 清空表单数据，默认值：状态=启用，排序=1，数据权限=仅本部门 |
| 打开编辑表单 | 加载角色详情，角色编码字段只读 |
| 状态切换 | 点击 Switch 开关直接切换 |
| 权限分配 | 打开弹窗后加载菜单树，回显已分配权限 |

#### 4.2.2 确认提示文案

- 单个删除：`确认删除角色「{name}」吗？`
- 批量删除：`确认删除选中的 {count} 个角色吗？`
- 存在关联用户：`该角色下已关联用户，无法删除，请先解绑或转移用户角色。`

## 5. 安全设计

### 5.1 权限控制

| 规则 | 说明 |
|------|------|
| **接口鉴权** | 所有角色管理操作均依据权限标识鉴权，无权限不可访问 |

### 5.2 数据安全

| 安全措施 | 说明 |
|---------|------|
| **数据隔离** | 用户仅可访问其角色数据权限范围内的数据 |
| **操作审计** | 角色的增删改、状态变更与权限分配需记录操作日志 |

### 5.3 输入校验

| 校验类型 | 说明 |
|---------|------|
| **必填与格式** | 必填项缺失或格式不合法时拒绝提交并提示 |
| **唯一性校验** | 角色编码唯一性校验（含已删除记录） |

## 6. 多端需求

| 端 | 角色管理入口 | 说明 |
|----|-------------|------|
| **Web Vue/React** | 后台管理页面 | 完整角色管理功能 |
| **Electron 桌面端** | 后台管理页面 | 复用 Web 端管理能力 |
| **Android/Flutter/小程序** | - | 不开放后台角色管理入口，仅受角色权限约束 |

**权限申请**：各端登录后获取的角色与权限信息一致，前端按端能力渲染菜单与按钮；角色变更后用户权限立即生效。

## 7. 依赖关系

### 7.1 依赖模块

| 模块 | 依赖说明 |
|------|---------|
| **菜单管理模块** | 角色需要关联到具体菜单/按钮/接口权限 |
| **字典管理模块** | 角色状态等信息需要字典数据支持 |
| **部门管理模块** | 数据权限范围需要部门信息支持 |
| **会员管理模块** | VIP 会员角色按等级细分权限由会员管理驱动 |

### 7.2 被依赖模块

| 模块 | 依赖说明 |
|------|---------|
| **用户管理模块** | 用户需要分配系统角色 |
| **系统所有业务模块** | 依赖角色管理模块提供权限控制 |
| **认证管理模块** | 依赖角色信息进行权限验证；注册默认分配 `guest` 角色 |
