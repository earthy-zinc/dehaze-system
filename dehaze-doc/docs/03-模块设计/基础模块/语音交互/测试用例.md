## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **短语音** | 2-3 秒录音（"你好"、"开始处理"、"强度调到80"） | 基础功能验证 |
| **长语音** | 30-55 秒录音（连续对话，含中英混杂专业术语） | 长语音连续识别验证 |
| **噪声语音** | 含环境噪声的录音（风扇/键盘/空调背景） | 噪声鲁棒性验证 |
| **专业术语语音** | 含"RIDCP"、"FFA-Net"、"PSNR"、"SSIM"、"暗通道先验"等术语 | 热词识别率验证 |
| **静音** | 1 秒和 5 秒静音录音 | 静音检测验证 |
| **TTS 文本** | "处理完成，PSNR 28.5，SSIM 0.92"，"您好，请上传图片"（缓存命中测试文本） | TTS 合成和缓存验证 |
| **长 TTS 文本** | 500 字 LLM 回复 | 长文本流式合成验证 |

### 3.2 测试基础设施

| 组件 | 说明 |
|------|------|
| FunASR 服务 | Python 微服务（SenseVoice-Small 流式 + Paraformer-Large 离线），WebSocket:8765 |
| 云 TTS API | Mock 阿里云/腾讯云 API（用于隔离外部依赖和控制返回） |
| 音频文件 | 预制测试用 WAV 文件（16kHz, 16bit, mono） |

### 3.3 数据清理策略

- TTS 缓存清理：测试前清空用户 `test_voice_user` 的 TTS 缓存
- ASR 会话超时后自动清理（无需手动清理）

### 3.4 测试范围

**包含的功能点：**
- F-VS-001 语音识别（流式实时、离线高精、热词、标点、噪声鲁棒、静音检测）
- F-VS-002 语音合成（非流式、流式、音色切换、语速控制、缓存命中、降级）
- 多轮语音交互（连续语音输入、静音自动结束）
- FunASR 服务不可用/超时等异常处理

## 5. 关键边界与异常场景

| 用例 ID | 测试场景 | 输入 | 期望行为 |
|---------|---------|------|---------|
| `T-VS-040` | 流式 ASR — 仅噪音（无有效语音） | 推送风扇噪声 5 秒 | 识别为空文本或不稳定噪音片段，不产生有意义的识别结果（正确行为） |
| `T-VS-041` | 流式 ASR — 采样率不匹配 | 推送 8kHz PCM 音频块（应为 16kHz） | FunASR 返回低质量结果或错误，后端日志告警 |
| `T-VS-042` | WebSocket 推送超大音频块 | 推送 10MB 单块 | 拒绝或超时，不内存溢出 |
| `T-VS-043` | 热词列表为空 | registerHotWords([]) | ASR 正常运行，无热词增强效果（不报错） |
| `T-VS-044` | 热词列表超大（1000 个） | registerHotWords([...1000 words]) | ASR 正常运行但可能影响延迟，策略限制为 100 个 |
| `T-VS-045` | TTS 文本含特殊字符 | text="处理完成: PSNR < 28.5 & SSIM > 0.9" | 云 API 正确处理特殊字符，合成音频正常（特殊字符不导致 API 异常） |
| `T-VS-046` | 多语音并发合成 | 10 个用户同时请求 TTS | 全部正常返回，缓存相互隔离（按 userId 存储） |
