# 语音交互模块测试用例

## 1. 测试目标

- [x] 验证核心功能符合需求规格（流式ASR、离线ASR、TTS合成、TTS缓存、TTS降级、多轮语音交互、热词管理）
- [x] 覆盖正常流程、边界条件、异常分支
- [x] 验证 FunASR 流式实时识别的延迟、准确率、热词效果

- [x] 验证多轮语音交互（会话超时、语音与文本混合输入、上下文连续性）
- [x] 验证热词管理（用户级/全局热词CRUD、生效范围隔离、权限校验）
- [x] 验证 AI 计费关联（ASR 按秒、TTS 按字符、余额不足拒绝）

## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **短语音** | 2-3 秒录音（"你好"、"开始处理"、"强度调到80"） | 基础功能验证 |
| **长语音** | 30-55 秒录音（连续对话，含中英混杂专业术语） | 长语音连续识别验证 |
| **噪声语音** | 含环境噪声的录音（风扇/键盘/空调背景） | 噪声鲁棒性验证 |
| **专业术语语音** | 含"RIDCP"、"FFA-Net"、"PSNR"、"SSIM"、"暗通道先验"等术语 | 热词识别率验证 |
| **静音** | 1 秒和 5 秒静音录音 | 静音检测验证 |
| **TTS 文本** | "处理完成，PSNR 28.5，SSIM 0.92"，"您好，请上传图片"（缓存命中测试文本） | TTS 合成和缓存验证 |
| **长 TTS 文本** | 500 字 LLM 回复 | 长文本流式合成验证 |

### 3.2 测试基础设施

| 组件 | 说明 |
|------|------|
| FunASR 服务 | Python 微服务（SenseVoice-Small 流式 + Paraformer-Large 离线），WebSocket:8765 |
| TTS 引擎 | 本地 Piper 引擎（进程内，模型自动下载）；异常场景经单元测试桩引擎函数模拟 |
| 音频文件 | 预制测试用 WAV 文件（16kHz, 16bit, mono） |

### 3.3 数据清理策略

- TTS 缓存清理：测试前清空用户 `test_voice_user` 的 TTS 缓存
- ASR 会话超时后自动清理（无需手动清理）

### 3.4 测试范围

**包含的功能点：**
- F-VS-001 语音识别（流式实时、离线高精、热词、标点、噪声鲁棒、静音检测）
- F-VS-002 语音合成（非流式、流式、音色切换、语速控制、缓存命中、降级、语音回复开关）
- F-VS-003 多轮语音交互（会话超时60秒、语音与文本混合输入、上下文连续性）
- F-VS-004 热词管理（用户级/全局热词CRUD、生效范围隔离、权限校验）
- AI 计费关联（ASR 按秒计费、TTS 按字符计费、余额不足拒绝）
- FunASR 服务不可用/超时等异常处理

## 5. 关键边界与异常场景

| 用例 ID | 测试场景 | 输入 | 期望行为 |
|---------|---------|------|---------|
| `T-VS-040` | 流式 ASR — 仅噪音（无有效语音） | 推送风扇噪声 5 秒 | 识别为空文本或不稳定噪音片段，不产生有意义的识别结果（正确行为） |
| `T-VS-041` | 流式 ASR — 采样率不匹配 | 推送 8kHz PCM 音频块（应为 16kHz） | FunASR 返回低质量结果或错误，后端日志告警 |
| `T-VS-042` | WebSocket 推送超大音频块 | 推送 10MB 单块 | 拒绝或超时，不内存溢出 |
| `T-VS-043` | 热词列表为空 | registerHotWords([]) | ASR 正常运行，无热词增强效果（不报错） |
| `T-VS-044` | 热词列表超大（1000 个） | registerHotWords([...1000 words]) | ASR 正常运行但可能影响延迟，策略限制为 100 个 |
| `T-VS-045` | TTS 文本含特殊字符 | text="处理完成: PSNR < 28.5 & SSIM > 0.9" | 引擎正确处理特殊字符，合成音频正常（特殊字符不导致引擎异常） |
| `T-VS-046` | 多语音并发合成 | 10 个用户同时请求 TTS | 全部正常返回，缓存相互隔离（按 userId 存储） |
| `T-VS-047` | 全局热词与用户级热词生效范围隔离 | 用户A配置用户级热词"RIDCP"；管理员配置全局热词"FFA-Net" | 用户A识别时"RIDCP"和"FFA-Net"均增强；用户B识别时仅"FFA-Net"增强，"RIDCP"不增强 |
| `T-VS-048` | TTS 语音回复开关默认关闭 | 新用户首次使用 | 语音回复开关默认为关闭状态，用户需主动开启后才对 AI 回复进行语音播报 |
| `T-VS-049` | WebSocket 空闲超时自动关闭 | 流式 ASR 会话建立后无音频推送 | 空闲 60s 后自动关闭 WebSocket 连接（前端与 FunASR 两端），回收资源，不泄漏连接 |

## 8. 数据一致性测试

| 用例 ID | 测试场景 | 前置条件 | 期望结果 |
|---------|---------|---------|---------|
| `T-VS-070` | ASR session 超时自动清理 | 无效 sessionId 超过 60 秒 | GET /result/{sessionId} 返回 404，session 标记为 expired |
| `T-VS-071` | TTS 缓存 Key 唯一性 | text="AA" voiceId="X" speed=1.0 → 缓存 A；text="AA" voiceId="Y" speed=1.0 → 缓存 B | A ≠ B（音色不同导致 key 不同） |
