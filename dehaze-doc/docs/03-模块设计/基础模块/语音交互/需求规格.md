# 语音交互模块需求规格

## 1. 模块概述

### 1.1 模块定位

语音交互模块是系统级的语音输入输出能力模块，提供语音识别与语音合成能力。识别文本直接进入 AI 对话模块的消息管道，由 LLM 统一理解意图与执行指令，模块不单独维护语音指令解析逻辑。

### 1.2 服务形态

语音识别与语音合成**统一纳入 AI 模型管理**：ASR/TTS 模型与供应商、密钥即 `sys_ai_model` / `sys_ai_provider` / `sys_ai_provider_key` 中 `model_type=asr`/`tts` 的行。识别与合成各有一个默认模型（dict `ai_model.default_model.asr/.tts`，解析链：请求显式 `model` > 平台默认）；本地推理服务 `dehaze-voice` 以 `local-voice` 供应商（OpenAI Audio 兼容协议）纳入统一管理，与云厂商模型同构、应用侧不感知差异。第三方语音按供应商 `protocol_type` 分派协议族——内置 `openai_audio`（dehaze-voice 私有 WS 扩展）/ 阿里云百炼 `dashscope_realtime` / 火山引擎 `volc_realtime`，应用侧会话协议统一。面向不同客户的私有化部署条件（高配环境提供本地语音服务，低配或无法提供高性能服务器的环境可全部由云厂商模型供给），由 `VOICE_LOCAL_ENABLED` 与默认模型配置切换。

### 1.4 依赖模块

| 模块             | 依赖说明                                                                       |
| ---------------- | ------------------------------------------------------------------------------ |
| **AI 对话模块**  | 识别文本进入对话消息管道，回复可选择语音播报；多轮语音上下文由 AI 对话模块管理 |
| **图像处理模块** | AI 对话模块调度图像处理能力，语音指令由 LLM 统一理解执行                       |
| **AI 计费管理**  | 语音识别与语音合成调用计入 AI 积分（识别按秒、合成按字符，见 §6.3）            |

## 2. 用户角色与权限

### 2.1 主要用户角色

| 角色     | 描述             | 主要职责                                                                     |
| -------- | ---------------- | ---------------------------------------------------------------------------- |
| 普通用户 | 所有登录用户     | 语音输入、语音播报、多轮语音对话、管理个人用户级热词                         |
| 管理员   | 系统后台管理人员 | 配置全局热词、监控语音服务运行状态（语音模型与供应商配置归 AI 模型管理模块） |

### 2.2 权限矩阵

| 功能点         |    普通用户    | 管理员 |
| -------------- | :------------: | :----: |
| 语音识别       |       ✅       |   ✅   |
| 语音合成       |       ✅       |   ✅   |
| 多轮语音对话   |       ✅       |   ✅   |
| 用户级热词管理 | ✅（仅自己的） |   ✅   |
| 全局热词管理   |       ❌       |   ✅   |
| 服务运行监控   |       ❌       |   ✅   |

> 语音模型/供应商/密钥/音色的管理不在本模块，归 [AI 模型管理模块](../AI模型管理/需求规格.md)（`ai:model:manage` / `ai:provider:manage`）。

### 2.3 多端能力差异

各端录音能力受运行环境影响，麦克风授权流程统一：进入语音功能 → 触发授权申请 → 用户授权 → 开始录音；拒绝授权时引导至系统设置开启。

## 3. 功能需求

### 3.1 语音识别 (F-VS-001)

#### 3.1.1 功能描述

将用户语音输入转换为文本，支持流式实时识别与离线批量识别两种模式。

#### 3.1.2 功能要求

| 要求       | 说明                                            |
| ---------- | ----------------------------------------------- |
| 语言支持   | 中文（普通话），支持中英混杂                    |
| 实时识别   | 流式推送音频，边说边出字（延迟 < 100ms）        |
| 离线识别   | 提交完整音频后返回识别结果，准确率更高          |
| 识别准确率 | 普通环境 ≥ 95%，带背景噪声 ≥ 90%                |
| 标点符号   | 自动添加标点和断句                              |
| 热词       | 支持配置领域热词，提升专业词汇识别率（见 §3.4） |

#### 3.1.3 识别模式

| 模式     | 场景                 | 延迟           |
| -------- | -------------------- | -------------- |
| 流式实时 | 实时对话、边说边出字 | < 100ms        |
| 离线高精 | 完整音频提交后识别   | 音频时长 × 0.3 |

#### 3.1.4 录音时长与超时控制

| 限制         | 值                                                         | 说明                                 |
| ------------ | ---------------------------------------------------------- | ------------------------------------ |
| 最长连续识别 | 60 秒                                                      | 超时自动结束录音                     |
| 录音结束方式 | 客户端发结束信号 / 达到 60 秒时长上限 / 通道空闲超时 60 秒 | 无静音自动结束，静音时由空闲超时兜底 |

### 3.2 语音合成 (F-VS-002)

#### 3.2.1 功能描述

将文本转换为语音。AI 对话回复可选择语音播报，用户可开关和控制语速。

#### 3.2.2 功能要求

| 要求     | 说明                                              |
| -------- | ------------------------------------------------- |
| 语言支持 | 中文（普通话）                                    |
| 音色选择 | 支持音色切换（当前提供中文女声，音色可扩展）      |
| 语速控制 | 慢速 0.8x / 正常 1.0x / 快速 1.2x                 |
| 输出格式 | mp3 / wav / pcm，采样率 8000/16000/24000/48000 Hz |
| 可选开关 | 用户可选择是否开启语音回复（默认关闭）            |

#### 3.2.4 降级策略

语音合成不可用时降级为纯文本回复，作为必备功能需求：

| 异常                   | 处理                             |
| ---------------------- | -------------------------------- |
| 语音合成服务不可用     | 返回错误提示，前端展示纯文本回复 |
| 合成失败（返回空音频） | 返回错误提示，不存储不扣费       |
| 音频存储失败           | 返回错误提示                     |

### 3.3 多轮语音交互 (F-VS-003)

#### 3.3.1 功能描述

支持上下文连续语音对话，多轮语音输入的上下文由 AI 对话模块管理，本模块不单独维护语音会话上下文。

#### 3.3.2 功能要求

| 要求       | 说明                                   |
| ---------- | -------------------------------------- |
| 上下文连续 | 同一会话内多轮语音输入共享上下文       |
| 会话超时   | 60 秒无新语音输入自动结束会话          |
| 会话管理   | 由 AI 对话模块统一管理会话 ID 与上下文 |
| 混合输入   | 同一会话支持语音与文本混合输入         |

### 3.4 热词配置 (F-VS-004)

#### 3.4.1 功能描述

管理员与用户配置领域热词（算法名、专业术语），提升语音识别对专业词汇的识别率。

#### 3.4.2 功能要求

| 要求     | 说明                                                           |
| -------- | -------------------------------------------------------------- |
| 管理界面 | 管理员通过热词管理界面配置全局热词；普通用户管理个人用户级热词 |
| 生效范围 | 全局热词（所有用户生效）/ 用户级热词（仅当前用户生效）         |
| 生效方式 | 会话创建时注册，变更后动态生效，无需重启服务                   |
| 热词示例 | RIDCP、FFA-Net、PSNR、SSIM、去雾、暗通道先验                   |

### 3.5 语音服务提供方的统一管理

语音提供方、密钥与模型音色的管理统一并入 [AI 模型管理模块](../AI模型管理/需求规格.md)：

- ASR/TTS 模型与供应商统一登记 `sys_ai_model` / `sys_ai_provider`，密钥统一登记 `sys_ai_provider_key`（统一密钥调度：priority 优先、同优先级加权随机、额度预留、失败冷却，供全模态复用）；
- 默认模型由 dict `ai_model.default_model.asr/.tts` 承载，不再有"提供方级默认（`is_default`）"语义；
- 本地语音服务 `dehaze-voice` 以 `local-voice` 供应商纳入统一管理（OpenAI Audio 兼容协议），与云厂商同构；
- 语音模块仅保留 `voice:hotword:edit` / `voice:service:monitor` 权限，不再有 `voice:engine:manage`。

## 4. 用户交互流程

### 4.1 语音输入流程

用户点击麦克风 → 申请录音权限 → 开始录音 → 流式推送音频实时识别 → 实时显示识别文本 → 用户结束或达到 60 秒上限自动结束（结束方式见 §3.1.4）→ 文本填入输入框 → 用户确认/编辑后发送 → 文本进入 AI 对话模块消息管道，由 LLM 统一理解意图并执行。

### 4.2 语音回复流程

AI 对话回复生成 → 用户开启语音播报 → 语音合成 → 返回音频播放。

## 5. 非功能需求

### 5.1 性能要求

| 指标             | 目标值         | 说明                     |
| ---------------- | -------------- | ------------------------ |
| 语音识别流式延迟 | < 100ms        | 增量文本返回延迟         |
| 语音识别离线识别 | 音频时长 × 0.3 | 高精度识别耗时           |
| 语音识别并发会话 | ≥ 50           | 同时进行流式识别的会话数 |
| 语音合成首播延迟 | ≤ 1s           | 文本到首段音频播放的延迟 |
| 语音合成流式延迟 | ≤ 200ms        | 增量音频返回延迟         |

### 5.2 并发与容量

| 指标         | 要求            | 说明                           |
| ------------ | --------------- | ------------------------------ |
| 并发会话上限 | 50              | 超过上限拒绝新会话并提示       |
| 连接超时     | 60s             | 通道空闲超时自动关闭，回收资源 |
| 合成限流     | 单用户 QPS 限流 | 防止滥用                       |

### 5.3 安全要求

| 方面             | 措施                                         |
| ---------------- | -------------------------------------------- |
| 音频数据不持久化 | 识别音频处理完即弃，不落盘存储               |
| 录音授权         | 录音前申请用户授权，拒绝时引导至系统设置开启 |
| 传输加密         | 语音数据传输需加密                           |
| 缓存加密         | 合成音频缓存需加密存储                       |
| 会话隔离         | 识别会话按用户隔离，不可跨用户访问           |

### 5.4 可用性要求

| 方面     | 要求                                      |
| -------- | ----------------------------------------- |
| 降级     | 语音合成不可用时降级为纯文本（见 §3.2.4） |
| 容错     | 单个识别会话异常不影响其他会话            |
| 资源隔离 | 语音识别与图像处理资源隔离，互不影响      |

## 6. 业务规则

### 6.3 AI 计费关联

语音识别与语音合成调用计入 AI 积分，与 AI 计费管理模块挂钩：

| 能力     | 计费维度   | billing_unit         | 说明                     |
| -------- | ---------- | -------------------- | ------------------------ |
| 语音识别 | 按秒计费   | `second`             | 按音频时长累计积分       |
| 语音合成 | 按字符计费 | `ten_thousand_chars` | 按合成文本字符数累计积分 |

> 计费单价由 AI 模型管理的模型价格表（`sys_ai_model_price`，`billing_unit` 维度化）承载，可**按模型差异化定价**；调用前校验用户 AI 积分余额，余额不足时拒绝并提示。
