# 语音交互模块需求规格

## 1. 模块概述

### 1.1 模块定位

语音交互模块是系统级的语音输入输出能力模块，提供语音识别（ASR）和语音合成（TTS）能力。语音识别的文本直接进入 AI 对话模块的消息管道，由 LLM 统一处理意图理解和指令执行，不单独维护语音指令解析逻辑——重复造轮子且 LLM 的自然语言理解远超规则匹配。

### 1.2 方案概览

| 能力 | 方案 | 理由 |
|------|------|------|
| **ASR（语音识别）** | 本地部署语音识别引擎 | 中文准确率高，CPU 即可运行不占用 GPU 资源，流式实时识别延迟低，无 API 成本 |
| **TTS（语音合成）** | 云语音合成服务 | 中文自然度优于开源方案，不占用图像处理 GPU 资源 |

> 选型核心逻辑：项目 GPU 是图像处理的核心资源，语音识别在 CPU 上即可达到生产级质量；语音合成的高质量中文输出依赖云服务。

### 1.3 核心价值

| 价值维度 | 具体内容 |
|---------|---------|
| **降低输入门槛** | 用户可通过语音完成操作，无需手动打字 |
| **流式实时识别** | 用户说话过程中实时显示识别结果，边说边出字 |
| **自然语音回复** | LLM 回复通过云 TTS 合成为自然语音播报 |

│  (LLM 中枢)   │     │  (语音能力)   │     │  (本地部署)      │

### 1.5 依赖模块

| 模块 | 依赖说明 |
|------|---------|
| **AI 对话模块** | ASR 文本进入对话消息管道，LLM 回复可选择语音播报 |
| **图像处理模块** | AI 对话模块调度图像处理能力，语音指令由 LLM 统一理解执行 |

## 2. 功能需求

### 2.1 语音识别 (F-VS-001)

#### 2.1.1 功能描述

将用户语音输入转换为文本。基于本地部署的语音识别引擎，支持流式实时识别和离线批量识别两种模式。

#### 2.1.2 功能要求

| 要求 | 说明 |
|------|------|
| 语言支持 | 中文（普通话），支持中英混杂 |
| 实时识别 | 流式推音频块，边说边出字（延迟 < 100ms） |
| 离线识别 | 支持完整音频文件提交后返回识别结果（离线高精度模型，准确率更高） |
| 识别准确率 | 普通环境下 ≥ 95%，带背景噪声下 ≥ 90% |
| 长语音支持 | 最长 60 秒连续识别 |
| 标点符号 | 自动添加标点和断句 |
| 热词 | 支持配置领域热词（算法名、专业术语），提升专业词汇识别率 |

#### 2.1.3 识别模式

| 模式 | 说明 | 场景 | 延迟 |
|------|------|------|------|
| 流式实时 | 流式识别模型 | 实时对话、边说边出字 | < 100ms |
| 离线高精 | 离线高精度模型 | 完整音频提交后识别 | 音频时长 × 0.3 |

### 2.2 语音合成 (F-VS-002)

#### 2.2.1 功能描述

将文本转换为语音，调用云 TTS API（阿里云/腾讯云）。AI 对话回复可选择语音播报，用户可开关和控制语速。

#### 2.2.2 功能要求

| 要求 | 说明 |
|------|------|
| 语言支持 | 中文（普通话） |
| 音色选择 | 支持多种音色（男声/女声/童声）和风格（自然/专业/活泼） |
| 语速控制 | 慢速 0.8x / 正常 1.0x / 快速 1.2x |
| 流式合成 | 支持流式 TTS，边合成边播放（减少首播延迟） |
| 自然度 | 精品音色，接近真人 |
| 可选开关 | 用户可选择是否开启语音回复（默认关闭） |

#### 2.2.3 TTS 缓存策略

| 缓存策略 | 说明 |
|---------|------|
| 相同文本缓存 | AI 对话常见开场语（如"您好，请上传图片"）首次合成后缓存音频，后续命中从缓存返回 |
| 缓存过期 | 缓存 24 小时过期，平衡存储成本和 API 调用量 |

## 3. 用户交互流程

### 3.1 语音输入流程

用户点击麦克风 → 开始录音 → 流式推送音频块到 FunASR → 实时显示识别文本 → 用户松手/静音 3 秒结束 → 文本填入输入框 → 用户确认/编辑后发送 → ASR 文本直接进入 AI 对话模块的消息管道，由 LLM 统一理解意图并执行

### 3.2 语音回复流程

AI 对话回复生成 → 用户开启语音播报 → 调用云 TTS API 流式合成 → 流式播放音频（不需要完整下载再播放）
