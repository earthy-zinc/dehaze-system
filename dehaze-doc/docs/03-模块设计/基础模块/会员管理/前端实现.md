# 会员管理模块 - 前端实现设计

## 1. 文档概述

本文档描述会员管理模块的前端实现方案（dehaze-front-vue），聚焦页面结构、数据流、关键交互决策与权限控制。

---

## 2. 页面结构

### 2.1 页面清单

| 页面 | 路由 | 角色 | 说明 |
|------|------|:----:|------|
| 会员中心 | `/member/center` | 用户 | 等级卡片、成长值进度、签到、权益概览、升级引导 |
| 成长值明细 | `/member/growth-logs` | 用户 | 成长值流水列表（按类型/时间筛选） |
| 会员管理 | `/member/list` | 管理员 | 会员列表、详情、等级调整、成长值调整、冻结/解冻 |

### 2.2 会员中心（center/index.vue）

| 区域 | 内容 |
|------|------|
| 等级卡片 | 等级名称（带渐变配色）、等级来源标识（套餐到期时间/成长值维持）、成长值 |
| 操作按钮 | "成长值明细"入口、升级引导按钮 |
| 成长值进度卡片 | 当前成长值、距下一等级差值、进度条（最高等级显示"已达最高等级"） |
| 权益概览 | 本月剩余次数（去雾/评估）、批量上限、已解锁功能列表 |
| 签到卡片 | 签到按钮（今日已签到置灰）、连续签到天数、累计签到天数、签到成功动画提示（+成长值） |

### 2.3 成长值明细（growth-logs/index.vue）

| 区域 | 内容 |
|------|------|
| 顶部 | 返回按钮 + 标题"成长值明细" |
| 筛选区 | 变动类型下拉（全部分类/去雾处理/效果评估/提交评价/每日签到/连续签到奖励/消费/退款扣减/管理员调整）、时间范围选择 |
| 列表 | 分页表格：变动类型（彩色标签）、变动值、变动后余额、原因、变动时间 |

### 2.4 会员管理（list/index.vue）

| 区域 | 内容 |
|------|------|
| 筛选区 | 关键字（用户名/昵称）、会员等级下拉、状态下拉（正常/冻结） |
| 表格 | 选择框、用户名、昵称、会员等级（标签）、成长值、本月已用次数、到期时间、状态、开通时间、操作（详情/调整等级/成长值调整/冻结解冻） |
| 详情弹窗 | 基本信息（用户名/昵称/等级/等级来源/成长值/到期时间/状态/开通时间/累计消费/冻结原因/当月配额）、成长值流水页签 |
| 等级调整弹窗 | 目标等级下拉、到期时间选择（可选）、调整原因（必填 2-200 字符）、降级二次确认 |
| 成长值调整弹窗 | 变动值输入（整数正负）、调整原因（必填）、提交后刷新 |
| 冻结/解冻弹窗 | 冻结：填写原因（必填）；解冻：确认提示 |

## 3. 数据流

### 3.1 会员中心

```
进入页面 → 加载会员档案 + 当月签到日历
    ↓
渲染等级卡片 / 成长值进度 / 权益概览 / 签到状态
    ↓
点击签到 → 提交签到 → 成功动画（+成长值）→ 刷新档案与日历
```

### 3.2 成长值明细

```
进入页面 → 按条件查询流水
    ↓
切换变动类型 / 选择时间范围 → 重新查询
```

### 3.3 后台会员管理

```
进入页面 → 分页查询会员列表
    ↓
筛选（关键字/等级/状态）→ 重新查询
    ↓
操作：
  - 详情 → 弹窗加载基本信息 + 成长值流水
  - 等级调整 → 表单 → 降级时二次确认 → 提交 → 刷新列表
  - 成长值调整 → 表单 → 提交 → 刷新列表
  - 冻结/解冻 → 表单（冻结需原因）→ 提交 → 刷新列表
```

### 3.4 模块间数据交互

| 交互方向 | 数据 | 说明 |
|---------|------|------|
| 会员管理 → 用户 | 会员档案/签到数据 | 用户端页面数据源 |
| 会员管理 → 去雾处理 | 等级/配额 | 去雾处理模块权益校验（Python 算法服务侧） |
| 会员管理 → 反馈评价 | 成长值事件 | 评价行为触发成长值奖励 |
| 订单/套餐 → 会员管理 | 支付回调 | 套餐购买升级（待接入） |

## 4. 关键交互决策

| 决策点 | 实现方式 |
|--------|---------|
| 等级配色 | 各等级映射渐变色与图标，等级卡片随等级变化 |
| 成长值进度 | 按当前等级与下一等级成长值区间计算进度百分比，最高等级显示 100% |
| 签到防重复 | 今日已签到按钮置灰，后端重复签到返回错误提示 |
| 降级二次确认 | 等级调整时比较新旧等级排序，降级弹二次确认框 |
| 冻结原因必填 | 冻结弹窗表单校验，原因必填方可提交 |
| 成长值调整预览 | 调整弹窗展示当前值 + 变动值 = 预期值（前端计算结果） |

---

## 5. 权限控制

| 操作 | 权限标识 | 无权限时 |
|------|---------|---------|
| 等级调整 | member:level:edit | 按钮隐藏 |
| 成长值调整 | member:growth:edit | 按钮隐藏 |
| 冻结/解冻 | member:status:edit | 按钮隐藏 |
| 权益配置修改 | member:benefit:edit | 按钮隐藏 |

> 会员中心/成长值明细为登录用户可用；会员管理列表页面为管理员后台页面。

---

## 6. 性能优化

| 优化项 | 实现方式 |
|--------|---------|
| 分页查询 | 后端分页，前端仅当前页渲染 |
| 搜索防抖 | 关键字输入防抖后触发查询 |
| 签到交互 | 按钮 loading 状态防重复提交 |
| 详情页签 | 切换页签时按需加载数据 |
