# 会员管理模块 - 前端实现设计

## 1. 文档概述

本文档描述会员管理模块的前端实现方案，包括组件设计、状态管理、API调用等实现要点。

- **API 接口规范**：参见 [API接口.md](./API接口.md)
- **需求规格**：参见 [需求规格.md](./需求规格.md)
- **UI-UX 设计规范**：参见 [01-产品设计/02-UI-UX设计规范.md](../../../01-产品设计/02-UI-UX设计规范.md)

## 2. 组件架构设计

### 2.1 用户端组件结构

```
会员中心页面 (MemberCenter/index.vue)
├── 等级卡片 (LevelCard)
│   ├── 等级图标与名称
│   ├── 到期时间/成长值维持标识
│   └── 升级按钮
├── 成长值进度 (GrowthProgress)
│   ├── 当前成长值
│   ├── 距下一等级差值
│   └── 进度条
├── 权益概览 (BenefitsOverview)
│   ├── 本月剩余次数（去雾/评估）
│   ├── 批量上限
│   └── 已解锁功能列表
└── 升级引导 (UpgradeGuide)
    ├── 下一等级权益对比
    └── 升级按钮
```

### 2.2 成长值明细组件

```
成长值明细页面 (GrowthLogs/index.vue)
├── 筛选容器
│   └── 时间/类型筛选
└── 流水列表
    └── 流水卡片 (GrowthLogCard)
```

### 2.3 签到组件

```
签到模块 (SignIn)
├── 签到日历 (SignInCalendar)
│   └── 月历展示签到情况
└── 签到按钮 (SignInButton)
```

### 2.4 后台管理组件结构

```
会员管理页面 (MemberManagement/index.vue)
├── 搜索容器
│   ├── 搜索表单 (SearchForm)
│   └── 操作按钮区域 (ActionButtons)
└── 数据展示区域
    ├── 会员表格 (MemberTable)
    └── 分页组件 (Pagination)

弹窗组件 (MemberDialog)
├── 会员详情弹窗 (MemberDetailDialog)
│   ├── 基本信息
│   ├── 成长值流水
│   ├── 消费记录
│   ├── 权益使用
│   └── 操作日志
├── 等级调整弹窗 (LevelAdjustDialog)
├── 成长值调整弹窗 (GrowthAdjustDialog)
└── 冻结弹窗 (FreezeDialog)

权益配置页面 (BenefitConfig/index.vue)
└── 权益配置表格 (BenefitTable)
```

### 2.5 组件职责划分

| 组件名称 | 职责描述 | 复用性 |
|---------|---------|--------|
| **LevelCard** | 等级卡片展示，含图标、名称、到期时间 | 用户端专用 |
| **GrowthProgress** | 成长值进度条，含动画 | 用户端专用 |
| **BenefitsOverview** | 权益概览，次数与功能列表 | 用户端专用 |
| **SignInCalendar** | 签到日历，支持月历视图 | 用户端专用 |
| **MemberDetailDialog** | 会员详情多页签弹窗 | 后台专用 |
| **LevelAdjustDialog** | 等级调整表单弹窗 | 后台专用 |

## 3. 组件详细设计

### 3.1 等级卡片组件

#### 组件属性

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| levelCode | String | - | 会员等级 |
| levelName | String | - | 等级名称 |
| expireTime | String | - | 到期时间 |
| growthValue | Number | - | 成长值 |

#### 等级图标映射

| 等级 | 图标 | 颜色 |
|------|------|------|
| level_0 | user | 灰色 |
| level_1 | star | 蓝色 |
| level_2 | crown | 紫色 |
| level_3 | diamond | 金色 |

### 3.2 成长值进度条组件

#### 展示逻辑

| 场景 | 展示内容 |
|------|---------|
| 普通用户 | 进度 0-1000，距 VIP1 差值 |
| VIP1 | 进度 1000-5000，距 VIP2 差值 |
| VIP2 | 进度 5000-20000，距 SVIP 差值 |
| SVIP | 进度 100%，"已达最高等级" |

### 3.3 签到日历组件

#### 组件属性

| 属性 | 类型 | 说明 |
|------|------|------|
| signedDates | Array&lt;String&gt; | 已签到日期（yyyy-MM-dd） |
| continuousDays | Number | 当前连续天数 |

#### 交互

- 点击当日日期：若未签到则触发签到
- 已签到日期显示对勾标记
- 连续签到7天显示奖励图标

### 3.4 后台会员表格

#### 列定义

| 字段 | 列名 | 宽度 | 特殊处理 |
|------|------|------|---------|
| - | 选择 | 55px | 复选框 |
| username | 用户名 | 120px | - |
| nickname | 昵称 | 120px | - |
| levelName | 会员等级 | 100px | 等级标签（带颜色） |
| growthValue | 成长值 | 100px | - |
| monthlyUsed | 本月已用 | 100px | 去雾/评估分别显示 |
| expireTime | 到期时间 | 180px | NULL 显示"成长值维持" |

### 3.5 等级调整弹窗

| 属性 | 说明 |
|------|------|
| 标题 | 调整会员等级 |
| 宽度 | 600px |
| 表单布局 | 单列 |

| 字段 | 类型 | 必填 | 校验规则 |
|------|------|------|---------|
| levelCode | 下拉选择 | ✅ | 等级选项 |
| expireTime | 日期选择 | ❌ | 永久/7天/30天/90天/自定义 |
| reason | 文本域 | ✅ | 最多200字符 |

### 3.6 成长值调整弹窗

| 字段 | 类型 | 必填 | 校验规则 |
|------|------|------|---------|
| changeValue | 数值输入 | ✅ | 整数，正负数 |
| reason | 文本域 | ✅ | 最多200字符 |

调整后展示预览：当前值 + 变动值 = 预期值。

## 5. API 调用设计

### 5.1 API 接口封装

使用 `dehaze-sdk-js` 提供的 MemberAPI 进行接口调用：

| 方法 | 功能 | 参数 |
|------|------|------|
| MemberAPI.getProfile | 当前用户会员信息 | - |
| MemberAPI.getGrowthLogs | 成长值明细 | queryParams |
| MemberAPI.signIn | 每日签到 | - |
| MemberAPI.getSignInCalendar | 签到日历 | year, month |
| MemberAPI.getPage | 后台分页查询 | queryParams |
| MemberAPI.getDetail | 会员详情 | userId |
| MemberAPI.adjustLevel | 等级调整 | userId, formData |
| MemberAPI.adjustGrowth | 成长值调整 | userId, formData |
| MemberAPI.updateStatus | 冻结/解冻 | userId, status, reason |
| MemberAPI.listBenefits | 权益配置列表 | - |
| MemberAPI.updateBenefit | 修改权益配置 | levelCode, formData |

### 5.2 请求错误处理

| 错误类型 | 处理方式 |
|---------|---------|
| MEMBER_NOT_FOUND | 提示"会员不存在" |
| MEMBER_FROZEN | 提示"会员已冻结" |
| SIGN_IN_ALREADY | 提示"今日已签到" |
| GROWTH_INSUFFICIENT | 提示"成长值不足" |
| BENEFIT_CONFIG_INVALID | 提示配置参数错误 |

## 6. 交互流程设计

### 6.1 会员中心初始化

1. 进入页面，显示骨架屏
2. 调用 `getProfile` 获取会员信息
3. 计算升级进度百分比
4. 渲染等级卡片、进度条、权益概览

### 6.2 关键流程说明

| 流程 | 关键点 |
|------|--------|
| 签到 | 查询今日签到状态 → 未签到则启用按钮 → 签到 → 动画展示 → 刷新日历与成长值 |
| 等级调整 | 加载等级选项 → 填写表单 → 降级二次确认 → 提交 → 刷新列表 |
| 成长值调整 | 输入变动值 → 预览结果 → 提交 → 刷新详情 |
| 冻结会员 | 填写原因 → 确认 → 状态变更 → 刷新列表 |

## 9. 性能优化设计

### 9.1 请求优化

| 优化项 | 实现方式 |
|--------|---------|
| 防抖处理 | 搜索输入防抖 300ms |
| 节流处理 | 签到按钮节流 3000ms |
| 并行请求 | 详情页并行加载基本信息与流水 |
| 请求缓存 | 权益配置缓存 5 分钟 |

### 9.2 渲染优化

| 优化项 | 实现方式 |
|--------|---------|
| 等级卡片动画 | CSS transition 实现等级升级动画 |
| 进度条动画 | requestAnimationFrame 平滑过渡 |
| 签到日历 | 虚拟滚动优化大量日期渲染 |
| 骨架屏 | 数据加载时显示骨架屏 |

### 9.3 缓存策略

| 数据类型 | 缓存位置 | 过期策略 |
|---------|---------|---------|
| 会员信息 | 组件状态 | 路由切换时清除 |
| 权益配置 | Pinia Store | 5 分钟 |
| 签到日历 | 组件状态 | 月切换时重新加载 |
