# 会员管理模块需求规格

## 1. 模块概述

### 1.1 模块定位

会员管理模块是系统商业化运营的核心模块，负责管理用户的会员等级、成长值、权益配置及会员全生命周期。该模块为去雾处理、效果对比等核心业务模块提供权益校验能力，同时与套餐管理、订单管理模块联动，构成完整的付费会员体系。

### 1.2 核心价值

| 价值维度 | 具体内容 |
|---------|---------|
| **等级体系** | 建立清晰的会员等级阶梯，激励用户持续使用和付费升级 |
| **权益驱动** | 通过差异化权益（次数配额、功能解锁、优先处理）提升付费转化 |
| **成长激励** | 成长值体系将用户行为量化，形成持续活跃的正向激励 |
| **运营管理** | 后台提供会员全景视图，支持等级调整、权益配置、数据统计 |

### 1.3 业务目标

#### 功能目标

- 建立四级会员等级体系（普通用户 → VIP1 → VIP2 → SVIP）
- 实现基于成长值的自动升降级机制
- 提供权益配置与管理能力
- 支持后台会员列表查询、等级调整、成长值管理

#### 性能目标

| 指标 | 目标值 | 说明 |
|-----|--------|------|
| 权益校验响应 | <50ms | 单次去雾/评估请求中的权益检查耗时 |
| 会员列表查询 | <500ms | 后台分页查询响应时间 |
| 等级变更生效 | <3s | 购买套餐后会员等级更新的延迟 |
| 成长值更新 | <1s | 用户行为后成长值写入延迟 |

### 1.4 模块依赖关系

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  套餐管理    │────▶│  订单管理    │────▶│  会员管理    │
│   模块      │     │    模块     │     │    模块     │
└─────────────┘     └─────────────┘     └──────┬──────┘
                                               │
                    ┌──────────────────────────┤
                    ▼                          ▼
             ┌─────────────┐           ┌─────────────┐
             │  去雾处理    │           │  效果对比    │
             │    模块     │           │    模块     │
             └─────────────┘           └─────────────┘
```

## 2. 会员等级体系

### 2.1 等级定义

| 等级 | 等级标识 | 成长值区间 | 定位 |
|------|---------|-----------|------|
| 普通用户 | `level_0` | 0 - 999 | 免费体验，引导转化 |
| VIP1 | `level_1` | 1000 - 4999 | 入门付费，满足轻度需求 |
| VIP2 | `level_2` | 5000 - 19999 | 进阶付费，满足中度需求 |
| SVIP | `level_3` | ≥20000 | 高级付费，满足重度/专业需求 |

### 2.2 权益配置

#### 2.2.1 核心权益 (F-MM-001)

| 权益项 | 普通用户 | VIP1 | VIP2 | SVIP |
|--------|---------|------|------|------|
| 每月去雾次数 | 20 | 100 | 500 | 3000 |
| 每月评估次数 | 20 | 100 | 500 | 3000 |
| 历史记录保留条数 | 10 | 50 | 100 | 500 |
| 批量处理上限 | 5 张 | 10 张 | 15 张 | 20 张 |
| 处理优先级 | 普通 | 优先 | 高优先 | 最高 |
| 高级参数调节 | ❌ | ✅ | ✅ | ✅ |
| 高清图导出 | ❌ | ✅ | ✅ | ✅ |
| 对比报告导出 | ❌ | ❌ | ✅ | ✅ |
| 批量打包下载 | ❌ | ❌ | ✅ | ✅ |

#### 2.2.2 权益校验逻辑

```
用户发起去雾/评估请求
    ↓
查询用户当前会员等级（Redis 缓存优先）
    ↓
查询对应等级的权益配置
    ↓
检查本月已用次数 < 配额上限
    ├─ 是 → 执行处理 → 扣减次数（Redis 原子操作 + 异步落库）
    └─ 否 → 返回次数不足提示 → 引导购买VIP/升级套餐
```

#### 2.2.3 次数重置规则

- 每月 1 日 00:00 自动重置去雾/评估次数
- 重置基于会员等级对应的配额，非累计
- 重置任务由定时任务执行，批量更新用户月度配额表
- 重置后推送通知（站内信/APP推送），告知用户次数已刷新

### 2.3 成长值体系 (F-MM-002)

#### 2.3.1 成长值获取规则

| 行为类型 | 成长值 | 频率限制 | 说明 |
|---------|--------|---------|------|
| 完成一次去雾处理 | +2 | 每日上限 10 | 鼓励核心功能使用 |
| 完成一次效果评估 | +1 | 每日上限 5 | 鼓励使用评估功能 |
| 提交处理评价 | +5 | 每日上限 5 | 鼓励用户反馈 |
| 每日签到 | +3 | 每日 1 次 | 维持日常活跃 |
| 连续签到 7 天 | +20 | 每周期 1 次 | 奖励持续活跃 |
| 购买套餐 | 按金额 1:1 | 无上限 | 消费直接转化为成长值 |

#### 2.3.2 成长值扣减规则

- 退款成功时，对应订单的成长值等额扣减
- 扣减后若成长值低于当前等级下限，触发降级
- 成长值不允许为负数，最低为 0

#### 2.3.3 成长值流水记录

每次成长值变动均记录流水，包含用户 ID、变动类型、变动值、变动后余额、关联业务 ID（订单号/任务 ID）、变动时间。

## 3. 会员生命周期管理

### 3.1 升级机制 (F-MM-003)

#### 3.1.1 升级条件

| 升级路径 | 条件 | 生效方式 |
|---------|------|---------|
| 普通 → VIP1 | 成长值 ≥ 1000 或 购买 VIP1 套餐 | 立即生效 |
| VIP1 → VIP2 | 成长值 ≥ 5000 或 购买 VIP2 套餐 | 立即生效 |
| VIP2 → SVIP | 成长值 ≥ 20000 或 购买 SVIP 套餐 | 立即生效 |

#### 3.1.2 升级流程

```
成长值变更 / 套餐支付成功
    ↓
检查是否达到更高等级门槛
    ├─ 是 → 更新用户等级 → 刷新权益配置 → 推送升级通知
    └─ 否 → 仅更新成长值
```

#### 3.1.3 升级通知

- 站内信：恭喜您升级至 {levelName}，已解锁 {权益列表}
- APP 推送：会员等级提升通知
- 个人中心：等级变更动画展示

### 3.2 降级机制 (F-MM-004)

#### 3.2.1 降级条件

会员等级通过套餐购买获得时，设有有效期保护：

| 场景 | 降级规则 |
|------|---------|
| 套餐到期未续费 | 等级降回成长值对应的等级 |
| 成长值因退款扣减 | 低于当前等级下限时立即降级 |
| 套餐到期但成长值达标 | 保持当前等级，不降级 |

#### 3.2.2 降级流程

```
套餐到期 / 退款扣减成长值
    ↓
计算成长值对应的目标等级
    ↓
目标等级 < 当前等级
    ├─ 是 → 更新用户等级 → 降级权益 → 推送降级预警（到期前7天）
    └─ 否 → 保持当前等级
```

#### 3.2.3 到期预警

- 套餐到期前 7 天：推送续费提醒
- 套餐到期前 3 天：推送续费提醒 + 降级后权益对比
- 套餐到期前 1 天：推送最后提醒
- 套餐到期当天：执行降级（如成长值不达标）

### 3.3 保级机制 (F-MM-005)

套餐到期时，若用户成长值仍达到当前等级门槛，则保持等级不变，权益从套餐权益降为成长值权益（差异：套餐有效期内的额外加成取消，如限时双倍次数等）。

## 4. 后台管理功能

### 4.1 会员列表查询 (F-MM-006)

#### 4.1.1 功能描述

提供会员信息的分页展示和多条件筛选，支持管理员快速定位目标会员。

#### 4.1.2 查询条件

| 条件类型 | 字段 | 说明 | 匹配方式 |
|---------|------|------|---------|
| 关键字搜索 | 用户名/昵称/手机号 | 多字段模糊匹配 | LIKE |
| 会员等级 | 等级标识 | 精确匹配 | = |
| 会员状态 | 有效/过期/冻结 | 精确匹配 | = |
| 到期时间 | 时间范围 | 套餐到期时间筛选 | BETWEEN |
| 成长值区间 | 最小值~最大值 | 数值范围 | BETWEEN |

#### 4.1.3 列表展示字段

| 字段 | 显示名称 | 说明 |
|------|---------|------|
| username | 用户名 | 登录账号 |
| nickname | 昵称 | 显示名称 |
| levelName | 会员等级 | 等级标签（带颜色） |
| growthValue | 成长值 | 当前成长值 |
| monthlyUsed | 本月已用次数 | 去雾/评估已用次数 |
| expireTime | 到期时间 | 套餐到期时间，无则为"成长值维持" |
| status | 状态 | 有效/过期/冻结 |
| createTime | 开通时间 | 首次成为会员的时间 |
| - | 操作 | 详情/调整等级/冻结/解冻 |

### 4.2 会员详情 (F-MM-007)

#### 4.2.1 功能描述

展示单个会员的完整信息，包括基本信息、等级信息、成长值流水、消费记录、权益使用情况。

#### 4.2.2 详情页签

| 页签 | 内容 | 数据来源 |
|------|------|---------|
| 基本信息 | 用户信息、会员等级、到期时间、成长值、累计消费 | `GET /api/v1/members/{userId}`（MemberDetailVO） |
| 成长值流水 | 时间、类型、变动值、余额、关联业务 | `GET /api/v1/members/growth-logs`（用户端接口，后台预览时切换登录态或前端模拟） |
| 消费记录 | 订单号、套餐名称、金额、支付时间、状态 | 订单管理模块接口 |
| 权益使用 | 本月去雾次数、评估次数、批量处理次数的使用明细 | MemberDetailVO 中 monthly 配额字段 |
| 操作日志 | 等级调整、冻结/解冻等后台操作记录 | 系统操作日志模块接口 |

> **说明**：`GET /api/v1/members/{userId}` 返回的 `MemberDetailVO` 包含基本信息和权益使用数据，成长值流水/消费记录/操作日志需调用对应模块的接口加载。

### 4.3 等级调整 (F-MM-008)

#### 4.3.1 功能描述

管理员可手动调整用户会员等级，适用于客服补偿、活动奖励等场景。

#### 4.3.2 操作流程

```
选择目标用户 → 点击"调整等级"
    ↓
选择目标等级 + 填写调整原因
    ↓
选择有效期（永久/7天/30天/90天/自定义）
    ↓
二次确认 → 确认调整
    ↓
更新用户等级 → 记录操作日志 → 推送通知给用户
```

#### 4.3.3 业务规则

1. 调整需填写原因，记录操作人和操作时间
2. 降级操作需二次确认
3. 调整后立即生效，权益同步更新
4. 手动调整不影响成长值

### 4.4 成长值管理 (F-MM-009)

#### 4.4.1 功能描述

管理员可手动调整用户成长值，适用于活动奖励、补偿等场景。

#### 4.4.2 操作流程

输入调整值（正数增加/负数扣减）→ 填写调整原因 → 确认调整 → 记录流水 → 检查等级变更

#### 4.4.3 业务规则

1. 扣减后成长值不低于 0
2. 调整后自动检查等级升降
3. 调整记录永久保留，不可删除
4. 需记录操作人、操作时间、调整原因

### 4.5 会员冻结/解冻 (F-MM-010)

#### 4.5.1 功能描述

管理员可冻结违规会员，冻结后会员权益暂停使用。

#### 4.5.2 冻结规则

- 冻结后：会员等级保留，但无法使用去雾/评估功能
- 解冻后：权益恢复，次数配额不补回冻结期间消耗
- 冻结需填写原因，记录操作日志
- 冻结期间套餐到期时间不顺延

### 4.6 权益配置管理 (F-MM-011)

#### 4.6.1 功能描述

管理员可配置各等级的权益参数，支持动态调整。

#### 4.6.2 可配置项

| 配置项 | 类型 | 说明 |
|--------|------|------|
| 月度去雾次数 | 数值 | 各等级每月去雾配额 |
| 月度评估次数 | 数值 | 各等级每月评估配额 |
| 历史记录保留条数 | 数值 | 各等级历史记录上限 |
| 批量处理上限 | 数值 | 单次批量处理最大图片数 |
| 处理优先级 | 枚举 | 普通/优先/高优先/最高 |
| 高级参数调节 | 布尔 | 是否开放高级参数 |
| 高清图导出 | 布尔 | 是否开放高清导出 |
| 对比报告导出 | 布尔 | 是否开放报告导出 |
| 批量打包下载 | 布尔 | 是否开放批量下载 |

#### 4.6.3 业务规则

1. 权益配置修改后立即生效
2. 已购买套餐的用户，取套餐权益与等级权益的较高值
3. 配置变更记录操作日志

## 5. 用户端功能

### 5.1 会员中心展示 (F-MM-012)

#### 5.1.1 功能描述

在个人中心展示用户当前会员状态、权益概览、成长值进度。

#### 5.1.2 展示内容

| 区域 | 内容 |
|------|------|
| 等级卡片 | 当前等级图标、等级名称、到期时间/成长值维持 |
| 成长值进度条 | 当前成长值、距下一等级的差值、进度百分比 |
| 权益概览 | 本月剩余次数（去雾/评估）、批量上限、已解锁功能列表 |
| 升级引导 | 下一等级权益对比、升级按钮 |

### 5.2 成长值明细 (F-MM-013)

#### 5.2.1 功能描述

展示用户成长值的变动记录，支持按时间和类型筛选。

#### 5.2.2 展示字段

| 字段 | 说明 |
|------|------|
| 变动时间 | 精确到分钟 |
| 变动类型 | 去雾处理/评估/评价/签到/消费/退款扣减/管理员调整 |
| 变动值 | +X / -X |
| 变动后余额 | 该次变动后的成长值 |
| 关联信息 | 订单号/任务ID/签到天数 |

### 5.3 签到功能 (F-MM-014)

#### 5.3.1 功能描述

每日签到获取成长值，连续签到有额外奖励。

#### 5.3.2 签到规则

- 每日可签到 1 次，签到后获得 3 成长值
- 连续签到 7 天额外获得 20 成长值
- 中断签到后连续天数归零，重新计算
- 签到日历展示当月签到情况

## 6. 非功能需求

### 6.1 性能需求

| 指标 | 要求 |
|-----|------|
| 权益校验 | Redis 缓存命中率 >95%，缓存未命中时 DB 查询 <50ms |
| 成长值写入 | 异步写入，用户无感知延迟 |
| 月度配额重置 | 全量用户重置在 1 小时内完成 |
| 会员列表查询 | 支持万级会员数据，分页查询 <500ms |

### 6.2 安全需求

| 方面 | 措施 |
|-----|------|
| 权益防篡改 | 次数扣减使用 Redis 原子操作（DECR），防止并发超扣 |
| 成长值防刷 | 签到、评价等行为做频率限制和防重复校验 |
| 操作审计 | 所有后台调整操作记录操作人、时间、原因 |
| 数据一致性 | 成长值变更与等级变更在同一个事务中 |

### 6.3 可用性需求

| 方面 | 要求 |
|-----|------|
| 缓存降级 | Redis 不可用时降级为 DB 查询，不影响核心功能 |
| 重置容错 | 月度配额重置失败时自动重试，失败记录告警 |
| 通知送达 | 升级/降级/到期通知至少保证站内信送达 |

## 8. 待确认事项

1. **成长值衰减机制**：长期不活跃用户的成长值是否需要衰减？若需要，衰减规则如何设计？
2. **跨等级权益叠加**：用户通过套餐直接购买 SVIP 但成长值仅 500，套餐到期后降到哪个等级？
3. **企业会员**：是否需要支持企业会员（多人共享配额）？当前设计仅支持个人会员。
4. **积分与成长值关系**：是否需要区分积分（可消费）和成长值（决定等级）？当前设计合并为成长值。
5. **会员转让**：会员权益是否允许转让给其他用户？
