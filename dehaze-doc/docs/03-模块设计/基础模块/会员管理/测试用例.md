## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **用户数据** | 各等级会员用户（普通/VIP1/VIP2/SVIP） | 用于等级查询、权益校验测试 |
| **会员记录** | 各状态会员（正常/冻结） | 用于状态管理测试 |
| **权益配置** | 四个等级默认权益配置（sys_member_benefit） | 用于权益读取与覆盖测试 |
| **成长值流水** | 不同类型的成长值变动记录 | 用于流水查询测试 |
| **签到数据** | 连续签到用户、中断签到用户 | 用于连续签到计算测试 |

### 3.2 数据清理策略

- 测试用户使用统一前缀 `test_member_` 标识
- 测试会员记录的 `user_id` 关联测试用户
- 测试结束按前缀清理会员记录与流水记录

### 3.3 测试范围

**包含的功能点：**
- 会员信息查询（用户端 profile、后台列表/详情）
- 会员等级体系（升级/降级/保级机制）
- 成长值管理（获取/扣减/手动调整/流水查询）
- 权益配置与校验
- 月度配额重置
- 签到功能
- 会员冻结/解冻

**不包含的功能点：**
- 用户注册流程（用户管理模块测试）
- 套餐购买流程（套餐/订单模块测试）
- 去雾处理与评估的次数扣减（业务模块测试）

## 5. 关键边界与异常场景

| 场景 | 测试点 | 期望行为 |
|------|--------|---------|
| **会员数量边界** | 会员达到10000+ | 列表查询响应时间仍&lt;500ms |
| **成长值并发变动** | 同时触发多种成长值变动 | 流水记录顺序正确，余额最终一致 |
| **配额并发扣减** | 并发去雾请求 | Redis 原子操作，无超扣 |
| **等级变更一致性** | 成长值变动触发等级变更 | 成长值变更与等级变更在同一事务 |
| **缓存与DB一致性** | 权益配置修改后 | Redis 缓存主动刷新，后续请求读新值 |
| **冻结与套餐到期** | 冻结期间套餐到期 | 到期时间不顺延，成长值达标则保级 |
| **保级机制** | level_source=purchase/admin 时成长值低于等级下限 | 不自动降级，仅 growth 来源才降级 |
| **到期预警幂等** | 同一天重复执行预警任务 | 消息幂等检查，仅推送一次 |
| **月度重置幂等** | 重复执行月度重置任务 | quota_reset_month 判断，不重复重置 |
