# 推荐管理模块测试用例

## 1. 测试目标

覆盖需求规格中的 F-REC-001 ～ F-REC-004 与推荐效果度量，并验证权限控制与未登录访问。

---

## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **测试用户** | 普通用户、管理员各 1 名 | 验证权限矩阵 |
| **测试图片 URL** | 不同 URL 若干（jpg/png/webp 等合法格式） | 特征分析确定性验证 |
| **算法数据** | 已发布算法若干、未发布算法若干 | 验证候选池过滤 |
| **推荐规则** | 各场景类型规则若干（含启用/禁用） | 验证规则匹配 |

### 3.2 数据清理策略

- 测试推荐记录使用统一测试用户，测试结束后清空该用户的推荐历史
- 测试规则配置修改后恢复为默认值

### 3.3 测试范围

**不包含：**

- 隐式反馈（采纳/评分/收藏）
- 冷启动、离线批量分析、A/B 测试
- 收藏/评分/VIP 与推荐的集成
- 报表扩展内容（场景准确率、算法采纳率、反馈分布）

## 6. 性能与并发测试

> 图像特征分析 / 推荐结果生成 / 端到端推荐的性能目标见 [需求规格.md](./需求规格.md) 第 1.3 节。

| 指标 | 目标值 | 测试方法 |
|------|--------|---------|
| **反馈提交响应** | < 200ms | 单次反馈操作 |
| **规则配置更新响应** | < 500ms | 管理员更新规则 |

### 并发场景

| 场景 | 并发数 | 验证点 |
|------|--------|--------|
| **并发获取推荐** | 50 用户 | 推荐结果正确，响应稳定 |
| **并发提交反馈** | 30 用户 | 反馈记录正确，无丢失 |
| **管理员并发更新规则** | 2 管理员 | 后提交者覆盖前值（无乐观锁，接口幂等性验证） |
