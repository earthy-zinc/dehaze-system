# 推荐管理模块测试用例

## 1. 测试目标

- [x] 验证图像特征分析（Mock 7 维特征、URL 校验、imageId 暂不支持）
- [x] 验证算法推荐（Top 3 推荐、匹配度、推荐理由、规则匹配）
- [x] 验证推荐反馈（有用/无用显式反馈）记录正确
- [x] 验证推荐规则管理（管理员 CRUD、权重校验、权限控制）
- [x] 验证推荐效果度量（采纳率、覆盖率、趋势统计）
- [x] 验证安全性（权限控制、未登录访问）

---

## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **测试用户** | 普通用户、管理员各 1 名 | 验证权限矩阵 |
| **测试图片 URL** | 不同 URL 若干（jpg/png/webp 等合法格式） | 特征分析确定性验证 |
| **算法数据** | 已发布算法若干、未发布算法若干 | 验证候选池过滤 |
| **推荐规则** | 各场景类型规则若干（含启用/禁用） | 验证规则匹配 |

### 3.2 数据清理策略

- 测试推荐记录使用统一测试用户，测试结束后清空该用户的推荐历史
- 测试规则配置修改后恢复为默认值

### 3.3 测试范围

**包含的功能点：**

- 图像特征分析（F-REC-001）：Mock 7 维特征、URL 扩展名校验、imageId 不支持、确定性
- 算法推荐（F-REC-002）：Top 3、匹配度、推荐理由、规则匹配、已发布算法过滤
- 推荐反馈（F-REC-003）：显式反馈（有用/无用）
- 推荐规则管理（F-REC-004）：规则新增/更新/禁用、权重校验、权限控制
- 推荐效果度量：采纳率、覆盖率、趋势统计

**不包含的功能点（功能尚未实现，不在测试范围内）：**

- 真实图像特征分析（当前 Mock）
- 隐式反馈（采纳/评分/收藏）
- 特征维度权重、算法评分权重、Top N、冷启动参数配置
- 报表扩展内容（场景准确率、算法采纳率、反馈分布）
- 收藏/评分/VIP 集成、冷启动场景
- 替代算法推荐、离线批量分析、A/B 测试

## 5. 关键边界与异常场景

| 场景 | 测试点 | 期望行为 |
|------|--------|---------|
| **非图片文件** | .txt/.pdf URL | 返回 `A0701` 文件格式不支持 |
| **imageId 方式** | 仅传 imageId | 返回"imageId方式暂不支持" |
| **参数缺失** | 均未提供 | 返回 `A0400` 参数错误 |
| **无已发布算法** | 系统无 status=4 算法 | 返回空列表，不报错 |
| **算法不足 Top N** | 候选 < 3 个 | 返回实际数量，不报错 |
| **规则权重非法** | 权重 <0 或 >100 | 返回 `A0500` 配置不合法 |
| **禁用规则** | 规则 enabled=0 | 不参与推荐匹配 |
| **跨用户推荐隔离** | 用户 A 的推荐记录 | 推荐记录按 user_id 归属，反馈互不影响 |

## 6. 性能与并发测试

> 性能目标参见 [需求规格.md](./需求规格.md) 第 1.3 节。当前特征分析为 Mock（无真实图像处理耗时），性能验证以推荐链路响应为主。

| 指标 | 目标值 | 测试方法 |
|------|--------|---------|
| **图像特征分析** | < 2s | 分析请求响应 |
| **推荐结果生成** | < 500ms | 获取推荐请求响应 |
| **端到端推荐** | < 3s | 分析 + 推荐整体链路 |
| **反馈提交响应** | < 200ms | 单次反馈操作 |
| **规则配置更新响应** | < 500ms | 管理员更新规则 |

### 并发场景

| 场景 | 并发数 | 验证点 |
|------|--------|--------|
| **并发获取推荐** | 50 用户 | 推荐结果正确，响应稳定 |
| **并发提交反馈** | 30 用户 | 反馈记录正确，无丢失 |
| **管理员并发更新规则** | 2 管理员 | 后提交者覆盖前值（无乐观锁，接口幂等性验证） |

## 7. 安全性测试

| 测试项 | 验证方式 | 预期结果 |
|--------|---------|---------|
| **未登录访问** | 未登录调用推荐接口 | 返回 `A0230` token无效 |
| **非管理员访问规则管理** | 普通用户调用 GET/PUT /rules | 返回 `A0301` 访问未授权 |
| **非管理员访问报表** | 普通用户调用 GET /report | 返回 `A0301` 访问未授权 |
| **文件格式校验** | 非图片扩展名 URL | 返回 `A0701` 文件格式不支持 |
| **SQL 注入** | 参数包含恶意字符 | 参数化查询防护 |
| **反馈归属隔离** | 用户 A 反馈用户 B 的推荐记录 | 当前接口按 ID 直接更新，**不校验归属**，任何登录用户可反馈任意 recommendationId（反馈记录写入当前操作用户） |
