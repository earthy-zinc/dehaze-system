## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **测试用户** | 普通用户、进阶用户、VIP 用户、管理员各 1 名 | 验证权限矩阵 |
| **测试图片** | 城市雾霾、自然风景、夜景、逆光、高噪声、纯色、极小、超大图片各 1 张 | 覆盖各场景特征 |
| **算法数据** | 已发布算法（DCP、CAP、AOD-Net、FFA-Net、DehazeFormer、GridDehazeNet）各 1 个 | 验证推荐匹配 |
| **实验性算法** | experimental 类型算法 1 个 | 验证 VIP 可见性 |
| **新算法** | 上线 < 7 天的算法 1 个 | 验证冷启动 |
| **推荐规则** | 默认规则配置 | 验证规则管理 |
| **反馈数据** | 历史推荐反馈记录若干 | 验证效果度量 |

### 3.2 数据清理策略

- 测试推荐记录使用统一测试用户，测试结束后清空该用户的推荐历史
- 测试规则配置修改后恢复为默认值
- 测试算法状态在测试结束后恢复

### 3.3 测试范围

**包含的功能点：**

- 图像特征分析（F-REC-001）：7 维特征提取、多场景分析
- 算法推荐（F-REC-002）：Top 3 推荐、匹配度、推荐理由
- 推荐反馈（F-REC-003）：显式反馈、隐式反馈（采纳/评分/收藏）
- 推荐规则管理（F-REC-004）：规则配置、权重调整、冷启动参数
- 推荐效果度量：采纳率、满意度、覆盖率计算
- 跨模块集成：算法管理、收藏管理、反馈评价、会员管理
- 冷启动场景：新算法推荐曝光

**不包含的功能点：**

- 参数方案推荐（preset，规划中）
- 数据集推荐（dataset，规划中）
- 增强策略推荐（enhance，规划中）
- A/B 测试框架（待确认事项）
- 离线批量分析（待确认事项）
- UI 组件渲染细节

## 5. 关键边界与异常场景

| 场景 | 测试点 | 期望行为 |
|------|--------|---------|
| **极小图片分析** | 100x100 图片 | 正常分析，返回特征 |
| **超大图片分析** | 4K 图片 | 正常分析，响应满足性能目标 |
| **纯色图片分析** | 纯黑/纯白图片 | 正常返回（复杂度极低） |
| **非图片文件** | .txt/.pdf 文件 | 返回 `A0701` 文件格式不支持 |
| **图片损坏** | 截断的图片文件 | 返回分析失败 |
| **无可用算法** | 系统无已发布算法 | 返回空列表或提示 |
| **算法不足 Top N** | 可用算法 < 3 个 | 返回实际数量，不报错 |
| **无匹配场景** | 特征极端，无匹配规则 | 返回默认推荐 |
| **规则权重非法** | 权重总和 ≠ 100% | 返回 `A0500` 配置不合法 |
| **修改禁用规则** | 规则处于禁用状态 | 返回 `A0502` 状态不允许 |
| **分析超时** | 算法服务响应慢 | 返回 `B0100` 系统超时 |
| **冷启动曝光** | 新算法上线 < 7 天 | 按策略获得曝光 |
| **VIP 权益差异** | 普通用户 vs VIP | 实验性算法可见性差异 |
| **跨用户反馈隔离** | 用户 A 的反馈影响用户 B | 各用户反馈独立计算，不串扰 |
