# 推荐管理模块 - 前端实现设计

## 1. 文档概述

本文档描述推荐管理模块的前端实现方案，聚焦组件架构、状态管理、路由设计等架构决策。推荐管理模块为用户提供基于图像特征分析的智能算法推荐能力，并支持管理员配置推荐规则和查看效果报表。

---

## 2. 组件设计

### 2.1 组件结构

```
推荐管理模块
├── RecommendationWidget           # 推荐主组件（可嵌入算法选择/去雾处理/图像输入页面）
│   ├── ImageUploader              # 图片上传/选择（复用图像输入模块组件）
│   ├── AnalysisProgress           # 特征分析进度展示（骨架屏 + 阶段提示）
│   ├── FeatureResultPanel         # 特征分析结果展示
│   │   ├── HazeLevel              # 雾霾浓度（轻度/中度/重度 + 置信度）
│   │   ├── SceneType              # 场景类型（城市/自然风景/建筑/夜景等）
│   │   ├── LightCondition         # 光照条件（进阶用户可见）
│   │   └── TechnicalMetrics       # 技术指标（噪声/分辨率/复杂度，进阶用户可见）
│   ├── RecommendationList         # Top 3 推荐算法列表
│   │   ├── RecommendationCard     # 单个推荐卡片
│   │   │   ├── MatchScore         # 匹配度可视化（进度条/星级）
│   │   │   ├── ReasonText         # 推荐理由
│   │   │   ├── RatingInfo         # 算法综合评分
│   │   │   ├── ExpectedEffect     # 预期效果（耗时预估/效果风格）
│   │   │   └── ActionButtons      # 操作按钮
│   │   │       ├── UseButton      # 一键使用推荐算法
│   │   │       ├── DetailButton   # 查看算法详情
│   │   │       └── CompareButton  # 加入对比
│   │   └── EmptyState             # 无推荐结果提示
│   └── FeedbackBar                # 反馈栏（有用/无用按钮）
├── RecommendationAdminPage        # 管理员推荐规则配置页面（独立路由）
│   ├── RuleList                   # 规则列表（场景类型→算法映射）
│   ├── RuleEditor                 # 规则编辑弹窗
│   │   ├── SceneSelector          # 场景类型选择
│   │   ├── AlgorithmMultiSelect   # 算法多选
│   │   └── WeightInput            # 权重设置
│   ├── WeightConfigPanel          # 特征维度权重配置面板（7 维度滑块）
│   ├── ColdStartConfigPanel       # 冷启动参数配置面板
│   └── RecommendationReport       # 推荐效果报表
│       ├── AdoptionTrendChart     # 采纳率趋势图（ECharts 折线图）
│       ├── CoverageChart          # 推荐覆盖率图表
│       ├── SceneAccuracyTable     # 各场景推荐准确率表格
│       └── FeedbackDistribution   # 用户反馈分布（有用/无用占比）
```

### 2.2 组件职责

| 组件 | 职责 | 复用性 |
|------|------|--------|
| RecommendationWidget | 推荐主组件，封装特征分析→推荐→反馈完整流程 | 高度可复用，供多页面嵌入 |
| ImageUploader | 图片上传/选择入口 | 复用图像输入模块组件 |
| AnalysisProgress | 特征分析阶段进度展示 | 不可复用 |
| FeatureResultPanel | 特征分析结果展示，按用户角色分级显示 | 可复用 |
| RecommendationList | Top 3 推荐算法列表渲染 | 可复用 |
| RecommendationCard | 单个推荐算法卡片 | 可复用 |
| FeedbackBar | 推荐结果反馈栏 | 可复用 |
| RecommendationAdminPage | 管理员规则配置页面容器 | 不可复用 |
| RuleList | 推荐规则列表展示与管理 | 不可复用 |
| RuleEditor | 规则编辑弹窗 | 可复用于其他规则编辑场景 |
| WeightConfigPanel | 7 维特征权重配置 | 不可复用 |
| ColdStartConfigPanel | 冷启动参数配置 | 不可复用 |
| RecommendationReport | 推荐效果报表容器 | 不可复用 |
| AdoptionTrendChart | 采纳率趋势图 | 复用通用图表组件 |
| CoverageChart | 覆盖率图表 | 复用通用图表组件 |

### 2.3 RecommendationWidget 嵌入位置

| 嵌入页面 | 使用场景 | 说明 |
|---------|---------|------|
| 算法选择页面 | 默认入口，上传图片获取推荐 | 作为推荐面板的默认数据源 |
| 去雾处理页面 | 无算法选择时引导用户获取推荐 | 引导式弹窗或侧边栏 |
| 图像输入页面 | 快速体验流程，上传后直接推荐 | 图片上传完成后自动展示 |

## 3. 页面布局设计

### 3.1 用户推荐页面结构

RecommendationWidget 采用**纵向流式布局**：

| 区域 | 说明 |
|------|------|
| 图片上传区 | 支持拖拽上传、点击选择、从历史记录选择 |
| 分析进度区 | 骨架屏 + 阶段提示文字 |
| 特征结果区 | 分级展示图像特征分析结果 |
| 推荐列表区 | Top 3 推荐算法卡片纵向排列 |
| 反馈栏 | 推荐列表底部，有用/无用按钮 |

### 3.2 管理员配置页面结构

采用**左侧导航 + 右侧内容**的双栏布局：

| 区域 | 宽度 | 说明 |
|------|------|------|
| 左侧导航 | 200px | 规则列表 / 权重配置 / 冷启动配置 / 效果报表 |
| 右侧内容 | 自适应填充 | 对应配置面板或报表 |

### 3.3 响应式布局

| 屏幕尺寸 | 用户推荐 | 管理员配置 |
|---------|---------|-----------|
| 桌面端（>=992px） | 单栏居中，最大宽度 800px | 双栏布局 |
| 移动端（<992px） | 全宽流式 | 单栏，左侧导航转为顶部 Tab |

### 3.4 路由设计

| 路由路径 | 页面 | 说明 |
|---------|------|------|
| `/recommendations` | RecommendationWidget（独立页面） | 用户推荐入口（可选） |
| `/admin/recommendations/rules` | RecommendationAdminPage | 管理员规则配置 |
| `/admin/recommendations/report` | RecommendationReport | 推荐效果报表 |

路由守卫：
- `/admin/recommendations/*` 路由需管理员权限校验，非管理员跳转 403 页面

## 4. 状态管理

### 4.1 状态定义

| Store | 职责 |
|-------|------|
| recommendStore | 推荐流程状态：图片、特征分析、推荐结果、反馈 |
| recommendAdminStore | 管理配置状态：规则列表、权重配置、报表数据 |

### 4.2 recommendStore 核心状态

| 状态字段 | 类型 | 说明 |
|---------|------|------|
| currentImage | object | 当前分析图片（imageId/url） |
| analyzing | boolean | 特征分析中状态 |
| analyzeStage | string | 当前分析阶段提示（"分析雾霾浓度..."/"匹配算法..."） |
| features | object | 特征分析结果（7 维特征向量 + 置信度） |
| recommendations | array | Top 3 推荐算法列表 |
| recommendLoading | boolean | 推荐结果加载状态 |
| feedbackSubmitted | object | 各推荐项的反馈状态（recommendId → useful/not_useful） |
| error | object | 分析/推荐错误信息 |

### 4.3 recommendStore Actions

| 方法 | 说明 |
|------|------|
| analyzeImage(imageId/file) | 触发图像特征分析 |
| fetchRecommendations() | 基于特征分析结果获取 Top 3 推荐 |
| submitFeedback(recommendId, feedback) | 提交推荐反馈（useful/not_useful） |
| resetAnalysis() | 重置分析状态，清空图片和结果 |
| useRecommendation(algorithmId) | 确认使用推荐算法，跳转去雾处理页面 |

### 4.4 recommendAdminStore 核心状态

| 状态字段 | 类型 | 说明 |
|---------|------|------|
| ruleList | array | 推荐规则列表（场景→算法映射） |
| weightConfig | object | 7 维特征权重配置 |
| coldStartConfig | object | 冷启动参数配置 |
| reportData | object | 推荐效果报表数据 |
| reportLoading | boolean | 报表加载状态 |
| editingRule | object | 当前编辑的规则对象 |

### 4.5 recommendAdminStore Actions

| 方法 | 说明 |
|------|------|
| fetchRules() | 获取推荐规则列表 |
| updateRule(rule) | 更新推荐规则 |
| addRule(rule) | 新增推荐规则 |
| deleteRule(ruleId) | 删除推荐规则 |
| updateWeightConfig(config) | 更新特征维度权重 |
| updateColdStartConfig(config) | 更新冷启动参数 |
| fetchReport(params) | 获取推荐效果报表（支持日/周/月维度） |
| previewRecommendation(imageId) | 即时预览：修改权重后测试推荐效果 |

## 5. 数据流

### 5.1 推荐流程

```
用户上传/选择图片
    ↓
调用 analyzeImage(imageId)
    ↓ 显示骨架屏 + 阶段提示
后端返回 7 维特征分析结果
    ↓
更新 features → 渲染 FeatureResultPanel
    ↓
调用 fetchRecommendations()
    ↓
后端基于特征匹配算法知识库
    ↓ 返回 Top 3 推荐（匹配度/理由/评分/预期效果）
渲染 RecommendationList
    ↓
用户操作：
  - 点击"一键使用" → useRecommendation() → 跳转去雾处理
  - 点击"查看详情" → 打开算法详情弹窗
  - 点击"加入对比" → 加入算法选择模块对比列表
```

### 5.2 反馈流程

```
用户点击推荐卡片底部"有用/无用"按钮
    ↓
调用 submitFeedback(recommendId, feedback)
    ↓
更新 feedbackSubmitted 本地状态（按钮置灰，不可重复反馈）
    ↓
后端记录反馈，用于优化推荐模型
```

### 5.3 管理配置流程

```
管理员进入 /admin/recommendations/rules
    ↓
调用 fetchRules() + 获取权重配置 + 冷启动配置
    ↓
渲染 RuleList + WeightConfigPanel + ColdStartConfigPanel
    ↓
管理员操作：
  - 编辑规则 → 打开 RuleEditor → 保存 → updateRule()
  - 调整权重 → 滑块拖动 → 可点击"预览效果"测试 → updateWeightConfig()
  - 配置冷启动 → 修改参数 → updateColdStartConfig()
```

### 5.4 模块间数据交互

| 交互方向 | 数据 | 说明 |
|---------|------|------|
| 图像输入 → 推荐管理 | imageId | RecommendationWidget 接收图片进行分析 |
| 推荐管理 → 算法选择 | 推荐结果 | 推荐结果作为算法选择的默认入口 |
| 推荐管理 → 去雾处理 | algorithmId | 用户确认使用推荐算法后跳转 |
| 推荐管理 → 算法选择 | 对比列表 | 推荐卡片的"加入对比"复用算法选择的对比功能 |
| 收藏管理 → 推荐管理 | 收藏行为 | 收藏行为作为推荐训练的正向信号 |
| 反馈评价 → 推荐管理 | 处理结果评分 | 评分作为推荐效果反馈 |
| 算法管理 → 推荐管理 | 算法列表/评分 | 作为推荐匹配的数据源 |

## 6. 关键交互决策

### 6.1 推荐结果展示形式

采用**卡片形式**展示 Top 3 推荐：

| 方案 | 选择理由 |
|------|---------|
| 卡片 | 信息密度适中，匹配度可视化（进度条），推荐理由独立呈现 |
| 列表 | 信息密度低，不适合强调推荐排序和匹配度 |

### 6.2 分析进度展示

采用**骨架屏 + 阶段提示**：

| 阶段 | 提示文案 |
|------|---------|
| 特征分析中 | "分析雾霾浓度..." → "识别场景类型..." → "评估光照条件..." |
| 匹配算法中 | "匹配最适合的算法..." |

骨架屏占位特征结果区和推荐列表区，避免内容跳变。

### 6.3 反馈按钮位置

反馈按钮位于推荐卡片底部，不干扰主流程（一键使用/查看详情/加入对比）。反馈后按钮置灰，不可重复提交。反馈为可选操作，不强制用户完成。

### 6.4 管理员配置即时预览

管理员修改特征维度权重后，可点击"预览效果"按钮，上传测试图片立即查看推荐结果变化。预览结果在配置面板右侧独立区域展示，不影响已保存的线上配置。

### 6.5 特征结果分级展示

| 用户角色 | 可见内容 |
|---------|---------|
| 普通用户 | 雾霾浓度、场景类型 |
| 进阶用户 | 普通用户内容 + 光照条件、技术指标（噪声/分辨率/复杂度） |
| 管理员 | 全部特征数据（含原始特征向量） |

## 8. 性能优化

| 优化项 | 实现方式 |
|--------|---------|
| 推荐结果缓存 | 同一图片的推荐结果缓存 5 分钟，避免重复分析 |
| 分析阶段提示 | 前端按固定间隔切换阶段文案，不依赖后端推送 |
| 图表懒加载 | 管理员报表图表按需加载（切换到报表 Tab 时才请求） |
| 请求取消 | 切换图片或离开页面时取消未完成的分析请求 |
| 权重预览防抖 | 权重滑块拖动时防抖 500ms 后才触发预览请求 |

## 9. 错误处理

| 错误类型 | 处理方式 |
|---------|---------|
| 图片上传失败 | 提示"图片上传失败"，支持重试 |
| 特征分析超时 | 提示"分析超时，请重试"，可跳过推荐直接浏览算法 |
| 特征分析失败 | 提示错误原因，支持重新上传图片 |
| 推荐结果为空 | 显示"暂无匹配推荐，请尝试浏览算法列表" |
| 反馈提交失败 | 静默重试一次，失败后不提示（反馈为非关键操作） |
| 规则保存失败 | 提示错误原因，保留编辑状态不丢失数据 |
| 报表加载失败 | 显示错误提示 + 重试按钮 |
