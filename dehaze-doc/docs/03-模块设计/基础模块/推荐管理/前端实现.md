# 推荐管理模块 - 前端实现设计

## 1. 文档概述

本文档描述推荐管理模块的前端实现方案（dehaze-front-vue），聚焦组件结构、推荐流程数据流、规则管理页面与关键交互决策。

---

## 2. 组件设计

### 2.1 组件结构

```
推荐管理模块
├── RecommendationPanel（components/RecommendationPanel/index.vue）  # 推荐面板（可嵌入算法选择页）
│   ├── 图像特征分析折叠面板（el-collapse）
│   └── Top 推荐算法列表（el-card 列表）
└── views/recommendation/rules/index.vue  # 推荐规则管理页（管理员）
    ├── 规则表格（el-table）
    ├── 新增/编辑对话框（el-dialog + el-form）
    └── 操作列（编辑/删除[=禁用]）
```

### 2.2 组件职责

| 组件 | 职责 | 复用性 |
|------|------|--------|
| RecommendationPanel | 推荐面板：接收 `imageId`/`imageUrl` prop → 特征分析 → 推荐列表 → 反馈 | 可复用（算法选择页使用） |
| rules/index.vue | 管理员规则配置页：规则列表、行内改权重/启停、新增/编辑、删除（禁用） | 独立页面 |

> **说明**：早期设计稿中的 RecommendationWidget / RecommendationAdminPage 拆分、ImageUploader / AnalysisProgress / FeatureResultPanel / RecommendationCard 等子组件、WeightConfigPanel / ColdStartConfigPanel / RecommendationReport（含 ECharts 图表）**均未实现**。

### 2.3 RecommendationPanel 嵌入位置

| 嵌入页面 | 使用场景 | 状态 |
|---------|---------|:----:|
| 算法选择页面 | 上传图片获取推荐，选择后跳转去雾处理 | ✅ 已实现 |

> 早期设计稿中的"去雾处理页面引导式弹窗、图像输入页面上传后自动推荐"**未实现**。

## 3. 页面布局设计

### 3.1 推荐面板（RecommendationPanel）

| 状态 | 展示内容 |
|------|---------|
| 未传入图片 | `el-empty` 空状态，提示通过 prop 传入 imageId/imageUrl |
| 分析中 | 圆形进度条（50%）+ "正在分析图像特征..." |
| 分析完成 | 特征分析折叠面板 + Top 推荐算法列表 |
| 分析失败 | `el-alert` 错误提示（可关闭） |

**特征分析折叠面板**：6 项特征网格（雾霾浓度[标签+置信度]、场景类型[标签+置信度]、光照条件、复杂度[进度条+颜色分级]、分辨率、噪声水平）。

**推荐算法卡片**：排名（圆形序号）、算法名 + 星级评分（el-rate 只读）、匹配度进度条（颜色分级：≥80 绿 / ≥60 橙 / 其他灰）、推荐理由、匹配度百分比 + 预计耗时（ms 自动格式化）、"选择"按钮 + "有用/无用"反馈按钮。

### 3.2 规则管理页（rules/index.vue）

| 区域 | 说明 |
|------|------|
| 顶部 | 标题"推荐规则管理" + "新增规则"按钮 |
| 表格 | 规则名称 / 场景类型（el-tag）/ 关联算法（el-tag 列表）/ 权重（行内 el-input-number）/ 启用状态（el-switch）/ 操作（编辑、删除） |
| 对话框 | 规则名称（输入）、场景类型（下拉：城市/风景/建筑/夜景/逆光/室内）、关联算法（多选，filterable）、权重（滑块 0-100）、启用状态（开关） |

> **说明**：删除操作为**禁用**（enabled=false），无物理删除；无报表页面（`GET /report` 接口已实现但前端未接入）。

## 4. 状态管理

推荐管理**无独立 Store**，状态在组件内局部管理：

| 组件 | 状态字段 | 说明 |
|------|---------|------|
| RecommendationPanel | analysis / recommendations / analyzing / error / feedbackLoading / imageReady | 分析结果、推荐列表、加载与错误状态 |
| rules/index.vue | loading / tableData / dialog / formData / submitting | 表格数据、对话框与表单状态 |

## 5. 数据流

### 5.1 推荐流程

```
页面传入 imageId / imageUrl（watch 触发）
    ↓
RecommendationAPI.analyze({ imageId, imageUrl })
    ↓ 分析完成
analysis 赋值 → 渲染特征折叠面板（imageReady=true）
    ↓
RecommendationAPI.getAlgorithmRecommendations({ imageMd5 })  # 取 Top 3
    ↓
渲染推荐卡片列表
    ↓
用户操作：
  - 点击"选择" → emit("select", algo) → 外层跳转去雾处理
  - 点击"有用/无用" → RecommendationAPI.submitFeedback({ recommendationId, useful })
```

### 5.2 规则管理流程

```
进入页面 → RecommendationAPI.getRules() + AlgorithmAPI.getOption()（算法选项用于名称映射）
    ↓
渲染表格（算法 ID → 名称映射）
    ↓
操作：
  - 新增/编辑 → 对话框 → RecommendationAPI.updateRule(formData.id || 0, formData)
  - 行内改权重 → updateRule(rule.id, {...rule})
  - 行内启停 → updateRule(rule.id, {...rule})
  - 删除 → ElMessageBox.confirm → updateRule(rule.id, {...rule, enabled: false})
```

### 5.3 模块间数据交互

| 交互方向 | 数据 | 说明 |
|---------|------|------|
| 算法选择 → 推荐管理 | imageId/imageUrl | 传入推荐面板 |
| 推荐管理 → 算法选择 | select 事件 | 选择推荐算法 |
| 推荐管理 → 算法管理 | 算法选项 | 规则页算法多选与名称映射 |

## 6. 关键交互决策

### 6.1 推荐卡片展示形式

采用**卡片列表**展示 Top 3 推荐：排名序号 + 算法名 + 星级 + 匹配度进度条 + 推荐理由 + 预计耗时，信息密度适中，匹配度可视化。

### 6.2 反馈交互

"有用/无用"按钮在推荐卡片底部，提交后按钮 loading，成功后提示；无推荐记录（recommendationId 为空）时提示"暂无反馈入口"。

### 6.3 特征分析结果展示

特征分析结果以**折叠面板**呈现（默认展开），6 项特征网格展示，所有登录用户可见，**无用户角色分级**（早期设计稿的普通用户/进阶用户/管理员分级展示未实现）。

## 7. 权限与会员控制

| 功能 | 控制方式 |
|------|---------|
| 推荐查询/反馈 | 登录用户即可（后端无权限标识，权限不足返回 A0301） |
| 规则管理 | 管理员：后端校验 `sys:recommendation:rule:view/edit`，普通用户访问返回 A0301 |
| 效果报表 | 管理员：后端校验 `sys:recommendation:report`，前端**未接入页面** |

> 推荐功能**无会员等级差异**（早期设计稿的 VIP 推荐优先级未实现）。

---

## 8. 性能优化

| 优化项 | 实现方式 |
|--------|---------|
| 推荐列表截取 | 前端 `list.slice(0, 3)` 仅展示 Top 3 |
| 分析/推荐分离 | analyze 完成后才请求推荐，避免串行等待 |
| 反馈局部 loading | 按 recommendationId 独立 loading，不阻塞其他卡片 |

---

## 9. 错误处理

| 错误类型 | 处理方式 |
|---------|---------|
| 图像分析失败 | `el-alert` 提示错误原因，可关闭 |
| 获取推荐失败 | `ElMessage.warning("未能获取推荐算法")`，保留分析结果 |
| 反馈提交失败 | `ElMessage.error("反馈提交失败")` |
| 规则保存失败 | `ElMessage.error("更新失败")`，保留对话框编辑状态 |
| 未传入图片 | 空状态提示（el-empty） |
