# 推荐管理模块需求规格

## 1. 模块概述

### 1.1 模块定位

推荐管理模块根据图像特征分析结果，按用户当前处理的任务类型（去雾/去雨/去雪/低光增强/超分辨率/去噪/图像修复）为用户推荐合适的图像处理算法，并提供推荐规则配置与推荐效果度量能力。该模块为算法选择页面提供"算法推荐"面板入口。

### 1.2 核心价值

| 价值维度 | 具体内容 |
|---------|---------|
| **降低选择门槛** | 用户无需了解算法差异，上传图片即可获得 Top 3 推荐 |
| **场景匹配** | 基于图像特征（场景类型）匹配预设规则，推荐理由可解释 |
| **规则可配置** | 管理员可配置场景→算法的映射规则及权重 |
| **效果可度量** | 推荐采纳率、覆盖率等基础指标统计 |

### 1.3 业务目标

#### 性能目标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 图像特征分析 | < 2s | 上传图片到完成特征提取 |
| 推荐结果生成 | < 500ms | 特征分析完成后生成推荐列表 |
| 端到端推荐 | < 3s | 用户上传图片到看到推荐结果 |
| 推荐覆盖率 | ≥ 80% | 有推荐结果的请求占比（推荐结果非空的请求数 / 总请求数） |
| 推荐采纳率 | ≥ 40% | 采纳数 / 展示数 |

## 2. 用户角色分析

### 2.1 主要用户角色

| 角色 | 描述 | 主要职责 |
|------|------|---------|
| **普通用户** | 需要图像处理但不懂算法选择的用户 | 上传图片获取推荐，一键使用推荐算法 |
| **系统管理员** | 管理推荐规则和权重的运营人员 | 配置推荐规则、查看推荐效果报表 |

### 2.2 权限矩阵

| 功能点 | 普通用户 | 管理员 |
|--------|:------:|:------:|
| 获取算法推荐 | ✅ | ✅ |
| 查看推荐理由 | ✅ | ✅ |
| 查看特征分析详情 | ✅ | ✅ |
| 反馈推荐效果（有用/无用） | ✅ | ✅ |

## 4. 功能需求

### 4.1 图像特征分析 (F-REC-001)

#### 4.1.1 功能描述

对用户选择的图像进行多维特征分析，输出结构化的图像特征向量，作为推荐匹配的输入。仅支持传入图片 URL，`imageId` 方式不支持。

#### 4.1.2 分析维度

| 维度 | 说明 |
|------|------|
| 雾霾浓度 | 轻度/中度/重度 + 置信度 |
| 场景类型 | 城市/风景/建筑/夜景/逆光/室内 + 置信度 |
| 光照条件 | 明亮/正常/偏暗/极暗/逆光 |
| 图像复杂度 | 0-1 数值（纹理/边缘/色彩） |
| 颜色分布 | 色温 + 饱和度 |
| 分辨率 | 标清/高清/超清 |
| 噪声水平 | 低/中/高 |

> 当前推荐匹配仅使用"场景类型"维度。

#### 4.1.3 分析结果展示

分析结果在折叠面板中展示全部维度，所有用户可见，无角色分级；复杂度以进度条可视化，颜色分布展示原始数值。

### 4.2 算法推荐 (F-REC-002)

#### 4.2.1 功能描述

基于图像特征分析结果，匹配推荐规则表，输出 Top 3 推荐算法列表，包含推荐理由和匹配度。

#### 4.2.2 推荐策略

采用**场景规则匹配**：确定图像场景类型（历史记录无法确定时回退为"城市"）→ 匹配该场景已启用的规则 → 取规则关联算法中已发布的部分作为候选 → 匹配度取该算法在命中规则中的最高权重（0-100）→ 按匹配度降序取 Top 3。

**推荐理由模板**（按场景类型，`算法名 + 理由`）：

| 场景类型 | 推荐理由模板 |
|---------|-------------|
| urban（城市） | 处理速度快，对城市雾霾效果出色 |
| landscape（风景） | 在自然场景下表现稳定，色彩还原度高 |
| building（建筑） | 深度模型，对建筑场景处理能力强 |
| night（夜景） | 低光照增强组合，避免过度暗化 |
| backlight（逆光） | HDR预处理提升暗部细节 |
| indoor（室内） | 室内场景适配，细节保留好 |

> 推荐由管理员配置的规则驱动，候选算法随规则变化。每次推荐均生成推荐记录，供反馈关联与效果度量。

#### 4.2.3 推荐结果展示

每个推荐算法展示：

| 字段 | 说明 |
|------|------|
| 算法名称 | 已发布算法的名称 |
| 匹配度 | 百分比（0-100，按规则权重计算） |
| 推荐理由 | 场景模板生成的一句话理由 |
| 算法评分、预期效果 | 不展示（无真实评分与耗时数据） |
| 操作 | 一键使用（`select` 事件，跳转图像处理） |

> 推荐列表仅按匹配度排序，无"按评分/按使用频率"排序选项。

### 4.3 推荐反馈 (F-REC-003)

#### 4.3.1 功能描述

用户对推荐结果进行显式反馈，反馈数据记录用于推荐效果度量。

#### 4.3.2 反馈方式

| 反馈方式 | 说明 |
|---------|------|
| 显式反馈 | "有用"/"无用"按钮 |

> 反馈仅用于报表统计，不参与后续推荐匹配。

### 4.4 推荐规则管理 (F-REC-004)

#### 4.4.1 功能描述

管理员可配置推荐规则（场景→算法映射）及权重。（规则 CRUD + 启用/禁用）。

#### 4.4.2 可配置项

| 配置项 | 说明 |
|--------|------|
| 场景匹配规则 | 新增/编辑/禁用场景→算法映射（规则名称/场景类型/关联算法/权重/启用状态） |
| 规则权重 | 0-100 数值，控制匹配优先级 |

删除规则实际为**禁用**，规则保留可追溯，可重新启用。

## 5. 推荐效果度量

### 5.1 核心指标

| 指标 | 定义 |
|------|------|
| 推荐覆盖率 | 有推荐结果的请求数 / 总请求数 |
| 推荐满意度 | 有反馈的推荐中"有用"的占比 |
| 趋势 | 按日聚合的采纳率 |

> 指标的计算方式见 [后端实现.md](./后端实现.md) 第 7 节。

### 5.2 报表

管理员可查询推荐效果报表，包含：推荐总量、覆盖率、采纳率、满意度、冷启动成功率、按日采纳率趋势。
