# 用户管理模块测试用例

## 1. 测试目标

验证用户管理模块的核心功能符合 [需求规格.md](./需求规格.md) 定义：

- **CRUD 操作**：用户列表查询（F-UM-001）、用户新增（F-UM-002）、用户编辑（F-UM-003）、用户删除含批量删除（F-UM-004）
- **密码管理**：密码重置（F-UM-005）、首次登录强制改密
- **状态管理**：启用/禁用（F-UM-006）、超级管理员保护
- **导入导出**：Excel 导入（F-UM-007）、导出（F-UM-008）、模板下载
- **场景覆盖**：正常流程、边界条件、异常分支、权限控制
- **非功能验证**：并发场景与数据一致性、性能指标、安全性（数据权限控制、超级管理员保护）

---

## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **部门数据** | 至少3级部门树结构 | 用于部门筛选、用户归属测试 |
| **角色数据** | 系统管理员、部门管理员、普通用户角色 | 用于权限验证测试 |
| **用户数据** | 各状态用户（启用/禁用）、各部门用户 | 用于列表查询、状态管理测试 |
| **字典数据** | 性别字典（男/女/未知） | 用于字典选择器测试 |

### 3.2 数据清理策略

- 测试用户数据使用统一前缀 `test_user_` 标识
- 测试结束后按前缀批量删除测试用户
- 保留系统默认管理员账户不做删除操作

### 3.3 测试范围

**包含的功能点：**
- 用户列表查询（分页、筛选、搜索）
- 用户新增、编辑、删除
- 密码重置、首次登录强制改密
- 状态管理（启用/禁用）
- 用户导入、导出

**不包含的功能点：**
- 登录认证流程（独立测试）
- 操作日志记录（依赖模块测试）
- 部门/角色管理功能（独立测试）

## 5. 关键边界与异常场景

| 场景 | 测试点 | 期望行为 |
|------|--------|---------|
| **用户数量边界** | 系统用户达到100万 | 列表查询响应时间仍&lt;500ms |
| **逻辑删除** | 删除用户后查询 | 已删除用户（deleted=1）默认不展示，不可登录 |
| **并发新增** | 同时新增相同用户名 | 只有一个成功，另一个提示用户名已存在 |
| **并发编辑** | 同一用户被多人同时编辑 | 乐观锁保护，冲突时提示重新加载 |
| **部门级联** | 选择父部门筛选 | 自动包含所有子部门用户 |
| **角色变更生效** | 修改用户角色后 | 用户权限立即更新，无需重新登录 |
| **会话一致性** | 禁用/删除/密码重置用户后 | 实时踢出该用户所有端在线会话，下次请求返回 401 |
| **批量操作限制** | 批量删除100+用户 | 按配置限制或分批处理 |

## 7. 安全性测试

| 测试项 | 验证方式 | 预期结果 |
|--------|---------|---------|
| **权限控制** | 无权限用户调用新增/编辑/删除接口 | 返回403 |
| **数据权限** | 部门管理员访问其他部门用户 | 返回403或数据过滤 |
| **SQL注入** | 参数中包含 `admin'--` | 被参数化查询转义，无SQL注入风险 |
| **XSS攻击** | 用户昵称注入 `&lt;script&gt;alert(1)&lt;/script&gt;` | 输出时编码，不执行脚本 |
| **密码安全** | 查询数据库密码字段 | 密码加密存储，非明文 |
| **传输安全** | 抓包分析请求 | 数据传输加密 |
| **防重复提交** | 快速连续点击提交 | 同一操作不可重复提交 |
