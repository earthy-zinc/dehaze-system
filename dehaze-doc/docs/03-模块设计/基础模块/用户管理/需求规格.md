# 用户管理模块需求规格

## 1. 模块概述

### 1.1 模块定位

用户管理模块是 AI 图像处理平台的核心基础模块之一，负责管理系统中所有用户账户的全生命周期。平台支持去雾/去雨/去雪/低光增强/超分辨率/去噪/图像修复等多任务图像处理，覆盖 Web（Vue/React）、Android、Flutter、Taro/UniApp 小程序、Electron 桌面端等多端，落地 VIP 会员商业化体系。用户管理模块为系统提供用户身份识别、权限分配、组织关联与商业化属性对接等基础能力，是整个平台安全体系与商业化的基石。

> **三后端契约**：Java/Go/Python 三后端 API 契约完全一致，Java 为权威来源，Go/Python 对齐。

> **职责边界**：认证管理模块负责用户注册流程（表单提交、验证码校验、创建用户记录、自动登录）；用户管理模块负责用户全生命周期管理（查询/编辑/禁用/删除/分配角色/密码重置/导入导出）。注册创建的用户记录由本模块维护，详见 [认证管理/需求规格.md](../认证管理/需求规格.md)。

### 1.2 核心价值

| 价值维度     | 具体内容                                           |
| ------------ | -------------------------------------------------- |
| **统一管理** | 提供系统用户的统一管理入口，实现用户全生命周期管理 |
| **权限控制** | 基于 RBAC 模型实现细粒度的权限控制，确保系统安全   |
| **组织关联** | 支持用户与部门、角色的关联管理，符合企业组织架构   |
| **商业化对接** | 与会员管理模块对接，展示会员等级、套餐、配额使用情况 |
| **批量操作** | 支持用户信息的批量导入导出，提高管理效率           |
| **安全保障** | 密码加密存储、权限验证、防重复提交等多重安全机制   |

### 1.3 业务目标

#### 功能目标

- 实现系统用户的统一管理（CRUD 操作，逻辑删除）
- 提供完善的用户权限控制体系（RBAC）
- 支持用户与组织架构的关联管理（部门、角色）
- 对接会员管理模块，展示会员等级、套餐、到期时间、配额使用情况
- 保障系统安全性和数据完整性

#### 性能目标

| 指标             | 目标值  | 说明                         |
| ---------------- | ------- | ---------------------------- |
| **列表查询响应** | &lt;500ms  | 用户列表分页查询响应时间     |
| **表单提交响应** | &lt;1s     | 新增/编辑用户操作响应时间    |
| **用户容量**     | ≥100万  | 系统支持的最大用户数量       |
| **批量导入**     | ≥100 条 | 单次批量导入支持的最大用户数 |

| 重置密码       | ✅         | ✅ (本部门) | ❌       |
| 启用/禁用用户  | ✅         | ❌          | ❌       |

| 批量导出       | ✅         | ✅ (本部门) | ❌       |
| 修改个人信息   | ✅         | ✅          | ✅       |
| 修改个人密码   | ✅         | ✅          | ✅       |

### 2.3 超级管理员保护规则

| 规则 | 说明 |
|------|------|
| 不可删除 | 超级管理员账户不可被删除，返回 `ROOT_USER_PROTECTED` 错误 |
| 不可禁用 | 超级管理员账户不可被禁用 |
| 不可自锁 | 超级管理员不可修改自己的状态（禁用自己），防止自锁 |

## 3. 功能需求

### 3.1 用户列表查询 (F-UM-001)

#### 3.1.1 功能描述

提供用户信息的分页展示和多条件筛选能力，支持管理员快速定位目标用户。

#### 3.1.2 查询条件

| 条件类型       | 字段               | 说明              | 匹配方式 |
| -------------- | ------------------ | ----------------- | -------- |
| **关键字搜索** | 用户名/昵称/手机号 | 多字段模糊匹配    | LIKE     |
| **部门筛选**   | 部门 ID            | 包含下级部门      | IN       |
| **状态筛选**   | 用户状态           | 启用/禁用         | =        |
| **用户类型**   | userType           | personal/enterprise | =      |
| **会员等级**   | memberLevel        | 普通/VIP1/VIP2/SVIP | =      |
| **时间筛选**   | 创建时间范围       | 开始时间~结束时间 | BETWEEN  |

> **默认过滤**：用户列表默认仅展示未删除用户（`deleted = 0`），已逻辑删除用户不展示。

#### 3.1.3 列表展示字段

| 字段 | 显示名称 | 宽度 | 说明 |
|------|---------|------|------|
| avatar | 头像 | 60px | 用户头像缩略图 |
| username | 用户名 | 120px | 登录账号，唯一 |
| nickname | 昵称 | 120px | 显示名称 |
| userType | 用户类型 | 100px | personal/enterprise |
| deptName | 部门 | 120px | 所属部门名称 |
| memberLevel | 会员等级 | 100px | 普通/VIP1/VIP2/SVIP（对接会员管理） |
| memberExpireTime | 会员到期 | 160px | 会员到期时间（普通用户为空） |
| quotaUsage | 配额使用 | 120px | 已用/总量（如 30/100） |
| mobile | 手机号 | 120px | 联系电话 |
| status | 状态 | 80px | 启用/禁用标签 |
| createTime | 创建时间 | 180px | 账户创建时间 |
| - | 操作 | 220px | 重置密码/编辑/删除 |

#### 3.1.4 分页配置

| 配置项   | 默认值        | 可选值       |
| -------- | ------------- | ------------ |
| 每页条数 | 10            | 10/20/50/100 |
| 页码显示 | 当前页/总页数 | -            |
| 总数显示 | 共 X 条       | -            |

### 3.2 用户新增 (F-UM-002)

#### 3.2.1 功能描述

支持创建新用户账户，包括基本信息设置、部门分配和角色授权。

#### 3.2.2 表单字段与校验规则

| 字段 | 显示名称 | 类型 | 必填 | 校验规则 |
| -------- | -------- | ---------- | ---- | ------------------ |
| username | 用户名 | 输入框 | ✅ | 不能为空，系统唯一 |
| nickname | 用户昵称 | 输入框 | ✅ | 不能为空 |
| avatar | 头像 | 图片上传 | ❌ | 用户头像，未上传使用默认头像 |
| userType | 用户类型 | 单选框组 | ✅ | personal/enterprise，默认 personal |
| deptId | 所属部门 | 树形选择器 | ✅ | 不能为空 |
| gender | 性别 | 字典选择器 | ✅ | 不能为空 |
| roleIds | 角色 | 多选下拉框 | ✅ | 不能为空 |
| mobile | 手机号 | 输入框 | ❌ | 手机号格式校验 |
| email | 邮箱 | 输入框 | ❌ | 邮箱格式校验 |
| status | 状态 | 单选框组 | ✅ | 默认启用(1) |

#### 3.2.3 业务规则

1. **用户名唯一性**：系统中用户名必须唯一，创建时需校验
2. **初始密码**：新用户使用系统默认密码（配置项 `default_password`，可配置），首次登录强制修改密码
3. **角色分配**：必须至少分配一个角色
4. **密码强度**：初始密码与重置密码均需满足 8-20 位含字母和数字

### 3.3 用户编辑 (F-UM-003)

#### 3.3.1 功能描述

支持修改现有用户的基本信息、部门和角色。

#### 3.3.2 可编辑字段

| 字段 | 是否可编辑 | 说明 |
| -------- | ---------- | -------------------- |
| username | ❌ | 用户名创建后不可修改 |
| nickname | ✅ | 可随时修改 |
| avatar | ✅ | 可修改头像 |
| userType | ✅ | 可修改用户类型 |
| deptId | ✅ | 支持部门调动 |
| gender | ✅ | 可修改 |
| roleIds | ✅ | 支持角色变更 |
| mobile | ✅ | 可修改 |
| email | ✅ | 可修改 |
| status | ✅ | 可启用/禁用 |

#### 3.3.3 业务规则

1. **用户名只读**：用户名一旦创建不可修改
2. **即时生效**：修改保存后立即生效
3. **权限变更**：角色变更后，用户权限立即更新

### 3.4 用户删除 (F-UM-004)

#### 3.4.1 功能描述

支持删除用户账户，包括单个删除和批量删除。删除为逻辑删除，保留数据完整性。

#### 3.4.2 删除方式

| 方式         | 触发操作               | 说明               |
| ------------ | ---------------------- | ------------------ |
| **单个删除** | 点击操作列删除按钮     | 删除单个用户       |
| **批量删除** | 勾选多个后点击批量删除 | 删除选中的所有用户 |

#### 3.4.3 业务规则

1. **二次确认**：删除操作需弹窗确认
2. **逻辑删除**：执行逻辑删除（标记 `deleted = 1`），数据保留可追溯，不物理删除
3. **登录禁止**：被删除用户不可登录
4. **列表过滤**：已删除用户默认不在用户列表展示
5. **管理员保护**：超级管理员账户不可删除，返回 `ROOT_USER_PROTECTED` 错误
6. **会话清理**：删除用户后实时踢出该用户所有在线会话（删除 Redis Session）

#### 3.4.4 确认提示

- 单个删除："确认删除用户「{username}」吗？删除后该用户不可登录，数据保留。"
- 批量删除："确认删除选中的 {count} 个用户吗？删除后不可登录，数据保留。"

### 3.5 密码重置 (F-UM-005)

#### 3.5.1 功能描述

管理员可以为用户重置密码，解决用户忘记密码的问题。

#### 3.5.2 操作流程

点击重置密码 → 弹出密码输入框 → 输入新密码 → 确认重置 → 密码更新成功

#### 3.5.3 业务规则

1. **权限控制**：仅具有 `sys:user:password:reset` 权限的用户可操作
2. **密码加密**：新密码 BCrypt 加密存储
3. **密码强度**：新密码需满足 8-20 位含字母和数字
4. **即时生效**：密码重置后立即生效，用户下次登录需使用新密码
5. **会话清理**：密码重置后实时踢出该用户所有在线会话，强制重新登录

### 3.6 状态管理 (F-UM-006)

#### 3.6.1 功能描述

支持启用或禁用用户账户，控制用户的系统访问权限。

#### 3.6.2 状态说明

| 状态值 | 显示             | 说明               |
| ------ | ---------------- | ------------------ |
| 1      | 启用（绿色标签） | 用户可正常登录系统 |
| 0      | 禁用（灰色标签） | 用户无法登录系统   |

#### 3.6.3 业务规则

1. **状态切换**：可通过状态列的开关或编辑表单切换状态
2. **即时生效**：状态变更后立即生效
3. **会话实时踢出**：禁用用户后实时踢出该用户所有在线会话（通过 Redis Session 扫描 `session:user:{username}` 索引删除全部 Session），被禁用用户下次请求返回 401
4. **管理员保护**：超级管理员不可禁用、不可修改自己的状态（防自锁）

### 3.7 用户导入 (F-UM-007)

#### 3.7.1 功能描述

支持通过 Excel 模板批量导入用户信息，提高批量用户创建效率。

#### 3.7.2 导入流程

下载导入模板 → 按模板填写用户信息 → 选择目标部门 → 上传 Excel 文件 → 系统校验数据 → 导入成功

#### 3.7.3 模板字段

| 列名     | 必填 | 说明                         |
| -------- | ---- | ---------------------------- |
| 用户名   | ✅   | 登录账号，系统唯一           |
| 昵称     | ✅   | 显示名称                     |
| 手机号   | ❌   | 联系电话                     |
| 邮箱     | ❌   | 电子邮箱                     |
| 性别     | ❌   | 男/女（留空默认男；其他取值该行导入报错） |
| 用户类型 | ❌   | personal/enterprise，默认 personal |
| 角色编码 | ❌   | 默认角色编码，多个用逗号分隔 |

#### 3.7.4 业务规则

1. **文件格式**：仅支持 `.xls` 和 `.xlsx` 格式
2. **部门指定**：导入时需指定目标部门
3. **冲突处理**：跳过已存在用户（按用户名/邮箱/手机号判重），返回冲突明细列表（含行号、用户名、冲突原因）
4. **默认密码**：导入用户使用系统默认密码（`default_password` 可配置），首次登录强制改密
5. **默认角色**：未指定角色编码时分配访客角色（`guest`）

#### 3.7.5 导入结果

| 结果类型     | 处理方式                                             |
| ------------ | ---------------------------------------------------- |
| **全部成功** | 显示"导入成功，共导入 X 条记录"                      |
| **部分成功** | 显示"导入完成，成功 X 条，跳过 Y 条"，并下载冲突明细 |
| **全部失败** | 显示"导入失败"，并下载冲突明细                       |

## 6. 多端需求

| 端 | 用户管理入口 | 说明 |
|----|-------------|------|
| **Web Vue/React** | 后台管理页面 | 完整用户管理功能 |
| **Electron 桌面端** | 后台管理页面 | 复用 Web 端管理能力 |
| **Android/Flutter/小程序** | 个人中心 | 仅个人资料查看/修改、头像上传、修改密码 |

**会话隔离**：多端用户状态变更（禁用/删除/密码重置）后，所有端在线会话统一踢出。**权限申请**：移动端/小程序仅提供个人资料管理，不开放后台用户管理入口。

## 7. 安全设计

### 7.1 数据安全

| 安全措施       | 说明                               |
| -------------- | ---------------------------------- |
| **密码加密**   | 密码 BCrypt 加密存储，不可明文     |
| **数据权限**   | 用户只能操作其数据权限范围内的用户 |
| **传输加密**   | 数据传输需加密                     |
| **防重复提交** | 同一操作不可重复提交               |
| **操作日志**   | 记录关键操作日志                   |

### 7.2 输入校验

| 校验类型     | 说明                             |
| ------------ | -------------------------------- |
| **前端校验** | 表单实时校验，提升用户体验       |
| **后端校验** | 服务端进行参数校验               |
| **格式校验** | 手机号、邮箱格式正则校验         |
| **长度校验** | 字段最大长度限制                 |
