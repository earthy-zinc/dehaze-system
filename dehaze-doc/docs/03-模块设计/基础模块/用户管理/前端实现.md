# 用户管理模块 - 前端实现设计

## 1. 文档概述

本文档描述用户管理模块的前端实现方案，聚焦组件架构、状态管理、数据流等架构决策。

## 2. 组件架构设计

### 2.1 组件层次结构

```
用户管理页面 (UserManagement/index.vue)
├── 部门树组件 (DeptTree)
│   └── 树形结构组件
└── 用户列表区域
    ├── 搜索容器
    │   ├── 搜索表单 (SearchForm)
    │   └── 操作按钮区域 (ActionButtons)
    └── 数据展示区域
        ├── 用户表格 (UserTable)
        └── 分页组件 (Pagination)
```

### 2.2 弹窗组件结构

```
弹窗组件 (UserDialog)
├── 用户表单弹窗 (UserFormDialog)
├── 用户导入弹窗 (UserImportDialog)
└── 密码重置对话框 (PasswordResetDialog)
```

### 2.3 组件职责划分

| 组件名称 | 职责描述 | 复用性 |
|---------|---------|--------|
| **DeptTree** | 部门树展示与选择，支持筛选联动 | 可复用于其他需要部门选择的模块 |
| **SearchForm** | 搜索条件输入与提交 | 页面内部组件 |
| **ActionButtons** | 操作按钮区域，统一管理权限控制 | 页面内部组件 |
| **UserTable** | 用户数据表格展示与行操作 | 页面内部组件 |
| **UserFormDialog** | 用户新增/编辑表单弹窗 | 页面内部组件 |
| **UserImportDialog** | 用户批量导入弹窗 | 页面内部组件 |

## 3. 组件详细设计

### 3.1 部门树组件

#### 组件属性

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| data | Array | [] | 部门树数据 |
| selectedKey | String/Number | - | 选中的部门ID |
| expandAll | Boolean | true | 是否默认展开所有节点 |

### 3.2 搜索表单组件

#### 表单字段

| 字段 | 类型 | 占位符 | 说明 |
|------|------|--------|------|
| keywords | 输入框 | "用户名/昵称/手机号" | 支持多字段模糊搜索 |
| status | 下拉选择 | "全部" | 选项：全部/启用/禁用 |
| dateRange | 日期范围 | "开始时间 ~ 截止时间" | 创建时间范围 |

### 3.3 操作按钮区域

| 按钮 | 类型 | 图标 | 权限标识 | 状态控制 |
|------|------|------|---------|---------|
| 新增 | 成功按钮 | + | sys:user:add | - |
| 删除 | 危险按钮 | 删除 | sys:user:delete | 无选中时禁用 |
| 导入 | 下拉按钮 | 导入 | - | - |
| 导出 | 默认按钮 | 下载 | - | 导出中显示加载 |

### 3.4 用户表格组件

#### 列定义

| 字段 | 列名 | 宽度 | 对齐 | 特殊处理 |
|------|------|------|------|---------|
| - | 选择 | 55px | 居中 | 复选框 |
| avatar | 头像 | 60px | 居中 | 头像缩略图，未上传用默认头像 |
| username | 用户名 | 120px | 居中 | - |
| nickname | 昵称 | 120px | 居中 | - |
| userType | 用户类型 | 100px | 居中 | personal/enterprise |
| deptName | 部门 | 120px | 居中 | - |
| memberLevel | 会员等级 | 100px | 居中 | 普通/VIP1/VIP2/SVIP（对接会员管理） |
| memberExpireTime | 会员到期 | 160px | 居中 | 普通用户为空 |
| quotaUsage | 配额使用 | 120px | 居中 | 已用/总量 |
| mobile | 手机号 | 120px | 居中 | - |
| status | 状态 | 80px | 居中 | Switch 开关 |
| createTime | 创建时间 | 180px | 居中 | 格式化显示 |
| - | 操作 | 220px | 居中 | 固定右侧 |

**交互规则**：
- 状态列使用 Switch 开关直接切换启用/禁用，需 `sys:user:status` 权限。
- 超级管理员不可禁用、用户不可禁用自己（防自锁），前端据当前用户与目标用户关系禁用开关。
- 状态变更后立即生效，被禁用用户的在线会话由后端实时踢出。

### 3.5 用户表单弹窗

## 5. 数据流设计

### 5.1 数据获取与操作

用户列表分页/新增/修改/删除/状态变更/密码重置/导入导出均通过 SDK 封装的用户接口调用，页面组件内完成请求与状态管理；部门树选项、角色选项通过部门/角色接口获取，用于表单选择器。

### 5.2 请求错误处理

| 错误类型 | 处理方式 |
|---------|---------|
| 网络错误 | 显示网络连接失败提示 |
| 未授权错误 | 跳转登录页 |
| 无权限错误 | 显示无操作权限提示 |
| 业务错误 | 显示后端返回的错误信息 |
| 服务器错误 | 显示服务器异常提示 |

## 6. 交互流程设计

### 6.1 页面初始化流程

1. 进入页面，显示加载状态
2. 并行请求部门树数据和用户列表数据
3. 数据加载完成，更新页面状态
4. 默认选中根部门

### 6.2 关键流程说明

| 流程 | 关键点 |
|------|--------|
| 用户新增 | 并行加载部门树和角色选项 → 表单校验 → 提交 → 刷新列表 |
| 用户编辑 | 并行加载部门树、角色选项和用户详情 → 用户名只读 → 提交 → 刷新列表 |
| 用户删除 | 确认对话框（显示用户名）→ 调用删除接口 → 刷新列表 |
| 状态切换 | Switch 开关 → 调用状态修改接口 → 刷新列表（超级管理员/自己不可禁用） |

## 7. 表单校验设计

### 7.1 格式校验规则

| 字段 | 正则表达式 | 说明 |
|------|-----------|------|
| mobile | `/^1[3-9]\d{9}$/` | 11位手机号 |
| email | `/^\w+([-+.]\w+)*@\w+([-.]\w+)*\.\w+([-.]\w+)*$/` | 标准邮箱格式 |

### 7.2 文件校验规则

| 校验项 | 规则 | 错误提示 |
|--------|------|---------|
| 文件格式 | .xls, .xlsx | 只能上传 Excel 文件 |
| 文件数量 | 最多 1 个 | 只能上传一个文件 |

## 8. 权限控制设计

### 8.1 路由设计

| 项 | 说明 |
|------|------|
| 路由配置 | 用户管理页面路由由权限信息接口返回的菜单树动态生成，菜单可见性由菜单权限分配控制 |
| 导航守卫 | 全局守卫校验登录态：未登录跳登录页，访问未授权菜单路由跳 403 页 |

### 8.2 按钮级权限

按权限标识控制按钮显示：

| 按钮 | 权限标识 | 无权限时 |
|------|---------|---------|
| 新增按钮 | sys:user:add | 隐藏 |
| 编辑按钮 | sys:user:edit | 隐藏 |
| 删除按钮 | sys:user:delete | 隐藏 |
| 重置密码按钮 | sys:user:password:reset | 隐藏 |
| 状态切换 | sys:user:status | 禁用 |

## 9. 性能优化设计

### 9.1 请求优化

| 优化项 | 实现方式 |
|--------|---------|
| 防抖处理 | 搜索输入防抖 300ms |
| 节流处理 | 提交按钮节流 3000ms |
| 并行请求 | 页面初始化时并行加载多个数据 |
| 请求缓存 | 部门树、角色选项数据缓存 |

### 9.2 渲染优化

| 优化项 | 实现方式 |
|--------|---------|
| 懒加载 | 部门树节点懒加载 |

### 9.3 缓存策略

| 数据类型 | 缓存位置 | 过期策略 |
|---------|---------|---------|
| 部门树数据 | 组件状态 | 页面卸载时清除 |
| 角色选项 | 组件状态 | 页面卸载时清除 |
| 字典数据 | 全局 Store | 登录后加载，退出时清除 |
