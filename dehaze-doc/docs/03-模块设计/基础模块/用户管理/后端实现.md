## 3. 服务层设计

### 3.1 服务接口定义

| 方法名 | 参数 | 返回值 | 说明 |
|--------|------|--------|------|
| listPagedUsers | UserPageQuery | IPage&lt;UserPageVO&gt; | 分页查询用户 |
| getUserFormData | Long userId | UserForm | 获取用户表单数据 |
| saveUser | UserForm | boolean | 保存新用户 |
| updateUser | Long userId, UserForm | boolean | 更新用户 |
| deleteUsers | String ids | boolean | 删除用户 |
| updatePassword | Long userId, String password | boolean | 更新密码 |
| updateStatus | Long userId, Integer status | boolean | 更新状态 |
| getCurrentUserInfo | - | UserInfoVO | 获取当前用户信息 |

### 3.2 核心业务逻辑

#### 用户新增逻辑

1. **参数校验**：校验必填字段、格式
2. **唯一性校验**：检查用户名是否已存在
3. **密码处理**：使用默认密码，加密存储
4. **保存用户**：插入用户主表
5. **角色关联**：批量插入用户-角色关联表

#### 用户更新逻辑

1. **参数校验**：校验必填字段、格式
2. **存在性校验**：检查用户是否存在
3. **更新用户**：更新用户主表
4. **角色更新**：删除原角色关联，插入新关联

#### 用户删除逻辑

1. **参数解析**：解析 ID 列表
2. **前置校验**：检查是否包含超级管理员
3. **删除关联**：删除用户-角色关联
4. **删除用户**：删除用户主表记录

### 3.3 事务管理

| 操作类型 | 事务级别 | 说明 |
|---------|---------|------|
| 查询操作 | 只读事务 | 优化数据库性能 |
| 新增用户 | 读写事务 | 用户表+关联表需事务保证 |
| 更新用户 | 读写事务 | 用户表+关联表需事务保证 |
| 删除用户 | 读写事务 | 用户表+关联表需事务保证 |

## 5. 导入导出设计

用户模块的导入导出由通用导入导出框架统一调度，模块侧只需实现 `UserExportHandler` 和 `UserImportHandler` 两个处理器接口。通用框架负责文件生成/解析、进度回调、结果上传、任务状态管理等通用流程，详见[任务管理/后端实现.md](../任务管理/后端实现.md)。

### 5.1 UserExportHandler

实现 `ExportHandler` 接口，`getModule()` 返回 `"user"`。

| 方法 | 说明 |
|------|------|
| estimateCount | 根据查询条件估算导出数据量（用于同步/异步判断） |
| export | 分批查询用户数据（每批 1000 条），通过 callback 回写进度，数据交由通用框架写入 Excel/CSV |
| getFieldConfigs | 返回导出字段配置（字段名、列名、顺序、字典类型、日期格式） |

**导出字段配置**：username（用户名）、nickname（昵称）、deptName（部门）、gender（性别，字典 `gender`）、mobile（手机号）、email（邮箱）、status（状态，字典 `status`）、createTime（创建时间）。

### 5.2 UserImportHandler

实现 `ImportHandler` 接口，`getModule()` 返回 `"user"`。

| 方法 | 说明 |
|------|------|
| getFieldConfigs | 返回导入字段配置（含必填、正则、最大长度、默认值） |
| importBatch | 批量导入用户：校验用户名唯一性、密码使用默认密码（配置项 `import.default-password`）加密存储、关联部门与角色 |
| getTemplateSampleData | 返回模板示例数据 |

**导入业务规则**：

| 异常类型 | 处理方式 |
|---------|---------|
| 用户名重复 | 跳过该行（部分模式）或整体回滚（全量模式），记录原因 |
| 必填字段为空 | 返回 A0706 错误 |
| 字段格式错误 | 返回 A0707 错误 |
| 部门不存在 | 跳过该行，记录原因 |

> **说明**：导入导出由通用导入导出框架统一调度，模块侧实现导入/导出处理器（字段配置、批量校验、模板示例数据），模板由框架按字段配置动态生成，详见 [任务管理/后端实现.md](../任务管理/后端实现.md)。

## 6. 安全设计

### 6.1 密码安全

| 策略项 | 配置值 | 说明 |
|--------|--------|------|
| 密码存储 | 加密存储（自带盐值） | 不可明文存储 |
| 最小长度 | 8 位 | 密码最少字符数 |
| 复杂度 | 中 | 至少包含字母和数字 |

### 6.2 防护机制

| 防护项 | 实现方式 |
|--------|---------|
| 防重复提交 | 自定义注解 + Redis 分布式锁，锁定时间 3 秒 |
| SQL 注入防护 | 参数化查询，ORM 框架自动转义 |
| XSS 防护 | 输出编码，输入过滤危险标签 |
