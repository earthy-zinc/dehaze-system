## 3. 服务层设计

### 3.1 服务接口定义

| 方法名 | 参数 | 返回值 | 说明 |
|--------|------|--------|------|
| listPagedUsers | UserPageQuery | IPage&lt;UserPageVO&gt; | 分页查询用户 |
| getUserFormData | Long userId | UserForm | 获取用户表单数据 |
| saveUser | UserForm | boolean | 保存新用户 |
| updateUser | Long userId, UserForm | boolean | 更新用户 |
| deleteUsers | String ids | boolean | 删除用户 |
| updatePassword | Long userId, String password | boolean | 更新密码 |
| updateStatus | Long userId, Integer status | boolean | 更新状态 |
| listExportUsers | UserPageQuery | List&lt;UserExportVO&gt; | 获取导出数据 |
| getCurrentUserInfo | - | UserInfoVO | 获取当前用户信息 |

### 3.2 核心业务逻辑

#### 用户新增逻辑

1. **参数校验**：校验必填字段、格式
2. **唯一性校验**：检查用户名是否已存在
3. **密码处理**：使用默认密码，BCrypt 加密
4. **保存用户**：插入用户主表
5. **角色关联**：批量插入用户-角色关联表

#### 用户更新逻辑

1. **参数校验**：校验必填字段、格式
2. **存在性校验**：检查用户是否存在
3. **更新用户**：更新用户主表
4. **角色更新**：删除原角色关联，插入新关联

#### 用户删除逻辑

1. **参数解析**：解析 ID 列表
2. **前置校验**：检查是否包含超级管理员
3. **删除关联**：删除用户-角色关联
4. **删除用户**：删除用户主表记录

### 3.3 事务管理

| 操作类型 | 事务级别 | 说明 |
|---------|---------|------|
| 查询操作 | 只读事务 | 优化数据库性能 |
| 新增用户 | 读写事务 | 用户表+关联表需事务保证 |
| 更新用户 | 读写事务 | 用户表+关联表需事务保证 |
| 删除用户 | 读写事务 | 用户表+关联表需事务保证 |

## 4. 数据访问层设计

### 4.1 查询优化

#### 分页查询

- 使用分页插件避免全表扫描
- 合理使用索引覆盖
- 只查询需要的字段，避免 SELECT *

#### 关联查询

| 关联数据 | 实现方式 |
|---------|---------|
| 部门名称 | JOIN sys_dept 表 |
| 角色名称 | 子查询或 GROUP_CONCAT |
| 性别显示 | 应用层字典翻译 |

#### 部门树查询

- 使用递归 CTE（MySQL 8.0+）查询子部门
- 或应用层递归获取子部门 ID 列表
- 缓存部门树结构

### 4.2 缓存策略

| 缓存对象 | 缓存 Key | 过期时间 | 更新策略 |
|---------|---------|---------|---------|
| 用户信息 | user:info:{userId} | 30 分钟 | 更新时删除 |
| 用户权限 | user:perms:{userId} | 30 分钟 | 角色变更时删除 |
| 部门树 | dept:tree | 1 小时 | 部门变更时删除 |
| 角色列表 | role:options | 1 小时 | 角色变更时删除 |

## 5. 导入导出设计

### 5.1 导入设计

> **导入模板字段与业务规则**：详见 [需求规格.md](./需求规格.md) 第 3.7 节

#### 导入处理流程

1. 文件校验：校验文件格式(xls/xlsx)
2. 解析文件：逐行解析数据
3. 数据校验：校验每行数据格式和业务规则
4. 批量保存：批量插入数据
5. 结果统计：统计成功/失败条数
6. 错误反馈：返回失败明细

#### 异常处理

| 异常类型 | 处理方式 |
|---------|---------|
| 文件格式错误 | 直接返回错误提示 |
| 数据格式错误 | 记录错误行，继续处理 |
| 用户名重复 | 跳过该行，记录原因 |
| 数据库异常 | 回滚当前批次，记录错误 |

### 5.2 导出设计

- 根据当前筛选条件导出数据
- 支持大批量数据导出

## 6. 安全设计

### 6.1 密码安全

| 策略项 | 配置值 | 说明 |
|--------|--------|------|
| 加密算法 | BCrypt | 自带盐值、抗彩虹表攻击 |
| 工作因子 | 10 | 可配置 |
| 最小长度 | 8 位 | 密码最少字符数 |
| 复杂度 | 中 | 至少包含字母和数字 |

### 6.2 防护机制

| 防护项 | 实现方式 |
|--------|---------|
| 防重复提交 | 自定义注解 + Redis 分布式锁，锁定时间 3 秒 |
| SQL 注入防护 | 参数化查询，ORM 框架自动转义 |
| XSS 防护 | 输出编码，输入过滤危险标签 |
