## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **测试用户** | 普通用户 1 名、VIP 用户 1 名 | 验证容量差异和排序权限 |
| **算法数据** | 已发布算法 3 个（DCP、AOD-Net、FFA-Net） | targetType=algorithm |
| **处理结果** | 已完成去雾处理结果 2 条 | targetType=result |
| **数据集数据** | 已发布数据集 2 个 | targetType=dataset |
| **失效对象** | 1 个被逻辑删除的算法、1 个被物理删除的处理结果 | 验证数据同步 |
| **收藏数据** | 普通用户已有 199 条收藏、VIP 用户已有 499 条收藏 | 验证容量边界 |

### 3.2 数据清理策略

- 测试收藏数据使用统一测试用户，测试结束后清空该用户的所有收藏记录
- 测试失效对象在测试结束后恢复或删除
- 不修改生产环境算法/数据集状态

### 3.3 测试范围

**包含的功能点：**

- 收藏操作（F-FAV-001）：收藏/取消收藏、重复收藏、容量校验
- 收藏列表（F-FAV-002）：分页、筛选、排序、搜索
- 收藏数据同步（F-FAV-003）：对象删除后同步
- 跨模块集成：去雾结果/算法/数据集收藏、推荐信号传递
- VIP 容量与排序权限校验

**不包含的功能点：**

- 预留类型（image、preset）的收藏（未实现）
- 收藏导出/分享（待确认事项）
- UI 组件渲染细节

## 5. 关键边界与异常场景

| 场景 | 测试点 | 期望行为 |
|------|--------|---------|
| **重复收藏** | 同一用户对同一对象多次收藏 | 返回 `A0501`，不产生重复记录 |
| **收藏容量满** | 达到用户等级容量上限 | 返回 `A0500`，引导升级 VIP |
| **对象逻辑删除** | 收藏对象被逻辑删除 | 收藏条目标记"已失效"，可一键清理 |
| **对象物理删除** | 收藏对象被物理删除 | 收藏条目级联删除 |
| **对象信息变更** | 收藏对象名称/评分变更 | 收藏列表展示最新信息 |
| **VIP 权益差异** | 普通用户 vs VIP 用户 | 容量（200/500）、排序权限、筛选权限差异 |
| **跨类型收藏** | 同时收藏算法/结果/数据集 | 各类型独立记录，统一查询 |
| **并发收藏** | 同一用户并发收藏同一对象 | 仅 1 条成功，其余返回 `A0501` |

## 7. 安全性测试

| 测试项 | 验证方式 | 预期结果 |
|--------|---------|---------|
| **未登录访问** | 未登录调用收藏接口 | 返回 `A0230` token无效 |
| **越权访问他人收藏** | 用户 A 查询用户 B 的收藏列表 | 返回 403 或仅返回当前用户数据 |
| **越权取消他人收藏** | 用户 A 取消用户 B 的收藏 | 返回 403 |
| **收藏不存在的对象** | targetId 传入不存在的 ID | 返回 `A0401`，无数据写入 |
| **SQL 注入** | targetId 参数包含 `1' OR '1'='1` | 参数化查询防护，无注入风险 |
| **XSS 防护** | 搜索关键词包含 `<script>` | 输出编码，不执行脚本 |
| **targetType 篡改** | 传入未定义的 targetType | 参数校验拒绝 |
| **容量穿透防护** | 绕过前端校验直接调用接口 | 后端校验容量上限 |
