# 收藏管理模块测试用例

## 1. 测试目标

- [x] 验证收藏操作（收藏/取消收藏/幂等/状态检查）符合实际实现
- [x] 验证收藏列表查询（分页、类型筛选、时间排序、搜索）功能
- [x] 验证收藏数据同步（算法/数据集删除后标记失效）
- [x] 验证容量校验（普通用户 200 条 / VIP 用户 500 条）
- [x] 验证安全性（越权访问、未登录访问）

---

## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **测试用户** | 普通用户 1 名、VIP 用户 1 名 | 验证容量差异 |
| **算法数据** | 已发布算法 3 个 | targetType=algorithm |
| **处理结果** | 已完成去雾处理结果 2 条 | targetType=result |
| **数据集数据** | 已发布数据集 2 个 | targetType=dataset |
| **失效对象** | 1 个待删除的算法、1 个待删除的数据集 | 验证失效标记 |
| **收藏数据** | 普通用户已有 199 条收藏、VIP 用户已有 499 条收藏 | 验证容量边界 |

### 3.2 数据清理策略

- 测试收藏数据使用统一测试用户，测试结束后清空该用户的所有收藏记录
- 测试删除的算法/数据集恢复原状态
- 不修改生产环境算法/数据集状态

### 3.3 测试范围

**包含的功能点：**

- 收藏操作（F-FAV-001）：收藏/取消收藏、重复收藏幂等、容量校验
- 收藏列表（F-FAV-002）：分页、类型筛选、时间排序、关键词搜索、计数
- 收藏数据同步（F-FAV-003）：算法/数据集删除后标记失效
- 容量校验（普通 200 / VIP 500）

**不包含的功能点（规划中/未实现）：**

- 评分/使用频率排序（后端仅时间排序，前端选项无效）
- 多类型组合筛选（仅单选）
- 失效条目"一键清理"、处理结果类型失效标记、物理级联删除
- 各业务页面收藏入口（`FavoriteButton` 组件未接入）
- 推荐引擎读取收藏信号
- 收藏导出/分享（待确认事项）
- 预留类型（image/preset）的对象校验（跳过校验，可收藏）

## 5. 关键边界与异常场景

| 场景 | 测试点 | 期望行为 |
|------|--------|---------|
| **重复收藏** | 同一用户对同一对象多次收藏 | 幂等成功返回原 ID，无重复记录 |
| **取消后重藏** | 取消后再次收藏同一对象 | 原记录复活，收藏时间更新 |
| **收藏容量满** | 达到用户等级容量上限 | 返回 `A0500`，引导升级 VIP |
| **对象不存在** | 收藏不存在的算法/数据集/处理结果 | 返回 `A0401` |
| **对象删除失效** | 算法/数据集删除 | 收藏标记失效，记录保留 |
| **越权取消** | 用户 A 取消用户 B 的收藏记录 ID | 更新 0 行，无报错（按用户过滤） |
| **越权查询** | 用户 A 查看用户 B 的收藏列表 | 仅返回当前用户数据 |

## 7. 安全性测试

| 测试项 | 验证方式 | 预期结果 |
|--------|---------|---------|
| **未登录访问** | 未登录调用收藏接口 | 返回 `A0230` token无效 |
| **越权取消他人收藏** | 用户 A 取消用户 B 的收藏 ID | 更新 0 行，无报错 |
| **越权查询他人列表** | 用户 A 查询用户 B 的收藏 | 仅返回当前用户数据 |
| **收藏不存在的对象** | targetId 传入不存在的 ID | 返回 `A0401`，无数据写入 |
| **SQL 注入** | targetId 参数包含恶意字符 | 参数化查询防护，无注入风险 |
| **容量穿透防护** | 绕过前端校验直接调用接口 | 后端校验容量上限 |
