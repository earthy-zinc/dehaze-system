# 收藏管理模块 - 前端实现设计

## 1. 文档概述

本文档描述收藏管理模块的前端实现方案（dehaze-front-vue），聚焦页面结构、数据流、关键交互决策与权限控制。

---

## 2. 组件设计

### 2.1 组件结构

```
收藏管理模块
├── FavoriteButton（components/FavoriteButton/index.vue）  # 通用收藏按钮（已封装，未接入业务页面）
└── MyFavorites（views/favorite/my/index.vue）             # 我的收藏页
    ├── 类型 Tab 栏（全部/算法/处理结果/数据集/图片/预设）
    ├── 搜索框 + 排序下拉
    ├── 收藏卡片网格（分页）
    └── 分页组件
```

> **说明**：
> - 早期设计稿中的 HeartIcon/Toast/TypeFilter/SortSelector/SearchInput/FavoriteCard/BatchManageBar/InvalidItemTip 等子组件拆分**不存在**，相关能力内聚在页面组件中
> - "我的收藏"页面文件已实现（`views/favorite/my`），**未注册在静态路由**（入口待接入/由动态菜单加载）
> - 无收藏相关 Pinia Store，状态在页面组件内局部管理

## 3. 页面布局设计

### 3.1 我的收藏页

| 区域 | 说明 |
|------|------|
| 页头 | 标题"我的收藏" + 类型 Tab 栏（全部/算法/处理结果/数据集/图片/预设，切换重新查询） |
| 筛选栏 | 搜索框（收藏名称，回车触发）+ 排序下拉（按时间/按评分/按使用频率） |
| 收藏卡片 | 网格布局（自适应列）：类型标签、失效标签（红色）、缩略图（仅数据集）、名称、摘要、收藏时间、取消收藏按钮 |
| 分页 | 每页 12 条 |

### 3.2 收藏卡片交互

| 交互 | 行为 |
|------|------|
| 点击卡片 | 按类型跳转详情路由（算法→算法详情、处理结果→对比结果、数据集→数据集详情、图片/预设→预留路由）；已失效卡片不跳转 |
| 取消收藏 | 确认弹窗 → 调用取消接口 → 提示"已取消收藏" → 刷新列表 |

---

## 4. 状态管理

收藏管理**无独立 Store**，状态在页面组件内局部管理：

| 状态字段 | 说明 |
|---------|------|
| currentTab | 当前类型筛选（all/algorithm/result/dataset/image/preset） |
| queryParams | 分页参数 + targetType + keywords + sortBy/sortOrder |
| pageData/total/loading | 列表数据、总数、加载状态 |

---

## 5. 数据流

### 5.1 收藏列表加载

```
进入页面 → 按当前筛选条件分页查询
    ↓
切换类型 Tab / 搜索 / 排序 → 重置页码重新查询
    ↓
渲染收藏卡片网格
```

### 5.2 收藏操作

```
页面点击取消收藏 → 确认弹窗 → 提交取消 → 提示 → 刷新列表
（收藏/取消收藏的入口按钮组件已封装，待接入各业务页面）
```

### 5.3 模块间数据交互

| 交互方向 | 数据 | 说明 |
|---------|------|------|
| 收藏管理 → 会员管理 | 用户等级 | 容量校验（普通 200 / VIP 500，后端执行） |
| 算法/数据集管理 → 收藏管理 | 删除事件 | 删除时标记相关收藏失效 |

---

## 6. 关键交互决策

| 决策点 | 实现方式 |
|--------|---------|
| 类型筛选 | 单选 Tab（targetType 单值），"全部"时不过滤 |
| 排序选项 | 下拉含"按时间/按评分/按使用频率"，**后端仅按时间排序生效**（评分/使用频率未实现） |
| 取消收藏确认 | 确认弹窗防误操作 |
| 失效卡片 | 展示"已失效"标签，点击不跳转 |
| 卡片跳转 | 按 targetType 映射详情路由 |

---

## 7. 权限与会员控制

| 功能 | 普通用户 | VIP 用户 |
|------|:------:|:------:|
| 收藏/取消收藏 | ✅ | ✅ |
| 查看收藏列表 | ✅ | ✅ |
| 类型筛选/搜索/时间排序 | ✅ | ✅ |
| 收藏容量 | 200 条 | 500 条（后端校验） |

> 容量校验由后端执行，前端不区分等级权限；无 VIP 专属排序/筛选能力。

---

## 8. 性能优化

| 优化项 | 实现方式 |
|--------|---------|
| 分页查询 | 后端分页，每页 12 条 |
| 搜索触发 | 回车触发查询（无防抖需求） |
| 图片预览 | 缩略图支持点击放大预览 |
