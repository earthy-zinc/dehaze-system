# 收藏管理模块 - 前端实现设计

## 1. 文档概述

本文档描述收藏管理模块的前端实现方案，聚焦组件架构、状态管理、数据流设计等架构决策。收藏管理模块为所有核心业务实体提供统一的收藏能力，并提供"我的收藏"聚合页面。

---

## 2. 组件设计

### 2.1 组件结构

```
收藏管理模块
├── FavoriteButton               # 通用收藏按钮（供各模块嵌入使用）
│   ├── HeartIcon                # 空心/实心心形图标
│   └── Toast                    # 操作反馈提示
├── MyFavoritesPage              # 我的收藏聚合页面
│   ├── FavoriteFilter           # 类型筛选 + 排序选择
│   │   ├── TypeFilter           # 类型筛选（全部/算法/处理结果/数据集）
│   │   ├── SortSelector         # 排序选择（时间/评分/使用频率）
│   │   └── SearchInput          # 收藏对象名称搜索
│   ├── FavoriteList             # 收藏列表（按时间倒序）
│   │   ├── FavoriteCard         # 收藏卡片
│   │   │   ├── Thumbnail        # 缩略图（按类型渲染）
│   │   │   ├── ObjectName       # 收藏对象名称
│   │   │   ├── TypeTag          # 类型标签（彩色区分）
│   │   │   ├── Summary          # 对象摘要（评分/描述等）
│   │   │   ├── FavoriteTime     # 收藏时间
│   │   │   └── ActionButtons    # 操作按钮（取消收藏/跳转详情）
│   │   └── EmptyState           # 空状态提示
│   ├── FavoriteStats            # 收藏统计（各类型数量）
│   ├── BatchManageBar           # 批量管理栏（编辑模式）
│   │   ├── SelectAll            # 全选
│   │   └── BatchUnfavorite      # 批量取消收藏
│   └── InvalidItemTip           # 失效对象提示 + 一键清理
```

### 2.2 组件职责

| 组件 | 职责 | 复用性 |
|------|------|--------|
| FavoriteButton | 通用收藏/取消收藏按钮，供各核心模块嵌入 | 高度可复用 |
| MyFavoritesPage | 收藏聚合页面容器，路由入口 | 不可复用 |
| FavoriteFilter | 类型筛选+排序+搜索 | 不可复用 |
| FavoriteList | 收藏列表渲染，分页加载 | 可复用 |
| FavoriteCard | 收藏卡片，按 targetType 渲染不同内容 | 可复用 |
| TypeTag | 类型标签（算法/结果/数据集），彩色区分 | 高度可复用 |
| FavoriteStats | 各类型收藏数量统计 | 不可复用 |
| BatchManageBar | 批量管理（编辑模式） | 可复用于其他列表管理场景 |
| InvalidItemTip | 失效对象标记和一键清理入口 | 不可复用 |

### 2.3 FavoriteButton 可复用组件接口

FavoriteButton 作为通用收藏按钮，供各核心模块嵌入使用。

**Props**：

| Prop | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| targetType | string | 是 | 收藏对象类型（algorithm/result/dataset） |
| targetId | string/number | 是 | 收藏对象 ID |
| size | string | 否 | 按钮尺寸（small/default/large），默认 default |

**Events**：

| Event | 参数 | 说明 |
|-------|------|------|
| change | { favorited: boolean, targetType: string, targetId: string } | 收藏状态变更时触发，供父组件同步 UI |

组件挂载时从 favoriteStore 查询当前对象的收藏状态初始化图标，操作成功后更新全局 Store 并触发 change 事件。

**嵌入位置**：

| 嵌入位置 | targetType | 说明 |
|---------|-----------|------|
| 算法选择-算法卡片 | algorithm | 算法收藏 |
| 算法选择-算法详情 | algorithm | 算法收藏 |
| 去雾处理-结果预览 | result | 处理结果收藏 |
| 效果对比-操作栏 | result | 处理结果收藏 |
| 图像输入-历史记录 | result | 处理结果收藏 |
| 数据集管理-数据集详情 | dataset | 数据集收藏 |

## 4. 状态管理

### 4.1 状态定义

| Store | 职责 |
|-------|------|
| favoriteStore | 收藏列表、统计、操作状态 |

### 4.2 favoriteStore 核心状态

| 状态字段 | 类型 | 说明 |
|---------|------|------|
| favoriteList | array | 收藏列表（分页数据） |
| totalCount | number | 收藏总数 |
| typeCounts | object | 各类型收藏数量（algorithm/result/dataset） |
| activeType | string | 当前筛选类型（all/algorithm/result/dataset） |
| sortBy | string | 排序方式（time/rating/usage） |
| searchKeyword | string | 搜索关键词 |
| pageNum | number | 当前页码 |
| hasMore | boolean | 是否还有更多数据 |
| capacity | object | 收藏容量（used/max） |
| editMode | boolean | 是否批量管理模式 |
| selectedIds | array | 批量管理选中的收藏ID列表 |

### 4.3 favoriteStore Actions

| 方法 | 说明 |
|------|------|
| fetchFavorites(params) | 获取收藏列表（分页+筛选+排序） |
| fetchMore() | 加载更多收藏 |
| fetchStats() | 获取各类型收藏数量统计 |
| addFavorite(targetType, targetId) | 添加收藏 |
| removeFavorite(id) | 取消收藏 |
| batchRemoveFavorites(ids) | 批量取消收藏 |
| checkFavorited(targetType, targetId) | 检查是否已收藏 |
| clearInvalidItems() | 一键清理失效对象 |
| setFilter(type) | 设置类型筛选 |
| setSort(sortBy) | 设置排序方式 |
| searchFavorites(keyword) | 搜索收藏对象 |
| toggleEditMode() | 切换批量管理模式 |
| selectItem(id) | 选中/取消选中 |
| selectAll() | 全选 |
| clearSelection() | 清空选中 |

## 5. 数据流

### 5.1 收藏按钮交互流程

```
用户点击收藏按钮（未收藏状态）
    ↓
调用 addFavorite(targetType, targetId)
    ↓ 检查容量
容量已满 → 提示"收藏已达上限（X条），请清理后重试" + 引导升级VIP
    ↓ 容量充足
收藏成功 → 图标切换为实心 → Toast "已添加到收藏"
    ↓ 同步全局状态
更新 favoriteStore.typeCounts
    ↓
触发 change 事件 → 通知父组件同步 UI
```

### 5.2 收藏列表加载

```
进入 /my-favorites
    ↓
并行请求：fetchFavorites + fetchStats
    ↓
渲染筛选栏 + 统计概览 + 收藏列表
    ↓
用户切换类型筛选 → 重新请求 fetchFavorites
用户搜索 → 防抖 300ms → searchFavorites
滚动到底部 → fetchMore 追加数据
```

### 5.3 失效对象处理

```
收藏列表加载时，后端标记对象是否已失效
    ↓
失效对象卡片显示"已失效"标记 + 灰色样式
    ↓
用户可手动取消收藏，或点击"一键清理"批量移除所有失效项
```

### 5.4 收藏状态跨模块同步

各模块中的 FavoriteButton 共享 favoriteStore 全局状态。当用户在一个页面收藏/取消收藏后，其他页面同一对象的收藏状态同步更新（通过 Store 全局状态）。FavoriteButton 组件挂载时从 Store 查询当前对象收藏状态初始化图标，操作成功后更新 Store 并通过 change 事件通知父组件。

### 5.5 模块间数据交互

| 交互方向 | 数据 | 说明 |
|---------|------|------|
| 收藏管理 → 会员管理 | 容量查询 | VIP收藏容量上限区分 |
| 收藏管理 → 推荐管理 | 收藏行为 | 收藏行为作为推荐训练的正向信号 |
| 各核心模块 → 收藏管理 | FavoriteButton | 各模块嵌入收藏按钮 |

## 6. 关键交互决策

### 6.1 收藏按钮状态同步策略

采用 **Pinia Store 全局状态** 管理收藏状态：

| 方案 | 选择理由 |
|------|---------|
| Pinia 全局 Store | 各模块共享同一份收藏状态，一处变更所有位置同步更新 |
| 不采用组件级状态 | 避免不同模块间收藏状态不一致 |

FavoriteButton 组件挂载时从 favoriteStore 查询当前对象收藏状态初始化图标，操作成功后更新全局 Store 并触发 change 事件通知父组件。

### 6.2 不同类型收藏卡片渲染

采用 **条件渲染** 而非组件工厂模式：

| 类型 | 卡片渲染内容 |
|------|-------------|
| algorithm | 算法名称 + 类型标签 + 评分星级 + 算法描述摘要 |
| result | 原图/结果缩略图 + 算法名称 + 处理时间 + 处理参数摘要 |
| dataset | 数据集名称 + 类型标签 + 图片数量 + 数据集描述摘要 |

卡片共享统一的外层结构（缩略图区+信息区+操作区），仅在信息区内容上按类型条件渲染。

### 6.3 批量管理模式

用户点击"管理"进入编辑模式，列表项左侧出现复选框。选中后底部出现批量操作栏（全选+批量取消收藏+取消选择）。退出编辑模式时清空选中状态。

## 8. 性能优化

| 优化项 | 实现方式 |
|--------|---------|
| 分页加载 | 每次加载 20 条，滚动加载更多 |
| 搜索防抖 | 输入防抖 300ms |
| 缩略图懒加载 | 卡片缩略图使用懒加载 |
| 统计缓存 | 类型数量统计缓存 5 分钟 |
| 收藏状态缓存 | 已收藏对象 ID 集合缓存于 Store，减少 checkFavorited 调用 |
| 请求取消 | 切换筛选条件时取消未完成的列表请求 |

---

## 9. 错误处理

| 错误类型 | 处理方式 |
|---------|---------|
| 容量已满 | 提示上限，引导升级VIP或清理 |
| 收藏操作失败 | Toast 提示失败原因，图标状态回滚 |
| 列表加载失败 | 显示错误提示 + 重试按钮 |
| 对象已失效 | 卡片标记"已失效"，提供一键清理 |
| 搜索无结果 | 显示空状态"未找到匹配的收藏" |
