# 收藏管理模块需求规格

## 1. 模块概述

### 1.1 模块定位

收藏管理模块是 AI 图像处理平台的通用基础模块，通过统一收藏表为所有核心业务实体提供收藏能力。用户可将感兴趣的算法、处理结果、数据集等对象加入收藏夹，并在"我的收藏"页面集中查看和管理。

> 三后端统一使用本模块的收藏 API，契约完全一致（Java 权威，Go/Python 对齐）。

### 1.2 核心价值

| 价值维度 | 具体内容 |
|---------|---------|
| **统一体验** | 所有可收藏对象使用一致的收藏/取消收藏/收藏列表交互 |
| **聚合入口** | "我的收藏"页面支持按类型筛选查看所有收藏内容 |
| **跨模块复用** | 新模块接入收藏能力只需声明收藏类型，无需重复开发收藏表/接口 |
| **数据沉淀** | 收藏行为作为用户偏好信号，供推荐引擎使用（推荐引擎未读取，暂未生效） |

### 1.3 业务目标

#### 功能目标

- 提供统一的收藏/取消收藏能力，支持多种业务实体类型
- 提供按类型筛选的"我的收藏"聚合页面
- 支持收藏列表的排序和搜索（仅按收藏时间排序；评分/使用频率排序不支持，前端不展示该选项）
- 收藏对象失效自动标记（算法/数据集删除时标记失效）

#### 性能目标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 收藏/取消收藏响应 | < 200ms | 单次操作 |
| 收藏列表查询响应 | < 500ms | 分页查询 |
| 收藏容量 | 普通用户 200 / VIP 500 条 | 按会员等级阶梯区分 |

## 2. 用户角色分析

### 2.1 主要用户角色

| 角色 | 描述 | 主要职责 |
|------|------|---------|
| **普通用户** | 所有登录用户 | 收藏/取消收藏、管理个人收藏列表（容量 200 条） |
| **VIP 用户** | 付费用户（VIP1/VIP2/SVIP） | 与普通用户能力一致，仅收藏容量按等级阶梯提升（VIP 500 条） |

> **说明**：普通用户与 VIP 用户在收藏功能上**仅容量存在差异**，筛选、排序、批量取消等能力一致。评分/使用频率排序不支持，前端不展示该选项。

### 2.2 权限矩阵

| 功能点 | 普通用户 | VIP用户 |
|--------|:------:|:------:|
| 收藏/取消收藏 | ✅ | ✅ |
| 查看收藏列表 | ✅ | ✅ |
| 按类型筛选（单选） | ✅ | ✅ |
| 收藏排序（时间） | ✅ | ✅ |
| 收藏排序（评分/使用频率） | ❌（不支持，前端不展示） | ❌（不支持，前端不展示） |
| 收藏容量 | 200 条 | VIP 500 条 |
| 批量取消收藏 | ✅ | ✅ |

## 3. 收藏对象类型定义

| 类型编码 | 类型名称 | 来源模块 | 说明 |
|---------|---------|---------|:----:|
| `algorithm` | 算法 | 算法选择/算法管理 | 收藏校验 + 删除标记失效 |
| `result` | 处理结果 | 图像处理/效果对比 | 收藏校验 |
| `dataset` | 数据集 | 数据集管理 | 收藏校验 + 删除标记失效 |
| `image` | 图片 | 图像输入 | 预留（可收藏，无对象校验） |
| `preset` | 参数方案 | 图像处理 | 预留（可收藏，无对象校验） |

> **说明**：五类类型均可提交收藏；其中 algorithm/dataset/result 三类在收藏时校验对象存在，image/preset 为预留类型跳过校验。算法/数据集删除时自动将相关收藏标记失效。

## 4. 功能需求

### 4.1 收藏操作 (F-FAV-001)

#### 4.1.1 功能描述

用户对可收藏对象执行收藏或取消收藏操作。同一用户对同一对象只能收藏一条记录（重复收藏幂等返回原记录）。

#### 4.1.2 操作入口

| 入口 | 说明 |
|------|------|
| 我的收藏页-取消收藏 | 卡片"取消收藏"按钮（确认弹窗） |
| 通用收藏按钮组件 | `FavoriteButton` 组件已封装（收藏/取消/状态初始化），规划接入图像处理结果页、算法详情页、数据集详情页 |

#### 4.1.3 交互规则

| 场景 | 行为 |
|------|------|
| 未收藏 → 点击收藏 | 收藏成功，返回收藏记录 ID |
| 已收藏 → 重复点击 | 幂等返回原记录（不报错、不产生重复数据） |
| 已取消 → 再次收藏 | 原记录复活（逻辑删除恢复），收藏时间更新 |
| 收藏容量已满 | 提示"收藏已达上限（X条），请清理后重试" |
| 对象已失效 | 收藏列表卡片标记"已失效"，点击卡片不跳转 |

### 4.2 收藏列表 (F-FAV-002)

#### 4.2.1 功能描述

用户可在"我的收藏"页面查看所有收藏内容，支持按类型筛选、排序和搜索。

#### 4.2.2 列表展示

| 字段 | 说明 |
|------|------|
| 收藏对象名称 | 算法名/数据集名（关联查询）；处理结果等类型暂无名称（显示"-"） |
| 类型标签 | 算法/处理结果/数据集/图片/预设（彩色标签区分） |
| 缩略图 | 数据集类型展示缩略图；其余类型无 |
| 对象摘要 | 当前恒为空（字段预留） |
| 收藏时间 | 何时收藏（日期） |
| 失效标记 | 对象已删除时展示"已失效"标签 |
| 操作 | 取消收藏、点击卡片跳转详情 |

> **说明**：列表信息由关联查询实时获取（名称随对象更新），对象删除后名称为空且标记失效。

#### 4.2.3 筛选与排序

| 维度 | 选项 |
|------|------|
| 类型筛选 | 全部/算法/处理结果/数据集/图片/预设（单选） |
| 排序方式 | 按收藏时间倒序（默认）/ 按收藏时间正序 |
| 搜索 | 按收藏对象名称关键词搜索（仅算法/数据集名称参与匹配） |

> **说明**：排序仅支持按收藏时间，评分/使用频率排序后端不支持，前端不展示该选项。如需支持评分/使用频率排序需后端先实现。

### 4.3 收藏数据同步 (F-FAV-003)

#### 4.3.1 功能描述

当收藏对象的状态发生变化时，收藏列表中的条目同步更新。

| 场景 | 行为 |
|------|------|
| 算法被删除（逻辑删除） | 相关收藏条目标记"已失效"（删除算法时自动触发） |
| 数据集被删除（逻辑删除） | 相关收藏条目标记"已失效"（删除数据集时自动触发） |
| 对象名称变更 | 收藏列表通过关联查询展示最新名称 |
| 失效条目清理 | 用户可手动取消收藏 |

## 交互规范

### 页面布局

| 页面 | 布局要点 |
|------|---------|
| 收藏列表页 | 顶部类型筛选（全部/算法/处理结果/数据集/图片/预设），主体为网格展示收藏卡片，按收藏时间倒序分页加载 |
| 收藏卡片 | 展示对象名称、类型标签、缩略图（数据集）、收藏时间、失效标记 |

### 关键交互行为

| 场景 | 交互行为 |
|------|---------|
| 收藏按钮 | 通用收藏按钮组件，收藏/取消状态实时同步 |
| 收藏操作 | 未收藏点击收藏，已收藏点击取消（确认弹窗） |
| 重复收藏 | 幂等返回，不报错不产生重复数据 |
| 收藏容量已满 | 提示"收藏已达上限，请清理后重试" |
| 对象已失效 | 卡片标记"已失效"，点击不跳转 |
| 批量取消 | 支持多选取消收藏 |

### 操作反馈

| 场景 | 反馈行为 |
|------|---------|
| 收藏成功 | 图标变实心，提示"已添加到收藏" |
| 取消收藏 | 图标变空心，提示"已取消收藏" |

## 5. 依赖关系

### 5.1 被依赖模块

| 模块 | 依赖说明 |
|------|---------|
| **算法管理** | 算法删除时标记相关收藏失效 |
| **数据集管理** | 数据集删除时标记相关收藏失效 |
| **图像处理结果页 / 算法详情页 / 数据集详情页** | 业务页面嵌入收藏入口（`FavoriteButton` 组件，规划排期接入） |
| **推荐管理** | 收藏行为作为用户偏好信号输入（推荐引擎未读取，暂未生效） |

### 5.2 依赖模块

| 模块 | 依赖说明 |
|------|---------|
| **会员管理** | 按会员等级阶梯区分收藏容量（普通 200 / VIP 500） |
| **算法/数据集/处理记录** | 收藏时校验对象存在 |

## 6. 待确认事项

1. **收藏导出**：是否需要支持导出收藏列表（为后续备份/迁移准备）？
2. **收藏分享**：是否允许用户分享自己的收藏夹给其他用户？
3. **收藏容量阶梯生效时机**：收藏容量四级阶梯（普通 200 / VIP1 500 / VIP2 1000 / SVIP 3000）的上线时机与存量用户迁移？
4. **失效收藏清理周期**：失效收藏条目是否需要自动清理（当前仅手动取消/一键清理），自动清理周期是多少？
5. **收藏排序扩展**：是否需要支持按对象评分或使用频率排序（当前仅按收藏时间）？
