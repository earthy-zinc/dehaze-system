# 收藏管理模块需求规格

## 1. 模块概述

### 1.1 模块定位

收藏管理模块是图像去雾系统的通用基础模块，为所有核心业务实体提供统一的收藏能力。用户可将感兴趣的算法、处理结果、数据集等任意类型的对象加入收藏夹，并在统一的收藏页面中集中查看和管理。

该模块替代当前各模块自行实现的独立收藏逻辑（算法收藏表、历史记录 is_favorite 字段等），提供一致的用户体验和可复用的收藏能力。

### 1.2 核心价值

| 价值维度 | 具体内容 |
|---------|---------|
| **统一体验** | 所有可收藏对象使用一致的交互模式（收藏/取消收藏/收藏列表），用户无需在不同页面学习不同的收藏操作 |
| **聚合入口** | 提供"我的收藏"聚合页，用户可在一个页面浏览所有类型的收藏内容，支持按类型筛选 |
| **跨模块复用** | 新模块接入收藏能力只需声明 targetType，无需重复开发收藏表/接口/组件 |
| **数据沉淀** | 收藏行为作为用户偏好的重要信号，为推荐引擎提供训练数据 |

### 1.3 业务目标

#### 功能目标

- 提供统一的收藏/取消收藏能力，支持任意业务实体类型
- 提供按类型筛选的"我的收藏"聚合页面
- 支持收藏列表的排序（收藏时间/使用频率/评分）和搜索
- 当前模块类型：算法、处理结果、数据集；预留图片、参数方案等扩展能力

#### 性能目标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 收藏/取消收藏响应 | < 200ms | 单次操作 |
| 收藏列表查询响应 | < 500ms | 分页查询 |
| 收藏容量 | ≥ 500 条/用户 | 单个用户收藏上限 |

## 2. 用户角色分析

### 2.1 主要用户角色

| 角色 | 描述 | 主要职责 |
|------|------|---------|
| **普通用户** | 所有登录用户 | 收藏/取消收藏、管理个人收藏列表 |
| **VIP用户** | 付费用户 | 享有更多收藏容量、更丰富的排序和筛选能力 |

### 2.2 权限矩阵

| 功能点 | 普通用户 | VIP用户 |
|--------|:------:|:------:|
| 收藏/取消收藏 | ✅ | ✅ |
| 查看收藏列表 | ✅ | ✅ |
| 按类型筛选 | ✅ (单一类型) | ✅ (多类型组合) |
| 收藏排序（时间） | ✅ | ✅ |
| 收藏排序（评分/使用频率） | ❌ | ✅ |
| 收藏容量 | 200 条 | 500 条 |
| 批量取消收藏 | ✅ | ✅ |

## 3. 收藏对象类型定义

| 类型编码 | 类型名称 | 来源模块 | 状态 |
|---------|---------|---------|:----:|
| `algorithm` | 算法 | 算法选择/算法管理 | 新增 |
| `result` | 处理结果 | 去雾处理/效果对比 | 迁移自 is_favorite |
| `dataset` | 数据集 | 数据集管理 | 新增 |
| `image` | 图片 | 图像输入 | 预留 |
| `preset` | 参数方案 | 去雾处理 | 预留 |

## 4. 功能需求

### 4.1 收藏操作 (F-FAV-001)

#### 4.1.1 功能描述

用户对可收藏对象执行收藏或取消收藏操作。同一用户对同一对象只能收藏一次。

#### 4.1.2 操作入口

| 入口 | 触发方式 | 说明 |
|------|---------|------|
| 列表/卡片收藏按钮 | 点击心形图标 | 主要操作入口 |
| 详情页收藏按钮 | 点击收藏按钮 | 在查看详情时收藏 |
| 收藏列表取消 | 左滑删除或点击已收藏图标 | 在收藏聚合页中取消 |

#### 4.1.3 交互规则

| 场景 | 行为 |
|------|------|
| 未收藏 → 点击收藏 | 图标变为实心，Toast 提示"已添加到收藏" |
| 已收藏 → 点击取消 | 图标变为空心，Toast 提示"已取消收藏" |
| 收藏容量已满 | 提示"收藏已达上限（X条），请清理后重试"，引导升级 VIP |
| 对象已失效（如算法已删除） | 收藏列表中标记为"已失效"，支持一键清理 |

### 4.2 收藏列表 (F-FAV-002)

#### 4.2.1 功能描述

用户可在"我的收藏"聚合页面查看所有收藏内容，支持按类型筛选、排序和搜索。

#### 4.2.2 列表展示

| 字段 | 说明 |
|------|------|
| 收藏对象名称 | 算法名/图片名/数据集名等 |
| 类型标签 | 算法/处理结果/数据集（彩色标签区分） |
| 对象摘要 | 算法评分、图片缩略图、数据集描述等（按类型） |
| 收藏时间 | 何时收藏 |
| 操作 | 取消收藏、跳转详情 |

#### 4.2.3 筛选与排序

| 维度 | 选项 |
|------|------|
| 类型筛选 | 全部/算法/处理结果/数据集 |
| 排序方式 | 收藏时间倒序（默认）/ 收藏时间正序 / 评分高低（VIP）/ 使用频率（VIP） |
| 搜索 | 按收藏对象名称关键词搜索 |

### 4.3 收藏数据同步 (F-FAV-003)

#### 4.3.1 功能描述

当收藏对象的状态发生变化时（如算法被删除、处理结果被清理），收藏列表中的条目同步更新。

| 场景 | 行为 |
|------|------|
| 对象被逻辑删除 | 收藏条目保留但标记"已失效"，用户可手动清理 |
| 对象被物理删除 | 收藏条目同步删除（级联清理） |
| 对象信息变更 | 收藏列表展示最新信息（名称/缩略图等通过关联查询实时获取） |

## 5. 依赖关系

### 5.1 被依赖模块

| 模块 | 依赖说明 |
|------|---------|
| **算法选择** | 算法收藏接入 |
| **去雾处理/效果对比** | 处理结果收藏接入（替代当前 is_favorite） |
| **数据集管理** | 数据集收藏接入 |
| **推荐管理** | 收藏行为作为用户偏好信号输入 |

### 5.2 依赖模块

| 模块 | 依赖说明 |
|------|---------|
| **会员管理** | VIP 收藏容量区分 |
| **文件管理** | 收藏列表中对象的缩略图展示 |

## 6. 待确认事项

1. **收藏上限策略**：是否所有用户统一上限，还是按会员等级阶梯设置？
2. **收藏导出**：是否需要支持导出收藏列表（为后续备份/迁移准备）？
3. **收藏分享**：是否允许用户分享自己的收藏夹给其他用户？
4. **排序权重**：评分和使用频率的排序是否需要用户自定义权重？
