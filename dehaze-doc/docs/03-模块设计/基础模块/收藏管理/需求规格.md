## 1. 模块概述

### 1.1 模块定位

收藏管理模块是图像去雾系统的通用基础模块，通过统一收藏表为所有核心业务实体提供收藏能力。用户可将感兴趣的算法、处理结果、数据集等对象加入收藏夹，并在"我的收藏"页面集中查看和管理。

> **迁移说明**：Java 端已迁移至统一收藏表（原算法收藏表已废弃，图像输入历史的收藏状态字段已移除，改由本模块统一管理）；Go 端仍存在旧的算法收藏逻辑（独立算法收藏表）待迁移。

### 1.2 核心价值

| 价值维度 | 具体内容 | 状态 |
|---------|---------|------|
| **统一体验** | 所有可收藏对象使用一致的收藏/取消收藏/收藏列表交互 | ✅ 已实现 |
| **聚合入口** | "我的收藏"页面支持按类型筛选查看所有收藏内容 | ✅ 已实现 |
| **跨模块复用** | 新模块接入收藏能力只需声明收藏类型，无需重复开发收藏表/接口 | ✅ 已实现（接口层） |
| **数据沉淀** | 收藏行为作为用户偏好信号，供推荐引擎使用 | ⏳ 规划中（推荐引擎未读取） |

### 1.3 业务目标

#### 功能目标

- 提供统一的收藏/取消收藏能力，支持多种业务实体类型 ✅ 已实现
- 提供按类型筛选的"我的收藏"聚合页面 ✅ 已实现
- 支持收藏列表的排序和搜索 ⏳ 部分实现（仅按收藏时间排序；评分/使用频率排序未实现）
- 收藏对象失效自动标记 ⏳ 部分实现（仅算法/数据集删除时标记；处理结果无失效标记）

#### 性能目标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 收藏/取消收藏响应 | < 200ms | 单次操作 |
| 收藏列表查询响应 | < 500ms | 分页查询 |
| 收藏容量 | 普通用户 200 条 / VIP 用户 500 条 | 按会员等级区分 |

## 2. 用户角色分析

### 2.1 主要用户角色

| 角色 | 描述 | 主要职责 |
|------|------|---------|
| **普通用户** | 所有登录用户 | 收藏/取消收藏、管理个人收藏列表（容量 200 条） |
| **VIP 用户** | 付费用户（非普通等级） | 与普通用户能力一致，仅收藏容量提升至 500 条 |

> **说明**：普通用户与 VIP 用户在收藏功能上**仅容量存在差异**，筛选、排序、批量取消等能力一致（早期设计稿的"VIP 多类型组合筛选、评分/使用频率排序"未实现）。

### 2.2 权限矩阵

| 功能点 | 普通用户 | VIP用户 |
|--------|:------:|:------:|
| 收藏/取消收藏 | ✅ | ✅ |
| 查看收藏列表 | ✅ | ✅ |
| 按类型筛选（单选） | ✅ | ✅ |
| 收藏排序（时间） | ✅ | ✅ |
| 收藏排序（评分/使用频率） | ❌（未实现） | ❌（未实现） |
| 收藏容量 | 200 条 | 500 条 |
| 批量取消收藏 | ✅ | ✅ |

## 3. 收藏对象类型定义

| 类型编码 | 类型名称 | 来源模块 | 状态 |
|---------|---------|---------|:----:|
| `algorithm` | 算法 | 算法选择/算法管理 | 已实现（收藏校验 + 删除标记失效） |
| `result` | 处理结果 | 去雾处理/效果对比 | 已实现（收藏校验；无失效标记） |
| `dataset` | 数据集 | 数据集管理 | 已实现（收藏校验 + 删除标记失效） |
| `image` | 图片 | 图像输入 | 预留（可收藏，无对象校验） |
| `preset` | 参数方案 | 去雾处理 | 预留（可收藏，无对象校验） |

> **说明**：五类类型均可提交收藏；其中 algorithm/dataset/result 三类在收藏时校验对象存在，image/preset 为预留类型跳过校验。算法/数据集删除时自动将相关收藏标记失效。

## 4. 功能需求

### 4.1 收藏操作 (F-FAV-001)

#### 4.1.1 功能描述

用户对可收藏对象执行收藏或取消收藏操作。同一用户对同一对象只能收藏一条记录（重复收藏幂等返回原记录）。**已实现**。

#### 4.1.2 操作入口

| 入口 | 说明 | 状态 |
|------|------|:----:|
| 我的收藏页-取消收藏 | 卡片"取消收藏"按钮（确认弹窗） | ✅ 已实现 |
| 通用收藏按钮组件 | `FavoriteButton` 组件已封装（收藏/取消/状态初始化），**尚未嵌入任何业务页面** | ⏳ 组件待接入 |
| 列表左滑删除 / 详情页收藏按钮 | 未实现 | ⏳ 规划中 |

#### 4.1.3 交互规则

| 场景 | 行为 |
|------|------|
| 未收藏 → 点击收藏 | 收藏成功，返回收藏记录 ID |
| 已收藏 → 重复点击 | 幂等返回原记录（不报错、不产生重复数据） |
| 已取消 → 再次收藏 | 原记录复活（逻辑删除恢复），收藏时间更新 |
| 收藏容量已满 | 提示"收藏已达上限（X条），请清理后重试" |
| 对象已失效 | 收藏列表卡片标记"已失效"，点击卡片不跳转 |

### 4.2 收藏列表 (F-FAV-002)

#### 4.2.1 功能描述

用户可在"我的收藏"页面查看所有收藏内容，支持按类型筛选、排序和搜索。**已实现**。

#### 4.2.2 列表展示

| 字段 | 说明 |
|------|------|
| 收藏对象名称 | 算法名/数据集名（关联查询）；处理结果等类型暂无名称（显示"-"） |
| 类型标签 | 算法/处理结果/数据集/图片/预设（彩色标签区分） |
| 缩略图 | 数据集类型展示缩略图；其余类型无 |
| 对象摘要 | 当前恒为空（字段预留，无数据） |
| 收藏时间 | 何时收藏（日期） |
| 失效标记 | 对象已删除时展示"已失效"标签 |
| 操作 | 取消收藏、点击卡片跳转详情 |

> **说明**：列表信息由关联查询实时获取（名称随对象更新），对象删除后名称为空且标记失效。

#### 4.2.3 筛选与排序

| 维度 | 选项 |
|------|------|
| 类型筛选 | 全部/算法/处理结果/数据集/图片/预设（单选） |
| 排序方式 | 按收藏时间倒序（默认）/ 按收藏时间正序 |
| 搜索 | 按收藏对象名称关键词搜索（仅算法/数据集名称参与匹配） |

> **说明**：前端排序下拉含"按评分/按使用频率"选项，但后端**当前仅支持按收藏时间排序**（评分/使用频率排序未实现，选择后实际仍按时间排序）。

### 4.3 收藏数据同步 (F-FAV-003)

#### 4.3.1 功能描述

当收藏对象的状态发生变化时，收藏列表中的条目同步更新。**部分实现**。

| 场景 | 行为 |
|------|------|
| 算法被删除（逻辑删除） | 相关收藏条目标记"已失效"（删除算法时自动触发） |
| 数据集被删除（逻辑删除） | 相关收藏条目标记"已失效"（删除数据集时自动触发） |
| 处理结果被清理 | 当前**无失效标记**（处理记录删除不联动收藏） |
| 对象名称变更 | 收藏列表通过关联查询展示最新名称 |
| 失效条目清理 | 用户可手动取消收藏；**无"一键清理失效"入口** |
