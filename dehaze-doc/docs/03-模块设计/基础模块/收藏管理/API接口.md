# 收藏管理模块 API 接口

## 1. 文档概述

本文档定义 **收藏管理** 模块的 HTTP API 规范，是该模块 API 契约的**唯一权威来源**。

- **基础路径**：`/api/v1/favorites`
- **公共约定**：参见 [02-系统架构/04-API规范.md](../../../02-系统架构/04-API规范.md)
- **需求规格**：[需求规格.md](./需求规格.md)

> **重要**：接口详细参数/响应结构可通过 API 文档 MCP 查询，本文档仅定义接口清单和权限标识。

## 2. 接口清单

| 路径 | 方法 | 功能描述 | 权限标识 | 关联功能点 |
|------|------|---------|---------|-----------|
| `/api/v1/favorites/page` | GET | 收藏列表分页查询（支持 type/algorithms/results/datasets 筛选、排序、关键词搜索） | - | F-FAV-002 |
| `/api/v1/favorites` | POST | 添加收藏（请求体：targetType + targetId） | - | F-FAV-001 |
| `/api/v1/favorites/{ids}` | DELETE | 批量取消收藏 | - | F-FAV-001 |
| `/api/v1/favorites/{id}/status` | GET | 检查指定对象是否已收藏（用于前端图标状态判断） | - | F-FAV-001 |
| `/api/v1/favorites/count` | GET | 收藏数量（按类型分组统计） | - | F-FAV-002 |

> **说明**：所有接口要求登录用户身份，通过 Session 自动识别当前用户，无特殊权限标识。

## 3. 权限标识汇总

| 权限标识 | 说明 |
|---------|------|
| - | 收藏管理无特殊权限，登录用户即可操作 |

## 4. 业务错误码

| 错误码 | 说明 | 触发场景 |
|--------|------|---------|
| `A0501` | 数据已存在 | 重复收藏同一对象 |
| `A0401` | 请求资源不存在 | 收藏对象已失效（targetType + targetId 对应对象不存在） |
| `A0500` | 业务异常 | 收藏容量已满（普通用户 200 条 / VIP 500 条） |
| `A0230` | token无效或已过期 | 未登录访问 |
