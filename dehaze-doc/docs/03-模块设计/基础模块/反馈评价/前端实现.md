# 反馈评价模块 - 前端实现设计

## 1. 文档概述

本文档描述反馈评价模块的前端实现方案（dehaze-front-vue），聚焦组件结构、页面布局、数据流、关键交互决策与权限控制。

---

## 2. 组件架构设计

### 2.1 组件结构

```
反馈评价模块
├── RatingCard（components/RatingCard/index.vue）  # 评价弹窗组件（已封装，未接入业务页面）
├── views/feedback/
│   ├── my-ratings/index.vue     # 我的评价（只读列表，含管理员回复）
│   ├── my/index.vue             # 我的反馈（列表 + 新建反馈对话框）
│   ├── detail/index.vue         # 反馈详情（内容 + 回复时间线 + 补充说明）
│   ├── rating/index.vue         # 后台评价管理（表格 + 筛选 + 隐藏/回复）
│   ├── list/index.vue           # 后台反馈管理（表格 + 筛选 + 详情弹窗 + 分配/回复/关闭/标签）
│   └── stats/index.vue          # 后台统计分析（评价统计 + 反馈统计，ECharts）
```

> **说明**：
> - 早期设计稿中的 RatingStars/TagSelector/ImageUploader/Timeline 等原子组件拆分**不存在**——相关能力内聚在页面组件与 RatingCard 中
> - 路由已注册：`/feedback/my-ratings`（我的评价）、`/feedback/my`（我的反馈）、`/feedback/detail`（反馈详情）
> - 后台页面（rating/list/stats）文件已实现，**未注册在静态路由**（后台入口待接入/由动态菜单加载）

### 2.2 组件职责

| 组件 | 职责 | 复用性 |
|------|------|--------|
| RatingCard | 评价弹窗：评分/标签/文字/截图/匿名 + 跳过/提交 | 可复用（待接入） |
| my-ratings | 我的评价列表：星级/评论/标签/图片/管理员回复 | 页面 |
| my | 我的反馈：卡片列表 + 新建反馈对话框 | 页面 |
| detail | 反馈详情：完整内容/图片/标签/回复时间线/补充说明 | 页面 |
| rating | 后台评价管理：分页表格 + 用户/算法/评分筛选 + 隐藏/回复 | 页面 |
| list | 后台反馈管理：分页表格 + 类型/状态/优先级筛选 + 分配/回复/关闭/标签 | 页面 |
| stats | 后台统计：评价统计（平均分/分布/算法/标签）+ 反馈统计（类型/状态/模块/响应/关键词） | 页面 |

## 3. 页面布局设计

### 3.1 评价弹窗（RatingCard）

弹窗（宽 600px，禁止关闭按钮与点击遮罩关闭）：

| 区域 | 说明 |
|------|------|
| 顶部提示 | 算法名称展示（品牌色胶囊） |
| 整体评分 | 星级评分（5 星，带文字提示：很不满意/不满意/一般/满意/非常满意） |
| 效果标签 | 标签多选（最多 5 个），按评分动态展示：≥4 正面标签、≤2 负面标签、=3 全部；切换评分档位清空已选 |
| 评价内容 | 多行输入（最多 500 字符，字数统计） |
| 上传截图 | 图片上传（限 3 张，JPG/PNG/WEBP，单张 ≤5MB） |
| 匿名评价 | 开关 |
| 底部 | 跳过 / 提交评价（提交节流，成功后提示"评价成功，获得成长值奖励"） |

### 3.2 我的评价（my-ratings）

只读卡片列表：算法名 + 星级（只读带分值）+ 时间、评价文字、标签、图片预览（可放大）、管理员回复卡片（头像/回复时间/内容）。分页展示。

> **无补评/修改入口**（后端修改能力已就绪，前端未接入）。

### 3.3 我的反馈（my）

| 区域 | 说明 |
|------|------|
| 页头 | 标题 + "新建反馈"按钮 |
| 列表 | 状态卡片（状态色带 + 状态标签 + 类型标签 + 模块标签 + 时间 + 标题 + 内容摘要 + 处理人 + 查看详情） |
| 新建对话框 | 反馈类型（下拉 4 类）/ 标题 / 内容 / 联系方式 / 截图（≤5 张）/ 相关模块（下拉），提交后刷新列表 |

### 3.4 反馈详情（detail）

| 区域 | 说明 |
|------|------|
| 内容卡片 | 标题、类型/状态/模块/时间标签、正文、图片、标签 |
| 时间线卡片 | 按回复记录升序展示：提交（用户）→ 回复（管理员，含回复类型标签）→ 补充（用户） |
| 补充说明卡片 | 状态非已关闭时显示：多行输入（≤1000）+ "提交补充"按钮 |

### 3.5 后台评价管理（rating）

筛选区（关键字/算法/评分范围）+ 表格（选择框/用户名[匿名显示"匿名用户"]/算法/星级/评价内容[溢出提示]/标签/时间/操作[详情、隐藏、回复]）+ 详情弹窗（完整评价 + 图片 + 回复）+ 回复弹窗（多行输入）。

### 3.6 后台反馈管理（list）

筛选区（关键字/类型/状态/优先级/模块）+ 表格（标题/类型/模块/状态/优先级/处理人/时间/操作）+ 详情弹窗（完整内容/图片/联系方式[管理员可见]/标签/回复时间线）+ 操作：分配（选择处理人）/ 回复（内容+回复类型）/ 关闭（关闭原因）/ 标签（多选/输入）。

### 3.7 后台统计分析（stats）

Tab 切换"评价统计 / 反馈统计"，顶部时间范围选择：

| Tab | 展示内容 |
|------|---------|
| 评价统计 | 统计卡片（平均评分/评价总数）、评分分布（柱状图/饼图）、算法维度统计表格、正负标签排行 |
| 反馈统计 | 统计卡片（反馈总数/平均响应/平均关闭）、类型分布、状态分布、模块排行（柱状图）、高频关键词（标签列表） |

## 4. 状态管理

反馈评价**无独立 Store**，状态在组件内局部管理（loading/分页数据/对话框显隐/表单数据等）。

---

## 5. 数据流

### 5.1 评价数据流

```
处理完成 → 评价弹窗打开（当前未接入，见需求规格 §2.1.5）
    ↓ 用户提交（评分/文字/标签/截图/匿名）
调用评价提交接口 → 成功提示"评价成功，获得成长值奖励" → 关闭弹窗
    ↓
我的评价页 / 后台评价管理 通过评价查询接口展示（列表含管理员回复）
```

### 5.2 反馈数据流

```
我的反馈页：新建反馈对话框提交 → 刷新列表
    ↓
我的反馈列表 → 查看详情（加载完整内容 + 回复时间线）
    ↓ 未关闭时可补充说明（状态"已回复"时回退为"处理中"）
后台反馈管理：筛选 → 详情 → 分配/回复/关闭/设置标签
```

### 5.3 模块间数据交互

| 交互方向 | 数据 | 说明 |
|---------|------|------|
| 去雾处理 → 反馈评价 | 处理记录 ID | 评价关联的处理记录（校验归属/状态/时限） |
| 反馈评价 → 会员管理 | 评价事件 | 提交评价获得成长值奖励 |
| 反馈评价 → 消息通知 | 低分评价事件 | 触发管理员站内信告警 |

---

## 6. 关键交互决策

| 决策点 | 实现方式 |
|--------|---------|
| 评价标签动态切换 | 评分 ≥4 展示正面标签、≤2 展示负面标签、=3 展示全部；切换评分档位时清空已选（监听评分变化比较档位） |
| 评价提交防抖 | 提交操作节流，防止重复提交 |
| 评分文字映射 | 星级评分带文字提示（很不满意/不满意/一般/满意/非常满意） |
| 截图校验 | 上传前校验类型（JPG/PNG/WEBP）与大小（≤5MB），超限提示 |
| 反馈状态展示 | 状态映射（待处理/处理中/已回复/已关闭），卡片色带 + 标签 |
| 详情联系信息 | 联系方式仅后台（管理员）可见；用户端详情不展示 |

---

## 7. 权限控制设计

| 功能 | 权限标识 | 说明 |
|------|---------|------|
| 评价隐藏/回复 | feedback:rating:edit / feedback:rating:reply | 后台页面按钮控制 |
| 反馈分配/回复/关闭/标签 | feedback:assign / reply / close / edit | 后台页面按钮控制 |
| 统计查看 | 登录即可 | stats 页面访问 |

---

## 8. 性能优化

| 优化项 | 实现方式 |
|--------|---------|
| 评价提交节流 | 提交节流，防止重复请求 |
| 分页查询 | 后端分页，前端仅当前页渲染 |
| 统计图表 | 图表按需初始化/销毁 |
| 统计缓存 | 后端统计数据缓存，前端无缓存 |
