## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **处理日志** | 各状态处理记录（已完成/失败） | 用于评价关联 |
| **算法数据** | 多个算法 | 用于评价统计按算法聚合 |
| **评价数据** | 各星级评价（1-5星）、含/不含文字、含/不含图片 | 用于评价管理测试 |
| **反馈数据** | 各类型/状态/优先级反馈 | 用于反馈管理测试 |
| **用户数据** | 各等级会员用户 | 用于按用户等级统计 |

### 3.2 数据清理策略

- 测试评价与反馈使用统一标识：评价 comment 前缀 `测试评价-`，反馈 title 前缀 `测试反馈-`
- 测试结束按前缀清理评价、反馈、回复记录
- 测试图片上传至 MinIO 专用 bucket，测试后清理

### 3.3 测试范围

**包含的功能点：**
- 处理结果评分（提交/修改/查询）
- 用户反馈（提交/查询/补充说明）
- 评价管理（列表/隐藏/回复/统计）
- 反馈管理（列表/分配/回复/关闭/标签）
- 低分告警
- 评价与反馈统计分析

**不包含的功能点：**
- 去雾处理流程（处理模块测试）
- 成长值增加（会员模块测试）
- 文件上传细节（文件模块测试）

## 5. 关键边界与异常场景

| 场景 | 测试点 | 期望行为 |
|------|--------|---------|
| **评价数量边界** | 单算法评价达到1000+ | 统计聚合响应时间&lt;2s |
| **评价防刷** | 同一处理记录多次评价 | uk_pred_log_id 唯一索引阻止 |
| **反馈频率限制** | 每用户每日 &gt;5条反馈 | 拒绝第6条 |
| **低分告警可靠** | 评价提交后10s内 | 必须完成告警判断 |
| **统计缓存降级** | Redis 不可用 | 降级 DB 查询，影响性能但功能正常 |
| **图片安全** | 上传恶意文件 | 类型校验+大小限制 |
| **内容过滤** | 评价/反馈含敏感词 | 过滤或拒绝 |
| **评价降级** | 评价功能不可用 | 不影响核心去雾流程 |

## 7. 安全性测试

| 测试项 | 验证方式 | 预期结果 |
|--------|---------|---------|
| **评价防刷** | 同一处理记录多次评价 | 唯一索引阻止 |

| **数据隔离** | 用户查看他人评价/反馈 | 返回 FEEDBACK_NOT_FOUND（404），不暴露资源是否存在 |

| **XSS攻击** | 评价内容注入脚本 | 输出时编码 |
| **传输安全** | 抓包分析请求 | HTTPS加密传输 |
