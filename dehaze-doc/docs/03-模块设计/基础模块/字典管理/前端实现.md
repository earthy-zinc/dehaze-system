# 字典管理模块 - 前端实现设计

## 1. 文档概述

本文档描述字典管理模块的前端实现方案，聚焦组件架构、状态管理、交互设计等架构决策。

### 2.3 组件接口定义

#### 2.3.1 字典类型搜索表单

| 属性/事件 | 类型 | 说明 |
|----------|------|------|
| modelValue | DictTypeQuery | 搜索条件 |
| @search | () => void | 搜索事件 |
| @reset | () => void | 重置事件 |

**搜索表单组件设计**：
- **类型名称输入框**：占位符 "字典名称"，支持回车键触发搜索，带清空按钮
- **类型编码输入框**：占位符 "字典编码"，支持回车键触发搜索，带清空按钮
- **搜索按钮**：主要按钮样式，搜索图标，触发字典类型列表查询
- **重置按钮**：默认按钮样式，刷新图标，清空搜索条件并重新查询

#### 2.3.2 字典类型表格

| 属性/事件 | 类型 | 说明 |
|----------|------|------|
| data | DictType[] | 表格数据 |
| loading | boolean | 加载状态 |

| @manage-data | (row: DictType) => void | 管理字典数据事件 |

## 3. 状态管理

### 3.1 字典类型页面状态

| 状态字段 | 类型 | 初始值 | 说明 |
|---------|------|--------|------|
| loading | Boolean | false | 加载状态 |
| removeIds | Array | [] | 待删除ID集合 |
| total | Number | 0 | 数据总数 |
| pageData | Array | [] | 字典类型分页数据 |

查询参数：`{ pageNum: 1, pageSize: 10, name: "", code: "" }`

### 3.2 字典数据弹窗状态

| 状态字段 | 类型 | 初始值 | 说明 |
|---------|------|--------|------|
| visible | Boolean | false | 弹窗可见性 |
| typeCode | String | "" | 当前字典类型编码 |
| typeName | String | "" | 当前字典类型名称 |
| loading | Boolean | false | 加载状态 |
| removeIds | Array | [] | 待删除ID集合 |
| total | Number | 0 | 数据总数 |
| pageData | Array | [] | 字典数据分页数据 |

### 3.3 表单数据状态

**字典类型表单**：`{ name, code, status(默认1=启用), remark }`

**字典数据表单**：`{ name, value, typeCode, defaulted(默认0=否), sort(默认1), status(默认1=启用), remark }`

### 3.4 页面状态类型

| 状态 | 显示效果 |
|------|---------|
| 加载中 | 显示加载动画/骨架屏 |
| 空数据 | 显示"暂无数据"提示 |
| 加载失败 | 显示错误提示，提供重试按钮 |
| 正常 | 显示数据列表 |

### 3.5 按钮状态控制

| 按钮 | 状态控制 |
|------|---------|
| 批量删除按钮 | 无选中项时禁用 |
| 确定按钮 | 表单校验未通过时禁用，提交中显示加载 |

## 4. 数据流

字典类型与字典数据的增删改查、表单回显、下拉选项获取均通过 SDK 封装的任务/字典接口调用，页面组件内完成请求与状态管理。

## 5. 交互设计

### 5.1 关键流程

| 流程 | 关键点 |
|------|--------|
| 字典类型新增 | 打开表单弹窗 → 实时校验 → 提交 → 关闭弹窗 → 刷新列表 → 成功提示 |
| 字典类型编辑 | 加载表单数据 → 编码只读 → 提交 → 刷新列表 |
| 字典类型删除 | 确认对话框 → 关联检查 → 删除 → 刷新列表 |
| 字典数据管理 | 点击"字典数据"按钮 → 打开管理弹窗 → 表格CRUD |
| 字典数据新增/编辑 | 表单弹窗 → typeCode只读 → 提交 → 刷新数据表格 |

## 6. 表单校验规则

### 6.1 字典类型表单校验

| 字段 | 规则 | 错误提示 |
|------|------|---------|
| name | 必填 | 字典名称不能为空 |
| code | 必填，编辑时只读 | 字典编码不能为空 |

### 6.2 字典数据表单校验

| 字段 | 规则 | 错误提示 |
|------|------|---------|
| name | 必填 | 字典标签不能为空 |
| value | 必填 | 字典键值不能为空 |
| sort | 必填，数字 | 字典排序必须为数字 |

### 6.3 业务校验规则

| 校验项 | 说明 |
|--------|------|
| 编码唯一性 | 字典类型编码在系统中必须唯一（后端校验） |
| 值唯一性 | 字典值在同一类型下必须唯一（后端校验） |
| 关联检查 | 删除字典类型前检查是否存在关联字典数据 |
