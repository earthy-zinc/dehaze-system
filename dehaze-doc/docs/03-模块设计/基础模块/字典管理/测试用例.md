## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **字典类型数据** | 至少5个不同类型（性别、状态、等级等） | 用于字典类型列表查询测试 |
| **字典数据** | 各类型下至少3条数据 | 用于字典数据列表查询测试 |
| **混合状态数据** | 包含启用/禁用状态的字典数据 | 用于下拉查询测试 |
| **排序数据** | 不同sort值的字典数据 | 用于排序功能测试 |

### 3.2 数据清理策略

- 测试字典类型数据使用统一前缀 `test_dict_type_` 标识
- 测试字典数据使用统一前缀 `test_dict_data_` 标识
- 测试结束后按前缀批量删除测试数据
- 保留系统默认字典数据（如性别、状态等）不做删除操作

### 3.3 测试范围

**包含的功能点：**
- 字典类型列表查询（分页、搜索）
- 字典类型新增、编辑、删除
- 字典类型状态管理（启用/禁用）
- 字典数据列表查询（按类型筛选）
- 字典数据新增、编辑、删除
- 字典数据状态管理（启用/禁用）
- 字典数据排序
- 字典下拉选项查询

**不包含的功能点：**
- 字典数据导入导出（未实现功能）
- 字典使用情况统计（未实现功能）
- 字典默认值标记（未实现功能）

## 6. 关键边界与异常场景

| 场景 | 测试点 | 期望行为 |
|------|--------|---------|
| **字典类型数量边界** | 系统字典类型达到1000+ | 列表查询响应时间仍&lt;500ms |
| **字典数据数量边界** | 字典类型下数据达到1000+ | 列表查询响应时间仍&lt;500ms |
| **并发新增字典类型** | 同时新增相同编码 | 只有一个成功，另一个提示编码已存在 |
| **并发新增字典数据** | 同一类型下同时新增相同value | 只有一个成功，另一个提示值已存在 |
| **并发编辑** | 同一字典类型/数据被多人同时编辑 | 乐观锁保护，冲突时提示重新加载 |
| **字典类型编码变更** | 修改字典类型编码 | 关联的字典数据typeCode同步更新 |
| **字典下拉缓存** | 修改字典数据状态 | 缓存立即更新，下拉查询返回最新数据 |
| **批量操作限制** | 批量删除100+字典数据 | 按配置限制或分批处理 |
| **事务完整性** | 字典类型编码更新失败 | 事务回滚，数据保持一致 |

## 8. 安全性测试

| 测试项 | 验证方式 | 预期结果 |
|--------|---------|---------|
| **权限控制** | 无权限用户调用新增/编辑/删除接口 | 返回403 |
| **SQL注入** | 参数中包含 `admin'--` | 被参数化查询转义，无SQL注入风险 |
| **XSS攻击** | 字典名称注入 `&lt;script&gt;alert(1)&lt;/script&gt;` | 输出时编码，不执行脚本 |
| **传输安全** | 抓包分析请求 | HTTPS加密传输 |
| **防重复提交** | 快速连续点击提交 | Token机制防护，仅执行一次 |
| **输入校验** | 超长字符串、特殊字符 | 前后端双重校验，拒绝非法输入 |
