# 字典管理模块需求规格

## 1. 模块概述

### 1.1 模块定位

字典管理模块是 **AI 图像处理平台**（远期演进为「AI 工作平台」）的核心基础模块之一，负责维护和管理系统中各种业务字典数据。该模块采用两级管理结构，包括字典类型和字典数据两个层次，为系统提供统一的基础数据管理能力，是整个系统数据一致性的保障。平台支持去雾/去雨/去雪/低光增强/超分辨率/去噪/图像修复等多任务图像处理，多端覆盖（Web Vue/React、Android、Flutter、Taro/UniApp 小程序、Electron 桌面端），字典数据通过缓存供各端业务模块共享消费。

> **三后端契约**：Java/Go/Python 三后端 API 契约完全一致，Java 为权威来源，Go/Python 对齐。

### 1.2 核心价值

| 价值维度 | 具体内容 |
|---------|---------|
| **统一管理** | 提供系统基础数据的统一管理入口，避免代码硬编码 |
| **动态调整** | 支持运行时动态调整字典数据，无需修改代码 |
| **两级分类** | 采用字典类型+字典数据两级结构，便于分类管理 |
| **状态控制** | 支持字典数据的启用/禁用状态控制，灵活控制数据可用性 |
| **全局共享** | 提供标准化的字典数据接口，供所有业务模块使用，多端读缓存 |

### 1.3 业务目标

#### 功能目标
- 实现字典类型的统一管理（CRUD 操作）
- 实现字典数据的统一管理（CRUD 操作）
- 提供字典数据下拉选项接口，供其他模块调用
- 确保字典数据的唯一性和一致性

#### 性能目标
| 指标 | 目标值 | 说明 |
|------|--------|------|
| **字典类型列表响应** | &lt;500ms | 字典类型分页查询响应时间 |
| **字典数据列表响应** | &lt;500ms | 字典数据分页查询响应时间 |
| **字典下拉选项响应** | &lt;200ms | 字典下拉选项查询响应时间 |
| **字典下拉选项 QPS** | ≥500 | 字典下拉选项接口吞吐量 |
| **缓存命中率** | ≥95% | 字典下拉选项缓存命中率 |
| **字典类型容量** | ≥1000 | 系统支持的最大字典类型数量 |
| **字典数据容量** | ≥10000 | 系统支持的最大字典数据数量 |

## 3. 功能需求

### 3.1 字典类型列表查询 (F-DM-001)

#### 3.1.1 功能描述

提供字典类型的分页展示和筛选能力，支持管理员快速查找目标字典类型。

#### 3.1.2 查询条件

| 条件类型 | 字段 | 说明 | 匹配方式 |
|---------|------|------|---------|
| **关键字搜索** | 名称/编码 | 多字段模糊匹配 | LIKE |
| **状态** | status | 按启用/禁用状态筛选 | = |

#### 3.1.3 列表展示字段

| 字段 | 显示名称 | 说明 |
|------|---------|------|
| id | 编号 | 字典类型唯一标识 |
| name | 类型名称 | 字典类型显示名称 |
| code | 类型编码 | 字典类型编码，全局唯一 |
| status | 状态 | 启用/禁用 |
| remark | 备注 | 备注信息 |
| createTime | 创建时间 | 创建时间 |
| - | 操作 | 字典数据/编辑/删除 |

#### 3.1.4 分页配置

| 配置项 | 默认值 | 可选值 |
|--------|--------|--------|
| 每页条数 | 10 | 10/20/50/100 |

### 3.2 字典类型新增 (F-DM-002)

#### 3.2.1 功能描述

支持创建新的字典类型，用于分类管理字典数据。

#### 3.2.2 表单字段

| 字段 | 显示名称 | 类型 | 必填 | 校验规则 |
|------|---------|------|------|---------|
| name | 类型名称 | 输入框 | ✅ | 不能为空 |
| code | 类型编码 | 输入框 | ✅ | 不能为空，系统唯一 |
| status | 状态 | 单选框组 | ✅ | 默认启用(1) |
| remark | 备注 | 文本域 | ❌ | 最多 255 字符 |

#### 3.2.3 业务规则

1. **编码唯一性**：字典类型编码在系统中必须唯一，创建时需校验
2. **编码不可变**：字典类型编码（code）创建后不可修改（与字典数据 typeCode 不可修改保持一致）
3. **状态默认值**：新增字典类型默认状态为启用

### 3.3 字典类型编辑 (F-DM-003)

#### 3.3.1 功能描述

支持修改现有字典类型的基本信息和状态。

#### 3.3.2 可编辑字段

| 字段 | 是否可编辑 | 说明 |
|------|-----------|------|
| name | ✅ | 可随时修改 |
| code | ❌ | 创建后不可修改 |
| status | ✅ | 可启用/禁用 |
| remark | ✅ | 可修改 |

#### 3.3.3 业务规则

1. **编码不可变**：字典类型编码（code）创建后不可修改，编辑表单中 code 字段只读
2. **即时生效**：修改保存后立即生效

### 3.4 字典类型删除 (F-DM-004)

#### 3.4.1 功能描述

支持删除字典类型，包括单个删除和批量删除。删除方式为**逻辑删除**（`deleted` 字段标记，0 未删/1 已删），禁止物理删除。系统预置字典类型不可删除。

#### 3.4.2 删除方式

| 方式 | 触发操作 | 说明 |
|------|---------|------|
| **单个删除** | 点击操作列删除按钮 | 删除单个字典类型 |
| **批量删除** | 勾选多个后点击批量删除 | 删除选中的所有字典类型 |

#### 3.4.3 业务规则

1. **二次确认**：删除操作需弹窗确认
2. **默认禁止级联**：默认（`force=false`）禁止删除存在关联字典数据的字典类型，需先删除或迁移关联字典数据
3. **强制级联删除**：传入 `force=true` 时级联逻辑删除关联的字典数据（字典数据一并标记 `deleted=1`），并清除对应缓存
4. **预置数据保护**：系统预置字典类型不可删除
5. **逻辑删除**：执行逻辑删除（`deleted=1`），数据保留可追溯，不物理删除

#### 3.4.4 确认提示

- 单个删除："确认删除字典类型「{name}」吗？"
- 批量删除："确认删除选中的 {count} 个字典类型吗？"
- 关联数据提示（`force=false`）："该字典类型下存在字典数据，无法删除！如需级联删除，请确认强制删除。"
- 强制级联确认（`force=true`）："确认删除字典类型「{name}」及其下 {count} 条字典数据吗？"

### 3.9 字典下拉选项查询 (F-DM-009)

#### 3.9.1 功能描述

提供字典数据下拉选项接口，供其他业务模块使用。

#### 3.9.2 接口输入

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| typeCode | String | ✅ | 字典类型编码 |

#### 3.9.3 接口输出

| 字段 | 类型 | 说明 |
|------|------|------|
| label | String | 显示标签，对应 name 字段 |
| value | String | 实际值，对应 value 字段 |

#### 3.9.4 业务规则

1. **排序返回**：按 sort 字段升序返回
2. **状态过滤**：仅返回启用状态（status=1）的字典数据
3. **缓存策略**：字典下拉选项数据启用 Redis 缓存，减少数据库查询（详见 3.10 缓存一致性策略）

### 3.10 缓存一致性策略

#### 3.10.1 缓存 Key 规则

| 缓存对象 | 缓存 Key | 数据类型 | TTL | 说明 |
|---------|---------|---------|-----|------|
| 字典类型 | `dict:type:{code}` | DictType | 1 小时 | 按 code 缓存字典类型信息 |
| 字典数据/下拉选项 | `dict:data:{typeCode}` | List&lt;OptionVO&gt; | 1 小时 | 按 typeCode 缓存启用状态的下拉选项 |

> 字典类型列表、字典数据列表（分页查询）不缓存，采用实时查询；仅下拉选项与字典类型信息启用缓存。

#### 3.10.2 缓存失效与多端同步

- **主动失效**：字典类型/字典数据新增、修改、删除、状态变更时，主动删除对应缓存 Key（`dict:type:{code}`、`dict:data:{typeCode}`）
- **Redis Pub/Sub 通知**：变更后发布 Redis Pub/Sub 消息（频道 `dict:invalidate`），通知 Java/Go/Python 三后端失效本地与 Redis 缓存，确保三后端缓存一致
- **多端读缓存**：各端（Web/移动端/小程序/桌面端）经业务后端读取缓存，业务后端缓存未命中时回源数据库并回写缓存
- **加载策略**：缓存不存在时从数据库加载并写入缓存，防穿透（空值缓存 + 布隆/SingleFlight）

## 4. 界面交互规范

### 4.1 页面布局

字典管理页面采用**单页双列表格布局**，主页面展示字典类型列表，字典数据通过弹窗进行管理。

| 触发方式 | 行为 |
|---------|------|

## 5. 安全设计

### 5.1 权限控制

| 权限标识 | 功能 | 控制方式 |
|---------|------|---------|
| sys:dict:type:add | 新增字典类型 | 按钮显示 + 接口校验 |
| sys:dict:type:edit | 编辑字典类型 | 按钮显示 + 接口校验 |
| sys:dict:type:delete | 删除字典类型 | 按钮显示 + 接口校验 |
| sys:dict:data:add | 新增字典数据 | 按钮显示 + 接口校验 |
| sys:dict:data:edit | 编辑字典数据 | 按钮显示 + 接口校验 |
| sys:dict:data:delete | 删除字典数据 | 按钮显示 + 接口校验 |

> 字典下拉选项接口（`/api/v1/dict/{typeCode}/options`）无需管理权限，登录用户即可调用，供业务模块消费。

### 5.2 数据安全

| 安全措施 | 说明 |
|---------|------|
| **数据校验** | 编码唯一性校验、字典值唯一性校验 |
| **关联检查** | 删除字典类型前检查关联数据（`force=false` 时禁止，`force=true` 时级联） |
| **传输加密** | 数据传输需加密 |
| **防重复提交** | 同一操作不可重复提交 |
| **操作日志** | **强制**记录创建/修改/删除操作日志（操作人、时间、对象编码/ID、变更内容） |
| **删除保护** | 逻辑删除保留数据，系统预置字典类型不可删除 |

### 5.3 输入校验

| 校验类型 | 说明 |
|---------|------|
| **前端校验** | 表单实时校验，提升用户体验 |
| **后端校验** | 服务端进行参数校验 |
| **格式校验** | 编码格式、排序字段正整数校验 |
| **长度校验** | 字段最大长度限制 |
