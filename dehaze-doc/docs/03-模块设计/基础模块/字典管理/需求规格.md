# 字典管理模块需求规格

## 1. 模块概述

### 1.1 模块定位

字典管理模块是图像去雾系统后台管理系统的核心基础模块之一，负责维护和管理系统中各种业务字典数据。该模块采用两级管理结构，包括字典类型和字典数据两个层次，为系统提供统一的基础数据管理能力，是整个系统数据一致性的保障。

### 1.2 核心价值

| 价值维度 | 具体内容 |
|---------|---------|
| **统一管理** | 提供系统基础数据的统一管理入口，避免代码硬编码 |
| **动态调整** | 支持运行时动态调整字典数据，无需修改代码 |
| **两级分类** | 采用字典类型+字典数据两级结构，便于分类管理 |
| **状态控制** | 支持字典数据的启用/禁用状态控制，灵活控制数据可用性 |
| **全局共享** | 提供标准化的字典数据接口，供所有业务模块使用 |

### 1.3 业务目标

#### 功能目标
- 实现字典类型的统一管理（CRUD操作）
- 实现字典数据的统一管理（CRUD操作）
- 提供字典数据下拉选项接口，供其他模块调用
- 确保字典数据的唯一性和一致性

#### 性能目标
| 指标 | 目标值 | 说明 |
|------|--------|------|
| **字典类型列表响应** | &lt;500ms | 字典类型分页查询响应时间 |
| **字典数据列表响应** | &lt;500ms | 字典数据分页查询响应时间 |
| **字典下拉选项响应** | &lt;200ms | 字典下拉选项查询响应时间 |
| **字典类型容量** | ≥1000 | 系统支持的最大字典类型数量 |
| **字典数据容量** | ≥10000 | 系统支持的最大字典数据数量 |

## 3. 功能需求

### 3.1 字典类型列表查询 (F-DM-001)

#### 3.1.1 功能描述

提供字典类型的分页展示和筛选能力，支持管理员快速查找目标字典类型。

#### 3.1.2 查询条件

| 条件类型 | 字段 | 说明 | 匹配方式 |
|---------|------|------|---------|
| **关键字搜索** | 名称/编码 | 多字段模糊匹配 | LIKE |

#### 3.1.3 列表展示字段

| 字段 | 显示名称 | 说明 |
|------|---------|------|
| id | 编号 | 字典类型唯一标识 |
| name | 类型名称 | 字典类型显示名称 |
| code | 类型编码 | 字典类型编码，全局唯一 |
| status | 状态 | 启用/禁用 |
| remark | 备注 | 备注信息 |
| createTime | 创建时间 | 创建时间 |
| - | 操作 | 字典数据/编辑/删除 |

#### 3.1.4 分页配置

| 配置项 | 默认值 | 可选值 |
|--------|--------|--------|
| 每页条数 | 10 | 10/20/50/100 |

### 3.2 字典类型新增 (F-DM-002)

#### 3.2.1 功能描述

支持创建新的字典类型，用于分类管理字典数据。

#### 3.2.2 表单字段

| 字段 | 显示名称 | 类型 | 必填 | 校验规则 |
|------|---------|------|------|---------|
| name | 类型名称 | 输入框 | ✅ | 不能为空 |
| code | 类型编码 | 输入框 | ✅ | 不能为空，系统唯一 |
| status | 状态 | 单选框组 | ✅ | 默认启用(1) |
| remark | 备注 | 文本域 | ❌ | 最多255字符 |

#### 3.2.3 业务规则

1. **编码唯一性**：字典类型编码在系统中必须唯一，创建时需校验
2. **状态默认值**：新增字典类型默认状态为启用

### 3.3 字典类型编辑 (F-DM-003)

#### 3.3.1 功能描述

支持修改现有字典类型的基本信息和状态。

#### 3.3.2 可编辑字段

| 字段 | 是否可编辑 | 说明 |
|------|-----------|------|
| name | ✅ | 可随时修改 |
| code | ✅ | 可修改，需校验唯一性 |
| status | ✅ | 可启用/禁用 |
| remark | ✅ | 可修改 |

#### 3.3.3 业务规则

1. **编码变更**：字典类型编码修改后，对应的字典数据需同步更新
2. **即时生效**：修改保存后立即生效

### 3.4 字典类型删除 (F-DM-004)

#### 3.4.1 功能描述

支持删除字典类型，包括单个删除和批量删除。

#### 3.4.2 删除方式

| 方式 | 触发操作 | 说明 |
|------|---------|------|
| **单个删除** | 点击操作列删除按钮 | 删除单个字典类型 |
| **批量删除** | 勾选多个后点击批量删除 | 删除选中的所有字典类型 |

#### 3.4.3 业务规则

1. **二次确认**：删除操作需弹窗确认
2. **关联检查**：删除前检查是否存在关联的字典数据
3. **禁止删除**：存在关联字典数据的字典类型禁止删除
4. **物理删除**：执行物理删除，数据不可恢复

#### 3.4.4 确认提示

- 单个删除："确认删除字典类型「{name}」吗？"
- 批量删除："确认删除选中的 {count} 个字典类型吗？"
- 关联数据提示："该字典类型下存在字典数据，无法删除！"

### 3.5 字典数据列表查询 (F-DM-005)

#### 3.5.1 功能描述

提供字典数据的分页展示，按字典类型进行筛选和管理。

#### 3.5.2 查询条件

| 条件类型 | 字段 | 说明 | 匹配方式 |
|---------|------|------|---------|
| **类型编码** | typeCode | 从字典类型列表传入 | = |

#### 3.5.3 列表展示字段

| 字段 | 显示名称 | 说明 |
|------|---------|------|
| id | 编号 | 字典数据唯一标识 |
| name | 字典标签 | 字典显示文本 |
| value | 字典键值 | 字典实际值 |
| defaulted | 是否默认 | 是否默认值(1:是;0:否) |
| sort | 排序 | 排序值，升序显示 |
| status | 状态 | 启用/禁用 |
| remark | 备注 | 备注信息 |
| createTime | 创建时间 | 创建时间 |
| - | 操作 | 编辑/删除 |

#### 3.5.4 排序规则

默认按 `sort` 字段升序排序，相同 `sort` 值按创建时间降序排序。

### 3.6 字典数据新增 (F-DM-006)

#### 3.6.1 功能描述

支持在指定字典类型下创建新的字典数据。

#### 3.6.2 表单字段

| 字段 | 显示名称 | 类型 | 必填 | 校验规则 |
|------|---------|------|------|---------|
| typeCode | 类型编码 | 只读输入框 | ✅ | 从字典类型列表传入 |
| name | 字典标签 | 输入框 | ✅ | 不能为空 |
| value | 字典键值 | 输入框 | ✅ | 不能为空，同一类型下唯一 |
| defaulted | 是否默认 | 单选框组 | ❌ | 默认否(0) |
| sort | 排序 | 数字输入框 | ✅ | 默认1，正整数 |
| status | 状态 | 单选框组 | ✅ | 默认启用(1) |
| remark | 备注 | 文本域 | ❌ | 最多255字符 |

#### 3.6.3 业务规则

1. **值唯一性**：字典值在同一字典类型下必须唯一，创建时需校验
2. **类型关联**：必须关联到某个字典类型
3. **排序默认值**：新增字典数据默认排序为1

### 3.7 字典数据编辑 (F-DM-007)

#### 3.7.1 功能描述

支持修改现有字典数据的基本信息、排序和状态。

#### 3.7.2 可编辑字段

| 字段 | 是否可编辑 | 说明 |
|------|-----------|------|
| typeCode | ❌ | 字典类型不可修改 |
| name | ✅ | 可修改 |
| value | ✅ | 可修改，需校验唯一性 |
| defaulted | ✅ | 可修改 |
| sort | ✅ | 可修改，影响显示顺序 |
| status | ✅ | 可启用/禁用 |
| remark | ✅ | 可修改 |

#### 3.7.3 业务规则

1. **类型只读**：字典类型一旦关联不可修改
2. **即时生效**：修改保存后立即生效
3. **排序生效**：排序值修改后立即影响列表显示顺序

### 3.8 字典数据删除 (F-DM-008)

#### 3.8.1 功能描述

支持删除字典数据，包括单个删除和批量删除。

#### 3.8.2 删除方式

| 方式 | 触发操作 | 说明 |
|------|---------|------|
| **单个删除** | 点击操作列删除按钮 | 删除单个字典数据 |
| **批量删除** | 勾选多个后点击批量删除 | 删除选中的所有字典数据 |

#### 3.8.3 业务规则

1. **二次确认**：删除操作需弹窗确认
2. **物理删除**：执行物理删除，数据不可恢复

#### 3.8.4 确认提示

- 单个删除："确认删除字典数据「{name}」吗？"
- 批量删除："确认删除选中的 {count} 个字典数据吗？"

### 3.9 字典下拉选项查询 (F-DM-009)

#### 3.9.1 功能描述

提供字典数据下拉选项接口，供其他业务模块使用。

#### 3.9.2 接口输入

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| typeCode | String | ✅ | 字典类型编码 |

#### 3.9.3 接口输出

| 字段 | 类型 | 说明 |
|------|------|------|
| label | String | 显示标签，对应 name 字段 |
| value | String | 实际值，对应 value 字段 |

#### 3.9.4 业务规则

1. **排序返回**：按 sort 字段升序返回
2. **缓存策略**：字典下拉选项数据可缓存，减少数据库查询

## 4. 界面交互规范

### 4.1 页面布局

字典管理页面采用**单页双列表格布局**，主页面展示字典类型列表，字典数据通过弹窗进行管理。

### 4.2 交互规则

#### 4.2.1 搜索交互

| 触发方式 | 行为 |
|---------|------|
| 点击搜索按钮 | 执行搜索，重置到第一页 |
| 按 Enter 键 | 执行搜索，重置到第一页 |
| 点击重置按钮 | 清空条件，执行搜索 |

#### 4.2.2 表单交互

| 场景 | 行为 |
|------|------|
| 打开新增表单 | 清空表单数据，状态默认启用 |
| 打开编辑表单 | 加载详情，填充表单数据 |
| 字典数据新增 | 自动填充类型编码（只读） |
| 实时校验 | 输入时触发校验，显示错误提示 |
| 提交表单 | 校验通过后提交，成功后关闭并刷新列表 |

#### 4.2.3 删除交互

- **单个删除确认**：`确认删除字典类型「{name}」吗？`
- **批量删除确认**：`确认删除选中的 {count} 个字典类型吗？`
- **关联数据提示**：`该字典类型下存在字典数据，无法删除！`

### 4.3 状态反馈

| 状态 | 显示 |
|------|------|
| 加载中 | 显示加载动画 |
| 空数据 | 显示"暂无数据"提示 |
| 加载失败 | 显示错误提示，提供重试按钮 |
| 批量删除按钮 | 无选中项时禁用 |

### 5.2 数据安全

| 安全措施 | 说明 |
|---------|------|
| **数据校验** | 编码唯一性校验、字典值唯一性校验 |

| **防重复提交** | 使用防抖机制防止重复提交 |
| **操作日志** | 记录关键操作日志（待实现） |

### 5.3 输入校验

| 校验类型 | 说明 |
|---------|------|
| **前端校验** | 表单实时校验，提升用户体验 |
| **后端校验** | 使用Validation注解进行参数校验 |
| **格式校验** | 编码格式、排序字段正整数校验 |
| **长度校验** | 字段最大长度限制 |
