# 菜单管理模块 - 前端实现设计

## 1. 文档概述

本文档描述菜单管理模块的前端实现方案，聚焦组件架构、状态管理、路由动态生成、表单校验等架构决策。

## 2. 组件架构设计

### 2.1 组件层次结构

```
菜单管理页面 (MenuManagement/index.vue)
├── 搜索容器
│   ├── 搜索表单 (SearchForm)
│   │   ├── 菜单名称输入框
│   │   ├── 搜索按钮
│   │   └── 重置按钮
│   └── 操作按钮区域 (ActionButtons)
│       └── 新增按钮
└── 数据展示区域
    └── 菜单表格 (MenuTable)
        ├── 树形表格结构
        └── 操作列按钮
```

### 2.2 弹窗组件结构

```
弹窗组件 (MenuDialog)
└── 菜单表单弹窗 (MenuFormDialog)
    ├── 菜单类型选择器
    ├── 上级菜单树形选择器
    ├── 菜单名称输入框
    ├── 路由地址输入框（条件显示）
    ├── 组件路径输入框（条件显示）
    ├── 权限标识输入框（条件显示）
    ├── 图标选择器（条件显示）
    ├── 路由重定向输入框（条件显示）
    ├── 显示状态单选框
    └── 菜单排序输入框
```

### 2.3 组件职责划分

| 组件名称 | 职责描述 | 复用性 |
|---------|---------|--------|
| **SearchForm** | 菜单搜索条件输入与提交 | 页面内部组件 |
| **ActionButtons** | 操作按钮区域，统一管理权限控制 | 页面内部组件 |
| **MenuTable** | 菜单数据树形表格展示与行操作 | 页面内部组件 |
| **MenuFormDialog** | 菜单新增/编辑表单弹窗 | 页面内部组件 |

## 3. 页面布局设计

### 3.1 整体布局

菜单管理页面采用**单栏布局**：

| 区域 | 高度 | 说明 |

## 6. API 调用设计

### 6.1 API 接口封装

使用 `dehaze-sdk-js` 提供的 MenuAPI 进行接口调用：

| 方法 | 功能 | 参数 |
|------|------|------|
| MenuAPI.getList | 获取菜单列表（树形结构） | queryParams |
| MenuAPI.getOptions | 获取菜单下拉选项（上级菜单） | - |
| MenuAPI.getRoutes | 获取路由列表（前端动态路由） | - |
| MenuAPI.getFormData | 获取菜单表单数据 | menuId |
| MenuAPI.add | 新增菜单 | formData |
| MenuAPI.update | 修改菜单 | menuId, formData |
| MenuAPI.deleteByIds | 删除菜单（支持批量） | ids（英文逗号分割的ID字符串） |
| MenuAPI.updateVisible | 修改菜单显示状态 | menuId, visible |

### 6.2 请求错误处理

全局拦截器统一处理 API 请求错误，前端只需关注错误展示。

| 错误类型 | 处理方式 |
|---------|---------|
| 网络错误 | 提示"网络连接失败，请检查网络" |
| 401 未授权 | 跳转登录页 |
| 403 无权限 | 提示"无操作权限" |
| 业务错误 | 提示后端返回的错误信息 |
| 服务器错误 | 提示"服务器异常，请稍后重试" |

## 7. 交互流程设计

### 7.1 页面初始化流程

1. 进入页面，显示加载状态
2. 并行请求菜单列表和下拉选项数据
3. 数据加载完成，默认展开第一级菜单

### 7.2 关键流程说明

| 流程 | 关键点 |
|------|--------|
| 菜单新增 | 初始化默认值（type=目录，visible=显示，sort=1）→ 类型切换动态显示字段 → 提交 → 刷新列表 → 清除路由缓存 |
| 菜单编辑 | 加载详情 → 类型切换动态显示字段 → 提交 → 刷新列表 → 清除路由缓存 |
| 菜单删除 | 确认对话框 → 子菜单检查 → 删除 → 刷新列表 → 清除路由缓存 |
| 菜单批量删除 | 勾选多行 → 点击删除按钮 → 确认对话框 → 批量删除（逗号分割ID）→ 刷新列表 → 清除路由缓存 |
| 显示状态切换 | 确认对话框 → 调用状态修改接口 → 更新表格 → 清除路由缓存 |

## 8. 表单校验设计

### 8.1 基础校验规则

| 字段 | 校验规则 | 触发时机 | 错误提示 |
|------|---------|---------|---------|
| name | 必填，长度 2-64 字符 | blur | 菜单名称不能为空 / 菜单名称长度应在 2-64 字符之间 |
| type | 必填 | change | 菜单类型不能为空 |
| sort | 必填 + 数字 | blur | 排序不能为空 / 排序必须为数字 |
| parentId | - | - | - |

### 8.2 条件校验规则（根据菜单类型动态）

根据 `formData.type` 的值动态添加校验规则：

#### type = 1（目录）

| 字段 | 校验规则 | 触发时机 | 错误提示 |
|------|---------|---------|---------|
| path | - | - | - |
| component | - | - | - |
| perm | - | - | - |
| icon | - | - | - |
| redirect | - | - | - |

#### type = 2（菜单）

| 字段 | 校验规则 | 触发时机 | 错误提示 |
|------|---------|---------|---------|
| path | 必填，以 `/` 开头 | blur | 路由地址不能为空 / 路由地址必须以 / 开头 |
| component | 必填 | blur | 组件路径不能为空 |
| perm | - | - | - |
| icon | - | - | - |
| redirect | - | - | - |

#### type = 3（按钮）

| 字段 | 校验规则 | 触发时机 | 错误提示 |
|------|---------|---------|---------|
| path | - | - | - |
| component | - | - | - |
| perm | 必填，格式 `模块:功能:操作` | blur | 权限标识不能为空 / 权限标识格式不正确 |
| icon | - | - | - |
| redirect | - | - | - |

#### type = 4（外链）

| 字段 | 校验规则 | 触发时机 | 错误提示 |
|------|---------|---------|---------|
| path | 必填，URL 格式校验 | blur | 外链地址不能为空 / 请输入正确的外链地址 |
| component | - | - | - |
| perm | - | - | - |
| icon | - | - | - |
| redirect | - | - | - |

### 8.3 格式校验规则

| 字段 | 正则表达式 | 说明 |
|------|-----------|------|
| perm（按钮类型） | `/^[a-z]+:[a-z]+:[a-z]+$/` | 格式：模块:功能:操作（如 sys:menu:add） |
| path（菜单类型） | `/^\/[a-zA-Z0-9\-_/]*$/` | 路由地址，以 / 开头 |
| path（外链类型） | `/^https?:\/\/.+/` | http 或 https 开头的完整 URL |

### 8.4 业务校验规则

| 字段 | 校验规则 | 说明 |
|------|---------|------|
| name | 唯一性校验（同一层级下） | 同一父菜单下，菜单名称不能重复 |
| perm | 唯一性校验（全局） | 权限标识在系统中必须唯一 |

**校验时机**：提交时由后端进行唯一性校验，前端显示后端返回的错误信息

| 按钮 | 权限标识 | 无权限时 |

## 10. 路由动态生成

### 10.1 路由生成时机

- 用户登录成功后
- 菜单权限变更后
- 角色权限分配后

### 10.2 路由生成流程

1. 调用 `MenuAPI.getRoutes()` 获取路由列表
2. 根据返回的路由数据动态注册路由
3. 过滤隐藏菜单（visible=0）
4. 递归处理子路由
5. 更新全局状态中的路由配置
6. 触发侧边栏菜单刷新

### 10.3 路由对象结构

| 字段 | 说明 |
|------|------|
| path | 路由路径 |
| component | 组件路径 |
| redirect | 路由重定向 |
| name | 路由名称（驼峰命名） |
| meta.title | 路由标题 |
| meta.icon | 图标 |
| meta.hidden | 是否隐藏 |
| meta.roles | 角色权限列表 |
| meta.keepAlive | 页面缓存 |
| meta.alwaysShow | 始终显示（目录） |
| children | 子路由列表 |

### 10.4 路由缓存清除

以下操作需要清除路由缓存，触发重新生成：

- 菜单新增
- 菜单编辑
- 菜单删除
- 菜单显示状态切换
- 角色权限分配

## 11. 性能优化设计

### 11.1 请求优化

| 优化项 | 实现方式 |
|--------|---------|
| 防抖处理 | 搜索输入防抖 300ms |
| 节流处理 | 提交按钮节流 3000ms |
| 并行请求 | 页面初始化时并行加载菜单列表和下拉选项 |
| 请求缓存 | 菜单下拉选项数据缓存 |

### 11.2 渲染优化

| 优化项 | 实现方式 |
|--------|---------|
| 虚拟滚动 | 大数据量树形表格使用虚拟滚动 |
| 懒加载 | 树形节点懒加载（可选） |
| 骨架屏 | 数据加载时显示骨架屏 |
| 按需渲染 | 仅渲染可见的表格行 |

### 11.3 缓存策略

| 数据类型 | 缓存位置 | 过期策略 |
|---------|---------|---------|
| 菜单列表数据 | 组件状态 | 页面卸载时清除 |
| 菜单下拉选项 | 组件状态 | 页面卸载时清除 |
| 路由配置 | 全局 Store | 菜单变更时清除 |

### 11.4 树形结构优化

- 限制菜单层级深度 ≤ 5 层
- 使用 key 属性优化树形节点渲染
- 展开状态使用受控模式，避免不必要的重新渲染
- 图标使用懒加载方式引入

## 13. 关键实现要点

### 13.1 菜单树构建

**实现思路**：
1. 后端返回树形结构数据（递归结构）
2. 前端直接使用，无需再次构建
3. 使用 Element Plus Table 的树形结构功能
4. 配置 row-key 和 tree-props 属性

**性能优化要点**：
- 使用 row-key 属性优化渲染性能
- 避免在表格单元格中使用复杂计算
- 使用 virtual-scroller 处理大数据量

### 13.2 动态表单字段

根据菜单类型（type）动态控制表单字段的显示/隐藏，类型切换时重置条件字段的值：

| 菜单类型 | 显示字段 |
|---------|---------|
| 目录(type=1) | 图标、路由重定向 |
| 菜单(type=2) | 路由地址、组件路径、图标 |
| 按钮(type=3) | 权限标识 |
| 外链(type=4) | 路由地址 |

### 13.3 条件校验规则

根据菜单类型动态生成校验规则，类型切换时触发表单重新校验。校验规则与显示字段保持一致（详见第8节）。

### 13.4 图标选择器

使用图标组件库，支持搜索和动态渲染。图标名称映射 `el-icon-xxx` 至对应组件名，点击选择后回显图标。

### 13.5 上级菜单选择器

使用 Cascader 或 TreeSelect 组件展示树形结构，过滤按钮和外链类型，支持顶级菜单选择。

### 13.6 路由缓存清除

菜单变更时通过全局 Store（Pinia）清除路由缓存，触发路由守卫重新生成路由。需要清除缓存的场景：菜单新增、编辑、删除、显示状态切换、角色权限分配。
