# 菜单管理模块需求规格

## 1. 模块概述

### 1.1 模块定位

菜单管理模块是图像去雾系统后台管理系统的核心基础模块之一,负责维护系统的导航菜单结构。该模块提供了完整的菜单增删改查功能,支持多级菜单结构、菜单类型分类、菜单显示控制以及权限标识配置等功能,是系统权限控制和用户导航的基础支撑。

### 1.2 核心价值

| 价值维度 | 具体内容 |
|---------|---------|
| **统一管理** | 提供系统菜单的统一管理入口,实现菜单全生命周期管理 |
| **权限控制** | 基于RBAC模型实现基于角色的菜单访问控制 |
| **灵活配置** | 支持多级菜单结构、多种菜单类型和灵活的显示控制 |
| **路由生成** | 为前端动态生成路由和导航结构 |
| **安全防护** | 保障系统安全性和用户体验的一致性 |

### 1.3 业务目标

#### 功能目标
- 实现系统菜单的统一管理(CRUD操作)
- 支持多级菜单结构(最多5级)
- 提供完善的菜单权限控制体系
- 支持菜单与角色权限的关联管理
- 为前端动态生成路由配置

#### 性能目标
| 指标 | 目标值 | 说明 |
|------|--------|------|
| **列表查询响应** | &lt;500ms | 菜单列表查询响应时间 |
| **表单提交响应** | &lt;1s | 新增/编辑菜单操作响应时间 |
| **菜单容量** | ≥1000 | 系统支持的最大菜单数量 |
| **树形渲染** | &lt;300ms | 菜单树形结构渲染时间 |

### 1.4 模块依赖关系

#### 依赖模块
| 模块 | 依赖说明 |
|------|---------|
| **角色管理模块** | 菜单需要与角色权限进行关联,实现基于角色的菜单访问控制 |
| **部门管理模块** | 部分场景下,菜单权限可能与部门数据权限关联 |

#### 被依赖模块
| 模块 | 依赖说明 |
|------|---------|
| **系统所有业务模块** | 依赖菜单管理模块提供导航结构和路由配置 |
| **前端路由系统** | 依赖菜单配置动态生成路由信息 |
| **权限控制模块** | 依赖菜单权限标识进行接口和页面级别的权限控制 |

## 3. 功能需求

### 3.1 菜单列表查询 (F-MM-001)

#### 3.1.1 功能描述

提供菜单信息的树形展示和关键字筛选能力,支持管理员快速定位目标菜单。

#### 3.1.2 查询条件

| 条件类型 | 字段 | 说明 | 匹配方式 |
|---------|------|------|---------|
| **关键字搜索** | 菜单名称 | 模糊匹配菜单名称 | LIKE |

#### 3.1.3 列表展示字段

| 字段 | 显示名称 | 宽度 | 说明 |
|------|---------|------|------|
| name | 菜单名称 | 200px | 树形结构展示,支持展开/收起 |
| icon | 图标 | 80px | 居中显示图标 |
| type | 类型 | 100px | 目录/菜单/按钮/外链 |
| path | 路由地址 | 150px | 前端路由路径 |
| perm | 权限标识 | 150px | 权限标识符 |
| visible | 显示状态 | 100px | 显示/隐藏标签 |
| sort | 排序 | 100px | 数字排序 |
| - | 操作 | 220px | 编辑/删除按钮 |

#### 3.1.4 展示方式

- **树形结构展示**:菜单以树形结构展示,支持最多5级深度
- **展开/收起**:支持节点的展开和收起操作
- **图标展示**:目录和菜单类型显示图标
- **状态标签**:显示状态使用标签形式展示(显示-绿色/隐藏-灰色)

### 3.2 菜单新增 (F-MM-002)

#### 3.2.1 功能描述

支持创建新菜单项,包括基本信息设置、上级菜单选择、菜单类型配置等。

#### 3.2.2 表单字段

| 字段 | 显示名称 | 类型 | 必填 | 校验规则 | 条件显示 |
|------|---------|------|------|---------|---------|
| type | 菜单类型 | 单选框组 | ✅ | 不能为空 | 始终显示 |
| parentId | 上级菜单 | 树形选择器 | ❌ | - | 始终显示 |
| name | 菜单名称 | 输入框 | ✅ | 不能为空 | 始终显示 |
| path | 路由地址 | 输入框 | ❌ | - | 菜单类型为"菜单"时必填 |
| component | 组件路径 | 输入框 | ❌ | - | 菜单类型为"菜单"时必填 |
| perm | 权限标识 | 输入框 | ❌ | 系统内唯一 | 菜单类型为"按钮"时必填 |
| icon | 菜单图标 | 图标选择器 | ❌ | - | 菜单类型为"目录"或"菜单"时显示 |
| redirect | 路由重定向 | 输入框 | ❌ | - | 菜单类型为"目录"时显示 |
| visible | 显示状态 | 单选框组 | ✅ | - | 始终显示(默认为显示) |
| sort | 菜单排序 | 数字输入框 | ✅ | 必须为数字 | 始终显示(默认为1) |

#### 3.2.3 菜单类型说明

| 类型值 | 类型名称 | 说明 | 典型用途 |
|-------|---------|------|---------|
| 1 | 目录 | 用于组织菜单结构,本身不对应具体页面 | 系统管理、数据管理等一级分类 |
| 2 | 菜单 | 对应具体的页面功能,可配置路由和组件 | 用户管理、角色管理等功能页 |
| 3 | 外链 | 外部链接,跳转到外部系统或文档 | 官方文档、外部帮助等 |
| 4 | 按钮 | 页面内的操作按钮,配置权限标识供前端权限控制使用 | 新增、编辑、删除等按钮权限 |

#### 3.2.4 业务规则

1. **菜单名称唯一性**:同一层级下菜单名称必须唯一
2. **权限标识唯一性**:权限标识符在系统中必须唯一
3. **上级菜单选择**:上级菜单可以是目录或菜单类型,不能选择按钮或外链
4. **路由地址**:菜单类型为"菜单"时必须配置路由地址
5. **组件路径**:菜单类型为"菜单"时必须配置组件路径
6. **权限标识**:菜单类型为"按钮"时必须配置权限标识
7. **外链地址**:菜单类型为"外链"时路由地址必须为完整的URL
8. **默认状态**:新增菜单默认为显示状态,排序默认为1

### 3.3 菜单编辑 (F-MM-003)

#### 3.3.1 功能描述

支持修改现有菜单的各项属性,包括菜单类型、上级菜单、路由配置等。

#### 3.3.2 可编辑字段

所有新增表单中的字段均可编辑,需遵循相同的业务规则。

#### 3.3.3 业务规则

1. **即时生效**:修改保存后立即生效
2. **权限变更**:权限标识变更后,角色关联的权限立即更新
3. **类型变更**:菜单类型变更时,需校验必填字段
4. **上级变更**:上级菜单变更时,需校验层级关系,避免循环引用

### 3.4 菜单删除 (F-MM-004)

#### 3.4.1 功能描述

支持删除单个菜单项。

#### 3.4.2 操作流程

点击删除按钮 → 弹出确认对话框 → 用户确认删除 → 检查关联数据 → 执行删除 → 刷新菜单树 → 显示成功提示

#### 3.4.3 业务规则

1. **二次确认**:删除操作需弹出确认对话框
2. **子菜单检查**:删除前需检查是否存在子菜单,存在子菜单则不允许删除
3. **角色关联处理**:删除菜单时,同步删除角色菜单关联表中的相关记录
4. **删除提示**:子菜单存在时提示"存在子菜单,无法删除"
5. **物理删除**:执行物理删除,数据不可恢复

#### 3.4.4 确认提示

- 单个删除:"确认删除菜单「{name}」吗？删除后不可恢复。"
- 存在子菜单:"该菜单存在子菜单,无法删除。"

### 3.5 菜单显示控制 (F-MM-005)

#### 3.5.1 功能描述

支持控制菜单的显示/隐藏状态,用于功能灰度发布或临时隐藏。

#### 3.5.2 状态说明

| 状态值 | 显示 | 说明 |
|--------|------|------|
| 1 | 显示(绿色标签) | 菜单在系统中正常显示 |
| 0 | 隐藏(灰色标签) | 菜单在系统中不显示 |

#### 3.5.3 业务规则

1. **状态切换**:可通过状态标签或编辑表单切换状态
2. **即时生效**:状态变更后立即生效
3. **子菜单继承**:隐藏上级菜单时,其子菜单也一并隐藏(待确认)
4. **权限保留**:隐藏状态的菜单权限仍生效,仅前端不显示

### 3.6 菜单排序 (F-MM-006)

#### 3.6.1 功能描述

支持设置菜单的显示顺序,通过排序字段控制菜单在树形结构中的位置。

#### 3.6.2 业务规则

1. **数字排序**:排序字段为整数类型,数字越小越靠前
2. **同级排序**:排序仅在同级菜单间生效
3. **默认值**:新增菜单排序默认为1
4. **实时生效**:排序变更后立即生效

### 3.7 菜单下拉选项 (F-MM-007)

#### 3.7.1 功能描述

为其他模块提供菜单下拉选项,用于选择上级菜单等场景。

#### 3.7.2 数据要求

- 以树形结构展示菜单选项
- 支持多级展开和选择
- 过滤掉按钮类型菜单(按钮类型不可作为上级菜单)

### 3.8 路由列表生成 (F-MM-008)

#### 3.8.1 功能描述

根据菜单配置生成前端路由列表,供前端动态路由使用。

#### 3.8.2 生成规则

1. **过滤条件**:仅生成类型为"目录"和"菜单"且显示状态为"显示"的菜单
2. **权限过滤**:根据用户角色权限过滤可见菜单
3. **路由配置**:生成包含路由路径、组件路径、图标、重定向等信息的路由对象
4. **树形结构**:保持菜单的层级关系

## 4. 界面交互规范

### 4.1 页面布局

菜单管理页面采用**单栏布局**，包含搜索条件区域、操作按钮区域和菜单树形数据表格。

### 4.2 交互规则

> 通用 UI 交互规范参见 [01-产品设计/02-UI-UX设计规范.md](../../../01-产品设计/02-UI-UX设计规范.md)

#### 4.2.1 本模块特有交互

| 场景 | 行为 |
|------|------|
| 打开新增表单 | 清空表单数据，默认值：type=目录，visible=显示，sort=1，parentId=0 |
| 打开编辑表单 | 加载菜单详情 |
| 菜单类型切换 | 根据类型动态显示/隐藏相关字段（详见 3.2.2 节条件显示） |
| 树形结构 | 默认展开第一级菜单，支持展开/收起操作 |

#### 4.2.2 确认提示文案

- 删除确认：`确认删除菜单「{name}」吗？删除后不可恢复。`
- 存在子菜单：`该菜单存在子菜单，无法删除。`

## 5. 安全设计

> **权限标识**：详见 [API接口.md - 权限标识汇总](./API接口.md)

### 5.1 数据安全

| 安全措施 | 说明 |
|---------|------|
| 数据权限 | 用户只能查看和操作其权限范围内的菜单数据 |
| 传输加密 | HTTPS加密传输 |
| 防重复提交 | 使用Token机制防止重复提交 |
| 操作日志 | 记录菜单增删改等关键操作日志 |

### 5.2 输入校验

| 校验类型 | 说明 |
|---------|------|
| 前端校验 | 表单实时校验 |
| 后端校验 | 参数校验 + 业务校验（名称唯一性、权限标识唯一性） |
| 格式校验 | 路由地址、权限标识等字段格式校验 |

## 6. 待确认事项

1. **菜单拖拽排序**:当前菜单管理界面未实现菜单拖拽排序功能,是否需要补充实现?
2. **菜单导入导出**:是否需要增加菜单导入/导出功能,以便快速初始化系统菜单或在不同环境间同步菜单配置?
3. **批量删除**:菜单删除操作是否需要支持批量删除多个菜单项?
4. **子菜单隐藏规则**:隐藏上级菜单时,其子菜单是否也应该一并隐藏?
5. **菜单图标选择**:菜单图标选择器目前依赖第三方图标库,是否需要支持自定义图标上传?
6. **菜单深度限制**:当前限制菜单最多5级深度,是否需要调整此限制?
7. **菜单回收站**:删除的菜单是否需要进入回收站,支持恢复操作?
8. **菜单版本管理**:是否需要支持菜单配置的版本管理和回滚功能?
9. **菜单预览**:是否需要增加菜单预览功能,查看菜单在系统中的实际显示效果?
10. **国际化支持**:菜单名称等字段是否需要支持多语言,实现国际化?
