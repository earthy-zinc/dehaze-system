# 菜单管理模块需求规格

## 1. 模块概述

### 1.1 模块定位

菜单管理模块是 **AI 图像处理平台**（远期演进为「AI 工作平台」）的核心基础模块之一，负责维护系统的导航菜单结构。该模块提供完整的菜单增删改查功能，支持多级菜单结构、菜单类型分类、菜单显示控制以及权限标识配置，是系统权限控制和多端用户导航的基础支撑。平台支持去雾/去雨/去雪/低光增强/超分辨率/去噪/图像修复等多任务图像处理，多端覆盖（Web Vue/React、Android、Flutter、Taro/UniApp 小程序、Electron 桌面端），菜单配置需为各端动态生成导航与路由。

> **三后端契约**：Java/Go/Python 三后端 API 契约完全一致，Java 为权威来源，Go/Python 对齐。

### 1.2 核心价值

| 价值维度 | 具体内容 |
|---------|---------|
| **统一管理** | 提供系统菜单的统一管理入口，实现菜单全生命周期管理 |
| **权限控制** | 基于 RBAC 模型实现基于角色的菜单可见性与接口级权限控制 |
| **灵活配置** | 支持多级菜单结构、多种菜单类型和灵活的显示控制 |
| **多端路由生成** | 为 Web、移动端、小程序、桌面端动态生成适配各端的路由与导航结构 |
| **安全防护** | 逻辑删除保留历史可追溯，操作审计保障系统安全性 |

### 1.3 业务目标

#### 功能目标
- 实现系统菜单的统一管理（CRUD 操作）
- 支持多级菜单结构（最多 5 级）
- 提供完善的菜单权限控制体系（接口级权限，权限标识格式 `模块:功能:操作`）
- 支持菜单与角色权限的关联管理
- 为多端动态生成路由配置

#### 性能目标
| 指标 | 目标值 | 说明 |
|------|--------|------|
| **列表查询响应** | &lt;500ms | 菜单列表查询响应时间 |
| **表单提交响应** | &lt;1s | 新增/编辑菜单操作响应时间 |
| **菜单容量** | ≥1000 | 系统支持的最大菜单数量 |
| **树形渲染** | &lt;300ms | 菜单树形结构渲染时间 |

**前端性能策略**：菜单数据量较大（≥500 节点）时，前端采用虚拟滚动与懒加载策略——首次仅渲染可见层级与可视区域节点，子节点展开时按需加载，避免一次性渲染全量树导致卡顿。

### 1.4 模块依赖关系

#### 依赖模块
| 模块 | 依赖说明 |
|------|---------|
| **角色管理模块** | 菜单需与角色权限关联，实现基于角色的菜单访问控制 |

#### 被依赖模块
| 模块 | 依赖说明 |
|------|---------|
| **系统所有业务模块** | 依赖菜单管理模块提供导航结构和路由配置 |
| **前端路由系统** | 依赖菜单配置动态生成各端路由信息 |
| **权限控制模块** | 依赖菜单权限标识进行接口级权限控制 |

## 2. 用户角色分析

### 2.1 主要用户角色

| 角色 | 描述 | 主要职责 |
|------|------|---------|
| **系统管理员** | 拥有菜单管理模块的所有操作权限（`sys:menu:add/edit/delete`） | 菜单增删改查、权限配置、显示控制、路由配置 |

> 菜单为系统级配置数据，仅系统管理员可维护。API 仅提供接口级权限控制（`sys:menu:add/edit/delete`），不实现字段级权限。普通用户通过登录后获取路由列表间接消费菜单配置，无管理权限。

| 角色 | 特征描述 | 核心需求 |

### 2.3 权限矩阵

| 功能点 | 系统管理员 | 普通用户（经路由接口间接消费） |

| 搜索/筛选菜单 | ✅ | ❌ |

| 配置权限标识 | ✅ | ❌ |
| 配置路由信息 | ✅ | ❌ |

## 3. 功能需求

### 3.1 菜单列表查询 (F-MM-001)

#### 3.1.1 功能描述

提供菜单信息的树形展示和多条件筛选能力，支持管理员快速定位目标菜单。

#### 3.1.2 查询条件

| 条件类型 | 字段 | 说明 | 匹配方式 |
|---------|------|------|---------|
| **关键字搜索** | 菜单名称（name） | 模糊匹配菜单名称 | LIKE |
| **权限标识** | 权限标识（perm） | 模糊匹配权限标识符 | LIKE |
| **路由地址** | 路由地址（path） | 模糊匹配路由路径 | LIKE |
| **菜单类型** | 菜单类型（type） | 精确匹配：目录/菜单/外链/按钮 | = |
| **显示状态** | 显示状态（visible） | 精确匹配：显示/隐藏 | = |

#### 3.1.3 列表展示字段

| 字段 | 显示名称 | 宽度 | 说明 |
|------|---------|------|------|
| name | 菜单名称 | 200px | 树形结构展示，支持展开/收起 |
| icon | 图标 | 80px | 居中显示图标 |
| type | 类型 | 100px | 目录/菜单/按钮/外链 |
| path | 路由地址 | 150px | 前端路由路径 |
| perm | 权限标识 | 150px | 权限标识符 |
| visible | 显示状态 | 100px | 显示/隐藏标签 |
| sort | 排序 | 100px | 数字排序 |
| - | 操作 | 220px | 编辑/删除按钮 |

#### 3.1.4 展示方式

- **树形结构展示**：菜单以树形结构展示，支持最多 5 级深度
- **展开/收起**：支持节点的展开和收起操作
- **图标展示**：目录和菜单类型显示图标
- **状态标签**：显示状态使用标签形式展示（显示-绿色/隐藏-灰色）

### 3.2 菜单新增 (F-MM-002)

#### 3.2.1 功能描述

支持创建新菜单项，包括基本信息设置、上级菜单选择、菜单类型配置等。

#### 3.2.2 表单字段

| 字段 | 显示名称 | 类型 | 必填 | 校验规则 | 条件显示 |
|------|---------|------|------|---------|---------|
| type | 菜单类型 | 单选框组 | ✅ | 不能为空 | 始终显示 |
| parentId | 上级菜单 | 树形选择器 | ❌ | - | 始终显示 |
| name | 菜单名称 | 输入框 | ✅ | 不能为空 | 始终显示 |
| path | 路由地址 | 输入框 | ❌ | - | 菜单类型为"菜单"时必填 |
| component | 组件路径 | 输入框 | ❌ | - | 菜单类型为"菜单"时必填 |
| perm | 权限标识 | 输入框 | ❌ | 系统内唯一 | 菜单类型为"按钮"时必填 |
| icon | 菜单图标 | 图标选择器 | ❌ | - | 菜单类型为"目录"或"菜单"时显示 |
| redirect | 路由重定向 | 输入框 | ❌ | - | 菜单类型为"目录"时显示 |
| visible | 显示状态 | 单选框组 | ✅ | - | 始终显示（默认为显示） |
| sort | 菜单排序 | 数字输入框 | ✅ | 必须为数字 | 始终显示（默认为 1） |

#### 3.2.3 菜单类型说明

| 类型值 | 类型名称 | 说明 | 典型用途 |
|-------|---------|------|---------|
| 1 | 目录 | 用于组织菜单结构，本身不对应具体页面 | 系统管理、数据管理等一级分类 |
| 2 | 菜单 | 对应具体的页面功能，可配置路由和组件 | 用户管理、角色管理等功能页 |
| 3 | 外链 | 外部链接，跳转到外部系统或文档 | 官方文档、外部帮助等 |
| 4 | 按钮 | 页面内的操作按钮，配置权限标识供前端权限控制使用 | 新增、编辑、删除等按钮权限 |

#### 3.2.4 业务规则

1. **菜单名称唯一性**：同一层级下菜单名称必须唯一
2. **权限标识唯一性**：权限标识符在系统中必须唯一
3. **上级菜单选择**：上级菜单可以是目录或菜单类型，不能选择按钮或外链
4. **路由地址**：菜单类型为"菜单"时必须配置路由地址
5. **组件路径**：菜单类型为"菜单"时必须配置组件路径
6. **权限标识**：菜单类型为"按钮"时必须配置权限标识
7. **外链地址**：菜单类型为"外链"时路由地址必须为完整的 URL
8. **默认状态**：新增菜单默认为显示状态，排序默认为 1

### 3.3 菜单编辑 (F-MM-003)

#### 3.3.1 功能描述

支持修改现有菜单的各项属性，包括菜单类型、上级菜单、路由配置等。

#### 3.3.2 可编辑字段

所有新增表单中的字段均可编辑，需遵循相同的业务规则。

#### 3.3.3 业务规则

1. **即时生效**：修改保存后立即生效
2. **权限变更**：权限标识变更后，角色关联的权限立即更新
3. **类型变更**：菜单类型变更时，需校验必填字段
4. **上级变更**：上级菜单变更时，需校验层级关系，避免循环引用

### 3.4 菜单删除 (F-MM-004)

#### 3.4.1 功能描述

支持删除单个或多个菜单项（批量删除），删除方式为**逻辑删除**（`deleted` 字段标记，0 未删/1 已删），数据可追溯，禁止物理删除。系统预置菜单不可删除。

#### 3.4.2 操作流程

选择菜单（单条或多条）→ 点击删除 → 弹出确认对话框 → 用户确认删除 → 级联标记删除目标菜单及其所有子孙菜单 → 清理角色菜单关联 → 刷新菜单树与缓存 → 显示成功提示

#### 3.4.3 业务规则

1. **批量删除**：支持批量删除，接口接收逗号分隔的菜单 ID 集合（`DELETE /api/v1/menus/{ids}`）
2. **二次确认**：删除操作需弹出确认对话框
3. **级联删除**：删除菜单时级联逻辑删除其所有子孙菜单（基于 treePath 匹配），子孙一并标记 `deleted=1`
4. **角色关联清理**：删除菜单时，同步删除角色菜单关联表（`sys_role_menu`）中的相关记录
5. **预置数据保护**：系统预置菜单不可删除，校验失败提示"系统预置菜单不可删除"
6. **逻辑删除**：执行逻辑删除（`deleted=1`），数据保留可追溯，不物理删除

#### 3.4.4 确认提示

- 单个删除："确认删除菜单「{name}」吗？其子菜单将一并删除。"
- 批量删除："确认删除选中的 {count} 个菜单吗？相关子菜单将一并删除。"
- 预置菜单："系统预置菜单不可删除。"

### 3.5 菜单显示控制 (F-MM-005)

#### 3.5.1 功能描述

支持控制菜单的显示/隐藏状态，用于功能灰度发布或临时隐藏。

#### 3.5.2 状态说明

| 状态值 | 显示 | 说明 |
|--------|------|------|
| 1 | 显示（绿色标签） | 菜单在系统中正常显示 |
| 0 | 隐藏（灰色标签） | 菜单在系统中不显示 |

#### 3.5.3 业务规则

1. **状态切换**：可通过状态标签或编辑表单切换状态
2. **即时生效**：状态变更后立即生效
3. **子菜单继承**：隐藏上级菜单时，其子菜单在导航中一并隐藏（前端渲染时父节点隐藏则子节点不渲染）
4. **权限保留**：隐藏状态的菜单权限仍生效，仅前端导航不显示

### 3.6 菜单排序 (F-MM-006)

#### 3.6.1 功能描述

支持设置菜单的显示顺序，通过排序字段控制菜单在树形结构中的位置。

#### 3.6.2 业务规则

1. **数字排序**：排序字段为整数类型，数字越小越靠前
2. **同级排序**：排序仅在同级菜单间生效
3. **默认值**：新增菜单排序默认为 1
4. **实时生效**：排序变更后立即生效

### 3.7 菜单下拉选项 (F-MM-007)

#### 3.7.1 功能描述

为其他模块提供菜单下拉选项，用于选择上级菜单等场景。

#### 3.7.2 数据要求

- 以树形结构展示菜单选项
- 支持多级展开和选择
- 过滤掉按钮类型菜单（按钮类型不可作为上级菜单）

### 3.8 路由列表生成 (F-MM-008)

#### 3.8.1 功能描述

根据菜单配置与用户角色权限，为各端动态生成路由列表与导航结构。

#### 3.8.2 生成规则

1. **过滤条件**：仅生成类型为"目录"和"菜单"且显示状态为"显示"的菜单
2. **权限过滤**：根据用户角色权限过滤可见菜单
3. **路由配置**：生成包含路由路径、组件路径、图标、重定向等信息的路由对象
4. **树形结构**：保持菜单的层级关系

#### 3.8.3 多端路由生成策略

后端返回统一的菜单/路由数据结构（path、component、meta 等），由各端按自身路由规范适配生成，避免后端耦合各端细节：

| 端 | 路由格式 | 生成策略 |
|----|---------|---------|
| **Web Vue** | `path` 路由（如 `/system/user`） | 前端按 path + component 注册 Vue Router 路由，component 为页面组件路径 |
| **Web React** | `path` 路由 | 前端按 path + component 注册 React Router 路由，component 为页面组件路径 |
| **桌面端（Electron）** | 同 Web React | 复用 Web React 路由生成策略 |
| **移动端（Android/Flutter）** | `page` 页面路径 | 前端按菜单配置映射为各端页面跳转路径，目录类型映射为 tab/分组 |
| **小程序（Taro/UniApp）** | `pages` 配置 | 前端按菜单配置生成 `pages` 数组与 tabBar 配置，目录类型映射为 tab |

> 后端统一返回 `path`、`component`、`name`、`meta`（title/icon/hidden/roles/keepAlive/alwaysShow）等字段；各端前端按自身规范解析并生成路由/导航。按钮类型（type=4）不参与路由生成，仅用于权限标识。

## 4. 界面交互规范

### 4.1 页面布局

菜单管理页面采用**单栏布局**，包含搜索条件区域、操作按钮区域和菜单树形数据表格。

### 4.2 交互规则

> 通用 UI 交互规范参见 [01-产品设计/02-UI-UX设计规范.md](../../../01-产品设计/02-UI-UX设计规范.md)

#### 4.2.1 本模块特有交互

| 场景 | 行为 |
|------|------|
| 打开新增表单 | 清空表单数据，默认值：type=目录，visible=显示，sort=1，parentId=0 |
| 打开编辑表单 | 加载菜单详情 |
| 菜单类型切换 | 根据类型动态显示/隐藏相关字段（详见 3.2.2 节条件显示） |
| 树形结构 | 默认展开第一级菜单，支持展开/收起操作；节点数较多时启用虚拟滚动与懒加载 |

#### 4.2.2 确认提示文案

- 删除确认：`确认删除菜单「{name}」吗？其子菜单将一并删除。`
- 批量删除：`确认删除选中的 {count} 个菜单吗？相关子菜单将一并删除。`

## 5. 安全设计

> **权限标识**：详见 [API接口.md - 权限标识汇总](./API接口.md)

### 5.1 数据安全

| 安全措施 | 说明 |
|---------|------|
| 数据可见性 | 菜单为系统级配置数据，基于角色权限控制可见性（角色拥有菜单权限即可见），不做用户级数据隔离 |
| 传输加密 | HTTPS 加密传输 |
| 防重复提交 | 同一操作不可重复提交 |
| 操作日志 | 强制记录菜单增删改等关键操作日志（操作人、时间、菜单 ID、变更内容） |
| 删除保护 | 逻辑删除保留数据，系统预置菜单不可删除 |

### 5.2 输入校验

| 校验类型 | 说明 |
|---------|------|
| 前端校验 | 表单实时校验 |
| 后端校验 | 服务端进行参数校验 + 业务校验（名称唯一性、权限标识唯一性） |
| 格式校验 | 路由地址、权限标识等字段格式校验 |

## 6. 远期规划（非本期实现）

以下能力不在本期实现，列为远期规划，待平台演进至「AI 工作平台」阶段按需评估：

1. **菜单拖拽排序**：支持拖拽调整菜单排序与层级
2. **菜单导入导出**：支持菜单配置导入/导出，便于环境间同步
3. **菜单回收站**：逻辑删除数据支持回收站恢复
4. **菜单版本管理**：菜单配置版本管理与回滚
5. **菜单国际化**：菜单名称支持多语言
6. **自定义图标上传**：图标选择器支持自定义图标上传

> 本期已定论事项：菜单深度限制 5 级；隐藏上级菜单时子菜单一并隐藏；批量删除支持（级联逻辑删除）。
