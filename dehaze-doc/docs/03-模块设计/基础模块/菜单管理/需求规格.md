# 菜单管理模块需求规格

## 1. 模块概述

### 1.1 模块定位

菜单管理模块负责维护系统的导航菜单结构，提供菜单增删改查、多级菜单结构、菜单类型分类、菜单显示控制与权限标识配置能力，是系统权限控制与多端用户导航的基础支撑。各端（Web、移动端、小程序、桌面端）的导航与路由均由菜单配置动态生成。

> **三后端契约**：Java/Go/Python 三后端 API 契约完全一致，Java 为权威来源，Go/Python 对齐。

### 1.2 核心价值

| 价值维度 | 具体内容 |
|---------|---------|
| **统一管理** | 提供系统菜单的统一管理入口，实现菜单全生命周期管理 |
| **权限控制** | 基于 RBAC 模型实现基于角色的菜单可见性与接口级权限控制 |
| **灵活配置** | 支持多级菜单结构（最多 5 级）、多种菜单类型和灵活的显示控制 |
| **多端路由生成** | 为 Web、移动端、小程序、桌面端动态生成适配各端的路由与导航结构 |
| **安全防护** | 逻辑删除保留历史可追溯，操作审计保障系统安全性 |

### 1.3 业务目标

#### 性能目标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| **列表查询响应** | &lt;500ms | 菜单列表查询响应时间 |
| **表单提交响应** | &lt;1s | 新增/编辑菜单操作响应时间 |
| **菜单容量** | ≥1000 | 系统支持的最大菜单数量 |
| **树形渲染** | &lt;300ms | 菜单树形结构渲染时间 |

### 1.4 模块依赖关系

| 方向 | 模块 | 说明 |
|------|------|------|
| 依赖 | **角色管理模块** | 菜单需与角色权限关联，实现基于角色的菜单访问控制 |
| 被依赖 | **各业务模块与权限控制** | 依赖菜单配置提供导航结构、各端路由，以及接口级权限校验依据 |

## 2. 用户角色分析

### 2.1 主要用户角色

| 角色 | 描述 | 主要职责 |
|------|------|---------|
| **系统管理员** | 拥有菜单管理模块的全部操作权限 | 菜单增删改查、权限配置、显示控制、路由配置 |

> 菜单为系统级配置数据，仅系统管理员可维护：查询、新增、编辑、删除、显示控制、排序、权限标识与路由配置。普通用户无管理权限，仅通过登录后获取的路由列表间接消费其有权限的菜单配置。菜单管理仅提供接口级权限控制，不实现字段级权限。

## 3. 功能需求

### 3.1 菜单列表查询 (F-MM-001)

#### 3.1.1 功能描述

提供菜单信息的树形展示和多条件筛选能力，支持管理员快速定位目标菜单。

#### 3.1.2 查询条件

| 条件类型 | 字段 | 说明 | 匹配方式 |
|---------|------|------|---------|
| **关键字搜索** | 菜单名称（name） | 模糊匹配菜单名称 | LIKE |
| **权限标识** | 权限标识（perm） | 模糊匹配权限标识符 | LIKE |
| **路由地址** | 路由地址（path） | 模糊匹配路由路径 | LIKE |
| **菜单类型** | 菜单类型（type） | 精确匹配：目录/菜单/外链/按钮 | = |
| **显示状态** | 显示状态（visible） | 精确匹配：显示/隐藏 | = |

#### 3.1.3 列表展示字段

列表按树形展示以下列：菜单名称、图标、类型、路由地址、权限标识、显示状态、排序、操作（编辑/删除）。

#### 3.1.4 展示方式

- **树形结构展示**：菜单以树形结构展示，支持最多 5 级深度，支持节点展开/收起
- **图标展示**：目录和菜单类型显示图标
- **状态标签**：显示状态使用标签形式展示（显示-绿色/隐藏-灰色）

### 3.2 菜单新增 (F-MM-002)

#### 3.2.1 功能描述

支持创建新菜单项，包括基本信息设置、上级菜单选择、菜单类型配置等。

#### 3.2.2 表单字段

| 字段 | 显示名称 | 类型 | 必填 | 校验规则 | 条件显示 |
|------|---------|------|------|---------|---------|
| type | 菜单类型 | 单选框组 | ✅ | 不能为空 | 始终显示 |
| parentId | 上级菜单 | 树形选择器 | ❌ | - | 始终显示 |
| name | 菜单名称 | 输入框 | ✅ | 不能为空 | 始终显示 |
| path | 路由地址 | 输入框 | ❌ | - | 菜单类型为"菜单"时必填 |
| component | 组件路径 | 输入框 | ❌ | - | 菜单类型为"菜单"时必填 |
| perm | 权限标识 | 输入框 | ❌ | 系统内唯一 | 菜单类型为"按钮"时必填 |
| icon | 菜单图标 | 图标选择器 | ❌ | - | 菜单类型为"目录"或"菜单"时显示 |
| redirect | 路由重定向 | 输入框 | ❌ | - | 菜单类型为"目录"时显示 |
| visible | 显示状态 | 单选框组 | ✅ | - | 始终显示（默认为显示） |
| sort | 菜单排序 | 数字输入框 | ✅ | 必须为数字 | 始终显示（默认为 1） |

#### 3.2.3 菜单类型说明

| 类型名称 | 说明 | 典型用途 |
|---------|------|---------|
| 目录 | 用于组织菜单结构，本身不对应具体页面 | 系统管理、数据管理等一级分类 |
| 菜单 | 对应具体的页面功能，可配置路由和组件 | 用户管理、角色管理等功能页 |
| 外链 | 外部链接，跳转到外部系统或文档 | 官方文档、外部帮助等 |
| 按钮 | 页面内的操作按钮，配置权限标识供权限控制使用 | 新增、编辑、删除等按钮权限 |

#### 3.2.4 业务规则

1. **菜单名称唯一性**：同一层级下菜单名称必须唯一
2. **权限标识唯一性**：权限标识符在系统中必须唯一
3. **上级菜单选择**：上级菜单可以是目录或菜单类型，不能选择按钮或外链
4. **类型必填项**：菜单类型必须配置路由地址与组件路径；按钮类型必须配置权限标识；外链类型的路由地址必须为完整 URL
5. **默认状态**：新增菜单默认为显示状态，排序默认为 1

### 3.3 菜单编辑 (F-MM-003)

#### 3.3.1 功能描述

支持修改现有菜单的各项属性，包括菜单类型、上级菜单、路由配置等。

#### 3.3.2 可编辑字段

所有新增表单中的字段均可编辑，需遵循相同的业务规则。

#### 3.3.3 业务规则

1. **即时生效**：修改保存后立即生效，权限标识变更后角色关联的权限同步更新
2. **类型变更**：菜单类型变更时，需校验该类型对应的必填字段
3. **上级变更**：上级菜单变更时，需校验层级关系，避免循环引用（不可将自身或自身子孙设为上级）

### 3.4 菜单删除 (F-MM-004)

#### 3.4.1 功能描述

支持删除单个或多个菜单项（批量删除），删除方式为**逻辑删除**，数据可追溯，禁止物理删除。系统预置菜单不可删除。

#### 3.4.2 操作流程

选择菜单（单条或多条）→ 点击删除 → 二次确认 → 级联标记删除目标菜单及其所有子孙菜单 → 清理角色菜单关联 → 刷新菜单树 → 显示成功提示

#### 3.4.3 业务规则

1. **批量删除**：支持一次提交多个菜单 ID 批量删除
2. **二次确认**：删除操作需弹出确认对话框
3. **级联删除**：删除菜单时级联逻辑删除其所有子孙菜单
4. **角色关联清理**：删除菜单时同步清理该菜单及其子孙与角色的权限关联
5. **预置数据保护**：系统预置菜单不可删除，校验失败提示"系统预置菜单不可删除"

#### 3.4.4 确认提示

- 单个删除："确认删除菜单「{name}」吗？其子菜单将一并删除。"
- 批量删除："确认删除选中的 {count} 个菜单吗？相关子菜单将一并删除。"
- 预置菜单："系统预置菜单不可删除。"

### 3.5 菜单显示控制 (F-MM-005)

#### 3.5.1 功能描述

支持控制菜单的显示/隐藏状态，用于功能灰度发布或临时隐藏。隐藏的菜单不在导航中呈现。

#### 3.5.2 状态说明

菜单显示状态分为"显示"（绿色标签）与"隐藏"（灰色标签）两种，隐藏状态的菜单在系统导航中不呈现。

#### 3.5.3 业务规则

1. **状态切换**：可通过状态标签或编辑表单切换状态，变更后立即生效
2. **子菜单继承**：隐藏上级菜单时，其子菜单在导航中一并隐藏
3. **权限保留**：隐藏状态的菜单权限仍生效，仅导航不显示

### 3.6 菜单排序 (F-MM-006)

#### 3.6.1 功能描述

支持设置菜单的显示顺序，通过排序字段控制菜单在树形结构中的位置。

#### 3.6.2 业务规则

1. **数字排序**：排序字段为整数，数字越小越靠前，仅在同级菜单间生效
2. **默认值**：新增菜单排序默认为 1
3. **实时生效**：排序变更后立即生效

### 3.7 菜单下拉选项 (F-MM-007)

#### 3.7.1 功能描述

为其他模块提供菜单下拉选项，用于选择上级菜单等场景。

#### 3.7.2 数据要求

以树形结构展示菜单选项，支持多级展开与选择；过滤掉按钮类型菜单（按钮不可作为上级菜单）。

### 3.8 路由列表生成 (F-MM-008)

#### 3.8.1 功能描述

根据菜单配置与用户角色权限，为各端动态生成路由列表与导航结构。

#### 3.8.2 生成规则

1. **过滤条件**：仅生成类型为"目录"和"菜单"且显示状态为"显示"的菜单；按钮类型不参与路由生成，仅用于权限标识
2. **权限过滤**：根据用户角色权限过滤可见菜单
3. **路由配置**：生成包含路由路径、组件路径、图标、重定向等信息的路由对象
4. **树形结构**：保持菜单的层级关系

#### 3.8.3 多端路由生成策略

后端返回统一的菜单/路由数据结构，由各端按自身路由规范适配生成，避免后端耦合各端细节：

| 端 | 生成策略 |
|----|---------|
| **Web Vue / Web React / 桌面端（Electron）** | 按路由路径 + 组件路径注册前端框架路由 |
| **移动端（Android/Flutter）** | 按菜单配置映射为各端页面跳转路径，目录类型映射为 tab/分组 |
| **小程序（Taro/UniApp）** | 按菜单配置生成页面配置与 tabBar，目录类型映射为 tab |

## 4. 界面交互规范

### 4.1 页面布局

菜单管理页面采用**单栏布局**，包含搜索条件区域、操作按钮区域和菜单树形数据表格。

### 4.2 交互规则

#### 4.2.1 本模块特有交互

| 场景 | 行为 |
|------|------|
| 打开新增表单 | 清空表单数据，默认值：类型=目录，显示状态=显示，排序=1，上级=顶级 |
| 打开编辑表单 | 加载菜单详情 |
| 菜单类型切换 | 根据类型动态显示/隐藏相关字段（条件显示规则见 3.2.2） |
| 树形结构 | 默认展开第一级菜单，支持展开/收起操作 |

## 5. 安全设计

### 5.1 数据安全

| 安全措施 | 说明 |
|---------|------|
| 数据可见性 | 菜单为系统级配置数据，基于角色权限控制可见性，不做用户级数据隔离 |
| 传输安全 | 数据传输需加密 |
| 防重复提交 | 同一操作不可重复提交 |
| 操作日志 | 强制记录菜单增删改等关键操作日志（操作人、时间、菜单标识、变更内容） |
| 删除保护 | 逻辑删除保留数据，系统预置菜单不可删除 |

### 5.2 输入校验

前端表单实时校验；服务端进行参数与格式校验，并校验菜单名称、权限标识的唯一性。
