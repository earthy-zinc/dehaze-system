# 消息通知模块 - 前端实现设计

## 1. 文档概述

本文档描述消息通知模块的前端实现方案（dehaze-front-vue），聚焦页面结构、状态管理、数据流、关键交互决策与权限控制。

---

## 2. 页面结构

### 2.1 页面清单

| 页面 | 路由 | 角色 | 说明 |
|------|------|:----:|------|
| 消息中心 | `notify/message` | 用户 | 类型 Tab 筛选 + 全部已读/按类型标记已读 + 搜索 + 单条/批量删除 |
| 消息详情 | `notify/message/detail` | 用户 | 消息完整内容 + 标记已读 |
| 通知设置 | `notify/settings` | 用户 | APP推送开关/类型偏好/模块开关/免打扰 |
| 公告管理 | `notify/announcement` | 管理员 | 公告列表 + 创建/编辑/发送/取消/删除 |
| 消息模板 | `notify/template` | 管理员 | 模板列表 + 编辑 |

> **说明**：消息中心为单页面组件，未拆分独立的图标/角标/筛选/列表/卡片子组件；未读角标由全局导航栏 + 通知 Store 承载。

### 2.2 消息中心（message/index.vue）

| 区域 | 内容 |
|------|------|
| 页头 | "消息中心"标题 + 未读数量胶囊（"X 条未读"）+ 全部已读按钮（未读数为 0 时禁用）+ 按类型标记已读（类型下拉，选择目标类型后标记） |
| 类型 Tab | 全部/站内信/系统公告/业务通知/会员通知/告警/严重告警/未读（未读 Tab 带数量角标） |
| 消息列表 | 多选复选框 + 每条：类型色条 + 类型标签（图标+名称）+ 标题 + 摘要 + 时间 + 未读标识 + 删除按钮 |
| 批量操作栏 | 选中消息后浮现：批量删除（确认弹窗） |
| 搜索框 | 按标题/正文关键字搜索（回车触发） |
| 分页 | 项目公共 Pagination 组件 |

**类型 Tab 逻辑**：`activeTab` 为 null 表示全部；切换 Tab 重置页码重新查询；"未读" Tab 使用 readStatus=0 筛选。

### 2.3 消息详情（message/detail.vue）

| 区域 | 内容 |
|------|------|
| 返回 | 返回消息列表 |
| 消息头部 | 类型标签 + 标题 + 时间 |
| 消息正文 | 完整消息内容 |
| 操作 | 标记已读（显式调用） |

### 2.4 通知设置（settings/index.vue）

| 区域 | 内容 |
|------|------|
| 通知方式偏好 | 按消息类型（系统公告/业务通知/会员通知/告警/严重告警）的 APP 推送开关 |
| 免打扰设置 | 免打扰开关 + 开始/结束时间选择 |
| 消息通知开关 | 按模块（处理任务完成/反馈进度/系统公告）的开关 |

> 修改即时生效（保存后刷新设置）。

### 2.5 公告管理（announcement/index.vue）

| 区域 | 内容 |
|------|------|
| 筛选区 | 标题/类型/状态 |
| 操作栏 | 新增公告（`notify:announcement:add`） |
| 表格 | 标题/类型/重要级别/发送范围/发送时间/创建时间/状态/操作（编辑、删除、发送、取消） |
| 新增/编辑弹窗 | 标题/内容/类型/重要级别/发送范围/定时发送时间/过期时间；按发送范围联动参数表单 |

**操作按钮显隐规则**：
- 编辑：status ∈ {1,2} 时显示
- 发送：status ∈ {1,2} 时显示（确认弹窗，成功后提示"发送成功，共送达 X 位用户"）
- 取消：仅 status=2（待发送）时显示（确认弹窗）
- 删除：确认弹窗

### 2.6 消息模板（template/index.vue）

| 区域 | 内容 |
|------|------|
| 筛选区 | 名称/类型/状态 |
| 表格 | 模板编码/名称/类型/标题模板/优先级/状态/操作（编辑） |
| 编辑弹窗 | 名称/标题模板/内容模板/优先级/渠道配置/启用状态 |

## 3. 状态管理

### 3.1 通知 Store（notification，Pinia）

| 状态 | 类型 | 说明 |
|------|------|------|
| unreadCount | number | 全局未读消息数（导航栏角标） |
| loaded | boolean | 未读数是否已加载 |

| 方法 | 说明 |
|------|------|
| fetchUnreadCount | 请求未读数并写入 |
| increment / decrement | 角标 +1 / -1（WebSocket 新消息 / 已读操作） |
| reset | 重置（登出时） |

> **说明**：存在独立通知 Store 管理未读数角标；消息列表分页数据等其他状态在页面组件内局部管理。

## 4. 数据流

### 4.1 消息中心

```
进入页面 → 通知 Store 加载未读数 + 分页查询消息列表
    ↓
切换类型 Tab / 搜索 → 重置页码重新查询
    ↓
操作：
  - 全部已读 → 调用标记接口 → 刷新列表 + 通知 Store 重置角标
  - 按类型标记已读 → 选择目标类型 → 调用标记接口（带类型参数）→ 刷新列表 + 通知 Store decrement
  - 单条删除 → 确认弹窗 → 调用删除接口 → 刷新列表
  - 批量删除 → 多选消息 → 确认弹窗 → 调用批量删除接口 → 刷新列表
```

### 4.2 实时角标更新

```
用户登录 → 建立全局 WebSocket 连接
    ↓
收到 new_message 事件 → 通知 Store increment（角标 +1）
    ↓
用户点击消息/全部已读 → 已读操作 → 通知 Store decrement/reset
```

### 4.3 消息详情已读

```
进入详情页 → 加载消息详情 → 显式调用标记已读 → 通知 Store decrement
（详情接口本身不自动标记已读，由前端显式调用）
```

### 4.4 模块间数据交互

| 交互方向 | 数据 | 说明 |
|---------|------|------|
| 全局 WebSocket → 消息中心 | new_message 事件 | 实时更新未读角标 |
| 业务模块 → 消息中心 | 站内信记录 | 各业务模块触发消息生成（后端） |

---

## 5. 关键交互决策

| 决策点 | 实现方式 |
|--------|---------|
| 类型 Tab 筛选 | 8 个 Tab（全部/6 类/未读），切换即查询 |
| 未读 Tab | readStatus=0 筛选 + 数量角标 |
| 全部已读 / 按类型标记已读 | 未读数为 0 时按钮禁用；按类型标记已读带类型参数，角标按已读数量 decrement |
| 单条/批量删除 | 均弹确认弹窗防误删；批量删除按 ID 列表提交 |
| 消息类型标识 | 类型色条 + 图标标签区分（announcement/business/member/alert/critical_alert/inbox） |
| 公告操作确认 | 发送/取消/删除均弹确认框 |
| 公告范围联动 | 全体用户隐藏参数 / 按等级选等级 / 指定用户填 ID 列表 |

## 6. 权限控制

| 操作 | 权限标识 | 无权限时 |
|------|---------|---------|
| 新增公告 | notify:announcement:add | 按钮隐藏 |
| 编辑公告 | notify:announcement:edit | 按钮隐藏 |
| 删除公告 | notify:announcement:delete | 按钮隐藏 |
| 发送公告 | notify:announcement:send | 按钮隐藏 |
| 取消公告 | notify:announcement:cancel | 按钮隐藏 |
| 编辑模板 | notify:template:edit | 按钮隐藏 |

> 消息中心/通知设置为登录用户可用；公告管理/消息模板为管理员后台页面。**无** `notify:announcement:list`/`notify:template:list` 权限标识（菜单级权限由后端菜单配置控制）。

---

## 7. 性能优化

| 优化项 | 实现方式 |
|--------|---------|
| 未读数全局缓存 | 通知 Store 缓存未读数，避免重复请求 |
| 分页查询 | 后端分页，前端仅当前页渲染 |
| WebSocket 推送 | 新消息经 WebSocket 实时推送（通知 Store increment），减少轮询 |
| 搜索触发 | 回车触发查询 |
