## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **用户数据** | 普通用户、VIP用户、管理员各至少1名 | 用于权限验证和消息接收测试 |
| **消息数据** | 各类型消息（站内信/公告/业务/会员/告警）各若干条 | 用于列表查询、筛选测试 |
| **公告数据** | 各状态公告（草稿/待发送/已发送/已取消） | 用于公告管理测试 |
| **模板数据** | 至少3个消息模板（启用/禁用） | 用于模板管理测试 |

### 3.2 数据清理策略

- 测试消息使用 `biz_module='test'` 标识，测试结束后按前缀批量删除
- 测试公告使用标题前缀 `test_` 标识，测试结束后按前缀批量删除
- 测试通知设置在测试结束后恢复为默认值

### 3.3 测试范围

**包含的功能点：**
- 消息列表查询（分页、筛选、排序）
- 消息详情查看与已读管理
- 消息删除（单条/批量）
- 消息搜索
- 通知偏好设置（推送开关、免打扰、模块开关）
- 系统公告管理（CRUD、发送、取消）
- 消息模板管理（查看、编辑）
- 内部消息发送接口（幂等去重）
- 未读消息数查询

**不包含的功能点：**
- APP推送通道本身的送达测试（依赖推送平台）
- 邮件/短信网关测试（依赖第三方服务）
- WebSocket 连接测试（依赖基础设施）

## 5. 关键边界与异常场景

| 场景 | 测试点 | 期望行为 |
|------|--------|---------|
| **消息量边界** | 单用户消息达10000+ | 列表查询响应时间仍&lt;500ms |
| **并发发送** | 多业务模块同时触发消息 | 消息均正确生成，无丢失 |
| **幂等去重** | 同一业务事件重复触发 | 仅生成一条消息 |
| **推送降级** | APP推送通道不可用 | 自动降级为仅站内信，消息不丢失 |
| **免打扰跨天** | 免打扰时段22:00-08:00 | 跨天逻辑正确，22:00后至次日08:00前不推送 |
| **公告批量投递** | 全体用户公告发送 | 批量生成消息记录，sentCount正确 |
| **过期清理** | 消息过期后（expires_at < NOW()） | 定时任务物理删除，列表不再展示 |
| **过期清理-未读消息** | 未读消息到期后 | 定时任务同样物理删除，不保留至已读 |
| **过期清理-已软删除** | 消息已软删除(deleted=1)且到期 | 定时任务物理删除，无论deleted=0或1 |
| **免打扰延迟推送** | 免打扰时段结束后 | DelayedPushJob弹出messageId并调用dispatch实际推送 |

## 6. 性能与并发测试

### 6.1 性能指标

> 性能目标参见 [需求规格.md](./需求规格.md) 第 5.1 节

| 指标 | 目标值 | 测试方法 |
|------|--------|---------|
| **消息生成延迟** | &lt;1s | 业务事件触发到消息记录可查 |
| **站内信查询响应** | &lt;500ms | 1000条消息数据，分页查询 |
| **未读数查询** | &lt;50ms | 高频调用，走缓存 |
| **公告批量发送** | &lt;30s | 1000用户全体公告 |

### 6.2 并发场景

| 场景 | 并发数 | 验证点 |
|------|--------|--------|
| **并发查询消息列表** | 50用户 | 响应时间稳定，无错误 |
| **并发标记已读** | 10请求标记不同消息 | 各自标记成功，互不影响 |
| **并发发送消息** | 10请求不同bizId | 消息均正确生成 |
| **幂等并发** | 5请求相同bizId | 仅生成一条消息 |

## 7. 安全性测试

| 测试项 | 验证方式 | 预期结果 |
|--------|---------|---------|
| **数据隔离** | 用户A请求用户B的消息 | 返回404或A0551 |
| **权限控制** | 普通用户调用公告管理接口 | 返回403 |
| **内部接口鉴权** | 无API Key调用发送接口 | 返回401 |
| **消息防篡改** | 直接修改数据库消息内容 | 前端展示不变（接口返回为准） |
| **SQL注入** | 搜索参数包含 `' OR 1=1--` | 参数化查询转义，无注入风险 |
| **XSS攻击** | 公告内容注入 `<script>` | 输出时编码，不执行脚本 |
| **越权删除** | 用户A删除用户B的消息 | 返回A0551 |
