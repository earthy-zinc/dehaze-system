# 任务管理模块 API 接口

## 1. 文档概述

本文档定义 **任务管理** 模块的 HTTP API 规范，是该模块 API 契约的**唯一权威来源**。

- **基础路径**：`/api/v1/tasks`
- **公共约定**：参见 [02-系统架构/04-API规范.md](../../../02-系统架构/04-API规范.md)
- **需求规格**：[需求规格.md](./需求规格.md)

> **重要**：接口详细参数/响应结构可通过 API 文档 MCP 查询，本文档仅定义接口清单和权限标识。

## 2. 接口清单

| 路径 | 方法 | 功能描述 | 权限标识 | 关联功能点 |
|------|------|---------|---------|-----------|
| `/api/v1/tasks` | POST | 创建任务 | `sys:task:add`(Go) | F-TM-001 |
| `/api/v1/tasks/{taskId}` | GET | 查询任务状态 | - | F-TM-002 |
| `/api/v1/tasks/{taskId}/download` | GET | 下载任务结果 | - | F-TM-003 |
| `/api/v1/tasks/{taskId}/cancel` | POST | 取消任务 | `sys:task:delete`(Go) | F-TM-004 |
| `/api/v1/tasks/{taskId}/retry` | POST | 重试失败任务 | `sys:task:add`(Go) | F-TM-006 |
| `/api/v1/tasks` | GET | 任务列表查询 | - | F-TM-005 |

> **接口规范约定**：取消任务使用 `POST /{taskId}/cancel`（动作型子资源），而非 `DELETE /{taskId}`。DELETE 语义为"删除资源"，取消是状态变更操作，使用 POST + 动作子资源更符合 RESTful 规范。三端（Java/Go/Python）及 SDK 必须统一遵循此约定。

### 2.1 创建任务请求头

| 请求头 | 是否必填 | 说明 |
|--------|---------|------|
| `Idempotency-Key` | 否 | 客户端幂等键，相同键返回已有任务，防止重复创建 |

## 3. 权限标识汇总

> 任务管理模块基于数据隔离控制权限，用户只能操作自己创建的任务（校验 `create_by`）。

| 操作 | Java | Go | Python |
|------|------|-----|--------|
| 创建任务 | 需登录态 | `sys:task:add` | 需登录态 |
| 查询状态 | 需登录态 + 任务所有者 | 需登录态 + 任务所有者 | 需登录态 + 任务所有者 |
| 下载结果 | 需登录态 + 任务所有者 | 需登录态 + 任务所有者 | 需登录态 + 任务所有者 |
| 取消任务 | 需登录态 + 任务所有者 | `sys:task:delete` + 任务所有者 | 需登录态 + 任务所有者 |
| 重试任务 | 需登录态 + 任务所有者 | `sys:task:add` + 任务所有者 | 需登录态 + 任务所有者 |
| 任务列表 | 需登录态（仅本人） | 需登录态（仅本人） | 需登录态（仅本人） |

## 4. 业务错误码

> 三端错误码存在差异，Java/Go 仅定义 `B0301`/`B0308`，其余错误码为 Python 端定义；Java/Go 其他任务错误通过通用 `A0500` 业务异常返回。统一目标以 Java 为 spec 权威来源，改造后对齐。

| 错误码 | 说明 | Java | Go | Python |
|--------|------|------|-----|--------|
| `B0301` | 任务不存在 | ✅ | ✅ | ✅ |
| `B0302` | 无权操作此任务 | A0500 | A0500 | ✅ |
| `B0303` | 任务状态不允许此操作 | A0500 | A0500 | ✅ |
| `B0304` | 不支持的任务类型 | A0500 | A0500 | ✅ |
| `B0305` | 任务参数错误 | A0500 | A0500 | ✅ |
| `B0306` | 任务已被取消 | A0500 | A0500 | ✅ |
| `B0307` | 同类型任务并发数已达上限 | -（未启用） | -（未启用） | 定义 |
| `B0308` | 导入导出任务并发超限 | 定义（未启用） | 定义（未启用） | 定义 |
