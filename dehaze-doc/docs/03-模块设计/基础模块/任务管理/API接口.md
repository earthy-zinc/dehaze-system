# 任务管理模块 API 接口

## 1. 文档概述

本文档定义 **任务管理** 模块的 HTTP API 规范，是该模块 API 契约的**唯一权威来源**。

- **基础路径**：`/api/v1/tasks`
- **错误码范围**：`B03xx`

## 2. 接口清单

| 路径 | 方法 | 功能描述 | 权限标识 | 关联功能点 |
|------|------|---------|---------|-----------|
| `/api/v1/tasks` | POST | 创建任务 | - | F-TM-001 |
| `/api/v1/tasks/{taskId}` | GET | 查询任务状态 | - | F-TM-002 |
| `/api/v1/tasks/{taskId}/download` | GET | 下载任务结果（完成后 302 重定向到文件下载地址） | - | F-TM-003 |
| `/api/v1/tasks/{taskId}/cancel` | POST | 取消任务 | - | F-TM-004 |
| `/api/v1/tasks/{taskId}/retry` | POST | 重试失败任务 | - | F-TM-006 |
| `/api/v1/tasks` | GET | 任务列表查询 | - | F-TM-005 |

## 3. 权限标识汇总

任务管理模块基于数据隔离控制访问权限，不定义细粒度权限标识：

- 所有接口均需登录态访问
- 普通用户仅能操作（查询/下载/取消/重试）本人创建的任务
- 管理员可查看与操作全量任务（运维监控）

## 4. 业务错误码

| 错误码 | 说明 | 触发场景 |
|--------|------|---------|
| B0301 | 任务不存在 | 查询/操作时任务不存在或非本人任务 |
| B0302 | 无权操作此任务 | 操作非本人创建的任务 |
| B0303 | 任务状态不允许此操作 | 非运行中任务执行取消/重试等 |
| B0304 | 不支持的任务类型 | 创建任务时类型不在支持范围 |
| B0305 | 任务参数错误 | 任务参数校验失败 |
| B0306 | 任务已被取消 | 对已取消任务执行取消/重试等 |
| B0307 | 同类型任务并发数已达上限 | 同类型任务并发超过限制 |
| B0308 | 导入导出任务并发超限 | 导入导出任务并发超过限制 |
