# 任务管理模块 API 接口

## 1. 文档概述

本文档定义 **任务管理** 模块的 HTTP API 规范，是该模块 API 契约的**唯一权威来源**。

- **基础路径**：`/api/v1/tasks`
- **公共约定**：参见 [02-系统架构/04-API规范.md](../../../02-系统架构/04-API规范.md)
- **需求规格**：[需求规格.md](./需求规格.md)

> **重要**：接口详细参数/响应结构可通过 API 文档 MCP 查询，本文档仅定义接口清单和权限标识。

## 2. 接口清单

| 路径 | 方法 | 功能描述 | 权限标识 | 关联功能点 |
|------|------|---------|---------|-----------|
| `/api/v1/tasks` | POST | 创建任务 | - | F-TM-001 |
| `/api/v1/tasks/{taskId}` | GET | 查询任务状态 | - | F-TM-002 |
| `/api/v1/tasks/{taskId}/download` | GET | 下载任务结果 | - | F-TM-003 |
| `/api/v1/tasks/{taskId}/cancel` | POST | 取消任务 | - | F-TM-004 |
| `/api/v1/tasks/{taskId}/retry` | POST | 重试失败任务 | - | F-TM-004 |
| `/api/v1/tasks` | GET | 任务列表查询 | - | F-TM-005 |

> **接口规范约定**：取消任务使用 `POST /{taskId}/cancel`（动作型子资源），而非 `DELETE /{taskId}`。DELETE 语义为"删除资源"，取消是状态变更操作，使用 POST + 动作子资源更符合 RESTful 规范。三端（Java/Go/Python）及 SDK 必须统一遵循此约定。

### 2.1 创建任务请求头

| 请求头 | 是否必填 | 说明 |
|--------|---------|------|
| `Idempotency-Key` | 否 | 客户端幂等键，相同键返回已有任务，防止重复创建 |

## 3. 权限标识汇总

> 任务管理模块基于数据隔离控制权限，用户只能操作自己创建的任务。

| 操作 | 访问控制 |
|------|---------|
| 创建任务 | 需登录态 |
| 查询/取消/下载 | 需登录态 + 任务所有者 |

## 4. 业务错误码

| 错误码 | 说明 | 触发场景 |
|--------|------|---------|
| `B0301` | 任务不存在 | 查询/取消/下载不存在的任务 |
| `B0302` | 无权操作此任务 | 操作非本人创建的任务 |
| `B0303` | 任务类型不支持 | 创建任务时类型不在支持列表 |
| `B0304` | 任务状态不允许此操作 | 取消已完成/失败/已取消的任务 |
| `B0305` | 任务结果已过期 | 下载已过期的任务结果 |
| `B0306` | 任务结果不存在 | 下载未完成任务或结果文件已删除 |
| `B0307` | 并发任务数超限 | 用户同类型未完成任务数超过限制 |
| `B0308` | 导出任务并发超限 | 单用户导入导出任务并发数超限 |
