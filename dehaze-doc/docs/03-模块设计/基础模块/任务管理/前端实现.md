# 任务管理模块 - 前端实现设计

## 1. 文档概述

本文档描述任务管理模块的前端实现方案，聚焦组件架构、状态管理、路由设计、轮询策略等架构决策。

## 2. 组件架构设计

### 2.1 组件层次结构

```
任务管理页面 (views/task/list/index.vue)
├── 页面头部
│   ├── 页面标题
│   └── 筛选栏 (FilterBar)
└── 任务列表区域
    ├── 任务列表 (TaskList)
    │   └── 任务卡片 (TaskCard)
    │       ├── 任务信息区域
    │       ├── 进度条 (ProgressBar)
    │       └── 操作按钮
    └── 分页组件 (Pagination)
```

### 2.2 弹窗组件结构

```
任务详情弹窗 (TaskDetailDialog)
├── 任务基本信息
├── 进度详情
├── 错误信息（失败时）
└── 操作按钮（取消/重试/下载）
```

### 2.3 组件职责划分

| 组件名称 | 职责描述 | 复用性 |
|---------|---------|--------|
| **FilterBar** | 任务多维筛选（状态/类别/类型/用户） | 页面内部组件 |
| **TaskList** | 任务列表展示 | 页面内部组件 |
| **TaskCard** | 单个任务展示卡片 | 可复用组件 |
| **ProgressBar** | 任务进度条 | 项目公共组件 |
| **Pagination** | 列表分页 | 项目公共组件 |
| **TaskDetailDialog** | 任务详情弹窗 | 页面内部组件 |

## 3. 路由设计

| 路由路径 | 视图组件 | 名称 | 加载方式 | 说明 |
|---------|---------|------|---------|------|
| `/task/list` | views/task/list/index.vue | TaskList | 动态菜单 | 任务列表与运维页，依据菜单权限控制入口可见性 |

- 任务管理为单一聚合页，无独立详情路由——任务详情经弹窗展示。
- 路由经动态菜单加载，普通用户与管理员共用同一入口，角色差异在页内按筛选器与字段渲染体现。
- 业务模块创建任务后通过编程式导航跳转至本页，自动启动状态轮询。

## 4. 组件详细设计

### 4.1 筛选栏组件

筛选栏按角色差异化渲染，支持四维联动筛选：

| 筛选维度 | 选项 | 说明 |
|---------|------|------|
| 任务状态 | 全部/待执行/执行中/已完成/失败/已取消 | 单选，按任务状态筛选 |
| 任务类别 | 全部/导入/导出 | 单选，按任务大类筛选 |
| 任务类型 | 全部/动态枚举（dataset_export 等） | 单选，按具体任务类型筛选；选项随任务类别联动 |
| 用户 | 用户选择器 | **仅管理员可见**，按任务创建人筛选；普通用户不渲染此项 |

> 切换任一维度均重置页码重新查询；任务类型选项随类别联动（选择"导出"时仅展示 export 类类型）。普通用户查询由后端按归属自动过滤，管理员默认返回全量任务。

### 4.2 任务卡片组件

#### 展示字段

| 字段 | 说明 | 特殊处理 |
|------|------|---------|
| taskId | 任务 ID | 可复制 |
| type | 任务类型 | 类型名称翻译 |
| status | 状态 | 状态标签（带颜色） |
| progress | 进度 | 进度条 + 百分比 |
| retryCount | 重试次数 | 大于 0 时展示"已重试 N 次" |
| createdBy | 创建人 | **仅管理员视角展示**，普通用户隐藏 |
| createdAt | 创建时间 | 相对时间显示 |
| completedAt | 完成时间 | 相对时间显示 |

#### 状态样式

| 状态 | 标签颜色 | 说明 |
|------|---------|--------|
| PENDING | 蓝色 | 待处理 |
| PROCESSING | 蓝色 | 处理中 |
| COMPLETED | 绿色 | 已完成 |
| FAILED | 红色 | 已失败 |
| CANCELLED | 灰色 | 已取消 |

#### 操作按钮

| 状态 | 可用操作 |
|------|---------|
| PENDING | 取消 |
| PROCESSING | 取消 |
| COMPLETED | 下载 |
| FAILED | 查看错误、重试 |
| CANCELLED | - |

> 操作权限由后端校验任务归属（普通用户仅自身任务，管理员全量）；前端统一渲染按钮，不做角色级显隐分支。

### 4.3 进度条组件

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| progress | Number | 0 | 进度百分比 (0-100) |
| status | String | 'active' | 进度条状态 |
| showInfo | Boolean | true | 是否显示百分比文字 |

## 6. 数据流设计

### 6.1 任务操作数据流

通过 SDK 的任务接口完成创建/查询/取消/重试/下载/列表操作，各业务模块创建任务后跳转任务管理页。

### 6.2 请求错误处理

| 错误类型 | 处理方式 |
|---------|---------|
| 任务不存在 | 从列表移除，提示任务已不存在 |
| 无权操作 | 提示无权限 |
| 结果已过期 | 提示结果已过期，禁用下载按钮 |
| 网络错误 | 显示网络连接失败提示 |

## 7. 交互流程设计

### 7.1 页面初始化流程

1. 进入页面，读取用户角色判断是否渲染用户筛选器
2. 显示加载状态，按筛选参数请求任务列表（普通用户由后端按归属过滤，管理员默认全量）
3. 数据加载完成，渲染列表
4. 启动轮询检测（针对 PENDING/PROCESSING 状态任务）

### 7.2 任务状态轮询机制

```
页面加载 → 获取任务列表
    ↓
筛选出 PENDING/PROCESSING 状态任务
    ↓
每 3 秒轮询更新状态
    ↓
状态变为终态(COMPLETED/FAILED/CANCELLED) → 停止轮询该任务
    ↓
列表中无需轮询任务 → 停止全局轮询
```

#### 轮询配置

| 配置项 | 值 | 说明 |
|--------|-----|------|
| 轮询间隔 | 3000ms | 每 3 秒查询一次 |
| 最大轮询时间 | 30分钟 | 超时后停止轮询 |
| 页面不可见时 | 暂停轮询 | 使用 visibilitychange 事件 |

### 7.3 任务创建流程

任务创建通常由业务模块触发（如数据集导出），任务管理模块负责展示：

```
业务模块调用任务创建接口 → 返回 taskId
    ↓
跳转/提示查看任务 → 任务管理页面
    ↓
自动开始轮询任务状态
```

### 7.4 任务取消流程

```
点击取消按钮 → 弹出确认框："确认取消该任务吗？"
    ↓ 确认
调用取消接口 → 更新任务状态为 CANCELLED
    ↓
停止该任务的轮询
```

### 7.5 失败任务重试流程

```
点击重试按钮 → 弹出确认框："确认重试该任务吗？"
    ↓ 确认
调用重试接口 → 任务状态由 FAILED 转为 PENDING
    ↓
重新纳入轮询队列，清除上次错误信息
```

### 7.6 结果下载流程

```
点击下载按钮
    ↓
检查任务状态是否为 COMPLETED
    ↓ 是
检查结果是否过期
    ↓ 未过期
触发文件下载（新标签页或直接下载）
```

## 8. 性能优化设计

### 8.1 请求优化

| 优化项 | 实现方式 |
|--------|---------|
| 轮询节流 | 控制轮询间隔，避免频繁请求 |
| 批量查询 | 多个任务状态可批量查询（如支持） |
| 页面不可见暂停 | 页面切换到后台时暂停轮询 |
| 离开页面清理 | 组件卸载时清除所有定时器 |

### 8.2 渲染优化

| 优化项 | 实现方式 |
|--------|---------|
| 列表虚拟化 | 大量任务时使用虚拟列表 |
| 状态局部更新 | 轮询返回后仅更新变化的任务 |

### 8.3 用户体验优化

| 优化项 | 实现方式 |
|--------|---------|
| 进度动画 | 进度条平滑动画过渡 |
| 操作反馈 | 取消/重试/下载操作即时反馈 |
| 空状态提示 | 无任务时显示引导信息 |
| 错误重试 | 网络错误时提供重试按钮 |

## 9. 任务创建集成

### 9.1 任务创建后的交互

| 场景 | 交互行为 |
|------|---------|
| 创建成功 | 显示成功提示，提供"查看任务"链接 |
