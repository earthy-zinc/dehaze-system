# 任务管理模块测试用例

## 1. 测试目标

验证任务管理模块的核心功能符合 [需求规格.md](./需求规格.md) 定义：

- **任务生命周期**：任务创建（F-TM-001）、任务状态查询（F-TM-002）、任务结果下载（F-TM-003）、任务取消（F-TM-004）
- **任务管理**：任务列表查询（F-TM-005）、任务重试（F-TM-006）
- **管理员运维**：全量查询、僵尸任务修复、过期清理
- **场景覆盖**：正常流程、边界条件、异常分支、权限控制
- **非功能验证**：状态流转正确性、幂等性、并发场景、性能指标

## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **测试用户** | 至少2个测试用户 + 1个系统管理员 | 用于数据隔离与管理员视角测试 |
| **数据集数据** | 含多个数据项的数据集 | 用于数据集导出任务测试 |
| **文件数据** | 测试文件 | 用于下载任务测试 |

### 3.2 数据清理策略

- 测试任务使用统一前缀标识
- 测试结束后清理测试创建的任务记录
- 清理测试生成的结果文件

### 3.3 测试范围

**包含的功能点：**
- 任务创建（多种任务类型，含 Idempotency-Key 幂等）
- 任务状态查询
- 任务取消
- 任务结果下载
- 任务列表查询（含状态/任务类别/任务类型筛选）
- 任务重试（F-TM-006）
- 状态流转验证（合法/非法状态转换）
- 管理员视角运维（全量查询、按用户筛选、取消/重试全量、僵尸任务修复、历史任务清理）

**不包含的功能点：**
- 具体任务执行逻辑（各策略独立测试）
- 文件存储服务（依赖模块测试）
- 并发任务数限制（常量已定义但三端未强制执行，见需求规格 §3.1.4）

## 5. 关键边界与异常场景

| 场景 | 测试点 | 期望行为 |
|------|--------|---------|
| **服务重启恢复** | 服务重启后 | PENDING 任务消息未 ACK 由 RabbitMQ 重投，自动恢复 |
| **并发取消** | 同一任务被多次取消 | 仅第一次成功（CAS），后续返回"任务状态已变更" |
| **大文件导出** | 导出包含大量文件的数据集 | 正常完成，进度实时更新 |
| **结果过期清理** | 任务结果超过保留时长（7 天） | 定时任务清理，下载返回已过期 |
| **僵尸任务修复** | 执行中超过 30 分钟 | 定时任务标记为失败 |
| **MQ 未启用** | 测试环境无 RabbitMQ | fallback 同步执行任务 |

## 6. 性能与并发测试

### 6.1 性能指标

> 性能目标参见 [需求规格.md](./需求规格.md) 第 1.3 节

| 指标 | 目标值 | 测试方法 |
|------|--------|---------|
| **任务创建响应时间** | &lt;200ms | 单次创建操作 |
| **状态查询响应时间** | &lt;50ms | 单次查询操作（走缓存） |
| **列表查询响应时间** | &lt;500ms | 分页查询（10条/页） |
| **取消操作响应时间** | &lt;200ms | 单次取消操作 |

### 6.2 并发场景

| 场景 | 并发数 | 验证点 |
|------|--------|--------|
| **并发创建任务（同幂等键）** | 10 请求 | 仅创建 1 个任务，其余返回相同 taskId |
| **并发创建任务（不同幂等键）** | 10 请求 | 创建 10 个独立任务 |
| **并发查询状态** | 50 请求 | 响应时间稳定 |
| **并发取消同一任务** | 5 请求 | 仅一个成功（CAS） |
| **高频轮询** | 100 请求/秒 | 系统稳定，无错误 |

## 7. 安全性测试

| 测试项 | 验证方式 | 预期结果 |
|--------|---------|---------|
| **数据隔离** | 用户A访问用户B的任务 | 返回无权操作（Python B0302 / Java A0500） |
| **taskId 不可猜测** | 尝试猜测 taskId | UUID 格式，不可枚举 |
| **下载鉴权** | 未登录下载任务结果 | 返回 401 |
| **下载归属校验** | 用户A下载用户B的任务结果 | 返回无权操作（Python B0302 / Java A0500） |
| **取消归属校验** | 用户A取消用户B的任务 | 返回无权操作（Python B0302 / Java A0500） |
| **查询归属校验** | 用户A查询用户B的任务 | 返回无权操作（Python B0302 / Java A0500） |
| **重试归属校验** | 用户A重试用户B的任务 | 返回无权操作（Python B0302 / Java A0500） |
| **参数校验** | 注入恶意参数 | 参数校验拦截 |
