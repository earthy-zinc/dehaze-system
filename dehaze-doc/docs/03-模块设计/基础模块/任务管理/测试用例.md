## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **测试用户** | 至少2个测试用户 | 用于数据隔离测试 |
| **数据集数据** | 含多个数据项的数据集 | 用于数据集导出任务测试 |
| **文件数据** | 测试文件 | 用于下载任务测试 |

### 3.2 数据清理策略

- 测试任务使用统一前缀标识
- 测试结束后清理测试创建的任务记录
- 清理测试生成的结果文件

### 3.3 测试范围

**包含的功能点：**
- 任务创建（多种任务类型）
- 任务状态查询
- 任务取消
- 任务结果下载
- 任务列表查询

**不包含的功能点：**
- 具体任务执行逻辑（各策略独立测试）
- 文件存储服务（依赖模块测试）

## 8. 关键边界与异常场景

| 场景 | 测试点 | 期望行为 |
|------|--------|---------|
| **任务执行超时** | 任务长时间处于 PROCESSING | 超时后标记为 FAILED（若配置） |
| **服务重启恢复** | 服务重启后 | PENDING 任务重新调度，PROCESSING 标记为 FAILED |
| **并发取消** | 同一任务被多次取消 | 仅第一次成功，后续返回状态不允许 (B0304) |
| **大文件导出** | 导出包含大量文件的数据集 | 正常完成，进度实时更新 |
| **结果过期清理** | 任务结果超过保留时长 | 自动清理，下载返回已过期 |

## 9. 性能与并发测试

### 9.1 性能指标

> 性能目标参见 [需求规格.md](./需求规格.md) 第 1.3 节

| 指标 | 目标值 | 测试方法 |
|------|--------|---------|
| **任务创建响应时间** | &lt;1s | 单次创建操作 |
| **状态查询响应时间** | &lt;500ms | 单次查询操作 |
| **列表查询响应时间** | &lt;500ms | 分页查询（10条/页） |
| **取消操作响应时间** | &lt;500ms | 单次取消操作 |

### 9.2 并发场景

| 场景 | 并发数 | 验证点 |
|------|--------|--------|
| **并发创建任务** | 10 请求 | 并发限制正确生效 |
| **并发查询状态** | 50 请求 | 响应时间稳定 |
| **并发取消同一任务** | 5 请求 | 仅一个成功 |
| **高频轮询** | 100 请求/秒 | 系统稳定，无错误 |

## 10. 安全性测试

| 测试项 | 验证方式 | 预期结果 |
|--------|---------|---------|
| **数据隔离** | 用户A访问用户B的任务 | 返回无权限 (B0302) |
| **taskId 不可猜测** | 尝试猜测 taskId | UUID 格式，不可枚举 |
| **下载鉴权** | 未登录下载任务结果 | 返回 401 |
| **下载归属校验** | 用户A下载用户B的任务结果 | 返回无权限 (B0302) |
| **取消归属校验** | 用户A取消用户B的任务 | 返回无权限 (B0302) |
| **查询归属校验** | 用户A查询用户B的任务 | 返回无权限 (B0302) |
| **参数校验** | 注入恶意参数 | 参数校验拦截 |
