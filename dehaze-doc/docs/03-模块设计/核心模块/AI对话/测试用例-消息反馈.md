# AI 对话模块测试用例 — 消息反馈 (F-M08-008)

## 1. 测试目标

- [x] 验证消息反馈（点赞/点踩/预设标签/反馈驱动闭环）

## 2. 测试前置

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **测试反馈** | 会话含 5 条 assistant 消息（已反馈 2 条） | 反馈 CRUD 和 upsert |

### 2.1 数据清理策略

- 测试反馈与衍生记忆打标 `source=test`，测试结束后软删除；测试会话前缀 `test_mf_conv_`，结束后软删除

### 3.2 反馈驱动闭环

| 用例 ID | 测试场景 | 前置条件 | 输入 | 期望输出 | 优先级 |
|---------|---------|---------|------|---------|--------|
| `T-MF-063` | 点踩→记忆提取 | rating=-1, tags=["too_long"], processed=0 | 触发 processFeedbackLoop | 新增语义记忆："用户偏好简洁回复"，processed 置 1 | P1 |
| `T-MF-064` | 高频负反馈→提示词优化 | "too_long" 标签累计 10 次 | 触发 processFeedbackLoop | 在 system_prompt 中增加"回复保持简洁"指令 | P2 |
| `T-MF-065` | 工具频繁负反馈→策略调整 | "incorrect" 标签频繁 | 触发 processFeedbackLoop | 降低该工具在类似场景的选择优先级 | P2 |
| `T-MF-066` | 闭环处理-幂等防重 | 点踩反馈 processed=1 | 再次触发 processFeedbackLoop | 已处理反馈不再重复处理（processed=1 跳过） | P1 |
| `T-MF-067` | 闭环处理-失败重试 | 处理失败（LLM 异常） | 再次触发 processFeedbackLoop | processed 仍为 0，下次扫描自动重试 | P2 |
| `T-MF-069` | 闭环处理-评测集回流 | 高价值差评（高频/关键业务/可确认根因） | 触发 processFeedbackLoop | 差评脱敏后转成回归用例，写入回归集（sys_ai_agent_eval_sample） | P2 |
| `T-MF-070` | 闭环处理-紧急错误时效 | tags=["harmful"] 或 ["incorrect"] | 触发 processFeedbackLoop | 24 小时内处理完成（process_time 记录） | P2 |
