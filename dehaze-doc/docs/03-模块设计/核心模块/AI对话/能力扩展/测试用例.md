# AI 对话模块测试用例 — 能力扩展 (F-M08-006)

## 1. 测试目标

- [x] 验证 Skills 管理（列表/创建/启停/渐进式加载/执行过程展示）
- [x] 验证工具调用生命周期与可见性（状态展示/审计记录）
- [x] 验证高风险操作确认、连续失败保护
- [x] 验证虚拟文件系统容量限制、任务清单约束
- [x] 验证搜索工具配额与降级、代码执行沙箱安全边界
- [x] 验证能力访问与安全（最小权限/凭据保护/调用审计）
- [x] 验证 MCP Server 管理（外部接入/命名空间/凭据/健康/审计）与 SKILL 市场

## 2. 测试前置

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **测试 Skill** | 2 个启用 Skill + 1 个禁用 Skill | Skills 管理验证 |
| **测试 Agent** | 1 个带 MCP 命名空间与文件权限配置的 Agent | 能力访问与权限验证 |
| **测试会话** | 含工具调用记录的消息（推理步骤含 thought/tool_use） | 工具调用可见性验证 |
| **Mock LLM** | 可编排工具调用序列（成功/失败/连续失败） | 工具生命周期与失败保护 |
| **Mock 沙箱** | 模拟代码执行（正常/超时/资源超限） | 代码执行安全验证 |

### 2.1 数据清理策略

- 测试 Skill 打标 `source=test`，测试结束后软删除
- 测试会话前缀 `test_mf_`，测试结束后软删除
