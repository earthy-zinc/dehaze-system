### 4.2 模型路由与降级

| 用例 ID | 测试场景 | 前置条件 | 输入 | 期望输出 | 优先级 |
|---------|---------|---------|------|---------|--------|
| `T-MF-010` | 主模型正常→不降级 | gpt-4o-mini（无 fallback） | 正常调用 | 使用 gpt-4o-mini，不计降级 | P0 |
| `T-MF-011` | 主模型 429→降级 | gpt-4o-mini（fallback=claude-3-5-haiku） | LLM 返回 429 | 自动切换到 claude-3-5-haiku，消息 model 记录为降级模型 | P0 |
| `T-MF-012` | 主模型 5xx→降级 | 同上 | LLM 返回 503 | 降级成功，积分按降级模型计算 | P0 |
| `T-MF-013` | 主模型超时→降级 | 同上 | LLM 超时 30s | 降级成功 | P1 |
| `T-MF-014` | 多级降级链（A→B→C） | A.fallback=B, B.fallback=C | A 不可用 | 降级到 B → B 也不可用 → 降级到 C → 全部不可用 → error | P1 |
| `T-MF-015` | 降级模型不满足能力要求 | 主模型 supports_multimodal=1，fallback 不支持 | 消息含图片 | 跳过 fallback，尝试下一级或报错 | P1 |
| `T-MF-016` | actual_model 记录 | 降级发生 | 查询 sys_ai_billing | actual_model="gpt-4o-mini"（用户选的），model="claude-3-5-haiku"（实际用） | P0 |
| `T-MF-017` | 全部模型不可用 | 主+降级全失败 | — | 推送 error 事件，消息 status=3(failed)，error 含"主模型和降级模型均不可用" | P1 |

### 4.3 Prompt Caching

| 用例 ID | 测试场景 | 前置条件 | 输入 | 期望输出 | 优先级 |
|---------|---------|---------|------|---------|--------|
| `T-MF-020` | 稳定前缀结构正确 | 模型 supports_prompt_cache=1 | 组装 prompt | system_prompt+工具定义在头部（稳定前缀），最近消息在尾部（动态后缀） | P1 |
| `T-MF-021` | 缓存命中→折扣计费 | 相同 system_prompt + 工具定义 | 第 2 次调用 | cached_input_tokens > 0，credits_saved > 0 | P1 |
