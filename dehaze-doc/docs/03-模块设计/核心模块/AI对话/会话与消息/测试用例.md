# AI 对话模块测试用例 — 会话与消息 (F-M08-001)

## 1. 测试目标

- [x] 验证会话生命周期（创建/编辑/归档/删除/列表搜索/批量管理/导出）
- [x] 验证消息流式输出、SSE 事件推送、断线重连、幂等性
- [x] 验证分支对话（重新生成/编辑重发/分支切换）
- [x] 验证消息删除、类似问题推荐、消息引用与朗读
- [x] 验证管理端会话审计（全量会话/消息查看、AI 链路追踪、权限隔离）
- [x] 覆盖正常流程、并发控制、异常分支

## 2. 测试前置

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **测试用户** | user_test_chat（含有效 API Key） | 会话创建/查询鉴权 |
| **测试会话** | 3 个不同状态的会话（活跃/已归档/已删除） | 列表筛选验证 |
| **测试消息** | 含分支消息的会话（主分支 + 2 个兄弟分支） | 分支查询验证 |
| **Mock LLM** | 模拟 SSE 流式输出 | 流式事件和断连测试 |
| **管理员账号** | admin（`ai:conversation:audit`）与普通用户 user_test_chat | 会话审计权限验证 |

### 2.1 数据清理策略

- 测试会话前缀 `test_conv_`，测试结束后软删除
- 测试消息随会话级联清理
