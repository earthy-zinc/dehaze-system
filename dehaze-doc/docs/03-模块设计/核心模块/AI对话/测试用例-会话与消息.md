## 3. 测试前置

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **测试用户** | user_test_chat（含有效 API Key） | 会话创建/查询鉴权 |
| **测试会话** | 3 个不同状态的会话（活跃/已归档/已删除） | 列表筛选验证 |
| **测试消息** | 含分支消息的会话（主分支 + 2 个兄弟分支） | 分支查询验证 |
| **Mock LLM** | 模拟 SSE 流式输出 | 流式事件和断连测试 |

### 数据清理策略

- 测试会话前缀 `test_conv_`，测试结束后软删除
- 测试消息随会话级联清理

### 4.3 SSE 断线重连

| 用例 ID | 测试场景 | 前置条件 | 输入 | 期望输出 | 优先级 |
|---------|---------|---------|------|---------|--------|
| `T-CV-040` | 正常断线重连 | 流式输出已推送 10 个事件 | SSE 断连，携带 Last-Event-ID=5 + streamSessionId | 服务端从事件 #6 开始重放，前端收到完整 10 个事件 | P0 |
| `T-CV-041` | 重连时原流已完成 | 流式已完成 | 断连后重连 | 重放剩余事件后发送 message.end，关闭连接 | P1 |
| `T-CV-042` | 重连时原流未完成 | 流式进行中 | 断连后重连 | 重放已缓存事件后，继续推送新 token | P1 |
| `T-CV-043` | 重连超时（>5 分钟） | 断连超过 5 分钟 | 携带过期 streamSessionId | 返回 410 Gone | P1 |
| `T-CV-044` | 重连超过最大次数 | 重连失败 4 次 | 第 4 次重连 | 返回 410 Gone，前端提示手动重试 | P2 |
| `T-CV-045` | ping 心跳保活 | 流式输出中无新 token | — | 每 15 秒收到 ping 事件，SSE 连接不超时断开 | P1 |
