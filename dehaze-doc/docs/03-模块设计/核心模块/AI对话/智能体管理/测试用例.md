# AI 对话模块测试用例 — 智能体管理 (F-M08-011)

## 1. 测试目标

- [x] 验证 Agent 配置管理（CRUD / 类型 / 启停 / 复制 / 测试）
- [x] 验证三级参数继承（系统默认 → Agent 配置 → 会话级覆盖）
- [x] 验证子 Agent 协作（独立上下文 / 不继承 / 防递归 / 优先级 / 并行）
- [x] 验证 Team 团队协作（Lead/Member 编排 / 并行 / 消耗归集）
- [x] 验证版本管理与发布（草稿 / 发布 / 回滚 / 会话版本锚定）
- [x] 验证发布门禁触发（评测集回归由 Agent 评测模块承载，见 [Agent评测/测试用例.md](../Agent评测/测试用例.md)）
- [x] 验证安全护栏（输入/输出拦截、PII 脱敏、越权检测）
- [x] 验证权限与数据隔离（文件系统权限 / 子 Agent 权限隔离 / 工具白名单）
- [x] 验证会话级选择与内置默认 Agent
- [x] 验证 A2A 协议（服务端暴露 / 客户端调用 / 端点注册）

## 2. 测试前置

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **测试 Agent** | 普通 Agent（`test_agent_default`）、子 Agent（`test_agent_sub_analysis`）、Team Lead（`test_agent_team`）、禁用 Agent | 覆盖三种类型与状态 |
| **测试 Skills / MCP** | `test_skill_report`、命名空间 `test_ns` | 关联验证 |
| **测试用户** | 管理员（`ai:agent:manage`）、普通用户 | 权限与列表可见性验证 |
| **Mock LLM** | 模拟正常/超时/越权工具调用/PII 输出 | 子 Agent / Team / 护栏运行时验证 |
| **评测集样本** | 开发集/回归集/保留集各若干，含高风险样本 | 四维评分与门禁验证 |
| **Mock 外部 A2A Agent** | 提供 `agent.json` 与 `/a2a` 端点 | A2A 客户端/服务端验证 |

### 2.1 数据清理策略

- 测试 Agent 统一前缀 `test_agent_`，测试结束后软删除，`agent_code` 不复用
- 测试评测集前缀 `test_eval_`，测试结束后清理
- 外部 A2A 端点前缀 `test_endpoint_`，测试结束后清理
