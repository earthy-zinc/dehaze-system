## 3. 测试前置

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **测试图片** | 3 张不同类型的雾图（非均匀/均匀/薄雾） | 算法推荐多样性验证 |
| **用户记忆** | "用户常用 RIDCP"（语义记忆）+"习惯强度 60-80"（程序记忆） | 偏好融合验证 |
| **算法知识库** | RIDCP/FFA-Net/DCP 的适用场景和典型指标 | 知识检索验证 |

### 数据清理策略

- 测试定时任务统一前缀 `test_sched_`，测试结束后删除
- 测试会话前缀 `test_sc_conv_`，结束后软删除；测试图片使用临时文件，结束后清理

| `T-SC-003` | 用户偏好融合 | 用户记忆含"常用 RIDCP" | LLM 调 recommend_algorithm | RIDCP 匹配度提升（偏好加权），推荐理由含"根据您的使用习惯" | P0 |
| `T-SC-004` | 无用户记忆→纯特征推荐 | 新用户无记忆 | — | 仅基于图像特征 + 知识库推荐，不报错 | P1 |
| `T-SC-005` | 推荐理由自然语言解释 | LLM observe | — | 回复文本包含推荐算法名称 + 非空推荐理由（融合图像特征/算法知识/用户偏好），reason 字段非空 | P1 |
| `T-SC-006` | 推荐结果置信度排序 | 返回 Top 3 | — | 第 1 名匹配度 > 第 2 名 > 第 3 名 | P1 |
| `T-SC-007` | 推荐结果数据结构完整性 | 推荐生成 | 查看 interrupt 事件 data.recommendation | 含 algorithm(id/name/description) + reason + params + match_score；含 alternatives 备选方案列表 | P1 |
| `T-SC-008` | 推荐参数验证 | 推荐结果 | 查看 recommendation.params | 含建议处理参数（如 strength/saturation），参数在算法合法范围内 | P1 |
| `T-SC-009` | 推荐结果注册为 artifact | 推荐结果生成后 | — | 产物记录创建（type=algorithm_recommend, ref_type=sys_recommendation），summary 含推荐算法/理由/匹配度/备选方案 | P1 |

| `T-SC-011` | 用户修改参数→发起处理 | 推荐结果展示中 | resume {confirmed:true, algorithm:"RIDCP", params:{strength:90}} | Agent 使用修改后参数发起处理 | P1 |
| `T-SC-012` | 采纳率统计 | 用户确认推荐 | — | 推荐管理模块更新 adopted_algorithm_id，统计采纳率 | P2 |

### 4.3 F-M06-009 定时调度

| 用例 ID | 测试场景 | 前置条件 | 输入 | 期望输出 | 优先级 |
|---------|---------|---------|------|---------|--------|
| `T-SC-050` | 创建定时任务（Cron 配置） | VIP2 用户 | 指定 Cron 表达式 + 输入来源（固定/动态拉取）+ 输出目标 | 任务创建成功，任务列表按下次触发时间排序 | P0 |
| `T-SC-051` | 任务自动执行 | 已创建定时任务 | 到达触发时间 | 以系统身份发起对话执行（复用多步推理），结果通过消息推送/回调通知用户 | P0 |
| `T-SC-052` | 失败重试（指数退避） | 任务执行失败 | — | 按指数退避重试 3 次，仍失败则记录失败原因并通知用户 | P1 |

| `T-SC-054` | 权限限制 | 普通用户（非 VIP2+） | 创建定时任务 | 拒绝创建，提示"定时调度仅 VIP2 及以上用户可用" | P1 |
| `T-SC-055` | 配额不足跳过执行 | 用户配额不足 | 到达触发时间 | 跳过本次执行并通知用户，不产生计费 | P1 |
| `T-SC-056` | 执行历史查询 | 含历史执行记录 | 查询执行历史 | 返回每次执行的结果/消耗/耗时/失败原因，保留 30 天 | P2 |
