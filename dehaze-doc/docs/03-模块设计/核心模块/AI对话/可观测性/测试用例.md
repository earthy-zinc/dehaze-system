# AI 对话模块测试用例 — 可观测性 (F-M08-013)

## 1. 测试目标

- [x] 验证过程链记录（`sys_ai_trace` 成功/失败/中断写入与幂等）
- [x] 验证上下文快照（构成项/占比/压缩事件）
- [x] 验证能力调用观测（复用推理步骤：工具/失败原因/重试）
- [x] 验证资源消耗汇总与计费口径一致
- [x] 验证异常标注、审计检索/导出与权限隔离
- [x] 验证防循环观测、保留策略、指标与告警规则
- [ ] 验证子 Agent 归属（agent_code/is_subagent）、error_detail 异常详情、中断恢复（resume）留痕与详情计费/产物关联
- [ ] 验证供应商物理调用尝试明细（attempts：逐 Key 重试/路由降级/熔断跳过）与旁路调用独立过程链（bypass_span/trace_type）

## 2. 测试前置

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **测试会话** | 含多轮历史 + 记忆注入 + 知识库检索的会话 | 验证上下文快照构成 |
| **测试消息** | 正常完成、工具失败重试、用户中断、超时各若干 | 验证状态与异常标注 |
| **Mock LLM** | 可控制流式输出与 tool_calls | 验证过程记录随执行写入 |
