# AI 对话模块测试用例 — 上下文管理 (F-M08-003)

## 1. 测试目标

- [x] 验证提示词工程（系统提示词稳定层/变量层组装、场景模板、结构化规范、优化闭环）
- [x] 验证短期记忆管理（对话历史摘要压缩、工作记忆、任务状态维护）
- [x] 验证长期记忆管理（三子类型存储/检索注入/重要性评分/遗忘曲线/反思整合/合并去重）
- [x] 验证长期记忆隐私合规（可见性/敏感信息过滤/批量清空/导出/注入可见性）
- [x] 验证 artifacts 引用化（产物注册/多态引用/is_invalid/URL 不落库）
- [x] 验证上下文组装（system_prompt+摘要+记忆注入+最近消息）

## 2. 测试前置

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **长对话会话** | 30 轮对话（token 超 70% 阈值） | 触发摘要压缩 |
| **记忆数据** | 用户含 20 条不同类型的记忆（episodic/semantic/procedural） | 检索和遗忘测试 |
| **产物数据** | 5 条 artifact（image_result×2 + metric_report×2 + file_ref×1） | 引用化和失效测试 |
| **提示词数据** | 平台稳定层提示词 + 多个 Agent 人设 + 各场景默认模板 + 负反馈标签数据 | 分层组装、场景模板、优化闭环测试 |

### 2.1 数据清理策略

- 测试记忆统一打标 `source=test`，测试结束后软删除并归档，不参与线上检索
- 测试产物随关联会话级联清理；会话前缀 `test_ctx_conv_`，结束后软删除
