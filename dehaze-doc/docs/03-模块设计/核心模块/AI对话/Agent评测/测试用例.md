# AI 对话模块测试用例 — Agent 评测 (F-M08-014)

## 1. 测试目标

- [x] 验证评测集/样本管理（分层、CRUD、去重）
- [x] 验证评测执行（四维评分 / 门禁判定 / 配额隔离 / 执行隔离）
- [x] 验证发布门禁（通过 / 阻断 / 高风险硬阻断 / 豁免）
- [x] 验证评测报告（版本对比 / 历史趋势）
- [x] 验证生产持续评估（定时回归 / 线上抽样 / 退化告警）
- [x] 验证 Bad Case 回流与结果可信（pass@k）
- [x] 验证判分治理（一致性验证 / 偏见缓解 / 漂移校准 / 人工复核）
- [x] 验证评测成本控制（失败快停 / 增量评测 / 预算上限 / 断点续跑）

> 评测接口见 [API接口.md](../API接口.md) §2.6。

## 2. 测试前置

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **评测 Agent** | 含配置/版本的智能体 | 评测对象 |
| **评测集样本** | 开发集/回归集/保留集各若干，含高风险样本 | 四维评分与门禁验证 |
| **Mock LLM** | 可控流式输出与 tool_calls | 评测执行链路 |
| **判分模型** | 本地 LLM（温度 0） | 评分一致性 |

### 2.1 数据清理策略

- 测试评测集前缀 `test_eval_`，测试结束后清理；评测产生的会话与消耗不污染生产数据

## 4. 关键边界与异常

| 用例 ID | 测试场景 | 输入 | 期望行为 |
|---------|---------|------|---------|
| `T-EVAL-060` | 样本含敏感信息 | 生产数据未脱敏 | 回流前强制脱敏，敏感信息不进入评测集 |
| `T-EVAL-061` | 判分模型不可用 | 本地 LLM 异常 | 评测失败且明确告警，不静默通过 |
| `T-EVAL-062` | 空评测集触发 | 回归集无样本 | 拒绝执行并提示先维护样本 |
| `T-EVAL-063` | 评测中断恢复 | 执行中服务重启 | 未完成 eval_run 保留进度，可断点续跑 |
| `T-EVAL-064` | 判分一致性验证 | 人工标注样本集 | 验证判分模型 | 与人工判定一致率 ≥ 90% 方可启用，不达标拒绝 |
| `T-EVAL-065` | 判分漂移校准 | 人工复核不一致率超阈值 | 触发校准 | 告警并暂停依赖其的门禁判定 |
| `T-EVAL-066` | 评测预算超限 | 单次消耗超预算 | 评测执行 | 终止并告警，防成本失控 |
| `T-EVAL-067` | 人工复核通道 | 线上抽样结果 | 抽 1% 复核 | 复核结果回填，用于判分模型校准 |
