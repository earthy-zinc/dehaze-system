### 4.2 ReAct 范式

| 用例 ID | 测试场景 | 前置条件 | 输入 | 期望输出 | 优先级 |
|---------|---------|---------|------|---------|--------|
| `T-RS-010` | 单步工具调用 | — | "用 RIDCP 去雾这张图" | understand→tool_call(predict_dehaze)→observe→回复 | P0 |
| `T-RS-011` | 多步工具调用（串行依赖） | 去雾完成后需评估 | "去雾并评估" | 去雾→等待完成→评估→回复摘要 | P0 |

### 4.4 Reflexion 范式

| 用例 ID | 测试场景 | 前置条件 | 输入 | 期望输出 | 优先级 |
|---------|---------|---------|------|---------|--------|
| `T-RS-030` | 执行→自评估 | — | "生成评估报告" | Executor 执行 → Evaluator 评分（LLM+规则+工具验证） | P1 |
| `T-RS-031` | 不达标→反思改进 | Evaluator 评分 0.6（< 0.8） | 触发 Reflexion | Reflector 分析失败原因 → 生成改进策略 → 重新执行 | P1 |

| `T-RS-033` | 最多 3 次迭代 | 3 次迭代后仍不达标 | — | 停止迭代，返回最优结果 + 警告"已尽力优化" | P1 |
| `T-RS-034` | 反思结果存入记忆 | 反思完成 | — | sys_ai_memory 写入反思结果（source=reflection），后续类似任务复用 | P1 |

### 4.5 中断与恢复

| 用例 ID | 测试场景 | 前置条件 | 输入 | 期望输出 | 优先级 |
|---------|---------|---------|------|---------|--------|
| `T-RS-040` | 算法选择确认中断 | LLM 推荐 3 个算法 | interrupt(type=confirm, data={algorithms}) | SSE 推送 interrupt 事件，前端渲染确认卡片，推理暂停 | P0 |
| `T-RS-041` | 确认后 resume | interrupt 暂停中 | POST /messages {resume:{confirmed:true,algorithm:"RIDCP"}} | LangGraph resume 恢复，state 注入用户选择，继续推理 | P0 |

## 5. 关键边界与异常

| 用例 ID | 测试场景 | 输入 | 期望行为 |
|---------|---------|------|---------|
| `T-RS-060` | 空 messages 启动 Agent | state.messages=[] | 返回错误或空回复 |
| `T-RS-061` | 工具返回超大结果（>100KB） | tools/call 返回超大 JSON | 截断为摘要（ResponseTruncator），不阻塞推理 |
| `T-RS-062` | 并发 resume（幂等） | 同一次 interrupt 两次 resume 请求 | 第二次幂等返回（已在执行中）或 409 |
