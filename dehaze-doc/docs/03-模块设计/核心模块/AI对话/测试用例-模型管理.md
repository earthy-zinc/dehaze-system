# AI 对话模块测试用例 — 模型管理 (F-M08-007)

## 1. 测试目标

- [x] 验证模型配置管理（CRUD/能力标识/不可变字段校验）
- [x] 验证供应商与 API Key 管理（连通性测试/哈希查重/优先级权重选取/失败冷却）
- [x] 验证供应商健康与容错（健康状态机/熔断/同模型备用供应商切换）
- [x] 验证模型生命周期（禁用/下线/替换迁移）
- [x] 验证模型路由与降级（主模型不可用→fallback 模型）
- [x] 验证 Prompt Caching 优化（稳定前缀/缓存命中/cached_rate 计费）
- [x] 验证结构化输出校验（JSON Schema 校验）
- [x] 验证降级计费（降级模型按 fallback 价格计费）
- [x] 验证上下文校验（超限压缩/压缩仍超限拒绝）

## 2. 测试前置

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **测试供应商** | openai（健康）、mock-provider（Mock LLM API，可配置返回 429/5xx/超时） | 供应商健康与熔断验证 |
| **测试模型** | gpt-4o-mini（主，fallback=claude-3-5-haiku）、claude-3-5-haiku（降级）、gpt-4o（无降级）、gpt-4o-mini@mock（同模型备用供应商，仅 mock-provider 上） | 降级链、备用供应商验证 |
| **Mock LLM API** | 模拟 429/5xx/超时 等异常响应；支持模型列表接口（GET /models）供连通性测试 | 降级触发与连通性验证 |

### 2.1 数据清理策略

- 测试模型配置统一前缀 `test_model_`，测试结束后软删除，model_id 不复用
- 测试供应商统一前缀 `test_provider_`，测试结束后软删除，provider_code 不复用
- 测试 Key 测试结束后物理删除
