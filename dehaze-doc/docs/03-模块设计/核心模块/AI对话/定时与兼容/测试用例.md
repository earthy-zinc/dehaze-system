## 1. 测试目标

- [x] 验证定时调度（F-M08-009 任务 CRUD、触发执行、执行可靠性）

| 用例 ID | 测试场景 | 输入 | 期望行为 |
|---------|---------|------|---------|
| `T-SC-070` | 服务重启不重复执行 | 任务执行后服务重启，调度器再次扫描同窗口 | 幂等键数据库约束兜底，同窗口不重复执行 |
| `T-SC-071` | 手动触发受幂等约束 | 手动触发与自动触发落在同一窗口 | 同窗口只执行一次 |
| `T-SC-072` | 任务删除后不再触发 | 任务被删除（软删除）后到达触发时间 | 不执行，不产生执行记录 |
