# 算法选择模块需求规格

## 1. 模块概述

### 1.1 模块定位

算法选择模块帮助用户从众多去雾算法中快速找到合适的算法。通过树形分类、智能推荐、搜索筛选等方式，降低用户的选择门槛。

### 1.2 核心价值

| 价值维度 | 具体内容 |
|---------|---------|
| **智能化** | 基于图像特征自动推荐最优算法 |
| **结构化** | 树形算法分类，清晰的层级展示 |
| **可搜索** | 支持关键词、拼音、英文缩写等多种搜索方式 |
| **个性化** | 支持算法收藏和个人偏好记忆 |

### 1.3 用户角色分析

| 用户类型 | 特征 | 使用偏好 | 功能需求 |
|---------|------|---------|---------|
| **轻度用户** | 对算法不了解 | 完全依赖推荐 | 一键使用推荐算法 |
| **中度用户** | 了解基本类型 | 参考推荐+自主浏览 | 推荐+分类浏览+简单筛选 |
| **重度用户** | 算法专家 | 精准搜索+对比 | 高级筛选+参数调优+性能对比 |

### 1.4 依赖的基础模块

| 模块 | 依赖说明 |
|------|---------|
| **推荐管理** | 算法推荐（F-REC-001、F-REC-002）替代原有的内置智能推荐逻辑 |
| **收藏管理** | 算法收藏，targetType="algorithm" |
| **会员管理** | VIP 用户可访问实验性算法、查看更多推荐候选 |

### 2.1 树形算法结构 (F-M03-001)

```

│   │   ├── 边界约束与上下文正则化 (BCCR)
│   │   └── 改进型暗通道先验 (RIDCP)
│   ├── 基于图像增强
│   │   ├── 直方图均衡化

│   │   └── 同态滤波
│   └── 基于融合
│       ├── 多尺度融合
│       └── 拉普拉斯金字塔融合

├── 深度学习算法
│   ├── CNN 系列
│   │   ├── DehazeNet
│   │   ├── AOD-Net
│   │   ├── GridDehazeNet
```

#### 2.1.2 树形展示

- 层级缩进：每级 24px
- 分类节点与算法节点使用不同图标区分
- 点击展开/收起子节点
- 选中节点高亮显示

#### 2.1.3 算法卡片信息

| 类别 | 内容 |
|------|------|
| 基础信息 | 算法名称（中英文）、算法类型标签、评分、推荐指数 |
| 性能指标 | 处理速度（快/中/慢）、效果质量（优/良/中）、适用场景（轻度/中度/重度雾霾） |
| 快捷操作 | 查看详情、收藏、立即使用 |

### 2.2 算法推荐 (F-M03-002)

#### 2.2.1 功能描述

算法推荐能力由[推荐管理模块](../../基础模块/推荐管理/需求规格.md)提供。用户上传图片后，系统自动分析图像特征并生成 Top 3 推荐算法列表。

推荐功能引用推荐管理模块的以下功能点：
- F-REC-001：图像特征分析（雾霾浓度、场景类型、光照条件等）
- F-REC-002：算法推荐（基于特征匹配，输出推荐列表含匹配度和推荐理由）

#### 2.2.2 推荐展示

推荐区域显示：
- 图像分析结果（雾霾程度、场景类型）
- Top 3 推荐算法列表
- 每个推荐算法展示：匹配度、算法名称、评分、推荐理由、预期效果、操作按钮（一键使用、查看详情、收藏）

---

### 2.3 搜索与筛选 (F-M03-003)

#### 2.3.1 搜索功能

| 搜索方式 | 说明 |
|---------|------|
| 关键词搜索 | 算法名称、标签、描述 |
| 拼音搜索 | 支持全拼和首字母 |
| 英文缩写搜索 | 如 DCP → Dark Channel Prior |
| 组合搜索 | 多关键词 AND 逻辑 |

搜索框显示热门搜索标签和最近 10 条搜索历史，支持删除单条历史或清空全部历史。

#### 2.3.2 筛选功能

| 筛选项 | 选项 | 选择方式 |
|-------|------|---------|
| 算法类型 | 传统/深度学习/混合 | 多选 |
| 处理速度 | 快/中/慢 | 单选 |
| 效果质量 | 优/良/中 | 单选 |
| 适用场景 | 轻度/中度/重度雾霾 | 多选 |
| 评分范围 | 1-5 星 | 滑动条 |

筛选面板支持重置筛选条件和保存筛选方案，并显示筛选结果数量。

---

### 2.4 算法详情页 (F-M03-004)

#### 2.4.1 详情页结构

详情页左侧提供导航锚点（基本信息、算法描述、效果样例、参数配置、性能指标、用户评价），右侧展示对应内容。

#### 2.4.2 效果样例展示

**对比方式**：并排对比（左右）、上下对比、滑动对比（拖动分界线）、叠加对比（透明度调节）。

**样例组织**：按场景分类（城市/风景/建筑/夜景）、按雾霾程度（轻度/中度/重度）。

#### 2.4.3 上传自定义图片测试

用户可在算法详情页上传自定义图片进行效果预览。系统使用该算法对上传图片执行处理并展示结果，帮助用户在正式使用前评估算法效果。

---

### 2.5 算法收藏 (F-M03-005)

#### 2.5.1 功能描述

算法收藏能力由[收藏管理模块](../../基础模块/收藏管理/需求规格.md)统一管理：

- 收藏类型：`algorithm`（算法）
- 收藏入口：算法卡片收藏按钮、算法详情页收藏按钮
- 取消收藏：再次点击已收藏图标或收藏列表中操作
- 收藏列表：可在"我的收藏"聚合页按类型筛选查看

#### 2.5.2 交互规则

| 场景 | 行为 |
|------|------|
| 未收藏 → 点击收藏 | 图标变为实心，提示"已添加到收藏" |
| 已收藏 → 点击取消 | 图标变为空心，提示"已取消收藏" |
| 收藏容量已满 | 提示上限并引导升级会员 |
| 算法已失效 | 收藏列表中标记为"已失效"，支持一键清理 |

---

### 2.6 算法对比 (F-M03-006)

#### 2.6.1 功能描述

支持同时选择 2-3 个算法进行多维度对比，帮助用户在多个候选算法中做出选择。

#### 2.6.2 对比方式

长按算法卡片进入多选模式，最多选择 3 个算法，点击"对比"按钮进入对比页面。

#### 2.6.3 对比维度

| 维度 | 展示形式 |
|------|---------|
| 基本信息对比 | 表格展示 |
| 性能指标对比 | 柱状图 |
| 适用性对比 | 雷达图 |
| 用户反馈对比 | 饼图 |
| 效果样例对比 | 并排展示 |

#### 2.6.4 对比页面

提供综合对比、效果对比、评价三个 Tab 视图。综合对比使用表格展示算法基本信息、处理速度、效果质量、平均时间、成功率、内存占用、用户评分等指标，下方显示各算法优势和推荐建议，提供直接使用按钮。

## 3. 用户交互流程

### 3.1 快捷流程（智能推荐）

用户上传图像 → 自动分析图像特征 → 生成 Top 3 推荐 → 用户点击"立即使用" → 跳转到处理页面。总耗时 < 5 秒，仅需 1 次点击。

### 3.2 标准流程（浏览选择）

用户上传图像 → 进入算法选择页面 → 查看推荐（可选） → 浏览算法树 → 展开分类 → 点击算法卡片 → 查看详情和样例 → 调整参数（可选） → 确认使用 → 跳转到处理页面。

### 3.3 专家流程（对比选择）

用户上传图像 → 使用搜索/筛选 → 长按进入多选模式 → 选择 2-3 个算法 → 查看详细对比 → 分析优劣势 → 配置高级参数 → 确认使用 → 跳转到处理页面。

## 4. 会员权益

### 4.1 等级差异

算法选择模块的会员权益由[会员管理模块](../../基础模块/会员管理/需求规格.md)统一管理：

| 权益项 | 普通用户 | VIP 用户 |
|--------|---------|---------|
| 可访问算法范围 | 标准算法 | 标准算法 + 实验性算法 |
| 推荐候选数量 | Top 3 | Top 5 |
| 算法对比数量 | 最多 2 个 | 最多 3 个 |
| 自定义图片测试 | 是 | 是 |

## 5. 收藏管理集成

算法收藏由[收藏管理模块](../../基础模块/收藏管理/需求规格.md)统一管理：

- 收藏类型：`algorithm`（算法）
- 收藏操作：引用 F-FAV-001
- 收藏列表：在"我的收藏"聚合页中按类型筛选查看

---

## 6. 推荐管理集成

算法推荐由[推荐管理模块](../../基础模块/推荐管理/需求规格.md)统一管理：

- 图像特征分析：F-REC-001
- 算法推荐生成：F-REC-002
- 推荐反馈：F-REC-003
- 推荐效果持续优化，用户采纳和评价数据反哺推荐引擎
