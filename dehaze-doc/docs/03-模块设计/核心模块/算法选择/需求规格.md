# 算法选择模块需求规格

## 1. 模块概述

### 1.1 模块定位

算法选择模块是图像去雾系统的智能核心，通过树形结构、智能推荐、搜索筛选等方式，帮助用户快速找到最合适的去雾算法。

### 1.2 核心价值

- **智能化**：基于图像特征自动推荐最优算法
- **专业性**：提供详细的算法信息和参数配置
- **结构化**：树形算法分类，清晰的层级展示
- **个性化**：记忆用户偏好，学习使用习惯

### 1.3 用户角色分析

| 用户类型 | 特征 | 使用偏好 | 功能需求 |
|---------|------|---------|---------|
| **轻度用户** | 对算法不了解 | 完全依赖推荐 | 一键使用推荐算法 |
| **中度用户** | 了解基本类型 | 参考推荐+自主浏览 | 推荐+分类浏览+简单筛选 |
| **重度用户** | 算法专家 | 精准搜索+对比 | 高级筛选+参数调优+性能对比 |
| **企业用户** | 批量处理 | 收藏常用算法 | 收藏管理+批量应用 |

### 2.2 智能推荐功能 (F-M03-002)

#### 2.2.1 推荐策略

**图像特征分析维度**

| 特征维度 | 分析方法 | 权重 |
|---------|---------|-----|
| **雾霾浓度** | 暗通道统计分析 | 30% |
| **场景类型** | 场景分类CNN模型 | 20% |
| **光照条件** | 直方图分析+亮度统计 | 15% |
| **图像复杂度** | 边缘密度+纹理分析 | 10% |
| **颜色分布** | 色彩空间分析 | 10% |
| **分辨率** | 图像尺寸 | 5% |
| **用户偏好** | 历史记录分析 | 10% |

**推荐场景规则**

| 场景特征 | 推荐算法 | 推荐理由 |
|---------|---------|---------|
| 轻度城市雾霾 | DCP, CAP, AOD-Net | 速度快，效果自然 |
| 中度风景雾霾 | AOD-Net, FFA-Net, GridDehazeNet | 平衡效果和速度 |
| 重度建筑雾霾 | DehazeFormer, GridDehazeNet, MSBDN | 处理能力强 |
| 夜景雾霾 | Retinex+CNN, 低光增强+去雾 | 亮度增强+去雾 |
| 逆光场景 | HDR+去雾, Restormer | 先处理曝光 |

#### 2.2.2 推荐展示

推荐区域显示图像分析结果（雾霾程度、场景类型、推荐策略）和Top 3推荐算法列表。每个推荐算法显示匹配度、算法名称、评分、推荐理由、预期效果（处理时间、图像质量、成功率）和操作按钮（立即使用、详情、收藏）。

### 2.3 搜索与筛选功能 (F-M03-003)

#### 2.3.1 搜索功能

**搜索方式**

- 关键词搜索：算法名称、标签、描述
- 拼音搜索：支持首字母+全拼
- 英文缩写：DCP → Dark Channel Prior
- 标签搜索：#深度学习
- 组合搜索：多关键词AND逻辑

**搜索体验**

搜索框提供关键词、拼音、英文缩写和标签搜索功能，支持组合搜索。显示热门搜索标签和最近10条搜索历史，支持删除单条历史或清空全部历史。

#### 2.3.2 筛选功能

**筛选维度**

| 筛选项 | 选项 | 类型 |
|-------|------|-----|
| 算法类型 | 传统/深度学习/混合 | 多选 |
| 处理速度 | 快/中/慢 | 单选 |
| 效果质量 | 优/良/中 | 单选 |
| 适用场景 | 轻度/中度/重度雾霾 | 多选 |
| 评分范围 | 1-5星 | 滑动条 |

**筛选面板**

提供算法类型（多选）、处理速度（单选）、效果质量（单选）、适用场景（多选）、评分范围（滑动条）等筛选维度，支持重置筛选条件、保存筛选方案，并显示筛选结果数量。

### 2.4 算法详情页 (F-M03-004)

#### 2.4.1 详情页结构

详情页左侧提供导航锚点（基本信息、算法描述、效果样例、参数配置、性能指标、用户评价、相关链接、版本历史），右侧展示对应内容。

#### 2.4.2 效果样例展示

**对比方式**
- 并排对比（左右）
- 上下对比
- 滑动对比（拖动分界线）
- 叠加对比（透明度调节）

**样例组织**
- 按场景分类：城市/风景/建筑/夜景
- 按雾霾程度：轻度/中度/重度
- 支持上传自定义图片测试

---

### 2.5 算法收藏功能 (F-M03-005)

#### 2.5.1 收藏操作

**添加收藏**
- 算法卡片/详情页的收藏按钮
- 图标变化：🤍 → ❤️
- Toast提示："已添加到收藏"

**取消收藏**
- 再次点击收藏按钮
- 收藏列表中左滑删除（移动端）
- 确认对话框："确定要取消收藏吗?"

#### 2.5.2 收藏列表

收藏列表显示收藏数量，提供编辑和全部删除操作，支持按收藏时间、使用频率、算法评分排序，以及网格和列表两种显示方式。每个收藏项显示算法名称、评分、使用次数、收藏时间和使用/删除操作按钮。

---

### 2.6 算法对比功能 (F-M03-006)

#### 2.6.1 对比方式

**选择算法**
- 长按算法卡片进入多选模式
- 最多选择3个算法
- 点击"对比 (3)"按钮

**对比维度**
- 基本信息对比：表格展示
- 性能指标对比：柱状图
- 适用性对比：雷达图
- 用户反馈对比：饼图
- 效果样例对比：并排展示

#### 2.6.2 对比页面

对比页面提供添加、保存和关闭操作，通过Tab切换综合对比、效果对比、评价三个视图。综合对比使用表格展示算法基本信息、处理速度、效果质量、平均时间、成功率、内存占用、用户评分等指标，下方显示各算法优势和推荐建议，提供直接使用按钮。

## 3. 用户交互流程

### 3.1 快捷流程（智能推荐）

```
用户上传图像
  ↓ (< 1s)
自动分析图像特征
  ↓ (< 2s)
生成Top 3推荐
  ↓
用户点击"立即使用"
  ↓ (< 0.5s)
跳转到处理页面

总耗时：< 5秒，仅1次点击
```

### 3.2 标准流程（浏览选择）

```
用户上传图像 → 进入算法选择页面
  ↓
查看推荐（可选） → 浏览算法树
  ↓
展开分类 → 点击算法卡片
  ↓
查看详情 → 阅读描述和样例
  ↓
调整参数（可选） → 确认使用
  ↓
跳转到处理页面

总耗时：< 30秒，3-5次点击
```

### 3.3 专家流程（对比选择）

```
用户上传图像 → 使用搜索/筛选
  ↓
长按进入多选模式 → 选择2-3个算法
  ↓
查看详细对比 → 分析优劣势
  ↓
配置高级参数 → 确认使用
  ↓
跳转到处理页面

总耗时：1-2分钟，6-10次点击
```
