# 算法选择模块 - 前端实现设计

## 1. 文档概述

本文档描述算法选择模块的前端实现方案，聚焦组件架构、状态管理、路由设计等架构决策。算法选择模块是用户选择算法的核心入口，提供树形浏览、智能推荐、关键词/拼音搜索和算法对比功能。

---

## 2. 组件设计

### 2.1 组件结构

```
算法选择模块
├── AlgorithmSelectionPage       # 算法选择主页面
│   ├── RecommendationPanel      # 智能推荐面板
│   │   ├── ImageUploadArea      # 上传图片获取推荐
│   │   ├── FeatureAnalysis      # 图像特征分析结果展示
│   │   └── RecommendList        # Top 3 推荐算法卡片
│   ├── AlgorithmTree            # 算法树形导航（复用算法管理模块组件）
│   ├── AlgorithmSearchBar       # 搜索栏（关键词/拼音/类型/描述）
│   ├── AlgorithmListView        # 算法列表/网格视图
│   │   ├── AlgorithmCard        # 算法卡片（名称/类型/评分/使用次数/快捷操作）
│   │   └── ViewModeToggle       # 列表/网格切换
│   ├── AlgorithmDetail          # 算法详情弹窗
│   │   ├── BasicInfoSection     # 基本信息（名称/类型/版本/模型大小/参数量/FLOPs）
│   │   ├── SampleGallery        # 效果样例图（最近3条预测结果）
│   │   ├── RatingSection        # 评分与使用次数
│   │   └── ActionButtons        # 操作按钮（立即使用/收藏/自定义测试）
│   ├── AlgorithmComparison      # 算法对比面板
│   │   ├── ComparisonSelector   # 对比算法选择（上限3个）
│   │   └── ResultComparison     # 处理结果并排对比（结果图+耗时+指标）
│   ├── FavoriteButton           # 收藏按钮（复用收藏管理模块组件）
│   └── CustomTestDialog         # 自定义测试弹窗
│       ├── TestImageUpload      # 测试图片上传
│       └── TestResult           # 测试结果展示
```

### 2.2 组件职责

| 组件 | 职责 | 复用性 |
|------|------|--------|
| AlgorithmSelectionPage | 页面容器，路由入口，管理推荐/搜索/对比全局状态 | 不可复用 |
| RecommendationPanel | 上传图片获取智能推荐，展示特征分析和 Top 3 推荐 | 可复用于图像输入模块快速体验 |
| AlgorithmTree | 算法树形导航，按分类层级展开（仅已发布） | 复用算法管理模块 AlgorithmTree 组件 |
| AlgorithmSearchBar | 关键词/拼音/类型/描述搜索 | 可复用 |
| AlgorithmListView | 算法列表/网格视图切换 | 可复用 |
| AlgorithmCard | 算法卡片信息展示 | 可复用 |
| AlgorithmDetail | 算法详情弹窗，含样例、评分、使用次数 | 可复用 |
| AlgorithmComparison | 多算法处理结果对比（上限3个） | 不可复用 |
| FavoriteButton | 收藏按钮 | 高度可复用（收藏管理模块） |
| CustomTestDialog | 上传自定义图片测试算法效果 | 不可复用 |

## 3. 页面布局设计

### 3.1 页面结构

采用**左侧导航+右侧内容**的双栏布局：

| 区域 | 宽度 | 说明 |
|------|------|------|
| 左侧导航 | 260px | 算法树形导航（可折叠） |
| 右侧内容 | 自适应填充 | 推荐面板（可收起）+ 算法列表 |

### 3.2 响应式布局

| 屏幕尺寸 | 布局方式 |
|---------|---------|
| 桌面端（>=992px） | 左侧固定宽度，右侧自适应 |
| 移动端（<992px） | 左侧导航抽屉式展开，算法列表切换为卡片视图 |

### 3.3 路由设计

| 路由路径 | 页面 | 说明 |
|---------|------|------|
| /algorithm-selection | AlgorithmSelectionPage | 算法选择主页 |
| /algorithm-selection?imageId=xxx | AlgorithmSelectionPage | 携带图片ID，自动触发推荐 |

路由参数说明：
- `imageId`：从图像输入模块传入，自动分析图片特征并展示推荐结果

## 4. 状态管理

### 4.1 状态定义

| Store | 职责 |
|-------|------|
| algorithmSelectionStore | 推荐结果、搜索状态、选中算法、对比列表 |

### 4.2 algorithmSelectionStore 核心状态

| 状态字段 | 类型 | 说明 |
|---------|------|------|
| selectedAlgorithm | object | 当前选中的算法 |
| imageFeatures | object | 图像特征分析结果（如有上传图片） |
| recommendResults | array | Top 3 推荐算法列表 |
| recommendLoading | boolean | 推荐请求加载状态 |
| searchKeyword | string | 当前搜索关键词 |
| searchResults | array | 搜索结果列表 |
| algorithmTree | array | 算法树形数据 |
| viewMode | list/grid | 列表/网格视图 |
| comparisonList | array | 对比列表（上限3个算法） |
| comparisonMaxReached | boolean | 是否达到对比上限 |

### 4.3 algorithmSelectionStore Actions

| 方法 | 说明 |
|------|------|
| fetchRecommendations(imageId) | 上传图片获取算法推荐 |
| fetchAlgorithmTree() | 获取算法树形列表 |
| searchAlgorithms(keyword) | 关键词搜索算法 |
| selectAlgorithm(algorithm) | 选中算法 |
| getAlgorithmDetail(id) | 获取算法详情 |
| addToComparison(algorithm) | 添加算法到对比列表 |
| removeFromComparison(id) | 从对比列表移除算法 |
| clearComparison() | 清空对比列表 |
| setViewMode(mode) | 切换列表/网格视图 |
| useAlgorithm(algorithmId) | 确认使用算法，跳转处理页面 |

## 5. 数据流

### 5.1 智能推荐流程

```
用户上传图片（或从 imageId 加载）
    ↓
调用 fetchRecommendations(imageId)
    ↓
后端分析图像特征（规则引擎，雾霾浓度/场景/光照等）
    ↓ 返回特征分析结果 + Top 3 推荐算法
展示推荐面板：
  - 图像特征摘要（雾霾程度/场景类型）
  - 3个推荐算法卡片（匹配度/推荐理由/预期效果）
    ↓
用户点击"立即使用" → 跳转处理页面（携带 algorithmId + recommendedBy）
用户点击"查看详情" → 打开算法详情弹窗
```

### 5.2 搜索流程

```
用户输入关键词
    ↓ 防抖 300ms
调用 searchAlgorithms(keyword)
    ↓
更新 searchResults → 展示搜索结果
    ↓
用户点击结果项 → 打开算法详情弹窗
```

### 5.3 对比流程

```
用户浏览算法列表 → 点击"加入对比"
    ↓
addToComparison(algorithm)
    ↓ 上限3个，达到上限时提示
对比列表更新 → 底部对比栏显示已选算法
    ↓
用户点击"开始对比" → 提交对比请求（携带测试图片）
    ↓
后端对同一图片分别执行各算法预测
    ↓
并排展示：处理结果图 + 耗时 + 评估指标
    ↓
用户选择最优算法 → 点击"立即使用" → 跳转处理页面
```

### 5.4 模块间数据交互

| 交互方向 | 数据 | 说明 |
|---------|------|------|
| 图像输入 → 算法选择 | imageId | 上传/拍照/样例/历史记录后跳转 |
| 算法选择 → 图像处理 | algorithmId | 选择算法后跳转处理页面 |
| 算法选择 → 收藏管理 | FavoriteButton | targetType=algorithm |
| 推荐管理 → 算法选择 | 推荐结果 | 推荐面板展示的数据由推荐管理模块提供 |
| 算法管理 → 算法选择 | 算法列表 | 已发布算法作为数据源 |

## 6. 关键交互决策

### 6.1 推荐结果展示形式

采用**卡片**形式展示 Top 3 推荐：

| 方案 | 选择理由 |
|------|---------|
| 卡片 | 视觉突出，信息密度适中，每个推荐算法独立呈现（匹配度+理由+操作） |
| 列表 | 信息密度低，不适合强调推荐排序 |

### 6.2 对比结果展示

对比结果以并排卡片展示各算法的处理结果图，下方列出处理耗时与评估指标（PSNR/SSIM）数值。

### 6.3 自定义测试结果展示

用户在算法详情中上传测试图片后，展示该算法处理后的结果，支持与原图并排对比（复用效果对比模块的对比组件）。

### 6.4 搜索防抖

搜索输入防抖 300ms。

## 7. 权限与会员控制

| 功能 | 说明 |
|------|------|
| 算法浏览 | 仅已发布算法（所有用户一致，无 VIP 专属） |
| 智能推荐 | 所有用户可用（Top 3 固定） |
| 关键词/拼音搜索 | 所有用户可用 |
| 算法对比 | 最多 3 个（所有用户一致） |
| 自定义测试 | 所有用户可用 |

## 8. 性能优化

| 优化项 | 实现方式 |
|--------|---------|
| 搜索防抖 | 输入防抖 300ms |
| 图片懒加载 | 算法样例图片使用懒加载 |
| 请求取消 | 切换页面时取消未完成请求 |

---

## 9. 错误处理

| 错误类型 | 处理方式 |
|---------|---------|
| 推荐分析失败 | 显示"分析失败，请重试"，可跳过推荐直接浏览算法 |
| 搜索无结果 | 显示空状态提示"未找到匹配的算法"，建议调整关键词 |
| 算法详情加载失败 | 显示错误提示 + 重试按钮 |
| 对比数据加载失败 | 显示错误提示，保留已加载的对比列 |
| 图片上传失败 | 显示上传失败提示 + 重试按钮 |
