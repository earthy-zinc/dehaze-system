# 算法选择模块 - 前端实现设计

## 1. 文档概述

本文档描述算法选择模块的前端实现方案，聚焦组件架构、状态管理、路由设计等架构决策。算法选择模块是用户选择去雾算法的核心入口，提供智能推荐、树形浏览、搜索筛选和算法对比功能。

---

## 2. 组件设计

### 2.1 组件结构

```
算法选择模块
├── AlgorithmSelectionPage       # 算法选择主页面
│   ├── RecommendationPanel      # 智能推荐面板
│   │   ├── ImageUploadArea      # 上传图片获取推荐
│   │   ├── FeatureAnalysis      # 图像特征分析结果展示
│   │   └── RecommendList        # Top 3 推荐算法卡片
│   ├── AlgorithmTree            # 算法树形导航（复用算法管理模块组件）
│   ├── AlgorithmSearchBar       # 搜索栏
│   │   ├── SearchInput          # 关键词/拼音/标签搜索
│   │   ├── SearchHistory        # 搜索历史
│   │   └── HotSearchTags        # 热门搜索标签
│   ├── AlgorithmFilterPanel     # 筛选面板
│   │   ├── TypeFilter           # 算法类型筛选（多选）
│   │   ├── SpeedFilter          # 处理速度筛选（单选）
│   │   ├── QualityFilter        # 效果质量筛选（单选）
│   │   ├── SceneFilter          # 适用场景筛选（多选）
│   │   └── RatingRange          # 评分范围滑动条
│   ├── AlgorithmListView        # 算法列表/网格视图
│   │   ├── AlgorithmCard        # 算法卡片（缩略图/名称/评分/推荐指数/快捷操作）
│   │   └── ViewModeToggle       # 列表/网格切换
│   ├── AlgorithmDetail          # 算法详情弹窗
│   │   ├── BasicInfoSection     # 基本信息（名称/类型/版本/推荐指数）
│   │   ├── SampleGallery        # 效果样例展示（并排/滑动/叠加对比）
│   │   ├── ParamConfig          # 参数配置预览
│   │   ├── PerformanceInfo      # 性能指标（速度/质量/资源消耗）
│   │   ├── ReviewSection        # 用户评价列表
│   │   └── ActionButtons        # 操作按钮（立即使用/收藏/对比）
│   ├── AlgorithmComparison      # 算法对比面板
│   │   ├── ComparisonSelector   # 对比算法选择（上限3个）
│   │   ├── ComparisonTable      # 多维度对比表格
│   │   ├── ComparisonChart      # 性能雷达图对比
│   │   └── SampleComparison     # 样例效果对比
│   ├── FavoriteButton           # 收藏按钮（复用收藏管理模块组件）
│   └── CustomTestDialog         # 自定义测试弹窗
│       ├── TestImageUpload      # 测试图片上传
│       ├── TestResult           # 测试结果展示
│       └── TestComparison       # 多算法测试结果对比
```

### 2.2 组件职责

| 组件 | 职责 | 复用性 |
|------|------|--------|
| AlgorithmSelectionPage | 页面容器，路由入口，管理推荐/搜索/筛选全局状态 | 不可复用 |
| RecommendationPanel | 上传图片获取智能推荐，展示特征分析和Top 3推荐 | 可复用于图像输入模块快速体验 |
| AlgorithmTree | 算法树形导航，按分类层级展开 | 复用算法管理模块 AlgorithmTree 组件 |
| AlgorithmSearchBar | 多模式搜索（关键词/拼音/标签），搜索历史管理 | 可复用 |
| AlgorithmFilterPanel | 多维度筛选面板，支持保存筛选方案 | 可复用 |
| AlgorithmListView | 算法列表/网格视图切换 | 可复用 |
| AlgorithmCard | 算法卡片信息展示 | 可复用 |
| AlgorithmDetail | 算法详情弹窗，含样例、评价、参数 | 可复用 |
| AlgorithmComparison | 多算法并排对比（上限3个） | 不可复用 |
| FavoriteButton | 收藏按钮 | 高度可复用（收藏管理模块） |
| CustomTestDialog | 上传自定义图片测试算法效果 | 不可复用 |

## 3. 页面布局设计

### 3.1 页面结构

采用**左侧导航+右侧内容**的双栏布局：

| 区域 | 宽度 | 说明 |
|------|------|------|
| 左侧导航 | 260px | 算法树形导航 + 筛选面板（可折叠） |
| 右侧内容 | 自适应填充 | 推荐面板（可收起）+ 算法列表 |

### 3.2 响应式布局

| 屏幕尺寸 | 布局方式 |
|---------|---------|
| 桌面端（>=992px） | 左侧固定宽度，右侧自适应 |
| 移动端（<992px） | 左侧导航抽屉式展开，算法列表切换为卡片视图 |

### 3.3 路由设计

| 路由路径 | 页面 | 说明 |
|---------|------|------|
| /algorithm-selection | AlgorithmSelectionPage | 算法选择主页 |
| /algorithm-selection?imageId=xxx | AlgorithmSelectionPage | 携带图片ID，自动触发推荐 |

路由参数说明：
- `imageId`：从图像输入模块传入，自动分析图片特征并展示推荐结果

## 4. 状态管理

### 4.1 状态定义

| Store | 职责 |
|-------|------|
| algorithmSelectionStore | 推荐结果、搜索状态、筛选条件、选中算法、对比列表 |

### 4.2 algorithmSelectionStore 核心状态

| 状态字段 | 类型 | 说明 |
|---------|------|------|
| activeTab | recommend/browse/search | 当前活跃功能Tab |
| selectedAlgorithm | object | 当前选中的算法 |
| imageFeatures | object | 图像特征分析结果（如有上传图片） |
| recommendResults | array | Top N推荐算法列表 |
| recommendLoading | boolean | 推荐请求加载状态 |
| searchKeyword | string | 当前搜索关键词 |
| searchResults | array | 搜索结果列表 |
| searchHistory | array | 最近10条搜索历史 |
| filterConditions | object | 当前筛选条件（类型/速度/质量/场景/评分） |
| algorithmList | array | 算法列表（分页） |
| viewMode | list/grid | 列表/网格视图 |
| comparisonList | array | 对比列表（上限3个算法） |
| comparisonMaxReached | boolean | 是否达到对比上限 |

### 4.3 algorithmSelectionStore Actions

| 方法 | 说明 |
|------|------|
| fetchRecommendations(imageId) | 上传图片获取算法推荐 |
| fetchAlgorithmTree() | 获取算法树形列表 |
| fetchAlgorithmList(params) | 获取算法分页列表（含筛选条件） |
| searchAlgorithms(keyword) | 关键词搜索算法 |
| addSearchHistory(keyword) | 添加搜索历史 |
| clearSearchHistory() | 清空搜索历史 |
| updateFilter(conditions) | 更新筛选条件 |
| resetFilter() | 重置筛选条件 |
| selectAlgorithm(algorithm) | 选中算法 |
| getAlgorithmDetail(id) | 获取算法详情 |
| addToComparison(algorithm) | 添加算法到对比列表 |
| removeFromComparison(id) | 从对比列表移除算法 |
| clearComparison() | 清空对比列表 |
| setViewMode(mode) | 切换列表/网格视图 |
| useAlgorithm(algorithmId) | 确认使用算法，跳转去雾处理页面 |

## 5. 数据流

### 5.1 智能推荐流程

```
用户上传图片（或从 imageId 加载）
    ↓
调用 fetchRecommendations(imageId)
    ↓
后端分析图像特征（雾霾浓度/场景/光照等）
    ↓ 返回特征分析结果 + Top 3 推荐算法
展示推荐面板：
  - 图像特征摘要（雾霾程度/场景类型）
  - 3个推荐算法卡片（匹配度/推荐理由/预期效果）
    ↓
用户点击"立即使用" → 跳转去雾处理页面（携带 algorithmId）
用户点击"查看详情" → 打开算法详情弹窗
```

### 5.2 搜索流程

```
用户输入关键词
    ↓ 防抖 300ms
调用 searchAlgorithms(keyword)
    ↓
更新 searchResults → 展示搜索结果
    ↓
用户点击结果项 → 打开算法详情弹窗
```

### 5.3 对比流程

```
用户浏览算法列表 → 点击"加入对比"
    ↓
addToComparison(algorithm)
    ↓ 上限3个，达到上限时提示
对比列表更新 → 底部对比栏显示已选算法
    ↓
用户点击"开始对比" → 打开对比面板
    ↓
并排展示：基本信息表格 + 性能雷达图 + 样例效果
    ↓
用户选择最优算法 → 点击"立即使用" → 跳转去雾处理
```

### 5.4 模块间数据交互

| 交互方向 | 数据 | 说明 |
|---------|------|------|
| 图像输入 → 算法选择 | imageId | 上传/拍照/样例/历史记录后跳转 |
| 算法选择 → 去雾处理 | algorithmId | 选择算法后跳转处理页面 |
| 算法选择 → 收藏管理 | FavoriteButton | targetType=algorithm |
| 推荐管理 → 算法选择 | 推荐结果 | 推荐面板展示的数据由推荐管理模块提供 |
| 算法管理 → 算法选择 | 算法列表 | 已发布算法作为数据源 |

## 6. 关键交互决策

### 6.1 推荐结果展示形式

采用**卡片**形式展示 Top 3 推荐：

| 方案 | 选择理由 |
|------|---------|
| 卡片 | 视觉突出，信息密度适中，每个推荐算法独立呈现（匹配度+理由+操作） |
| 列表 | 信息密度低，不适合强调推荐排序 |

### 6.2 算法对比同步滚动

多算法对比表格中，当用户滚动时，对比列同步滚动（使用 CSS `position: sticky` 固定表头，内容区域共享同一个滚动容器）。雷达图对比使用 ECharts 多系列叠加渲染。

### 6.3 自定义测试结果展示

用户在算法详情中上传测试图片后，展示该算法处理后的结果。支持与原图并排对比和滑动对比，与效果对比模块的 SideBySideView 和 OverlayView 复用。

### 6.4 搜索防抖与历史

搜索输入防抖 300ms。搜索历史最多保存 10 条，存储于 localStorage。热门搜索标签从后端获取（基于全局搜索频率统计）。

### 6.5 筛选方案保存

用户可保存当前筛选条件为方案（命名存储于 localStorage），方便快速切换常用筛选组合。

## 8. 性能优化

| 优化项 | 实现方式 |
|--------|---------|
| 树形懒加载 | 展开节点时按需加载子节点 |
| 搜索防抖 | 输入防抖 300ms |
| 推荐结果缓存 | 同一图片的推荐结果缓存 5 分钟 |
| 算法列表分页 | 每次加载 20 条，滚动加载更多 |
| 图片懒加载 | 算法样例图片使用懒加载 |
| 请求取消 | 切换页面时取消未完成请求 |
| 筛选去抖 | 多个筛选条件变更时合并为单次请求 |

## 9. 错误处理

| 错误类型 | 处理方式 |
|---------|---------|
| 推荐分析失败 | 显示"分析失败，请重试"，可跳过推荐直接浏览算法 |
| 搜索无结果 | 显示空状态提示"未找到匹配的算法"，建议调整关键词 |
| 算法详情加载失败 | 显示错误提示 + 重试按钮 |
| 对比数据加载失败 | 显示错误提示，保留已加载的对比列 |
| 图片上传失败 | 显示上传失败提示 + 重试按钮 |
