# 算法选择模块 - 测试用例

## 1. 测试目标

- 验证算法选择树展示（层级关系、任务类型 Tab、仅已发布算法、空分类过滤）（F-M03-001）
- 验证智能推荐集成（F-M03-002，通过推荐管理模块）
- 验证搜索功能（关键词/中文/拼音全拼/拼音首字母/类型/描述，与任务类型 Tab 联动）（F-M03-003）
- 验证算法详情展示（样例图、评分、使用次数、上传自定义图片测试）（F-M03-004）
- 验证算法收藏集成（F-M03-005，通过收藏管理模块）
- 验证算法对比功能（2-3 个、同图预测对比）（F-M03-006）
- 验证算法推荐匹配入口（F-M03-007 关键词/任务类型/样例算法匹配、降级与空结果兜底）

## 2. 测试前置

### 2.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| 测试算法 | 已发布算法 20+ 个（覆盖多分类层级、多任务类型） | 覆盖树形结构与任务类型 Tab |
| 未发布算法 | 状态为草稿/停用/归档的算法 3 个 | 测试仅展示已发布 |
| 测试用户 | 普通用户 1 个 | 测试树/搜索/对比/测试 |
| 样例图片 | 各算法关联的预测结果图 | 每种算法至少 2 张 |
| 收藏数据 | 已收藏和未收藏的算法 | 测试收藏状态 |
| 搜索关键词 | 中文/英文/拼音全拼/拼音首字母/类型/描述 | 测试搜索功能 |

### 2.2 数据清理策略

- 测试收藏数据按测试用户清理
- 保留系统预置算法不做删除

### 2.3 测试范围

测试覆盖的功能点见 §1 测试目标。**不包含的功能点（由相关模块承载 / 规划项，不在本模块范围）：**

- 多维筛选面板（处理速度/效果质量/场景/评分范围，见需求规格 §2.3.2）
- 搜索历史、热门标签、组合搜索、标签搜索（见需求规格 §2.3.1）
- 多维对比 Tab/柱状图/雷达图（见需求规格 §2.6.3）
- 详情页导航锚点、样例滑动/叠加对比、样例按场景筛选
- 收藏列表排序（使用频率/评分）、收藏容量上限、编辑模式、左滑删除
- VIP 权益差异（实验性算法可见性、推荐 Top5）
- 自然语言意图理解、多轮对话（由 AI 对话模块 F-M08-004 承载，见需求规格 §2.7）
- UI 组件渲染细节

## 4. 关键边界与异常

> 各边界条件对应的期望行为以 §3 用例为准，本章仅索引用例编号，不重复内容。

### 4.1 算法可见性与筛选边界

仅已发布可见、空分类过滤、任务类型 Tab 切换见 §3.1（T-AS-005/006/009）；算法详情不存在、无样例图见 §3.4（T-AS-033/034）。

### 4.2 搜索与推荐匹配边界

搜索无结果、空关键词、仅限已发布见 §3.3（T-AS-026/027/028）；推荐匹配结果为空、topN 超范围、接口超时降级见 §3.7（T-AS-065/066/067/069）；推荐服务异常见 §3.2（T-AS-016）。

### 4.3 算法对比边界

对比上限、下限、未发布、单算法失败见 §3.6（T-AS-054/055/056/057）。

### 4.4 自定义图片测试边界

格式不支持、大小超限、测试超时见 §3.4（T-AS-036/037/039）。

### 4.5 数据一致性

算法状态变更后树刷新、样例图一致性见 §3.1/§3.4 对应用例（T-AS-005、T-AS-031）；收藏状态同步见 §3.5（T-AS-043）。

## 6. 安全性测试

| 测试项 | 验证方式 | 预期结果 |
|--------|---------|---------|
| 未登录访问 | 未登录访问算法选择接口 | 返回 A0230"token无效或已过期" |
| 越权访问未发布算法 | 直接请求未发布算法详情 | 返回 A0401"算法不存在或未发布" |
| 搜索参数注入 | 搜索词包含 SQL 注入字符 | 参数化查询防护，无注入风险 |
| 上传图片安全 | 上传恶意脚本文件作为测试图片 | 格式白名单拒绝 |
