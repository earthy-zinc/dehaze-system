## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| 测试算法 | 已发布算法 20+ 个（覆盖多分类层级） | 覆盖树形结构 |
| 未发布算法 | 状态为草稿/停用/归档的算法 3 个 | 测试仅展示已发布 |
| 测试用户 | 普通用户 1 个 | 测试树/搜索/对比/测试 |
| 样例图片 | 各算法关联的预测结果图 | 每种算法至少 2 张 |
| 收藏数据 | 已收藏和未收藏的算法 | 测试收藏状态 |
| 搜索关键词 | 中文/英文/拼音全拼/拼音首字母/类型/描述 | 测试搜索功能 |

### 3.2 数据清理策略

- 测试收藏数据按测试用户清理
- 保留系统预置算法不做删除

### 3.3 测试范围

**包含的功能点：**

- 树形算法结构（F-M03-001）：层级展示、展开/收起、仅已发布、空分类过滤
- 智能推荐（F-M03-002）：特征分析、Top 3 推荐、推荐理由
- 搜索（F-M03-003）：关键词/中文/拼音全拼/拼音首字母/类型/描述
- 算法详情（F-M03-004）：样例图、评分、使用次数、上传自定义图片测试
- 算法收藏（F-M03-005）：收藏/取消收藏、收藏状态
- 算法对比（F-M03-006）：2-3 个算法同图预测对比
- 收藏集成与推荐集成

**不包含的功能点（未实现，不编写用例）：**

- 多维筛选面板（处理速度/效果质量/场景/评分范围，见需求规格 §2.3.2）
- 搜索历史、热门标签、组合搜索、标签搜索（见需求规格 §2.3.1）
- 多维对比 Tab/柱状图/雷达图（见需求规格 §2.6.3）
- 详情页导航锚点、样例滑动/叠加对比、样例按场景筛选
- 收藏列表排序（使用频率/评分）、收藏容量上限、编辑模式、左滑删除
- VIP 权益差异（实验性算法可见性、推荐 Top5）
- 自然语言推荐（远期规划，见需求规格 §2.7）
- UI 组件渲染细节

## 5. 关键边界与异常场景

| 场景 | 测试点 | 期望行为 |
|------|--------|---------|
| 仅已发布算法可见 | 数据库有草稿/停用算法 | 算法树与搜索中均不出现 |
| 空分类过滤 | 分类下无已发布算法 | 分类节点隐藏 |
| 算法对比上限 | 选择 4 个算法 | 拒绝并提示 |
| 对比算法未发布 | 勾选未发布算法 | 返回"算法不存在或未发布" |
| 搜索无结果 | 搜索不存在的关键词 | 返回空列表 |
| 算法详情不存在 | 访问无效/未发布算法 ID | 返回 A0401 |
| 自定义图片测试格式 | 上传不支持的格式 | 返回 A0701 |
| 推荐服务异常 | 推荐服务不可用 | 降级为手动浏览 |

## 6. 性能与并发测试

### 6.1 性能指标

| 指标 | 目标值 | 测试方法 |
|------|--------|---------|
| 算法树加载 | &lt; 1s | 加载 20+ 算法 |
| 搜索响应 | &lt; 300ms | 关键词搜索 |
| 算法详情加载 | &lt; 1s | 详情页全部内容加载 |
| 算法对比响应 | &lt; 5s | 3 个算法同图预测对比 |

### 6.2 并发场景

| 场景 | 并发数 | 验证点 |
|------|--------|--------|
| 并发查询算法树 | 100 用户 | 响应时间 &lt; 1s |
| 并发搜索算法 | 50 用户 | 搜索结果正确 |
| 并发获取推荐 | 50 用户 | 推荐结果正确，无错乱 |

## 7. 安全性测试

| 测试项 | 验证方式 | 预期结果 |
|--------|---------|---------|
| 未登录访问 | 未登录访问算法选择接口 | 返回 401 |
| 越权访问未发布算法 | 直接请求未发布算法详情 | 返回 A0401"算法不存在或未发布" |
| 搜索参数注入 | 搜索词包含 SQL 注入字符 | 参数化查询防护，无注入风险 |
| 上传图片安全 | 上传恶意脚本文件作为测试图片 | 格式白名单拒绝 |

## 8. 数据一致性测试

| 场景 | 验证点 | 期望行为 |
|------|--------|---------|
| 算法状态变更后树刷新 | 管理员停用某算法 | 算法树刷新后该算法不显示 |
| 收藏状态同步 | 收藏后立即查询收藏管理模块 | 收藏记录存在，targetType=algorithm |
| 推荐采纳记录 | 使用推荐算法后查询 | 处理记录 recommendedBy 正确 |
| 样例图一致性 | 新预测成功后刷新详情 | 样例图更新为最近 3 条成功记录 |
