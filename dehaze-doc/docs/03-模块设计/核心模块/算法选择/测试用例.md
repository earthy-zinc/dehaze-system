## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| 测试算法 | 已发布算法 20+ 个（传统/深度学习/混合各分类） | 覆盖三级分类树 |
| 未发布算法 | 状态为草稿/下线的算法 3 个 | 测试仅展示已发布 |
| 实验性算法 | 标记为 experimental 的算法 2 个 | 测试 VIP 可见性 |
| 测试用户 | 普通用户、VIP1、SVIP 各 1 个 | 测试不同权益 |
| 样例图片 | 各算法关联的样例图 | 每种算法至少 2 张 |
| 收藏数据 | 已收藏和未收藏的算法 | 测试收藏状态 |
| 搜索关键词 | 中文/英文/拼音/标签 | 测试搜索功能 |

### 3.2 数据清理策略

- 测试收藏数据按测试用户清理
- 测试搜索历史按测试用户清理
- 保留系统预置算法不做删除

### 3.3 测试范围

**包含的功能点：**

- 树形算法结构（F-M03-001）：三级分类展示、展开/收起、仅已发布算法
- 智能推荐（F-M03-002）：图像特征分析、Top 3 推荐、推荐理由
- 搜索筛选（F-M03-003）：关键词/拼音/标签搜索、多维筛选
- 算法详情（F-M03-004）：样例图展示、上传自定义图片测试
- 算法收藏（F-M03-005）：收藏/取消收藏、收藏列表管理
- 算法对比（F-M03-006）：多选对比、多维度对比
- VIP 权益差异：实验性算法可见性
- 收藏集成与推荐集成

**不包含的功能点：**

- 算法管理后台（属于算法管理模块）
- UI 组件渲染细节
- 未来扩展的 AI 能力增强功能
