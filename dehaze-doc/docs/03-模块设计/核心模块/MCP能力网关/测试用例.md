## 3. 测试前置

### 3.1 测试基础设施

| 组件 | 说明 |
|------|------|
| **MCP Inspector CLI** | 官方测试工具 `npx @modelcontextprotocol/inspector --cli`，测试 `tools/list`、`tools/call` 等标准方法 |
| **Python pytest** | 集成测试框架，测试 ApiDiscoverer 转换正确性、VIP 过滤逻辑 |
| **Mock 后端** | 本地 Flask/FastAPI mock 端点模拟 OpenAPI 文档和后端 API 响应 |

### 3.2 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **Mock OpenAPI 文档** | 含 5 类 API（image_processing×3、evaluation×2、algorithm×3、system×2、admin×1） | 模拟不同 tag 的 API，验证分组和过滤 |
| **Mock 后端端点** | 每个 API 对应的 Mock HTTP 端点（返回固定 JSON） | 用于测试 tools/call 转发 |
| **VIP 配置** | VIP1（仅 image_processing），VIP2（image_processing+evaluation），VIP3（全部） | 验证分级可见性 |
| **API Key** | `dhak_test_valid`（有效）、`dhak_test_revoked`（已吊销）、空字符串 | 验证认证 |

### 3.3 数据清理策略

- Mock 数据在内存和临时文件中管理，每次测试后自动销毁
- API Key 在测试数据库的 `sys_api_key` 表中插入测试记录，测试后清除
