# MCP 能力网关模块测试用例

## 1. 测试目标

- [x] 验证自建核心逻辑：ApiDiscoverer 解析转换、RequestForwarder 参数映射、NamespaceBuilder 分组、ToolSearchEngine 搜索
- [x] 验证 VIP 工具可见性过滤、速率限制、工具结果缓存
- [x] 验证同步流程与变更通知
- [x] 覆盖正常流程、边界条件、异常分支

> SDK 内置的 JSON-RPC 2.0 解析/路由/错误码、`@mcp.tool()` 参数 JSON Schema 校验、resource/prompt 装饰器能力不在此测试范围内，由 MCP Python SDK 框架保证。

## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **Mock OpenAPI 文档** | 含 5 类 API（image_processing×3、evaluation×2、algorithm×3、system×2、admin×1） | 模拟不同 tag 的 API，验证分组和过滤 |
| **Mock 后端端点** | 每个 API 对应的 Mock HTTP 端点（返回固定 JSON） | 用于测试 tools/call 转发 |
| **VIP 配置** | VIP1（仅 image_processing），VIP2（image_processing+evaluation），VIP3（全部） | 验证分级可见性 |
| **API Key** | `dhak_test_valid`（有效）、`dhak_test_revoked`（已吊销）、空字符串 | 验证认证 |

### 3.2 数据清理策略

- Mock 数据在内存和临时文件中管理，每次测试后自动销毁
- API Key 在测试数据库的 `sys_api_key` 表中插入测试记录，测试后清除

### 3.3 测试范围

**包含：**
- F-M07-001~008：协议服务、API 自动发现与工具注册、认证与访问控制、请求转发与响应转换、安全与工程化、调用可观测性、工具分组与上下文压缩、后台管理
- ApiDiscoverer 转换正确性、RequestForwarder 参数映射正确性

**不包含：**
- MCP Python SDK 内置能力（JSON-RPC 解析/路由/错误码、`@mcp.tool()` 参数 JSON Schema 校验、resource/prompt 装饰器）
- 后端 API 业务逻辑与底层配额扣减（由底层 API 独立测试）
- AI 对话模块的推理编排（属 AI 对话模块测试）
