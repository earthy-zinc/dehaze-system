# 效果对比模块需求规格

## 1. 模块概述

### 1.1 模块定位

效果对比模块是用户评估去雾效果的核心工具，承接去雾处理模块的输出结果，提供多种对比方式和专业评估指标，帮助用户全面了解处理效果，决定是否保存结果或调整算法。

### 1.2 核心价值

| 价值维度 | 具体内容 |
|---------|---------|
| **多维对比** | 6 种对比模式，满足不同场景下的对比需求 |
| **专业评估** | 量化指标分析，客观评价处理效果 |
| **直观展示** | 可视化对比工具，清晰呈现处理前后差异 |
| **信息透明** | 完整的算法信息和处理参数展示 |
| **灵活操作** | 支持缩放、平移、滤镜调节等交互操作 |

### 1.3 用户角色分析

| 用户类型 | 特征 | 使用偏好 | 功能需求 |
|---------|------|---------|---------|
| **轻度用户** | 对图像处理不了解 | 直观视觉对比 | 并排对比、重叠对比 |
| **中度用户** | 有一定图像处理经验 | 细节检查、效果调整 | 放大镜、滤镜调节 |
| **专业用户** | 图像处理专家 | 量化数据分析 | 指标对比、算法信息、报告导出 |
| **VIP用户** | 高频使用者 | 高效评估、批量对比 | 多算法对比、历史对比、高级导出 |

### 1.4 模块依赖关系

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  去雾处理    │────▶│  效果对比    │────▶│  结果管理    │
│    模块     │     │    模块     │     │  保存/分享   │
└─────────────┘     └──────┬──────┘     └─────────────┘
                          │
                          ▼
                   ┌─────────────┐
                   │  不满意结果  │
                   │ 返回算法选择 │
                   └─────────────┘
```

### 1.5 依赖的基础模块

| 模块 | 依赖说明 |
|------|---------|
| **会员管理** | 对比功能权限校验（放大镜倍数、滤镜项数、多算法对比数、报告导出格式等） |
| **收藏管理** | 处理结果收藏，targetType="result" |
| **消息通知** | 对比报告生成完成通知 |
| **推荐管理** | 对比页面可跳转获取替代算法推荐 |
| **任务管理** | 对比报告导出通过任务管理模块创建异步导出任务 |

## 2. 功能需求

### 2.1 并排对比 (F-M05-001)

#### 2.1.1 功能描述

将原图和处理后的图片并排显示，方便整体效果对比，是最基础也是最常用的对比方式。

#### 2.1.2 布局

- **竖屏布局（移动端默认）**：原图和处理后图片上下排列显示
- **横屏布局（桌面端/平板）**：原图和处理后图片左右并排显示

#### 2.1.3 交互功能

| 交互操作 | 触发方式 | 效果说明 |
|---------|---------|---------|
| 同步缩放 | 双指捏合 | 两张图片同步放大/缩小 |
| 同步移动 | 单指拖动 | 拖动时两张图片同步移动 |
| 双击放大 | 双击图片 | 放大到 100% 显示 |
| 双击还原 | 再次双击 | 还原到适应屏幕 |
| 标签切换 | 点击标签 | 切换显示原图/处理后 |

---

### 2.2 重叠对比 (F-M05-002)

#### 2.2.1 功能描述

将原图和处理后的图片重叠显示，通过滑动分隔线对比效果，适合精细对比局部差异。

#### 2.2.2 对比方式

- **垂直分隔线（默认）**：左右滑动分隔线，对比图片左右区域差异
- **水平分隔线**：上下滑动分隔线，对比图片上下区域差异

#### 2.2.3 交互功能

| 交互操作 | 触发方式 | 效果说明 |
|---------|---------|---------|
| 拖动分隔线 | 按住分隔线滑动 | 调整原图/处理后显示比例 |
| 自动对齐 | 松开分隔线 | 分隔线自动吸附到中心（可关闭） |
| 切换方向 | 点击切换按钮 | 垂直/水平分隔线切换 |
| 锁定位置 | 长按分隔线 | 固定分隔线位置 |
| 动画播放 | 点击播放按钮 | 分隔线自动滑动 |

---

### 2.3 放大镜对比 (F-M05-003)

#### 2.3.1 功能描述

使用放大镜工具查看局部细节，精确对比处理效果，适合检查纹理、边缘等细节。

#### 2.3.2 放大镜参数

| 参数项 | 选项 | 默认值 | 说明 |
|--------|------|--------|------|
| 放大倍数 | 2x / 3x / 5x | 2x | 放大倍数受会员等级限制（见 §4.1） |
| 放大镜大小 | 小 / 中 / 大 | 中 | 放大镜显示区域大小 |
| 边框样式 | 圆形 / 方形 / 圆角方形 | 圆形 | 放大镜外观样式 |
| 显示模式 | 原图 / 处理后 / 对比 | 对比 | 放大镜内显示内容 |

#### 2.3.3 对比模式

在对比模式下，同时显示原图和处理后两个放大镜窗口，方便对比查看同一位置的细节差异。

#### 2.3.4 交互功能

| 交互操作 | 触发方式 | 效果说明 |
|---------|---------|---------|
| 移动放大镜 | 手指拖动 | 放大镜跟随手指移动 |
| 调整倍数 | 双指捏合 | 调整放大倍数 |
| 切换显示 | 点击放大镜 | 切换原图/处理后/对比 |
| 固定位置 | 长按 | 固定放大镜位置 |
| 添加标记 | 双击 | 在当前位置添加对比标记点 |

---

### 2.4 滤镜调节对比 (F-M05-004)

#### 2.4.1 功能描述

对处理后的图片进行滤镜参数微调，实时预览调节效果，满足用户个性化需求。

#### 2.4.2 滤镜参数

| 滤镜名称 | 调节范围 | 默认值 | 说明 |
|---------|---------|--------|------|
| 亮度 | -100 ~ +100 | 0 | 调整图片整体明暗 |
| 对比度 | -100 ~ +100 | 0 | 调整明暗对比程度 |
| 饱和度 | -100 ~ +100 | 0 | 调整色彩鲜艳度 |
| 色温 | -100 ~ +100 | 0 | 调整冷暖色调 |
| 锐化 | 0 ~ 100 | 0 | 增强细节清晰度 |
| 降噪 | 0 ~ 100 | 0 | 减少图片噪点 |

滤镜项数受会员等级限制（见 §4.1）。

#### 2.4.3 预设方案

**内置预设**：

| 预设名称 | 效果说明 | 参数特点 |
|---------|---------|---------|
| 自然 | 轻微增强，保持自然 | 亮度+5，对比度+10，饱和度+5 |
| 鲜艳 | 色彩艳丽，视觉冲击 | 对比度+30，饱和度+40 |
| 柔和 | 降低对比，柔化效果 | 对比度-20，锐化-10 |
| 清晰 | 增强细节，提升清晰度 | 对比度+20，锐化+40 |
| 复古 | 复古暖色调效果 | 色温+30，饱和度-20 |

**自定义预设**：用户可保存当前参数为预设，命名、编辑、删除个人预设。自定义预设数量受会员等级限制（见 §4.1）。

---

### 2.5 指标对比 (F-M05-005)

#### 2.5.1 功能描述

通过量化指标客观评估去雾效果，提供专业的数据分析，适合专业用户和算法评测场景。指标评估为计算密集型任务，以异步方式执行。

#### 2.5.2 评估指标

**图像质量指标**：

| 指标名称 | 说明 | 理想值 |
|---------|------|--------|
| 峰值信噪比 (PSNR) | 图像质量评价，越高越好 | >25 dB |
| 结构相似性 (SSIM) | 结构相似程度，越接近 1 越好 | >0.85 |
| 均方误差 (MSE) | 图像差异程度，越小越好 | <100 |
| 信息熵 | 图像信息量，适中为好 | 7-8 |

**去雾效果指标**：

| 指标名称 | 说明 | 理想值 |
|---------|------|--------|
| 对比度提升 | 对比度增加程度 | 20%-50% |
| 饱和度提升 | 色彩饱和度增加 | 10%-30% |
| 清晰度提升 | 图像清晰度增加 | 30%-60% |
| 暗通道值 | 雾霾浓度指标 | <0.2 |

**性能指标**：处理时间、内存占用、输出文件大小。

#### 2.5.3 指标可视化

提供雷达图和柱状图两种图表形式展示量化指标。雷达图用于多维度指标综合评估，柱状图用于对比展示各项指标的具体数值和提升幅度。

#### 2.5.4 对比分析

- **原图 vs 处理后**：单次处理效果对比
- **多算法对比**：同一图片不同算法效果对比（VIP 功能，数量见 §4.1）
- **历史记录对比**：与历史处理结果对比

---

### 2.6 算法信息展示 (F-M05-006)

#### 2.6.1 功能描述

展示本次处理使用的算法详细信息和处理参数，帮助用户了解处理过程，便于后续调优。

#### 2.6.2 展示内容

| 类别 | 内容 |
|------|------|
| 算法基本信息 | 算法名称、类型标签、版本、适用场景、推荐指数 |
| 处理参数 | 本次使用的参数及与默认值的对比 |
| 效果评估 | 各项质量指标的评价结果 |
| 性能数据 | 处理时间、内存占用等性能指标 |

---

### 2.7 对比工具栏 (F-M05-007)

#### 2.7.1 功能描述

提供快速切换对比模式和常用操作的工具栏，始终固定在屏幕底部（移动端）或侧边（桌面端）。

#### 2.7.2 快捷操作

| 操作 | 说明 |
|------|------|
| 保存结果 | 保存处理后的图片 |
| 分享图片 | 分享到社交平台或生成分享链接 |
| 重新处理 | 使用相同参数重新处理 |
| 更换算法 | 返回算法选择页更换算法 |
| 导出报告 | 生成并导出对比分析报告 |
| 添加收藏 | 收藏本次处理结果 |

---

### 2.8 对比报告导出 (F-M05-008)

#### 2.8.1 功能描述

将对比结果导出为结构化报告，支持多种格式。导出任务通过任务管理模块以异步方式执行，避免长时间等待。

#### 2.8.2 导出格式

| 格式 | 适用场景 | 权限要求 |
|------|---------|---------|
| 图片格式 (PNG/JPG) | 快速分享、社交媒体 | VIP1 及以上 |
| PDF 报告 | 专业报告、存档 | VIP2 及以上 |
| 数据导出 (CSV/JSON) | 进一步分析 | SVIP |

#### 2.8.3 报告内容

对比报告包含：原图与结果图并排展示、处理参数详情、评估指标数据、算法信息、生成时间。

#### 2.8.4 导出流程

用户点击导出 → 选择格式和内容 → 系统通过任务管理模块创建异步导出任务 → 用户可在任务列表中查看进度 → 导出完成后通过消息通知模块推送完成通知 → 用户下载报告文件。

## 3. 用户交互流程

### 3.1 标准对比流程

处理完成自动进入对比页面 → 默认显示并排对比模式 → 用户查看整体效果 → 切换对比模式（并排/重叠/放大镜/滤镜/指标/算法信息） → 满意则保存/分享/导出报告/收藏 → 不满意则返回算法选择/调整参数/重新上传。

### 3.2 多算法对比流程（VIP 功能）

选择"多算法对比" → 选择 2-4 个算法 → 系统依次执行处理 → 进入多算法对比页面 → 网格展示各算法处理结果 → 查看各算法指标对比 → 选择最优结果保存。

## 4. 会员权益

### 4.1 等级差异

效果对比模块的会员权益由[会员管理模块](../../基础模块/会员管理/需求规格.md)统一管理，各等级差异如下：

| 功能项 | 普通用户 | VIP1 | VIP2 | SVIP |
|--------|---------|------|------|------|
| 并排对比 | 是 | 是 | 是 | 是 |
| 重叠对比 | 是 | 是 | 是 | 是 |
| 放大镜倍数 | 2x | 2x / 3x | 2x / 3x / 5x | 2x / 3x / 5x |
| 滤镜调节项数 | 基础 3 项 | 全部 6 项 | 全部 6 项 | 全部 6 项 |
| 自定义预设数量 | 3 个 | 10 个 | 20 个 | 无限制 |
| 指标对比 | 基础指标 | 全部指标 | 全部指标 | 全部指标 |
| 多算法对比数 | 不支持 | 2 个 | 3 个 | 4 个 |
| 历史对比 | 不支持 | 最近 10 条 | 最近 50 条 | 全部 |
| 报告导出格式 | 不支持 | 图片格式 | PDF 格式 | PDF + 数据 |

### 4.2 权限提示

当用户尝试使用超出权限的功能时，展示升级引导提示，列出需升级才能使用的功能项，引导用户了解会员权益。

## 5. 消息通知集成

效果对比模块通过[消息通知模块](../../基础模块/消息通知/需求规格.md)（F-MN-001）向用户推送以下通知：

| 触发事件 | 消息类型 | 通知内容 |
|---------|---------|---------|
| 对比报告生成完成 | 业务通知 | 报告已生成，点击下载 |

---

## 6. 收藏管理集成

处理结果支持收藏功能，由[收藏管理模块](../../基础模块/收藏管理/需求规格.md)统一管理：

- 收藏类型：`result`（处理结果）
- 收藏入口：对比页面的收藏按钮、工具栏收藏按钮
- 取消收藏：收藏列表中操作

---

## 7. 推荐管理集成

效果对比模块与[推荐管理模块](../../基础模块/推荐管理/需求规格.md)集成：

- 用户对当前处理结果不满意时，可通过"更换算法"跳转至推荐管理获取替代算法推荐（F-REC-002）
- 推荐结果可一键进入去雾处理流程，无需手动返回算法选择页面

---

## 8. 任务管理对齐

对比报告导出通过[任务管理模块](../../基础模块/任务管理/需求规格.md)创建异步导出任务：

- 导出任务状态：待执行 → 执行中 → 已完成/已失败
- 用户可在任务列表中查看导出进度
- 导出完成后可下载报告文件
- 结果文件保留 24 小时
