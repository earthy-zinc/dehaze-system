# 效果对比模块 - 前端实现设计

## 1. 文档概述

本文档描述效果对比模块的前端实现方案，聚焦组件架构、状态管理、路由设计等架构决策。效果对比模块承接去雾处理模块的输出，提供 6 种对比模式和专业评估指标。

---

## 2. 组件设计

### 2.1 组件结构

```
效果对比模块
├── ComparisonPage                  # 效果对比主页面
│   ├── ComparisonModeBar           # 对比模式切换栏
│   ├── SideBySideView              # 并排对比视图
│   │   ├── OriginalImage           # 原图
│   │   └── ResultImage             # 处理结果图
│   ├── OverlayView                 # 重叠对比视图
│   │   └── DraggableLine           # 拖拽分隔线（复用通用组件）
│   ├── MagnifierView               # 放大镜对比视图
│   │   ├── MagnifierCanvas         # 放大镜画布
│   │   └── MagnifierControls       # 放大镜参数控制（倍数/大小/样式/模式）
│   ├── FilterView                  # 滤镜调节视图
│   │   ├── FilterSliderGroup       # 滤镜滑块组（亮度/对比度/饱和度/色温/锐化/降噪）
│   │   ├── PresetSelector          # 滤镜预设选择器
│   │   └── FilterPresetManage      # 滤镜预设管理
│   ├── MetricsPanel                # 指标对比面板
│   │   ├── MetricsChart            # 雷达图+柱状图（ECharts）
│   │   └── MetricsTable            # 指标数值表格
│   ├── AlgorithmInfoPanel          # 算法信息面板
│   │   ├── BasicInfo               # 基本信息（名称/类型/版本/场景/推荐指数）
│   │   ├── ParamInfo               # 处理参数（本次使用值 vs 默认值）
│   │   └── PerformanceInfo         # 性能数据（耗时/内存/GPU/成功率）
│   ├── ActionBar                   # 操作栏
│   │   ├── SaveButton              # 保存结果
│   │   ├── ShareButton             # 分享结果
│   │   ├── FavoriteButton          # 收藏按钮（复用收藏管理模块组件）
│   │   ├── ExportReportButton      # 导出报告
│   │   ├── ReprocessButton         # 重新处理

│   └── ReportGenerationDialog      # 报告生成弹窗
│       ├── FormatSelector          # 格式选择（图片/PDF）
│       ├── ContentConfig           # 内容配置（指标/对比图/参数信息）
│       └── ReportProgress          # 报告生成进度
```

### 2.2 组件职责

| 组件 | 职责 | 复用性 |
|------|------|--------|
| ComparisonPage | 页面容器，路由入口，管理对比模式切换和全局状态 | 不可复用 |
| ComparisonModeBar | 6种对比模式图标按钮切换栏 | 可复用 |
| SideBySideView | 并排展示原图+结果图，支持同步缩放/移动 | 可复用于算法选择模块 |

| MagnifierView | 放大镜对比，Canvas渲染 + 鼠标位置同步 | 可复用于数据集图片查看 |
| FilterView | 滤镜参数调节，实时预览 | 可复用于去雾处理参数调节 |
| MetricsPanel | 评估指标可视化（雷达图+柱状图） | 可复用于算法管理效果评估 |
| AlgorithmInfoPanel | 算法信息三级展示（基本/参数/性能） | 可复用 |
| ActionBar | 结果操作入口集合 | 可复用 |
| ReportGenerationDialog | 报告配置+异步生成进度 | 不可复用 |
| MagnifierCanvas | 放大镜 Canvas 渲染核心 | 高度可复用 |
| DraggableLine | 拖拽分隔线 | 高度可复用（通用组件） |
| FavoriteButton | 收藏按钮 | 高度可复用（收藏管理模块） |

## 3. 页面布局设计

### 3.1 页面结构

采用**顶部模式栏 + 主体对比区 + 底部操作栏**的三段式布局：

| 区域 | 说明 |
|------|------|
| 顶部模式栏 | 6种对比模式图标切换，当前模式高亮 |
| 主体对比区 | 根据选中模式渲染对应对比视图 |
| 底部操作栏 | 保存/分享/收藏/导出报告/重新处理/更换算法 |

### 3.2 响应式布局

| 屏幕尺寸 | 布局调整 |
|---------|---------|
| 桌面端（>=992px） | 底部操作栏固定，侧边栏展示算法信息 |
| 移动端（<992px） | 底部操作栏两行显示，算法信息面板可展开/收起 |

### 3.3 路由设计

| 路由路径 | 页面 | 说明 |
|---------|------|------|
| /comparison/:logId | ComparisonPage | 从处理结果跳转，携带处理日志ID |

路由参数说明：
- `logId`：处理日志ID，用于加载原图、处理结果、算法信息、评估指标

## 4. 状态管理

### 4.1 状态定义

| Store | 职责 |
|-------|------|
| comparisonStore | 对比模式、图片数据、评估指标、滤镜参数、报告生成状态 |

### 4.2 comparisonStore 核心状态

| 状态字段 | 类型 | 说明 |
|---------|------|------|
| activeMode | string | 当前对比模式（side-by-side/overlay/magnifier/filter/metrics/algorithm） |
| originalImage | object | 原图URL及元数据 |
| resultImage | object | 处理结果图URL及元数据 |
| gtImage | object | GT参考图（如有） |
| metrics | object | 评估指标（PSNR/SSIM/MSE/Entropy等） |
| metricsStatus | idle/loading/completed/failed | 指标评估异步任务状态 |
| filterParams | object | 滤镜参数（亮度/对比度/饱和度/色温/锐化/降噪） |
| filterPresets | array | 滤镜预设列表（内置+自定义） |
| algorithmInfo | object | 算法信息（基本/参数/性能） |
| zoomLevel | number | 当前缩放级别 |
| reportStatus | idle/generating/completed/failed | 报告生成状态 |
| reportTaskId | string | 报告生成异步任务ID |
| rating | number | 用户评分（1-5星） |

### 4.3 comparisonStore Actions

| 方法 | 说明 |
|------|------|
| loadComparisonData(logId) | 根据处理日志ID加载对比数据 |
| switchMode(mode) | 切换对比模式 |
| updateZoom(level) | 更新缩放级别 |
| updateFilterParams(params) | 更新滤镜参数 |
| resetFilters() | 重置滤镜参数为默认值 |
| applyFilterPreset(presetId) | 应用滤镜预设 |
| saveFilterPreset(name, params) | 保存当前滤镜参数为预设 |
| deleteFilterPreset(presetId) | 删除滤镜预设 |
| fetchMetrics(logId) | 提交指标评估异步任务 |
| pollMetricsStatus(taskId) | 轮询指标评估任务状态 |
| submitRating(rating) | 提交效果评分 |
| generateReport(config) | 提交报告生成异步任务 |
| pollReportStatus(taskId) | 轮询报告生成状态 |
| downloadReport(taskId) | 下载生成的报告 |

## 5. 数据流

### 5.1 页面初始化

```
路由进入 /comparison/:logId
    ↓
调用 loadComparisonData(logId)
    ↓ 并行请求
加载原图 + 结果图 + 算法信息
    ↓
默认显示并排对比模式
    ↓
用户可手动触发指标评估（fetchMetrics）
```

### 5.2 对比模式切换

切换模式时的状态保持策略：

| 状态项 | 切换后行为 |
|-------|-----------|
| 缩放级别 | 保持（所有模式共享） |
| 滤镜参数 | 保持（切换到 filter 模式时生效） |
| 指标数据 | 保持（切换到 metrics 模式时直接展示） |

### 5.3 指标评估流程

```
用户点击"计算指标" → 提交异步评估任务
    ↓
更新 metricsStatus = loading
    ↓ 轮询间隔：3s
评估完成 → 更新 metrics 数据 → 自动展示图表
评估失败 → 更新 metricsStatus = failed → 展示错误+重试
```

### 5.4 报告生成流程

```
用户配置报告内容 → 点击生成
    ↓
提交异步生成任务 → 更新 reportStatus = generating
    ↓ 轮询间隔：5s
生成完成 → 更新 reportStatus = completed → 提供下载
生成失败 → 更新 reportStatus = failed → 展示错误+重试
```

### 5.5 模块间数据交互

| 交互方向 | 数据 | 说明 |
|---------|------|------|
| 去雾处理 → 效果对比 | logId | 处理完成后自动跳转 |
| 效果对比 → 收藏管理 | FavoriteButton | targetType=result |
| 效果对比 → 算法选择 | 原图信息 | 不满意结果时返回重新选择算法 |
| 效果对比 → 推荐管理 | rating数据 | 评分作为推荐反馈信号 |

## 6. 关键交互决策

### 6.1 6种对比模式的组件切换策略

采用 **v-if 条件渲染** 策略而非 keep-alive：

| 策略 | 选择理由 |
|------|---------|
| v-if 完全销毁 | 各模式组件结构差异大（Canvas/拖拽线/图表），共享状态通过 Store 保持，无需 keep-alive 缓存 DOM |
| 状态保持 | 缩放级别、滤镜参数等通过 comparisonStore 全局管理，切换模式后状态不丢失 |

### 6.2 放大镜 Canvas 性能优化

| 优化项 | 实现方式 |
|--------|---------|
| 离屏 Canvas | 预渲染原图+结果图到离屏 Canvas，放大镜仅裁剪显示对应区域 |
| 鼠标位置节流 | mousemove 事件节流 16ms（60fps），减少 Canvas 重绘 |
| requestAnimationFrame | 放大镜重绘使用 RAF 同步屏幕刷新率 |
| 图片尺寸限制 | 超大图片先缩放至合理尺寸再渲染，避免 Canvas 内存溢出 |

### 6.3 重叠对比分隔线

| 技术选型 | 实现方式 |
|---------|---------|
| CSS clip-path | 左侧显示原图、右侧显示结果图，分隔线位置动态更新 clip-path 值 |
| 拖拽组件 | 复用通用 DraggableLine 组件，支持垂直/水平方向 |

### 6.4 滤镜调节实时预览

滤镜参数变更后使用 **CSS filter** 属性直接应用于结果图，无需重新请求后端。参数调节滑块使用防抖 100ms 避免高频重绘。

### 6.5 指标图表

使用 ECharts 渲染雷达图和柱状图。指标评估为异步任务，前端提交后轮询结果，完成后自动渲染图表。

### 6.6 对比报告预览

报告生成后提供在线预览（PDF 使用 iframe 嵌入，图片直接展示），用户确认后下载。不支持实时编辑报告内容。

## 7. 权限与会员控制

| 功能 | 普通用户 | VIP |
|------|:------:|:---:|
| 并排对比 | 是 | 是 |
| 重叠对比 | 是 | 是 |
| 放大镜对比 | 2x固定 | 2x/3x/5x |
| 滤镜调节 | 基础3项 | 全部6项 |
| 指标对比 | 基础指标 | 全部指标 |
| 报告导出 | 否 | 图片/PDF格式 |

权限不足时，对应按钮置灰并显示升级引导提示。

## 8. 性能优化

| 优化项 | 实现方式 |
|--------|---------|
| 图片预加载 | 进入页面时预加载原图+结果图 |
| Canvas 离屏渲染 | 放大镜使用离屏 Canvas 避免主线程阻塞 |
| 滤镜 CSS 实现 | 滤镜参数直接映射 CSS filter，无需后端 |
| 轮询控制 | 页面不可见时停止指标/报告轮询 |
| 图表懒加载 | 切换到指标模式时才初始化 ECharts 实例 |
| 请求取消 | 切换页面时取消进行中的轮询和未完成请求 |

---

## 9. 错误处理

| 错误类型 | 处理方式 |
|---------|---------|
| 图片加载失败 | 显示占位图 + 重新加载按钮 |
| 指标评估失败 | 显示错误提示 + 重试按钮 |
| 报告生成失败 | 显示错误提示 + 重新生成按钮 |
| 权限不足 | 功能按钮置灰 + 升级引导提示 |
