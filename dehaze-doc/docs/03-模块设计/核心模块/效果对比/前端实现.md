# 效果对比模块 - 前端实现设计

## 1. 文档概述

本文档描述效果对比模块的前端实现方案（dehaze-front-vue），聚焦组件结构、状态管理、关键交互决策。效果对比模块承接去雾处理模块的输出，提供并排对比、放大镜、滤镜调节、量化评估与报告导出能力。功能需求与业务规则详见 [需求规格.md](./需求规格.md)，API 契约详见 [API接口.md](./API接口.md)。

---

## 2. 组件设计

### 2.1 组件结构

```
效果对比模块
├── CompareParallel               # 并排对比页（F-M05-001）
│   └── ParallelImageShow + 导出对比报告
├── CompareOverlap                # 效果评估页（F-M05-002）
│   └── ParallelImageShow + 算法信息 + 指标表格 + 雷达图 + 柱状图 + 导出对比报告
└── 通用组件
    ├── ParallelImageShow         # 并排展示核心（放大镜/滤镜/自适应布局）
    ├── Magnifier                 # 放大镜工具
    └── DraggableLine             # 通用拖拽分隔线（用于重叠对比 F-M05-009，未接入对比页）
```

### 2.2 组件职责

| 组件 | 职责 | 复用性 |
|------|------|--------|
| CompareParallel | 并排对比页容器：并排展示 + 导出 HTML 报告 | 页面 |
| CompareOverlap | 效果评估页容器：并排展示 + 算法信息 + 量化指标 + 导出 HTML 报告 | 页面 |
| ParallelImageShow | 并排图片展示核心：自适应布局、同步缩放、放大镜、滤镜、标签 | 高度可复用 |
| Magnifier | 放大镜 Canvas 渲染（形状/倍数/大小） | 可复用 |
| DraggableLine | 拖拽分隔线（用于重叠对比 F-M05-009） | 通用组件 |

## 3. 页面布局设计

### 3.1 并排对比页（CompareParallel）

| 区域 | 说明 |
|------|------|
| 顶部 | 导出对比报告按钮 |
| 主体 | 并排展示区（自适应横/竖布局，滚轮缩放 + 放大镜 + 滤镜） |

### 3.2 效果评估页（CompareOverlap）

| 区域 | 说明 |
|------|------|
| 顶部 | 导出对比报告按钮 + 标题 + 设置面板入口 |
| 主体 | ParallelImageShow 并排展示 |
| 下方 | 算法信息 + 指标评价区 |

算法信息展示内容：

| 类别 | 内容 |
|------|------|
| 算法基本信息 | 算法名称、类型（标签）、权重大小 |
| 性能参数 | 浮点数量（FLOPs）、参数量（Params） |
| 算法描述 | 算法简介文本 |
| 网络架构 | 网络架构图（图片） |

指标评价区包含指标表格（指标名、数值、方向标记、描述）、雷达图、柱状图。

## 4. 状态管理

### 4.1 imageShow Store（核心）

| 状态字段 | 类型 | 说明 |
|---------|------|------|
| imageInfo.images.urls | array | 图片列表（url/label/id），用于并排展示 |
| imageInfo.brightness/contrast/saturate | number | 滤镜参数 |
| imageInfo.width/height | number | 图片显示尺寸 |
| magnifierInfo | object | 放大镜配置（enabled/shape/width/height/zoomLevel） |
| scaleX/scaleY | number | 原图与显示尺寸的比例（放大镜绘制用） |
| mouse.x/mouse.y | number | 鼠标位置 |
| modelId | number | 当前算法 ID |
| dehazeParams | object（页面局部） | 处理参数（去雾强度/色彩饱和度/对比度/锐化程度），从去雾处理页经 `route.query.params` 传入，默认 50/50/50/30 |

### 4.2 评估状态（页面局部）

评估采用异步任务模式：页面加载自动提交评估任务，轮询状态（1 处理中 / 2 已完成 / 3 失败），完成后将指标写入表格与图表。

## 5. 数据流

### 5.1 评估流程

```
进入效果评估页（携带处理记录）→ 页面加载自动提交评估任务
    ↓ 异步轮询（间隔 2s，轮询契约详见 API接口.md §2.1）
评估完成 → 渲染指标表格 + 雷达图 + 柱状图（ECharts）
```

### 5.2 对比报告导出流程

```
点击"导出对比报告" → 提交报告生成请求（仅 logId 参数）
    ↓ 立即返回 taskId + status=1
轮询报告状态（间隔 2s，轮询契约详见 API接口.md §2.2）
    ├─ status=2 → 触发 HTML 文件下载
    └─ status=3 → 展示失败原因
```

### 5.3 模块间数据交互

| 交互方向 | 数据 | 说明 |
|---------|------|------|
| 去雾处理 → 效果对比 | logId | 处理完成跳转至效果评估页（CompareOverlap） |
| 效果对比 → 算法选择 | 原图信息 | 不满意结果时返回算法选择重新处理 |

## 6. 关键交互决策

### 6.1 放大镜 Canvas 渲染

- 按住鼠标拖动显示放大镜画布，实时绘制鼠标附近区域
- 放大镜参数（形状/倍数/宽高）通过 Store 管理，多张图片同步显示放大镜窗口
- 绘制使用 Canvas `drawImage`，按 `scaleX/scaleY` 换算原图像素坐标

### 6.2 滤镜实时预览

滤镜参数变更后使用 **CSS filter** 属性直接应用于图片（`contrast() brightness() saturate()`），无需重新请求后端。滤镜参数范围与默认值详见 [需求规格.md §2.4.2](./需求规格.md)。

### 6.3 指标图表

使用 ECharts 渲染雷达图和柱状图。雷达图各维度使用**固定指标上限**（PSNR=100、SSIM=1、LPIPS=1、NIQE=10、NIMA=10、BRISQUE=100），保证不同评估结果横向可比；柱状图展示各项指标数值。

---

## 7. 权限与会员控制

当前效果对比模块前端**无会员等级差异控制**（放大镜倍数、滤镜项数、报告格式均无等级限制），所有登录用户一致可用。评估接口的会员配额校验由后端（Python 算法服务）执行，配额不足时接口返回业务错误，前端展示错误提示。

---

## 8. 性能优化

| 优化项 | 实现方式 |
|--------|---------|
| 图片预加载 | 图片 onload 后统一调整尺寸布局 |
| Canvas 放大镜 | 局部绘制，仅重绘鼠标附近区域 |
| 滤镜 CSS 实现 | 滤镜参数直接映射 CSS filter，无后端请求 |
| 图表按需渲染 | 指标区域渲染时初始化 ECharts |
