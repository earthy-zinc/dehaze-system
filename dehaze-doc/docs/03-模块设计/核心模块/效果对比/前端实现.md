# 效果对比模块 - 前端实现设计

## 1. 文档概述

本文档描述效果对比模块的前端实现方案（dehaze-front-vue），聚焦组件结构、状态管理、关键交互决策。效果对比模块承接去雾处理模块的输出，提供并排对比、放大镜、滤镜调节、量化评估与报告导出能力。

---

## 2. 组件设计

### 2.1 组件结构

```
效果对比模块
├── Evaluation                    # 图像效果评估页（评估 + 三 Tab 展示）
│   ├── ParallelImageUpload       # 图片上传（原图/结果图/参考图）
│   ├── ParallelImageShow         # 并排图片展示（放大镜 + 滤镜）
│   ├── 指标对比 Tab              # 算法信息 + 指标表格 + 雷达图 + 柱状图
│   ├── 图片对比 Tab              # 并排展示
│   ├── 参数对比 Tab              # 处理参数 vs 默认值
│   └── 导出报告（txt，前端本地生成）
├── CompareParallel               # 并排对比页
│   └── 并排展示 + 缩放 + 放大镜 + 滤镜 + 导出对比报告（HTML 异步）
├── CompareOverlap                # 重叠对比页（当前承载效果评估能力）
│   └── ParallelImageShow + 指标表格 + 算法信息 + 导出对比报告
└── 通用组件
    ├── ParallelImageShow         # 并排展示核心（放大镜/滤镜/自适应布局）
    ├── DraggableLine             # 通用拖拽分隔线（预留，未接入对比页）
    ├── Magnifier                 # 放大镜工具
    └── EffectDisplay / AlgorithmToolBar   # 效果展示 / 算法工具栏
```

### 2.2 组件职责

| 组件 | 职责 | 复用性 |
|------|------|--------|
| Evaluation | 效果评估页容器：上传、评估、三 Tab 展示、导出 txt 报告 | 页面 |
| CompareParallel | 并排对比页容器：并排展示 + 导出 HTML 报告 | 页面 |
| CompareOverlap | 重叠对比页容器（当前为评估页）：并排 + 指标 + 算法信息 | 页面 |
| ParallelImageShow | 并排图片展示核心：自适应布局、同步缩放、放大镜、滤镜、标签 | 高度可复用 |
| ParallelImageUpload | 多图上传组件 | 可复用 |
| Magnifier | 放大镜 Canvas 渲染（形状/倍数/大小） | 可复用 |
| DraggableLine | 拖拽分隔线（规划中用于重叠对比） | 通用组件 |

> **说明**：早期设计稿中的 ComparisonModeBar（6 模式切换栏）、FilterPresetManage（预设管理）、ShareButton、FavoriteButton 等**未实现**。`compare/parallel`、`compare/overlap` 页面当前未注册在静态路由中。

## 4. 状态管理

### 4.1 imageShow Store（核心）

| 状态字段 | 类型 | 说明 |
|---------|------|------|
| imageInfo.images.urls | array | 图片列表（url/label/id），用于并排展示 |
| imageInfo.brightness/contrast/saturate | number | 滤镜参数（内部 0-200，UI 映射 -100~+100） |
| imageInfo.width/height | number | 图片显示尺寸 |
| magnifierInfo | object | 放大镜配置（enabled/shape/width/height/zoomLevel） |
| scaleX/scaleY | number | 原图与显示尺寸的比例（放大镜绘制用） |
| mouse.x/mouse.y | number | 鼠标位置 |
| modelId | number | 当前算法 ID |
| dehazeParams | object | 处理参数（去雾强度/色彩饱和度/对比度/锐化程度） |

### 4.2 评估状态（页面局部）

评估采用异步模式：提交后轮询状态（状态码 1 处理中 / 2 已完成 / 3 失败），完成后将指标写入表格与图表。

## 5. 数据流

### 5.1 评估流程

```
上传原图/结果图/参考图 → 点击"开始评估"
    ↓
AlgorithmAPI.getAlgorithmInfoById(modelId) 获取算法信息
    ↓
ModelAPI.evaluateAndWait({ algorithmId, predUrl, gtUrl })   # SDK 封装：提交+轮询
    ↓ 完成
指标表格 + 雷达图 + 柱状图渲染（ECharts）
```

### 5.2 对比报告导出流程

```
点击"导出对比报告" → 弹窗选择格式/内容
    ↓
ModelAPI.generateReport({ logId, format, includeMetrics, includeFilters })
    ↓ 立即返回 taskId + status=1
轮询 ModelAPI.getReportStatus(taskId)（间隔 2s）
    ├─ status=2 → 使用 downloadUrl 触发下载（<a download>）
    └─ status=3 → 展示失败原因
```

> **说明**：前端弹窗的格式选项（PDF/图片）仅为 UI 配置项，后端当前统一生成 HTML 报告。

### 5.3 模块间数据交互

| 交互方向 | 数据 | 说明 |
|---------|------|------|
| 去雾处理 → 效果对比 | logId | 处理完成跳转对比/评估页面 |
| 效果对比 → 算法选择 | 原图信息 | 不满意结果时返回算法选择重新处理 |

## 6. 关键交互决策

### 6.1 并排展示自适应布局

根据容器宽高比自动决定布局方向：宽屏左右并排（row），窄屏上下排列（column）。图片按原始宽高比等比缩放，多张图片等宽分配。

### 6.2 放大镜 Canvas 渲染

- 按住鼠标拖动显示放大镜画布，实时绘制鼠标附近区域
- 放大镜参数（形状/倍数/宽高）通过 Store 管理，多张图片同步显示放大镜窗口
- 绘制使用 Canvas `drawImage`，按 `scaleX/scaleY` 换算原图像素坐标

### 6.3 滤镜实时预览

滤镜参数变更后使用 **CSS filter** 属性直接应用于图片（`contrast() brightness() saturate()`），无需重新请求后端。UI 滑块范围 -100~+100，内部映射 0-200（`transform = 0.5 * x + 100`）。

### 6.4 指标图表

使用 ECharts 渲染雷达图和柱状图。雷达图各维度使用独立最大值（当前值 × 1.3），使不同量纲指标可横向比较；柱状图展示各项指标数值。

### 6.5 评估结果本地导出（txt）

评估页支持导出 **txt 文本报告**（前端本地生成 Blob 下载），包含生成时间、算法信息、评估指标、处理参数，不依赖后端接口。

## 7. 权限与会员控制

当前效果对比模块前端**无会员等级差异控制**（放大镜倍数、滤镜项数、报告格式均无等级限制），所有登录用户一致可用。评估接口的会员配额校验由后端（Python 算法服务）执行，配额不足时接口返回业务错误，前端展示错误提示。

> **本次改造目标（规划中）**：按会员等级差异化控制功能（放大镜倍数、滤镜项数、多算法对比数、报告格式），权限不足时按钮置灰并显示升级引导。

## 8. 性能优化

| 优化项 | 实现方式 |
|--------|---------|
| 图片预加载 | 图片 onload 后统一调整尺寸布局 |
| Canvas 放大镜 | 局部绘制，仅重绘鼠标附近区域 |
| 滤镜 CSS 实现 | 滤镜参数直接映射 CSS filter，无后端请求 |
| 图表按需渲染 | 切换到指标 Tab 时初始化/调整 ECharts |
| 评估模型延迟加载 | 指标模型在 Python 端首次计算时加载 |
