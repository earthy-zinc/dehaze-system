# 效果对比模块 API 接口

## 1. 文档概述

本文档定义 **效果对比** 模块的 HTTP API 规范，是该模块 API 契约的唯一权威来源。

- **基础路径**：
  - 效果评估：`/api/v1/evaluation`
  - 对比报告：`/api/v1/compare`
- **公共约定**：参见 [02-系统架构/04-API规范.md](../../../02-系统架构/04-API规范.md)
- **需求规格**：[需求规格.md](./需求规格.md)

> 评估与报告生成均为计算密集型异步任务，POST 立即返回任务 ID 与处理中状态，前端通过 GET 轮询直至终态。

## 2. 接口清单

### 2.1 效果评估接口

| 路径 | 方法 | 功能描述 | 权限标识 | 关联功能点 |
|------|------|---------|---------|-----------|
| `/api/v1/evaluation` | POST | 提交效果评估（结果图 + 参考图 + 算法ID，异步） | `evaluation:execute` | F-M02-005 |
| `/api/v1/evaluation/{taskId}` | GET | 查询评估任务状态（1 处理中 / 2 已完成 / 3 失败） | - | F-M02-005 |
| `/api/v1/evaluation/metrics` | GET | 获取评估指标历史（当前用户，仅已完成记录） | - | F-M02-005 |
| `/api/v1/evaluation/logs` | GET | 获取评估日志列表（分页，支持算法ID筛选） | - | F-M02-005 |

> 评估指标：PSNR / SSIM / LPIPS（需参考图）；NIQE / NIMA / BRISQUE（无参考指标）。

### 2.2 对比报告接口

| 路径 | 方法 | 功能描述 | 权限标识 | 关联功能点 |
|------|------|---------|---------|-----------|
| `/api/v1/compare/report` | POST | 生成对比报告（异步） | `evaluation:execute` | F-M02-008 |
| `/api/v1/compare/report/{taskId}` | GET | 查询报告状态（返回 JSON）；`?download=true` 时返回 HTML 报告文件流 | - | F-M02-008 |

## 3. 权限标识汇总

| 权限标识 | 说明 |
|---------|------|
| `evaluation:execute` | 提交效果评估、生成对比报告 |
| - | 登录态接口：查询评估任务状态、评估指标历史、评估日志、查询报告状态（评估受会员"评估次数"配额限制） |

## 4. 业务错误码

| 错误码 | 说明 | 触发场景 |
|--------|------|---------|
| `A0401` | 请求资源不存在 | 评估任务不存在、对比报告不存在、处理记录不存在、报告内容为空 |
| `A0500` | 业务异常 | 处理任务尚未完成，无法生成报告 |
| `A0515` | 当月次数已用完 | 评估配额不足 |
| `B0001` | 系统执行出错 | 报告生成失败 |
| `A0230` | token无效或已过期 | 未登录访问 |
