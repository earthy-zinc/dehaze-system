# 效果对比模块 API 接口

## 1. 文档概述

本文档定义 **效果对比** 模块的 HTTP API 规范，是该模块 API 契约的**唯一权威来源**。

- **基础路径**：
  - 评估：`/api/v1/evaluation`
  - 对比报告：`/api/v1/compare`
- **公共约定**：参见 [02-系统架构/04-API规范.md](../../../02-系统架构/04-API规范.md)
- **需求规格**：[需求规格.md](./需求规格.md)

> **重要**：接口详细参数/响应结构可通过 API 文档 MCP 查询，本文档仅定义接口清单和权限标识。

## 2. 接口清单

### 2.1 效果评估接口

> **异步任务模式**：评估为计算密集型任务，POST 立即返回 taskId + status，前端通过轮询直至终态。

| 路径 | 方法 | 功能描述 | 权限标识 | 关联功能点 |
|------|------|---------|---------|-----------|
| `/api/v1/evaluation` | POST | 提交效果评估（原图 + 结果图 + 可选 GT 参考图） | - | F-M05-005 |
| `/api/v1/evaluation/{taskId}` | GET | 轮询评估任务状态（processing/completed/failed） | - | F-M05-005 |
| `/api/v1/evaluation/metrics` | GET | 获取评估指标历史（当前用户的历史评估记录） | - | F-M05-005 |

### 2.2 对比报告接口

> **异步任务模式**：报告生成为异步任务，通过任务管理模块追踪进度。

| 路径 | 方法 | 功能描述 | 权限标识 | 关联功能点 |
|------|------|---------|---------|-----------|
| `/api/v1/compare/report` | POST | 生成对比报告（异步任务，通过任务管理追踪进度） | - | F-M05-005 |
| `/api/v1/compare/report/{taskId}` | GET | 下载对比报告（报告生成完成后返回文件流） | - | F-M05-005 |

## 3. 权限标识汇总

| 权限标识 | 说明 |
|---------|------|
| - | 效果对比无特殊权限标识，登录用户即可操作 |

## 4. 业务错误码

| 错误码 | 说明 | 触发场景 |
|--------|------|---------|
| `A0401` | 请求资源不存在 | 轮询的 taskId 不存在、对比报告不存在 |
| `A0701` | 文件格式不支持 | 上传的图片格式不支持 |
| `A0702` | 文件大小超限 | 上传图片超过大小限制 |
| `A0500` | 业务异常 | 评估任务参数不合法（如图片数量不匹配） |
| `B0100` | 系统执行超时 | 评估任务执行超时 |
| `B0001` | 系统执行出错 | 报告生成失败 |
| `A0230` | token无效或已过期 | 未登录访问 |
