# 效果对比模块 API 接口

## 1. 文档概述

本文档定义 **效果对比** 模块的 HTTP API 规范，是该模块 API 契约的**唯一权威来源**。

- **基础路径**：
  - 效果评估：`/api/v1/evaluation`
  - 对比报告：`/api/v1/compare`
- **公共约定**：参见 [02-系统架构/04-API规范.md](../../../02-系统架构/04-API规范.md)
- **需求规格**：[需求规格.md](./需求规格.md)

> **重要**：接口详细参数/响应结构可通过 API 文档 MCP 查询，本文档仅定义接口清单和权限标识。

## 2. 接口清单

### 2.1 效果评估接口

> **异步任务模式**：评估为计算密集型任务，POST 立即返回 `taskId + status=1(处理中)`，前端通过轮询直至终态（2 已完成 / 3 失败）。

| 路径 | 方法 | 功能描述 | 权限标识 | 关联功能点 |
|------|------|---------|---------|-----------|
| `/api/v1/evaluation` | POST | 提交效果评估（结果图 + 参考图 + 算法ID，异步） | - | F-M05-005 |
| `/api/v1/evaluation/{taskId}` | GET | 查询评估任务状态（1 处理中 / 2 已完成 / 3 失败） | - | F-M05-005 |
| `/api/v1/evaluation/metrics` | GET | 获取评估指标历史（当前用户，仅已完成记录） | - | F-M05-005 |
| `/api/v1/evaluation/logs` | GET | 获取评估日志列表（分页，支持算法ID筛选） | - | F-M05-005 |

**评估指标**：PSNR / SSIM / LPIPS / NIQE / NIMA / BRISQUE（其中 PSNR/SSIM/LPIPS 需要参考图，NIQE/NIMA/BRISQUE 为无参考指标）。

### 2.2 对比报告接口

> **异步任务模式**：报告生成复用 `sys_eval_log` 表存储（`taskId` 即评估日志 ID），**不经过任务管理模块**。

| 路径 | 方法 | 功能描述 | 权限标识 | 关联功能点 |
|------|------|---------|---------|-----------|
| `/api/v1/compare/report` | POST | 生成对比报告（异步，返回 `taskId + status=1`） | - | F-M05-008 |
| `/api/v1/compare/report/{taskId}` | GET | 查询报告状态（默认，返回 JSON）；`?download=true` 时返回 HTML 报告文件流 | - | F-M05-008 |

## 3. 权限标识汇总

| 权限标识 | 说明 |
|---------|------|
| - | 效果对比无特殊权限标识，登录用户即可操作（评估受会员"评估次数"配额限制） |

## 4. 业务错误码

| 错误码 | 说明 | 触发场景 |
|--------|------|---------|
| `A0401` | 请求资源不存在 | 评估任务不存在、对比报告不存在、处理记录不存在、报告内容为空 |
| `A0500` | 业务异常 | 处理任务尚未完成，无法生成报告 |
| `A0515` | 当月次数已用完 | 评估配额不足（Python 算法服务侧返回） |
| `B0001` | 系统执行出错 | 报告生成失败 |
| `A0230` | token无效或已过期 | 未登录访问 |
