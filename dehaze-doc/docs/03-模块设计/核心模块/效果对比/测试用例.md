## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| 测试图片 | 原图和处理后图片（JPG/PNG），分辨率 1920×1080 | 用于各对比模式测试 |
| 测试用户 | 普通用户、VIP1、VIP2、SVIP 各 1 个 | 测试不同 VIP 权益 |
| 评估数据 | 已有 GT 参考图的处理结果 3 组 | 用于指标评估测试 |
| 处理记录 | 去雾处理模块已完成任务 5 条 | 用于对比页面入口 |
| 收藏数据 | 已收藏和未收藏的处理结果 | 测试收藏状态 |

### 3.2 数据清理策略

- 测试评估任务使用统一前缀 `test_compare_` 标识
- 测试结束后按前缀批量删除评估记录
- 测试评价数据按测试用户清理
- 测试报告文件按前缀批量删除

### 3.3 测试范围

**包含的功能点：**

- 并排对比（F-M05-001）：横屏/竖屏布局、同步缩放、同步移动
- 重叠对比（F-M05-002）：垂直/水平分隔线、自动对齐、动画播放
- 放大镜对比（F-M05-003）：倍数切换、大小切换、显示模式
- 滤镜调节对比（F-M05-004）：6 项滤镜参数、内置预设、自定义预设
- 指标对比（F-M05-005）：PSNR/SSIM/MSE/Entropy 等评估指标、异步任务模式
- 算法信息展示（F-M05-006）：基本信息、处理参数、性能数据
- 对比工具栏（F-M05-007）：保存、分享、重新处理、更换算法、导出报告、收藏
- VIP 权益差异验证
- 评价提交与低分告警
- 收藏集成与推荐集成

**不包含的功能点：**

- UI 组件渲染细节（响应式断点、动画过渡效果）
- 视频去雾对比（未来扩展）
- 3D 对比展示（未来扩展）
- 协作功能（未来扩展）
