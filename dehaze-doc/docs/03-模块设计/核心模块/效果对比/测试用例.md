# 效果对比模块 - 测试用例

## 1. 测试目标

- 验证并排对比（自适应布局、同步缩放、放大镜、滤镜调节、标签）（F-M02-001）
- 验证效果评估（异步任务提交、状态轮询、指标获取、表格/图表展示）（F-M02-002）
- 验证放大镜对比（形状/倍数/大小调节、多图同步）（F-M02-003）
- 验证滤镜调节（亮度/对比度/饱和度、边界值）（F-M02-004）
- 验证指标对比（PSNR/SSIM/LPIPS/NIQE/NIMA/BRISQUE、缓存命中、配额）（F-M02-005）
- 验证算法信息展示（名称/类型/权重/参数量/描述）（F-M02-006）
- 验证对比报告导出（异步生成、状态轮询、下载、失败处理）（F-M02-008）
- 验证安全性（未登录访问、配额限制）

---

## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| 测试图片 | 原图（haze）、处理结果图（pred）、参考图（gt）各若干组 | 用于评估与对比测试 |
| 测试用户 | 普通用户 1 个 | 评估配额校验 |
| 处理记录 | 去雾处理模块已完成任务 2 条、未完成任务 1 条 | 用于报告导出入口 |

### 3.2 数据清理策略

- 测试评估任务使用统一前缀标识，测试结束后按前缀批量删除评估日志
- 测试报告任务复用评估日志表，随评估日志一并清理

### 3.3 测试范围

**包含的功能点：**

- F-M02-001（并排对比）
- F-M02-002（效果评估，已实现部分）
- F-M02-003（放大镜对比）
- F-M02-004（滤镜调节）
- F-M02-005（指标对比）
- F-M02-006（算法信息展示）
- F-M02-008（对比报告导出）

**不包含的功能点（已迁移至 [模块远期规划登记](../../../05-改造计划/模块远期规划登记.md)）：**

- 重叠对比（F-M02-009）、双击手势、滤镜预设/自定义预设
- 多算法对比（VIP 差异化）、历史记录对比、工具栏扩展（保存/分享/收藏）
- 智能报告生成、收藏集成、推荐集成、消息通知
- 报告格式（PDF/PNG/CSV/JSON）
- 会员等级差异化权限控制
- 评价提交与低分告警

## 5. 关键边界与异常

| 场景 | 测试点 | 期望行为 |
|------|--------|---------|
| 未上传图片评估 | 三图不齐时点击评估 | 提示"请先上传图片" |
| 缺少参考图 | 未传 gtUrl 提交评估 | 返回 B0001 |
| 评估配额不足 | 配额耗尽后提交评估 | 返回 A0515，前端展示错误 |
| 处理记录未完成 | 对处理中的记录导出报告 | 返回 A0500，提示未完成 |
| 报告生成失败 | 生成过程异常 | 状态 3 + errorMessage，可重试 |
| 未登录访问 | 未登录调用评估/报告接口 | 返回 A0230 token 无效 |
| 放大镜倍数边界 | 滑块拖至 2（下限）/ 20（上限） | 倍数不低于 2、不超过 20 |
| 放大镜宽高边界 | 滑块拖至 100（下限）/ 1000（上限） | 宽高不低于 100、不超过 1000 |
| 滤镜滑块边界 | 拖至 -100 / +100 | 参数值被钳制在有效范围 |
| 雷达图固定上限 | 不同评估结果切换 | 各维度上限固定（PSNR=100、SSIM=1 等），禁止动态缩放 |

## 6. 性能与并发

### 6.1 性能指标

| 指标 | 目标值 |
|------|--------|
| 评估任务提交响应 | ≤ 2s |
| 评估任务计算（首次加载模型） | ≤ 30s（P95） |
| 评估任务计算（模型已加载） | ≤ 10s（P95） |
| 报告生成提交响应 | ≤ 2s |
| 报告异步生成 | ≤ 10s（P95） |
| 操作响应（放大镜/滤镜） | ≤ 100ms |
| 评估缓存命中返回 | ≤ 2s |

### 6.2 并发场景

| 场景 | 并发数 | 验证点 |
|------|--------|--------|
| 并发提交评估任务 | 10 用户 | 评估任务正确创建，配额扣减正确，失败时配额恢复 |
| 并发生成对比报告 | 10 用户 | 报告任务正确生成，无相互干扰 |
