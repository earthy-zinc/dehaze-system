## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| 测试图片 | 原图（haze）、处理结果图（pred）、参考图（gt）各若干组 | 用于评估与对比测试 |
| 测试用户 | 普通用户 1 个 | 评估配额校验 |
| 处理记录 | 去雾处理模块已完成任务 2 条、未完成任务 1 条 | 用于报告导出入口 |

### 3.2 数据清理策略

- 测试评估任务使用统一前缀标识，测试结束后按前缀批量删除评估日志
- 测试报告任务复用评估日志表，随评估日志一并清理

### 3.3 测试范围

**包含的功能点：**

- 并排对比（F-M05-001）：自适应布局、同步缩放、放大镜、滤镜、标签
- 效果评估页（F-M05-002 已实现部分）：上传、评估、指标/图片/参数三 Tab
- 放大镜（F-M05-003）：形状/倍数/大小切换
- 滤镜调节（F-M05-004）：亮度/对比度/饱和度
- 指标对比（F-M05-005）：异步评估、指标获取、表格/雷达图/柱状图、参数对比
- 算法信息展示（F-M05-006）：名称/类型/权重/flops/参数量/描述
- 对比报告导出（F-M05-008）：异步生成、状态轮询、下载、失败处理

**不包含的功能点（规划中/未实现）：**

- 滑动分隔线重叠对比、双击手势、滤镜预设/自定义预设
- 多算法对比（VIP 差异化）、历史记录对比
- 报告格式（PDF/PNG/CSV/JSON）
- 收藏集成、推荐集成、消息通知
- 会员等级差异化权限控制
- 评价提交与低分告警

## 5. 关键边界与异常场景

| 场景 | 测试点 | 期望行为 |
|------|--------|---------|
| 未上传图片评估 | 三图不齐时点击评估 | 提示"请先上传图片" |
| 评估配额不足 | 配额耗尽后提交评估 | 返回 A0515，前端展示错误 |
| 处理记录未完成 | 对处理中的记录导出报告 | 返回业务错误，提示未完成 |
| 报告生成失败 | 生成过程异常 | 状态 3 + errorMessage，可重试 |
| 未登录访问 | 未登录调用评估/报告接口 | 返回 A0230 token 无效 |

## 6. 性能与并发测试

### 6.1 性能指标

| 指标 | 目标值 | 测试方法 |
|------|--------|---------|
| 评估任务提交响应 | < 1s | 提交评估到返回 logId |
| 评估状态轮询响应 | < 500ms | 单次轮询请求 |
| 报告生成 | < 30s | 从提交报告生成到完成 |
| 报告下载响应 | < 2s | download=true 返回 HTML 流 |

### 6.2 并发场景

| 场景 | 并发数 | 验证点 |
|------|--------|--------|
| 并发提交评估任务 | 10 用户 | 评估任务正确创建，配额扣减正确，失败时配额恢复 |
