# 算法管理模块 - 测试用例

## 1. 测试目标

- 验证算法列表与详情查询（树形结构、搜索、筛选、数据范围隔离）（F-M05-001、F-M05-002）
- 验证新增算法（必填校验、名称唯一、模型文件上传）（F-M05-003）
- 验证审核机制（审核通过/驳回、驳回原因必填、状态约束）（F-M05-004）
- 验证修改与版本管理（基本信息修改、版本创建/回滚、缓存失效）（F-M05-005）
- 验证停用/删除算法（状态约束、级联删除、关联数据保护）（F-M05-006）
- 验证导入导出功能（模板下载、导入校验、格式限制）（F-M05-007）
- 验证性能监控（监控指标、统计报表）（F-M05-008）
- 验证模型预测与效果评估的算法侧契约（缓存命中、日志记录）（F-M05-009、F-M05-010）
- 验证状态机流转合法性（非法跳跃拒绝、终态约束）
- 验证权限控制与安全性

## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 数据准备 |
|---------|---------|
| 用户数据 | 超级管理员、算法管理员、算法开发者、普通用户各1个 |
| 角色权限 | 配置 `sys:algorithm:*` 相关权限 |
| 算法数据 | 各状态算法（草稿1/测试中2/待审核3/已发布4/已停用5/已归档6）各1个 |
| 模型文件 | 有效的 .pth/.onnx/.h5 测试文件 |
| 测试图片 | 雾霾图 + 清晰图各3张 |

### 3.2 数据清理策略

- 测试创建的算法、版本记录在测试结束后清理
- 系统预置算法与预设不可删除，保留不动
- 测试导入的算法记录按测试前缀批量删除

### 3.3 测试范围

**包含的功能点**：F-M05-001 ~ F-M05-010（算法列表、详情、新增、审核、修改、停用/删除、导入导出、监控、预测、评估）

**不包含的功能点**：

- Python 算法服务内部实现
- MinIO 文件存储底层
- 预测调用流程与评估流程（归属去雾处理模块与效果对比模块）

## 5. 关键边界与异常

### 5.1 状态机约束

| 边界条件 | 测试点 | 期望行为 |
|---------|--------|---------|
| 非法状态跳跃 | 草稿直接->已发布 | 返回 A0502 状态不允许操作 |
| 已归档终态 | 已归档状态尝试变更 | 返回 A0502 状态不允许操作 |
| 删除已发布算法 | 对已发布状态算法执行删除 | 返回 A0502 状态不允许删除 |
| 删除正在使用的算法 | 算法有预测任务进行中 | 返回 A0504 存在关联数据 |
| 审核非待审核状态 | 对非待审核状态执行审核 | 返回 A0502 状态不允许操作 |

### 5.2 唯一性与校验边界

| 边界条件 | 测试点 | 期望行为 |
|---------|--------|---------|
| 算法名称重复 | 新增/导入时名称已存在 | 返回 A0501 数据已存在 |
| 版本号重复 | 创建已存在的版本号 | 返回 A0501 数据已存在 |
| 回滚到当前版本 | versionId 为当前活跃版本 | 返回 A0502 状态不允许操作 |
| 审核驳回原因为空 | 驳回时未填写 remark | 返回 B0001 驳回时必须填写审核备注 |
| 导入必填字段为空 | Excel 中 name/type 列为空 | 返回 A0706 必填字段为空 |
| 导入名称冲突 | 导入数据含已有算法名称 | 返回 A0707 数据校验失败 |
| 导入文件超大 | Excel 文件超过 20MB | 返回 B0001 文件大小超限 |

### 5.3 模型文件边界

| 边界条件 | 测试点 | 期望行为 |
|---------|--------|---------|
| 模型格式不支持 | 上传 .txt/.exe 文件 | 拒绝，仅允许 .pt/.pth/.onnx/.h5 |
| 导入文件格式不支持 | 上传 .txt 文件导入 | 返回 A0701 文件格式不支持 |

### 5.4 缓存一致性

| 场景 | 验证点 | 期望行为 |
|------|--------|---------|
| 算法列表缓存 | 新增/删除算法后查询 | 列表查询返回最新数据 |
| 算法详情缓存 | 修改算法后查询 | 详情查询返回最新数据 |
| 预测结果缓存 | 相同算法+版本+图像重复请求 | 命中缓存，响应时间显著降低 |
| 版本切换缓存失效 | 算法版本切换后 | 历史预测缓存自动失效 |
| 监控数据缓存 | 缓存过期后查询 | 重新计算，返回最新指标 |

## 7. 安全性测试

| 测试项 | 验证方式 | 预期结果 |
|--------|---------|---------|
| 权限控制 | 无权限用户调用审核/停用/删除接口 | 返回 403 |
| SQL 注入 | 名称字段注入 `admin'--` | 恶意输入被拦截，返回错误 |
| XSS 攻击 | 描述字段注入 `&lt;script&gt;` | 恶意脚本被拦截，返回错误 |
| 文件上传 | 上传 .exe/.sh 文件 | 拒绝，仅允许 .pt/.pth/.onnx/.h5 |
| 越权访问 | 开发者尝试删除他人算法 | 失败，数据范围隔离 |
| 导入包安全 | 上传包含恶意脚本的 .zip | 拒绝 |
