# 算法管理模块测试用例

- [ ] 验证核心功能符合 [需求规格](./需求规格.md)

## 2. 测试前置

### 2.1 测试数据

| 数据类型 | 数据准备 |
|---------|---------|
| 用户数据 | 超级管理员、算法管理员、算法开发者、普通用户各1个 |
| 角色权限 | 配置 `sys:algorithm:*` 相关权限 |
| 算法数据 | 各状态算法（草稿/测试中/待审核/已发布/已停用）各1个 |
| 模型文件 | 有效的 .pth/.onnx/.h5 测试文件 |
| 测试图片 | 雾霾图 + 清晰图各3张 |

### 2.2 测试范围

**包含的功能点**：
- F-M05-001 ~ F-M05-010（算法列表、详情、新增、审核、修改、停用/删除、导入导出、监控、预测、评估）

**不包含的功能点**：
- Python 算法服务内部实现
- MinIO 文件存储底层

## 4. 接口测试要点

> API 契约详见 [API接口文档](./API接口.md)

### 4.1 接口级测试

| 接口 | 测试重点 |
|------|---------|
| GET /api/v1/algorithm | 树形结构构建、搜索筛选、权限过滤 |
| POST /api/v1/algorithm | 参数校验、唯一性校验、状态初始化 |
| PUT /api/v1/algorithm/{id}/audit | 审核权限、状态转换、驳回原因校验 |
| POST /api/v1/algorithm/_import | 包格式校验、配置解析、名称冲突检测 |
| POST /api/v1/prediction | 缓存命中、超时处理、日志记录 |
| POST /api/v1/evaluation | 指标计算准确性、缓存机制、result JSON 结构 |

### 4.2 异常参数测试

- 缺少必填项（name, type, import_path）
- 字段类型错误（id 传字符串）
- 超长字符串（name > 64, description > 2048）
- SQL 注入字符（`admin'--`）
- XSS 注入（`&lt;script&gt;alert(1)&lt;/script&gt;`）

## 5. 关键边界与异常场景

| 场景 | 测试点 | 期望行为 |
|------|--------|---------|
| 状态流转 | 草稿→测试中→待审核→已发布 | 按规则流转，不允许跳跃 |
| 审核驳回 | 驳回原因必填 | 空原因返回 B0208 |
| 版本回滚 | 回滚到已归档版本 | 返回 B0206 |
| 导入冲突 | 名称与现有算法重复 | 返回 B0201，提示修改名称 |
| 预测缓存 | 相同图片+算法 | 第二次请求命中缓存，不调用 Python |
| 版本更新缓存 | 算法更新版本后 | 该算法所有预测缓存失效 |
| 并发预测 | 100 用户同时预测 | Redis 分布式锁防重，结果正确 |

## 7. 安全性测试

| 测试项 | 验证方式 | 预期结果 |
|--------|---------|---------|
| 权限控制 | 无权限用户调用审核/停用/删除接口 | 返回 403 |
| SQL 注入 | 名称字段注入 `admin'--` | 被参数化查询转义 |
| XSS 攻击 | 描述字段注入 `&lt;script&gt;` | 输出时编码 |
| 文件上传 | 上传 .exe/.sh 文件 | 拒绝，仅允许 .pt/.pth/.onnx/.h5 |
| 越权访问 | 开发者尝试删除他人算法 | 失败，数据范围隔离 |
| 导入包安全 | 上传包含恶意脚本的 .zip | 拒绝或沙箱执行 |
