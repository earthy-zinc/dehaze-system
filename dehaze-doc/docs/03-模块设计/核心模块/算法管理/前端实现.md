# 算法管理模块 - 前端实现设计

## 1. 文档概述

本文档描述算法管理模块的前端实现方案，聚焦组件架构、状态管理、路由设计等架构决策。

---

## 2. 组件设计

### 2.1 组件结构

```
算法管理模块
├── AlgorithmList          # 算法列表页面
│   └── AlgorithmTree      # 算法树形表格（可复用）
├── AlgorithmDetail        # 算法详情页面
│   ├── VersionTimeline    # 版本时间线
│   └── AuditInfo          # 审核信息展示
├── AlgorithmForm          # 算法表单（新增/编辑）
│   ├── ModelUploader      # 模型文件上传
│   └── ConfigEditor       # JSON配置编辑器（可复用）
├── AlgorithmAudit         # 算法审核页面
│   └── AuditForm          # 审核表单（通过/驳回）
├── AlgorithmImportExport  # 导入导出页面
│   ├── ImportDialog       # 导入弹窗（上传+校验+预览）
│   └── ExportDialog       # 导出弹窗（单个/批量）
├── VersionManage          # 版本管理页面
├── AlgorithmMonitor       # 性能监控页面
│   └── MetricsChart       # 监控图表（可复用）
├── PredictionTest         # 预测测试页面
│   └── ImageCompare       # 图片对比组件（可复用）
└── EvaluationResult       # 效果评估页面
    └── MetricsDisplay     # 评估指标展示（PSNR/SSIM/LPIPS等）
```

### 2.2 组件列表

| 组件 | 职责 | 复用性 |
|------|------|--------|
| AlgorithmTree | 算法树形展示，支持搜索过滤 | 可复用于算法选择器 |
| AuditInfo | 审核信息展示（审核人、时间、备注） | 详情页专用 |
| AuditForm | 审核表单（通过/驳回+原因） | 审核页专用 |
| ImportDialog | 算法导入弹窗（上传+校验+预览） | 导入文件格式：`.xlsx`/`.xls`/`.csv`，≤20MB |
| ExportDialog | 算法导出弹窗（单个/批量） | 导出格式：`.xlsx`（默认）/ `.csv`，元数据导出（不含模型权重） |
| MetricsChart | 监控指标图表 | 可复用于其他监控场景 |
| MetricsDisplay | 评估指标展示（PSNR/SSIM/LPIPS/NIQE/Entropy） | 评估结果页 |
| ImageCompare | 图片对比展示（去雾前后） | 可复用于效果对比 |
| ConfigEditor | JSON 配置参数编辑器 | 通用组件 |

## 3. 组件架构

### 3.1 组件层级关系

- **页面组件**：直接对应路由，负责页面整体布局和数据获取
- **业务组件**：封装特定业务逻辑，如审核表单、导入弹窗
- **通用组件**：可跨模块复用，如树形表格、图表组件

### 3.2 组件通信方式

| 通信场景 | 推荐方式 |
|---------|---------|
| 父子组件 | Props / Events |
| 跨层级组件 | 状态管理 Store |
| 兄弟组件 | 状态管理 Store / 事件总线 |

## 4. 页面布局设计

### 4.1 页面结构

| 页面 | 布局方式 |
|------|---------|
| 列表页 | 全宽单栏：搜索区域 + 表格区域 |
| 详情页 | 左右分栏：主内容区(70%) + 侧边栏(30%) |
| 监控页 | 网格布局：概览卡片(4列) + 图表区域(2列) + 详情表格(全宽) |

### 4.2 路由配置

| 路由路径 | 页面 | 说明 |
|---------|------|------|
| /algorithm | AlgorithmList | 算法列表 |
| /algorithm/:id | AlgorithmDetail | 算法详情 |
| /algorithm/create | AlgorithmForm | 新增算法 |
| /algorithm/:id/edit | AlgorithmForm | 编辑算法 |
| /algorithm/:id/audit | AlgorithmAudit | 算法审核 |
| /algorithm/import-export | AlgorithmImportExport | 导入导出 |
| /algorithm/:id/version | VersionManage | 版本管理 |
| /algorithm/:id/monitor | AlgorithmMonitor | 性能监控 |
| /algorithm/prediction | PredictionTest | 预测测试 |
| /algorithm/evaluation | EvaluationResult | 效果评估 |

## 5. 状态管理

### 5.1 状态定义

| Store | 职责 |
|-------|------|
| algorithmStore | 算法列表、详情、版本管理、审核、导入导出 |
| predictionStore | 预测任务、结果、日志 |
| evaluationStore | 评估任务、结果（含 LPIPS 等指标）、日志 |
| monitorStore | 监控数据、统计报表 |

### 5.2 状态更新逻辑

**algorithmStore Actions**

| 方法名 | 说明 |
|--------|------|
| fetchAlgorithmTree() | 获取算法树形列表 |
| getAlgorithmDetail(id) | 获取算法详情 |
| createAlgorithm(form) | 新增算法 |
| updateAlgorithm(id, form) | 更新算法 |
| deleteAlgorithm(id) | 删除算法 |
| updateStatus(id, status) | 更新算法状态 |
| auditAlgorithm(id, action, remark) | 审核算法（通过/驳回） |
| fetchVersionHistory(id) | 获取版本历史 |
| createVersion(id, form) | 创建新版本 |
| rollbackVersion(id, version) | 版本回滚 |
| exportAlgorithm(id) | 导出算法元数据（通过通用导入导出框架） |
| batchExportAlgorithms(ids) | 批量导出算法元数据 |
| downloadImportTemplate() | 下载导入模板（Excel/CSV） |
| importAlgorithm(file, options) | 导入算法元数据 |

**predictionStore Actions**

| 方法名 | 说明 |
|--------|------|
| submitPrediction(form) | 提交预测任务 |
| getTaskStatus(taskId) | 查询任务状态 |
| fetchPredictionLogs() | 获取预测日志列表 |

**evaluationStore Actions**

| 方法名 | 说明 |
|--------|------|
| submitEvaluation(form) | 提交评估任务 |
| getTaskStatus(taskId) | 查询任务状态 |
| fetchEvaluationLogs() | 获取评估日志列表 |

**评估结果数据结构**

| 字段 | 类型 | 说明 |
|------|------|------|
| psnr | number | 峰值信噪比，越高越好（通常>30dB为好） |
| ssim | number | 结构相似性，0-1，越接近1越好 |
| lpips | number | 学习感知图像块相似度，0-1，越低越好 |
| niqe | number | 自然图像质量评价，越低越好 |
| entropy | number | 信息熵，越高越好 |

**推荐指数说明**：

算法管理模块中算法的推荐指数由[推荐管理模块](../../基础模块/推荐管理/需求规格.md)计算并提供，算法管理模块负责展示和管理：

| 操作 | 说明 |
|------|------|
| 列表展示 | 算法树形表格中展示推荐指数（星级或数值） |
| 详情展示 | 算法详情页头部信息区域展示推荐指数 |
| 新增/编辑 | 算法表单中支持手动设置推荐指数初始值（0-5星），后续由推荐管理模块根据用户反馈动态更新 |
| 导入/导出 | 导入导出模板中包含推荐指数字段 |

**monitorStore Actions**

| 方法名 | 说明 |
|--------|------|
| fetchMonitorData(algorithmId) | 获取监控数据 |
| fetchStatsReport(algorithmId, timeRange) | 获取统计报表 |
| startRealtimePolling(algorithmId) | 开始实时轮询 |
| stopRealtimePolling() | 停止实时轮询 |

## 7. 表单校验规则

### 7.1 算法基本信息

| 字段 | 校验规则 | 错误提示 |
|------|---------|---------|
| name | 必填，2-50字符，全局唯一 | 算法名称不能为空/已存在 |
| code | 必填，字母数字下划线，全局唯一 | 算法编码格式错误/已存在 |
| type | 必填 | 请选择算法类型 |
| description | 最大500字 | 描述不能超过500字 |
| rating | 0-5星，可选 | 推荐指数（初始值，后续由推荐管理模块动态更新） |

### 7.2 版本信息

| 字段 | 校验规则 | 错误提示 |
|------|---------|---------|
| version | 必填，语义化版本格式(x.x.x) | 版本号格式错误 |
| changeLog | 必填，最大1000字 | 变更说明不能为空 |

### 7.3 模型上传

| 校验项 | 规则 | 错误提示 |
|--------|------|---------|
| 文件格式 | .pt/.pth/.onnx/.h5 | 仅支持 .pt/.pth/.onnx/.h5 格式 |
| 文件大小 | ≤500MB | 文件大小不能超过 500MB |

### 7.4 算法导入

| 校验项 | 规则 | 错误提示 |
|--------|------|---------|
| 文件格式 | .xlsx/.xls/.csv | 支持 .xlsx、.xls、.csv 格式 |
| 文件大小 | ≤20MB | 文件大小不能超过 20MB |
| 必填字段 | name、type 不能为空 | 必填字段不能为空 |
| 名称唯一 | 算法名称不能重复 | 算法名称已存在，请修改 |

> 导入导出由通用 `ImportExportToolbar` 组件实现，算法模块通过 `module="algorithm"` 接入，支持模板下载、同步/异步导出、批量导入。

### 7.5 审核表单

| 字段 | 校验规则 | 错误提示 |
|------|---------|---------|
| action | 必选，通过/驳回 | 请选择审核操作 |
| remark | 驳回时必填，最大500字 | 驳回原因不能为空 |

## 9. 性能优化

| 优化项 | 实现方式 |
|--------|---------|
| 树形懒加载 | 展开节点时按需加载子节点 |
| 虚拟滚动 | 大数据量时使用虚拟列表 |
| 搜索防抖 | 输入防抖 300ms |
| 图表懒加载 | 进入视口后加载图表 |
| 轮询控制 | 页面不可见时停止轮询 |
| 分片上传 | 大文件分片上传 + 断点续传 |
| 请求取消 | 切换页面时取消未完成请求 |
