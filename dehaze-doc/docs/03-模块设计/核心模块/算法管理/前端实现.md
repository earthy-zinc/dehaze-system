# 算法管理模块 - 前端实现设计

## 1. 文档概述

本文档描述算法管理模块的前端实现方案，聚焦组件架构、状态管理、路由设计等架构决策。字段级业务规则、校验规则、评估指标定义、权限标识等见 [需求规格.md](./需求规格.md) 与 [API接口.md](./API接口.md)。

---

## 2. 组件设计

### 2.1 组件结构

```
算法管理模块
├── AlgorithmList              # 算法列表页面（左右布局）
│   ├── CategoryTree           # 左侧：算法分类树（按 parent_id 层级 + task_type 分组）
│   └── AlgorithmTable         # 右侧：算法列表表格（搜索 + task_type 筛选 + 操作按钮）
├── AlgorithmDetail            # 算法详情页面（垂直布局 + Tab）
│   ├── DetailHeader           # 头部：基本信息 + 操作工具栏
│   └── DetailTabs             # Tab：基本信息 / 技术信息 / 运营信息
├── AlgorithmForm              # 算法表单（新增/编辑）
│   └── ConfigEditor           # JSON 配置参数编辑器（可复用）
├── AlgorithmAudit             # 算法审核页面
│   └── AuditForm              # 审核表单（通过/驳回）
├── AlgorithmImportExport      # 导入导出（通用 ImportExportToolbar 接入）
├── VersionManage              # 版本管理页面
├── AlgorithmMonitor           # 性能监控页面
│   └── MetricsChart           # 监控图表（可复用）
├── PredictionTest             # 预测测试页面
│   └── ImageCompare           # 图片对比组件（可复用）
└── EvaluationResult           # 效果评估页面
    └── MetricsDisplay         # 评估指标展示
```

### 2.2 组件列表

| 组件 | 职责 | 复用性 |
|------|------|--------|
| CategoryTree | 算法分类树，按 parent_id 层级组织，支持 task_type 分组筛选 | 列表页左侧 |
| AlgorithmTable | 算法列表表格，支持关键字搜索、task_type 筛选、状态展示、操作按钮 | 列表页右侧 |
| AuditForm | 审核表单（通过/驳回 + 驳回原因） | 审核页专用 |
| MetricsChart | 监控指标图表（调用次数趋势等） | 可复用于其他监控场景 |
| MetricsDisplay | 评估指标展示（PSNR/SSIM 等） | 评估结果页 |
| ImageCompare | 图片对比展示（去雾前后） | 可复用于效果对比 |
| ConfigEditor | JSON 配置参数编辑器 | 通用组件 |

> 导入导出由通用 `ImportExportToolbar` 组件实现，算法模块通过 `module="algorithm"` 接入，支持模板下载、同步/异步导出、批量导入。

## 3. 组件架构

### 3.1 组件层级关系

- **页面组件**：直接对应路由，负责页面整体布局和数据获取
- **业务组件**：封装特定业务逻辑，如分类树、审核表单
- **通用组件**：可跨模块复用，如图表组件、配置编辑器

### 3.2 组件通信方式

| 通信场景 | 推荐方式 |
|---------|---------|
| 父子组件 | Props / Events |
| 跨层级组件 | 状态管理 Store |
| 兄弟组件 | 状态管理 Store |

---

## 4. 页面布局设计

### 4.1 页面结构

| 页面 | 布局方式 |
|------|---------|
| 列表页 | 左右布局：左侧分类树（CategoryTree）+ 右侧列表表格（AlgorithmTable） |
| 详情页 | 垂直布局：头部信息 + 工具栏，主体 Tab 切换（基本信息/技术信息/运营信息） |
| 监控页 | 网格布局：概览卡片 + 趋势图表 + 详情表格 |

> 任务类型（task_type）为本次改造新增维度，分类树支持按 task_type 分组，列表表格支持 task_type 筛选，详见 [需求规格.md §1.1 / §2.1.2](./需求规格.md)。

### 4.2 路由配置

| 路由路径 | 页面 | 说明 |
|---------|------|------|
| /algorithm | AlgorithmList | 算法列表 |
| /algorithm/:id | AlgorithmDetail | 算法详情 |
| /algorithm/create | AlgorithmForm | 新增算法 |
| /algorithm/:id/edit | AlgorithmForm | 编辑算法 |
| /algorithm/:id/audit | AlgorithmAudit | 算法审核 |
| /algorithm/import-export | AlgorithmImportExport | 导入导出 |
| /algorithm/:id/version | VersionManage | 版本管理 |
| /algorithm/:id/monitor | AlgorithmMonitor | 性能监控 |
| /algorithm/prediction | PredictionTest | 预测测试 |
| /algorithm/evaluation | EvaluationResult | 效果评估 |

## 5. 状态管理

### 5.1 状态定义

| Store | 职责 |
|-------|------|
| algorithmStore | 算法列表、详情、版本管理、审核、导入导出 |
| predictionStore | 预测任务、结果、日志 |
| evaluationStore | 评估任务、结果、日志 |
| monitorStore | 监控数据、统计报表 |

### 5.2 状态更新逻辑

**algorithmStore Actions**

| 方法名 | 说明 |
|--------|------|
| fetchAlgorithmTree(params) | 获取算法树形列表（支持 keywords、task_type 筛选） |
| getAlgorithmDetail(id) | 获取算法详情 |
| createAlgorithm(form) | 新增算法（含 task_type 字段） |
| updateAlgorithm(id, form) | 更新算法 |
| deleteAlgorithm(id) | 删除算法 |
| updateStatus(id, status) | 更新算法状态 |
| auditAlgorithm(id, action, remark) | 审核算法（通过/驳回） |
| fetchVersionHistory(id) | 获取版本历史 |
| createVersion(id, form) | 创建新版本 |
| rollbackVersion(id, version) | 版本回滚 |
| exportAlgorithm(id) | 导出算法元数据（通过通用导入导出框架） |
| batchExportAlgorithms(ids) | 批量导出算法元数据 |
| downloadImportTemplate() | 下载导入模板（Excel/CSV，含 task_type 字段） |
| importAlgorithm(file, options) | 导入算法元数据 |

**predictionStore Actions**

| 方法名 | 说明 |
|--------|------|
| submitPrediction(form) | 提交预测任务 |
| getTaskStatus(taskId) | 查询任务状态 |
| fetchPredictionLogs() | 获取预测日志列表 |

**evaluationStore Actions**

| 方法名 | 说明 |
|--------|------|
| submitEvaluation(form) | 提交评估任务 |
| getTaskStatus(taskId) | 查询任务状态 |
| fetchEvaluationLogs() | 获取评估日志列表 |

> 评估结果含 PSNR/SSIM 等指标，指标定义详见 [需求规格.md §2.10.2](./需求规格.md)。

**推荐指数数据流**

算法推荐指数由 [推荐管理模块](../../基础模块/推荐管理/需求规格.md) 计算并提供，本模块负责展示与初始值录入：

| 场景 | 处理方式 |
|------|---------|
| 列表/详情展示 | 展示推荐指数（星级） |
| 新增/编辑表单 | 支持手动设置初始值（0-5星），后续由推荐管理模块动态更新 |
| 导入/导出 | 模板包含推荐指数字段 |

**monitorStore Actions**

| 方法名 | 说明 |
|--------|------|
| fetchMonitorData(algorithmId) | 获取监控数据 |
| fetchStatsReport(algorithmId, timeRange) | 获取统计报表 |
| startRealtimePolling(algorithmId) | 开始实时轮询 |
| stopRealtimePolling() | 停止实时轮询 |

## 6. 错误处理

算法模块复用系统通用错误码体系（A 系列），不单独定义算法专属业务码。错误码定义详见 [API接口.md §4](./API接口.md)。

| 错误类型 | 处理方式 |
|---------|---------|
| 业务错误（A 系列，如 A0501 数据已存在、A0502 状态不允许、A0701 文件格式不支持等） | 显示后端返回的错误信息 |
| 未认证（A0230 / 401） | 跳转登录页 |
| 禁止访问（403） | 显示权限不足提示 |
| 资源不存在（A0401 / 404） | 显示资源不存在提示 |
| 网络/服务器错误 | 显示通用错误提示 |

## 7. 校验交互设计

字段级校验规则（必填、长度、格式、唯一性等）详见 [需求规格.md §2.3.4](./需求规格.md)，本节仅描述前端特有的校验交互决策。

| 校验场景 | 交互设计 |
|---------|---------|
| 表单字段 | 失焦时触发同步校验，提交时统一校验所有字段 |
| 算法名称唯一性 | 提交时异步校验（调用后端），避免每次输入请求 |
| 版本号格式 | 前端按 vX.Y.Z 正则预校验，减少无效提交 |
| 模型文件路径 | 路径输入框，提交时由后端校验路径有效性（HTTP HEAD 校验） |
| 导入文件 | 上传前前端校验文件格式与大小，行级数据校验由后端完成 |
| 审核驳回 | 选择"驳回"时动态显示驳回原因输入框并置为必填 |

> 版本号格式统一为 vX.Y.Z（如 v2.1.3），与 [需求规格.md §2.3.3](./需求规格.md) 一致。

## 8. 权限控制

权限标识清单及控制范围详见 [需求规格.md §4.1](./需求规格.md) 与 [API接口.md §3](./API接口.md)。前端按权限标识控制按钮显隐，无权限时隐藏对应操作按钮。

> 查看算法详情/监控为登录用户默认权限，无独立权限标识；停用/启用通过编辑权限（`sys:algorithm:edit`）执行状态变更。

## 9. 性能优化

| 优化项 | 实现方式 |
|--------|---------|
| 分类树懒加载 | 展开节点时按需加载子节点 |
| 虚拟滚动 | 大数据量时使用虚拟列表 |
| 搜索防抖 | 输入防抖 300ms |
| 图表懒加载 | 进入视口后加载图表 |
| 轮询控制 | 页面不可见时停止轮询 |
| 请求取消 | 切换页面时取消未完成请求 |
