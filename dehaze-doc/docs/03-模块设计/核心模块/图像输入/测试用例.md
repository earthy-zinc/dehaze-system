# 图像输入模块 - 测试用例

## 1. 测试目标

- 验证 4 种输入方式（上传、拍照、样例、历史）的核心功能（F-M01-001 ~ F-M01-004）
- 覆盖图片格式验证、大小限制、分辨率限制、权限控制等边界条件
- 验证用户配额限制和过期清理策略
- 验证 MD5 去重（秒传）策略
- 验证性能指标（上传速度、加载时间）与并发场景
- 验证安全性（权限控制、文件上传安全、注入防护）

---

## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| 测试图片 | 各种格式：JPG, PNG, WEBP, HEIC, BMP | 包含有效和无效格式 |
| 测试图片 | 各种大小：1MB, 5MB, 10MB, 15MB, 25MB | 测试大小限制 |
| 测试图片 | 各种分辨率：320×240, 640×480, 1920×1080, 4K, 8K | 测试分辨率限制 |
| 测试用户 | 游客、注册用户、VIP 用户、企业用户 | 测试不同配额 |
| 样例图片 | 数据集管理模块中标记为公开的图片 | 至少 40 张 |
| 历史记录 | 已有的处理记录（成功/失败/处理中） | 各状态至少 5 条 |

### 3.2 数据清理策略

- 测试数据使用统一前缀 `test_input_` 标识
- 测试结束后按前缀批量删除
- 保留系统默认样例图片不做删除
- 测试历史记录使用独立的测试用户账号

### 3.3 测试范围

**包含的功能点**：F-M01-001（图片上传）、F-M01-002（拍照）、F-M01-003（样例图片库）、F-M01-004（历史记录）

**不包含的功能点**：

- 图片处理算法（属于算法管理模块）
- 数据集管理功能（由数据集管理模块测试）
- 用户权限管理（由用户管理模块测试）

## 5. 关键边界与异常

### 5.1 文件上传边界

| 边界条件 | 测试点 | 期望行为 |
|---------|--------|---------|
| 分辨率下限 | 上传 320×240 / 640×480 图片 | 低于 640×480 警告 A0703，允许上传 |
| 分辨率上限 | 免费用户上传 4K+ / VIP 上传 8K+ | 超限拒绝上传 |
| 批量上传上限 | 免费用户 5 张 / VIP 20 张 / 高级 VIP 100 张 | 超限拒绝并提示 |
| 格式白名单 | 上传 GIF/PDF/EXE 等非支持格式 | 返回 A0701 拒绝 |
| 损坏文件 | 上传内容损坏的图片文件 | 返回 B0003 拒绝 |

### 5.2 历史记录配额与清理

| 边界条件 | 测试点 | 期望行为 |
|---------|--------|---------|
| 保留时长 | 注册 30 天 / VIP 90 天 / 企业永久 | 过期记录定时清理 |
| 配额耗尽创建 | 关闭自动清理场景下超配额创建 | 返回 B0301 |

### 5.3 缓存与事务一致性

| 场景 | 验证点 | 期望行为 |
|------|--------|---------|
| 创建历史记录后查询 | 缓存是否更新 | 立即查询到新记录 |
| 删除历史记录后查询 | 缓存是否失效 | 查询不到已删除记录 |
| 创建历史记录失败 | 处理过程异常 | 不产生孤立记录，配额不增加 |
| 删除历史记录失败 | 删除过程异常 | 记录仍可查询，可重试删除 |

### 5.4 网络异常与重试

| 异常场景 | 测试点 | 期望行为 |
|---------|--------|---------|
| 服务器错误 | 上传时服务端 5xx | 自动重试 1 次（间隔 5s），失败后提示用户 |
| 格式错误 | 上传不支持的格式 | 不重试，直接提示错误原因 |

## 7. 安全性测试

| 测试项 | 验证方式 | 预期结果 |
|--------|---------|---------|
| 权限控制 | 未登录用户上传图片 | 返回 A0230，提示登录 |
| 越权访问 | 访问其他用户的历史记录 | 返回 B0300，提示记录不存在 |
| SQL 注入 | 参数包含 `admin'--` | 参数化查询转义 |
| XSS 攻击 | 图片描述注入 `&lt;script&gt;` | 输出编码 |
| CSRF 攻击 | 伪造上传请求 | Token 验证失败 |
| 文件上传漏洞 | 上传恶意脚本文件 | 格式白名单拒绝 |
