## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| 测试图片 | 各种格式：JPG, PNG, WEBP, HEIC, BMP | 包含有效和无效格式 |
| 测试图片 | 各种大小：1MB, 5MB, 10MB, 15MB, 25MB | 测试大小限制 |
| 测试图片 | 各种分辨率：320×240, 640×480, 1920×1080, 4K, 8K | 测试分辨率限制 |
| 测试用户 | 游客、注册用户、VIP 用户、企业用户 | 测试不同配额 |
| 样例图片 | 数据集管理模块中标记为公开的图片 | 至少 40 张 |
| 历史记录 | 已有的处理记录（成功/失败/处理中） | 各状态至少 5 条 |

### 3.2 数据清理策略

- 测试数据使用统一前缀 `test_input_` 标识
- 测试结束后按前缀批量删除
- 保留系统默认样例图片不做删除
- 测试历史记录使用独立的测试用户账号

### 3.3 测试范围

**包含的功能点：**

- 图片上传（拖拽、选择、粘贴）
- 拍照功能（权限、预览、裁剪）
- 样例图片库（分类、筛选、快速体验）
- 历史记录管理（创建、查询、删除、同步）
- 配额管理和清理策略
- 缩略图生成

**不包含的功能点：**

- 图片处理算法（属于算法管理模块）
- 数据集管理功能（由数据集管理模块测试）
- 用户权限管理（由用户管理模块测试）

## 7. 安全性测试

| 测试项 | 验证方式 | 预期结果 |
|--------|---------|---------|
| 权限控制 | 未登录用户上传图片 | 返回 401，提示登录 |
| 权限控制 | 免费用户上传超过配额 | 返回 403，提示升级 VIP |
| 越权访问 | 访问其他用户的历史记录 | 返回 403，提示无权限 |
| SQL 注入 | 参数包含 `admin'--` | 参数化查询转义 |
| XSS 攻击 | 图片描述注入 `&lt;script&gt;` | 输出编码 |
| CSRF 攻击 | 伪造上传请求 | Token 验证失败 |
| 文件上传漏洞 | 上传恶意脚本文件 | 格式白名单拒绝 |

## 8. 数据一致性测试

### 8.1 缓存一致性测试

| 场景 | 验证点 | 期望行为 |
|------|--------|---------|
| 创建历史记录后查询 | 缓存是否更新 | 立即查询到新记录 |
| 删除历史记录后查询 | 缓存是否失效 | 查询不到已删除记录 |
| 更新历史记录后查询 | 缓存是否刷新 | 查询到最新数据 |
| 同步历史记录后查询 | 本地和云端数据一致 | 本地和云端记录相同 |

### 8.2 事务回滚测试

| 场景 | 触发条件 | 验证点 |
|------|---------|--------|
| 创建历史记录失败 | 数据库异常 | 缩略图文件未生成，配额未更新 |
| 删除历史记录失败 | 文件删除失败 | 数据库记录未删除 |
| 同步失败 | 网络中断 | 记录到离线队列，数据库未更新 |
