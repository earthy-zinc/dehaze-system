# 图像输入模块 - 前端实现设计

## 1. 文档概述

本文档描述图像输入模块的前端架构决策，聚焦组件树、状态管理、路由与关键交互设计。业务规则、文件限制、错误提示、交互流程详见 [需求规格.md](./需求规格.md)（功能点编号 F-M01-001 ~ F-M01-004）；接口契约详见 [API接口.md](./API接口.md)。

## 2. 组件架构

### 2.1 组件树

```
ImageInputPage (页面容器，单路由 + Tab 组件状态切换)
├── ImageInputTabs (输入方式选择器)
├── UploadPanel (上传面板)
│   ├── DragDropZone (拖拽上传区域，Web/桌面端)
│   ├── FileSelector (文件选择器)
│   ├── ClipboardPasteListener (剪贴板粘贴监听，Web/桌面端)
│   ├── UploadProgress (上传进度)
│   └── ImagePreview (预览组件，复用公共组件)
├── CameraPanel (拍照面板)
│   ├── CameraStream (相机流)
│   ├── CameraControls (相机控制)
│   └── ImagePreview (预览组件)
├── SampleGallery (样例图片库)
│   ├── CategoryFilter (分类过滤器)
│   ├── ImageGrid (网格布局)
│   └── ImageCard (图片卡片)
└── HistoryList (历史记录列表)
    ├── HistoryCard (历史记录卡片)
    └── ResultActions (结果操作：重新处理/下载/分享/收藏/删除)
```

### 2.2 组件职责

| 组件 | 职责 |
|---------|------|
| ImageInputPage | 页面容器，路由入口，托管 Tab 状态与各面板 |
| ImageInputTabs | 输入方式切换 |
| UploadPanel | 上传流程编排：选择/粘贴/拖拽 → 校验 → MD5 去重 → 上传 |
| DragDropZone | 拖拽上传交互（Web/桌面端，移动端禁用） |
| FileSelector | 文件选择器，触发格式与大小校验 |
| ClipboardPasteListener | 监听剪贴板粘贴，提取图片接入上传流程 |
| UploadProgress | 上传进度、速度、剩余时间展示 |
| CameraPanel | 相机流程编排：权限 → 取流 → 拍摄 → 预览 → 上传 |
| CameraStream | 相机流渲染 |
| CameraControls | 前后切换/闪光灯/对焦/网格线/变焦控制 |
| SampleGallery | 样例库展示与选择，对接推荐管理模块取推荐算法 |
| CategoryFilter | 按任务类型/场景过滤样例 |
| ImageGrid | 虚拟滚动 + 懒加载的缩略图网格 |
| HistoryList | 历史记录列表，时间分组与本地/云端同步 |
| HistoryCard | 单条历史记录展示与操作入口 |
| ResultActions | 结果操作菜单（重新处理/更换算法/下载/分享/收藏/删除） |

### 2.3 组件通信

统一使用 Pinia 管理跨组件状态，不引入 EventBus。理由：Tab 内组件树固定，状态变更均可由 Pinia Store 驱动，无一次性全局事件需求，避免 Pinia 与 EventBus 职责重叠。

| 通信场景 | 方式 |
|---------|------|
| 父子组件 | Props + Emits（单向数据流） |
| 跨层级/兄弟组件 | Pinia Store |
| 配置注入 | Provide/Inject |

## 3. 路由与响应式

### 3.1 路由设计

`/image-input` 为单一路由，4 个输入方式（上传/拍照/样例/历史）通过 Tab 组件状态切换，不拆分为子路由。理由：Tab 切换高频，子路由切换会销毁/重建组件并丢失本地状态（已选拍照预览、上传队列、样例筛选），改用组件状态切换（缓存各面板实例）以保留状态。

### 3.2 响应式断点

断点体系对齐 UI-UX 规范：sm 640px / md 768px / lg 1024px / xl 1280px。

| 断点 | 布局方式 | 特殊处理 |
|---------|---------|---------|
| <sm(640px) | 单列布局，全屏 Tab | 拖拽禁用，优先拍照 |
| sm~lg(640~1024px) | 双列网格 | 支持拖拽上传、剪贴板粘贴 |
| ≥xl(1280px) | 三列网格 | 完整功能，支持快捷键 |

## 4. 状态管理

### 4.1 Store 划分

模块级 Store 精简为 3 个，跨模块引用用户管理模块的 `useUserStore`：

| Store | 职责 | 核心状态 |
|---------|------|---------|
| useImageInputStore | 输入流程总状态 | activeTab、selectedImage（输出给去雾处理）、uploadQueue/progress/results、sampleFilter、md5Cache（已查询 MD5→文件 URL 映射） |
| useHistoryStore | 历史记录 | localRecords、cloudRecords、syncStatus、quota(used/total) |
| useCameraStore | 相机 | permission、stream、deviceCapability（前后摄像头/闪光灯） |
| useUserStore（引用用户管理模块） | 用户配额 | 用户类型、文件大小/数量配额 |

合并说明：原 `useUploadStore`/`useSampleStore`/`useImageStore` 并入 `useImageInputStore`（上传队列、样例筛选、选中图片同属输入流程强相关状态，原 `useImageStore` 与 `useImageInputStore` 命名易混）；原 `useDeviceStore` 并入 `useCameraStore`（设备能力检测仅服务于相机）。

### 4.2 核心数据流

**上传流程状态流转**（业务规则见 F-M01-001）：

| 阶段 | 状态变更 |
|---------|---------|
| 选择/粘贴/拖入文件 | uploadQueue 新增项 |
| MD5 去重查询 | md5Cache 命中 → 直接产出 selectedImage，跳过上传；未命中 → 进入上传 |
| 上传中 | progress 更新 |
| 上传成功 | results 记录，selectedImage 就绪，跳转算法选择页 |
| 上传失败 | 记录错误，保留队列项供重试 |

**历史记录同步**：登录后自动拉取云端记录与本地合并（按时间戳去重，冲突保留最新）；本地存储采用 IndexedDB 支持离线；离线操作入队，网络恢复后同步。同步类型、触发时机与优先级见需求规格 F-M01-004 §2.4.5。

## 5. 关键交互设计决策

### 5.1 图片上传（F-M01-001）

| 触发方式 | 实现决策 |
|---------|---------|
| 上传按钮 / 文件选择器 | FileSelector，全平台 |
| 拖拽上传 | DragDropZone，Web/桌面端；移动端禁用 |
| 剪贴板粘贴（Ctrl+V） | ClipboardPasteListener 监听 paste 事件，Web/桌面端，提取图片后复用上传流程 |

文件格式、大小、数量、分辨率校验规则及错误提示见需求规格 F-M01-001 §2.1.3~§2.1.6，前端按 `useUserStore` 的用户类型动态读取配额（游客/VIP/高级VIP/企业版，对应单张大小 10/20/50MB/不限、批量 5/20/100张/不限），不在前端硬编码限制值。

### 5.2 MD5 去重（F-M01-001 §2.1.7）

上传前由前端计算文件 MD5（Web Crypto API / spark-md5），调用文件查询接口校验是否已存在：

| 命中情况 | 前端行为 |
|---------|---------|
| 命中 | 复用已有文件 URL，跳过文件流上传，Toast 提示"检测到重复图片，已复用已有文件" |
| 未命中 | 正常上传，结果写入 md5Cache 供后续命中 |

去重适用于上传与拍照两种输入方式（拍照图片同样走上传接口）。MD5 查询与文件注册复用数据集管理模块能力，本模块不维护文件指纹存储。

### 5.3 拍照（F-M01-002）

相机权限请求流程见需求规格 F-M01-002 §2.2.4。前端架构决策：权限状态由 `useCameraStore` 持有，授权失败时引导跳转系统设置；拍摄结果复用上传流程（含 MD5 去重）。相机能力（前后切换/闪光灯/对焦/网格线/变焦）见需求规格 F-M01-002 §2.2.2。

### 5.4 样例图片（F-M01-003）

样例数据来源于数据集管理模块公开数据项，查询参数契约见 [API接口.md](./API接口.md) §2.2，前端不重复定义查询参数。推荐算法由推荐管理模块动态获取，前端不静态配置。快速体验流程见需求规格 F-M01-003 §2.3.4。ImageGrid 采用虚拟滚动 + Intersection Observer 懒加载优化大量缩略图渲染。

### 5.5 历史记录与结果操作（F-M01-004）

历史记录展示、分组、清理、同步策略见需求规格 F-M01-004。前端架构决策聚焦结果操作交互（对应需求 §2.4.4 快速操作）：

| 操作 | 实现决策 |
|---------|---------|
| 重新处理 | 携带原图 + 算法 ID 跳转去雾处理页，自动开始 |
| 更换算法 | 携带原图跳转算法选择页 |
| 下载结果 | 由结果图 URL 触发浏览器下载，前端不中转文件流 |
| 分享结果 | 调用分享能力生成分享链接/图片，复制到剪贴板 |
| 添加收藏 | 复用收藏管理模块，targetType="result" |
| 删除记录 | 二次确认后调用历史记录删除接口（本地 + 云端） |

### 5.6 拖拽上传交互状态（DragDropZone）

仅描述交互行为，不规定样式：

| 状态 | 交互行为 |
|---------|---------|
| idle | 显示上传引导，接受拖入 |
| hover | 鼠标悬停高亮提示 |
| dragover | 拖入时提示"释放以上传" |
| disabled | 移动端禁用，不响应拖拽事件 |

## 7. 权限控制

按钮级权限控制，权限标识见 [API接口.md](./API接口.md) §3。

| 功能 | 权限标识 | 无权限处理 |
|---------|---------|-----------|
| 上传图片 | `sys:dataset:edit` | 隐藏上传入口，显示升级提示 |

| 查看历史 | - | 游客仅本地记录，登录用户云端同步 |

数据权限（历史记录用户隔离、样例公开、上传配额按用户类型）见需求规格 §5.1 与 API接口.md §3。
