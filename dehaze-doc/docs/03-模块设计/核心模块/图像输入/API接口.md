# 图像输入模块 API 接口

## 1. 文档概述

本文档定义 **图像输入** 模块的 HTTP API 规范，是该模块 API 契约的唯一权威来源。

- **基础路径**：`/api/v1/image-input`（本模块历史记录接口）；图片上传与样例图片查询复用数据集管理模块接口（`/api/v1/dataset-items`、`/api/v1/item-files`）
- **公共约定**：参见 [02-系统架构/04-API规范.md](../../../02-系统架构/04-API规范.md)
- **需求规格**：[需求规格.md](./需求规格.md)

## 2. 接口清单

### 2.1 图片上传接口（复用数据集管理）

| 路径 | 方法 | 功能描述 | 权限标识 | 关联功能点 |
|------|------|---------|---------|-----------|
| `/api/v1/dataset-items/upload` | POST | 上传配对图片（清晰图+有雾图），复用数据集管理模块 | `image:upload` | - |
| `/api/v1/item-files` | POST | 单独上传图片文件，复用数据集管理模块 | `image:upload` | - |

### 2.2 样例图片库接口（复用数据集管理）

样例图片库来源于数据集管理模块中标记为"公开展示"的数据项。

| 路径 | 方法 | 功能描述 | 权限标识 | 关联功能点 |
|------|------|---------|---------|-----------|
| `/api/v1/dataset-items` | GET | 查询公开数据项（样例库），复用数据集管理模块 | - | - |
| `/api/v1/dataset-items/{id}` | GET | 获取样例图片详情，复用数据集管理模块 | - | - |

### 2.3 历史记录管理接口（本模块新增）

| 路径 | 方法 | 功能描述 | 权限标识 | 关联功能点 |
|------|------|---------|---------|-----------|
| `/api/v1/image-input/history` | GET | 分页查询历史记录 | - | F-M01-004 |
| `/api/v1/image-input/history/{id}` | GET | 获取历史记录详情 | - | F-M01-004 |
| `/api/v1/image-input/history` | POST | 创建历史记录 | - | F-M01-004 |
| `/api/v1/image-input/history/{id}` | DELETE | 删除单条历史记录 | `image:delete` | F-M01-004 |
| `/api/v1/image-input/history/batch` | DELETE | 批量删除历史记录 | `image:delete` | F-M01-004 |
| `/api/v1/image-input/history/clear` | DELETE | 清空历史记录 | `image:delete` | F-M01-004 |

> 收藏状态通过收藏管理模块 `/api/v1/favorites` 统一管理，历史记录接口不维护收藏字段。

### 2.4 快速体验流程接口（复用）

| 路径 | 方法 | 功能描述 | 权限标识 | 关联功能点 |
|------|------|---------|---------|-----------|
| `/api/v1/dataset-items` | GET | 获取推荐样例图片，复用数据集管理模块 | - | - |
| `/api/v1/prediction` | POST | 执行去雾处理，复用算法管理模块 | - | - |

## 3. 权限标识汇总

| 权限标识 | 说明 |
|---------|------|
| `image:upload` | 上传图片（配对上传、单文件上传） |
| `image:delete` | 删除历史记录（单条/批量/清空） |
| - | 公开或登录态接口：查询样例图片、查询与创建历史记录（历史记录通过用户身份自动隔离数据） |

## 4. 业务错误码

| 错误码 | 说明 | 触发场景 |
|--------|------|---------|
| `B0001` | 业务错误 | 通用业务错误 |
| `B0100` | 数据集不存在 | 上传图片时指定的数据集不存在 |
| `B0105` | 清晰图必须上传 | 配对上传时缺少清晰图 |
| `B0106` | 至少上传一张有雾图 | 配对上传时缺少有雾图 |
| `B0107` | 配对图片分辨率不一致 | 配对图片尺寸不匹配 |
| `B0300` | 历史记录不存在 | 查询/删除不存在的历史记录 |
| `B0301` | 历史记录已达上限 | 超过用户配额限制 |
| `A0701` | 文件格式不支持 | 上传不支持的图片格式 |
| `A0702` | 文件大小超限 | 文件大小超过限制 |
| `A0703` | 分辨率不足 | 图片分辨率过低 |
| `A0301` | 权限不足 | 相机权限被拒绝或上传权限不足 |
| `B0002` | 网络异常 | 网络连接失败 |
| `B0003` | 上传失败 | 上传过程中出错 |
| `A0230` | token无效或已过期 | 未认证访问需要权限的接口 |
