# 图像输入模块 API 接口文档

## 1. 文档概述

本文档定义 **图像输入** 模块的 HTTP API 规范，包括接口路径、权限标识等，基础路径：`/api/v1/image-input`

- 需求规格：`03-模块设计/核心模块/图像输入/需求规格.md`

## 2. 接口清单

### 2.1 图片上传接口（复用数据集管理）

图像上传功能复用数据集管理模块的上传接口。

| 路径 | 方法 | 功能描述 | 权限标识 | 复用来源 |
|------|------|---------|---------|---------|
| `/api/v1/dataset-items/upload` | POST | 上传配对图片（清晰图+有雾图） | `sys:dataset:edit` | 数据集管理模块 |
| `/api/v1/item-files` | POST | 单独上传图片文件 | `sys:dataset:edit` | 数据集管理模块 |

### 2.2 样例图片库接口（复用数据集管理）

样例图片库直接来源于数据集管理模块中标记为"公开展示"的数据项，通过查询接口实现。

| 路径 | 方法 | 功能描述 | 权限标识 | 复用来源 |
|------|------|---------|---------|---------|
| `/api/v1/dataset-items` | GET | 查询公开数据项（样例库） | - | 数据集管理模块 |
| `/api/v1/dataset-items/{id}` | GET | 获取样例图片详情 | - | 数据集管理模块 |

### 2.3 历史记录管理接口（本模块新增）

历史记录管理是图像输入模块特有的功能，需要独立的接口设计。

| 路径 | 方法 | 功能描述 | 权限标识 | 关联功能点 |
|------|------|---------|---------|-----------|
| `/api/v1/image-input/history` | GET | 分页查询历史记录 | - | F-M01-004 |
| `/api/v1/image-input/history/{id}` | GET | 获取历史记录详情 | - | F-M01-004 |
| `/api/v1/image-input/history` | POST | 创建历史记录 | - | F-M01-004 |
| `/api/v1/image-input/history/{id}` | PUT | 更新历史记录 | - | F-M01-004 |

> **注意**：收藏状态通过收藏管理模块 `/api/v1/favorites` 统一管理，历史记录接口不再维护 `is_favorite` 字段。
| `/api/v1/image-input/history/{id}` | DELETE | 删除单条历史记录 | - | F-M01-004 |
| `/api/v1/image-input/history/batch` | DELETE | 批量删除历史记录 | - | F-M01-004 |
| `/api/v1/image-input/history/clear` | DELETE | 清空历史记录 | - | F-M01-004 |
| `/api/v1/image-input/history/sync` | POST | 同步本地与云端历史记录 | - | F-M01-004 |

### 2.4 拍照功能接口（前端原生能力）

拍照功能主要依赖前端原生相机 API，后端仅提供图片上传接口（复用 2.1 节接口）。

**说明**：
- 相机调用：前端使用 `navigator.mediaDevices.getUserMedia()` API
- 权限请求：前端处理相机权限授权流程
- 图片处理：前端进行预览、裁剪、旋转等操作
- 图片上传：使用复用的数据集管理上传接口

### 2.5 快速体验流程接口（复用）

快速体验流程复用样例图片查询（2.2 节）和算法处理接口。

| 路径 | 方法 | 功能描述 | 权限标识 | 复用来源 |
|------|------|---------|---------|---------|
| `/api/v1/dataset-items` | GET | 获取推荐样例图片 | - | 数据集管理模块 |
| `/api/v1/prediction` | POST | 执行去雾处理 | - | 算法管理模块 |

**参考文档**：
- 算法处理接口：[算法管理 API 接口 § 2.4 模型预测接口](../算法管理/API接口.md#24-模型预测接口)

## 3. 权限标识汇总

| 权限标识 | 说明 | 控制范围 |
|---------|------|---------|
| `sys:dataset:edit` | 上传图片（复用数据集权限） | 按钮显示 + 接口校验 |
| - | 查询样例图片（无需权限） | 默认所有用户 |
| - | 历史记录管理（无需权限） | 用户仅能访问自己的记录 |

**说明**：
- 历史记录接口无需特殊权限，通过用户身份自动隔离数据
- 游客模式下历史记录仅存储在本地，注册用户可云端同步

## 4. 业务错误码

| 错误码 | 说明 | 触发场景 |
|--------|------|---------|
| `B0001` | 业务错误 | 通用业务错误 |
| `B0100` | 数据集不存在 | 上传图片时指定的数据集不存在 |
| `B0105` | 清晰图必须上传 | 配对上传时缺少清晰图 |
| `B0106` | 至少上传一张有雾图 | 配对上传时缺少有雾图 |
| `B0107` | 配对图片分辨率不一致 | 配对图片尺寸不匹配 |
| `B0300` | 历史记录不存在 | 查询/删除不存在的历史记录 |
| `B0301` | 历史记录已达上限 | 超过用户配额限制 |
| `B0302` | 同步冲突 | 本地与云端数据冲突 |
| `ERR_FILE_TOO_LARGE` | 文件过大 | 文件大小超过限制 |
| `ERR_UNSUPPORTED_FORMAT` | 格式不支持 | 上传不支持的图片格式 |
| `ERR_NETWORK_ERROR` | 网络异常 | 网络连接失败 |
| `ERR_UPLOAD_FAILED` | 上传失败 | 上传过程中出错 |
| `ERR_RESOLUTION_LOW` | 分辨率不足 | 图片分辨率过低 |
| `ERR_PERMISSION_DENIED` | 权限不足 | 相机权限被拒绝或上传权限不足 |
| `A0230` | token无效或已过期 | 未认证访问需要权限的接口 |
