# 去雾处理模块 API 接口

## 1. 文档概述

本文档定义 **去雾处理** 模块的 HTTP API 规范，是该模块 API 契约的**唯一权威来源**。

- **基础路径**：
  - 预测：`/api/v1/prediction`
  - 参数预设：`/api/v1/presets`
- **公共约定**：参见 [02-系统架构/04-API规范.md](../../../02-系统架构/04-API规范.md)
- **需求规格**：[需求规格.md](./需求规格.md)

> **重要**：接口详细参数/响应结构可通过 API 文档 MCP 查询，本文档仅定义接口清单和权限标识。

## 2. 接口清单

### 2.1 预测接口

> **异步任务模式**：POST 立即返回 logId + status，前端通过 WebSocket 实时推送获取任务状态，轮询作为降级兜底。

| 路径 | 方法 | 功能描述 | 权限标识 | 关联功能点 |
|------|------|---------|---------|-----------|
| `/api/v1/prediction` | POST | 提交去雾预测任务（参数中增加 `recommendedBy` 字段标记是否来自推荐） | - | F-M04-001 |
| `/api/v1/prediction/{taskId}` | GET | 轮询任务状态（processing/completed/failed） | - | F-M04-001 |
| `/api/v1/prediction/batch` | POST | 批量处理（一次提交多张图片，最多 20 张） | - | F-M04-002 |

**POST `/api/v1/prediction` 请求体变更说明**：
- 新增 `recommendedBy` 字段（可选，String）：标记预测是否来自推荐管理模块，用于追踪推荐采纳率

### 2.2 参数预设接口

| 路径 | 方法 | 功能描述 | 权限标识 | 关联功能点 |
|------|------|---------|---------|-----------|
| `/api/v1/presets` | GET | 参数预设列表（系统预设 + 用户自定义） | - | F-M04-003 |
| `/api/v1/presets` | POST | 创建自定义预设 | - | F-M04-003 |
| `/api/v1/presets/{id}` | PUT | 更新自定义预设 | - | F-M04-003 |
| `/api/v1/presets/{id}` | DELETE | 删除自定义预设 | - | F-M04-003 |

> **说明**：系统预设为只读，不可修改或删除；用户仅能操作自己的自定义预设。

### 2.3 配额接口

| 路径 | 方法 | 功能描述 | 权限标识 | 关联功能点 |
|------|------|---------|---------|-----------|
| `/api/v1/prediction/quota` | GET | 查询用户剩余处理次数 | - | F-M04-006 |

## 3. 权限标识汇总

| 权限标识 | 说明 |
|---------|------|
| - | 去雾处理无特殊权限标识，登录用户即可操作；VIP 配额通过会员等级控制 |

## 4. 业务错误码

| 错误码 | 说明 | 触发场景 |
|--------|------|---------|
| `A0401` | 请求资源不存在 | 轮询的 taskId 不存在、预设不存在 |
| `A0500` | 业务异常 | 批量处理图片数量超过上限（20 张） |
| `A0502` | 数据状态不允许 | 尝试修改/删除系统预设、操作他人的自定义预设 |
| `A0600` | 操作失败 | 预测任务执行失败 |
| `A0503` | 操作不允许 | 去雾次数已达上限，需升级 VIP |
| `B0100` | 系统执行超时 | 预测任务执行超时 |
| `A0230` | token无效或已过期 | 未登录访问 |
