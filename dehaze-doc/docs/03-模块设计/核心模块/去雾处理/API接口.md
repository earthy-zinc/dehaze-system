# 去雾处理模块 API 接口

## 1. 文档概述

本文档定义 **去雾处理** 模块的 HTTP API 规范，是该模块 API 契约的唯一权威来源。

- **基础路径**：
  - 预测：`/api/v1/prediction`
  - 评估：`/api/v1/evaluation`
  - 参数预设：`/api/v1/presets`
- **公共约定**：参见 [02-系统架构/04-API规范.md](../../../02-系统架构/04-API规范.md)
- **需求规格**：[需求规格.md](./需求规格.md)

> 预测与评估接口均采用异步任务模式：POST 立即返回任务 ID 与处理中状态，前端通过 GET 轮询直至终态。

## 2. 接口清单

### 2.1 预测接口

| 路径 | 方法 | 功能描述 | 权限标识 | 关联功能点 |
|------|------|---------|---------|-----------|
| `/api/v1/prediction` | POST | 提交去雾预测任务（异步） | `dehaze:execute` | F-M04-001 |
| `/api/v1/prediction/{taskId}` | GET | 轮询任务状态（1=处理中/2=已完成/3=失败/4=已取消） | - | F-M04-001 |
| `/api/v1/prediction/{taskId}/cancel` | POST | 取消预测任务（幂等） | `dehaze:execute` | F-M04-001 |
| `/api/v1/prediction/logs` | GET | 预测日志列表（分页，可按算法筛选） | - | F-M04-007 |
| `/api/v1/prediction/batch` | POST | 批量处理（一次提交多张图片，上限按会员等级动态计算） | `dehaze:execute` | F-M04-002 |
| `/api/v1/prediction/quota` | GET | 查询用户剩余处理次数 | - | F-M04-006 |

### 2.2 评估接口

> 评估能力由[效果对比模块](../效果对比/API接口.md)承接，此处列出接口供主链路调用参考。

| 路径 | 方法 | 功能描述 | 权限标识 | 关联功能点 |
|------|------|---------|---------|-----------|
| `/api/v1/evaluation` | POST | 提交指标评估任务（计算 PSNR/SSIM/LPIPS 等指标，异步） | `evaluation:execute` | F-M02-005 |
| `/api/v1/evaluation/{taskId}` | GET | 轮询评估任务状态 | - | F-M02-005 |
| `/api/v1/evaluation/metrics` | GET | 评估指标历史列表（当前用户） | - | F-M02-005 |
| `/api/v1/evaluation/logs` | GET | 评估日志列表（分页） | - | F-M02-005 |

### 2.3 参数预设接口

| 路径 | 方法 | 功能描述 | 权限标识 | 关联功能点 |
|------|------|---------|---------|-----------|
| `/api/v1/presets` | GET | 参数预设列表（系统预设 + 用户自定义，可按算法/类型筛选） | - | F-M04-003 |
| `/api/v1/presets` | POST | 创建自定义预设 | - | F-M04-003 |
| `/api/v1/presets/{id}` | PUT | 更新自定义预设 | - | F-M04-003 |
| `/api/v1/presets/{id}` | DELETE | 删除自定义预设 | - | F-M04-003 |

> 预设分为系统预设（只读）与用户自定义（仅本人可操作）两类。

### 2.4 配额接口

| 路径 | 方法 | 功能描述 | 权限标识 | 关联功能点 |
|------|------|---------|---------|-----------|
| `/api/v1/prediction/quota` | GET | 查询用户剩余处理次数 | - | F-M04-006 |

> **配额响应字段**：`total`（总配额）、`used`（本月已使用）、`remaining`（本月剩余）、`resetDate`（配额重置日期，月度配额按下月 1 日重置，格式 `YYYY-MM-DD`）。

## 3. 权限标识汇总

| 权限标识 | 说明 |
|---------|------|
| `dehaze:execute` | 提交去雾预测任务、批量处理、取消任务 |
| `evaluation:execute` | 提交指标评估任务 |
| - | 登录态接口：轮询任务状态、查询日志、参数预设管理、查询配额（VIP 配额通过会员等级控制） |

## 4. 业务错误码

| 错误码 | 说明 | 触发场景 |
|--------|------|---------|
| `A0401` | 请求资源不存在 | 轮询的 taskId 不存在、预设不存在、算法不存在 |
| `A0500` | 业务异常 | 批量处理图片数量超过会员等级上限；图片来源为空 |
| `A0501` | 数据已存在 | 预设名称冲突（如系统预设同名） |
| `A0502` | 数据状态不允许 | 尝试修改/删除系统预设、操作他人的自定义预设 |
| `A0515` | 当月次数已用完 | 配额耗尽 |
| `A0230` | token无效或已过期 | 未登录访问 |

> 预测任务执行失败不通过错误码返回，任务状态通过 `status=3(失败)` + 错误信息表达。
