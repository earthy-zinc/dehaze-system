# 去雾处理模块 API 接口

## 1. 文档概述

本文档定义 **去雾处理** 模块的 HTTP API 规范，是该模块 API 契约的唯一权威来源。

- **基础路径**：
  - 图像任务：`/api/v1/images`
  - 评估：`/api/v1/evaluation`
  - 参数预设：`/api/v1/presets`
- **公共约定**：参见 [02-系统架构/04-API规范.md](../../../02-系统架构/04-API规范.md)
- **需求规格**：[需求规格.md](./需求规格.md)

> 图像任务与评估接口均采用异步任务模式：POST 立即返回任务 ID 与处理中状态，前端通过 GET 轮询直至终态。图像任务端点为资源命名（对齐 OpenAI `/v1/images/*`），不使用 `/api/v1/prediction/*`。

## 2. 接口清单

### 2.1 图像任务接口

| 路径                                   | 方法 | 功能描述                                                                                | 权限标识         | 关联功能点 |
| -------------------------------------- | ---- | --------------------------------------------------------------------------------------- | ---------------- | ---------- |
| `/api/v1/images/edits`                 | POST | 提交图像编辑任务（去雾/去雨/…，异步），请求携带 `model`                                 | `dehaze:execute` | F-M04-001  |
| `/api/v1/images/tasks/{taskId}`        | GET  | 轮询任务状态（1=处理中/2=已完成/3=失败/4=已取消），仅任务本人可查（他人任务返回 A0401） | -                | F-M04-001  |
| `/api/v1/images/tasks/{taskId}/cancel` | POST | 取消图像任务（幂等，仅任务本人可取消）                                                  | `dehaze:execute` | F-M04-001  |
| `/api/v1/images/tasks`                 | GET  | 图像任务历史列表（分页，可按 `?model=` 筛选，仅返回当前用户记录）                       | -                | F-M04-007  |
| ~~`/api/v1/prediction/batch`~~         | —    | 批量 = 多次提交单张任务，由 SDK 封装                                            | —                | F-M04-002  |
| ~~`/api/v1/prediction/quota`~~         | —    | 配额展示为积分余额（SDK `AiBillingAPI` 余额方法）                               | —                | F-M04-006  |

> **提交请求体**（JSON）：`{ "model": "<slug>", "fileId"?: n, "imageUrl"?: "...", "params"?: "<json-string>", "recommendedBy"?: n }`（`fileId`/`imageUrl` 至少一）。
>
> **提交响应字段**（三端一致）：`taskId`、`status`（1=处理中/2=已完成/3=失败/4=已取消）、`estimatedCredits`（预估消耗积分，可选）、`resultUrl`、`resultMd5`（结果图内容 MD5，completed 时返回）、`originMd5`（原图内容 MD5，completed 时返回）、`resultThumbnailUrl`、`time`（推理耗时，单位**秒**）、`errorMessage`（failed 时返回）。缓存命中时 POST 即返回 completed 全字段，无需轮询。两个 MD5 由编排侧计算，Java/Go 后端据此写各自 `sys_pred_log` 的 `pred_md5` / `origin_md5`，不得用 URL 的 MD5 代替。

### 2.2 评估接口

> 评估能力由[效果对比模块](../效果对比/API接口.md)承接，此处列出接口供主链路调用参考。**评估不计费**。

| 路径                          | 方法 | 功能描述                                              | 权限标识             | 关联功能点 |
| ----------------------------- | ---- | ----------------------------------------------------- | -------------------- | ---------- |
| `/api/v1/evaluation`          | POST | 提交指标评估任务（计算 PSNR/SSIM/LPIPS 等指标，异步） | `evaluation:execute` | F-M02-005  |
| `/api/v1/evaluation/{taskId}` | GET  | 轮询评估任务状态                                      | -                    | F-M02-005  |
| `/api/v1/evaluation/metrics`  | GET  | 评估指标历史列表（当前用户）                          | -                    | F-M02-005  |
| `/api/v1/evaluation/logs`     | GET  | 评估日志列表（分页）                                  | -                    | F-M02-005  |

### 2.3 参数预设接口

| 路径                   | 方法   | 功能描述                                            | 权限标识 | 关联功能点 |
| ---------------------- | ------ | --------------------------------------------------- | -------- | ---------- |
| `/api/v1/presets`      | GET    | 参数预设列表（系统预设 + 用户自定义，可按模型筛选） | -        | F-M04-003  |
| `/api/v1/presets`      | POST   | 创建自定义预设                                      | -        | F-M04-003  |
| `/api/v1/presets/{id}` | PUT    | 更新自定义预设                                      | -        | F-M04-003  |
| `/api/v1/presets/{id}` | DELETE | 删除自定义预设                                      | -        | F-M04-003  |

> 预设分为系统预设（只读）与用户自定义（仅本人可操作）两类，按模型标识 `modelId` 关联（列表筛选与创建/更新均用 `modelId`）。

## 3. 权限标识汇总

| 权限标识             | 说明                                                                         |
| -------------------- | ---------------------------------------------------------------------------- |
| `dehaze:execute`     | 提交图像任务、取消任务                                                       |
| `evaluation:execute` | 提交指标评估任务                                                             |
| -                    | 登录态接口：轮询任务状态、查询历史、参数预设管理（积分余额通过计费模块查询） |

## 4. 业务错误码

| 错误码  | 说明              | 触发场景                                                              |
| ------- | ----------------- | --------------------------------------------------------------------- |
| `A0401` | 请求资源不存在    | 轮询的 taskId 不存在、访问/取消他人的图像任务、预设不存在、模型不存在 |
| `A0410` | 请求必填参数为空  | 图片来源缺失（fileId 与 imageUrl 均未提供）                           |
| `A0501` | 数据已存在        | 预设名称冲突（如系统预设同名）                                        |
| `A0502` | 数据状态不允许    | 尝试修改/删除系统预设、操作他人的自定义预设                           |
| `A0515` | 积分余额不足      | 提交前余额预校验不通过（不足以支付该模型单张单价）                    |
| `A0230` | token无效或已过期 | 未登录访问                                                            |

> 图像任务执行失败不通过错误码返回，任务状态通过 `status=3(失败)` + `errorMessage` 表达。
