# 去雾处理模块需求规格

## 1. 模块概述

### 1.1 模块定位

去雾处理模块是图像去雾系统的核心处理引擎，负责调用算法对图像进行去雾处理，并管理处理过程和结果。该模块承接图像输入和算法选择，输出处理结果至效果对比模块，是整个系统业务流程的关键环节。

### 1.2 核心价值

- **高效处理**：优化的处理流程，快速完成单张/批量去雾
- **实时反馈**：完整的进度监控，清晰展示处理阶段
- **参数可调**：高级用户可调节算法参数，实现个性化效果
- **结果管理**：完善的结果保存、分享、导出功能
- **容错机制**：断点续传、自动重试，保障处理稳定性

### 1.3 用户角色分析

| 用户类型 | 特征 | 使用偏好 | 功能需求 |
|---------|------|---------|---------|
| **轻度用户** | 偶尔使用，对参数不了解 | 默认参数，一键处理 | 单张处理+自动保存 |
| **中度用户** | 定期使用，有一定了解 | 参考默认+微调参数 | 单张/批量处理+手动调参 |
| **重度用户** | 高频使用，专业需求 | 精确控制参数 | 批量处理+高级参数+队列管理 |
| **VIP用户** | 付费用户，更高权益 | 高效批量处理 | 更多次数+历史记录+优先处理 |

### 1.4 模块依赖关系

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  图像输入    │────▶│  算法选择    │────▶│  去雾处理    │
│   模块      │     │    模块     │     │    模块     │
└─────────────┘     └─────────────┘     └──────┬──────┘
                                               │
                                               ▼
                                        ┌─────────────┐
                                        │  效果对比    │
                                        │    模块     │
                                        └─────────────┘
```

## 2. 功能需求

### 2.1 单张处理功能 (F-M04-001)

#### 2.1.1 功能描述

对单张图片进行去雾处理，支持实时进度监控、处理控制和结果预览。

#### 2.1.2 处理流程

```
确认图片和算法
    ↓
点击"开始去雾"
    ↓
显示确认对话框
    ↓
用户确认处理
    ↓
┌─────────────────────────────────────┐
│          图片预处理阶段              │
│  • 图片格式转换                      │
│  • 尺寸归一化                        │
│  • 内存预分配                        │
│  进度：0% - 10%                      │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│          算法初始化阶段              │
│  • 加载算法模型                      │
│  • GPU/CPU资源分配                   │
│  • 参数配置                          │
│  进度：10% - 20%                     │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│          去雾处理阶段                │
│  • 执行去雾算法                      │
│  • 实时进度更新                      │
│  • 中间结果缓存                      │
│  进度：20% - 90%                     │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│          后处理优化阶段              │
│  • 色彩校正                          │
│  • 对比度增强                        │
│  • 锐化处理                          │
│  进度：90% - 95%                     │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│          结果保存阶段                │
│  • 生成结果图像                      │
│  • 保存到服务器/本地                 │
│  • 记录处理日志                      │
│  进度：95% - 100%                    │
└─────────────────────────────────────┘
    ↓
处理完成
    ↓
自动进入对比页面
```

#### 2.1.3 处理控制

**开始处理**

开始处理前显示确认对话框，包含图片信息（文件名、尺寸、大小）、算法信息（算法名称、预估时间、参数配置）和处理提示，用户可选择取消或开始处理。

**暂停/恢复**（规划中，未实现）

- 支持暂停处理（仅部分算法支持）
- 显示暂停状态和已处理进度
- 支持从暂停点恢复处理

**取消处理**

- 支持取消正在进行的处理
- 取消确认对话框
- 自动释放资源

#### 2.1.4 进度显示

处理过程中显示实时进度条、当前处理阶段、已用时间和预估剩余时间。可选支持实时预览处理中的图像，并提供暂停和取消控制按钮。

### 2.2 批量处理功能 (F-M04-002)

#### 2.2.1 功能描述

支持一次性处理多张图片（最多20张），提高处理效率，适用于批量去雾需求场景。

#### 2.2.2 批量处理流程

```
选择多张图片（最多20张）
    ↓
显示图片列表预览
    ↓
选择统一算法
    ↓
设置处理参数（可选）
    ↓
点击"批量处理"
    ↓
显示确认对话框
    ↓
用户确认处理
    ↓
逐张/并行处理
    ↓
显示整体进度和单张进度
    ↓
处理完成
    ↓
生成处理报告
    ↓
查看批量结果
```

#### 2.2.3 批量处理策略

**处理模式**

| 模式 | 说明 | 适用场景 | 并发数 |
|-----|------|---------|--------|
| 串行处理 | 逐张处理，稳定可靠 | 内存有限的设备 | 1 |
| 并行处理 | 同时处理多张，速度快 | 高性能设备（GPU显存≥16G） | 2-4 |
| 智能模式 | 根据设备性能自动选择 | 推荐模式 | 自适应 |

**失败处理策略**

- 单张失败不影响其他图片处理
- 记录失败原因和失败图片
- 支持重试失败的图片
- 生成详细处理报告

#### 2.2.4 批量进度显示

批量处理过程中显示整体进度（完成数量、成功数、失败数、预估剩余时间）、当前正在处理的图片进度和状态。处理列表展示所有图片的处理状态和用时，支持暂停全部、取消全部和重试失败的操作。

### 2.3 参数调节功能 (F-M04-003)

#### 2.3.1 功能描述

为高级用户提供算法参数调节功能，实现个性化处理效果。支持实时预览调参效果。

#### 2.3.2 参数类型

**通用参数**

| 参数名称 | 类型 | 范围 | 默认值 | 说明 |
|---------|------|------|--------|------|
| 去雾强度 | 滑块 | 0-100 | 50 | 控制去雾程度，值越大去雾效果越强 |
| 色彩饱和度 | 滑块 | 0-200 | 100 | 调整色彩鲜艳度，100为原始值 |
| 对比度 | 滑块 | 0-200 | 100 | 调整明暗对比，100为原始值 |
| 锐化程度 | 滑块 | 0-100 | 30 | 增强细节清晰度 |

**算法特定参数**

**DCP算法（暗通道先验）**

| 参数名称 | 类型 | 范围 | 默认值 | 说明 |
|---------|------|------|--------|------|
| ω值 | 滑块 | 0.85-0.95 | 0.95 | 去雾系数，控制保留雾的程度 |
| 窗口大小 | 选择 | 3/5/7/9/11/13/15 | 15 | 暗通道估计窗口大小 |
| 引导滤波半径 | 滑块 | 20-60 | 40 | 引导滤波的平滑半径 |

**深度学习算法**

| 参数名称 | 类型 | 选项 | 默认值 | 说明 |
|---------|------|------|--------|------|
| 推理精度 | 选择 | FP16/FP32 | FP16 | 浮点精度，FP16更快 |
| 批处理大小 | 选择 | 1/2/4 | 1 | 同时处理的图片数量 |

#### 2.3.3 参数调节界面

参数调节界面提供通用参数和算法特定参数的设置区域，支持滑块、选择等输入方式。提供预设方案（推荐配置、风景优化、夜景增强）和自定义方案保存功能，支持实时预览调参效果（原图与效果对比）。

### 2.4 处理结果管理 (F-M04-004)

#### 2.4.1 功能描述

管理处理结果，支持保存、分享、导出等操作，满足不同场景下的结果使用需求。

#### 2.4.2 自动保存

- 处理完成自动保存到应用服务器
- 保存原图和处理结果图
- 保存处理参数和元数据
- 关联预测日志记录

**文件命名规则**

```
格式：原文件名_算法名_时间戳.格式
示例：IMG_20250117_AODNet_143024.jpg
```

#### 2.4.3 手动保存

**保存选项**

| 选项 | 说明 | 可选值 |
|------|------|--------|
| 保存位置 | 保存到相册/自定义目录 | 相册/自定义路径 |
| 保存格式 | 图片文件格式 | JPG/PNG |
| 保存质量 | 图片压缩质量 | 60%/80%/90%/100% |
| 元数据 | 是否包含EXIF信息 | 是/否 |

#### 2.4.4 结果分享

**分享方式**

- 分享到社交平台（微信、QQ、微博等）
- 生成分享链接（有效期可设置）
- 生成二维码
- 发送到邮箱

**分享内容选项**

- 仅处理后的图片
- 对比图（原图+处理后并排/上下）
- 处理信息（算法、参数、时间）

#### 2.4.5 结果导出

**导出格式**

| 格式 | 说明 | 适用场景 |
|------|------|---------|
| 单张图片 | JPG/PNG格式 | 日常使用 |
| 对比图 | 原图+结果并排/上下 | 效果展示 |
| PDF报告 | 包含详细处理信息 | 专业报告 |
| 批量打包 | ZIP压缩包 | 批量处理结果 |

**导出选项**

导出设置支持选择导出格式，并提供分辨率选项（原始尺寸、1920×1080、1280×720、自定义）、质量设置（高质量90%等）、水印选项（是否添加系统水印）和元数据选项（是否包含处理参数），显示预计文件大小。

### 2.5 处理队列管理 (F-M04-005)（规划中，未实现）

#### 2.5.1 功能描述

管理处理任务队列，支持任务优先级和并发控制，适用于多任务处理场景。

#### 2.5.2 队列功能

**任务管理**

- 查看队列中的所有任务
- 调整任务优先级（拖拽排序）
- 暂停/恢复单个任务
- 取消任务
- 清空队列

**队列状态**

| 状态 | 图标 | 说明 |
|------|------|------|
| 等待中 | ⏳ | 排队等待处理 |
| 处理中 | 🔄 | 正在处理 |
| 已暂停 | ⏸️ | 用户手动暂停 |
| 已完成 | ✅ | 处理成功 |
| 已失败 | ❌ | 处理失败 |
| 已取消 | 🚫 | 用户取消 |

#### 2.5.3 并发控制

**并发策略**

- 根据设备性能自动调整并发数
- 最大并发数：1-3（根据GPU显存）
- 优先处理高优先级任务
- VIP用户享有优先处理权

**重试机制**

- 失败任务自动重试（最多3次）
- 重试间隔递增：2s → 5s → 10s
- 支持手动触发重试

#### 2.5.4 队列界面

队列界面显示当前并发设置和所有任务列表，包括任务优先级、图片名称、算法、状态、进度和操作按钮。支持清空已完成和清空全部操作，已完成任务可折叠显示。

### 2.6 错误处理与恢复 (F-M04-006)

#### 2.6.1 错误类型及处理

| 错误类型 | 错误代码 | 错误提示 | 处理方式 |
|---------|---------|---------|---------|
| 内存不足 | E001 | "设备内存不足，请关闭其他应用后重试" | 释放资源，提示用户清理 |
| 算法加载失败 | E002 | "算法加载失败，请检查网络连接" | 重试加载，提供离线备用算法 |
| 处理超时 | E003 | "处理超时，建议更换算法或降低图片分辨率" | 取消处理，提供优化建议 |
| 图片损坏 | E004 | "图片文件损坏，无法处理" | 跳过该图片，继续后续 |
| 存储空间不足 | E005 | "存储空间不足，请清理后重试" | 提示清理空间 |
| 网络异常 | E006 | "网络连接异常，请检查网络设置" | 自动重试/提示用户 |
| GPU资源不足 | E007 | "GPU资源不足，已切换到CPU处理" | 自动降级到CPU |
| 权限不足 | E008 | "去雾次数已达上限，请升级VIP" | 引导升级VIP |

#### 2.6.2 恢复机制

**断点续传**（规划中，未实现）

- 每处理完一个阶段自动保存进度
- 应用重启后检测未完成任务
- 支持从断点恢复处理
- 保留处理上下文和参数

**自动重试**

```
重试策略：
├── 重试次数：最多3次
├── 重试间隔：2s → 5s → 10s（指数退避）
├── 重试条件：网络错误、临时性失败
└── 不重试：图片损坏、权限不足、用户取消
```

**错误恢复界面**

检测到未完成的处理任务时，显示中断原因、图片信息、算法名称、已完成的进度和中断时间，提供放弃或从断点恢复的选项。

## 3. 用户交互流程

### 3.1 单张处理完整流程

用户选择或上传图片，系统加载预览并自动分析图像特征。用户选择算法（或使用推荐）并可选调整参数，系统显示算法信息和预估处理时间。点击开始去雾后显示确认对话框，用户确认后开始处理，显示进度条、处理阶段、预估时间和可选的实时预览。处理完成后显示提示并自动跳转到对比页面，用户查看对比效果后可保存或分享结果。

### 3.2 批量处理完整流程

```
【用户操作】                      【系统响应】
    │
选择多张图片（最多20张）
    │                            ← 显示图片列表
    │                            ← 显示总大小和数量
    │
选择统一算法
    │                            ← 显示算法信息
    │                            ← 计算预估总时间
    │
设置参数（可选）
    │                            ← 预览参数效果
    │
点击"批量处理"
    │                            ← 显示确认对话框
    │
确认处理
    │                            ← 开始批量处理
    │                            ├─ 显示整体进度
    │                            ├─ 显示单张进度
    │                            ├─ 显示成功/失败数
    │                            └─ 显示预估时间
    │
    │                            ← 全部处理完成
    │                            ← 显示处理报告
    │
查看批量结果
    │                            ← 展示所有结果
    │
批量导出/分享
    │                            ← 打包下载/分享
```
