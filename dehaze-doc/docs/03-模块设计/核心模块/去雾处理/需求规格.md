# 去雾处理模块需求规格

## 1. 模块概述

### 1.1 模块定位

去雾处理模块是图像去雾系统的核心处理引擎，负责对用户输入的图像执行去雾算法处理，并管理处理过程与结果。该模块承接图像输入和算法选择，输出处理结果至效果对比模块，是整个系统业务流程的关键环节。

### 1.2 核心价值

| 价值维度 | 具体内容 |
|---------|---------|
| **高效处理** | 支持单张与批量去雾，满足不同规模的处理需求 |
| **进度可见** | 全程展示任务处理阶段和实时耗时，用户对处理状态一目了然 |
| **参数可控** | 提供通用参数和算法专属参数调节能力，满足个性化效果需求 |
| **结果管理** | 完整的处理历史记录，支持回溯、对比、重新处理 |
| **会员差异** | 基于会员等级提供差异化的处理配额和功能权限 |

### 1.3 用户角色分析

| 用户类型 | 特征 | 使用偏好 | 功能需求 |
|---------|------|---------|---------|
| **轻度用户** | 偶尔使用，对参数不了解 | 默认参数，一键处理 | 单张处理、自动保存 |
| **中度用户** | 定期使用，有一定了解 | 参考推荐+微调参数 | 单张/批量处理、手动调参 |
| **重度用户** | 高频使用，专业需求 | 精确控制参数 | 批量处理、高级参数、自定义预设 |
| **VIP用户** | 付费用户，更高权益 | 高效批量处理 | 更多配额、批量上限、高清导出、处理优先 |

### 1.4 模块依赖关系

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  图像输入    │────▶│  算法选择    │────▶│  去雾处理    │
│   模块      │     │    模块     │     │    模块     │
└─────────────┘     └─────────────┘     └──────┬──────┘
                                               │
                                               ▼
                                        ┌─────────────┐
                                        │  效果对比    │
                                        │    模块     │
                                        └─────────────┘
```

### 1.5 依赖的基础模块

| 模块 | 依赖说明 |
|------|---------|
| **会员管理** | 处理前校验会员次数配额、处理优先级、功能权限；历史记录保留条数由会员等级决定 |
| **消息通知** | 处理完成通知、处理失败告警、配额即将用尽提醒 |
| **收藏管理** | 处理结果收藏，targetType="result" |
| **推荐管理** | 推荐算法一键使用，推荐策略指导默认参数方案 |
| **任务管理** | 异步任务状态机设计参考任务管理模块，统一用户体验 |

## 2. 功能需求

### 2.1 单张处理 (F-M04-001)

#### 2.1.1 功能描述

对单张图片进行去雾处理。处理任务以异步方式执行，用户提交后无需等待，可随时查看处理进度和结果。

#### 2.1.2 处理流程

```
确认图片和算法
    ↓
点击"开始去雾"
    ↓
显示确认对话框（图片信息、算法信息、预估耗时）
    ↓
用户确认处理
    ↓
任务提交 → 立即返回任务标识
    ↓
异步执行阶段（后端执行算法推理）
    ↓
实时进度推送（阶段变更、完成、失败）
    ↓
处理完成 → 跳转对比页面
处理失败 → 展示错误信息、支持重试
```

#### 2.1.3 任务状态

| 状态 | 说明 | UI 表现 |
|------|------|---------|
| 处理中 | 任务正在执行 | 加载动画 + 当前阶段名称 + 实时耗时 |
| 已完成 | 任务成功完成 | 自动跳转效果对比页面 |
| 已失败 | 任务失败 | 错误提示 + 重试按钮 |

失败任务支持重试，重试间隔递增（2s → 5s → 10s），最多重试 3 次。不可重试的错误（如图片损坏、权限不足）直接提示失败原因。

#### 2.1.4 处理控制

**开始处理**：确认对话框展示图片信息（文件名、尺寸、大小）、算法信息（名称、预估时间、参数配置）和处理提示，用户可选择取消或开始处理。

**取消处理**：支持取消进行中的处理，取消后前端不再展示该任务结果。

#### 2.1.5 进度反馈

处理过程中实时推送任务状态变更：

| 事件 | 触发时机 | 前端响应 |
|------|---------|---------|
| 阶段变更 | 处理阶段切换（如图片加载→模型推理→后处理） | 更新阶段提示文案 |
| 任务完成 | 任务成功完成 | 停止计时，跳转对比页面 |
| 任务失败 | 任务失败 | 停止计时，展示错误信息+重试按钮 |

UI 展示规则：
- 显示当前处理阶段名称（如"正在加载图片..." → "模型推理中..." → "后处理..."）
- 实时耗时计时器与进度同步运行
- 计算密集型任务无真实进度百分比，不显示预估剩余时间
- 阶段切换时有过渡动画，避免界面突变

#### 2.1.6 快速返回优化

对于已有预计算结果的场景（如标准数据集图片），系统可跳过算法推理直接返回已缓存的处理结果，将响应时延从秒级降至毫秒级。

### 2.2 批量处理 (F-M04-002)

#### 2.2.1 功能描述

支持一次性处理多张图片，提高处理效率，适用于批量去雾需求场景。

#### 2.2.2 处理流程

```
选择多张图片（上限由会员等级决定）
    ↓
显示图片列表预览
    ↓
选择统一算法
    ↓
设置处理参数（可选）
    ↓
点击"批量处理"
    ↓
显示确认对话框
    ↓
用户确认 → 逐张/并行处理
    ↓
显示整体进度和单张进度
    ↓
处理完成 → 查看批量结果
```

#### 2.2.3 批量处理策略

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| 串行处理 | 逐张处理，稳定可靠 | 资源受限环境 |
| 并行处理 | 同时处理多张，速度快 | 高性能设备 |
| 智能模式 | 根据设备性能自动选择 | 推荐模式 |

#### 2.2.4 失败处理

- 单张失败不影响其他图片处理
- 记录失败原因和失败图片
- 支持重试失败的图片
- 生成详细处理报告

#### 2.2.5 批量进度

展示整体进度（完成数量、成功数、失败数）和当前正在处理的图片进度。支持暂停全部、取消全部和重试失败的操作。

---

### 2.3 参数调节 (F-M04-003)

#### 2.3.1 功能描述

为用户提供算法参数调节能力，实现个性化处理效果。支持实时预览调参效果。

#### 2.3.2 通用参数

| 参数名称 | 调节范围 | 默认值 | 说明 |
|---------|---------|--------|------|
| 去雾强度 | 0-100 | 50 | 控制去雾程度，值越大去雾效果越强 |
| 色彩饱和度 | 0-200 | 100 | 调整色彩鲜艳度，100为原始值 |
| 对比度 | 0-200 | 100 | 调整明暗对比，100为原始值 |
| 锐化程度 | 0-100 | 30 | 增强细节清晰度 |

#### 2.3.3 算法特定参数

不同算法提供各自的专属参数，例如：
- DCP 算法：去雾系数、窗口大小、引导滤波半径
- 深度学习算法：推理精度、批处理大小

#### 2.3.4 参数预设

系统提供预设参数方案，帮助用户快速获得理想效果：

| 来源 | 说明 |
|------|------|
| **管理员预设** | 系统管理员预置的推荐方案（如"自然""鲜艳""风景优化"），所有用户可见 |
| **用户自定义** | 用户保存的个人参数方案，可命名、编辑、删除 |

VIP 用户享有更多自定义预设数量（见 §4.1）。

---

### 2.4 处理结果管理 (F-M04-004)

#### 2.4.1 功能描述

管理处理结果，支持保存、分享、导出等操作。

#### 2.4.2 自动保存

处理完成后自动保存原图和处理结果图，并关联处理参数和元数据。

文件命名规则：`原文件名_算法名_时间戳.格式`

#### 2.4.3 手动保存

| 选项 | 说明 | 可选值 |
|------|------|--------|
| 保存格式 | 图片文件格式 | JPG / PNG |
| 保存质量 | 图片压缩质量 | 60% / 80% / 90% / 100% |
| 元数据 | 是否包含处理信息 | 是 / 否 |

#### 2.4.4 结果分享

支持将处理结果分享到社交平台、生成分享链接、生成二维码或发送到邮箱。

分享内容可选：仅处理后图片、对比图（原图+处理结果并排/上下）、处理信息（算法、参数、时间）。

#### 2.4.5 结果导出

| 格式 | 说明 | 适用场景 |
|------|------|---------|
| 单张图片 | JPG/PNG 格式 | 日常使用 |
| 对比图 | 原图+结果并排/上下 | 效果展示 |
| PDF 报告 | 包含详细处理信息 | 专业报告 |
| 批量打包 | ZIP 压缩包 | 批量处理结果 |

导出设置支持选择分辨率、质量、水印选项和元数据选项，并显示预计文件大小。

---

### 2.5 处理队列管理 (F-M04-005)

#### 2.5.1 功能描述

管理处理任务队列，支持任务优先级和并发控制，适用于多任务处理场景。

#### 2.5.2 队列功能

- 查看队列中的所有任务
- 调整任务优先级（拖拽排序）
- 暂停/恢复单个任务
- 取消任务
- 清空队列

#### 2.5.3 队列状态

| 状态 | 说明 |
|------|------|
| 等待中 | 排队等待处理 |
| 处理中 | 正在处理 |
| 已暂停 | 用户手动暂停 |
| 已完成 | 处理成功 |
| 已失败 | 处理失败 |
| 已取消 | 用户取消 |

#### 2.5.4 并发与优先级

- 根据设备性能自动调整并发数
- VIP 用户享有优先处理权（见 §4.1）
- 失败任务自动重试（最多 3 次，间隔递增）

#### 2.5.5 队列界面

显示当前并发设置和所有任务列表（优先级、图片名称、算法、状态、进度、操作按钮）。支持清空已完成和清空全部，已完成任务可折叠显示。

---

### 2.6 错误处理与恢复 (F-M04-006)

#### 2.6.1 错误类型及处理

| 错误类型 | 提示信息 | 处理方式 |
|---------|---------|---------|
| 内存不足 | "设备内存不足，请关闭其他应用后重试" | 释放资源，提示用户清理 |
| 算法加载失败 | "算法加载失败，请检查网络连接" | 重试加载 |
| 处理超时 | "处理超时，建议更换算法或降低图片分辨率" | 取消处理，提供优化建议 |
| 图片损坏 | "图片文件损坏，无法处理" | 跳过该图片，继续后续 |
| 存储空间不足 | "存储空间不足，请清理后重试" | 提示清理空间 |
| 网络异常 | "网络连接异常，请检查网络设置" | 自动重试/提示用户 |
| 硬件资源不足 | "硬件资源不足，已切换到备用处理模式" | 自动降级处理 |
| 次数配额不足 | "去雾次数已达上限，请升级会员" | 引导升级会员 |

#### 2.6.2 断点续传

- 每完成一个处理阶段自动保存进度
- 应用重启后检测未完成任务
- 支持从断点恢复处理
- 保留处理上下文和参数

#### 2.6.3 恢复界面

检测到未完成的处理任务时，显示中断原因、图片信息、算法名称、已完成进度和中断时间，提供"放弃"或"从断点恢复"选项。

### 2.7 处理历史 (F-M04-007)

#### 2.7.1 功能描述

记录用户的所有去雾处理结果，支持历史记录查询、筛选、查看对比、重新处理等操作。处理历史是用户回溯处理效果、对比不同算法结果的核心入口。

#### 2.7.2 存储内容

每条处理历史记录包含：原图信息、结果信息、算法信息、处理参数、评估指标（如有）、用户评价（如有）、处理时间和状态。

#### 2.7.3 查询与筛选

| 条件类型 | 说明 |
|---------|------|
| 时间范围 | 按处理时间筛选 |
| 算法筛选 | 按算法筛选历史记录 |
| 评分筛选 | 按用户评分筛选（含"未评价"选项） |
| 状态筛选 | 成功/失败 |
| 关键字搜索 | 按原图文件名模糊匹配 |

排序方式：处理时间（默认倒序）、评分（倒序）、处理耗时（正序）。

#### 2.7.4 展示形式

**列表视图（默认）**：时间线形式展示，每条记录包含缩略图、算法名称、处理时间、耗时、评分、评估指标（如有）和操作按钮（查看对比/重新处理/删除）。

**网格视图**：卡片式布局，以结果图缩略图为主体，适合快速浏览。

两种视图可通过按钮切换。

#### 2.7.5 数据管理

历史记录保留条数受会员等级控制（见 §4.1）。超出上限时自动删除最早记录，被评价过的记录优先保留。用户可手动删除记录，删除操作需二次确认且不可恢复。

#### 2.7.6 重新处理

从历史记录可发起重新处理，支持两种模式：
- **同算法重处理**：使用原算法重新处理同一张图片，可沿用原参数或重新配置
- **换算法处理**：使用不同算法处理同一张图片

重新处理流程复用单张处理流程（§2.1），原图从历史记录中获取，无需重新上传。

#### 2.7.7 历史记录对比

支持选择 2-3 条历史记录进行横向对比，对比维度包括：结果图并排、指标对比、参数对比、评分对比。

## 3. 用户交互流程

### 3.1 单张处理完整流程

用户选择或上传图片 → 系统加载预览并自动分析图像特征 → 用户选择算法（或使用推荐）并可选调整参数 → 系统显示算法信息和预估处理时间 → 点击开始去雾 → 显示确认对话框 → 用户确认 → 显示进度（处理阶段、实时耗时） → 处理完成 → 自动跳转对比页面 → 用户查看对比效果后可保存或分享结果。

### 3.2 批量处理完整流程

选择多张图片 → 显示图片列表 → 选择统一算法 → 设置参数（可选） → 点击批量处理 → 确认对话框 → 开始批量处理 → 显示整体进度和单张进度 → 全部完成 → 查看批量结果 → 批量导出/分享。

## 4. 会员权益

### 4.1 等级差异

去雾处理模块的会员权益由[会员管理模块](../../基础模块/会员管理/需求规格.md)统一管理，各等级差异如下：

| 权益项 | 普通用户 | VIP1 | VIP2 | SVIP |
|--------|---------|------|------|------|
| 每月去雾次数 | 20 次 | 100 次 | 500 次 | 3000 次 |
| 批量处理上限 | 5 张 | 10 张 | 15 张 | 20 张 |
| 处理优先级 | 普通 | 优先 | 高优先 | 最高 |
| 历史记录保留 | 10 条 | 50 条 | 100 条 | 500 条 |
| 高级参数调节 | 否 | 是 | 是 | 是 |
| 高清图导出 | 否 | 是 | 是 | 是 |
| 自定义预设数量 | 3 个 | 10 个 | 20 个 | 无限制 |

### 4.2 次数扣减

用户每次发起去雾处理，系统校验会员等级对应的月度配额。次数充足则执行处理并扣减次数，次数不足则提示升级会员。

月度配额每月 1 日自动重置。

## 5. 消息通知集成

去雾处理模块通过[消息通知模块](../../基础模块/消息通知/需求规格.md)（F-MN-001）向用户推送以下通知：

| 触发事件 | 消息类型 | 通知内容 |
|---------|---------|---------|
| 单张/批量处理完成 | 业务通知 | 任务完成，点击查看效果 |
| 处理失败 | 业务通知 | 任务失败，说明失败原因 |
| 月度配额即将用尽 | 业务通知 | 本月剩余次数不足 3 次，建议升级会员 |

---

## 6. 收藏管理集成

处理结果支持收藏功能，由[收藏管理模块](../../基础模块/收藏管理/需求规格.md)统一管理：

- 收藏类型：`result`（处理结果）
- 收藏入口：处理历史列表的收藏按钮、对比页面的收藏按钮
- 取消收藏：收藏列表左滑删除或再次点击已收藏图标

---

## 7. 推荐管理集成

去雾处理模块与[推荐管理模块](../../基础模块/推荐管理/需求规格.md)集成：

- 算法选择页面的"推荐"Tab 展示推荐管理模块生成的算法推荐（F-REC-002）
- 用户可一键使用推荐算法进入去雾处理流程
- 推荐策略指导默认参数方案

---

## 8. 任务管理对齐

去雾处理模块的异步任务状态管理参考[任务管理模块](../../基础模块/任务管理/需求规格.md)：

- 任务状态值：处理中 / 已完成 / 已失败（对应任务管理模块的 PROCESSING / COMPLETED / FAILED）
- 状态变更流程：创建→处理中→已完成/已失败
- 重试机制和间隔策略与任务管理模块保持一致
