# 去雾处理模块 - 前端实现设计

## 1. 文档概述

本文档描述去雾处理模块的前端实现方案，聚焦组件架构、状态管理、路由设计等架构决策。

---

## 2. 组件设计

### 2.1 组件结构

```
去雾处理模块
├── PredictionPage             # 去雾处理主页面
│   ├── ImagePreview            # 原图预览区（复用图像输入模块组件）
│   ├── AlgorithmSelector       # 算法选择面板（复用算法选择模块组件）
│   ├── ParameterPanel          # 参数调节面板
│   │   ├── CommonParams        # 通用参数（去雾强度/饱和度/对比度/锐化）
│   │   └── AlgorithmParams     # 算法特定参数（动态表单）
│   ├── PresetSelector          # 预设方案选择器
│   │   ├── SystemPresets       # 系统预设列表
│   │   └── UserPresets         # 用户自定义预设列表
│   ├── BatchPanel              # 批量处理面板
│   │   ├── ImageListPreview    # 多图片选择列表
│   │   └── BatchParamConfig    # 批量参数配置
│   ├── ProcessProgress         # 处理进度展示
│   │   ├── ProgressBar         # 进度条
│   │   ├── StageDescription    # 当前阶段描述
│   │   └── CancelButton        # 取消按钮
│   ├── ResultPreview           # 结果预览区
│   │   ├── ResultImage         # 处理后图片
│   │   └── QuickActions        # 快速操作（保存/分享/对比/收藏）
│   ├── ConfirmDialog           # 处理确认对话框
│   ├── QuotaWarningDialog      # 配额不足弹窗
│   └── HistoryPanel            # 处理历史面板（可选入口）
└── PresetManageDialog          # 预设管理弹窗（新增/编辑/删除）
```

### 2.2 组件职责

| 组件 | 职责 | 复用性 |
|------|------|--------|
| PredictionPage | 页面容器，路由入口，管理处理流程全局状态 | 不可复用 |
| ImagePreview | 展示原图，支持缩放和基础操作 | 复用图像输入模块组件 |
| AlgorithmSelector | 算法选择交互，支持推荐、搜索、树形浏览 | 复用算法选择模块组件 |
| ParameterPanel | 通用参数+算法特定参数的统一调节面板 | 可复用 |
| CommonParams | 通用参数滑块组（去雾强度/饱和度/对比度/锐化） | 可复用于效果对比 |
| AlgorithmParams | 根据算法动态渲染特定参数控件 | 可复用 |
| PresetSelector | 预设方案下拉选择，区分系统/用户预设 | 可复用 |
| BatchPanel | 批量处理图片列表管理和参数配置 | 不可复用 |
| ProcessProgress | 异步处理进度展示，阶段描述+耗时计时 | 可复用于其他异步任务场景 |
| ResultPreview | 结果图展示+快速操作入口 | 可复用 |
| ConfirmDialog | 处理前确认（图片信息/算法信息/预估耗时） | 不可复用 |
| QuotaWarningDialog | VIP配额不足时的升级引导弹窗 | 可复用于其他会员受限场景 |
| PresetManageDialog | 预设方案的增删改管理弹窗 | 不可复用 |

## 3. 页面布局设计

### 3.1 页面结构

采用**左侧参数配置+右侧预览**的双栏布局：

| 区域 | 宽度 | 说明 |
|------|------|------|
| 左侧面板 | 380px | 算法选择器 + 参数调节 + 预设选择 |
| 右侧预览 | 自适应填充 | 原图预览 + 处理进度/结果 |

### 3.2 响应式布局

| 屏幕尺寸 | 布局方式 |
|---------|---------|
| 桌面端（>=992px） | 左右双栏，左侧固定宽度 |
| 移动端（<992px） | 上下堆叠，参数面板可折叠 |

### 3.3 路由设计

| 路由路径 | 页面 | 说明 |
|---------|------|------|
| /prediction | PredictionPage | 去雾处理主页（无预设参数） |
| /prediction?imageId=xxx&algorithmId=yyy | PredictionPage | 携带图片ID和算法ID跳转，自动加载对应资源 |

路由参数说明：
- `imageId`：从图像输入/历史记录传入，自动加载对应图片
- `algorithmId`：从算法选择/推荐模块传入，自动选中对应算法

## 4. 状态管理

### 4.1 状态定义

| Store | 职责 |
|-------|------|
| predictionStore | 处理状态、当前图片、选中算法、参数配置、预设列表、批量任务 |

### 4.2 predictionStore 核心状态

| 状态字段 | 类型 | 说明 |
|---------|------|------|
| status | idle/processing/completed/failed | 当前处理状态 |
| currentImage | object | 当前处理的图片信息 |
| selectedAlgorithm | object | 当前选中的算法 |
| commonParams | object | 通用参数值（去雾强度/饱和度/对比度/锐化） |
| algorithmParams | object | 算法特定参数值（动态键值对） |
| systemPresets | array | 管理员预设方案列表 |
| userPresets | array | 用户自定义预设方案列表 |
| activePresetId | string | 当前应用的预设ID |
| batchImages | array | 批量处理图片列表 |
| batchProgress | object | 批量处理进度（total/success/failed） |
| taskId | string | 当前异步任务ID |
| processStage | string | 当前处理阶段描述 |
| elapsedTime | number | 处理耗时（秒） |
| result | object | 处理结果（图片URL+元数据） |
| error | string | 失败原因 |

### 4.3 predictionStore Actions

| 方法 | 说明 |
|------|------|
| setImage(image) | 设置当前处理图片 |
| selectAlgorithm(algorithm) | 选择算法 |
| updateCommonParams(params) | 更新通用参数 |
| updateAlgorithmParams(params) | 更新算法特定参数 |
| fetchPresets() | 获取预设列表（系统+用户） |
| applyPreset(presetId) | 应用预设方案 |
| savePreset(name, params) | 保存当前参数为用户预设 |
| deletePreset(presetId) | 删除用户预设 |
| submitProcess() | 提交单张处理任务 |
| submitBatchProcess() | 提交批量处理任务 |
| pollTaskStatus(taskId) | 轮询任务状态 |
| cancelProcess(taskId) | 取消处理任务 |
| checkQuota() | 检查VIP配额 |
| fetchHistory(params) | 获取处理历史（分页） |
| reprocess(historyId) | 从历史记录重新处理 |
| resetState() | 重置处理状态 |

## 5. 数据流

### 5.1 单张处理流程

```
选择图片 → 选择算法/使用推荐 → 配置参数 → 检查配额
    ↓ 配额不足：弹窗引导升级VIP
    ↓ 配额充足
弹出确认对话框（图片信息/算法信息/预估耗时）
    ↓ 用户确认
提交异步任务 → 更新状态为 processing → 开启轮询
    ↓ 轮询间隔：2s
阶段变更 → 更新 stage + 计时器
任务完成 → 更新状态为 completed → 停止轮询 → 展示结果
任务失败 → 更新状态为 failed → 展示错误+重试按钮
```

### 5.2 批量处理流程

```
选择多张图片 → 选择统一算法 → 配置参数 → 检查配额
    ↓
弹出确认对话框（图片数量/算法/预估总耗时）
    ↓ 用户确认
提交批量任务 → 更新 batchProgress → 开启轮询
    ↓
整体进度 + 单张进度实时更新
    ↓
全部完成 → 展示批量结果统计 → 支持批量导出/分享
```

### 5.3 模块间数据交互

| 交互方向 | 数据 | 说明 |
|---------|------|------|
| 图像输入 → 去雾处理 | imageId | 从上传/拍照/样例/历史记录选择图片后跳转 |
| 算法选择 → 去雾处理 | algorithmId | 从算法选择/推荐页面选择算法后跳转 |
| 去雾处理 → 收藏管理 | FavoriteButton | 结果展示区收藏按钮，targetType=result |
| 去雾处理 → 推荐管理 | imageId | 提交图片特征分析请求，获取推荐算法列表 |
| 去雾处理 → 会员管理 | 配额检查 | 提交前查询剩余次数，不足时弹窗引导升级 |

### 5.4 预设加载优先级

加载预设列表时，按以下优先级排序展示：

1. 用户自定义预设（优先展示，按创建时间倒序）
2. 系统预设（管理员预设，按推荐度排序）
3. 默认参数（兜底方案，始终存在）

## 6. 关键交互决策

### 6.1 批量参数配置策略

| 配置模式 | 说明 | 适用场景 |
|---------|------|---------|
| 统一配置 | 所有图片使用相同参数 | 图片场景相似（默认模式） |
| 单张配置 | 每张图片独立设置参数 | 图片场景差异大 |

默认使用统一配置模式，单张配置作为高级选项。

### 6.2 处理进度实时更新

| 方案 | 当前状态 | 说明 |
|------|:------:|------|
| 轮询 | 实现 | 前端每 2s 轮询任务状态接口，获取当前阶段和耗时 |
| WebSocket | 预留 | 架构已预留 WebSocket 切换能力，后续可升级为推送模式 |

轮询策略：
- 正常间隔：2s
- 页面不可见时：停止轮询，恢复可见后立即查询一次
- 组件卸载时：取消轮询定时器

### 6.3 处理阶段展示

不显示具体百分比（计算密集型任务无真实进度），改为展示当前阶段描述：

| 阶段 | 描述文案 | 持续时间 |
|------|---------|---------|
| 图片加载 | "正在加载图片..." | 1-3s |
| 模型推理 | "模型推理中..." | 取决于算法 |
| 后处理 | "后处理中..." | 1-2s |

阶段切换时有过渡动画，避免界面突变。

### 6.4 重试策略

失败任务重试间隔递增：2s -> 5s -> 10s，最多重试 3 次。不可重试的错误（图片损坏、权限不足）直接提示原因，不自动重试。

### 6.5 快速返回优化

对于已有预计算结果的场景（标准数据集图片），后端直接返回缓存结果，前端无需展示处理进度，直接跳转结果展示。

## 7. 权限与会员控制

### 7.1 配额检查

| 检查时机 | 操作 | 说明 |
|---------|------|------|
| 提交处理前 | 查询剩余次数 | 调用会员管理模块接口 |
| 次数不足 | 弹窗引导升级 | 展示当前等级/已用次数/升级权益对比 |

### 7.2 功能限制

| 功能 | 普通用户 | VIP |
|------|:------:|:---:|
| 单张处理 | 20次/月 | 100-3000次/月 |
| 批量处理上限 | 5张 | 10-20张 |
| 高级参数调节 | 否 | 是 |
| 高清图导出 | 否 | 是 |
| 自定义预设数量 | 3个 | 10个-无限制 |

---

## 8. 性能优化

| 优化项 | 实现方式 |
|--------|---------|
| 图片预加载 | 从路由参数获取 imageId 后预加载原图 |
| 轮询控制 | 页面不可见时停止轮询，恢复后立即查询 |
| 参数防抖 | 滑块调节参数时防抖 200ms 更新预览 |
| 预设缓存 | 预设列表缓存至 Store，页面切换不清除 |
| 请求取消 | 切换页面时取消进行中的轮询和未完成请求 |

---

## 9. 错误处理

| 错误类型 | 处理方式 |
|---------|---------|
| 配额不足 | 弹窗引导升级VIP |
| 处理失败 | 展示错误信息 + 重试按钮（可重试错误） |
| 算法加载失败 | 提示检查网络，提供备选算法 |
| 图片损坏 | 提示文件无效，引导重新选择 |
| 网络异常 | 自动重试 + 提示用户 |
| 处理超时 | 提示建议更换算法或降低分辨率 |
