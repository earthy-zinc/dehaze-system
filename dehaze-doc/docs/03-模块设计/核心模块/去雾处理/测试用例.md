# 去雾处理模块 - 测试用例

## 1. 测试目标

- 验证单张图像处理异步任务全流程（提交->轮询->结果->取消）（F-M04-001）
- 验证批量处理功能及部分失败、超限等边界场景（F-M04-002）
- 验证配额查询（剩余/总次数、等级差异、配额耗尽）
- 验证参数预设管理（创建/查询/更新/删除、系统预设保护、名称冲突）（F-M04-003）
- 验证拦截器链（MD5 缓存命中/WPXNet 预查询）
- 验证取消接口（终止推理+回滚配额+幂等性）
- 验证失败重试退避（指数退避 2s->4s->8s，最大 3 次）
- 验证结果管理（自动注册、重新处理）（F-M04-004）
- 验证收藏集成（处理结果收藏/取消收藏、收藏状态检查）
- 验证推荐集成（recommendedBy 字段记录）
- 验证预测日志管理（分页、按算法筛选）
- 验证主链路跨模块集成（图像输入->算法选择->去雾处理->效果对比）

## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| 测试图片 | JPG/PNG 格式，1MB/5MB/10MB/20MB | 测试不同大小处理 |
| 测试用户 | 普通用户、VIP1、SVIP 各 1 个 | 测试配额查询与批量上限差异 |
| 测试算法 | 已发布算法（DCP、AOD-Net、FFA-Net）各 1 个 | 测试算法选择与 MD5 缓存 |
| 参数预设 | 系统预设 3 个、用户自定义预设 2 个 | 测试预设管理 |
| 预测记录 | 各状态记录（1/2/3/4）各 5 条 | 测试日志列表与状态查询（含已取消） |
| 收藏数据 | 收藏管理模块已有收藏记录 | 测试收藏集成 |

### 3.2 数据清理

- 测试产生的预测记录、自定义预设需在测试结束后清理
- 系统预设不可删除，保留不动

### 3.3 测试范围

**包含的功能点：**

- 单张图像处理（F-M04-001）：异步任务提交、状态轮询、拦截器链（MD5 缓存/WPXNet 预查询）、取消接口（终止推理+回滚配额+幂等性）、失败重试退避
- 批量处理（F-M04-002）：数量上限校验、部分失败处理
- 参数预设管理（F-M04-003）：创建/查询/更新/删除、系统预设保护、名称冲突
- 结果管理（F-M04-004）：结果自动注册、重新处理
- 效果评估（F-M02-005）：指标计算、评估日志（评估能力由[效果对比模块](../效果对比/需求规格.md)承接，接口归属本模块文档）
- 预测日志管理：分页查询、按算法筛选（处理记录属 F-M04-001/F-M04-002）
- 配额查询：剩余/总次数、等级差异、配额耗尽
- 收藏集成：收藏管理模块能力（**前端未接入收藏入口**，接口级用例见收藏管理模块）
- 推荐集成：recommendedBy 字段记录（接口级）

**不包含的功能点（规划中/未实现，不编写用例）：**

- 处理队列管理（F-M04-005，规划中未实现）
- 断点续传（规划中未实现）
- 结果分享/PDF 导出（规划中未实现）
- 处理完成/失败消息通知（未接入，见需求规格 §5）
- 真实进度推送 WebSocket（改造目标未实现，当前为前端模拟进度）
- 配额扣减拦截（预测流程未接入 deductQuota，仅查询展示）
- 视频去雾（未来扩展）
- UI 组件渲染细节

## 5. 关键边界与异常

### 5.1 算法参数与缓存边界

| 边界条件 | 测试点 | 期望行为 |
|---------|--------|---------|
| MD5 缓存 TTL | 缓存超过 24h 后重复提交 | 缓存过期，重新执行算法推理 |
| WPXNet 预查询映射缺失 | 原图 MD5 不在 sys_wpx_file 表中 | 走正常异步处理流程 |
| 无效算法 ID | 提交不存在的 algorithmId | 返回 A0401"算法不存在" |
| 图片来源缺失 | fileId 和 imageUrl 均为空 | 返回 A0410"图片来源不能为空" |
| 配额耗尽 | 用户本月配额已用完 | 返回 A0515"当月次数已用完" |

### 5.2 批量处理边界

| 边界条件 | 测试点 | 期望行为 |
|---------|--------|---------|
| 普通用户批量上限 | 提交 6 张（Java 端上限 5） | 返回 A0500"批量处理图片数量不能超过5张" |
| VIP1 批量上限 | 提交 51 张（Java）/ 21 张（Python） | Java 端超 50 张拒绝；Python 端超 20 张拒绝 |
| SVIP 批量上限 | 提交 1000 张 | Java 端正常；Python 端超 20 张被硬编码上限拒绝 |
| 空 items | 提交空数组 | 返回参数校验失败 |
| 批量单张失败 | 某张图片处理异常 | 该张 status=3，不影响其他图片 |

### 5.3 任务状态与取消幂等性
