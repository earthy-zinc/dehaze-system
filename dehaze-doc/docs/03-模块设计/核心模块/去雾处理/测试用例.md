# 去雾处理模块 - 测试用例

## 1. 测试目标

- 验证单张图像处理异步任务全流程（提交->轮询->结果->取消）（F-M04-001）
- 验证批量处理功能及部分失败、超限等边界场景（F-M04-002）
- 验证图像按张积分计费（提交前余额校验、成功后实扣、缓存命中/失败/取消不计费、评估免费）
- 验证参数预设管理（创建/查询/更新/删除、系统预设保护、名称冲突）（F-M04-003）
- 验证拦截器链（MD5 缓存命中/WPXNet 预查询）
- 验证取消接口（终止推理+幂等性）
- 验证失败重试退避（指数退避 2s->4s->8s，最大 3 次）
- 验证结果管理（自动注册、重新处理）（F-M04-004）
- 验证收藏集成（处理结果收藏/取消收藏、收藏状态检查）
- 验证推荐集成（recommendedBy 字段记录）
- 验证任务历史管理（分页、按模型筛选）
- 验证主链路跨模块集成（图像输入->图像模型选择->去雾处理->效果对比）

## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容                                         | 说明                               |
| -------- | ------------------------------------------------ | ---------------------------------- |
| 测试图片 | JPG/PNG 格式，1MB/5MB/10MB/20MB                  | 测试不同大小处理                   |
| 测试用户 | 普通用户、VIP1、SVIP 各 1 个                     | 测试积分余额与批量上限差异         |
| 测试模型 | 已启用图像模型（aecrnet、aodnet、ffanet）各 1 个 | 测试模型选择与 MD5 缓存            |
| 参数预设 | 系统预设 3 个、用户自定义预设 2 个               | 测试预设管理                       |
| 任务记录 | 各状态记录（1/2/3/4）各 5 条                     | 测试历史列表与状态查询（含已取消） |
| 收藏数据 | 收藏管理模块已有收藏记录                         | 测试收藏集成                       |

### 3.2 数据清理

- 测试产生的任务记录、自定义预设需在测试结束后清理
- 系统预设不可删除，保留不动

### 3.3 测试范围

**包含的功能点：**

- 单张图像处理（F-M04-001）：异步任务提交、状态轮询、拦截器链（MD5 缓存/WPXNet 预查询）、取消接口（终止推理+幂等性）、失败重试退避
- 批量处理（F-M04-002）：数量上限校验、部分失败处理（SDK 多次提交）
- 参数预设管理（F-M04-003）：创建/查询/更新/删除、系统预设保护、名称冲突
- 结果管理（F-M04-004）：结果自动注册、重新处理
- 效果评估（F-M02-005）：指标计算、评估日志（评估能力由[效果对比模块](../效果对比/需求规格.md)承接，免费不计费）
- 任务历史管理：分页查询、按模型筛选（处理记录属 F-M04-001/F-M04-002）
- 图像积分计费：提交前余额校验（不预扣）、成功后按张实扣、缓存命中/失败/取消不计费
- 收藏集成：处理结果（targetType=result）可收藏，用例见 §4.6
- 推荐集成：recommendedBy 字段记录（接口级）

**不包含的功能点（不编写用例）：**

- 处理队列管理（F-M04-005）
- 断点续传
- 结果分享/PDF 导出
- 处理完成/失败消息通知（消息通知不接入，进度经实时推送获知）
- 真实进度推送 WebSocket（由任务管理模块承载，暂不执行）
- 视频去雾
- UI 组件渲染细节

## 5. 关键边界与异常

> 以下大部分边界已由 §4 用例覆盖，本节仅保留 §4 未覆盖的增量项，其余以用例编号引用。

### 5.1 模型参数与缓存边界

已由 §4 覆盖：图片来源缺失（T-DH-011）、积分不足（T-DH-019）、WPXNet 预查询映射缺失（T-DH-006）、无效模型标识（T-DH-082）。

增量项：

| 边界条件           | 测试点                                       | 期望行为                                                       |
| ------------------ | -------------------------------------------- | -------------------------------------------------------------- |
| MD5 缓存 TTL       | 缓存超过 24h 后重复提交                      | 缓存过期，重新执行模型推理                                     |
| 缓存值不落绝对 URL | 命中缓存后变更存储域名配置，再次提交相同请求 | 返回当前环境域名下的结果 URL，可直接访问（不返回历史环境域名） |

### 5.2 批量处理边界

已由 §4 覆盖：普通用户批量上限（T-DH-023）、VIP1/SVIP 批量上限（T-DH-025/T-DH-024）、空列表（T-DH-027）、批量单张失败（T-DH-026）。

### 5.3 任务状态与取消幂等性

已由 §4 覆盖：取消已完成/失败/重复取消（T-DH-014/T-DH-015/T-DH-016）、轮询不存在任务（T-DH-093）、轮询超时（T-DH-010）。

### 5.4 失败重试边界

已由 §4 覆盖：指数退避重试（T-DH-017）、超过最大重试次数（T-DH-018）。

### 5.5 预设管理边界

已由 §4 覆盖：系统预设保护（T-DH-054）、预设名称冲突（T-DH-058）。

增量项：

| 边界条件     | 测试点                   | 期望行为                       |
| ------------ | ------------------------ | ------------------------------ |
| 操作他人预设 | 删除其他用户的自定义预设 | 返回 A0502"不能操作他人的预设" |

### 5.6 数据一致性

| 场景               | 验证点             | 期望行为                                                       |
| ------------------ | ------------------ | -------------------------------------------------------------- |
| 任务完成后日志记录 | 查询 sys_pred_log  | status=2(已完成)，pred_url 非空，耗时正确；`model_id` 正确落库 |
| 任务失败后日志记录 | 查询 sys_pred_log  | status=3(失败)，error_message 非空，无积分流水                 |
| 任务取消后日志记录 | 查询 sys_pred_log  | status=4(已取消)，无积分流水                                   |
| MD5 缓存一致性     | 缓存命中时查询日志 | 写入已完成日志记录，与原结果一致，无积分流水                   |

## 6. 性能与并发

> 性能目标参见 [需求规格.md](./需求规格.md) 非功能需求

### 6.1 性能指标

| 指标              | 目标值     | 测试方法                                 |
| ----------------- | ---------- | ---------------------------------------- |
| WPXNet 预查询响应 | &lt; 100ms | 命中预查询拦截器，测量从请求到响应的时间 |
| MD5 缓存命中响应  | &lt; 100ms | 相同图片+模型重复提交，测量响应时间      |
| 任务提交响应      | &lt; 1s    | 提交任务到返回 taskId 的时间             |
| 轮询间隔          | 2s         | 前端轮询任务状态接口的频率               |
| 历史列表查询      | &lt; 500ms | 20 条任务历史分页查询                    |

### 6.2 并发场景

| 场景              | 并发数          | 验证点                        |
| ----------------- | --------------- | ----------------------------- |

| 并发历史列表查询  | 100 用户        | 响应时间 &lt; 1s              |
| 并发 MD5 缓存命中 | 10 用户相同图片 | 均返回历史结果，无重复执行    |

## 7. 安全性测试

| 测试项                       | 验证方式                                          | 预期结果                                       |
| ---------------------------- | ------------------------------------------------- | ---------------------------------------------- |
| 权限控制：未登录提交任务     | 未登录调用 POST /images/edits                     | 返回 A0230"token无效或已过期"                  |
| 数据隔离：访问他人任务状态   | 用户 A 查询用户 B 的 taskId                       | 返回 A0401"图像任务不存在"，无他人 taskId 泄漏 |
| 数据隔离：取消他人任务       | 用户 A 取消用户 B 的处理中任务                    | 返回 A0401，任务状态未被篡改                   |
| 数据隔离：历史列表仅本人     | 用户 A 查询历史列表                               | 仅返回用户 A 的记录                            |
| 状态机：取消后结果复活       | 取消任务后后台推理完成                            | 状态保持已取消，结果不覆盖终态                 |
| 输入防护：本地路径 imageUrl  | imageUrl 传服务器本地路径                         | 返回参数错误（任意文件读取防护）               |
| SSRF 防护：内网地址 imageUrl | imageUrl 传 127.0.0.1/10.x/192.168.x/169.254.x 等 | 返回参数错误，不发起内网请求                   |
| 推理超时                     | 推理超过 30s                                      | 任务标记失败且不计费，错误信息提示超时         |
| 参数校验：无效模型标识       | 提交不存在的模型 slug                             | 返回 A0401"模型不存在"，且不产生积分扣减       |
| 参数校验：图片来源缺失       | 不提供 fileId 和 imageUrl                         | 返回 A0410"图片来源不能为空"                   |
| 预设归属：操作他人预设       | 用户 A 删除用户 B 的预设                          | 返回 A0502"不能操作他人的预设"                 |
| 预设保护：修改系统预设       | PUT 系统预设                                      | 返回 A0502"系统预设不可修改"                   |
| 参数注入：恶意字符           | 图片 ID 参数包含恶意字符                          | 参数校验拒绝                                   |

> 上述归属校验/状态机/超时/SSRF 用例覆盖于 pytest `tests/service/test_prediction_security.py`（service/repository 层）、`tests/router/test_images_router.py`（路由层越权）、SDK `test/modules/ai-image/ai-image.test.ts`「越权防护」组。

### 8.1 端到端流程

| 用例ID   | 场景                                           | 前置条件               | 输入                   | 期望输出                                         | 优先级 |

### 8.2 跨模块数据传递验证

| 验证点             | 数据流                     | 期望行为                                                         |
| ------------------ | -------------------------- | ---------------------------------------------------------------- |
| imageUrl 传递      | 图像输入 -> 去雾处理       | imageUrl 正确传递，去雾处理使用该 URL 获取原图                   |

### 8.3 跨模块异常传播

| 异常场景     | 触发条件                | 期望行为                                           |
| ------------ | ----------------------- | -------------------------------------------------- |
| 图像输入失败 | 上传图片失败/格式不支持 | 去雾处理不被触发，前端停留在图像输入页             |
| 模型选择失败 | 选择的模型已被禁用      | 去雾处理返回 A0401"模型不存在"，前端引导重新选择   |
| 去雾处理失败 | 模型推理异常/超时       | 效果对比不被触发，前端展示失败信息+重试面板        |
| 去雾处理取消 | 用户取消处理中任务      | 效果对比不被触发，不产生积分扣减，任务状态为已取消 |
| 效果对比失败 | 评估任务异常            | 不影响去雾处理结果，评估失败可重试                 |
