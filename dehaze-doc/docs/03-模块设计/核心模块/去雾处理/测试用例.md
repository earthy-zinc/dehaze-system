## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| 测试图片 | JPG/PNG/WEBP 格式，1MB/5MB/10MB/20MB | 测试不同大小处理 |
| 测试用户 | 普通用户、VIP1、VIP2、SVIP 各 1 个 | 测试不同配额和权益 |
| 测试算法 | 已发布算法（DCP、AOD-Net、FFA-Net）各 1 个 | 测试算法选择 |
| 参数预设 | 系统预设 3 个、用户自定义预设 2 个 | 测试预设管理 |
| 历史记录 | 各状态记录（completed/failed）各 5 条 | 测试历史管理 |
| 收藏数据 | 收藏管理模块已有收藏记录 | 测试收藏集成 |

### 3.2 数据清理策略

- 测试处理记录使用统一前缀 `test_dehaze_` 标识任务 ID
- 测试结束后按前缀批量删除处理日志
- 测试用户配额在测试后恢复初始值
- 保留系统默认参数预设不做删除

### 3.3 测试范围

**包含的功能点：**

- 单张去雾处理（F-M04-001）：异步任务提交、状态流转、实时推送、WPXNet 预查询拦截器
- 批量处理（F-M04-002）：串行/并行/智能模式、部分失败处理
- 参数调节（F-M04-003）：通用参数、算法特定参数、预设管理
- 处理结果管理（F-M04-004）：自动保存、手动保存、分享、导出
- 错误处理与恢复（F-M04-006）：各类错误码、自动重试、僵尸任务恢复
- 处理历史（F-M04-007）：查询筛选、重新处理、自动清理
- VIP 权益校验：次数配额、等级差异
- 收藏集成：处理结果收藏/取消收藏
- 推荐集成：recommendedBy 字段记录
- 消息通知：处理完成、失败告警、配额不足提醒

**不包含的功能点：**

- 处理队列管理（F-M04-005，规划中未实现）
- 断点续传（规划中未实现）
- 视频去雾（未来扩展）
- UI 组件渲染细节

## 5. 关键边界与异常场景

| 场景 | 测试点 | 期望行为 |
|------|--------|---------|
| 实时推送连接断开 | 处理中连接断开 | 自动重连 3 次，失败后降级为轮询 |
| 服务重启后僵尸任务 | processing 超 10min 记录 | 定时任务标记为 failed |
| 并发配额扣减 | 剩余 1 次，2 个并发请求 | 仅 1 个成功，原子操作防护 |
| 批量部分失败 | 5 张中 2 张失败 | 失败图片记录原因，不影响成功图片 |
| 超限批量提交 | 提交 21 张（上限 20） | 拒绝提交 |
| 配额耗尽 | 本月次数用尽 | 拦截请求，引导升级 |
| 算法不可用 | 使用已禁用算法 | 拒绝提交 |
| 历史记录超限 | 普通用户第 11 条记录 | 自动删除最早的未评价记录 |
| 推荐算法失效 | 推荐的算法被下线 | 提示不可用，刷新推荐 |
| 收藏容量满 | 收藏数达上限 | 提示清理或升级 |
