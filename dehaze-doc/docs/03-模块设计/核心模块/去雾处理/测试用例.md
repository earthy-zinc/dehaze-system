## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| 测试图片 | JPG/PNG 格式，1MB/5MB/10MB/20MB | 测试不同大小处理 |
| 测试用户 | 普通用户、VIP1、SVIP 各 1 个 | 测试配额查询与批量上限差异 |
| 测试算法 | 已发布算法（DCP、AOD-Net、FFA-Net）各 1 个 | 测试算法选择与 MD5 缓存 |
| 参数预设 | 系统预设 3 个、用户自定义预设 2 个 | 测试预设管理 |
| 预测记录 | 各状态记录（1/2/3）各 5 条 | 测试日志列表与状态查询 |
| 收藏数据 | 收藏管理模块已有收藏记录 | 测试收藏集成 |

### 3.2 数据清理策略

- 测试处理记录使用统一前缀 `test_dehaze_` 标识任务 ID
- 测试结束后按前缀批量删除处理日志
- 测试用户配额在测试后恢复初始值
- 保留系统默认参数预设不做删除

### 3.3 测试范围

**包含的功能点：**

- 单张图像处理（F-M04-001）：异步任务提交、状态轮询、拦截器链（MD5 缓存/WPXNet 预查询）
- 批量处理（F-M04-002）：数量上限校验、部分失败处理
- 参数预设管理（F-M04-003）：创建/使用/删除、系统预设保护
- 效果评估：指标计算、评估日志（评估能力由[效果对比模块](../效果对比/需求规格.md)承接，接口归属本模块文档）
- 预测日志管理（F-M04-007）：分页查询、按算法筛选
- 配额查询：剩余/总次数、等级差异
- 收藏集成：收藏管理模块能力（**前端未接入收藏入口**，接口级用例见收藏管理模块）
- 推荐集成：recommendedBy 字段记录（接口级）

**不包含的功能点（规划中/未实现，不编写用例）：**

- 处理队列管理（F-M04-005，规划中未实现）
- 断点续传（规划中未实现）
- 结果分享/PDF 导出（规划中未实现）
- 处理完成/失败消息通知（未接入，见需求规格 §5）
- 处理任务后端取消（无取消接口；前端提供本地取消，仅忽略回调）
- 配额扣减拦截（预测流程未接入 deductQuota，仅查询展示）
- 视频去雾（未来扩展）
- UI 组件渲染细节

## 5. 关键边界与异常场景

| 场景 | 测试点 | 期望行为 |
|------|--------|---------|
| Python 轮询超时 | 处理中超过 300s | 任务标记为失败 |
| 批量部分失败 | 5 张中 2 张失败 | 失败图片记录原因，不影响成功图片 |
| 超限批量提交 | 普通用户提交 6 张 | 拒绝提交（上限 5 张） |
| MD5 缓存命中 | 相同图片+算法重复提交 | 直接返回历史结果，<100ms |
| 算法不可用 | 使用不存在的算法 | 返回 A0401 |
| 图片来源缺失 | 无 fileId 且无 imageUrl | 返回 A0500 |
| 系统预设保护 | 修改/删除系统预设 | 返回 A0502 |
| 收藏容量满 | 收藏数达上限 | 提示清理或升级 |

## 6. 性能与并发测试

### 6.1 性能指标

| 指标 | 目标值 | 测试方法 |
|------|--------|---------|
