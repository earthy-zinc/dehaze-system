# 数据集管理模块需求规格

## 1. 模块概述

### 1.1 模块定位

数据集管理模块是图像去雾系统的核心数据管理模块，负责管理系统中用于算法训练、测试和演示的各类图像数据集。该模块提供数据集和数据项（图片）的完整生命周期管理，包括创建、浏览、编辑、删除，以及图片的上传、配对、标注、下载等功能。

作为系统核心模块之一，数据集管理模块为【图像输入模块】的样例图片库提供数据源，为【算法管理模块】的算法评估提供测试数据集，是整个系统数据资产管理的中枢。

### 1.2 核心价值

| 价值维度 | 具体内容 |
|---------|---------|
| **集中管理** | 统一管理所有图像数据，支持数据集和图片的增删改查 |
| **结构化组织** | 树形结构管理数据集，最多5级深度，支持父子关系 |
| **高效浏览** | 瀑布流/网格/列表多种展示模式，流畅浏览体验 |
| **灵活标注** | 支持用户自定义场景类型，人工标注雾霾程度 |
| **配对管理** | 支持清晰图与多张有雾图的配对关系管理 |
| **快速搜索** | 多维度搜索和筛选，按相关度和时间排序 |
| **使用统计** | 记录用户使用数据集和图片的次数（Redis缓存） |

### 1.3 用户角色分析

| 用户类型 | 特征 | 使用偏好 | 功能需求 |
|---------|------|---------|---------|
| **算法研究员** | 负责数据集维护，熟悉数据组织方法 | 频繁上传/管理数据 | 批量上传+配对管理+标注功能 |
| **系统管理员** | 拥有完整操作权限，管理全局数据 | 权限控制+数据清理 | 全量管理+权限配置+审计 |
| **普通用户** | 使用公开数据集进行测试 | 浏览+选择+使用 | 数据集浏览+图片搜索+下载 |
| **VIP用户** | 更高存储配额和访问权限 | 私有数据集管理 | 私有空间+更大配额+优先处理 |

## 2. 功能需求

### 2.1 数据集列表展示 (F-M06-001)

#### 2.1.1 功能描述

以树形结构展示所有数据集列表，支持查看数据集基本信息和统计数据，提供搜索、筛选和排序功能。

#### 2.1.2 数据集分类

| 数据集类型 | 说明 | 典型数量 | 可见性 |
|----------|------|---------|--------|
| **样例数据集** | 系统预置的样例图片，供快速体验 | 40张 | 公开 |
| **测试数据集** | 用于算法测试的标准数据集 | 100张+ | 公开/受限 |
| **用户数据集** | 用户上传的私有图片 | 不限 | 私有 |
| **处理结果集** | 去雾处理后的结果图片 | 不限 | 私有 |

#### 2.1.3 列表信息展示

**基本信息**

| 字段 | 说明 | 示例 |
|------|------|------|
| 数据集名称 | 支持树形展示 | "城市建筑" |
| 数据集类型 | 样例/测试/用户/结果 | "测试数据集" |
| 数据集状态 | 启用/禁用（标签形式） | 🟢 启用 |
| 图片数量 | 数据集内图片总数 | 150张 |
| 总大小 | 占用存储空间 | 256MB |
| 创建时间 | YYYY-MM-DD HH:mm | 2025-01-15 10:30 |
| 最后更新时间 | YYYY-MM-DD HH:mm | 2025-01-17 14:20 |

**统计信息（Redis缓存）**

- 场景类型分布（用户自定义场景类型）
- 雾霾程度分布（人工标注：轻度/中度/重度）
- 分辨率分布
- 使用次数（用户使用该数据集进行去雾处理的次数）

#### 2.1.4 树形结构管理

**功能要求**

数据集列表页面需提供：
- 搜索功能：按数据集名称搜索，支持重置
- 操作功能：新增数据集（权限：sys:dataset:add）
- 展示内容：数据集树、数据集名称、数据集类型、数据集状态、图片数量
- 操作按钮：查看、新增下级、编辑、删除（各需对应权限控制）

**树形结构规则**

- 支持最多5级层级深度
- 数据集名称在同一层级下必须唯一
- 支持节点展开/收起
- 支持按关键字搜索过滤

### 2.2 数据集增删改查 (F-M06-002)

#### 2.2.1 新增数据集

**表单字段**

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|------|------|------|---------|------|
| 数据集名称 | 输入框 | ✅ | 不能为空，同级唯一 | - |
| 上级数据集 | 树形选择器 | ❌ | - | 为空则为顶级数据集 |
| 数据集类型 | 输入框 | ✅ | 不能为空 | - |
| 数据集描述 | 文本域 | ❌ | - | 最多500字 |
| 存储路径 | 输入框 | ✅ | 不能为空 | 系统自动生成或用户指定 |
| 数据集状态 | 单选框 | ✅ | - | 启用(1)/禁用(0)，默认启用 |

**业务流程**

1. 用户触发新增操作
2. 打开数据集表单弹窗
3. 用户填写表单并进行实时验证
4. 系统验证数据合法性
5. 验证通过后保存数据集
6. 刷新数据集树并显示成功提示

#### 2.2.2 编辑数据集

**可修改内容**

- 数据集名称
- 数据集类型
- 数据集描述
- 存储路径
- 数据集状态（启用/禁用）

**业务流程**

1. 用户触发编辑操作
2. 加载并显示数据集详细信息
3. 用户修改表单内容并进行实时验证
4. 系统验证数据合法性
5. 验证通过后更新数据集
6. 刷新数据集树并显示成功提示

#### 2.2.3 删除数据集

**删除规则**

- 支持单个删除和批量删除
- 删除时递归删除所有子数据集
- 删除时同时删除关联的所有图片数据
- 需进行二次确认，明确提示影响范围（子数据集数量、图片数量、占用空间）

**业务流程**

1. 用户触发删除操作
2. 系统弹出确认对话框，显示影响范围
3. 用户确认后执行递归删除
4. 刷新数据集树并显示成功提示

#### 2.2.4 数据集下载

**整体打包下载**

- 点击数据集操作栏的"下载"按钮
- 后端异步打包生成 ZIP 文件
- 打包完成后提供下载链接
- 支持下载进度显示

**下载内容**

- 所有数据项的图片文件
- 保持原始文件名
- 按数据项分目录组织（可选）
- 配对图片放在同一目录下

#### 2.3.1 功能描述

点击数据集"查看"按钮，进入数据集详情页面，展示数据集详细信息、统计分析和图片列表。

#### 2.3.2 页面内容

**头部信息区域**

展示数据集的基本信息：
- 数据集名称、类型、描述
- 创建时间、创建人
- 图片总数、占用空间、使用次数
- 提供"查看统计分析"功能

**工具栏区域**

提供以下功能：
- 展示模式切换：列表、纵向瀑布流、横向瀑布流、网格
- 类型筛选：全部、轻度、中度、重度、未标注
- 搜索功能
- 操作按钮：上传图片、批量下载、批量删除

**图片展示区域**

根据选择的展示模式显示图片列表

#### 2.3.3 统计分析弹窗

点击"查看统计分析"按钮，弹出统计分析弹窗：

**统计内容**

| 统计项 | 图表类型 | 说明 |
|--------|---------|------|
| 场景类型分布 | 饼图 | 用户自定义的场景类型占比 |
| 雾霾程度分布 | 柱状图 | 轻度/中度/重度/未标注占比 |
| 文件格式分布 | 饼图 | JPG/PNG/WEBP等格式占比 |
| 分辨率分布 | 柱状图 | 按分辨率区间统计 |

**缓存策略**

- 统计信息通过Redis缓存，响应时间&lt;200ms
- 缓存失效时间：数据变更时主动失效
- 缓存预热：后台定时更新热门数据集统计

### 2.4 图片展示模式 (F-M06-004)

#### 2.4.1 功能描述

提供多种图片展示模式，满足不同使用场景的需求：
- **列表模式**：注重数据管理，支持批量操作
- **图片模式**：注重图片预览，提供流畅浏览体验

系统记住用户偏好设置。

#### 2.4.2 列表模式

**功能定位**：注重数据集图片的管理，适合批量操作和详细信息查看

**列表信息展示**

需要显示的信息列：
- 缩略图（小尺寸预览）
- 文件名（可点击查看大图）
- 分辨率（宽×高）
- 文件大小
- 雾霾程度（轻度/中度/重度/未标注）
- 场景类型（用户自定义）
- 图片类型（有雾图/清晰图/去雾图）
- 上传时间
- 操作按钮（下载/编辑/删除）

**批量操作**

- 支持多选（Shift连续选择、Ctrl多选、全选）
- 批量删除：选中后显示删除按钮
- 批量下载：选中后显示下载按钮，打包下载所选图片

**交互要求**

- 点击文件名：打开大图查看
- 点击下载：下载图片（配对图片需弹出选择框）
- 点击编辑：打开图片信息编辑功能
- 点击删除：二次确认后删除

#### 2.4.3 纵向瀑布流模式

**功能定位**：适合浏览不同高度的图片，充分利用垂直空间

**布局要求**

- 竖屏显示：2列
- 横屏显示：3-4列
- 图片保持原始宽高比
- 支持自适应列宽

**图片卡片信息**

- 图片缩略图
- 图片名称（底部悬浮显示）
- 支持点击查看大图

#### 2.4.4 横向瀑布流模式

**功能定位**：适合浏览不同宽度的图片，横向滚动浏览

**布局要求**

- 2-3行展示
- 图片高度固定，宽度按比例自适应

**交互要求**

- 支持横向滚动浏览
- 支持鼠标滚轮横向滚动
- 支持触摸滑动

#### 2.4.5 网格模式

**功能定位**：整齐划一的展示方式，适合快速浏览大量图片

**布局要求**

- 列数自适应（根据容器宽度计算）
- 卡片尺寸固定
- 图片居中裁剪填充

**图片卡片信息**

- 图片缩略图（居中裁剪）
- 底部信息：文件名、雾霾程度标签
- 悬浮显示：分辨率、文件大小

#### 2.4.6 通用加载策略

**分页加载**

- 首屏加载：20张
- 滚动加载：每次20张
- 支持预加载下一屏
- 支持懒加载（可见区域才加载）

**性能优化**

- 虚拟滚动（列表模式）
- 图片懒加载（所有模式）
- 缩略图缓存

### 2.5 大图查看功能 (F-M06-005)

#### 2.5.1 触发方式

- 列表模式：点击文件名
- 图片模式：点击图片

#### 2.5.2 大图信息展示

| 信息项 | 说明 |
|--------|------|
| 图片原图 | 支持缩放、拖动 |
| 文件名 | - |
| 分辨率 | 宽×高 |
| 文件大小 | 格式化显示 |
| 雾霾程度 | 轻度/中度/重度/未标注 |
| 场景类型 | 用户自定义 |
| 上传时间 | YYYY-MM-DD HH:mm |
| 使用次数 | 被用于去雾处理的次数 |

#### 2.5.3 基本操作

| 操作 | 说明 |
|------|------|
| 双击放大/缩小 | 切换100%/适应屏幕 |
| 捏合手势缩放 | 移动端支持 |
| 拖动移动 | 放大后移动查看 |
| 旋转图片 | 90度旋转 |

#### 2.5.4 配对图片切换

当前图片如果有配对图像，需提供配对图片切换功能。

**配对结构说明**

- **清晰图像（Ground Truth）**：数据项可有 0 或 1 张清晰图像（部分数据集如 RESIDE/RTTS 无 GT）
- **有雾图像**：数据项可有 0 到多张有雾图像，每张有不同的雾霾程度（haze_level 可为人工分级或学术参数）
- **透射率图**：部分数据集（如 RESIDE/ITS、Haze4K）还包含透射率图

**切换方式**

支持以下切换方式之一：
- Tab切换：清晰图、有雾图（如有多个则按 haze_level 排序显示，如 "有雾图(beta=0.5)"、"有雾图(beta=0.8)"）
- 下拉选择：列表显示所有配对图片（含 haze_level 标识），选择切换

#### 2.5.5 操作按钮

| 按钮 | 功能 | 说明 |
|------|------|------|
| 下载 | 下载图片 | 配对图片弹出选择框 |
| 编辑 | 编辑图片信息 | 场景类型、雾霾程度、描述 |
| 删除 | 删除图片 | 二次确认 |
| 上一张/下一张 | 切换数据项 | 显示当前位置（如"3/50"） |

#### 2.5.6 下载选项弹窗

当图片有配对时，点击下载按钮需弹出选择弹窗。

**下载选项**

提供以下选项：
- 仅下载当前图片
- 仅下载清晰图
- 下载所有有雾图（打包下载）
- 下载全部图片（打包下载）

**特殊情况**

- 无配对图片时直接下载，不弹窗
- 选择打包下载时生成 ZIP 文件下载

### 2.6 图片类型切换与筛选 (F-M06-006)

#### 2.6.1 功能描述

支持按图片类型快速切换显示内容，多维度筛选图片。

#### 2.6.2 类型分类

**按雾霾程度分类（多规范支持）**

不同数据集采用不同的雾霾程度标注规范，系统统一支持以下几种格式（存储于 `haze_level` 字段，类型为 varchar(32)，可空）：

| 规范类型 | haze_level 取值 | 适用数据集示例 | 说明 |
|---------|----------------|---------------|------|
| 人工三级分级 | `light` / `medium` / `heavy` | 自定义数据集 | 由人工标注的轻度/中度/重度 |
| β 参数单值 | `beta=0.5` | RESIDE/ITS、RSHAZE | 学术界大气散射模型中的散射系数 β |
| A+β 双参数 | `A=0.8,beta=0.2` | RESIDE/OTS | 大气光 A 与散射系数 β 组合 |
| A+β 反序 | `beta=0.85,A=1.28` | Haze4K | β 在前、A 在后的变体格式 |
| 真实雾图无标注 | 空（NULL） | RESIDE/RTTS、RESIDE/HSTS(真实部分) | 真实场景拍摄的雾图，无合成参数 |
| 清晰图 | 空（NULL） | 所有 GT/clear 子目录 | 清晰图本身无雾霾程度概念 |

**Tab 切换展示**：当数据集存在多种 haze_level 格式时，Tab 切换按"是否为空"二分（已标注/未标注），不按具体值枚举，避免 Tab 数量爆炸。

**筛选面板**：提供 haze_level 关键字模糊搜索（如输入 "beta=0.5" 筛选所有 β=0.5 的图片）。

**按处理状态分类**

| 类型 | 说明 |
|------|------|
| 全部 | 显示所有图片 |
| 未处理 | 原始上传图片 |
| 已处理 | 已完成去雾处理 |
| 处理失败 | 去雾处理失败 |

**按图片类型分类**

| 类型 | 说明 |
|------|------|
| 有雾图 | type = hazy |
| 清晰图 | type = clear |
| 去雾图 | type = dehazed |

#### 2.6.3 切换交互

**Tab切换**

提供快速切换Tab，按雾霾程度分类（因 haze_level 支持多种规范，Tab 按是否标注二分）：
- 全部
- 已标注（haze_level 非空）
- 未标注（haze_level 为空）

**筛选面板**

提供多维度筛选功能：
- 弹出筛选面板
- 多维度筛选条件选择
- 实时预览结果数量
- 应用筛选条件

### 2.7 图片搜索功能 (F-M06-007)

#### 2.7.1 功能描述

支持多种方式搜索图片，搜索结果按相关度和时间排序。

#### 2.7.2 搜索方式

**关键词搜索**

- 按文件名搜索
- 按描述搜索
- 按场景类型搜索（用户自定义）
- 按上传时间搜索

**高级搜索**

- 按分辨率范围搜索（基于图片宽高）
- 按文件大小范围搜索
- 按雾霾程度搜索（人工标注）
- 按处理状态搜索

**智能搜索（扩展）**

- 相似图片搜索
- 以图搜图
- 智能推荐

#### 2.7.3 搜索结果

**结果展示**

- 瀑布流展示
- 高亮匹配关键词
- 显示匹配度
- **排序规则：按相关度降序，相关度相同时按时间降序**

**相关度计算规则**

| 匹配类型 | 权重 |
|---------|------|
| 文件名完全匹配 | 100 |
| 文件名包含关键词 | 50 |
| 描述包含关键词 | 30 |
| 场景类型匹配 | 20 |

**搜索历史**

- 保存最近10条搜索
- 快速重复搜索
- 清空搜索历史

### 2.8 图片上传功能 (F-M06-008)

#### 2.8.1 单张图片上传

**上传方式**

**上传时自动处理**

- 自动解析图片宽高并存储
- 自动生成缩略图
- 自动计算文件MD5

**上传时可选编辑**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 场景类型 | 输入框 | ❌ | 用户自定义，系统记录用于搜索建议 |
| 雾霾程度 | 下拉选择 | ❌ | light/medium/heavy |
| 图片描述 | 文本框 | ❌ | 自由文本输入 |
| 图片类型 | 下拉选择 | ❌ | 有雾图/清晰图 |

#### 2.8.2 配对图片上传（Image Pair）

**功能描述**

支持同时上传配对的有雾图像和清晰图像，系统自动校验并建立配对关系。

**配对结构说明**

- **清晰图像（Ground Truth）**：每个数据项只有一张清晰图像
- **有雾图像**：每个数据项可以有多张有雾图像，每张有不同的雾气程度
- 所有配对图片必须分辨率一致

**上传界面**

配对图片上传功能需提供：

1. **清晰图像区域**（必须上传一张）
   - 上传清晰图像（Ground Truth）
   - 显示上传预览

2. **有雾图像区域**（至少上传一张）
   - 支持上传多张有雾图像
   - 每张有雾图可单独设置雾霾程度（轻度/中度/重度）
   - 支持添加更多有雾图

3. **配对校验状态**
   - 显示分辨率一致性校验状态
   - 显示文件格式校验状态

**配对校验规则**

| 校验项 | 规则 | 错误提示 |
|--------|------|---------|
| 清晰图可选 | 数据项可只有清晰图、只有有雾图、或两者都有（适配不同数据集规范） | - |
| 分辨率一致性 | 同一数据项下所有图片分辨率必须完全相同（如上传了清晰图） | "配对图片分辨率不一致，清晰图：1920×1080，有雾图1：1280×720" |
| 文件格式 | 必须为支持的图片格式 | "仅支持 jpg/png/gif 格式" |
| 文件大小 | 单张不超过 10MB | "文件大小不能超过 10MB" |
| 雾霾程度格式 | haze_level 可空；非空时支持多种规范（详见 2.6.2） | "雾霾程度格式无效" |

**说明**：取消"清晰图必填/有雾图必填"的硬性校验，原因是实际数据集规范多样：
- **GT+Hazy 配对型**（如 Dense-Haze、O-HAZE、RESIDE-6k）：清晰图+有雾图配对
- **仅 Hazy 无 GT 型**（如 RESIDE/RTTS 真实雾图测试集）：只有有雾图，无清晰图对照
- **多 Hazy 对一 GT 型**（如 RESIDE/ITS、RESIDE/OTS）：1 张清晰图对应多张不同雾霾程度的有雾图

**配对关系存储**

- 所有配对图片属于同一个数据项（DatasetItem）
- 清晰图类型标记为 `clear`（GT、clean、gt 等命名统一归为 clear）
- 有雾图类型标记为 `hazy`（haze、hazy 等命名统一归为 hazy）
- 透射率图类型标记为 `trans`
- 有雾图的 `haze_level` 字段记录雾霾程度（支持多种规范，详见 2.6.2）
- 通过 `itemId` 关联

#### 2.8.3 批量上传

**支持的批量上传模式**

| 模式 | 说明 |
|------|------|
| 普通批量上传 | 一次选择多张图片上传 |
| 配对批量上传 | 按文件名自动匹配配对 |

**命名规则示例（支持多种数据集规范）**

清晰图识别（文件名含以下关键字之一即识别为 clear）：
- `clear` / `gt` / `GT` / `clean`

有雾图识别（文件名含以下关键字之一即识别为 hazy）：
- `hazy` / `haze` / `Hazy` / `Haze`

透射率图识别：
- `trans` / `Transmission`

**配对分组规则**：按文件名前导数字分组（如 `01_GT.png` 与 `01_hazy.png` 归为 "01" 组），无前导数字时按完整文件名 stem 分组。

**haze_level 自动解析规则**（从有雾图文件名提取，无法解析则为空）：

| 文件名模式 | 解析出的 haze_level | 适用数据集 |
|-----------|---------------------|-----------|
| `xxx_hazy_light.jpg` | `light` | 自定义数据集 |
| `xxx_hazy_medium.jpg` | `medium` | 自定义数据集 |
| `xxx_hazy_heavy.jpg` | `heavy` | 自定义数据集 |
| `1000_1_0.74905.png` | `beta=0.74905` | RESIDE/ITS、RSHAZE（格式：`{id}_{idx}_{beta}`） |
| `0025_0.8_0.2.jpg` | `A=0.8,beta=0.2` | RESIDE/OTS（格式：`{id}_{A}_{beta}`） |
| `1012_0.85_1.28.png` | `beta=0.85,A=1.28` | Haze4K（格式：`{id}_{beta}_{A}`） |
| `01_hazy.png`（无参数后缀） | 空（NULL） | Dense-Haze、O-HAZE 等无参数标注数据集 |

同一前导数字的图片自动归为一个配对组。

**批量上传流程**

1. 用户选择多张图片
2. 系统自动识别配对关系（根据文件名）
3. 显示配对预览列表（每组显示清晰图+多张有雾图）
4. 用户确认或调整配对关系和雾霾程度
5. 批量校验分辨率一致性（同组内所有图片）
6. 开始上传并显示进度
7. 上传完成，显示结果统计

**配对预览列表要求**

需要显示：
- 配对组信息：组名、清晰图、有雾图列表
- 每张有雾图的雾霾程度选择
- 校验状态标识（✓ 或 ⚠）
- 未配对文件列表

#### 2.8.4 图片修改

**可修改内容**

- 图片文件（重新上传时自动重新解析宽高）
- 场景类型
- 雾霾程度
- 图片描述
- 图片类型（清晰图/雾霾图等）

**配对图片修改**

- 修改单张图片时，若为配对图片，显示配对信息（包括同组的其他图片）
- 支持解除配对关系
- 支持重新建立配对关系
- 支持向已有配对组添加新的有雾图
- 支持修改有雾图的雾霾程度

#### 2.8.5 图片删除

- 单张删除
- 批量删除（列表模式下）
- 删除时同时删除缩略图
- 删除配对图片时，提示是否同时删除配对的其他图片

## 3. 用户交互流程

### 3.1 数据集浏览流程

1. 进入数据集管理页面
2. 加载数据集树形结构
3. 显示所有数据集
4. 用户可选择搜索操作
5. 根据关键字过滤数据集
6. 点击数据集查看按钮
7. 跳转到数据集详情页面
8. 加载数据集详细信息
9. 以选定模式展示图片（默认瀑布流）
10. 用户可切换图片类型或筛选
11. 重新加载对应类型图片

### 3.2 图片浏览流程

1. 进入数据集详情页面
2. 选择展示模式（列表/瀑布流/网格）
3. 浏览图片列表
4. 可选择切换类型或搜索
5. 点击图片查看大图
6. 可选择切换配对图片
7. 左右滑动浏览不同数据项
8. 执行操作（下载/编辑/删除）

### 3.3 图片上传流程

1. 进入数据集详情页
2. 点击上传按钮
3. 选择上传模式（单张/配对/批量）
4. 选择图片文件
5. 填写可选信息（场景类型、雾霾程度）
6. 系统自动解析图片宽高
7. 系统校验文件（格式、大小、分辨率一致性）
8. 上传完成
9. 如需修改，点击图片进入详情
10. 修改场景类型、雾霾程度、描述等
11. 保存修改
