# 数据集管理模块需求规格

## 1. 模块概述

### 1.1 模块定位

数据集管理模块是AI图像处理平台的核心数据管理模块，负责管理系统中用于算法训练、测试和演示的各类图像数据集。该模块提供数据集和数据项（图片）的完整生命周期管理，包括创建、浏览、编辑、删除，以及图片的上传、配对、标注等功能。

作为系统核心模块之一，数据集管理模块为【图像输入模块】的样例图片库提供数据源，为【算法管理模块】的算法评估提供测试数据集（接入契约见 §2.11），是整个系统数据资产管理的中枢。

> **任务类型（task_type）维度**：数据集通过 `task_type` 字段按任务类型分类（去雾/去雨/去雪/低光/超分/去噪/修复），为当前必填单选字段，支撑"算法按任务类型路由分发"战略（见 [近期改造计划总览 §3.1 任务类型路由](../../05-改造计划/近期改造计划总览.md)）。

### 1.2 核心价值

| 价值维度 | 具体内容 |
|---------|---------|
| **集中管理** | 统一管理所有图像数据，支持数据集和图片的增删改查 |
| **结构化组织** | 树形结构管理数据集，最多5级深度，支持父子关系 |
| **高效浏览** | 瀑布流/网格/列表多种展示模式，流畅浏览体验 |
| **灵活标注** | 支持用户自定义场景类型，人工标注雾霾程度 |
| **配对管理** | 支持清晰图与多张有雾图的配对关系管理 |
| **快速搜索** | 多维度搜索和筛选，按相关度和时间排序 |
| **使用统计** | 记录用户使用数据集和图片的次数（缓存） |

### 1.3 用户角色分析

| 用户类型 | 特征 | 使用偏好 | 功能需求 |
|---------|------|---------|---------|
| **算法研究员** | 负责数据集维护，熟悉数据组织方法 | 频繁上传/管理数据 | 批量上传+配对管理+标注功能 |
| **系统管理员** | 拥有完整操作权限，管理全局数据 | 权限控制+数据清理 | 全量管理+权限配置+审计 |
| **普通用户** | 使用公开数据集进行测试 | 浏览+选择+使用 | 数据集浏览+图片搜索+下载 |
| **VIP用户** | 更高存储配额和访问权限 | 私有数据集管理 | 私有空间+更大配额+优先处理 |

### 1.4 模块依赖关系

```mermaid

    F[文件管理模块] -->|图片存储| D[数据集管理模块]
    U[用户管理模块] -->|权限| D
    D -->|样例| I[图像输入模块]
    D -->|测试数据| A[算法管理模块]
```

## 2. 功能需求

### 2.1 数据集列表展示 (F-M06-001)

#### 2.1.1 功能描述

以树形结构展示所有数据集列表，支持查看数据集基本信息和统计数据，提供搜索、筛选和排序功能。

#### 2.1.2 数据集分类

数据集通过 `type` 字段标识类别，为自由文本（支持自定义），常见类别如：

| 数据集类型 | 说明 | 典型数量 | 可见性 |
|----------|------|---------|--------|
| **样例数据集** | 系统预置的样例图片，供快速体验 | 40张 | 公开 |
| **测试数据集** | 用于算法测试的标准数据集 | 100张+ | 公开/受限 |
| **用户数据集** | 用户上传的私有图片 | 不限 | 私有 |

> `type` 为自由字符串，无固定枚举约束；数据集的可见性（公开/私有）由权限控制实现（见 §4.2）。

**任务类型（task_type）维度**：数据集按任务类型分类与筛选（见 §1.1），`task_type` 为当前必填单选：

| task_type | 数据集类型示例 |
|-----------|-------------|
| `dehaze` | 去雾数据集（如 RESIDE、Dense-Haze、O-HAZE） |
| `derain` | 去雨数据集（如 Rain100H、Rain1200） |
| `desnow` | 去雪数据集（如 Snow100K） |
| `lowlight` | 低光增强数据集（如 LOL、MIT-Adobe FiveK） |
| `super_resolution` | 超分辨率数据集（如 DIV2K、Set5/Set14） |
| `denoise` | 去噪数据集（如 BSD68、SIDD） |
| `inpaint` | 图像修复数据集（如 Places2、CelebA-HQ） |

#### 2.1.3 列表信息展示

**基本信息**

| 字段 | 说明 | 示例 |
|------|------|------|
| 数据集名称 | 支持树形展示 | "城市建筑" |
| 数据集类型 | 样例/测试/用户/结果 | "测试数据集" |
| 任务类型 | 去雾/去雨/去雪/低光/超分/去噪/修复 | "去雾" |
| 数据集状态 | 启用/禁用（标签形式） | 🟢 启用 |
| 图片数量 | 数据集内图片总数 | 150张 |
| 总大小 | 占用存储空间 | 256MB |
| 创建时间 | YYYY-MM-DD HH:mm | 2025-01-15 10:30 |
| 最后更新时间 | YYYY-MM-DD HH:mm | 2025-01-17 14:20 |

**统计信息（缓存）**

- 场景类型分布（用户自定义场景类型）
- 退化程度分布（按 haze_level 格式统计，含未标注占比）
- 文件格式分布（JPG/PNG/WEBP）
- 使用次数（用户使用该数据集进行图像处理的次数）

#### 2.1.4 树形结构管理

**功能要求**

数据集列表页面需提供：
- 搜索功能：按数据集名称搜索，支持重置
- 筛选功能：按任务类型（task_type）筛选
- 操作功能：新增数据集（权限：sys:dataset:add）
- 展示内容：数据集树、数据集名称、数据集类型、任务类型、数据集状态、图片数量
- 操作按钮：查看、新增下级、编辑、删除（各需对应权限控制）

**树形结构规则**

- 支持最多5级层级深度（根节点分页，子节点懒加载）
- 数据集名称在同一层级下必须唯一
- 支持节点展开/收起
- 支持按名称关键字搜索、按类型/状态筛选
- **任务类型分组**：第一级按任务类型（task_type）分类，第二级起按数据集层级展开，并支持按任务类型搜索过滤（见 §1.1）

### 2.2 数据集增删改查 (F-M06-002)

#### 2.2.1 新增数据集

**表单字段**

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|------|------|------|---------|------|
| 数据集名称 | 输入框 | ✅ | 不能为空，同级唯一 | - |
| 上级数据集 | 树形选择器 | ❌ | - | 为空则为顶级数据集 |
| 任务类型 | 下拉选择 | ✅ | 不能为空 | 去雾/去雨/去雪/低光/超分/去噪/修复 |
| 数据集类型 | 输入框 | ✅ | 不能为空 | - |
| 数据集描述 | 文本域 | ❌ | - | 最多500字 |
| 存储路径 | 输入框 | ✅ | 不能为空 | 系统自动生成或用户指定 |
| 数据集状态 | 单选框 | ✅ | - | 启用(1)/禁用(0)，默认启用 |

**业务流程**

1. 用户触发新增操作
2. 打开数据集表单弹窗
3. 用户填写表单并进行实时验证
4. 系统验证数据合法性
5. 验证通过后保存数据集
6. 刷新数据集树并显示成功提示

#### 2.2.2 编辑数据集

**可修改内容**

- 数据集名称
- 数据集类型
- 数据集描述
- 存储路径
- 数据集状态（启用/禁用）

**业务流程**

1. 用户触发编辑操作
2. 加载并显示数据集详细信息
3. 用户修改表单内容并进行实时验证
4. 系统验证数据合法性
5. 验证通过后更新数据集
6. 刷新数据集树并显示成功提示

#### 2.2.3 删除数据集

**删除规则**

- 支持单个删除和批量删除
- 删除时递归删除所有子数据集
- 删除时同时删除关联的所有图片数据
- 需进行二次确认，明确提示影响范围（子数据集数量、图片数量、占用空间）

**业务流程**

1. 用户触发删除操作
2. 系统弹出确认对话框，显示影响范围
3. 用户确认后执行递归删除
4. 刷新数据集树并显示成功提示

#### 2.2.4 数据集导入导出

数据集导入导出纳入本期需求，支撑数据集跨环境迁移与备份。所有导入导出均经任务管理模块异步执行（避免大文件阻塞请求），任务接口见 [API接口 §2.4](./API接口.md)。

**导出（dataset_export 任务）**

- 入口：数据集详情页"导出数据集"按钮、数据集列表行操作
- 行为：异步生成 ZIP（含数据集元数据 JSON + 图片文件，保留配对关系与 `haze_level` 标注），完成后通过 `/api/v1/tasks/{taskId}/download` 下载
- 任务参数：`{ type: "dataset_export", params: { datasetId, includeChildren: true } }`

**导入（dataset_import 任务）**

- 入口：数据集列表页"导入数据集"按钮
- 行为：上传 ZIP 文件，异步解析元数据与图片，按原结构还原数据集层级与配对关系
- 任务参数：`{ type: "dataset_import", params: { fileUrl, parentId } }`
- 导入图片同样执行 MD5 去重（见 §2.8.1），命中已有文件则跳过存储并记录到导入报告

**导入报告**

任务完成后生成导入报告，包含：成功数、跳过数（含 MD5 命中重复）、失败数及失败原因。

### 2.3 数据集详情展示 (F-M06-003)

#### 2.3.1 功能描述

点击数据集"查看"按钮，进入数据集详情页面，展示数据集详细信息、统计分析和图片列表。

#### 2.3.2 页面内容

**头部信息区域**

展示数据集的基本信息：
- 数据集名称、类型、描述
- 创建时间、创建人
- 图片总数、占用空间、使用次数
- 提供"查看统计分析"功能（场景类型/雾霾程度/文件格式分布）

> 任务类型（task_type）为数据集必填字段，详情头部需展示。

**工具栏区域**

提供以下功能：
- 展示模式切换：列表、纵向瀑布流、横向瀑布流、网格
- 类型筛选：全部、轻度、中度、重度、未标注
- 搜索功能
- 操作按钮：上传图片、批量下载、批量删除

**图片展示区域**

根据选择的展示模式显示图片列表

#### 2.3.3 统计分析弹窗

点击"查看统计分析"按钮，弹出统计分析弹窗：

**统计内容**

| 统计项 | 图表类型 | 说明 |
|--------|---------|------|
| 场景类型分布 | 饼图 | 用户自定义的场景类型占比 |
| 退化程度分布 | 柱状图 | 按 haze_level 格式统计（含未标注） |
| 文件格式分布 | 饼图 | JPG/PNG/WEBP等格式占比 |

**缓存策略**

- 统计信息通过缓存提供，响应时间&lt;200ms
- 缓存失效时间：数据变更时主动失效
- 缓存预热：后台定时更新热门数据集统计

#### 2.3.4 图片访问与静态服务约束

数据集图片为静态文件，**必须通过 nginx-dataset（端口 9000）访问**，禁止经 Java 后端接口代理图片流：

- 后端接口（数据集/数据项/图片）仅返回图片的**相对路径**（如 `/dataset/2025/01/15/xxx.jpg`），不返回图片二进制
- 前端拼接完整访问 URL：`http://{host}:9000{相对路径}`（缩略图同理）
- 图片上传仍走 Java 后端 `/api/v1/item-files` 接口（需鉴权与配额校验、MD5 去重），后端落盘后仅写入相对路径
- 该约束适用于数据集详情、大图查看、缩略图、配对图切换等所有图片展示场景

> nginx-dataset 的部署与配置见 [02-系统架构/06-部署架构.md](../../02-系统架构/06-部署架构.md)。

### 2.4 图片展示模式 (F-M06-004)

#### 2.4.1 功能描述

提供多种图片展示模式，满足不同使用场景的需求：
- **列表模式**：注重数据管理，支持批量操作
- **图片模式**：注重图片预览，提供流畅浏览体验

系统记住用户偏好设置。

#### 2.4.2 列表模式

**功能定位**：注重数据集图片的管理，适合批量操作和详细信息查看

**列表信息展示**

需要显示的信息列：
- 缩略图（小尺寸预览）
- 文件名（可点击查看大图）
- 分辨率（宽×高）
- 文件大小
- 雾霾程度（轻度/中度/重度/未标注）
- 场景类型（用户自定义）
- 图片类型（有雾图/清晰图/去雾图）
- 上传时间
- 操作按钮（下载/编辑/删除）

**批量操作**

- 支持多选（Shift连续选择、Ctrl多选、全选）
- 批量删除：选中后显示删除按钮
- 批量下载：选中后显示下载按钮，打包下载所选图片

**交互要求**

- 点击文件名：打开大图查看
- 点击下载：下载图片（配对图片需弹出选择框）
- 点击编辑：打开图片信息编辑功能
- 点击删除：二次确认后删除

#### 2.4.3 纵向瀑布流模式

**功能定位**：适合浏览不同高度的图片，充分利用垂直空间

**布局要求**

- 竖屏显示：2列
- 横屏显示：3-4列
- 图片保持原始宽高比
- 支持自适应列宽

**图片卡片信息**

- 图片缩略图
- 图片名称（底部悬浮显示）
- 支持点击查看大图

#### 2.4.4 横向瀑布流模式

**功能定位**：适合浏览不同宽度的图片，横向滚动浏览

**布局要求**

- 2-3行展示
- 图片高度固定，宽度按比例自适应

**交互要求**

- 支持横向滚动浏览
- 支持鼠标滚轮横向滚动
- 支持触摸滑动

#### 2.4.5 网格模式

**功能定位**：整齐划一的展示方式，适合快速浏览大量图片

**布局要求**

- 列数自适应（根据容器宽度计算）
- 卡片尺寸固定
- 图片居中裁剪填充

**图片卡片信息**

- 图片缩略图（居中裁剪）
- 底部信息：文件名、雾霾程度标签
- 悬浮显示：分辨率、文件大小

#### 2.4.6 通用加载策略

**分页加载**

- 首屏加载：20张
- 滚动加载：每次20张
- 支持预加载下一屏
- 支持懒加载（可见区域才加载）

**性能优化**

- 虚拟滚动（列表模式）
- 图片懒加载（所有模式）
- 缩略图缓存

### 2.5 大图查看功能 (F-M06-005)

#### 2.5.1 触发方式

- 列表模式：点击文件名
- 图片模式：点击图片

#### 2.5.2 大图信息展示

| 信息项 | 说明 |
|--------|------|
| 图片原图 | 支持缩放、拖动（URL 经 nginx-dataset:9000 静态访问，见 §2.3.4） |
| 文件名 | - |
| 分辨率 | 宽×高 |
| 文件大小 | 格式化显示 |
| 雾霾程度 | 轻度/中度/重度/未标注 |
| 场景类型 | 用户自定义 |
| 上传时间 | YYYY-MM-DD HH:mm |
| 使用次数 | 被用于图像处理的次数 |

#### 2.5.3 基本操作

| 操作 | 说明 |
|------|------|
| 双击放大/缩小 | 切换100%/适应屏幕 |
| 捏合手势缩放 | 移动端支持 |
| 拖动移动 | 放大后移动查看 |
| 旋转图片 | 90度旋转 |

#### 2.5.4 配对图片切换

当前图片如果有配对图像，需提供配对图片切换功能。

**配对结构说明**

- **清晰图像（Ground Truth）**：数据项可有 0 或 1 张清晰图像（部分数据集如 RESIDE/RTTS 无 GT）
- **退化图像**：数据项可有 0 到多张退化图像，每张有不同的退化程度（haze_level 字段，含义与格式见 §2.6.2）
- **透射率图**：部分数据集（如 RESIDE/ITS、Haze4K）还包含透射率图

**切换方式**

支持以下切换方式之一：
- Tab切换：清晰图、退化图（如有多个则按 haze_level 排序显示，如 "退化图(beta=0.5)"、"退化图(beta=0.8)"）
- 下拉选择：列表显示所有配对图片（含 haze_level 标识），选择切换

#### 2.5.5 操作按钮

| 按钮 | 功能 | 说明 |
|------|------|------|
| 下载 | 下载图片 | 配对图片弹出选择框 |
| 编辑 | 编辑图片信息 | 场景类型、雾霾程度、描述 |
| 删除 | 删除图片 | 二次确认 |
| 上一张/下一张 | 切换数据项 | 显示当前位置（如"3/50"） |

#### 2.5.6 下载选项弹窗

当图片有配对时，点击下载按钮需弹出选择弹窗。

**下载选项**

提供以下选项：
- 仅下载当前图片
- 仅下载清晰图
- 下载所有退化图（打包下载）
- 下载全部图片（打包下载）

**特殊情况**

- 无配对图片时直接下载，不弹窗
- 选择打包下载时生成 ZIP 文件下载

### 2.6 图片类型切换与筛选 (F-M06-006)

#### 2.6.1 功能描述

支持按图片类型快速切换显示内容，多维度筛选图片。

#### 2.6.2 类型分类

**按退化程度分类（多规范支持）**

退化程度按 task_type 区分含义（如去雾为雾霾程度、去雨为雨纹密度），不同数据集采用不同的标注规范，系统统一支持以下几种格式（存储于 `haze_level` 字段，类型为 varchar(32)，可空）：

| 规范类型 | haze_level 取值 | 适用数据集示例 | 说明 |
|---------|----------------|---------------|------|
| 人工三级分级 | `light` / `medium` / `heavy` | 自定义数据集 | 由人工标注的轻度/中度/重度 |
| β 参数单值 | `beta=0.5` | RESIDE/ITS、RSHAZE | 学术界大气散射模型中的散射系数 β |
| A+β 双参数 | `A=0.8,beta=0.2` | RESIDE/OTS | 大气光 A 与散射系数 β 组合 |
| A+β 反序 | `beta=0.85,A=1.28` | Haze4K | β 在前、A 在后的变体格式 |

| 清晰图 | 空（NULL） | 所有 GT/clear 子目录 | 清晰图本身无雾霾程度概念 |

**Tab 切换展示**：当数据集存在多种 haze_level 格式时，Tab 切换按"是否为空"二分（已标注退化程度/未标注），不按具体值枚举，避免 Tab 数量爆炸。

### 2.8 图片上传功能 (F-M06-008)

#### 2.8.1 单张图片上传

**上传方式**

- 点击上传
- 拖拽上传

**上传时自动处理**

- 自动解析图片宽高并存储
- 自动生成缩略图
- 自动计算文件 MD5 指纹（存入 `file_md5` 字段）

**MD5 去重策略**

上传时基于 MD5 拦截重复文件，避免同一文件重复存储：

1. 后端接收图片后先计算 MD5
2. 查询当前数据集下是否已存在相同 `file_md5` 的图片
3. **命中重复**：跳过文件落盘（不重复存储），返回提示"文件已存在（MD5 命中），已跳过重复上传"，并返回已存在图片的引用信息
4. **未命中**：正常落盘并建立数据项关联

去重范围：默认按**当前数据集**去重（同一数据集内不允许 MD5 重复）；跨数据集允许相同文件存在（不同数据集可复用同一图片）。

> 配对上传（§2.8.2）与批量上传（§2.8.3）同样适用此去重策略，命中重复的图片在配对预览列表中标记"已跳过（MD5 重复）"。

**上传时可选编辑**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 场景类型 | 输入框 | ❌ | 用户自定义，系统记录用于搜索建议 |
| 退化程度 | 下拉选择 | ❌ | light/medium/heavy |
| 图片描述 | 文本框 | ❌ | 自由文本输入 |
| 图片类型 | 下拉选择 | ❌ | 退化图/清晰图 |

#### 2.8.2 配对图片上传（Image Pair）

**功能描述**

支持同时上传配对的退化图像和清晰图像，系统自动校验并建立配对关系。

**配对结构说明**

- **清晰图像（Ground Truth）**：每个数据项只有一张清晰图像
- **退化图像**：每个数据项可以有多张退化图像，每张有不同的退化程度
- 所有配对图片必须分辨率一致

**上传界面**

配对图片上传功能需提供：

1. **清晰图像区域**（必须上传一张）
   - 上传清晰图像（Ground Truth）
   - 显示上传预览

2. **退化图像区域**（至少上传一张）
   - 支持上传多张退化图像
   - 每张退化图可单独设置退化程度
   - 支持添加更多退化图

3. **配对校验状态**
   - 显示分辨率一致性校验状态
   - 显示文件格式校验状态

**配对校验规则**

| 校验项 | 规则 | 错误提示 |
|--------|------|---------|
| 清晰图可选 | 数据项可只有清晰图、只有退化图、或两者都有（适配不同数据集规范） | - |
| 分辨率一致性 | 同一数据项下所有图片分辨率必须完全相同（如上传了清晰图） | "配对图片分辨率不一致，清晰图：1920×1080，退化图1：1280×720" |
| 文件格式 | 必须为支持的图片格式 | "仅支持 jpg/png/gif 格式" |
| 文件大小 | 单张不超过 10MB | "文件大小不能超过 10MB" |
| 退化程度格式 | haze_level 可空；非空时支持多种规范（详见 2.6.2） | "退化程度格式无效" |

**说明**：清晰图/退化图为可选字段，数据项可只有清晰图、只有退化图、或两者都有，以适配不同的数据集规范：
- **GT+退化图配对型**（如 Dense-Haze、O-HAZE、RESIDE-6k）：清晰图+退化图配对
- **仅退化图无 GT 型**（如 RESIDE/RTTS 真实雾图测试集）：只有退化图，无清晰图对照
- **多退化图对一 GT 型**（如 RESIDE/ITS、RESIDE/OTS）：1 张清晰图对应多张不同退化程度的退化图

**配对关系存储**

- 所有配对图片属于同一个数据项（DatasetItem）
- 清晰图类型标记为 `clear`（GT、clean、gt 等命名统一归为 clear）
- 退化图类型标记为 `hazy`（haze、hazy 等命名统一归为 hazy）
- 透射率图类型标记为 `trans`
- 退化图的 `haze_level` 字段记录退化程度（支持多种规范）
- 通过 `itemId` 关联

#### 2.8.3 批量上传

**支持的批量上传模式**

| 模式 | 说明 |
|------|------|
| 普通批量上传 | 一次选择多张图片上传 |
| 配对批量上传 | 按文件名自动匹配配对 |

**命名规则示例（支持多种数据集规范）**

清晰图识别（文件名含以下关键字之一即识别为 clear）：
- `clear` / `gt` / `GT` / `clean`

退化图识别（文件名含以下关键字之一即识别为 hazy）：
- `hazy` / `haze` / `Hazy` / `Haze` / `rainy` / `rain` / `low` / `dark` / `noisy`

透射率图识别：
- `trans` / `Transmission`

**配对分组规则**：按文件名前导数字分组（如 `01_GT.png` 与 `01_hazy.png` 归为 "01" 组），无前导数字时按完整文件名 stem 分组。

**haze_level 自动解析规则**（从有雾图文件名提取，无法解析则为空）：

| 文件名模式 | 解析出的 haze_level | 适用数据集 |
|-----------|---------------------|-----------|
| `xxx_hazy_light.jpg` | `light` | 自定义数据集 |
| `xxx_hazy_medium.jpg` | `medium` | 自定义数据集 |
| `xxx_hazy_heavy.jpg` | `heavy` | 自定义数据集 |
| `1000_1_0.74905.png` | `beta=0.74905` | RESIDE/ITS、RSHAZE（格式：`{id}_{idx}_{beta}`） |
| `0025_0.8_0.2.jpg` | `A=0.8,beta=0.2` | RESIDE/OTS（格式：`{id}_{A}_{beta}`） |
| `1012_0.85_1.28.png` | `beta=0.85,A=1.28` | Haze4K（格式：`{id}_{beta}_{A}`） |
| `01_hazy.png`（无参数后缀） | 空（NULL） | Dense-Haze、O-HAZE 等无参数标注数据集 |

同一前导数字的图片自动归为一个配对组。

**批量上传流程**

1. 用户选择多张图片
2. 系统自动识别配对关系（根据文件名）
3. 显示配对预览列表（每组显示清晰图+多张退化图）
4. 用户确认或调整配对关系和退化程度
5. 批量校验分辨率一致性（同组内所有图片）
6. 开始上传并显示进度
7. 上传完成，显示结果统计

**配对预览列表要求**

需要显示：
- 配对组信息：组名、清晰图、退化图列表
- 每张退化图的退化程度选择
- 校验状态标识（✓ 或 ⚠）
- 未配对文件列表

#### 2.8.4 图片修改

**可修改内容**

- 场景类型
- 退化程度（haze_level）
- 图片描述
- 图片类型（清晰图/退化图等）

> **不支持修改图片文件本身**——如需更换图片请删除后重新上传（系统会自动重新解析宽高、生成缩略图）。

**配对图片修改**

- 修改单张图片时，若为配对图片，显示配对信息（包括同组的其他图片）
- 支持修改退化图的退化程度
- 支持向已有配对组添加新的退化图（通过数据项图片上传接口）
- 删除配对图片时不影响其他配对图片

#### 2.8.5 图片删除

- 单张删除（同时删除缩略图文件）
- 批量删除（列表模式下，单次最多 100 张）
- 删除配对图片中的一张，不影响其他配对图片
- 删除数据项时级联删除其下所有图片与缩略图

### 2.11 算法评估数据集接入 (F-M06-011)

#### 2.11.1 功能描述

数据集管理模块为【算法管理模块】的效果评估（F-M05-010）提供测试数据集来源，支持从数据集选择测试集批量发起评估，替代用户手动上传预测图/参考图的方式，建立数据集与算法评估的关联。

#### 2.11.2 接入契约

| 项 | 说明 |
|---|------|
| 评估发起方 | 算法管理模块（效果评估入口） |
| 数据来源方 | 数据集管理模块（提供测试集查询与图片引用） |
| 图片访问 | 经 nginx-dataset:9000 静态访问（见 §2.3.4），评估服务通过相对路径拉取图片 |
| 关联粒度 | 数据集 → 数据项 → 图片（参考图取自数据项清晰图 GT，预测图取自算法处理结果） |
| 任务类型对齐 | 数据集 `task_type` 与算法 `task_type` 取值对齐，按任务类型过滤可选测试集 |

#### 2.11.3 测试集选项接口

数据集模块提供"测试集选项"查询能力，供算法评估入口选择测试集：

- 路径：`/api/v1/datasets/evaluation-options`（详见 [API接口.md](./API接口.md)）
- 查询参数：`taskType`（按任务类型过滤，与算法 `task_type` 对齐）
- 返回：数据集列表（`datasetId`、`datasetName`、`taskType`、`itemCount`），仅返回含清晰图 GT 的数据集

#### 2.11.4 批量评估流程

```mermaid
graph TD
    A[算法评估入口选择算法] --> B[选择测试数据集]
    B --> C[调用数据集测试集选项接口]
    C --> D[按 taskType 过滤返回数据集列表]
    D --> E[用户选择数据集]
    E --> F[遍历数据项: 预测图=算法处理结果, 参考图=数据项清晰图GT]
    F --> G[批量调用算法评估接口]
    G --> H[聚合评估结果: PSNR/SSIM/LPIPS均值]
    H --> I[展示评估报告]
```

#### 2.11.5 数据映射规则

| 评估角色 | 数据集来源 | 说明 |
|---------|-----------|------|
| 参考图（Reference） | 数据项的清晰图（`type=clear`） | 数据项必须含清晰图 GT 才能参与有参考评估 |
| 预测图（Predicted） | 算法对数据项退化图的处理结果 | 由算法管理模块调用图像处理生成 |

> 无清晰图 GT 的数据项（如 RESIDE/RTTS 真实雾图测试集）不参与有参考评估（PSNR/SSIM），仅可参与无参考评估（NIQE/Entropy）。
