## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **数据集数据** | 至少5级树形结构数据集 | 用于树形结构、层级深度测试 |
| **用户数据** | 不同角色的用户账户（管理员、普通用户） | 用于权限验证测试 |
| **测试图片文件** | 不同格式（jpg/png/gif）、不同大小（&lt;10MB、>10MB）、不同分辨率 | 用于上传功能测试 |
| **配对图片** | 清晰图+多张有雾图（轻度/中度/重度），分辨率一致 | 用于配对上传测试 |
| **导出任务** | 不同状态的导出任务数据 | 用于任务生命周期测试 |

### 3.2 数据清理策略

- 测试数据集数据使用统一前缀 `test_ds_` 标识
- 测试结束后按前缀批量删除测试数据集
- 保留系统默认数据集（如样例数据集）不做删除操作
- 测试后清理导出任务数据
- 删除测试上传的物理文件

### 3.3 测试范围

**包含的功能点：**
- 数据集列表展示（树形结构、搜索、筛选）
- 数据集CRUD操作（新增、编辑、删除）
- 数据集详情展示（统计分析）
- 数据项管理（查询、新增、编辑、删除）
- 图片上传（单张、配对、批量）
- 图片文件管理（编辑、删除、下载）
- 导出任务管理（创建、进度查询、下载、取消）
- 缓存机制验证

**不包含的功能点：**
- 文件存储服务（MinIO）独立测试
- 用户认证与授权（系统架构层测试）
- 图片去雾处理算法（算法管理模块测试）
