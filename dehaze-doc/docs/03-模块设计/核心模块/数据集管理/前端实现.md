# 数据集管理模块 - 前端实现设计

## 1. 文档概述

本文档描述数据集管理模块的前端架构决策，仅包含前端特有的组件结构、状态管理、数据流与关键技术选型。业务功能、字段定义、校验规则、交互行为详见 [需求规格.md](./需求规格.md)；接口契约详见 [API接口.md](./API接口.md)。本文档适用于 Vue3 与 React 两端，两端通过 Composable / Custom Hooks 复用核心逻辑。

## 2. 组件架构设计

### 2.1 页面组件层次

```
数据集管理
├── DatasetList（数据集列表页）
│   ├── SearchForm（搜索区：名称搜索 + task_type 筛选）
│   └── DatasetTree（树形表格，第一级按 task_type 分组）
└── DatasetDetail（数据集详情页）
    ├── DatasetHeader（基本信息 + 统计摘要入口）
    ├── ImageToolbar（模式切换 + 类型筛选 Tab + 搜索 + 操作按钮）
    └── ImageBrowser（图片展示容器）
        ├── ImageListView（列表模式，支持批量选择）
        ├── VerticalWaterfall（纵向瀑布流）
        ├── HorizontalWaterfall（横向瀑布流）
        └── ImageGridView（网格模式）
```

### 2.2 弹窗与抽屉组件

| 组件 | 职责 |
|------|------|
| DatasetFormDialog | 数据集新增/编辑表单（含 task_type 必填） |
| ImagePreviewModal | 大图查看、配对切换、信息面板、导航底栏 |
| SingleUploadDialog | 单张图片上传 |
| PairedUploadDialog | 配对上传（清晰图 + 多张退化图，均非必填） |
| BatchUploadDialog | 批量上传（按文件名自动配对） |
| AnnotationDialog | 图片标注编辑（场景类型、haze_level、描述、图片类型） |
| StatisticsDialog | 统计图表展示（场景类型/退化程度/文件格式分布） |
| TaskCenterDrawer | 异步任务（导出/导入）状态集中管理 |

### 2.3 组件复用性

| 组件 | 复用范围 |
|------|---------|
| DatasetTree | 数据集选择器、算法评估测试集选择 |
| ImageBrowser | 其他图片浏览场景 |
| ImagePreviewModal | 算法结果对比等场景 |
| DisplayModeSwitch | 其他图片浏览场景 |

## 3. 状态管理设计

### 3.1 Store 模块划分

| Store | 职责 |
|------|------|
| datasetStore | 数据集树、查询参数、当前详情 |
| datasetItemStore | 数据项分页列表、查询参数、选中状态、展示模式偏好、当前查看图片 |
| taskStore | 异步任务（导出/导入）状态与轮询 |

### 3.2 核心状态与操作

**datasetStore**

| 类别 | 内容 |
|------|------|
| 状态 | 数据集树、查询参数（keyword、task_type、status）、当前详情 |
| 操作 | fetchDatasetTree、getDatasetDetail、createDataset、updateDataset、deleteDataset、batchDelete |

**datasetItemStore**

| 类别 | 内容 |
|------|------|
| 状态 | 数据项分页列表、查询参数（含 haze_level 关键字、图片类型 Tab）、选中集合、展示模式、无限滚动游标 |
| 操作 | fetchItems、loadMore、createItemWithImages、batchCreateItems、deleteItem、batchDeleteItems、setDisplayMode、selectItem、selectAll、clearSelection |

**taskStore**

| 类别 | 内容 |
|------|------|
| 状态 | 任务列表、当前轮询任务 ID 集合 |
| 操作 | createTask（统一入口，type 区分 dataset_export / dataset_import）、fetchTaskStatus、cancelTask、pollTaskProgress |

## 4. 关键架构决策

### 4.1 task_type 分组与筛选

依据 [需求规格 §1.1 / §2.1.4](./需求规格.md)，task_type 为数据集必填维度，前端在列表、表单、详情均需体现：

| 场景 | 实现决策 |
|------|---------|
| 树形表格第一级 | 按 task_type 分组展示（去雾/去雨/去雪/低光/超分/去噪/修复），第二级起按数据集层级展开 |
| 搜索区 | 提供 task_type 下拉筛选，与名称搜索并列 |
| 表单弹窗 | task_type 为必填下拉选择，取值与算法管理模块对齐 |
| 详情头部 | 展示 task_type 标签 |

### 4.2 图片 URL 拼接（nginx-dataset 静态服务）

依据 [需求规格 §2.3.4](./需求规格.md)，图片为静态文件，必须经 nginx-dataset（端口 9000）访问，禁止经 Java 后端代理图片流：

| 项 | 决策 |
|---|------|
| 后端返回 | 仅图片相对路径（如 `/dataset/2025/01/15/xxx.jpg`） |
| 前端拼接 | `http://{host}:9000{相对路径}`，缩略图同理 |
| 上传通道 | 仍走 Java 后端 `/api/v1/item-files`（需鉴权、配额校验、MD5 去重） |
| 适用范围 | 数据集详情、大图查看、缩略图、配对图切换等所有图片展示场景 |

> nginx-dataset 部署配置见 [02-系统架构/06-部署架构.md](../../../02-系统架构/06-部署架构.md)。

### 4.3 图片类型与 haze_level 多规范支持

依据 [需求规格 §2.6.2 / §2.8.2](./需求规格.md)，图片类型与退化程度需支持多规范。

**图片类型**（`type` 字段）

| 类型 | 标识 | 说明 |
|------|------|------|
| 退化图 | `hazy` | 按 task_type 区分含义（有雾图/有雨图/暗光图等） |
| 清晰图 | `clear` | GT/clean/gt 命名统一归为此类 |
| 透射率图 | `trans` | 部分数据集（如 RESIDE/ITS、Haze4K）包含 |
| 处理结果图 | `dehazed` | 算法处理结果 |

**haze_level 多规范**

| 规范类型 | 取值示例 | 适用数据集 |
|---------|---------|-----------|
| 人工三级分级 | `light` / `medium` / `heavy` | 自定义数据集 |
| β 参数单值 | `beta=0.5` | RESIDE/ITS、RSHAZE |
| A+β 双参数 | `A=0.8,beta=0.2` | RESIDE/OTS |
| A+β 反序 | `beta=0.85,A=1.28` | Haze4K |
| 真实图无标注 | 空（NULL） | RESIDE/RTTS 等 |

**Tab 切换决策**：因 haze_level 支持多种规范，类型筛选 Tab 按"是否标注"二分（全部 / 已标注 / 未标注），不按具体值枚举，避免 Tab 数量爆炸；另提供 haze_level 关键字模糊搜索（如输入 `beta=0.5` 筛选所有 β=0.5 的图片）。

### 4.4 配对上传校验（取消必填硬性校验）

依据 [需求规格 §2.8.2](./需求规格.md)，配对上传取消"清晰图必填/退化图必填"硬性校验，适配多种数据集规范：

| 数据集规范 | 配对结构 |
|-----------|---------|
| GT + 退化图配对型（Dense-Haze、O-HAZE、RESIDE-6k） | 清晰图 + 退化图 |
| 仅退化图无 GT 型（RESIDE/RTTS 真实雾图） | 仅退化图 |
| 多退化图对一 GT 型（RESIDE/ITS、RESIDE/OTS） | 1 清晰图 + 多退化图 |

配对上传弹窗允许单图上传（仅清晰图、仅退化图、或两者都有），仅保留分辨率一致性、文件格式、文件大小校验；退化图 haze_level 可空，非空时支持多种规范（见 §4.3）。

### 4.5 批量上传命名规则

依据 [需求规格 §2.8.3](./需求规格.md)，批量上传按文件名自动识别图片类型与配对关系。

**类型识别关键字**

| 图片类型 | 命名关键字 |
|---------|-----------|
| 清晰图（clear） | `clear` / `gt` / `GT` / `clean` |
| 退化图（hazy） | `hazy` / `haze` / `Hazy` / `Haze` / `rainy` / `rain` / `low` / `dark` / `noisy` |
| 透射率图（trans） | `trans` / `Transmission` |

**配对分组**：按文件名前导数字分组（如 `01_GT.png` 与 `01_hazy.png` 归为 "01" 组），无前导数字时按完整文件名 stem 分组。

**haze_level 自动解析**（从退化图文件名提取，无法解析则为空）

| 文件名模式 | 解析结果 | 适用数据集 |
|-----------|---------|-----------|
| `xxx_hazy_light.jpg` | `light` | 自定义 |
| `xxx_hazy_medium.jpg` | `medium` | 自定义 |
| `xxx_hazy_heavy.jpg` | `heavy` | 自定义 |
| `1000_1_0.74905.png` | `beta=0.74905` | RESIDE/ITS、RSHAZE |
| `0025_0.8_0.2.jpg` | `A=0.8,beta=0.2` | RESIDE/OTS |
| `1012_0.85_1.28.png` | `beta=0.85,A=1.28` | Haze4K |
| `01_hazy.png`（无参数后缀） | 空（NULL） | Dense-Haze、O-HAZE |

### 4.6 导入导出任务统一走 TaskAPI

依据 [API接口 §2.4](./API接口.md) 与 [需求规格 §2.2.4](./需求规格.md)，数据集导出/导入统一经任务管理模块 `/api/v1/tasks` 异步执行，前端不挂在 DatasetAPI 上：

| 任务类型 | type 值 | 入口 | 任务参数 |
|---------|---------|------|---------|
| 数据集导出 | `dataset_export` | 详情页"导出数据集"按钮、列表行操作 | `{ datasetId, includeChildren: true }` |
| 数据集导入 | `dataset_import` | 列表页"导入数据集"按钮 | `{ fileUrl, parentId }` |

**前端流程**：创建任务 → 加入 TaskCenterDrawer → 轮询状态 → 完成后经 `/api/v1/tasks/{taskId}/download` 下载（导出）或刷新数据集树（导入）；导入完成后展示导入报告（成功数、跳过数含 MD5 命中重复、失败数及失败原因）。

> 单张/批量图片打包下载**尚未实现**（见 [API接口 §2.4](./API接口.md)），前端不擅自定义下载接口；单张图片下载经文件管理模块 `/api/v1/files/download/**` 直接获取。

## 5. 数据流设计

### 5.1 数据获取策略

| 场景 | 策略 |
|------|------|
| 数据集树 | 根节点分页加载，子节点懒加载（展开时请求） |
| 数据项列表 | 无限滚动，每页 20 条，支持预加载下一屏 |
| 统计信息 | 随详情接口返回（后端缓存 <200ms），数据变更后主动失效 |
| 展示模式偏好 | localStorage 持久化 |

### 5.2 请求优化

| 优化项 | 决策 |
|--------|------|
| 搜索防抖 | 300ms |
| 滚动节流 | 200ms |
| 请求取消 | 切换数据集时取消未完成请求 |
| 虚拟滚动 | 列表模式启用 |
| 图片懒加载 | 所有模式启用，仅加载可视区域 |

## 6. 多框架复用设计

Vue 与 React 两端通过 Composable / Custom Hooks 封装复用核心逻辑：

| Hook | 职责 |
|------|------|
| useImageSearch | 图片搜索、筛选、haze_level 关键字匹配 |
| useInfiniteScroll | 无限滚动加载、虚拟滚动 |
| useImageUpload | 单张/配对/批量上传、文件名解析、配对校验 |
| useDisplayMode | 展示模式切换与偏好持久化 |
| useDatasetImage | 图片 URL 拼接（nginx-dataset:9000） |
| useTaskPolling | 异步任务状态轮询 |
