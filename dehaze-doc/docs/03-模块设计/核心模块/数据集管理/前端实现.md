# 数据集管理模块 - 前端实现设计

## 1. 文档概述

本文档描述数据集管理模块的前端实现方案，包括组件设计、状态管理、API调用、交互流程等实现细节，为前端开发提供指导。本文档适用于 Vue3 和 React 两个前端项目。

## 2. 组件架构设计

### 2.1 页面组件层次结构

```
数据集管理模块
├── 数据集列表页面 (DatasetList)

│   │   │   ├── 名称搜索框
```

## 3. 页面布局设计

### 3.1 数据集列表页面布局

采用**全宽单栏布局**：

| 区域 | 高度 | 说明 |
|------|------|------|
| **搜索区域** | 自适应 | 搜索表单 + 操作按钮 |
| **表格区域** | 自适应填充 | 数据集树形表格 |

### 3.2 数据集详情页面布局

采用**上下分栏布局**：

| 区域 | 高度 | 说明 |
|------|------|------|
| **头部信息** | 约 120px | 数据集信息 + 统计摘要 |
| **工具栏** | 约 50px | 模式切换 + 筛选 + 搜索 + 操作 |
| **图片区域** | 自适应填充 | 根据模式展示图片 |

### 3.3 响应式布局

| 屏幕尺寸 | 布局调整 |
|---------|---------|
| **≥1200px** | 完整布局，瀑布流3-4列 |
| **992px~1199px** | 完整布局，瀑布流2-3列 |
| **&lt;992px** | 工具栏折叠，瀑布流2列，部分按钮收入下拉菜单 |

| 参数 | 竖屏 | 横屏 |

#### 4.4.3 横向瀑布流 (HorizontalWaterfall)

**布局参数**

- 行数：2-3行
- 间距：8px

- 图片宽度：按比例自适应

**交互设计**

- 横向滚动浏览
- 支持鼠标滚轮横向滚动
- 支持触摸滑动

#### 4.4.4 网格模式 (ImageGridView)

**布局参数**

- 列数：自适应（根据容器宽度）
- 卡片尺寸：200×200px
- 间距：8px
- 图片填充：居中裁剪（object-fit: cover）

**卡片信息**

- 图片缩略图（居中裁剪）

| 文件格式 | jpg/png/gif | "仅支持 jpg/png/gif 格式" |
| 文件大小 | 单张≤10MB | "文件大小不能超过 10MB" |
| 雾霾程度 | 必须选择 | "请为有雾图选择雾霾程度" |

## 7. 交互流程设计

### 7.1 数据集列表页面初始化

1. 进入页面
2. 显示加载状态
3. 调用 DatasetAPI.getList() 获取数据集树
4. 渲染树形表格
5. 隐藏加载状态

### 7.2 数据集详情页面初始化

1. 从路由获取数据集 ID
2. 显示加载状态
3. 并行请求：
   - DatasetAPI.getDetail(id) 获取数据集详情
   - DatasetItemAPI.getPage({ datasetId, pageNum: 1, pageSize: 20 })
4. 渲染头部信息和图片列表
5. 从 localStorage 读取用户展示模式偏好
6. 隐藏加载状态

### 7.3 新增数据集流程

1. 点击新增按钮
2. 打开数据集表单弹窗
3. 用户填写表单
4. 实时表单校验
5. 点击确定按钮
6. 显示提交加载状态
7. 调用 DatasetAPI.add()
8. 成功：关闭弹窗 → 显示成功提示 → 刷新列表
9. 失败：显示错误提示 → 保持弹窗

### 7.4 删除数据集流程

1. 点击删除按钮
2. 弹出确认对话框
   - 提示信息："确定要删除数据集「{name}」吗？"
   - 警告信息："此操作将同时删除该数据集下的所有子数据集和图片数据，且不可恢复！"
   - 显示影响范围：子数据集数量、图片数量
3. 用户确认删除
4. 显示加载状态
5. 调用 DatasetAPI.delete()
6. 成功：显示成功提示 → 刷新列表
7. 失败：显示错误提示

### 7.5 图片浏览流程

1. 进入数据集详情页面
2. 选择展示模式（默认从 localStorage 读取）
3. 浏览图片列表
4. 切换类型/筛选（可选）
5. 点击图片打开大图
6. 切换配对图片（可选）
7. 左右滑动/键盘浏览不同数据项
8. 执行操作（下载/编辑/删除）

### 7.6 配对图片上传流程

1. 点击上传按钮
2. 选择上传模式（单张/配对/批量）
3. 选择"配对上传"
4. 打开配对上传弹窗
5. 上传清晰图
6. 上传有雾图（支持多张）
7. 为每张有雾图选择雾霾程度
8. 系统自动校验分辨率一致性
9. 校验通过 → 点击确认上传
10. 显示上传进度
11. 上传完成 → 关闭弹窗 → 刷新列表

### 7.7 批量上传流程

1. 点击上传按钮 → 选择"批量上传"
2. 选择多张图片文件
3. 系统根据文件名自动识别配对关系
4. 显示配对预览列表
5. 用户确认/调整配对关系
6. 批量校验分辨率
7. 开始上传（显示总体进度 + 单个进度）
8. 上传完成，显示结果统计
9. 关闭弹窗 → 刷新列表

### 7.8 图片下载流程

**单张图片无配对**：点击下载 → 直接下载图片

**单张图片有配对**

1. 点击下载按钮
2. 弹出下载选项对话框
   - 仅下载当前图片
   - 仅下载清晰图
   - 下载所有有雾图（打包）
   - 下载全部图片（打包）
3. 用户选择
4. 执行下载

**数据集导出**

1. 点击数据集导出按钮
2. 弹出导出选项对话框
   - 文件组织方式：按数据项分目录 / 扁平结构
   - 包含类型：清晰图 / 有雾图
   - 是否包含缩略图
3. 确认创建导出任务
4. 任务加入任务中心
5. 轮询任务状态
6. 完成后通知用户下载

### 7.9 无限滚动加载流程

1. 监听滚动事件
2. 检测是否接近底部（距离底部 200px）
3. 检查是否还有更多数据
4. 触发加载更多
5. 显示加载指示器
6. 调用 API 获取下一页
7. 追加数据到列表
8. 更新加载状态

## 8. 表单校验设计

### 8.1 数据集表单校验规则

| 字段 | 校验规则 | 触发时机 | 错误提示 |
|------|---------|---------|---------|
| name | 必填 | blur | 数据集名称不能为空 |
| name | 同级唯一 | blur | 同级已存在相同名称的数据集 |
| type | 必填 | blur | 数据集类型不能为空 |
| path | 必填 | blur | 存储路径不能为空 |
| description | 最大长度 | change | 描述不能超过500字 |

### 8.2 图片上传校验规则

| 校验项 | 规则 | 错误提示 |
|--------|------|---------|
| 文件格式 | jpg/jpeg/png/gif | 仅支持 jpg/png/gif 格式 |
| 文件大小 | 单张≤10MB | 文件大小不能超过 10MB |
| 清晰图必填 | 配对上传时必须 | 请上传清晰图像 |
| 有雾图必填 | 配对上传时至少一张 | 请至少上传一张有雾图像 |
| 分辨率一致 | 配对图片相同 | 配对图片分辨率不一致 |
| 雾霾程度 | 有雾图必选 | 请为有雾图选择雾霾程度 |

### 8.3 标注表单校验规则

| 字段 | 校验规则 | 触发时机 | 错误提示 |
|------|---------|---------|---------|
| sceneType | 最大长度 | change | 场景类型不能超过50字 |
| description | 最大长度 | change | 描述不能超过500字 |

## 10. 性能优化设计

### 10.1 图片加载优化

| 优化项 | 实现方式 |
|--------|---------|
| 懒加载 | 仅加载可视区域内图片 |
| 缩略图 | 列表/瀑布流使用缩略图 |
| 渐进加载 | 先显示低质量图，再加载高质量 |
| 预加载 | 预加载相邻图片 |

### 10.2 列表优化

| 优化项 | 实现方式 |
|--------|---------|
| 虚拟滚动 | 列表模式使用虚拟列表 |
| 分页加载 | 每次加载20条 |
| 无限滚动 | 滚动到底部自动加载 |
| 骨架屏 | 加载时显示骨架屏 |

### 10.3 请求优化

| 优化项 | 实现方式 |
|--------|---------|
| 防抖处理 | 搜索输入防抖 300ms |
| 节流处理 | 滚动加载节流 200ms |
| 请求取消 | 切换数据集时取消未完成请求 |
| 数据缓存 | 数据集详情短期缓存 |

### 10.4 缓存策略

| 数据类型 | 缓存位置 | 过期策略 |
|---------|---------|---------|
| 数据集树 | Store | 页面卸载时清除 |
| 数据集详情 | Store | 5分钟过期 |
| 展示模式偏好 | localStorage | 长期保存 |
| 统计信息 | Store | 5分钟过期 |
