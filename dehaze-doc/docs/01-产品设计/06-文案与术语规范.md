# 文案与术语规范

> 本规范定义产品的**统一术语**与**统一文案风格**，作为全部前端产品文案（Web / 移动端 / 桌面端）的单一信息源。目标：术语口径唯一、文案风格一致，从源头消除"同一事物多种叫法、同一动作多种说法"造成的混乱。

## 1. 定位与适用范围

- **术语表（第 2 节）**：产品名词的权威定义，模块文档与代码引用此处，**禁止复制定义造成漂移**。
- **文案规范（第 3-5 节）**：按钮、提示、空状态、错误、表单等各类文案的写法模板与语言规则。
- 适用于：全端界面文案、错误提示、空状态、通知文案、运营文案中的产品术语。

## 2. 产品术语表（单一信息源）

### 2.2 任务类型与状态术语

| 枚举值 | 规范术语 | 禁用叫法 | 说明 |
|--------|---------|---------|------|
| DEHAZE | 去雾处理 | 图像去雾（单任务展示可用） | 单图去雾任务类型 |
| BATCH_DEHAZE | 批量处理 | 批量去雾 | 多图批量任务类型 |
| EVALUATION | 指标评估 | 算法评测 | 算法质量评估任务类型 |
| 1 | 待执行 | 排队中、未开始 | 任务状态 |
| 2 | 执行中 | 处理中（进度展示可用） | 任务状态 |
| 3 | 已完成 | 完成、成功 | 任务状态 |
| 4 | 失败 | 出错 | 任务状态 |
| 5 | 已取消 | 取消 | 任务状态 |

> 任务类型/状态枚举在前后端、多端展示统一使用本表术语（如任务列表、工作台、处理历史）。

### 2.3 术语使用规则

1. **全端一致**：同一术语在所有端（Web/移动/桌面）的导航、标题、按钮中保持一致，禁止一端叫"A"另一端叫"B"。
2. **禁用别名**：表格中"禁用/易混叫法"不得作为正式界面文案；仅在口语化运营场景可酌情使用。
3. **新增术语**：新增功能/页面必须先在本表登记，再进入代码与文档；未登记不投产。
4. **名词与动词分离**："去雾"作动词（开始去雾）、"去雾处理"作功能名词；"上传"作动词（上传图片）、"图像输入"作功能名词。
5. **阶段演进**：产品名若调整为「图像增强系统」，须全局统一替换并同步本表，禁止新旧并存。

## 3. 文案风格总则

| 原则 | 说明 | 示例 |
|------|------|------|
| 动词开头 | 操作按钮用动词 + 对象，直达动作 | 开始去雾、保存设置、删除图片 |
| 简洁直接 | 避免"请""您好"等客套堆砌；必要时保留"请"用于权限类提示 | 请登录后继续 |
| 一致性 | 同一动作全端同一文案，禁止同义替换 | 全端统一"保存"而非此处"存储"彼处"存档" |
| 结果导向 | 提示语说明结果/影响，而非过程 | 删除后不可恢复（而非"正在删除…"） |
| 解决方案 | 错误提示给出原因 + 可执行动作 | 网络异常，请检查网络后重试 |

## 4. 分类文案模板

### 4.1 按钮

| 类型 | 模板 | 示例 |
|------|------|------|
| 主操作 | 动词 + 对象 | 开始去雾、确认支付 |
| 确认/取消 | 确定 / 取消（不追加动词重复） | 确定删除？→ 确定 / 取消 |
| 危险操作 | 动词 + 对象（红色） | 删除数据集 |
| 次级操作 | 动词（弱化样式） | 查看详情、导出报告 |

### 4.2 提示（Toast / Snackbar）

| 场景 | 模板 | 示例 |
|------|------|------|
| 成功 | 已 + 动作 | 已保存、已删除 |
| 失败 | 动作 + 失败：原因，解决方案 | 上传失败：文件过大，请压缩后重试 |
| 进行中 | 动作 + … | 处理中…（长任务附加进度） |
| 权限 | 请 + 动作 | 请登录后继续 |

### 4.3 空状态

| 区块 | 文案要求 | 示例 |
|------|---------|------|
| 主标题 | 说明"无内容"，句式：还没有 {对象} | 还没有处理记录 |
| 副文案 | 引导下一步动作 | 上传一张图片，开始第一次去雾 |
| 操作按钮 | 动词 + 对象 | 去处理、去上传 |

### 4.4 错误页

| 区块 | 文案要求 | 示例 |
|------|---------|------|
| 标题 | 错误概括（名词化） | 页面加载失败 |
| 原因 | 一句说明 | 网络异常或服务暂时不可用 |
| 方案 | 可执行动作 | 请检查网络后刷新重试 |
| 按钮 | 刷新 / 返回首页 | 重新加载 |

### 4.5 表单校验

| 场景 | 模板 | 示例 |
|------|------|------|
| 必填 | 请输入{字段名} / 请选择{字段名} | 请输入手机号 |
| 格式 | {字段名}{格式}不正确 | 手机号格式不正确 |
| 范围 | {字段名}需在 {范围} 内 | 图片大小需在 20MB 内 |
| 重复 | {字段名}已存在 | 该用户名已存在 |

### 4.6 对话框

| 区块 | 模板 | 示例 |
|------|------|------|
| 标题 | 名词（动作对象） | 删除数据集 |
| 正文 | 说明操作后果 | 删除后数据集及其中图片将不可恢复，确定继续？ |
| 操作 | 确认 / 取消；危险操作用红色确认 | 删除 / 取消 |

## 5. 语言与格式规则

| 规则 | 要求 | 示例 |
|------|------|------|
| 中英混排 | 中文与英文/数字间加半角空格 | 支持 Dehaze 去雾；20+ 种算法 |
| 数字 | 使用阿拉伯数字；千分位按需 | 每月 100 次、1,000 张 |
| 单位 | 与数值间不加空格（中文语境） | 20MB、1080P |
| 大小写 | 专有名词保持大写 | PSNR、SSIM、VIP、Dehaze |
| 标点 | 界面文案统一中文标点；列表/标签句末不加句号 | 上传图片（无句号） |
| 省略号 | 使用半角三连点… | 处理中… |
| 禁用 | 网络流行语、"亲"、过度英文直译、感叹号堆砌 | —— |

## 6. 文案维护流程

1. **先查表**：新文案涉及产品名词时，先查术语表，使用规范术语。
2. **后登记**：新术语出现时，先在本表登记再投产。
3. **同源引用**：模块文档引用本表术语，不复制定义；术语变化只改本表。
4. **全端同步**：术语/文案变更须同步所有端（Web/移动/桌面）与相关文档。
5. **走查项**：设计走查时对照本表检查术语一致性（见 [文档治理规则](../00-文档治理/01-文档治理规则)）。
