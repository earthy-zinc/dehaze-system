## 二、跨端共性问题（出现于 2+ 端）

### 2.1 Result.traceId 声明但从不赋值（Java + Python）

文档 2.1 明确批评 Java"Result.traceId 声明但从不赋值"，但 Python 端有**完全相同**的 bug：

- [result.py:22](file:///E:/DehazeSystem/dehaze-python/app/core/result.py#L22) 声明 `traceId: Optional[str] = Field(default=None)`
- [result.py:35-44](file:///E:/DehazeSystem/dehaze-python/app/core/result.py#L35-L44) `success()`/`error()`/`warning()` 均未设置 traceId
- 配合 `exclude_none=True`，traceId 字段从不出现在响应体中

Java 端已修复（[Result.java:57](file:///E:/DehazeSystem/dehaze-java/src/main/java/com/pei/dehaze/common/result/Result.java#L57) 通过 `MDC.get("traceId")` 回填），但 **MQ 消费者未将 traceId 写入 MDC**（[ExportTaskConsumer.java:35](file:///E:/DehazeSystem/dehaze-java/src/main/java/com/pei/dehaze/mq/ExportTaskConsumer.java#L35)），导致异步场景下 Result.traceId 仍为 null。

### 2.2 权限缓存 Hash Key TTL 语义错误（Java + Go）

两端都把所有角色权限存入单个 Hash Key，并对整个 Hash 设 TTL：

- Java: [SysRoleMenuServiceImpl.java:82-85](file:///E:/DehazeSystem/dehaze-java/src/main/java/com/pei/dehaze/service/impl/SysRoleMenuServiceImpl.java#L82-L85) `role_perms:` Hash + `expire(整个Hash, 30min)`
- Go: [role_service.go:420-421](file:///E:/DehazeSystem/dehaze-go/internal/service/role/role_service.go#L420-L421) `role:perms` Hash + `Expire(整个Hash, 30min)`

后果：刷新角色 A → 整个 Hash TTL 重置 → 角色 B/C/D 的 TTL 也被重置，单角色权限可能长期残留。文档要求"逐角色 TTL"，应改为 `role_perms:{roleCode}` 独立 Key。

### 2.3 MQ 消费者是 TODO 桩（Java + Go）

两端都搭建了完整的 DLX/重试/死信基础设施，但实际 handler 是空壳：

- Java: [ExportTaskConsumer.java:40-42](file:///E:/DehazeSystem/dehaze-java/src/main/java/com/pei/dehaze/mq/ExportTaskConsumer.java#L40-L42) `// TODO: 调用导出服务处理任务`，且 [TaskExecutorImpl.java:51](file:///E:/DehazeSystem/dehaze-java/src/main/java/com/pei/dehaze/service/impl/TaskExecutorImpl.java#L51) 直接 `@Async` 绕过 MQ，MQ 路径全是死代码
- Go: [handler.go:36-44](file:///E:/DehazeSystem/dehaze-go/internal/service/task/handler.go#L36-L44) `// Go 端暂未实现任务执行策略，收到消息后将任务标记为 FAILED`

### 2.4 监控端点鉴权角色与文档不符（Java + Go + Python）

文档要求"其余监控端点要求 `ROLE_ADMIN`"，但三端实现都不一致：

- Java: [SecurityConfig.java:54](file:///E:/DehazeSystem/dehaze-java/src/main/java/com/pei/dehaze/config/SecurityConfig.java#L54) `hasRole("ROOT")`
