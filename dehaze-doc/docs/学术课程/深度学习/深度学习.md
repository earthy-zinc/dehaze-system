# 深度学习基础

## 神经网络简介

受生物神经元的启发，人工神经元接收来自其他神经元或者外部源的输入，每个输入都有一个相关的权值，该权值根据输入对当前神经元的重要性确定。对输入进行加权求和后，经过激活函数f计算得到该神经元的输出。

利用神经元构建神经网络时，相邻层之间的神经元相互连接，并且给每个连接分配一个强度，即权值。神经网络中的信息只能向一个方向流动，即从输入节点向前移动，通过中间多层隐藏节点，再向输出节点移动，网络中没有环路。输入层是输入x所在的层，输出层为输出y所在的层，隐藏层是输入层和输出层之间的层级。

神经网络的特点包括：

- 同一层神经元之间没有连接
- 第N层的每个神经元和第N+1层的所有神经元相连，第N-1层神经元的输出就是第N层神经元的输入
- 每个连接都有对应的权值

人工神经网络中每个输入xi需要一个权重wi，同时所有输入还需要一个偏置值b，然后对其求和后的结果输入到神经元的激活函数中。这引出了三个关键问题：

1. 如何初始化每个输入的权重和所有输入的偏置值
2. 神经元的激活函数应该选择哪一种
3. 如何衡量神经元从输入到输出与实际情况之间的差距，即如何构建损失函数

## 激活函数

在神经元中引入激活函数的目的是向神经网络中引入非线性因素。通过激活函数，神经网络可以拟合各种曲线。如果不用激活函数，每一层输出都是上层输入的线性函数，无论神经网络有多少层，输出都是输入的线性组合。引入非线性函数作为激活函数后，输出就不再是输入的线性组合，可以逼近任意函数。

## 参数初始化

对于某一个神经元来说需要初始化的参数有两种：权重和偏置。偏置通常初始化为0，而权重的初始化比较重要，会影响神经网络的效率。一般参数的初始化有四种方法。

### 随机初始化

随机初始化从均值为0，标准差为1的高斯分布中取样，使用一些很小的值对权重w进行初始化。

### 标准初始化

权重w会从一个区间中均匀随机取值，在(-1/√d, 1/√d)均匀分布中生成当前神经元的权重，其中d是每个神经元的输入数量。

### Xavier初始化

各层的激活值和梯度的方差在传播过程中保持一致，也叫做Glorot初始化。

- 正态化的Xavier初始化：以0为中心，标准差为stddev = √(2/(输入神经元个数 + 输出神经元个数))的正态分布中抽取样本。

### He初始化

在正向传播时，激活值的方差保持不变；反向传播时，关于状态值的梯度的方差保持不变。与Xavier初始化类似，也有正态化和均匀化两种方法。

## 损失函数

### 分类任务中的损失函数

分类任务中使用最多的衡量模型与实际之间差距的损失函数是交叉熵损失函数。

#### 多分类任务

通常使用softmax将原始结果转换为概率形式，因此也称为softmax损失。损失函数计算方法是当前类别的标记值乘以log(softmax)
函数的对数结果，对所有类别求和取负值。从概率角度理解，目的是最小化正确类别所对应的预测概率的负对数，即正确类别对应的预测概率值越大，损失越小；其他错误类别对应的预测概率值越小，损失也越小。损失函数计算值越接近于0，说明模型预测产生的损失越小。

#### 二分类任务

处理二分类任务时不使用softmax函数，而是使用sigmoid函数，对应的损失函数也有所不同，但基本原理相同：损失越小，损失函数计算值越小。

### 回归任务中的损失函数

#### MAE损失

也称为L1损失。用绝对误差作为距离。计算方法是真实值与预测值之间差的绝对值，对于多个样本点，取所有误差的平均值。该损失函数在函数零点不可导，在寻找损失最小值时容易越过极小值，导致找不到最优预测模型。

#### MSE损失

也称为L2损失或欧式距离。与L1损失的区别是，一个用绝对值，一个使用平方，即真实值与预测值之间差的平方。从图像可以看出，函数离零点越远，导数值越大，因此目标值和预测值相差很大时会造成梯度爆炸。

#### Smooth L1损失

结合了L1和L2损失的优缺点。L1损失在零点不可导，而L2损失在远处梯度过大。Smooth L1损失很好地解决了这两个问题，类似于在|x|<
1时使用L2，其他情况下使用L1的分段函数。

## 神经网络优化算法

### 梯度下降算法

梯度下降是一种寻找使损失函数最小化的方法。梯度的方向是函数增长速度最快的方向，梯度的反方向是函数减少最快的方向。沿着梯度下降方向，能够找到损失函数的最小值。对于每个输入权值，在深度学习中进行优化的公式为：新权值 =
旧权值 - 学习率 × 负梯度。

学习率是一个重要因素。如果学习率太小，则每次训练后得到的效果太小，增大训练成本；如果学习率太大则容易跳过最优解。一个较好的方法是让学习率随着训练进行变化，开始时较大，之后变小。

模型训练的概念：

| 术语        | 含义                             |
|-----------|--------------------------------|
| Epoch     | 使用训练集的全部数据对模型进行一次完整的训练         |
| Batch     | 使用训练集的一小部分样本对模型权重进行一次反向传播的参数更新 |
| Iteration | 使用一个batch数据对模型参数进行一次更新的过程      |

### 反向传播算法

- 前向传播：指数据输入到神经网络中，逐层向前传播，一直运算到输出层为止。
- 反向传播：在网络训练过程中经过前向传播得到的最终结果和训练样本的真实值总是存在一定误差，这个误差就是损失函数。要减小这个误差，需要从后往前依次求出各个参数的偏导，这就是反向传播。
- 链式法则：反向传播算法利用链式法则进行梯度求解以及权重更新。对于复杂的复合函数，将其拆分为一系列加减乘除或者指数、对数、三角函数等初等函数，通过链式法则完成复合函数的求导。

### 梯度下降优化方法

在寻找损失函数最小值时会遇到一些问题，如函数在一段平坦区域内下降缓慢，这部分运用梯度下降算法会耗费许多运算能力；函数在某个区域到达鞍点（导数为0但不是极值点）；或者函数到达局部极小值但不是全局最小值。这些问题会影响深度神经网络模型的效果，因此提出了一些解决方法，主要有：动量算法、AdaGrad、RMSprop、Adam。

### 学习率调度

一般情况下，在训练神经网络时，让学习率随着训练而变化。如果学习率过高，就找不到损失函数的最小点；如果学习率过低，会造成收敛变慢，耗费大量时间。调整学习率的方法有以下几种：

#### 分段常数衰减

分段常数衰减是在事先定义好的训练次数区间上设置不同的学习率常数。刚开始学习率大一些，之后越来越小。区间的设置需要根据样本量调整，一般样本量越大区间间隔越小。

在tf.keras中对应的方法是：

```python
tf.keras.optimizers.schedules.PiecewiseConstantDecay(boundaries, values)
```

- boundaries: 设置分段更新的step值
- values: 针对不同分段的学习率值

例如，设置前十万步学习率为1.0，接下来的十万步到十一万步学习率设置为0.5，之后的步骤将学习率设置为0.1，以达到学习率逐步降低的效果。

#### 指数衰减

指数衰减是学习率按照指数图像逐步衰减。刚开始学习率为1，之后逐步下降，呈指数形式。这种情况下，刚开始衰减较慢，之后越来越快。

在tf.keras中对应的方法是：

```python
tf.keras.optimizers.schedules.ExponentialDecay(initial_learning_rate, decay_steps, decay_rate)
```

- initial_learning_rate: 初始学习率
- decay_steps: 衰减步数
- decay_rate: 指数衰减公式中的底数

#### 1/t衰减

使用数学公式表示随着步数增加学习率减少的趋势，公式为：α = α₀/(1+kt)

总结来说，学习率调度是让深度学习网络的学习率逐步下降的过程，防止学习率过大跳过最优点。

## 深度学习正则化

在设计机器学习算法时，不仅要求在训练集上的误差小，而且希望在新样本上的泛化能力强。许多机器学习算法采用相关策略来减小测试误差，这些策略统称为正则化。因为神经网络经常会遇到过拟合现象，因此需要使用不同策略来增强模型的泛化能力。

正则化通过对算法的修改来减少泛化误差，目前使用较多的有参数范数惩罚、提前终止、Dropout等。

### L1和L2正则化

正则化是减少泛化误差的方法。L1和L2正则化在损失函数上增加一个正则项，由于添加了正则化项，权重矩阵的值会减小，因为具有更小权重矩阵的神经网络会拥有更简单的网络模型。更简单的网络一定程度上会减少过拟合现象的发生。

- L2正则化

正则化后的损失函数 = 原损失函数 + α/2m × ||w||²

其中α属于正则化参数，是一个需要优化的超参数。L2正则化又称为权重衰减，因为它会导致权重趋向于0。

- L1正则化

L1正则化与L2正则化的不同在于，权重w不采用平方，这种情况下权重可能会被减少到0。

在tf.keras中使用的方法是：

```python
tf.keras.regularizers.L1(l1=0.01)
tf.keras.regularizers.L2(l2=0.01)
tf.keras.regularizers.L1L2(l1=0.0, l2=0.0)
```

### Dropout正则化

假设神经网络是全连接的，在每个迭代过程中，随机选择某些节点，删除前向和后向连接，因此每个迭代过程都会有不同的节点组合，从而导致不同的输出。这可以看作机器学习中的集成方法，集成模型优于一般单一模型，因为可以捕获更多随机性。因此dropout模型使得神经网络模型优于正常模型，将dropout理解为随机丢弃某些节点及其对应的连接。

```python
tf.keras.layers.Dropout(rate)
```

- rate: 表示每个神经元被丢弃的概率

### 提前终止

提前停止是将一部分训练集作为验证集，当验证集的性能越来越差或性能不再提升时，立即停止对该模型的训练。

在实际应用中使用callbacks函数实现模型的早期终止：

```python
tf.keras.callbacks.EarlyStopping(monitor="val_loss", patience=5)
```

- monitor: 表示监测量，val_loss表示验证集损失
- patience: 表示epoch的数量

当整个训练过程中性能无提升时就会停止训练。

### 批标准化

批标准化(Batch Normalization)
是对一批数据进行标准化处理，是神经网络中的一层，简称BN层，与全连接层类似。但批标准化层针对单个神经元进行，利用网络训练时的一个mini批次的数据来计算该神经元的均值和方差，归一化后重构，因此称为批标准化。

```python
tf.keras.layers.BatchNormalization(
    epsilon=0.01, center=True, scale=True, 
    beta_initializer="zeros", gamma_initializer="ones")
```

## 卷积神经网络

### 卷积神经网络构成

卷积神经网络(Convolutional Neural Network, CNN)
受到人类视觉神经系统的启发。从原始信号摄入开始，做出初步处理，大脑皮层某些细胞发现图形的边缘和方向，然后抽象物体，判定眼前物体的形状，进一步抽象判定该物体是什么。

CNN网络主要由三部分构成：卷积层、池化层、全连接层。其中卷积层负责提取图像中的局部特征，池化层用来降低参数数量级（降维操作），全连接层类似于人工神经网络部分，用来输出想要的结果。

### 卷积层

卷积层的目的是提取输入特征图的特征，可以提取图像中的边缘信息。卷积的本质是在滤波器和输入数据的局部区域之间做点积。将图像看作二维矩阵（暂时忽略RGB分量），滤波器也是二维矩阵，通常为3×3矩阵，内部由规律的01元素构成。滤波器的维度通常比输入图像维度小很多，将输入图像的每一部分和滤波器做矩阵乘积，得到输出元素，进而得到输出矩阵，即特征图。

在卷积过程中，得到的结果（特征图）相比原始图会小一圈，可以在原图像周围扩张一个维度（padding），扩张后的图像再与卷积核做点积，就能保证在卷积过程中特征图大小保持不变。

卷积的三个关键点：

1. 卷积核如何构造
2. 扩张维度（padding）应填充什么值
3. 卷积核和原图像相乘的步长，通常步长为1

实际情况下，当输入有多个通道时，卷积核也需要拥有相同通道数。每个卷积核对应通道矩阵和输入层对应矩阵进行卷积，将每个通道卷积的结果按位相加得到最终结果，称为feature
map特征图。

当有多个卷积核对原始图像进行卷积时，每个卷积核学习到不同特征，对应产生包含多个通道的特征图。

输出特征图的大小与以下参数相关：卷积核大小、零填充方式、卷积步长。

### 池化层

池化层主要降低了后续网络层的输入维度，缩减模型大小，提高计算速度，并提高特征图的健壮性，防止过拟合现象发生。主要对卷积层学习到的特征图进行下采样处理，包括最大池化和平均池化两种方式。

#### 最大池化

最大池化对特征矩阵建立窗口，窗口尺寸小于特征矩阵维数，然后在每个窗口内部取内部元素的最大值作为输出。

```python
tf.keras.layer.MaxPool2D(pool_size=(2, 2), strides=None, padding="valid")
```

- pool_size: 池化窗口大小
- strides: 窗口移动步长，默认为1
- padding: 是否进行填充，默认不填充

#### 平均池化

取窗口内所有元素的均值作为输出。

经过池化后，输出矩阵维度减少，意味着后续网络层输入维度减小，计算速度变快。

### 全连接层

全连接层位于卷积神经网络末端，经过卷积层的特征提取和池化层的降维后，将特征图转化为一维向量送入全连接层中进行分类或回归操作。

### AlexNet

AlexNet网络是卷积神经网络框架下的一种模型。首先输入3通道矩阵，矩阵维度为227×227，即图像分辨率为227×227。在网络中经过卷积→池化→再卷积→池化→平整（转为1维）→全连接得到输出结果。

AlexNet包含8层变换，有5层卷积和2层全连接隐藏层，以及一个全连接输出层。

第一层卷积核形状为11×11，卷积核个数为96，卷积步长为4，对227×227×3的3通道图像做卷积，得到55×55的特征图，共96个。每个卷积核分别与三个通道中的每个通道做卷积，结果相加输出一个特征图。因此得到形状为55×55×96的三维特征图。

第二层为池化层，对特征矩阵建立3×3窗口，步长设为2，采用最大池化方法，特征图维度减小到27×27×96，达到初步降维目的。

第三层仍为卷积层，卷积核变为5×5，个数为256。对上一步传下的特征图进行范围填充(padding)，使卷积后特征图的长和宽保持不变。

第四至第六层进行卷积，卷积核形状为3×3，同时进行范围填充保持特征图形状不变。

第七层进行池化，结果降维变成6×6×256的三维特征图。

然后对三维特征图进行平整展开变为一维向量6×6×256=9216个参数。与原图像227×227×3=154587相比，参数降低了16倍。这些参数保留了图像特征，同时降低了参数个数，可用于全连接层训练，减少计算量。这些参数同时作为神经元送入下层全连接层。

第八和第九层为全连接层，输入9216个参数到4096个神经元中，经过全连接神经网络进行学习。

第十层为全连接输出层，接受4096个参数，输出1000个分类结果。使用softmax将每个分类结果的得分转化为概率值，从中选取概率值最大的作为神经网络学习后的判断结果。

AlexNet网络将sigmoid激活函数改为relu激活函数，计算更简单，网络更容易训练。

通过dropout方法，即丢弃一些神经元来降低全连接层的复杂度。

引入大量图像增强方法，如反转、裁剪、颜色变化，进一步扩大数据集，缓解过拟合现象。

### VGG

VGG神经网络可以看作加深版的AlexNet，整个网络由卷积层和全连接层叠加形成。但VGG网络在卷积层使用的卷积核都是小尺寸（3×3），池化层使用的池化窗口是2×2，通过不断加深卷积网络来提升性能（准确度、计算用时等）。

输入224×224×3的三维矩阵（三通道RGB图片）经过两个3×3×64的卷积核（padding=same）生成特征图，然后2×2池化窗口池化，缩小维度，再卷积两次，池化，卷积三次，池化，卷积三次，池化……最后形成7×7×512的特征矩阵，平整展开进入全连接层。

VGG模型中可将整体模型分为多个VGG块，组成规律是：连续使用多个相同的填充为1、卷积核大小为3×3的卷积层，后面接上步幅为2、窗口形状为2×2的最大池化层。卷积层保持输入的高和宽不变，池化层则对输入减半。定义vgg_block函数实现基础VGG块，可指定卷积层数量num_convs和每层卷积核个数num_filters。

VGG模型：

```python
import numpy as np
import tensorflow as tf
from tensorflow.keras.datasets import mnist
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Conv2D
from tensorflow.keras.layers import MaxPool2D
from tensorflow.keras.layers import Flatten
from tensorflow.keras.layers import Dense
from tensorflow.keras.layers import Dropout

def vgg_block(num_convs, num_filters):
    block = Sequential()
    for _ in range(num_convs):
        block.add(
            Conv2D(
                num_filters, kernel_size=3, padding="same", activation="relu"))
    block.add(MaxPool2D(pool_size=2, strides=2))
    return block

def vgg(conv_arch):
    net = Sequential()
    for (num_convs, num_filters) in conv_arch:
        net.add(vgg_block(num_convs, num_filters))
    net.add(Sequential([
        Flatten(),
        Dense(4096, activation="relu"),
        Dropout(0.5),
        Dense(4096, activation="relu"),
        Dropout(0.5),
        Dense(10, activation="softmax")
    ]))
    
def get_train(size):
    index = np.random.randint(0, np.shape(train_images)[0], size)
    resized_images = tf.image.resize_with_pad(train_images[index], 224, 224,)
    return resized_images.numpy(), train_labels[index]

def get_test(size):
    index = np.random.randint(0, np.shape(test_images)[0], size)
    resized_images = tf.image.resize_with_pad(test_images[index], 224, 224,)
    return resized_images.numpy(), test_labels[index]

conv_arch = ((2, 64), (2, 128), (3, 256), (3, 512), (3, 512))
net = vgg(conv_arch)

(train_images, train_labels), (test_images, test_labels) = mnist.load_data()
train_images = tf.reshape(train_images, (train_images.shape[0], train_images.shape[1], train_images.shape[2], 1))
test_images = tf.reshape(test_images, (test_images.shape[0], test_images.shape[1], test_images.shape[2], 1))

train_images = get_train(5000)
test_images = get_test(1000)

optimizer = tf.keras.optimizers.SGD(learning_rate=0.01, momentum=0.0, nesterov=False)
net.compile(optimizer=optimizer, loss="sparse_categorical_crossentropy", metrics=["accuracy"])

net.fit(train_images, train_labels, batch_size=256, epochs=5, verbose=1, validation_split=0.2)

net.evaluate(test_images, test_labels, verbose=1)
```

VGG16中有5个这样的VGG块，前两块使用两个卷积层，后三块使用三个卷积层，第一块输出通道是64，之后每次输出通道数翻倍，直到变为512。

### GoogLeNet

GoogLeNet在加深网络层数的同时做了结构上的创新，引入了Inception结构代替之前的卷积加激活组件。

GoogLeNet中的Inception块有四条并行线路，前三条线路使用窗口大小分别是1×1、3×3和5×5的卷积层来抽取不同空间尺寸下的信息，其中中间两个线路会对输入先做1×1的卷积来减少输入通道数，用来降低模型复杂度，第四条线路使用3×3的最大池化层，后接1×1的卷积层来改变通道数，四条线路都使用合适的填充使输入和输出的高度和宽度一致，最后将每条线路的输出在通道维上连接并向后传输，这是GoogLeNet中Inception块的结构。

1×1卷积核：

1×1大小的卷积特点是不考虑特征图局部信息之间的关系，即图像像素和其周围像素的关系。该卷积核的作用是实现跨通道的交互和信息整合，实现卷积核通道数的降维、升维，减少网络参数。
