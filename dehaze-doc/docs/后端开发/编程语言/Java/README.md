# Java 学习笔记

本目录包含Java相关的学习笔记，为了便于阅读和维护，内容已按主题进行结构化拆分。

## 目录结构

- [类与对象](类与对象.md) - Java类的定义、静态方法与实例方法、构造方法、抽象类、内部类、枚举类、包装类等
- [继承](继承.md) - 继承机制、super关键字、多态、动态绑定与静态绑定、类加载过程等
- [接口](接口.md) - 接口定义与实现、接口继承、instanceof操作符等
- [包](包.md) - 包的声明与使用、可见性、编译与连接等
- [字符串](字符串.md) - String类常用方法、StringBuilder类等
- [数组](数组.md) - Arrays工具类、数组操作等
- [异常处理](异常处理.md) - 异常类型体系、日志处理等
- [日期与时间](日期与时间.md) - Java 8时间API等
- [函数式编程](函数式编程.md) - Lambda表达式、函数式接口、Stream API等
- [反射](反射.md) - Class类、Field、Method、Constructor的使用等
- [注解](注解.md) - 注解定义、元注解、运行时注解处理等
- [泛型](泛型.md) - 泛型标记符、泛型方法、泛型类等
- [网络编程](网络编程.md) - Socket编程、TCP/UDP通信、HTTP编程等
- [Web开发](Web开发.md) - Servlet生命周期、Session与Cookie、Filter与Listener等
- [动态代理](动态代理.md) - 静态代理与动态代理、Proxy类、cglib等
- [并发](并发.md) - 多线程、锁机制、并发容器、线程池等
- [集合框架](集合框架.md) - List、Set、Map等集合类的使用与实现原理
- [IO/NIO](IO.md) - 输入输出流、NIO、文件操作等
- [JVM](JVM.md) - 类加载机制等JVM相关知识
