## 一、模块概述

### 1.1 模块定位

算法选择模块是用户选择去雾算法的核心界面，通过树形结构、智能推荐、搜索筛选等方式，帮助用户快速找到合适的算法。

### 1.2 核心价值

- **结构化展示**：树形算法结构，清晰的分类层级
- **智能推荐**：基于图像特征推荐最优算法
- **快速查找**：支持搜索、筛选、收藏等多种查找方式
- **信息透明**：完整的算法信息和样例效果展示

## 二、功能需求

### 2.1 树形算法结构 (F-M02-001)

#### 2.1.1 功能描述

以树形结构展示所有去雾算法，支持分类浏览和层级导航。

#### 2.1.2 算法分类体系

**三级分类结构**

```
去雾算法（根节点）
├── 传统算法
│   ├── 基于物理模型
│   │   ├── 暗通道先验（DCP）
│   │   ├── 色彩衰减先验（CAP）
│   │   └── 边界约束与上下文正则化（BCCR）
│   ├── 基于图像增强
│   │   ├── 直方图均衡化
│   │   ├── Retinex算法
│   │   └── 同态滤波
│   └── 基于融合
│       ├── 多尺度融合
│       └── 拉普拉斯金字塔融合
├── 深度学习算法
│   ├── CNN系列
│   │   ├── DehazeNet
│   │   ├── AOD-Net
│   │   ├── GridDehazeNet
│   │   └── FFA-Net
│   ├── GAN系列
│   │   ├── CycleGAN
│   │   ├── Pix2Pix
│   │   └── DCPDN
│   └── Transformer系列
│       ├── DehazeFormer
│       ├── Restormer
│       └── Uformer
└── 混合算法
    ├── 传统+深度学习
    ├── 多算法融合
    └── 自适应算法
```

#### 2.1.3 树形展示设计

**视觉设计**

- 使用缩进表示层级关系
- 使用图标区分节点类型（文件夹/算法）
- 使用展开/收起图标控制子节点显示
- 当前选中节点高亮显示

**交互设计**

- 点击文件夹节点：展开/收起子节点
- 点击算法节点：显示算法详情
- 长按节点：显示快捷操作菜单
- 支持手势滑动返回上级

**节点信息**

| 节点类型 | 显示信息             | 图标 |
| -------- | -------------------- | ---- |
| 分类节点 | 分类名称、子节点数量 | 📁/📂  |
| 算法节点 | 算法名称、标签、评分 | ⚡    |

#### 2.1.4 算法卡片信息

**基础信息**

- 算法名称（中英文）
- 算法类型标签
- 算法评分（⭐⭐⭐⭐⭐）
- 推荐指数

**性能指标**

- 处理速度：快/中/慢
- 效果质量：优/良/中
- 适用场景：轻度/中度/重度雾霾

**快捷操作**

- 查看详情按钮
- 收藏/取消收藏按钮
- 快速预览按钮
- 直接使用按钮

### 2.2 智能推荐功能 (F-M02-002)

#### 2.2.1 功能描述

基于输入图像的特征，智能推荐最适合的去雾算法。

#### 2.2.2 推荐策略

**图像特征分析**

- 雾霾浓度检测（轻度/中度/重度）
- 场景类型识别（城市/风景/建筑/人像）
- 光照条件分析（正常/逆光/夜景）
- 图像复杂度评估

**推荐算法**

| 场景     | 推荐算法                    | 理由                 |
| -------- | --------------------------- | -------------------- |
| 轻度雾霾 | DCP、CAP                    | 处理速度快，效果自然 |
| 中度雾霾 | AOD-Net、FFA-Net            | 平衡效果和速度       |
| 重度雾霾 | DehazeFormer、GridDehazeNet | 效果最佳             |
| 夜景雾霾 | Retinex + CNN               | 增强亮度同时去雾     |
| 逆光场景 | HDR + 去雾                  | 先处理曝光再去雾     |

#### 2.2.3 推荐展示

**推荐区域**

- 位于页面顶部，醒目位置
- 显示"智能推荐"标识
- 最多推荐3个算法
- 显示推荐理由

**推荐卡片**

- 算法名称和图标
- 推荐指数（⭐⭐⭐⭐⭐）
- 推荐理由（简短说明）
- 预期效果预览
- 一键使用按钮

**示例**

```
🎯 智能推荐

┌─────────────────────────────┐
│ ⚡ AOD-Net                   │
│ 推荐指数: ⭐⭐⭐⭐⭐          │
│ 理由: 您的图片为中度雾霾，   │
│       该算法效果好且速度快   │
│ [预览效果] [立即使用]        │
└─────────────────────────────┘
```

### 2.3 搜索与筛选功能 (F-M02-003)

#### 2.3.1 搜索功能

**搜索方式**

- 关键词搜索：支持算法名称、标签搜索
- 拼音搜索：支持拼音首字母搜索
- 模糊搜索：支持部分匹配

**搜索范围**

- 算法名称（中英文）
- 算法标签
- 算法描述
- 算法分类

**搜索体验**

- 实时搜索（输入即搜索）
- 搜索历史记录（最近10条）
- 热门搜索推荐
- 搜索结果高亮显示

**搜索结果展示**

- 按相关度排序
- 显示匹配的关键词高亮
- 显示算法基本信息
- 支持快速操作

#### 2.3.2 筛选功能

**筛选维度**

| 筛选项   | 选项                       | 说明     |
| -------- | -------------------------- | -------- |
| 算法类型 | 传统算法/深度学习/混合算法 | 多选     |
| 处理速度 | 快/中/慢                   | 单选     |
| 效果质量 | 优/良/中                   | 单选     |
| 适用场景 | 轻度/中度/重度雾霾         | 多选     |
| 评分范围 | 1-5星                      | 滑动选择 |

**筛选交互**

- 点击"筛选"按钮打开筛选面板
- 底部弹出式面板设计
- 实时预览筛选结果数量
- 支持重置筛选条件
- 支持保存筛选方案

**筛选结果**

- 显示筛选条件标签
- 显示结果数量
- 支持二次筛选
- 支持排序（评分/速度/效果）

### 2.5 算法收藏功能 (F-M02-005)

#### 2.4.1 功能描述

支持用户收藏常用算法，快速访问。

#### 2.4.2 收藏操作

**添加收藏**

- 算法卡片上的收藏按钮
- 算法详情页的收藏按钮
- 收藏成功提示

**取消收藏**

- 再次点击收藏按钮
- 收藏列表中左滑删除
- 取消收藏确认提示

#### 2.4.3 收藏列表

**展示方式**

- 独立的"我的收藏"入口
- 网格或列表布局
- 显示收藏时间
- 支持排序（时间/使用频率）

**快捷操作**

- 直接使用
- 查看详情
- 取消收藏
- 分享给好友

#### 2.6.1 功能描述

**对比展示**

- 表格形式对比
- 雷达图对比
- 样例效果对比

## 三、交互流程

### 3.1 完整交互流程图

```
用户进入算法选择页面
    ↓
┌─────────────────────────────┐
│ 查看智能推荐（可选）         │
│ - 查看推荐算法               │
│ - 查看推荐理由               │
│ - 预览效果                   │
│ - 直接使用 → 进入处理阶段    │
└─────────────────────────────┘
    ↓
┌─────────────────────────────┐
│ 浏览算法树形结构             │
│ - 展开/收起分类              │
│ - 查看算法卡片               │
│ - 点击查看详情               │
└─────────────────────────────┘
    ↓
┌─────────────────────────────┐
│ 搜索/筛选算法（可选）        │
│ - 输入关键词搜索             │
│ - 设置筛选条件               │
│ - 查看筛选结果               │
└─────────────────────────────┘
    ↓
┌─────────────────────────────┐
│ 查看算法详情                 │
│ - 阅读算法描述               │
│ - 查看效果样例               │
│ - 了解参数说明               │
│ - 查看用户评价               │
└─────────────────────────────┘
    ↓
┌─────────────────────────────┐
│ 选择算法                     │
│ - 点击"立即使用"             │
│ - 或添加到收藏               │
└─────────────────────────────┘
    ↓
进入去雾处理阶段
```

### 3.2 快捷流程

**智能推荐快捷流程**

```
进入页面 → 查看推荐 → 点击"立即使用" → 开始处理
（预计用时：<5秒）
```

**收藏快捷流程**

```
进入页面 → 点击"我的收藏" → 选择算法 → 开始处理
（预计用时：<3秒）
```
