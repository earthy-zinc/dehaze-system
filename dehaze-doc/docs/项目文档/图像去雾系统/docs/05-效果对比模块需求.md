# 效果对比模块需求文档

**文档版本**: v2.0  
**最后更新**: 2025-11-21  
**所属系统**: 手机端图像去雾系统APP  
**模块编号**: M04

---

## 一、模块概述

### 1.1 模块定位

效果对比模块是用户评估去雾效果的核心工具，提供多种对比方式和专业评估指标，帮助用户全面了解处理效果。

### 1.2 核心价值

- **多维对比**：6种对比模式，满足不同对比需求
- **专业评估**：量化指标分析，客观评价效果
- **直观展示**：可视化对比工具，清晰呈现差异
- **信息透明**：完整的算法信息和处理参数

### 1.3 相关文档

- 上级文档：[01-产品概述和总体架构.md](01-产品概述和总体架构.md)
- 上游模块：[04-去雾处理模块需求.md](04-去雾处理模块需求.md)

## 二、功能需求

### 2.1 并排对比模式 (F-M04-001)

#### 2.1.1 功能描述

将原图和处理后的图片并排显示，方便整体效果对比。

#### 2.1.2 布局设计

**竖屏布局**

```
┌─────────────────────────────┐
│      原图                    │
│  [图片显示区域]              │
│                              │
├─────────────────────────────┤
│      处理后                  │
│  [图片显示区域]              │
│                              │
└─────────────────────────────┘
```

**横屏布局**

```
┌──────────────┬──────────────┐
│    原图      │   处理后     │
│ [图片区域]   │  [图片区域]  │
│              │              │
└──────────────┴──────────────┘
```

#### 2.1.3 交互功能

- 同步缩放：两张图片同步放大/缩小
- 同步移动：拖动时两张图片同步移动
- 双击放大：双击图片放大到100%
- 捏合手势：支持缩放操作
- 标签切换：点击标签切换显示内容

---

### 2.2 重叠对比模式 (F-M04-002)

#### 2.2.1 功能描述

将原图和处理后的图片重叠显示，通过滑动分隔线对比效果。

#### 2.2.2 对比方式

**垂直分隔线**

```
┌─────────────────────────────┐
│  原图  │  处理后              │
│        │                      │
│        │                      │
│   ←────┼────→                │
│        │                      │
└─────────────────────────────┘
```

**水平分隔线**

```
┌─────────────────────────────┐
│        原图                  │
│                              │
├──────────↑↓─────────────────┤
│      处理后                  │
│                              │
└─────────────────────────────┘
```

#### 2.2.3 交互功能

- 拖动分隔线：左右或上下拖动
- 自动对齐：分隔线自动对齐到中心
- 切换方向：垂直/水平分隔线切换
- 锁定位置：固定分隔线位置
- 动画效果：分隔线移动动画

---

### 2.3 放大镜对比模式 (F-M04-003)

#### 2.3.1 功能描述

使用放大镜工具查看局部细节，精确对比处理效果。

#### 2.3.2 放大镜设计

**放大镜样式**

```
┌─────────────────────────────┐
│                              │
│         ┌─────┐              │
│         │ 🔍  │              │
│         │放大 │              │
│         │区域 │              │
│         └─────┘              │
│                              │
└─────────────────────────────┘
```

**放大镜参数**

- 放大倍数：2x、3x、5x可选
- 放大镜大小：小、中、大可选
- 边框样式：圆形或方形
- 显示模式：原图/处理后/对比

#### 2.3.3 交互功能

- 拖动放大镜：手指拖动移动位置
- 调整倍数：双指捏合调整放大倍数
- 切换显示：点击切换显示内容
- 固定位置：长按固定放大镜位置
- 对比模式：同时显示原图和处理后的放大效果

---

### 2.4 滤镜调节对比模式 (F-M04-004)

#### 2.4.1 功能描述

通过调节滤镜参数，实时对比不同视觉效果。

#### 2.4.2 滤镜类型

| 滤镜名称 | 调节范围    | 默认值 | 说明           |
| -------- | ----------- | ------ | -------------- |
| 亮度     | -100 ~ +100 | 0      | 调整图片明暗   |
| 对比度   | -100 ~ +100 | 0      | 调整明暗对比   |
| 饱和度   | -100 ~ +100 | 0      | 调整色彩鲜艳度 |
| 色温     | -100 ~ +100 | 0      | 调整冷暖色调   |
| 锐化     | 0 ~ 100     | 0      | 增强细节清晰度 |
| 降噪     | 0 ~ 100     | 0      | 减少图片噪点   |

#### 2.4.3 调节界面

**滑块控制**

```
┌─────────────────────────────┐
│  [图片显示区域]              │
│                              │
├─────────────────────────────┤
│ 亮度    ●────────── 0        │
│ 对比度  ──────●──── +20      │
│ 饱和度  ────────●── +30      │
│ [更多滤镜 ▼]                 │
├─────────────────────────────┤
│ [重置] [保存] [应用]         │
└─────────────────────────────┘
```

#### 2.4.4 预设方案

**内置预设**

- 自然：轻微增强，保持自然
- 鲜艳：提高饱和度和对比度
- 柔和：降低对比度，柔化效果
- 黑白：去除色彩，黑白效果
- 复古：复古色调效果

**自定义预设**

- 保存当前参数为预设
- 命名自定义预设
- 管理预设列表
- 分享预设给好友

### 2.5 指标对比模式 (F-M04-005)

#### 2.4.1 功能描述

通过量化指标客观评估去雾效果，提供专业的数据分析。

#### 2.4.2 评估指标

**图像质量指标**

| 指标名称 | 说明                    | 理想值 | 单位 |
| -------- | ----------------------- | ------ | ---- |
| PSNR     | 峰值信噪比，越高越好    | >25    | dB   |
| SSIM     | 结构相似性，越接近1越好 | >0.85  | -    |
| MSE      | 均方误差，越小越好      | <100   | -    |
| 信息熵   | 图像信息量，适中为好    | 7-8    | -    |

**去雾效果指标**

| 指标名称   | 说明           | 理想值  | 单位 |
| ---------- | -------------- | ------- | ---- |
| 对比度提升 | 对比度增加程度 | 20%-50% | %    |
| 饱和度提升 | 色彩饱和度增加 | 10%-30% | %    |
| 清晰度提升 | 图像清晰度增加 | 30%-60% | %    |
| 暗通道值   | 雾霾浓度指标   | <0.2    | -    |

**性能指标**

| 指标名称 | 说明           | 单位 |
| -------- | -------------- | ---- |
| 处理时间 | 算法处理耗时   | 秒   |
| 内存占用 | 处理过程内存   | MB   |
| 文件大小 | 处理后文件大小 | MB   |

#### 2.4.3 指标展示

**图表展示**

- 雷达图：多维度指标对比
- 柱状图：单项指标对比
- 折线图：指标变化趋势
- 数值表格：详细数据列表

**对比分析**

- 原图 vs 处理后对比
- 多算法效果对比
- 历史处理效果对比
- 生成分析报告

- 参数值和说明
- 默认值对比

**性能信息**

- 内存占用峰值

## 三、交互流程

### 3.1 完整交互流程

```
处理完成，自动进入对比页面
    ↓
默认显示并排对比模式
    ↓
┌─────────────────────────────┐
│ 用户选择对比模式             │
│ ├─ 并排对比：查看整体效果    │
│ ├─ 重叠对比：精细对比细节    │
│ ├─ 放大镜：查看局部细节      │
│ ├─ 滤镜调节：调整视觉效果    │
│ ├─ 指标对比：查看量化数据    │
│ └─ 算法信息：了解算法详情    │
└─────────────────────────────┘
    ↓
满意结果
    ├─ 保存到相册
    ├─ 分享到社交平台
    ├─ 导出对比报告
    └─ 添加到收藏
    ↓
不满意结果
    ├─ 返回算法选择（更换算法）
    ├─ 调整处理参数
    └─ 重新上传图片
```
