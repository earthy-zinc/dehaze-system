## 一、模块概述

### 1.1 模块定位

数据集管理模块负责管理系统中的图像数据集，包括样例图片、测试数据、用户上传图片等，提供浏览、搜索、分类、标注等功能。支持数据集和数据项（图片）的完整增删改查操作。

### 1.2 核心价值

- **集中管理**：统一管理所有图像数据，支持数据集和图片的增删改查
- **高效浏览**：瀑布流/网格式/列表式展示图像，流畅浏览体验
- **灵活分类**：支持用户自定义场景类型，人工标注雾霾程度
- **快速搜索**：多维度搜索和筛选，按相关度和时间排序
- **使用统计**：记录用户使用数据集和图片的次数

## 二、数据集管理功能

### 2.1 数据集列表展示 (F-M06-001)

#### 2.1.1 功能描述

展示所有数据集的列表，支持查看数据集基本信息和统计数据。

#### 2.1.2 数据集分类

| 数据集类型 | 说明                     | 数量  |
| ---------- | ------------------------ | ----- |
| 样例数据集 | 系统预置的样例图片       | 40张  |
| 测试数据集 | 用于算法测试的标准数据集 | 100张 |
| 用户数据集 | 用户上传的图片           | 不限  |
| 处理结果集 | 去雾处理后的结果图片     | 不限  |

#### 2.1.3 列表信息

**基本信息**

- 数据集名称
- 数据集类型
- 图片数量
- 总大小
- 创建时间
- 最后更新时间

**统计信息**

- 场景分布（用户自定义场景类型，如：城市街道、山区风景、海边等）
- 雾霾程度分布（人工标注：轻度/中度/重度）
- 分辨率分布
- 使用次数（用户使用该数据集进行去雾处理的次数）

#### 2.1.4 数据集下载

**整体打包下载**

支持将整个数据集的所有图片打包下载：
- 点击数据集操作栏的"下载"按钮
- 后端异步打包生成 ZIP 文件
- 打包完成后提供下载链接
- 支持下载进度显示

**下载内容**

- 所有数据项的图片文件
- 保持原始文件名
- 按数据项分目录组织（可选）
- 配对图片放在同一目录下

#### 2.1.5 数据集增删改查

**新增数据集**
- 输入数据集名称、类型、描述
- 选择父数据集（支持树形结构）
- 上传样例图片

**修改数据集**
- 修改数据集名称、描述、样例图片等信息
- 修改数据集状态（启用/禁用）

**删除数据集**
- 支持批量删除
- 级联删除子数据集和关联图片

---

### 2.2 数据集详情查看 (F-M06-002)

#### 2.2.1 功能描述

点击某一具体数据集时，进入数据集详情页面，展示数据集的详细信息和图片部分。获取数据集详情时，统计信息一并返回（通过Redis缓存优化）。详情页面的头部区域为数据集基本信息，包括数据集名称、类型、描述、创建时间、创建人、图片总数、占用空间大小、使用次数等。存在一查看统计分析的按钮，点击后出现统计分析弹窗，展示数据集的统计分析信息，包括场景类型分布图、雾霾程度分布图、文件格式分布图等。

图片部分详细见 文档 07-数据集管理模块需求-02-图片展示与浏览功能.md

#### 2.2.2 详情信息

**数据集信息**

- 数据集名称
- 数据集描述
- 数据集类型
- 创建时间
- 创建人
- 图片总数
- 占用空间大小
- 使用次数

**统计分析**

- 场景类型分布图（用户自定义的场景类型）
- 雾霾程度分布图（人工标注数据）
- 文件格式分布图
