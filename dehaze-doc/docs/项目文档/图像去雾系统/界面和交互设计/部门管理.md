# 部门管理模块

## 1. 概述

### 1.1 文档目的
本文档详细描述图像去雾系统部门管理模块的界面设计和交互规范，涵盖页面布局、组件设计、交互流程和状态管理等方面。

### 1.2 适用范围
本文档适用于部门管理模块的前端开发、UI设计和测试人员，确保界面实现的一致性和用户体验的统一性。

### 1.3 设计原则
本文档遵循《总体界面和交互设计文档》中定义的设计原则，包括一致性、可用性、可访问性和响应式设计等原则。

## 2. 页面结构设计

### 2.1 整体布局
部门管理页面采用单栏布局，主要内容区域包含搜索条件、操作按钮和部门数据表格。

### 2.2 页面组件结构
```
部门管理页面
├── 搜索容器
│   ├── 搜索表单
│   │   ├── 部门名称输入框
│   │   ├── 状态选择器
│   │   ├── 搜索按钮
│   │   └── 重置按钮
│   └── 操作按钮区域
│       └── 新增按钮
└── 数据展示区域
    ├── 部门表格
    │   ├── 部门名称列
    │   ├── 状态列
    │   ├── 排序列
    │   ├── 创建时间列
    │   └── 操作列
    └── 分页组件（如需要）
```

## 3. 组件详细设计

### 3.1 搜索表单组件
- **部门名称输入框**：
  - 占位符："部门名称"
  - 支持回车键触发搜索
  - 清空按钮
- **状态选择器**：
  - 下拉选项：全部、启用、禁用
  - 默认选中"全部"
- **搜索按钮**：
  - 类型：主要按钮
  - 图标：搜索图标
  - 功能：触发部门列表查询
- **重置按钮**：
  - 类型：默认按钮
  - 图标：刷新图标
  - 功能：清空搜索条件并重新查询

### 3.2 操作按钮区域
- **新增按钮**：
  - 类型：成功按钮
  - 图标：加号图标
  - 权限控制：sys:dept:add
  - 功能：打开部门新增表单弹窗

### 3.3 部门表格组件
- **部门名称列**：
  - 字段：name
  - 显示方式：树形结构展示
  - 展开/收起：支持节点展开和收起
- **状态列**：
  - 字段：status
  - 对齐方式：居中
  - 显示方式：标签形式
    - 启用状态：绿色标签显示"启用"
    - 禁用状态：灰色标签显示"禁用"
- **排序列**：
  - 字段：sort
  - 宽度：100px
  - 对齐方式：居中
- **创建时间列**：
  - 字段：createTime
  - 宽度：180px
  - 对齐方式：居中
- **操作列**：
  - 宽度：220px
  - 固定位置：右侧固定
  - 操作按钮：
    - 新增下级按钮：
      - 类型：主要链接按钮
      - 图标：加号图标
      - 权限控制：sys:dept:add
      - 功能：打开新增下级部门表单弹窗
    - 编辑按钮：
      - 类型：主要链接按钮
      - 图标：编辑图标
      - 权限控制：sys:dept:edit
      - 功能：打开部门编辑表单弹窗
    - 删除按钮：
      - 类型：主要链接按钮
      - 图标：删除图标
      - 权限控制：sys:dept:delete
      - 功能：删除部门

### 3.4 部门表单弹窗
- **弹窗类型**：模态对话框
- **标题**：
  - 新增部门：显示"新增部门"
  - 编辑部门：显示"修改部门"
- **宽度**：600px
- **表单字段**：
  - 部门名称：
    - 类型：输入框
    - 必填：是
    - 校验：不能为空
  - 上级部门：
    - 类型：树形选择器
    - 必填：是
    - 数据源：部门树数据
    - 校验：不能为空
  - 排序：
    - 类型：数字输入框
    - 必填：是
    - 默认值：1
    - 校验：必须为数字
  - 状态：
    - 类型：单选框组
    - 选项：正常(1)、禁用(0)
    - 默认值：正常(1)
- **底部按钮**：
  - 确定按钮：提交表单
  - 取消按钮：关闭弹窗

## 4. 交互流程设计

### 4.1 页面加载流程
1. 页面初始化
2. 加载部门树形数据
3. 页面渲染完成

### 4.2 部门查询流程
1. 用户输入查询条件
2. 点击搜索按钮或按回车键
3. 显示加载状态
4. 发送查询请求
5. 接收查询结果
6. 更新部门列表
7. 隐藏加载状态

### 4.3 部门新增流程
1. 点击新增按钮
2. 打开部门表单弹窗
3. 用户填写表单
4. 实时表单验证
5. 点击确定按钮
6. 表单整体验证
7. 显示加载状态
8. 发送新增请求
9. 接收响应结果
10. 关闭弹窗
11. 刷新部门列表
12. 隐藏加载状态
13. 显示操作结果提示

### 4.4 部门编辑流程
1. 点击编辑按钮
2. 打开部门表单弹窗
3. 加载部门详细信息
4. 用户修改表单
5. 实时表单验证
6. 点击确定按钮
7. 表单整体验证
8. 显示加载状态
9. 发送更新请求
10. 接收响应结果
11. 关闭弹窗
12. 刷新部门列表
13. 隐藏加载状态
14. 显示操作结果提示

### 4.5 部门删除流程
1. 点击删除按钮
2. 弹出确认对话框
3. 用户确认删除
4. 显示加载状态
5. 发送删除请求
6. 接收响应结果
7. 刷新部门列表
8. 隐藏加载状态
9. 显示操作结果提示

## 5. 状态管理设计

### 5.1 页面状态
- **加载状态**：页面数据加载中，显示加载动画
- **空状态**：无部门数据，显示空状态提示
- **错误状态**：数据加载失败，显示错误提示

### 5.2 表单状态
- **初始状态**：表单字段为空，校验未触发
- **输入状态**：用户正在输入，实时校验进行中
- **校验通过状态**：所有字段校验通过
- **校验失败状态**：存在字段校验失败，显示错误信息

### 5.3 按钮状态
- **默认状态**：正常可点击状态
- **禁用状态**：条件不满足时禁用
- **加载状态**：请求处理中，显示加载动画

## 6. 校验规则设计

### 6.1 表单校验规则
- **部门名称**：
  - 必填校验：不能为空
- **上级部门**：
  - 必填校验：不能为空
- **排序**：
  - 必填校验：不能为空
  - 数字校验：必须为数字

## 7. 权限控制设计

### 7.1 按钮权限控制
- **新增按钮**：权限标识 sys:dept:add
- **编辑按钮**：权限标识 sys:dept:edit
- **删除按钮**：权限标识 sys:dept:delete

### 7.2 数据权限控制
- 用户只能查看和操作其数据权限范围内的部门数据

## 8. 响应式设计

### 8.1 屏幕适配
- **大屏幕（≥1200px）**：完整布局展示
- **中等屏幕（992px-1199px）**：完整布局展示
- **小屏幕（<992px）**：
  - 表格支持横向滚动
  - 按钮适当缩小或堆叠显示

### 8.2 组件适配
- 表单弹窗在小屏幕下自动调整宽度
- 表格列在小屏幕下支持横向滚动查看

## 9. 用户体验优化

### 9.1 操作反馈
- 所有异步操作提供加载状态提示
- 操作成功/失败提供消息提示
- 表单校验提供实时错误提示

### 9.2 性能优化
- 部门树支持懒加载
- 图片和静态资源CDN加速

### 9.3 交互优化
- 支持键盘快捷操作
- 表单支持回车提交
- 搜索支持防抖处理
