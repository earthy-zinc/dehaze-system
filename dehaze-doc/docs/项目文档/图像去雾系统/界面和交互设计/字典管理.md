# 字典管理模块

## 1. 概述

### 1.1 文档目的
本文档详细描述图像去雾系统字典管理模块的界面设计和交互规范，涵盖页面布局、组件设计、交互流程和状态管理等方面。

### 1.2 适用范围
本文档适用于字典管理模块的前端开发、UI设计和测试人员，确保界面实现的一致性和用户体验的统一性。

### 1.3 设计原则
本文档遵循《总体界面和交互设计文档》中定义的设计原则，包括一致性、可用性、可访问性和响应式设计等原则。

## 2. 页面结构设计

### 2.1 整体布局
字典管理页面采用单栏布局，主要内容区域包含字典类型列表和字典数据管理功能。

## 3. 组件详细设计

### 3.1 字典类型搜索表单组件
- **类型名称输入框**：
  - 占位符："字典名称"
  - 支持回车键触发搜索
  - 清空按钮
- **类型编码输入框**：
  - 占位符："字典编码"
  - 支持回车键触发搜索
  - 清空按钮
- **搜索按钮**：
  - 类型：主要按钮
  - 图标：搜索图标
  - 功能：触发字典类型列表查询
- **重置按钮**：
  - 类型：默认按钮
  - 图标：刷新图标
  - 功能：清空搜索条件并重新查询

## 4. 交互流程设计

### 4.1 页面加载流程
1. 页面初始化
2. 加载字典类型列表数据（第一页）
3. 页面渲染完成

### 4.2 字典类型查询流程
1. 用户输入查询条件
2. 点击搜索按钮或按回车键
3. 显示加载状态
4. 发送查询请求
5. 接收查询结果
6. 更新字典类型列表
7. 隐藏加载状态

### 4.3 字典类型新增流程
1. 点击新增按钮
2. 打开字典类型表单弹窗

4. 实时表单验证
5. 点击确定按钮

## 5. 状态管理设计

### 5.1 页面状态
- **加载状态**：页面数据加载中，显示加载动画
- **空状态**：无字典类型数据，显示空状态提示
- **错误状态**：数据加载失败，显示错误提示

### 5.2 表单状态
- **初始状态**：表单字段为空，校验未触发
- **输入状态**：用户正在输入，实时校验进行中
- **校验通过状态**：所有字段校验通过
- **校验失败状态**：存在字段校验失败，显示错误信息

### 5.3 按钮状态
- **默认状态**：正常可点击状态
- **禁用状态**：条件不满足时禁用（如删除按钮在无选中数据时）
- **加载状态**：请求处理中，显示加载动画

## 6. 校验规则设计

### 6.1 字典类型表单校验规则
- **字典名称**：
  - 必填校验：不能为空
- **字典编码**：
  - 必填校验：不能为空
  - 唯一性校验：在系统中必须唯一

### 6.2 字典数据表单校验规则
- **字典标签**：
  - 必填校验：不能为空
- **字典键值**：
  - 必填校验：不能为空
- **字典排序**：
  - 必填校验：不能为空
  - 数字校验：必须为数字

## 7. 权限控制设计

### 7.1 按钮权限控制
- **字典类型新增按钮**：权限标识 sys:dict:type:add
- **字典类型编辑按钮**：权限标识 sys:dict:type:edit
- **字典类型删除按钮**：权限标识 sys:dict:type:delete
- **字典数据新增按钮**：权限标识 sys:dict:data:add
- **字典数据编辑按钮**：权限标识 sys:dict:data:edit
- **字典数据删除按钮**：权限标识 sys:dict:data:delete

### 7.2 数据权限控制
- 用户只能查看和操作其权限范围内的字典数据

## 8. 响应式设计

### 8.1 屏幕适配
- **大屏幕（≥1200px）**：完整布局展示
- **中等屏幕（992px-1199px）**：完整布局展示
- **小屏幕（<992px）**：
  - 表格支持横向滚动
  - 按钮适当缩小或堆叠显示

### 8.2 组件适配
- 表单弹窗在小屏幕下自动调整宽度
- 表格列在小屏幕下支持横向滚动查看

## 9. 用户体验优化

### 9.1 操作反馈
- 所有异步操作提供加载状态提示
- 操作成功/失败提供消息提示
- 表单校验提供实时错误提示

### 9.2 性能优化
- 表格虚拟滚动支持大数据量展示
- 图片和静态资源CDN加速

### 9.3 交互优化
- 支持键盘快捷操作
- 表单支持回车提交
- 搜索支持防抖处理
