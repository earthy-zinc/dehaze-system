移动端字体大小规范

1. 基础字体设置
基准字体大小： 16px
行高：22.4px 为字体大小的 1.4 倍
2. 字体层级规范
用途 字体大小 说明
特大标题 32px 页面大标题
主标题 22px 页面主要标题
副标题 18px 内容区域标题
正文 16px 主要内容文本
辅助信息 14px 注释、说明等
小字提示 12px 标签、时间等
3. 字体粗细规范
常规文本：font-weight: 400
重要文本：font-weight: 500-600
强调文本：font-weight: 700
4. 颜色规范
主要内容：#333 或 #212121
次要内容：#666 或 #757575
辅助信息：#999 或 #BDBDBD
提示信息：#CCC 或 #E0E0E0
5. 行间距规范
段落行高：28.8px 字体大小的 1.8 倍
列表行高：22.4px 字体大小的 1.4 倍
