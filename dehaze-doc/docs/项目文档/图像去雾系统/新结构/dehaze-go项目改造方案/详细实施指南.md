## 2. Phase 1：Repository 层实现

### 2.1 Repository 接口定义

**文件**：`internal/repository/interfaces.go`

**设计原则**：
- 每个实体对应一个 Repository 接口
- 方法签名使用 `context.Context` 作为第一个参数
- 查询方法返回指针或切片，未找到记录返回 `nil` 而非 error
- 统一处理软删除条件（`deleted = 0`）

**典型示例**（用户仓储）：

```go
package repository

import (
    "context"
    "github.com/earthyzinc/dehaze-go/internal/model"
)

type IUserRepository interface {
    FindByID(ctx context.Context, id int64) (*model.SysUser, error)
    FindByUsername(ctx context.Context, username string) (*model.SysUser, error)
    List(ctx context.Context, query *UserQuery) ([]*model.SysUser, int64, error)
    Create(ctx context.Context, user *model.SysUser) error
    Update(ctx context.Context, user *model.SysUser) error
    Delete(ctx context.Context, id int64) error
}

type UserQuery struct {
    Keywords string
    Status   *int
    DeptID   *int64
    PageNum  int
    PageSize int
}
```

其他 Repository（Role、Dataset、Menu 等）参照此模式定义。

### 2.2 Repository 实现

**文件**：`internal/repository/user_repo.go`

**实现原则**：
- 私有结构体，通过构造函数返回接口类型
- 封装 GORM 操作细节，对外暴露简洁 API
- 统一处理软删除、分页、排序逻辑
- 记录不存在返回 `nil, nil` 而非 error

```go
package repository

import (
    "context"
    "errors"
    "gorm.io/gorm"
    "github.com/earthyzinc/dehaze-go/internal/model"
)

type userRepository struct {
    db *gorm.DB
}

func NewUserRepository(db *gorm.DB) IUserRepository {
    return &userRepository{db: db}
}

func (r *userRepository) FindByID(ctx context.Context, id int64) (*model.SysUser, error) {
    var user model.SysUser
    err := r.db.WithContext(ctx).Where("id = ? AND deleted = 0", id).First(&user).Error
    if errors.Is(err, gorm.ErrRecordNotFound) {
        return nil, nil
    }
    return &user, err
}

func (r *userRepository) List(ctx context.Context, query *UserQuery) ([]*model.SysUser, int64, error) {
    var users []*model.SysUser
    var total int64
    db := r.db.WithContext(ctx).Model(&model.SysUser{}).Where("deleted = 0")
    
    if query.Keywords != "" {
        db = db.Where("username LIKE ? OR nickname LIKE ?", "%"+query.Keywords+"%", "%"+query.Keywords+"%")
    }
    if query.Status != nil {
        db = db.Where("status = ?", *query.Status)
    }
    
    if err := db.Count(&total).Error; err != nil {
        return nil, 0, err
    }
    
    offset := (query.PageNum - 1) * query.PageSize
    err := db.Offset(offset).Limit(query.PageSize).Order("create_time DESC").Find(&users).Error
    return users, total, err
}
```

## 3. Phase 2：Cache 层实现

### 3.1 Cache 接口定义

**文件**：`internal/cache/interfaces.go`

**设计原则**：
- 统一的缓存操作契约，支持多种后端实现
- 键不存在时返回空字符串而非 error
- 支持 TTL、批量操作、分布式锁

```go
package cache

import (
    "context"
    "time"
)

type ICacheService interface {
    Get(ctx context.Context, key string) (string, error)
    Set(ctx context.Context, key string, value string, ttl time.Duration) error
    Del(ctx context.Context, key string) error
    Exists(ctx context.Context, key string) (bool, error)
    Lock(ctx context.Context, key string, ttl time.Duration) (bool, error)
    Unlock(ctx context.Context, key string) error
}
```

### 3.2 Cache 实现

**生产环境**：`internal/cache/redis_cache.go`

```go
type redisCache struct {
    client redis.UniversalClient
}

func NewRedisCache(client redis.UniversalClient) ICacheService {
    return &redisCache{client: client}
}

func (c *redisCache) Get(ctx context.Context, key string) (string, error) {
    result, err := c.client.Get(ctx, key).Result()
    if err == redis.Nil {
        return "", nil
    }
    return result, err
}
```

**测试环境**：`internal/cache/memory_cache.go`

测试时使用内存实现，避免依赖 Redis。

## 4. Phase 3：Service 层改造

### 4.1 Service 接口定义

**文件**：`service/interfaces.go`

**设计原则**：
- 定义业务服务契约，供 API 层依赖
- 方法命名体现业务语义，而非 CRUD
- 返回 VO/BO 而非实体

```go
package service

type IUserService interface {
    Login(ctx context.Context, username, password string) (*model.UserAuthInfo, error)
    GetUserByID(ctx context.Context, id int64) (*vo.UserVO, error)
    ListPagedUsers(ctx context.Context, query *UserPageQuery) (*PageResult[vo.UserVO], error)
    CreateUser(ctx context.Context, form *bo.UserFormBO) error
    UpdateUser(ctx context.Context, form *bo.UserFormBO) error
    DeleteUser(ctx context.Context, id int64) error
}
```

### 4.2 Service 改造示例

**改造前**（旧代码，将被删除）：

```go
type UserService struct{}  // 空结构体

func (s *UserService) Login(u *model.SysUser) (*model.UserAuthInfo, error) {
    err := global.DB.Where("username = ?", u.Username).First(u).Error  // ❌ 直接依赖全局变量
}
```

**改造后**：

```go
type UserService struct {
    userRepo repository.IUserRepository
    roleRepo repository.IRoleRepository
    cache    cache.ICacheService
    logger   *zap.Logger
}

func NewUserService(
    userRepo repository.IUserRepository,
    roleRepo repository.IRoleRepository,
    cache cache.ICacheService,
    logger *zap.Logger,
) *UserService {
    return &UserService{userRepo: userRepo, roleRepo: roleRepo, cache: cache, logger: logger}
}

func (s *UserService) Login(ctx context.Context, username, password string) (*model.UserAuthInfo, error) {
    user, err := s.userRepo.FindByUsername(ctx, username)  // ✅ 使用注入的 Repository
    if err != nil {
        s.logger.Error("查询用户失败", zap.Error(err))
        return nil, fmt.Errorf("系统错误")
    }
    if user == nil {
        return nil, errors.New("用户不存在")
    }
    
    if err := bcrypt.CompareHashAndPassword([]byte(user.Password), []byte(password)); err != nil {
        return nil, errors.New("密码错误")
    }
    
    roles, _ := s.roleRepo.FindByUserID(ctx, user.ID)
    // ... 构建返回结果
}
```

## 5. Phase 4：API 层改造

### 5.1 改造原则

- API 结构体依赖 Service **接口**类型
- 通过构造函数注入 Service 实例
- Router 从 Container 获取 API 实例

### 5.2 改造示例

```go
// api/user_api.go
type SysUserApi struct {
    userService service.IUserService  // ✅ 依赖接口
}

func NewSysUserApi(userService service.IUserService) *SysUserApi {
    return &SysUserApi{userService: userService}
}

func (api *SysUserApi) ListPagedUsers(c *gin.Context) {
    var query service.UserPageQuery
    if err := c.ShouldBindQuery(&query); err != nil {
        common.FailWithMessage("参数错误", c)
        return
    }
    
    result, err := api.userService.ListPagedUsers(c.Request.Context(), &query)
    if err != nil {
        common.FailWithMessage("查询失败", c)
        return
    }
    
    common.OkWithDetailed(result, "查询成功", c)
}
```

## 6. Phase 5：依赖容器与启动

### 6.1 依赖容器

**文件**：`internal/container/container.go`

```go
package container

type Container struct {
    DB     *gorm.DB
    Redis  redis.UniversalClient
    Logger *zap.Logger

    UserRepo    repository.IUserRepository
    RoleRepo    repository.IRoleRepository
    CacheService cache.ICacheService

    UserService service.IUserService
    RoleService service.IRoleService

    UserApi *api.SysUserApi
    RoleApi *api.SysRoleApi
}

func NewContainer(db *gorm.DB, redis redis.UniversalClient, logger *zap.Logger) *Container {
    c := &Container{DB: db, Redis: redis, Logger: logger}

    // Repository
    c.UserRepo = repository.NewUserRepository(db)
    c.RoleRepo = repository.NewRoleRepository(db)
    c.CacheService = cache.NewRedisCache(redis)

    // Service
    c.UserService = service.NewUserService(c.UserRepo, c.RoleRepo, c.CacheService, logger)
    c.RoleService = service.NewRoleService(c.RoleRepo, c.CacheService, logger)

    // API
    c.UserApi = api.NewSysUserApi(c.UserService)
    c.RoleApi = api.NewSysRoleApi(c.RoleService)

    return c
}
```

### 6.2 main.go 改造

```go
func main() {
    // 初始化基础设施
    db := initialize.InitGorm()
    redis := initialize.InitRedis()
    logger := initialize.InitZap()

    // 创建依赖容器
    container := container.NewContainer(db, redis, logger)

    // 初始化路由（传入容器）
    router := initialize.InitRouter(container)

    // 启动服务
    initialize.RunServer(router)
}
```
