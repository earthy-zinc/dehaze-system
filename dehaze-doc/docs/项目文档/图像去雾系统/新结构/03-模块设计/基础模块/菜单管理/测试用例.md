## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **角色数据** | 系统管理员角色 | 用于权限验证测试 |
| **菜单数据** | 完整的5级菜单树结构 | 用于层级限制、子菜单检查测试 |
| **菜单数据** | 各类型菜单（目录/菜单/按钮/外链） | 用于菜单类型条件字段测试 |

### 3.2 数据清理策略

- 测试菜单数据使用统一前缀 `test_menu_` 标识
- 测试结束后按前缀批量删除测试菜单
- 保留系统默认菜单（如系统管理根目录）不做删除操作
- 测试后清理角色-菜单关联表数据

### 3.3 测试范围

**包含的功能点：**
- 菜单列表查询（树形结构、关键字搜索）
- 菜单新增（四种菜单类型）
- 菜单编辑
- 菜单删除（含子菜单检查）
- 菜单显示控制
- 菜单排序
- 菜单下拉选项
- 路由列表生成

**不包含的功能点：**
- 角色管理功能（独立测试）
- 用户角色关联（角色管理模块测试）
- 权限验证中间件（系统架构层测试）

## 6. 关键边界与异常场景

| 场景 | 测试点 | 期望行为 |
|------|--------|---------|
| **菜单树深度** | 层级超过5级 | 禁止新增，提示层级限制 |
| **菜单数量** | 单次返回1000+菜单 | 性能测试：响应时间 < 500ms |
| **并发修改** | 同一菜单被2个请求同时修改 | 乐观锁/事务保护，只一个成功 |
| **层级变更** | 将父菜单的子菜单设为新父菜单 | 校验失败，防止循环引用 |
| **缓存一致性** | 修改菜单后查询 | 缓存立即失效，返回最新数据 |
| **权限唯一性** | 新增菜单权限标识重复 | 校验失败，提示唯一性约束 |
| **角色关联** | 删除已分配给角色的菜单 | 同步删除角色-菜单关联表记录 |
| **路由生成** | 用户无权限访问菜单 | 路由列表不包含该菜单 |

## 8. 安全性测试

| 测试项 | 验证方式 | 预期结果 |
|--------|---------|---------|
| **权限控制** | 无权限用户调用新增/编辑/删除接口 | 返回403 |
| **数据权限** | 用户访问无权限的菜单 | 返回403或数据过滤 |
| **SQL注入** | 参数中包含 `admin'--` | 被参数化查询转义，无SQL注入风险 |
| **XSS攻击** | 菜单名称注入 `<script>alert(1)</script>` | 输出时编码，不执行脚本 |
| **传输安全** | 抓包分析请求 | HTTPS加密传输 |
| **防重复提交** | 快速连续点击提交 | Token机制防护，仅执行一次 |
| **越权访问** | 修改其他角色的菜单关联 | 失败，仅能操作自己有权限的菜单 |

## 9. 数据一致性测试

### 9.1 缓存一致性测试

| 场景 | 验证点 | 期望行为 |
|------|--------|---------|
| **创建菜单后** | 查询菜单列表 | 新菜单立即出现在列表中 |

### 9.2 事务回滚测试

| 场景 | 触发条件 | 验证点 |
|------|---------|--------|
| **数据库错误** | 模拟DB连接断开 | 操作回滚，数据不变 |
| **业务异常** | 校验失败抛异常 | 事务回滚，数据一致 |
| **Panic触发** | 代码运行时错误 | 事务回滚，数据恢复 |
| **多表操作** | 同时更新菜单表和关联表 | 全部成功或全部回滚 |

### 9.3 数据完整性测试
