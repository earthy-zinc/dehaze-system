## 3. 测试前置

### 3.1 测试数据

| 数据类型 | 准备内容 | 说明 |
|---------|---------|------|
| **测试文件** | 不同大小、类型的文件 | 用于上传测试 |
| **重复文件** | MD5 相同的文件 | 用于去重测试 |
| **大文件** | 接近上限的文件（如 90MB） | 用于边界测试 |
| **超限文件** | 超过上限的文件（如 110MB） | 用于异常测试 |

### 3.2 数据清理策略

- 测试上传的文件使用统一前缀标识
- 测试结束后清理测试创建的文件元数据和物理文件
- MinIO 测试桶与生产桶隔离

### 3.3 测试范围

**包含的功能点：**
- 文件上传（含 MD5 去重）
- 文件下载
- 文件删除
- MD5 校验
- 文件分页查询
- 文件详情查询

**不包含的功能点：**
- 业务模块的文件权限控制（各业务模块独立测试）
- WPX 格式转换（可选扩展功能）

## 7. 性能测试

### 7.1 性能指标

> 性能目标参见 [需求规格.md](./需求规格.md) 第 1.3 节

| 指标 | 目标值 | 测试方法 |
|------|--------|---------|
| **上传响应时间** | <3s | 10MB 文件上传（含 MD5 计算） |

| **MD5 查询响应时间** | <100ms | MD5 校验接口 |
| **列表查询响应时间** | <300ms | 分页查询（10条/页） |

| 场景 | 并发数 | 验证点 |

## 8. 安全性测试

| 测试项 | 验证方式 | 预期结果 |
|--------|---------|---------|
| **路径遍历防护** | objectName 包含 `../` | 请求被拒绝 |
| **文件名注入** | 文件名包含特殊字符 | 正确处理，无安全风险 |
| **MIME 类型校验** | 伪装文件类型 | 按实际内容判断（若配置） |
| **文件大小校验** | 超大文件上传 | 上传被拒绝 |
| **访问控制** | 未登录访问接口 | 返回 401 |
