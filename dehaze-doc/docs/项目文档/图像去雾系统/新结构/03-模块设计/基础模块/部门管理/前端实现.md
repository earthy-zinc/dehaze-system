# 部门管理模块 - 前端实现设计

## 1. 文档概述

本文档描述部门管理模块的前端实现方案，包括组件设计、状态管理、API调用、交互流程等实现细节，为前端开发提供指导。

## 2. 组件架构设计

### 2.1 组件层次结构

```
部门管理页面 (DeptManagement/index.vue)
├── 搜索容器
│   ├── 搜索表单 (SearchForm)
│   │   ├── 部门名称输入框
│   │   ├── 状态选择器
│   │   ├── 搜索按钮
│   │   └── 重置按钮
│   └── 操作按钮区域 (ActionButtons)
│       └── 新增按钮
└── 数据展示区域
    └── 部门表格 (DeptTable)
        └── 树形结构表格组件
```

### 2.2 弹窗组件结构

```
弹窗组件 (DeptDialog)
└── 部门表单弹窗 (DeptFormDialog)
    └── 部门表单 (DeptForm)
        ├── 部门名称输入框
        ├── 上级部门选择器（树形选择）
        ├── 排序输入框
        └── 状态单选框组
```

### 2.3 组件职责划分

| 组件名称 | 职责描述 | 复用性 |
|---------|---------|--------|
| **SearchForm** | 搜索条件输入与提交 | 页面内部组件 |
| **ActionButtons** | 操作按钮区域，统一管理权限控制 | 页面内部组件 |
| **DeptTable** | 部门数据树形表格展示与行操作 | 页面内部组件 |
| **DeptFormDialog** | 部门新增/编辑表单弹窗 | 页面内部组件 |

## 3. 页面布局设计

### 3.1 整体布局

部门管理页面采用**单栏布局**，主要内容区域包含搜索条件、操作按钮和部门数据表格。

| 区域 | 高度 | 说明 |
|------|------|------|
| **搜索区域** | 自适应 | 搜索表单 + 操作按钮 |
| **表格区域** | 自适应填充 | 部门树形数据表格 |

### 3.2 响应式布局

| 屏幕尺寸 | 布局调整 |
|---------|---------|
| **≥1200px** | 完整布局展示 |
| **992px~1199px** | 完整布局展示 |
| **<992px** | 表格支持横向滚动，按钮适当缩小或堆叠显示 |

## 5. 状态管理设计

### 5.1 页面状态

| 状态字段 | 类型 | 初始值 | 说明 |
|---------|------|--------|------|
| loading | Boolean | false | 页面加载状态 |
| deptList | Array | [] | 部门树形列表数据 |
| deptOptions | Array | [] | 部门下拉选项数据 |

### 5.2 查询参数状态

| 状态字段 | 类型 | 初始值 | 说明 |
|---------|------|--------|------|
| name | String | '' | 部门名称 |
| status | Number | undefined | 部门状态 |

### 5.3 弹窗状态

| 状态字段 | 类型 | 初始值 | 说明 |
|---------|------|--------|------|
| visible | Boolean | false | 弹窗可见性 |
| type | String | 'dept-form' | 弹窗类型 |
| title | String | '' | 弹窗标题 |
| width | Number | 600 | 弹窗宽度 |
| loading | Boolean | false | 提交加载状态 |

### 5.4 表单数据状态

| 状态字段 | 类型 | 初始值 | 说明 |
|---------|------|--------|------|
| id | Number | null | 部门 ID（编辑时） |
| name | String | '' | 部门名称 |
| parentId | Number | null | 上级部门 ID |
| sort | Number | 1 | 排序值 |
| status | Number | 1 | 状态（1=启用） |

### 5.5 状态定义示例

```typescript
// 页面状态
const state = reactive({
  loading: false,           // 加载状态
  queryParams: {            // 查询参数
    name: "",
    status: undefined
  },
  deptList: [],             // 部门列表数据
  deptOptions: []           // 部门下拉选项
});

// 弹窗状态
const dialog = reactive({
  visible: false,           // 弹窗可见性
  type: "dept-form",        // 弹窗类型
  width: 600,               // 弹窗宽度
  title: ""                 // 弹窗标题
});

// 表单数据
const formData = reactive<DeptForm>({
  sort: 1,                  // 默认排序为1
  status: 1                 // 默认状态为启用
});
```

## 6. API 调用设计

### 6.1 API 接口封装

使用 `dehaze-sdk-js` 提供的 DeptAPI 进行接口调用：

| 方法 | 功能 | 参数 |
|------|------|------|
| DeptAPI.getList | 获取部门列表 | queryParams |
| DeptAPI.getOptions | 获取部门下拉选项 | - |
| DeptAPI.add | 新增部门 | formData |
| DeptAPI.getFormData | 获取部门表单数据 | deptId |
| DeptAPI.update | 修改部门 | deptId, formData |
| DeptAPI.deleteByIds | 删除部门 | deptIds |

## 7. 交互流程设计

> **交互规范**：详见 [需求规格.md](./需求规格.md) 第 3 节

### 7.1 页面初始化流程

1. 进入页面，显示加载状态
2. 请求部门树形列表数据
3. 数据加载完成，默认展开所有节点

### 7.2 关键流程说明

| 流程 | 关键点 |
|------|--------|
| 部门新增 | 加载部门下拉选项 → 填写表单 → 提交 → 刷新列表 |
| 新增下级 | parentId 自动填充当前部门 → 填写其他字段 → 提交 → 刷新列表 |
| 部门编辑 | 并行加载下拉选项和详情 → 修改 → 提交 → 刷新列表 |
| 部门删除 | 确认对话框 → 关联检查 → 删除 → 刷新列表 |
