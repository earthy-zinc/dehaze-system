# 部门管理模块需求规格

## 1. 模块概述

### 1.1 模块定位

部门管理模块是图像去雾系统后台管理系统的核心基础模块之一，负责维护和管理系统中的组织架构部门结构。该模块提供完整的部门增删改查功能，支持部门的树形层级结构管理，为用户管理提供部门归属信息，并为角色管理模块提供数据权限控制的基础支撑。

### 1.2 核心价值

| 价值维度 | 具体内容 |
|---------|---------|
| **组织管理** | 提供企业组织架构的统一管理入口，实现部门全生命周期管理 |
| **层级结构** | 支持多层级树形部门结构，适应不同企业组织形态 |
| **数据支撑** | 为用户管理和角色数据权限提供组织基础数据 |
| **灵活配置** | 支持部门排序、状态控制等灵活配置选项 |
| **高效管理** | 提供直观的树形管理界面，快速定位和操作部门 |

### 1.3 用户角色分析

#### 主要用户角色

| 角色 | 描述 | 主要职责 |
|------|------|---------|
| **系统管理员** | 拥有部门管理模块的所有操作权限 | 部门增删改查、状态管理、排序设置、批量操作 |
| **部门管理员** | 拥有对部门及其下级部门的有限管理权限 | 查看部门、新增下级部门、编辑本部门及下级部门、管理状态和排序 |

#### 用户特征与需求

| 角色 | 特征描述 | 核心需求 |
|------|---------|---------|
| **系统管理员** | 具备专业的系统管理知识，熟悉组织架构管理操作流程 | 直观的树形部门管理界面、快速批量操作、完整的操作日志 |
| **部门管理员** | 了解本部门组织架构，具备基本的部门管理能力 | 管理本部门及下级部门信息、便捷的新增下级部门功能 |

#### 权限矩阵

| 功能点 | 系统管理员 | 部门管理员 | 普通用户 |
|--------|-----------|-----------|---------|
| 查看所有部门 | ✅ | ✅ | ❌ |
| 新增部门 | ✅ | ✅ (仅下级部门) | ❌ |
| 编辑部门 | ✅ | ✅ (本部门及下级部门) | ❌ |
| 删除部门 | ✅ | ❌ | ❌ |
| 状态管理 | ✅ | ✅ (本部门及下级部门) | ❌ |
| 排序设置 | ✅ | ✅ (本部门及下级部门) | ❌ |
| 查看部门列表 | ✅ | ✅ | ❌ |

### 1.4 模块依赖关系

#### 依赖模块

| 模块 | 依赖说明 |
|------|---------|
| **字典管理模块** | 部门状态等信息需要字典数据支持 |
| **权限管理模块** | 部门操作权限需要权限系统支持 |

#### 被依赖模块

| 模块 | 依赖说明 |
|------|---------|
| **用户管理模块** | 用户需要关联到具体部门，部门下拉选项供用户分配使用 |
| **角色管理模块** | 角色数据权限需要部门信息支持，数据权限按部门范围控制 |
| **其他业务模块** | 按部门范围进行数据隔离和权限控制的模块 |

## 2. 功能需求

### 2.1 部门列表查询 (F-DM-001)

#### 功能描述

提供部门信息的树形展示和多条件筛选能力，支持管理员快速定位目标部门。

#### 查询条件

| 条件类型 | 字段 | 说明 | 匹配方式 |
|---------|------|------|---------|
| **部门名称** | keywords | 部门名称关键字 | LIKE |
| **状态** | status | 部门状态 | = (启用/禁用) |

#### 列表展示字段

| 字段 | 显示名称 | 宽度 | 说明 |
|------|---------|------|------|
| name | 部门名称 | 自动 | 树形结构展示，支持展开/收起 |
| status | 状态 | 100px | 启用/禁用标签 |
| sort | 排序 | 100px | 部门显示顺序 |
| createTime | 创建时间 | 180px | 部门创建时间 |
| - | 操作 | 220px | 新增下级/编辑/删除 |

#### 业务规则

1. 部门列表以树形结构展示，支持多级层级
2. 树形结构支持最多5级深度
3. 支持节点的展开和收起操作
4. 查询响应时间不超过500ms
5. 支持至少100个部门的信息管理

### 2.2 部门新增 (F-DM-002)

#### 功能描述

支持创建新部门，包括基本信息设置、上级部门分配和排序设置。

#### 表单字段

| 字段 | 显示名称 | 类型 | 必填 | 默认值 | 校验规则 |
|------|---------|------|------|--------|---------|
| name | 部门名称 | 输入框 | ✅ | - | 不能为空，同一层级下唯一 |
| parentId | 上级部门 | 树形选择器 | ✅ | - | 不能为空 |
| sort | 排序 | 数字输入框 | ✅ | 1 | 必须为数字 |
| status | 状态 | 单选框组 | ✅ | 启用(1) | 不能为空 |

#### 业务规则

1. **部门名称唯一性**：同一层级下部门名称必须唯一
2. **上级部门**：必须选择一个上级部门（根部门除外）
3. **排序默认值**：新部门排序默认为1
4. **状态默认值**：新部门默认为启用状态
5. **快速新增**：支持在现有部门下快速新增下级部门
6. **权限控制**：系统管理员可在任意部门下新增子部门；部门管理员仅可在本部门及下级部门下新增子部门

### 2.3 部门编辑 (F-DM-003)

#### 功能描述

支持修改现有部门的基本信息、上级部门和状态。

#### 可编辑字段

| 字段 | 是否可编辑 | 说明 |
|------|-----------|------|
| name | ✅ | 可随时修改（需检查唯一性） |
| parentId | ✅ | 支持部门层级调整 |
| sort | ✅ | 可修改排序值 |
| status | ✅ | 可启用/禁用 |

#### 业务规则

1. **部门名称**：修改时需检查同一层级下名称是否唯一
2. **上级部门**：不能选择自身或其子部门作为上级部门，防止循环引用
3. **即时生效**：修改保存后立即生效
4. **根部门保护**：系统内置根部门不可修改上级部门
5. **权限控制**：系统管理员可编辑所有部门；部门管理员仅可编辑本部门及下级部门

### 2.4 部门删除 (F-DM-004)

#### 功能描述

支持删除部门，包括单个删除。

#### 删除方式

| 方式 | 触发操作 | 说明 |
|------|---------|------|
| **单个删除** | 点击操作列删除按钮 | 删除单个部门 |

#### 业务规则

1. **二次确认**：删除操作需弹窗确认
2. **关联用户检查**：删除前需检查部门及子部门下是否存在关联用户
3. **级联删除**：删除部门时是否级联删除子部门（待确认）
4. **根部门保护**：系统内置根部门不可删除
5. **物理删除**：执行物理删除，数据不可恢复

#### 确认提示

- 存在关联用户：无法删除，提示"该部门下存在用户，无法删除"
- 无关联用户："确认删除部门「{deptName}」吗？删除后不可恢复。"

### 2.5 新增下级部门 (F-DM-005)

#### 功能描述

支持在当前部门下快速新增子部门。

#### 操作流程

```
点击新增下级按钮 → 打开部门表单弹窗 → 上级部门自动填充当前部门 → 用户填写信息 → 提交保存
```

#### 业务规则

1. **上级部门预设**：表单中的上级部门自动设置为当前选中部门
2. **规则继承**：其他业务规则与普通新增部门一致

### 2.6 部门状态管理 (F-DM-006)

#### 功能描述

支持启用或禁用部门，控制该部门下用户的访问权限。

#### 状态说明

| 状态值 | 显示 | 说明 |
|--------|------|------|
| 1 | 启用（绿色标签） | 部门正常使用 |
| 0 | 禁用（灰色标签） | 部门暂停使用 |

#### 业务规则

1. **状态切换**：可通过编辑表单或状态开关切换状态
2. **即时生效**：状态变更后立即生效
3. **用户影响**：禁用部门后，该部门下用户的访问权限可能受影响（待确认）
4. **级联影响**：是否级联影响子部门（待确认）
5. **权限控制**：系统管理员可管理所有部门状态；部门管理员仅可管理本部门及下级部门的状态

### 2.7 部门排序设置 (F-DM-007)

#### 功能描述

支持设置部门的显示顺序，控制部门树中的排列顺序。

#### 排序规则

1. **排序字段**：整数类型
2. **排序依据**：按sort字段升序排列
3. **同级排序**：同一层级下按sort值排序
4. **默认值**：新增部门默认排序为1

#### 业务规则

1. **实时生效**：排序修改后立即生效
2. **灵活调整**：支持任意排序值调整
3. **自动排序**：同部门下按sort值自动排序
4. **权限控制**：系统管理员可设置所有部门的排序；部门管理员仅可设置本部门及下级部门的排序

### 2.8 部门下拉选项 (F-DM-008)

#### 功能描述

提供部门树形下拉选项，供用户管理等模块使用。

#### 数据格式

| 字段 | 说明 |
|------|------|
| value | 部门ID |
| label | 部门名称 |
| children | 子部门数组（递归） |

#### 使用场景

1. 用户新增/编辑时选择所属部门
2. 角色数据权限配置时选择数据范围
3. 其他需要按部门筛选的场景

#### 业务规则

1. **树形结构**：返回完整的部门树形结构
2. **状态过滤**：可配置是否仅返回启用状态的部门
3. **权限过滤**：根据用户数据权限过滤可访问的部门

## 3. 界面交互规范

### 3.1 页面布局

部门管理页面采用**单栏布局**，包含搜索条件区域、操作按钮区域和部门树形数据表格。

### 3.2 交互规则

> 通用 UI 交互规范参见 [01-产品设计/02-UI-UX设计规范.md](../../../01-产品设计/02-UI-UX设计规范.md)

#### 3.2.1 本模块特有交互

| 场景 | 行为 |
|------|------|
| 打开新增表单 | 清空表单数据，默认值：状态=启用，排序=1 |
| 打开编辑表单 | 加载部门详情 |
| 新增下级部门 | 上级部门自动填充为当前选中部门 |
| 树形结构 | 默认展开所有节点，支持展开/收起操作 |

#### 3.2.2 确认提示文案

- 删除确认：`确认删除部门「{deptName}」吗？删除后不可恢复。`
- 存在关联用户：`该部门下存在用户，无法删除。`
- 根部门保护：`根部门不可删除/修改。`

## 4. 安全设计

> **权限标识**：详见 [API接口.md - 权限标识汇总](./API接口.md)

### 4.1 数据权限

| 角色 | 数据范围 |
|------|---------|
| 系统管理员 | 所有部门 |
| 部门管理员 | 本部门及下级部门 |

### 4.2 输入校验

| 校验类型 | 说明 |

| 前端校验 | 表单实时校验 |
| 后端校验 | 参数校验 + 业务校验（名称唯一性、上级部门合法性） |

## 5. 待确认事项

1. **级联删除策略**：删除部门时，是否需要级联删除子部门？
2. **关联用户处理**：删除部门时如存在关联用户，应如何处理？（当前策略是禁止删除）
3. **状态级联影响**：禁用部门后，是否需要级联禁用子部门？是否影响该部门下用户的登录？
4. **部门负责人**：是否需要增加部门负责人字段及相关管理功能？
5. **部门复制功能**：是否需要增加部门复制功能，以便快速创建相似部门结构？
6. **拖拽排序**：是否需要支持部门的拖拽排序功能？
7. **导入导出**：是否需要增加部门导入导出功能？
8. **部门描述**：是否需要增加部门描述字段？
9. **部门代码**：是否需要增加部门编码字段，用于外部系统对接？
10. **虚拟部门**：是否支持创建虚拟部门（用于组织架构展示，不实际分配用户）？
