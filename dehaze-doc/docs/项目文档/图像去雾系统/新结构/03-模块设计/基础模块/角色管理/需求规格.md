# 角色管理模块需求规格

## 1. 模块概述

### 1.1 模块定位

角色管理模块是图像去雾系统权限管理体系的核心组成部分,负责定义和管理系统中的各种角色及其权限。该模块为系统提供完整的角色生命周期管理能力,是整个系统RBAC权限控制的基础。

### 1.2 核心价值

| 价值维度 | 具体内容 |
|---------|---------|
| **统一管理** | 提供系统角色的统一管理入口,实现角色全生命周期管理 |
| **权限控制** | 基于RBAC模型实现细粒度的权限控制,确保系统安全 |
| **灵活分配** | 支持菜单权限和数据权限的灵活配置,适应复杂业务场景 |
| **数据安全** | 通过数据权限范围控制用户可访问的数据,保障数据安全 |

### 1.3 业务目标

#### 功能目标
- 实现系统角色的统一管理(CRUD操作)
- 提供完善的菜单权限分配体系(包括按钮权限)
- 支持数据权限的细粒度控制(全部数据/部门数据/个人数据等)
- 保障系统权限控制的安全性和准确性

#### 性能目标
| 指标 | 目标值 | 说明 |
|------|--------|------|
| **列表查询响应** | <500ms | 角色列表分页查询响应时间 |
| **表单提交响应** | <1s | 新增/编辑角色操作响应时间 |
| **角色容量** | ≥1000 | 系统支持的最大角色数量 |
| **权限分配响应** | <1s | 权限分配操作响应时间 |

## 3. 功能需求

### 3.1 角色列表查询 (F-RM-001)

#### 3.1.1 功能描述

提供角色信息的分页展示和关键字筛选能力,支持管理员快速定位目标角色。

#### 3.1.2 查询条件

| 条件类型 | 字段 | 说明 | 匹配方式 |
|---------|------|------|---------|
| **关键字搜索** | 角色名称 | 模糊匹配 | LIKE |

#### 3.1.3 列表展示字段

| 字段 | 显示名称 | 宽度 | 说明 |
|------|---------|------|------|
| id | 编号 | 100px | 角色唯一标识 |
| name | 角色名称 | 150px | 角色显示名称 |
| code | 角色编码 | 150px | 角色唯一编码 |
| dataScopeLabel | 数据权限 | 180px | 数据权限范围标签 |
| status | 状态 | 80px | 启用/禁用标签 |
| sort | 排序 | 100px | 角色排序 |
| createTime | 创建时间 | 180px | 角色创建时间 |
| - | 操作 | 280px | 状态切换/分配权限/编辑/删除 |

#### 3.1.4 分页配置

| 配置项 | 默认值 | 可选值 |
|--------|--------|--------|
| 每页条数 | 10 | 10/20/50/100 |
| 页码显示 | 当前页/总页数 | - |
| 总数显示 | 共 X 条 | - |

### 3.2 角色新增 (F-RM-002)

#### 3.2.1 功能描述

支持创建新角色,包括基本信息设置、数据权限配置。

#### 3.2.2 表单字段

| 字段 | 显示名称 | 类型 | 必填 | 校验规则 |
|------|---------|------|------|---------|
| name | 角色名称 | 输入框 | ✅ | 不能为空 |
| code | 角色编码 | 输入框 | ✅ | 不能为空,系统唯一 |
| dataScope | 数据权限 | 下拉选择器 | ✅ | 不能为空（选项见 [API接口.md](./API接口.md)） |
| status | 状态 | 单选框组 | ✅ | 默认启用(1) |
| sort | 排序 | 数字输入框 | ✅ | 必须为数字,默认1 |

#### 3.2.3 业务规则

1. **角色名称**: 不能为空,建议唯一
2. **角色编码唯一性**: 系统中角色编码必须唯一,创建时需校验
3. **数据权限**: 必须选择数据权限范围
4. **排序值**: 用于控制角色在列表中的显示顺序

### 3.3 角色编辑 (F-RM-003)

#### 3.3.1 功能描述

支持修改现有角色的基本信息、数据权限等。

#### 3.3.2 可编辑字段

| 字段 | 是否可编辑 | 说明 |
|------|-----------|------|
| name | ✅ | 可随时修改 |
| code | ❌ | 角色编码创建后不可修改 |
| dataScope | ✅ | 支持数据权限变更 |
| status | ✅ | 支持状态变更 |
| sort | ✅ | 可修改 |

#### 3.3.3 业务规则

1. **角色编码只读**: 角色编码一旦创建不可修改
2. **即时生效**: 修改保存后立即生效

### 3.4 角色删除 (F-RM-004)

#### 3.4.1 功能描述

支持删除角色,包括单个删除和批量删除。

#### 3.4.2 删除方式

| 方式 | 触发操作 | 说明 |
|------|---------|------|
| **单个删除** | 点击操作列删除按钮 | 删除单个角色 |
| **批量删除** | 勾选多个后点击批量删除 | 删除选中的所有角色 |

#### 3.4.3 业务规则

1. **二次确认**: 删除操作需弹窗确认
2. **关联检查**: 检查角色是否有关联的用户,如存在则提示无法删除
3. **管理员保护**: 超级管理员角色不可删除(待确认)
4. **物理删除**: 执行物理删除,数据不可恢复

#### 3.4.4 确认提示

- 单个删除:"确认删除角色「{name}」吗?删除后不可恢复。"
- 批量删除:"确认删除选中的 {count} 个角色吗?删除后不可恢复。"
- 存在关联用户:"该角色下已关联用户,无法删除!"

### 3.5 状态管理 (F-RM-005)

#### 3.5.1 功能描述

支持启用或禁用角色,控制用户是否可以使用该角色对应的权限。

#### 3.5.2 状态说明

> **状态枚举**：详见 [API接口.md - 状态枚举](./API接口.md)

#### 3.5.3 业务规则

1. **状态切换**: 可通过状态标签快速切换
2. **即时生效**: 状态变更后立即生效

### 3.6 菜单权限分配 (F-RM-006)

#### 3.6.1 功能描述

支持为角色分配菜单权限(包括页面权限和按钮权限)。

#### 3.6.2 操作流程

点击分配权限 → 打开权限分配弹窗 → 加载菜单权限树 → 回显已分配权限 → 勾选权限 → 保存 → 提示成功

#### 3.6.3 业务规则

1. **树形结构**: 菜单权限以树形结构展示,支持展开/收起
2. **全选支持**: 支持父节点选择时自动勾选所有子节点
3. **即时保存**: 点击确定后立即保存权限分配
4. **权限覆盖**: 每次分配时覆盖原有权限

### 3.7 数据权限配置 (F-RM-007)

#### 3.7.1 功能描述

支持配置角色的数据访问范围,实现数据级别的权限控制。

#### 3.7.2 数据权限选项

> **数据权限 SSOT**：详见 [API接口.md - 数据权限选项](./API接口.md)

#### 3.7.3 业务规则

1. **默认值**: 新建角色默认为"本部门数据"(2)
2. **权限继承**: 用户拥有多个角色时,取最大权限范围
3. **生效机制**: 在查询业务数据时根据数据权限范围自动过滤

## 4. 界面交互规范

### 4.1 页面布局

角色管理页面采用**单栏布局**，包含搜索条件区域、操作按钮区域、角色数据表格和分页组件。

### 4.2 交互规则

> 通用 UI 交互规范参见 [01-产品设计/02-UI-UX设计规范.md](../../../01-产品设计/02-UI-UX设计规范.md)

#### 4.2.1 本模块特有交互

| 场景 | 行为 |
|------|------|
| 打开新增表单 | 清空表单数据，默认值：状态=启用，排序=1，数据权限=本部门 |
| 打开编辑表单 | 加载角色详情，角色编码字段只读 |
| 状态切换 | 点击 Switch 开关直接切换，需 `sys:role:edit` 权限 |
| 权限分配 | 打开弹窗后加载菜单树，回显已分配权限 |

#### 4.2.2 确认提示文案

- 单个删除：`确认删除角色「{name}」吗？删除后不可恢复。`
- 批量删除：`确认删除选中的 {count} 个角色吗？删除后不可恢复。`
- 存在关联用户：`该角色下已关联用户，无法删除！`

## 5. 安全设计

### 5.1 权限控制

> **权限标识**：详见 [API接口.md - 权限标识定义](./API接口.md)

### 5.2 数据安全

| 安全措施 | 说明 |
|---------|------|
| **权限验证** | 基于RBAC模型实现细粒度权限控制 |

| 校验类型 | 说明 |
|---------|------|
| **前端校验** | 表单实时校验,提升用户体验 |
| **后端校验** | 使用Validation注解进行参数校验 |
| **唯一性校验** | 角色编码唯一性校验 |
| **长度校验** | 字段最大长度限制 |
