# 效果对比模块需求规格

## 1. 模块概述

### 1.1 模块定位

效果对比模块是用户评估去雾效果的核心工具，承接去雾处理模块的输出结果，提供多种对比方式和专业评估指标，帮助用户全面了解处理效果，决定是否保存结果或调整算法。

### 1.2 核心价值

| 价值维度 | 具体内容 |
|---------|---------|
| **多维对比** | 6种对比模式，满足不同场景下的对比需求 |
| **专业评估** | 量化指标分析（PSNR/SSIM等），客观评价效果 |
| **直观展示** | 可视化对比工具，清晰呈现处理前后差异 |
| **信息透明** | 完整的算法信息和处理参数展示 |
| **灵活操作** | 支持缩放、平移、滤镜调节等交互操作 |

### 1.3 用户角色分析

| 用户类型 | 特征 | 使用偏好 | 功能需求 |
|---------|------|---------|---------|
| **轻度用户** | 对图像处理不了解 | 直观视觉对比 | 并排对比+重叠对比 |
| **中度用户** | 有一定图像处理经验 | 细节检查+效果调整 | 放大镜+滤镜调节 |
| **专业用户** | 图像处理专家 | 量化数据分析 | 指标对比+算法信息+报告导出 |
| **VIP用户** | 高频使用者 | 高效评估+批量对比 | 多算法对比+历史对比 |

### 1.4 模块依赖关系

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  去雾处理    │────▶│  效果对比    │────▶│  结果管理    │
│    模块     │     │    模块     │     │  保存/分享   │
└─────────────┘     └──────┬──────┘     └─────────────┘
                          │
                          ↓
                   ┌─────────────┐
                   │  不满意结果  │
                   │ 返回算法选择 │
                   └─────────────┘
```

## 2. 功能需求

### 2.1 并排对比模式 (F-M05-001)

#### 2.1.1 功能描述

将原图和处理后的图片并排显示，方便整体效果对比，是最基础也是最常用的对比方式。

#### 2.1.2 布局需求

支持竖屏和横屏两种布局模式，根据设备类型自动适配：
- **竖屏布局（移动端默认）**：原图和处理后的图片上下排列显示
- **横屏布局（桌面端/平板）**：原图和处理后的图片左右并排显示

#### 2.1.3 交互功能

| 交互操作 | 触发方式 | 效果说明 |
|---------|---------|---------|
| **同步缩放** | 双指捏合 | 两张图片同步放大/缩小 |
| **同步移动** | 单指拖动 | 拖动时两张图片同步移动 |
| **双击放大** | 双击图片 | 放大到100%显示 |
| **双击还原** | 再次双击 | 还原到适应屏幕 |
| **标签切换** | 点击标签 | 切换显示原图/处理后 |

---

### 2.2 重叠对比模式 (F-M05-002)

#### 2.2.1 功能描述

将原图和处理后的图片重叠显示，通过滑动分隔线对比效果，适合精细对比局部差异。

#### 2.2.2 对比方式

支持垂直分隔线和水平分隔线两种对比方式：
- **垂直分隔线（默认）**：通过拖动左右滑动的分隔线，对比图片的左右区域差异
- **水平分隔线**：通过拖动上下滑动的分隔线，对比图片的上下区域差异

#### 2.2.3 交互功能

| 交互操作 | 触发方式 | 效果说明 |
|---------|---------|---------|
| **拖动分隔线** | 按住分隔线滑动 | 调整原图/处理后显示比例 |
| **自动对齐** | 松开分隔线 | 分隔线自动吸附到中心（可关闭） |
| **切换方向** | 点击切换按钮 | 垂直/水平分隔线切换 |
| **锁定位置** | 长按分隔线 | 固定分隔线位置 |
| **动画播放** | 点击播放按钮 | 分隔线自动左右/上下滑动 |

---

### 2.3 放大镜对比模式 (F-M05-003)

#### 2.3.1 功能描述

使用放大镜工具查看局部细节，精确对比处理效果，适合检查纹理、边缘等细节。

#### 2.3.2 放大镜需求

放大镜工具在图片上方显示，可跟随移动，用于查看局部细节。

#### 2.3.3 放大镜参数

| 参数项 | 选项 | 默认值 | 说明 |
|--------|------|--------|------|
| **放大倍数** | 2x / 3x / 5x | 2x | 放大镜内图像放大倍数 |
| **放大镜大小** | 小(100px) / 中(150px) / 大(200px) | 中 | 放大镜显示区域大小 |
| **边框样式** | 圆形 / 方形 / 圆角方形 | 圆形 | 放大镜外观样式 |
| **显示模式** | 原图 / 处理后 / 对比 | 对比 | 放大镜内显示内容 |

#### 2.3.4 对比模式需求

在对比模式下，同时显示原图和处理后两个放大镜窗口，方便对比查看同一位置的细节差异。

#### 2.3.5 交互功能

| 交互操作 | 触发方式 | 效果说明 |
|---------|---------|---------|
| **移动放大镜** | 手指拖动 | 放大镜跟随手指移动 |
| **调整倍数** | 双指捏合 | 调整放大倍数(2x-5x) |
| **切换显示** | 点击放大镜 | 切换原图/处理后/对比 |
| **固定位置** | 长按 | 固定放大镜位置 |
| **添加标记** | 双击 | 在当前位置添加对比标记点 |

---

### 2.4 滤镜调节对比模式 (F-M05-004)

#### 2.4.1 功能描述

对处理后的图片进行滤镜参数微调，实时预览调节效果，满足用户个性化需求。

#### 2.4.2 滤镜参数

| 滤镜名称 | 调节范围 | 默认值 | 说明 |
|---------|---------|--------|------|
| **亮度** | -100 ~ +100 | 0 | 调整图片整体明暗 |
| **对比度** | -100 ~ +100 | 0 | 调整明暗对比程度 |
| **饱和度** | -100 ~ +100 | 0 | 调整色彩鲜艳度 |
| **色温** | -100 ~ +100 | 0 | 调整冷暖色调 |
| **锐化** | 0 ~ 100 | 0 | 增强细节清晰度 |
| **降噪** | 0 ~ 100 | 0 | 减少图片噪点 |

#### 2.4.3 调节界面需求

调节界面应包括以下区域：
- 实时预览区域：展示滤镜调节后的效果
- 滤镜参数控制区：提供各滤镜参数的滑动条控件
- 预设方案区域：提供内置预设和自定义预设选择
- 操作按钮区：重置、对比、应用等操作按钮

#### 2.4.4 预设方案

**内置预设**

| 预设名称 | 效果说明 | 参数特点 |
|---------|---------|---------|
| **自然** | 轻微增强，保持自然 | 亮度+5，对比度+10，饱和度+5 |
| **鲜艳** | 色彩艳丽，视觉冲击 | 对比度+30，饱和度+40 |
| **柔和** | 降低对比，柔化效果 | 对比度-20，锐化-10 |
| **清晰** | 增强细节，提升清晰度 | 对比度+20，锐化+40 |
| **复古** | 复古暖色调效果 | 色温+30，饱和度-20 |

**自定义预设**

- 保存当前参数为预设
- 命名自定义预设
- 管理预设列表（编辑/删除/排序）
- 导入/导出预设配置

### 2.5 指标对比模式 (F-M05-005)

#### 2.5.1 功能描述

通过量化指标客观评估去雾效果，提供专业的数据分析，适合专业用户和算法评测场景。

#### 2.5.2 评估指标体系

**图像质量指标**

| 指标名称 | 英文缩写 | 说明 | 理想值 | 单位 |
|---------|---------|------|--------|------|
| **峰值信噪比** | PSNR | 图像质量评价，越高越好 | >25 | dB |
| **结构相似性** | SSIM | 结构相似程度，越接近1越好 | >0.85 | - |
| **均方误差** | MSE | 图像差异程度，越小越好 | <100 | - |
| **信息熵** | Entropy | 图像信息量，适中为好 | 7-8 | - |

**去雾效果指标**

| 指标名称 | 说明 | 理想值 | 计算方式 |
|---------|------|--------|---------|
| **对比度提升** | 对比度增加程度 | 20%-50% | (处理后对比度-原图对比度)/原图对比度 |
| **饱和度提升** | 色彩饱和度增加 | 10%-30% | (处理后饱和度-原图饱和度)/原图饱和度 |
| **清晰度提升** | 图像清晰度增加 | 30%-60% | 基于边缘检测算法计算 |
| **暗通道值** | 雾霾浓度指标 | <0.2 | 基于暗通道先验计算 |

**性能指标**

| 指标名称 | 说明 | 单位 | 来源 |
|---------|------|------|------|
| **处理时间** | 算法处理耗时 | 秒 | 服务端记录 |
| **内存占用** | 处理过程内存峰值 | MB | 服务端监控 |
| **输出文件大小** | 处理后图片大小 | MB | 文件系统 |

#### 2.5.3 指标可视化需求

提供多种图表形式展示量化指标：
- 雷达图：多维度指标综合评估，直观展示各项指标表现
- 柱状图：对比展示各项指标的具体数值和提升幅度

#### 2.5.4 对比分析功能

- **原图 vs 处理后**：单次处理效果对比
- **多算法对比**：同一图片不同算法效果对比
- **历史记录对比**：与历史处理结果对比
- **生成分析报告**：导出PDF/图片格式报告

**处理参数**

| 参数项 | 本次使用值 | 默认值 | 说明 |
|--------|-----------|--------|------|
| 去雾强度 | 50 | 50 | 控制去雾程度 |
| 色彩饱和度 | 110 | 100 | 色彩增强程度 |
| 对比度 | 105 | 100 | 对比度调整 |

**性能数据**

| 数据项 | 值 | 说明 |
|--------|-----|------|
| 实际处理时间 | 2.5秒 | 本次处理耗时 |

#### 2.6.3 信息展示需求

算法信息展示界面应包括以下内容区块：
- 算法基本信息：名称、类型、版本、适用场景、推荐指数
- 处理参数：本次处理使用的参数及与默认值的对比
- 效果评估：各项质量指标的评价结果
- 性能数据：处理时间、内存占用等性能指标

### 2.7 对比工具栏 (F-M05-007)

#### 2.7.1 功能描述

提供快速切换对比模式和常用操作的工具栏，始终固定在屏幕底部或侧边。

#### 2.7.2 工具栏布局需求

工具栏布局应根据设备类型自适应：
- 底部工具栏（移动端）：对比模式切换按钮和常用操作按钮分两行显示
- 侧边工具栏（桌面端）：采用垂直布局，包含模式切换和常用操作按钮

#### 2.7.3 快捷操作

| 操作 | 图标 | 说明 |
|------|------|------|
| **保存结果** | 💾 | 保存处理后的图片到相册/本地 |
| **分享图片** | 📤 | 分享到社交平台或生成分享链接 |
| **重新处理** | 🔄 | 使用相同参数重新处理 |
| **更换算法** | ⚡ | 返回算法选择页更换算法 |
| **导出报告** | 📄 | 生成并导出对比分析报告 |
| **添加收藏** | ⭐ | 收藏本次处理结果 |

## 3. 用户交互流程

### 3.1 标准对比流程

```
【用户操作】                      【系统响应】
    │
处理完成，自动进入对比页面
    │                            ← 默认显示并排对比模式
    │                            ← 加载原图和处理结果
    │
查看整体效果
    │                            ← 并排展示原图和处理后
    │
切换对比模式
    │                            ← 平滑切换到目标模式
    │                            ← 保持当前缩放/位置状态
    │
├─ 重叠对比                      ← 显示分隔线，支持拖动
├─ 放大镜对比                    ← 显示放大镜，支持移动
├─ 滤镜调节                      ← 显示滤镜控制面板
├─ 指标对比                      ← 计算并展示量化指标
└─ 算法信息                      ← 展示算法详情
    │
满意结果
    │                            
├─ 保存到相册                    ← 保存成功提示
├─ 分享到社交平台                ← 打开分享面板
├─ 导出对比报告                  ← 生成PDF/图片报告
└─ 添加到收藏                    ← 收藏成功提示
    │
不满意结果
    │
├─ 返回算法选择                  ← 保留原图，重新选择算法
├─ 调整处理参数                  ← 返回参数调节页面
└─ 重新上传图片                  ← 返回图像输入页面
```

│ │ [结果]  │ │         │             │

    ↓

## 6. 未来扩展规划
