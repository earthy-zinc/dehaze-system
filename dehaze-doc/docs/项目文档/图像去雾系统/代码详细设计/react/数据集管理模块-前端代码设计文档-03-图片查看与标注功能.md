# 代码设计文档

## 文档说明
- **对应需求**：`demo/docs/07-数据集管理模块需求-03-图片查看与标注功能.md`
- **适用版本**：dehaze-front-react
- **设计原则**：
  1. **组件化查看**：大图查看、配对切换、元数据编辑拆分为可复用组件（可嵌入浏览页或独立弹窗）。
  2. **强一致性**：标注/编辑表单使用乐观锁 + 回滚提示，避免多端同时操作冲突。
  3. **可观测日志**：每次编辑、下载、分享在前端生成事件并送往日志/埋点，辅助排查。

## 1. 修改目标与范围定位
- 实现图片详情查看、配对浏览、上一张/下一张导航、标注编辑、批量标注、使用次数上报等交互。
- 覆盖文件：
  | 路径 | 调整 |
  | --- | --- |
  | `src/pages/dataset/components/ImageBrowser` | 集成“查看/编辑”入口。 |
  | `src/components/image-viewer/ImagePreviewModal.tsx` | 新增大图查看模态框。 |
  | `src/components/image-viewer/ImageMetaPanel.tsx` | 显示文件/元数据/使用次数。 |
  | `src/components/image-viewer/ImagePairSwitcher.tsx` | 清晰图/雾霾图切换控件。 |
  | `src/components/image-viewer/AnnotationForm.tsx` | 场景类型、雾霾程度、描述等编辑表单。 |
  | `src/components/image-viewer/NavigationFooter.tsx` | 上一张/下一张控制。 |
  | `src/components/modals/BatchAnnotateModal.tsx` | 批量标注弹窗。 |
  | `src/hooks/useImageDetail.ts` | 统一拉取详情、配对、导航、usage 数据。 |
  | `src/api/image.ts` | 新增接口 `getImageDetail`, `getImagePeers`, `updateImageMeta`, `batchUpdateMeta`, `touchImageUsage`. |

## 2. 现有实现概览
- 仅在 `DatasetDetail` 中通过 `Viewer` 展示原图列表，缺少：
  - 图片级别的元数据信息（文件名、分辨率、雾霾程度、描述等）；
  - 清晰图与多张雾霾图的切换；
  - 导航到上一数据项/下一数据项；
  - 元数据编辑、场景类型输入、雾霾程度选择；
  - 批量标注/使用次数埋点。

## 3. 代码设计与修改方案

### 3.1 详情查看流程
1. 用户点击任意图片 -> 调用 `openImagePreview(itemFileId)`，挂载 `ImagePreviewModal`。
2. `useImageDetail(itemFileId)`：
   - 并行请求 `/dataset/image/:id`（详情）与 `/dataset/image/:id/peers`（配对），缓存结果；
   - 请求 `/dataset/:datasetId/item/:itemId/navigation` 获取上一张/下一张。
3. Modal 左右布局：
   - 左侧 `ImageViewer`（支持放大/缩小/旋转/拖动）；
   - 右侧 `ImageMetaPanel`（信息 + 标签切换 + AnnotationForm + Usage）；
   - 底部 `NavigationFooter`（上一张/下一张 + 当前序号）。
4. `ImagePairSwitcher` 在 `ImageMetaPanel` 顶部，显示配对数量与雾霾标签；选择不同配对即更新 `ImageViewer`。

### 3.2 元数据编辑
- `AnnotationForm` 使用 AntD Form + Schema：
  ```ts
  interface AnnotationFormValues {
    sceneType?: string;
    hazeLevel?: 'light'|'medium'|'heavy'|'unknown';
    processStatus?: 'unprocessed'|'processed'|'failed';
    description?: string;
    imageType?: 'clear'|'hazy'|'dehazed';
  }
  ```
- “保存”时调用 `updateImageMeta(itemFileId, payload, lastUpdateTime)`：
  - 成功：刷新详情并 toast；
  - 409（乐观锁冲突）：弹框提示“数据已更新，是否覆盖/重新加载”。
- 批量标注 `BatchAnnotateModal`
  - 支持“应用到配对”选项；
  - 调用 `batchUpdateMeta({ itemFileIds, payload, applyToPairs })`。

### 3.3 使用次数与下载
- 在 `ImagePreviewModal` 中提供 “下载”/“分享” 按钮：
  - 下载：调用 `/dataset/image/:id/download?variant=...` 并在完成后触发 `touchImageUsage`（event = download）。
  - 分享：复制链接或触发系统分享后记录 event `share`。
- `ImageMetaPanel` 展示 `usageCount` + 分布图（如“下载 3 / 浏览 10”），数据来自详情接口。

### 3.4 导航
- `NavigationFooter` 按钮调用 `useImageDetail` 提供的 `goPrev/goNext`，内部会重新加载详情。
- 如果上一/下一条不存在，按钮置灰。
- 提供 `shortcut`（←/→）以键盘切换。

### 3.5 扩展点
- 日志：构建 `logImageEvent` 方法，将事件（view/download/edit）提交到埋点服务（如 `src/utils/metrics.ts`）。
- 权限：在 `AnnotationForm` 外围根据 `usePermission('dataset:annotation')` 控制编辑/批量按钮的显隐。

## 4. 异常处理与边界情况
- 详情接口 404 -> 显示“图片已删除”提示并关闭 Modal。
- 配对接口返回空 -> 显示空态提示“未配置清晰图/雾霾图”。
- Batch 接口部分失败 -> 返回列表（itemId + 错误原因），在 Modal 中逐条展示。
- 下载接口失败 -> 显示 Toast，usage 不累加。

## 5. 安全与性能注意事项
- 表单输入需限制长度并进行字符转义，防止 XSS。
- 对原图 URL 追加鉴权 token（若需要），避免泄露；
- 使用 `react-viewer` 时关闭 `navbar` 以减少内存；
- `useImageDetail` 缓存 key = `itemFileId`，缓存 5 min，避免重复请求。

## 6. 测试建议
- **功能**：
  - 大图查看（缩放/旋转/拖拽）；
  - 配对切换（单清晰图 + 多雾霾图）；
  - 元数据编辑（单张/批量）与冲突提示；
  - 下载/分享后 usage 自增；
  - 上一张/下一张导航与键盘快捷键。
- **性能**：
  - Modal 打开时首屏渲染耗时；
  - 批量标注 500 张图片的平均延迟；
  - 多次打开 Modal 是否存在内存泄漏。
- **兼容**：
  - 深色模式下的 Modal 样式；
  - 移动端（若需）是否支持滑动切换。

## 7. 待确认事项与风险
- 场景类型是否需提供运营录入的建议词；
  - 若需，需在前端添加 `AutoComplete` + 远程搜索。
- 使用次数是否需要区分“浏览/下载/分享”三个统计维度；
  - 若是，需要后端返回拆分字段。
- 批量标注是否需要“导入 CSV”能力（需求文档未明确）。
- 操作日志是否保存在前端（仅埋点）还是提供 UI 列表，需要产品确认。
