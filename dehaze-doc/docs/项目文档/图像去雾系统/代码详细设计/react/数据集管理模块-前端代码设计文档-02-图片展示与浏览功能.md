# 代码设计文档

## 文档说明
- **对应需求**：`demo/docs/07-数据集管理模块需求-02-图片展示与浏览功能.md`
- **适用版本**：dehaze-front-react
- **设计原则**：
  1. **多模式统一**：列表 / 纵向瀑布流 / 横向瀑布流 / 网格由同一数据源驱动，依赖模式切换仅影响渲染层。
  2. **高性能滚动**：采用虚拟列表、懒加载与分页游标，保障 10w+ 图片浏览体验。
  3. **操控一体化**：筛选、排序、批量操作入口集中在“控制台”组件，减少跳转。

## 1. 修改目标与范围定位
- 提供满足四种展示模式、筛选、搜索、批量操作、无限滚动的图片浏览界面。
- 覆盖范围：`src/pages/dataset/DatasetDetail.tsx`（图片 Tab）、新建 `src/pages/dataset/components/ImageBrowser/*`、`src/store/modules/imageSlice.ts`（或 React Query 缓存）、`src/components/Waterfall`（增强虚拟化）、`src/components/ImageToolbar`、`src/components/ImageCard`。
- **文件调整**：
  | 路径 | 调整 |
  | --- | --- |
  | `src/pages/dataset/DatasetDetail.tsx` | 将图片逻辑抽离为 `ImageBrowser` 组件，接入模式切换和筛选。 |
  | `src/pages/dataset/components/ImageBrowser/index.tsx` | 主容器，渲染模式切换、筛选、批量操作、内容区域。 |
  | `src/pages/dataset/components/ImageBrowser/ImageModeToggle.tsx` | 四种模式切换按钮，与用户偏好联动。 |
  | `src/pages/dataset/components/ImageBrowser/ImageFilterDrawer.tsx` | 场景 / 雾霾 / 状态 / 分辨率筛选抽屉。 |
  | `src/pages/dataset/components/ImageBrowser/ImageListMode.tsx` | AntD Table + 虚拟滚动，支持列自定义/批量勾选。 |
  | `src/pages/dataset/components/ImageBrowser/ImageWaterfall.tsx` | 基于现有 Waterfall 重构，新增虚拟化 + 懒加载。 |
  | `src/pages/dataset/components/ImageBrowser/ImageGrid.tsx` | 固定卡片尺寸的网格实现。 |
  | `src/hooks/useInfiniteImages.ts` | 读取分页 + cursor，封装滚动、刷新、预加载逻辑。 |
  | `src/cache/userPreferences.ts` | 保存用户模式、排序、列设置至 Redis/LocalStorage。 |

## 2. 现有实现概览
- `DatasetDetail` 目前仅有一个瀑布流组件，依赖 `DatasetAPI.getImageItem` 简单分页；
- 图片类型切换仅基于 `imgUrl` 数组索引，没有与场景/雾霾/状态筛选联动；
- 无限滚动逻辑通过 `IntersectionObserver` + `setTimeout`，缺少去抖与边界控制；
- 无列表模式、无批量操作、无横向瀑布流/网格模式。

## 3. 代码设计与修改方案

### 3.1 视图结构
```
<ImageBrowser>
  <Toolbar>
    <ModeToggle />
    <FilterDrawerTrigger />
    <SearchInput />
    <SortDropdown />
    <BatchActions />
  </Toolbar>
  <ContentArea>
    {mode === 'list' && <ImageListMode />}
    {mode === 'waterfall_v' && <ImageWaterfall orientation="vertical" />}
    {mode === 'waterfall_h' && <ImageWaterfall orientation="horizontal" />}
    {mode === 'grid' && <ImageGrid />}
  </ContentArea>
  <LoadMoreTrigger />
</ImageBrowser>
```
- `Toolbar` 使用 AntD `Space` + `Segmented` 组件；
- `BatchActions` 集成批量删除、批量下载、批量标注入口；
- `LoadMoreTrigger` 触发 `useInfiniteImages` 加载下一页。

### 3.2 数据层
1. **数据结构**
   ```ts
   interface ImageQueryState {
     datasetId: number;
     mode: 'list'|'waterfall_v'|'waterfall_h'|'grid';
     filters: {
       keywords?: string;
       sceneType?: string;
       hazeLevel?: string;
       processStatus?: string;
       minWidth?: number;
       maxWidth?: number;
       minSizeKB?: number;
       maxSizeKB?: number;
     };
     sortField: 'uploadTime'|'usageCount'|'width'|'height';
     sortOrder: 'asc'|'desc';
   }
   ```
2. **Hook `useInfiniteImages`**
   - 入参：`ImageQueryState`
   - 输出：`{ items, isLoading, isEnd, loadMore, refresh, toggleSelect, selectedIds }`
   - 逻辑：
     - 首次加载 `pageNum=1`；
     - 使用 `cursor` + `pageSize` 控制分页；
     - 滚动加载时若 `isLoading` 或 `isEnd` 则忽略；
     - 支持 `cacheKey = datasetId + JSON.stringify(filters) + mode`。
3. **用户偏好**
   - `useUserPreference('imageMode')` Hook 读取/写入 localStorage；
   - 进入页面时自动应用上次模式、排序、列设置。

### 3.3 组件实现要点
- **ImageListMode**：
  - 基于 AntD `Table` + `rc-virtual-list`；
  - 列包含：缩略图、文件名、分辨率、大小、雾霾程度、场景类型、处理状态、上传时间、操作；
  - 批量勾选后触发 `BatchActions`。
- **ImageWaterfall**：
  - 对现有 `Waterfall` 组件添加 `virtualizer`，仅渲染可视列；
  - 横纵两种模式分别设置 `columns` / `rowHeight`；
  - 支持轻量 `ImageCard` 组件（展示标签、Hover 操作）。
- **ImageGrid**：
  - 使用 CSS Grid (`repeat(auto-fill, minmax(200px, 1fr))`)，卡片显示图片 + 雾霾标签 + hover 操作。
- **FilterDrawer**：
  - Form + Tabs：场景/雾霾/状态/尺寸/文件大小/上传时间；
  - “场景类型”联动后端字典 + 搜索建议；
  - 点击“应用”更新 query state。

### 3.4 批量操作流程
- `BatchActions` 组件读取 `selectedIds`：
  - 批量下载 -> 调用后端 `/dataset/item/batch/download`，展示 `TaskProgress`。
  - 批量删除 -> 调 `DELETE /dataset/item/batch`，成功后 `refresh()`。
  - 批量标注 -> 打开 `BatchAnnotateModal`（文档 03 复用）。

### 3.5 性能优化
- 使用 `requestAnimationFrame` 内部节流 `IntersectionObserver` 回调。
- 在 Waterfall 模式中对图片 src 追加 `?x-oss-process=image/resize,w_<width>`（若后端支持）以减小带宽。
- 列表模式下 `rowSelection` 使用 `checkboxProps` 限制不可选项（例如锁定图片）。

## 4. 异常处理与边界情况
- 无数据：显示 AntD `Empty` + “上传图片”按钮；
- 查询返回部分字段缺失（如 `hazeLevel`）时以 `未标注` 代替；
- 无限滚动到末尾：`LoadMoreTrigger` 显示“已加载全部”；
- 批量操作时若未选择图片，禁用按钮并提示。

## 5. 安全与性能注意事项
- 批量操作需校验权限标签（如仅管理员可批量删除）。
- 防止 XSS：所有描述/标签需转义显示。
- 过滤器输入值需限制最大/最小范围，防止触发大范围查询。
- 虚拟列表容器宽高变更时重新计算布局，避免内存泄漏。

## 6. 测试建议
- **模式切换**：四种模式间切换不丢失已加载数据，偏好持久化正常。
- **筛选**：组合筛选（场景 + 雾霾 + 分辨率）是否正确；重置后数据恢复。
- **无限滚动**：在滚到末尾时不再请求；模拟网络慢速时不会重复触发。
- **批量操作**：选择全部/部分记录执行删除/下载/标注结果正确。
- **性能**：1000+ 图片渲染时帧率保持 >50fps；窗口 resize 时布局无错位。

## 7. 待确认事项与风险
- 横向瀑布流是否需要“按行分组”展示（需求图示未明确）。
- 搜索相关度排序是否后端完成，若前端需要需拿到权重字段。
- 批量下载压缩包命名规范需与后端对齐。
- 瀑布流图片 URL 是否可直接访问原图，如需鉴权需整合签名。
