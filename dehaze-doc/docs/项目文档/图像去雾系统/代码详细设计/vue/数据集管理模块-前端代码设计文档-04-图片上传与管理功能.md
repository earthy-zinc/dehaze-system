## 文档说明

本文档为图像去雾系统数据集管理模块的前端代码设计方案，旨在满足《07-数据集管理模块需求-04-图片上传与管理功能.md》中定义的图片上传与管理功能需求。

### 设计原则

1. **组件化设计**：将各种上传功能拆分为独立组件，复用现有 `SingleUpload`、`MultiUpload` 组件
2. **用户体验优先**：提供直观的上传流程和实时进度反馈
3. **前端预校验**：上传前在前端进行分辨率校验，减少无效上传

## 1. 修改目标与范围定位

### 1.1 核心目标

本次改动的核心目标：
- 实现单张图片上传功能，支持上传时指定标注信息
- 实现配对图片上传功能，支持一张清晰图+多张有雾图的配对上传

- 实现图片下载功能，支持单张下载、配对下载、批量下载、数据集整体下载

#### 3.8.1 useImagePairValidation

**文件路径**：`src/composables/useImagePairValidation.ts`

**导出接口**：

| 名称 | 类型 | 说明 |
|-----|------|------|
| `getImageDimensions` | `(file: File) => Promise<{width, height}>` | 获取图片尺寸 |
| `validatePairGroup` | `(clearFile, hazyItems) => Promise<ValidationResult>` | 校验配对组 |
| `validateAllDimensions` | `(files: File[]) => Promise<boolean>` | 校验所有图片尺寸一致性 |
| `validationStatus` | `Ref<'idle' \| 'validating' \| 'passed' \| 'failed'>` | 校验状态 |
| `validationError` | `Ref<string>` | 校验错误信息 |

**实现逻辑**：

```typescript
export function useImagePairValidation() {
  const validationStatus = ref<'idle' | 'validating' | 'passed' | 'failed'>('idle');
  const validationError = ref('');

  const getImageDimensions = (file: File): Promise<{width: number, height: number}> => {
    return new Promise((resolve, reject) => {
      const img = new Image();
      img.onload = () => {
        resolve({ width: img.width, height: img.height });
        URL.revokeObjectURL(img.src);
      };
      img.onerror = reject;
      img.src = URL.createObjectURL(file);
    });
  };

  const validatePairGroup = async (
    clearFile: File | null,
    hazyItems: HazyImageItem[]
  ): Promise<ValidationResult> => {
    validationStatus.value = 'validating';
    validationError.value = '';

    // 1. 校验清晰图必填
    if (!clearFile) {
      validationStatus.value = 'failed';
      validationError.value = '请上传清晰图像';
      return { valid: false, error: validationError.value };
    }

    // 2. 校验有雾图必填
    const validHazyItems = hazyItems.filter(i => i.file);
    if (validHazyItems.length === 0) {
      validationStatus.value = 'failed';
      validationError.value = '请至少上传一张有雾图像';
      return { valid: false, error: validationError.value };
    }

    // 3. 校验雾霾程度必填
    const missingHazeLevel = validHazyItems.find(i => !i.hazeLevel);
    if (missingHazeLevel) {
      validationStatus.value = 'failed';
      validationError.value = '请为每张有雾图选择雾霾程度';
      return { valid: false, error: validationError.value };
    }

    // 4. 校验分辨率一致性
    const clearDim = await getImageDimensions(clearFile);
    for (let i = 0; i < validHazyItems.length; i++) {
      const hazyDim = await getImageDimensions(validHazyItems[i].file!);
      if (hazyDim.width !== clearDim.width || hazyDim.height !== clearDim.height) {
        validationStatus.value = 'failed';
        validationError.value = `配对图片分辨率不一致，清晰图：${clearDim.width}×${clearDim.height}，有雾图${i+1}：${hazyDim.width}×${hazyDim.height}`;
        return { valid: false, error: validationError.value };
      }
    }

    validationStatus.value = 'passed';
    return { valid: true };
  };

  return {
    getImageDimensions,
    validatePairGroup,
    validateAllDimensions,
    validationStatus,
    validationError
  };
}
```

**文件名配对规则**：

| 文件名模式 | 图片类型 | 雾霾程度 |
|-----------|---------|---------|
| `xxx_clear.jpg` / `xxx_gt.jpg` / `xxx_ground_truth.jpg` | 清晰图 | - |
| `xxx_hazy.jpg` / `xxx_input.jpg` | 有雾图 | 需手动选择 |
| `xxx_hazy_light.jpg` / `xxx_foggy_light.jpg` | 有雾图 | light |
| `xxx_hazy_medium.jpg` / `xxx_foggy_medium.jpg` | 有雾图 | medium |
| `xxx_hazy_heavy.jpg` / `xxx_foggy_heavy.jpg` | 有雾图 | heavy |

**配对识别逻辑**：

```typescript
const detectPairGroups = async () => {
  const groups = new Map<string, PairGroup>();
  const unpaired: File[] = [];

  for (const file of files.value) {
    const { prefix, type, hazeLevel } = parseFileName(file.name);
    
    if (!prefix) {
      unpaired.push(file);
      continue;
    }

    if (!groups.has(prefix)) {
      groups.set(prefix, {
        id: generateId(),
        name: prefix,
        clearFile: null,
        clearPreview: '',
        clearDimensions: null,
        hazyFiles: [],
        validated: false,
        validationError: ''
      });
    }

    const group = groups.get(prefix)!;
    
    if (type === 'clear') {
      group.clearFile = file;
      group.clearPreview = URL.createObjectURL(file);
      group.clearDimensions = await getImageDimensions(file);
    } else if (type === 'hazy') {
      const dimensions = await getImageDimensions(file);
      group.hazyFiles.push({
        id: generateId(),
        file,
        preview: URL.createObjectURL(file),
        dimensions,
        hazeLevel: hazeLevel || ''
      });
    }
  }

  pairGroups.value = Array.from(groups.values());
  unpairedFiles.value = unpaired;
};

const parseFileName = (fileName: string) => {
  const baseName = fileName.replace(/\.[^.]+$/, ''); // 去除扩展名
  
  // 匹配清晰图
  const clearMatch = baseName.match(/^(.+?)_(clear|gt|ground_truth)$/i);
  if (clearMatch) {
    return { prefix: clearMatch[1], type: 'clear', hazeLevel: null };
  }
  
  // 匹配有雾图（带程度）
  const hazyWithLevelMatch = baseName.match(/^(.+?)_(hazy|foggy)_(light|medium|heavy)$/i);
  if (hazyWithLevelMatch) {
    return { prefix: hazyWithLevelMatch[1], type: 'hazy', hazeLevel: hazyWithLevelMatch[3].toLowerCase() };
  }
  
  // 匹配有雾图（不带程度）
  const hazyMatch = baseName.match(/^(.+?)_(hazy|foggy|input)$/i);
  if (hazyMatch) {
    return { prefix: hazyMatch[1], type: 'hazy', hazeLevel: null };
  }
  
  return { prefix: null, type: null, hazeLevel: null };
};
```

### 3.10 数据流说明

#### 3.10.1 配对图片上传流程

```
用户打开配对上传弹窗
    ↓
上传清晰图 → 读取尺寸 → 显示预览
    ↓
点击"添加有雾图"
    ↓
上传有雾图 → 读取尺寸 → 显示预览
    ↓
为每张有雾图选择雾霾程度（必选）
    ↓
useImagePairValidation.validatePairGroup()
    ↓
├── 校验失败 → 显示详细错误信息
└── 校验通过 → 启用"确认上传"按钮
    ↓
用户点击"确认上传"
    ↓
构建 FormData（clearImage + hazyImages[] + hazeLevels[]）
    ↓
DatasetAPI.uploadPairedImages(params)
    ↓
├── 失败 → 显示错误提示
└── 成功 → 关闭弹窗，刷新列表
```

#### 3.10.2 批量上传流程

```
用户打开批量上传弹窗（步骤1）
    ↓
拖拽或选择多个文件
    ↓
useBatchUpload.addFiles(files)
    ↓
点击"下一步"
    ↓
useBatchUpload.detectPairGroups()（步骤2）
    ↓
显示配对预览列表（BatchUploadPreview）
    ↓
用户确认/调整配对关系和雾霾程度
    ↓
useBatchUpload.validateAllGroups()
    ↓
├── 有校验失败 → 显示错误，禁止继续
└── 全部通过 → 启用"开始上传"按钮
    ↓
用户点击"开始上传"（步骤3）
    ↓
useBatchUpload.uploadAll(datasetId)
    ↓
遍历配对组，逐个上传
    ↓
显示上传进度
    ↓
上传完成，显示结果统计
    ↓
关闭弹窗，刷新列表
```

#### 3.10.3 数据集下载流程

```
用户点击数据集"下载"按钮

    ↓

    ↓

    ↓

├── 打包完成 → 返回下载URL，触发下载

    ↓
下载完成，关闭弹窗
```

### 5.1 安全方面

| 安全项 | 措施 |
|-------|------|

| 性能项 | 措施 |
|-------|------|
| 前端预校验 | 上传前在前端读取图片尺寸进行校验，避免无效上传 |
| 并行上传 | 配对图片并行上传，提高效率 |
| 并发控制 | 批量上传时控制并发数（建议3-5个） |
| 内存管理 | 及时释放预览 URL（`URL.revokeObjectURL`） |
| 进度显示 | 显示上传/下载进度，提升用户体验 |
| 分批处理 | 大量文件分批处理，避免内存溢出 |
