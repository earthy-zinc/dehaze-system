#### TC-IF-001: 获取图片详细信息

**测试目的**: 验证根据ID获取图片完整信息

- 方法: GET

### 6.2 支持的图片格式

| 格式   | MIME类型     | 说明     |
|------|------------|--------|
| jpg  | image/jpeg | JPEG格式 |
| jpeg | image/jpeg | JPEG格式 |
| png  | image/png  | PNG格式  |
| webp | image/webp | WebP格式 |

### 6.3 图片类型说明

| 类型    | 说明  | 用途                |
|-------|-----|-------------------|
| clear | 清晰图 | Ground Truth，无雾图像 |
| hazy  | 有雾图 | 雾霾图像，需标注雾霾程度      |

### 6.4 雾霾程度说明

| 程度 | 值      | 说明         |
|----|--------|------------|
| 轻度 | light  | 轻度雾霾，能见度较高 |
| 中度 | medium | 中度雾霾，能见度一般 |
| 重度 | heavy  | 重度雾霾，能见度很低 |

| 字段         | 类型       | 说明             |

| size       | Long     | 文件大小（字节）       |
| format     | String   | 文件格式（jpg/png等） |

| usageCount | Long     | 使用次数           |
| createTime | DateTime | 创建时间           |
