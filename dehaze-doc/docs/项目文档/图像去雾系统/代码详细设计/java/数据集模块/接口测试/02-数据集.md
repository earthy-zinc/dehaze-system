## 4. 数据库问题修复

### 4.1 问题描述

测试过程中发现两个数据库表缺少字段：

1. `sys_dataset` 表缺少 `usage_count` 字段
2. `sys_dataset_item` 表缺少 `create_time` 和 `update_time` 字段

### 4.2 修复方案

执行以下SQL语句：

```sql
-- 添加 sys_dataset.usage_count 字段
ALTER TABLE sys_dataset
ADD COLUMN usage_count BIGINT DEFAULT 0 COMMENT '使用次数';

-- 添加 sys_dataset_item 时间字段
ALTER TABLE sys_dataset_item
ADD COLUMN create_time DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
ADD COLUMN update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间';
```

### 4.3 修复验证
