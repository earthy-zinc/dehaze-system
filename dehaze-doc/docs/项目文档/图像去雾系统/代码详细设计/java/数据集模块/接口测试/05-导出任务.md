### 3.1 数据集导出接口

#### TC-ET-001: 创建数据集导出任务

**测试目的**: 验证创建数据集导出任务功能

**前置条件**: 已登录获取Token，存在包含图片的数据集

**请求信息**:

- 方法: POST
- 路径: `/api/v1/datasets/{id}/export`
- 请求头: `Authorization: Bearer {token}`
- 请求体:

```json
{
  "structure": "by_item",
  "includeTypes": ["clear", "hazy"],
  "includeThumbnail": false
}
```

**预期结果**:

- 状态码: 200
- 返回任务ID和状态

**实际结果**: PASS

**测试数据**:

```json

    "status": "pending",

  }
}
```

|---------|---------|---------------------|

### 4.3 任务状态

| 状态         | 说明   |
|------------|------|
| pending    | 等待处理 |
| processing | 处理中  |
| completed  | 已完成  |
| failed     | 失败   |
