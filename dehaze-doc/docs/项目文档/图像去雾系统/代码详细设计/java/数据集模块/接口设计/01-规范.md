## 一、接口设计规范

### 1.1 URL命名规范

| 规则             | 示例                                    | 说明                         |
|----------------|---------------------------------------|----------------------------|
| 资源用复数名词        | `/datasets`                           | 不用 `/dataset`              |
| 层级用嵌套表示        | `/datasets/{id}/items`                | 表示从属关系                     |
| 动作用HTTP方法      | `DELETE /datasets/{id}`               | 不用 `/datasets/{id}/delete` |
| 批量操作加 `/batch` | `/datasets/batch`                     | 统一批量操作后缀                   |
| ID参数统一用 `{id}` | `/datasets/{id}`                      | 不用 `{datasetId}`           |
| 路径层级不超过3层      | `/datasets/{id}/items/{itemId}/files` | 超过时用独立资源                   |

### 1.2 HTTP方法使用规范

| HTTP方法 | 操作         | 幂等性 | 安全性 |
|--------|------------|-----|-----|
| GET    | 查询资源       | 是   | 是   |
| POST   | 创建资源/复杂操作  | 否   | 否   |
| PUT    | 更新资源（整体更新） | 是   | 否   |
| PATCH  | 更新资源（部分更新） | 否   | 否   |
| DELETE | 删除资源       | 是   | 否   |

### 1.3 响应结构规范

#### 单资源响应

```json
{
  "code": "00000",
  "message": "一切ok",
  "data": {
    "id": 1,
    "name": "数据集1"
  }
}
```

#### 列表响应（与实际 PageResult 对齐）

```json
{
  "code": "00000",
  "msg": "一切ok",
  "data": {
    "list": [ /* 资源数组 */ ],
    "total": 100
  }
}
```

**字段说明**（基于 `com.pei.dehaze.common.result.PageResult`）：

- `list`: 当前页数据列表
- `total`: 总记录数

#### 批处理响应

```json
{
  "code": "00000",
  "message": "一切ok",
  "data": {
    "total": 10,
    "succeeded": 8,
    "failed": 2,
    "results": [
      {
        "id": 1,
        "status": "success",
        "message": null
      },
      {
        "id": 3,
        "status": "failed",
        "message": "数据集不存在",
        "errorCode": "RESOURCE_NOT_FOUND"
      }
    ]
  }
}
```

#### 异步任务响应

```json
{
  "code": "00000",
  "message": "一切ok",
  "data": {
    "taskId": "uuid-xxx",
    "status": "pending | processing | completed | failed",
    "progress": 0,
    "createdAt": "2025-01-10T10:00:00Z"
  }
}
```

### 1.4 错误码规范

| 错误码                | HTTP状态 | 说明       | 示例             |
|--------------------|--------|----------|----------------|
| PARAM_INVALID      | 400    | 参数校验失败   | `name不能为空`     |
| RESOURCE_NOT_FOUND | 404    | 资源不存在    | `数据集123不存在`    |
| RESOURCE_EXISTS    | 400    | 资源已存在    | `名称"测试数据集"已存在` |
| BUSINESS_ERROR     | 400    | 业务规则校验失败 | `分辨率不一致`       |
| PERMISSION_DENIED  | 403    | 无权限      | `无删除权限`        |
| SYSTEM_ERROR       | 500    | 系统异常     | `服务暂时不可用`      |
