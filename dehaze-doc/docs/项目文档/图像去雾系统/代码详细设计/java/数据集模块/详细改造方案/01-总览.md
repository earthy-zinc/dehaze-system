# 数据集模块架构优化方案

> **文档版本**: v2.0  
> **更新日期**: 2025-01-10  
> **文档性质**: ADR（架构决策记录）+ 实施计划

---

## 总体目标

| 目标        | 具体指标                 | 验收标准            |
|-----------|----------------------|-----------------|
| **解耦副作用** | 缩略图、统计、缓存不阻塞主流程      | 主接口响应时间 < 500ms |
| **保证一致性** | MySQL+Redis+文件系统最终一致 | 补偿任务覆盖率 100%    |
| **提升性能**  | 统计查询命中缓存             | 缓存命中率 > 90%     |
| **降低复杂度** | 不引入过多分层，保持现有结构       | 新增文件 < 10 个     |

---

## 架构改动概览

### 改动前后对比

```diff
改动前：
Controller → Service（事务+校验+文件+缓存+统计 全部同步）
             ↓ 阻塞等待
         缩略图生成、统计刷新、文件删除

改动后：
Controller → Service（事务+校验） ✅ 快速返回
             ↓ 发布事件（非阻塞）
         EventHandler（异步处理副作用）
             ↓ 失败记录
         补偿任务（定时重试）
```
