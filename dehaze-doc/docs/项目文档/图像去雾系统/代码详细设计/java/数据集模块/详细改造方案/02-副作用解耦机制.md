## ADR-001：副作用解耦机制

### 1. 决策背景

**当前问题**：

- 缩略图生成、文件删除、统计刷新等副作用在事务同步链路内执行
- 响应时间长（平均 > 2s），失败率高（文件系统/Redis 抖动影响主流程）
- 事务边界与外部系统耦合，回滚逻辑复杂

**影响业务**：

- 上传接口慢导致用户体验差
- 删除失败阻塞事务，数据一致性难保证
- 无法扩展更多异步能力（如算法预处理）

### 2. 决策方案

**采用事务后事件模式**：

| 操作类型  | 主链路（同步+事务）                           | 副作用（异步）     |
|-------|--------------------------------------|-------------|
| 创建数据项 | 写入 `sys_dataset_item` 表              | 失效统计缓存      |
| 上传清晰图 | 写入 `sys_item_file` + `sys_file`、上传原图 | 生成缩略图       |
| 上传有雾图 | 写入 `sys_item_file` + `sys_file`、上传原图 | 生成缩略图       |
| 删除数据集 | 删除DB记录（数据集+数据项+文件记录）                 | 删除物理文件、清理缓存 |

**关键点**：

- 使用 `@TransactionalEventListener(phase = AFTER_COMMIT)` 保证事件在事务提交后发布
- 副作用失败不影响主流程，记录到 Redis 失败集合
- 补偿任务定时重试失败项

### 3. 技术实现

#### 3.1 事件定义

```java
package com.pei.dehaze.event;

import lombok.Getter;
import org.springframework.context.ApplicationEvent;

import java.util.List;

public abstract class DatasetEvent extends ApplicationEvent {

    public DatasetEvent(Object source) {
        super(source);
    }

    /** 数据项文件上传完成 */
    @Getter
    public static class ItemFilesUploaded extends DatasetEvent {
        private final Long datasetId;
        private final Long itemId;
        private final List<Long> fileIds;
        private final List<String> filePaths;

        public ItemFilesUploaded(Object source, Long datasetId, Long itemId,
                                 List<Long> fileIds, List<String> filePaths) {
            super(source);
            this.datasetId = datasetId;
            this.itemId = itemId;
            this.fileIds = fileIds;
            this.filePaths = filePaths;
        }
    }

    /** 数据集删除完成（数据库已删除） */
    @Getter
    public static class DatasetDeleted extends DatasetEvent {
        private final Long datasetId;
        private final List<String> filePaths;  // 待删除的物理文件

        public DatasetDeleted(Object source, Long datasetId, List<String> filePaths) {
            super(source);
            this.datasetId = datasetId;
            this.filePaths = filePaths;
        }
    }

    /** 数据项删除完成 */
    @Getter
    public static class ItemDeleted extends DatasetEvent {
        private final Long datasetId;
        private final Long itemId;
        private final List<String> filePaths;

        public ItemDeleted(Object source, Long datasetId, Long itemId, List<String> filePaths) {
            super(source);
            this.datasetId = datasetId;
            this.itemId = itemId;
            this.filePaths = filePaths;
        }
    }

    /** 统计信息需要刷新 */
    @Getter
    public static class StatsRefreshRequired extends DatasetEvent {
        private final Long datasetId;

        public StatsRefreshRequired(Object source, Long datasetId) {
            super(source);
            this.datasetId = datasetId;
        }
    }
}
```

#### 3.2 事件处理器

```java
package com.pei.dehaze.event;

import com.pei.dehaze.service.FileService;
import com.pei.dehaze.mapper.SysItemFileMapper;
import com.pei.dehaze.common.util.ImageUtils;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.context.event.EventListener;
import org.springframework.data.redis.core.RedisTemplate;
import org.springframework.retry.annotation.Backoff;
import org.springframework.retry.annotation.Retryable;
import org.springframework.scheduling.annotation.Async;
import org.springframework.stereotype.Component;
import org.springframework.transaction.event.TransactionalEventListener;
import org.springframework.transaction.event.TransactionPhase;

import java.util.List;

@Slf4j
@Component
@RequiredArgsConstructor
public class DatasetEventHandler {

    private final FileService fileService;
    private final RedisTemplate<String, Object> redisTemplate;
    private final SysItemFileMapper itemFileMapper;

    private static final String CACHE_KEY_STATS = "dataset:stats:";
    private static final String CACHE_KEY_TREE = "dataset:tree";

    /**
     * 处理文件上传后的副作用：生成缩略图
     * 使用 TransactionalEventListener 保证事务提交后执行
     */
    @Async("datasetTaskExecutor")
    @TransactionalEventListener(phase = TransactionPhase.AFTER_COMMIT)
    @Retryable(maxAttempts = 3, backoff = @Backoff(delay = 2000, multiplier = 2))
    public void handleThumbnailGeneration(DatasetEvent.ItemFilesUploaded event) {
        log.info("开始生成缩略图, itemId={}, fileCount={}", event.getItemId(), event.getFilePaths().size());

        for (int i = 0; i < event.getFilePaths().size(); i++) {
            String filePath = event.getFilePaths().get(i);
            Long fileId = event.getFileIds().get(i);
            try {
                // 生成缩略图并保存
                String thumbPath = ImageUtils.generateThumbnail(filePath, 200);
                // 注意：当前实现是 thumbnailFileId 指向 SysFile，需要先创建 SysFile 再更新
                // 这里简化为直接更新路径，实际需要根据 SysFile 体系调整
                itemFileMapper.updateThumbnailPath(fileId, thumbPath);
            } catch (Exception e) {
                log.error("生成缩略图失败: fileId={}, path={}", fileId, filePath, e);
                // 记录失败，由补偿任务处理
                recordThumbnailFailure(fileId, filePath);
            }
        }
    }

    /**
     * 处理文件上传后的副作用：失效统计缓存
     */
    @TransactionalEventListener(phase = TransactionPhase.AFTER_COMMIT)
    public void handleCacheInvalidation(DatasetEvent.ItemFilesUploaded event) {
        invalidateStatsCache(event.getDatasetId());
    }

    /**
     * 处理删除后的副作用：删除物理文件
     */
    @Async("datasetTaskExecutor")
    @TransactionalEventListener(phase = TransactionPhase.AFTER_COMMIT)
    public void handlePhysicalFileDeletion(DatasetEvent.DatasetDeleted event) {
        log.info("开始删除物理文件, datasetId={}, fileCount={}",
                event.getDatasetId(), event.getFilePaths().size());

        for (String filePath : event.getFilePaths()) {
            try {
                fileService.deleteFile(filePath);
                // 同时删除缩略图
                String thumbPath = buildThumbnailPath(filePath);
                fileService.deleteFile(thumbPath);
            } catch (Exception e) {
                log.error("删除文件失败: {}", filePath, e);
                // 记录失败，由补偿任务处理
                recordDeletionFailure(filePath);
            }
        }

        // 清理缓存
        invalidateStatsCache(event.getDatasetId());
        invalidateTreeCache();
    }

    /**
     * 处理数据项删除
     */
    @Async("datasetTaskExecutor")
    @TransactionalEventListener(phase = TransactionPhase.AFTER_COMMIT)
    public void handleItemFileDeletion(DatasetEvent.ItemDeleted event) {
        for (String filePath : event.getFilePaths()) {
            try {
                fileService.deleteFile(filePath);
            } catch (Exception e) {
                log.error("删除文件失败: {}", filePath, e);
                recordDeletionFailure(filePath);
            }
        }
        invalidateStatsCache(event.getDatasetId());
    }

    /**
     * 异步刷新统计信息
     */
    @Async("datasetTaskExecutor")
    @TransactionalEventListener(phase = TransactionPhase.AFTER_COMMIT)
    public void handleStatsRefresh(DatasetEvent.StatsRefreshRequired event) {
        // 这里可以预计算统计信息并写入缓存
        // 当前先简单失效缓存，让下次查询时重新计算
        invalidateStatsCache(event.getDatasetId());
    }

    // ========== 私有方法 ==========

    private void invalidateStatsCache(Long datasetId) {
        redisTemplate.delete(CACHE_KEY_STATS + datasetId);
    }

    private void invalidateTreeCache() {
        redisTemplate.delete(CACHE_KEY_TREE);
    }

    private void recordThumbnailFailure(Long fileId, String filePath) {
        String key = "dataset:thumbnail:failed";
        redisTemplate.opsForHash().put(key, fileId.toString(), filePath);
    }

    private void recordDeletionFailure(String filePath) {
        redisTemplate.opsForSet().add("dataset:deletion:failed", filePath);
    }

    private String buildThumbnailPath(String originalPath) {
        int lastSlash = originalPath.lastIndexOf('/');
        return originalPath.substring(0, lastSlash + 1) + "thumb_" + originalPath.substring(lastSlash + 1);
    }
}
```

#### 3.3 异步配置

```java
package com.pei.dehaze.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.retry.annotation.EnableRetry;
import org.springframework.scheduling.annotation.EnableAsync;
import org.springframework.scheduling.annotation.EnableScheduling;
import org.springframework.scheduling.concurrent.ThreadPoolTaskExecutor;

import java.util.concurrent.Executor;
import java.util.concurrent.ThreadPoolExecutor;

@Configuration
@EnableAsync
@EnableScheduling
@EnableRetry
public class AsyncConfig {

    /**
     * 数据集模块专用线程池
     *
     * 核心线程数：2（低负载场景足够）
     * 最大线程数：5（避免资源耗尽）
     * 队列容量：100（缓冲峰值请求）
     * 拒绝策略：CallerRunsPolicy（降级到同步执行，保证不丢失）
     */
    @Bean("datasetTaskExecutor")
    public Executor datasetTaskExecutor() {
        ThreadPoolTaskExecutor executor = new ThreadPoolTaskExecutor();
        executor.setCorePoolSize(2);
        executor.setMaxPoolSize(5);
        executor.setQueueCapacity(100);
        executor.setThreadNamePrefix("dataset-async-");
        executor.setRejectedExecutionHandler(new ThreadPoolExecutor.CallerRunsPolicy());
        executor.setWaitForTasksToCompleteOnShutdown(true);
        executor.setAwaitTerminationSeconds(60);
        executor.initialize();
        return executor;
    }
}
```

### 4. 验收标准

| 指标          | 目标值     | 验证方式              |
|-------------|---------|-------------------|
| **主接口响应时间** | < 500ms | 压测工具测试上传/删除接口 P99 |
| **异步任务成功率** | > 99%   | 监控异步任务失败日志        |
| **补偿任务覆盖率** | 100%    | 人工注入失败，验证重试成功     |
| **事务一致性**   | 100%    | 事务回滚时不应发布事件       |

### 5. 回滚方案

**场景1：异步任务异常导致积压**

- 临时降级：移除 `@Async`，改为同步执行
- 清空队列：重启应用自动清空内存队列

**场景2：事件发布异常**

- 回退方案：直接注释 `eventPublisher.publishEvent()` 调用
- 临时措施：手动触发补偿任务清理不一致数据
