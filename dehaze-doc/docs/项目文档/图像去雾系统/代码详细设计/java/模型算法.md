# 模型算法模块

## 1. 概述

### 1.1 文档目的

本文档详细描述图像去雾系统模型算法模块的代码设计，包括架构设计、模块划分、接口定义、数据结构和关键算法等技术实现细节。

### 1.2 适用范围

本文档适用于模型算法模块的后端和前端开发人员，为代码实现提供技术指导和参考。

### 1.3 架构设计

本文档遵循《总体系统架构文档》中定义的分层架构设计原则，采用前后端分离的架构模式。

## 2. 技术架构设计

### 2.1 整体架构

模型算法模块采用复杂的分布式架构设计：

- 前端：基于Vue3 + Element Plus的单页应用
- Java后端：基于Spring Boot的RESTful API服务
- Python算法服务：基于PyTorch和Flask的深度学习模型服务

### 2.2 后端分层架构

```
Controller层 (SysAlgorithmController)
    ↓
Service层 (SysAlgorithmService)
    ↓
Mapper层 (SysAlgorithmMapper)
    ↓
数据库 (MySQL)
```

### 2.3 前端架构

```
页面组件 (algorithm/index.vue, presentation/dehaze/index.vue, evaluation/index.vue)
    ↓
API调用层 (dehaze-sdk-js)
    ↓
状态管理 (Vuex/Pinia)
    ↓
UI组件 (Element Plus + 自定义组件)
```

### 2.4 算法服务架构

```
Flask应用 (app.py)
    ↓
算法处理层 (predict.py, evaluate.py)
    ↓
模型加载层 (init_algorithm.py)
    ↓
深度学习框架 (PyTorch)
```

#### 3.1.2 接口设计

| 接口URL                     | 请求方法   | 功能描述       | 权限控制                                                 |
|---------------------------|--------|------------|------------------------------------------------------|
| /api/v1/algorithm         | GET    | 获取算法树形表格   | 无特殊权限                                                |
| /api/v1/algorithm/options | GET    | 获取模型下拉选项列表 | 无特殊权限                                                |
| /api/v1/algorithm/{id}    | GET    | 根据ID获取算法信息 | 无特殊权限                                                |
| /api/v1/algorithm         | POST   | 新增算法       | @PreAuthorize("@ss.hasPerm('sys:algorithm:add')")    |
| /api/v1/algorithm/{id}    | PUT    | 修改算法       | @PreAuthorize("@ss.hasPerm('sys:algorithm:edit')")   |
| /api/v1/algorithm         | DELETE | 删除算法       | @PreAuthorize("@ss.hasPerm('sys:algorithm:delete')") |

#### 3.1.3 关键注解说明

- `@PreAuthorize`：Spring Security权限控制注解，用于方法级别的权限验证
- `@Valid`/`@Validated`：用于请求参数校验

## 6. 关键算法设计

### 6.1 算法模型树构建算法

通过递归算法构建算法模型树形结构：

1. 查询所有算法模型数据
2. 根据父子关系构建树形结构
3. 递归构建完整的树形结构

### 6.2 处理结果缓存算法

通过MD5校验实现处理结果缓存：

1. 计算输入文件的MD5值
2. 查询是否存在相同MD5的缓存结果
3. 如存在则直接返回缓存结果，否则进行处理

### 6.3 图像质量评估算法

支持多种图像质量评估指标计算：

1. PSNR（峰值信噪比）
2. SSIM（结构相似性指标）
3. 其他自定义评估指标
