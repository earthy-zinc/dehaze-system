# 用户管理模块

## 1. 概述

### 1.1 文档目的
本文档详细描述图像去雾系统用户管理模块的代码设计，包括架构设计、模块划分、接口定义、数据结构和关键算法等技术实现细节。

### 1.2 适用范围
本文档适用于用户管理模块的后端和前端开发人员，为代码实现提供技术指导和参考。

### 1.3 架构设计
本文档遵循《总体系统架构文档》中定义的分层架构设计原则，采用前后端分离的架构模式。

## 2. 技术架构设计

### 2.1 整体架构
用户管理模块采用前后端分离的架构设计：
- 后端：基于Spring Boot的RESTful API服务
- 前端：基于Vue3 + Element Plus的单页应用

### 2.2 后端分层架构
```
Controller层 (SysUserController)
    ↓
Service层 (SysUserService)
    ↓
Mapper层 (SysUserMapper)
    ↓
数据库 (MySQL)
```

### 2.3 前端架构
```
页面组件 (index.vue)
    ↓
API调用层 (dehaze-sdk-js)
    ↓
状态管理 (Vuex/Pinia)
    ↓
UI组件 (Element Plus)
```

## 3. 后端详细设计

### 3.1 控制层设计 (SysUserController)

#### 3.1.1 类结构
```java
@RestController
@RequestMapping("/api/v1/users")
@RequiredArgsConstructor
@Tag(name = "02.用户接口")
public class SysUserController {
    private final SysUserService userService;
}
```

#### 3.1.2 接口设计

| 接口URL | 请求方法 | 功能描述 | 权限控制 |
|---------|---------|---------|---------|
| /api/v1/users/page | GET | 用户分页列表 | 无特殊权限 |
| /api/v1/users | POST | 新增用户 | @PreAuthorize("@ss.hasPerm('sys:user:add')") |
| /api/v1/users/{userId}/form | GET | 用户表单数据 | 无特殊权限 |
| /api/v1/users/{userId} | PUT | 修改用户 | @PreAuthorize("@ss.hasPerm('sys:user:edit')") |
| /api/v1/users/{ids} | DELETE | 删除用户 | @PreAuthorize("@ss.hasPerm('sys:user:delete')") |
| /api/v1/users/{userId}/password | PATCH | 修改用户密码 | @PreAuthorize("@ss.hasPerm('sys:user:password:reset')") |
| /api/v1/users/{userId}/status | PATCH | 修改用户状态 | 无特殊权限 |
| /api/v1/users/me | GET | 获取当前登录用户信息 | 无特殊权限 |
| /api/v1/users/template | GET | 用户导入模板下载 | 无特殊权限 |
| /api/v1/users/_import | POST | 导入用户 | 无特殊权限 |
| /api/v1/users/_export | GET | 导出用户 | 无特殊权限 |

#### 3.1.3 关键注解说明
- `@PreAuthorize`：Spring Security权限控制注解，用于方法级别的权限验证
- `@PreventDuplicateSubmit`：自定义注解，用于防止重复提交
- `@Valid`/`@Validated`：用于请求参数校验

## 5. 数据库设计

### 5.1 用户表 (sys_user)
```sql
CREATE TABLE `sys_user` (
  `id` bigint NOT NULL AUTO_INCREMENT COMMENT '用户ID',
  `username` varchar(64) NOT NULL COMMENT '用户名',
  `nickname` varchar(64) NOT NULL COMMENT '用户昵称',
  `mobile` varchar(20) DEFAULT NULL COMMENT '手机号',
  `email` varchar(128) DEFAULT NULL COMMENT '邮箱',
  `gender` tinyint DEFAULT NULL COMMENT '性别',
  `avatar` varchar(255) DEFAULT NULL COMMENT '头像',
  `password` varchar(128) NOT NULL COMMENT '密码',
  `status` tinyint NOT NULL DEFAULT '1' COMMENT '用户状态(1:启用;0:禁用)',
  `dept_id` bigint DEFAULT NULL COMMENT '部门ID',
  `create_time` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_username` (`username`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';
```

### 5.2 索引设计
- 主键索引：id字段
- 唯一索引：username字段，确保用户名唯一性
- 普通索引：dept_id字段，优化部门查询性能
