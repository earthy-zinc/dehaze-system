# 第6章：插件系统与生态

## 6.1 插件系统概述

### 6.1.1 插件的作用与价值

**Gradle插件核心价值：**

Gradle插件系统是Gradle强大功能的基石，它允许开发者以模块化的方式扩展构建功能。与Maven插件相比，Gradle插件提供了更大的灵活性和更强的编程能力。

```groovy
// build.gradle - 插件价值演示

// 1. 插件对比：Maven vs Gradle
/*
Maven插件特点：
- 基于XML配置
- 功能相对固定
- 扩展性有限
- 主要通过插件参数配置

Gradle插件特点：
- 基于DSL编程
- 高度可定制
- 支持编程式扩展
- 可以自定义任务和配置
*/

// 2. 插件类型演示
plugins {
    // 二进制插件 - 最常见的插件类型
    id 'java'                    // Java项目支持
    id 'application'             // 应用程序支持
    id 'java-library'            // Java库支持

    // 项目插件 - 来自Gradle Plugin Portal
    id 'com.github.johnrengelman.shadow' version '8.1.1'  // Fat JAR创建
    id 'com.github.ben-manes.versions' version '0.50.0'    // 依赖更新检查
    id 'org.sonarqube' version '4.4.1.3373'              // 代码质量分析

    // 脚本插件 - 本地或远程脚本
    // apply from: 'https://example.com/gradle-script.gradle'
}

// 3. 插件价值示例
task demonstratePluginValue {
    description 'Demonstrate the value of Gradle plugins'
    group 'demonstration'

    doLast {
        println """
        === Gradle插件核心价值 ===

        1. 模块化构建逻辑：
           - 将复杂构建逻辑分解为可重用的模块
           - 支持团队协作和知识共享
           - 便于维护和升级

        2. 类型安全：
           - 提供强类型的DSL
           - IDE支持和代码补全
           - 编译时错误检查

        3. 增量构建支持：
           - 内置缓存机制
           - 智能任务依赖
           - 显著提升构建性能

        4. 丰富的生态系统：
           - 官方插件覆盖各种场景
           - 社区插件扩展功能
           - 企业级插件支持

        5. 编程式配置：
           - 支持条件逻辑
           - 动态配置能力
           - 复杂业务逻辑支持
        """
    }
}
```

### 6.1.3 插件应用方式

**插件应用方法对比：**

```groovy
// build.gradle - 插件应用方式

// 1. 现代方式：plugins块（推荐）
plugins {

if (project.hasProperty('enableDocker')) {
    apply plugin: 'com.palantir.docker'

// 5. 插件应用对比任务
task comparePluginApplication {
    description 'Compare different plugin application methods'
    group 'demonstration'

    doLast {
        println """
        === 插件应用方式对比 ===

        1. plugins块方式（推荐）：
           优点：
           - 类型安全
           - 支持增量构建
           - 版本管理清晰
           - IDE支持好
           - 性能更好

           缺点：
           - 不能在if语句中使用
           - 需要Gradle 2.1+

        2. apply plugin方式（旧方式）：
           优点：
           - 可以条件化应用
           - 语法简单
           - 兼容性好

           缺点：
           - 不支持增量构建
           - 版本管理复杂
           - IDE支持有限
           - 性能较差

        3. apply from方式（脚本插件）：
           优点：
           - 高度可定制
           - 支持远程脚本
           - 易于共享

           缺点：
           - 缺乏类型安全
           - 难以调试
           - 版本控制困难

        推荐策略：
        - 优先使用plugins块
        - 脚本插件用于特定场景
        - 避免使用apply plugin方式
        """
    }
}

// 6. 插件版本管理

    repositories {
        gradlePluginPortal()
        mavenCentral()
        maven { url 'https://repo.spring.io/milestone' }
```

**版本管理最佳实践：**

```groovy
// build.gradle - 插件版本管理

// 1. 版本目录管理（推荐）
// gradle/libs.versions.toml
/*
[plugins]
spring-boot = { id = "org.springframework.boot", version = "3.2.0" }

*/

// 2. 使用版本目录

    alias(libs.plugins.springBoot)
    alias(libs.plugins.shadow)
    alias(libs.plugins.versions)
```

## 6.2 核心插件详解

### 6.2.1 Java插件深度解析

**Java插件核心功能：**

```groovy
// build.gradle - Java插件深度配置

plugins {
    id 'java'
    id 'java-library'  // 扩展Java插件功能
}

// 1. Java版本配置
java {
    // 源码兼容性
    sourceCompatibility = JavaVersion.VERSION_17

    // 目标兼容性
    targetCompatibility = JavaVersion.VERSION_17

    // 生成源码JAR
    withSourcesJar()

    // 生成Javadoc JAR
    withJavadocJar()

    // 工具链配置（Gradle 6.7+）
    toolchain {
        languageVersion = JavaLanguageVersion.of(17)
        vendor = JvmVendorSpec.ADOPTIUM
        implementation = JvmImplementation.VENDOR_SPECIFIC
    }
}

// 2. 源集配置
sourceSets {
    main {
        java {
            srcDirs = ['src/main/java', 'src/generated/java']
        }
        resources {
            srcDirs = ['src/main/resources', 'src/main/config']
        }
    }

    test {
        java {
            srcDirs = ['src/test/java', 'src/integration-test/java']
        }
        resources {
            srcDirs = ['src/test/resources']
        }
    }

    // 自定义源集
    integrationTest {
        java {
            srcDir 'src/integration-test/java'
        }
        resources {
            srcDir 'src/integration-test/resources'
        }
        compileClasspath += sourceSets.main.output
        runtimeClasspath += sourceSets.main.output
    }

    functionalTest {
        java {
            srcDir 'src/functional-test/java'
        }
        compileClasspath += sourceSets.main.output
        runtimeClasspath += sourceSets.main.output
    }
}

// 3. 配置扩展
configurations {
    // 继承主配置
    integrationTestImplementation.extendsFrom testImplementation
    integrationTestRuntimeOnly.extendsFrom testRuntimeOnly

    functionalTestImplementation.extendsFrom testImplementation
    functionalTestRuntimeOnly.extendsFrom testRuntimeOnly

    // 自定义配置
    provided
    compileOnly.extendsFrom provided

    // 配置属性
    testImplementation {
        // 排除特定依赖
        exclude group: 'org.junit.vintage', module: 'junit-vintage-engine'
    }
}

// 4. Java编译任务定制
tasks.named('compileJava', JavaCompile) {
    options.encoding = 'UTF-8'
    options.compilerArgs += [
        '-Xlint:unchecked',
        '-Xlint:deprecation',
        '-parameters',
        '-Werror'
    ]

    // 增量编译
    options.incremental = true

    // 注解处理器
    options.annotationProcessorGeneratedSourcesDirectory = file("$buildDir/generated/sources/annotationProcessor/java/main")
}

tasks.named('compileTestJava', JavaCompile) {
    options.encoding = 'UTF-8'
    options.compilerArgs += [
        '-Xlint:unchecked',
        '-Xlint:deprecation'
    ]
}

// 5. 测试任务定制
tasks.named('test', Test) {
    useJUnitPlatform()

    // 测试配置
    testLogging {
        events "passed", "skipped", "failed"
        exceptionFormat "full"
        showStandardStreams = true
    }

    // JVM参数
    jvmArgs = [
        '-Dspring.profiles.active=test',
        '-Dfile.encoding=UTF-8',
        '-Djava.awt.headless=true'
    ]

    // 系统属性
    systemProperty 'test.groups', System.getProperty('test.groups', '')
    systemProperty 'build.timestamp', new Date().format('yyyy-MM-dd HH:mm:ss')

    // 并行测试
    maxParallelForks = Runtime.runtime.availableProcessors().intdiv(2) ?: 1
}

// 6. 自定义集成测试任务
task integrationTest(type: Test) {
    description 'Run integration tests'
    group = 'verification'

    testClassesDirs = sourceSets.integrationTest.output.classesDirs
    classpath = sourceSets.integrationTest.runtimeClasspath

    useJUnitPlatform()
    include '**/*IntegrationTest.class'

    testLogging {
        events "passed", "skipped", "failed"
        exceptionFormat "full"
    }

    dependsOn test
}

// 7. JAR任务定制
tasks.named('jar', Jar) {
    manifest {
        attributes(
            'Implementation-Title': project.name,
            'Implementation-Version': project.version,
            'Build-Timestamp': new Date().format('yyyy-MM-dd HH:mm:ss'),
            'Build-Jdk': System.getProperty('java.version'),
            'Build-Gradle': gradle.gradleVersion
        )
    }

    // 包含额外文件
    from('src/main/resources/META-INF') {
        into 'META-INF'
    }

    // 排除特定文件
    exclude '**/logback-test.xml'
}

// 8. Java插件功能演示
task javaPluginDemo {
    description 'Demonstrate Java plugin features'
    group = 'demonstration'

    doLast {
        println """
        === Java插件核心功能 ===

        1. 源集管理：
           - main: 主要源码和资源
           - test: 测试源码和资源
           - 支持自定义源集
           - 灵活的目录结构

        2. 依赖配置：
           - implementation: 编译和运行时依赖
           - api: 公开API依赖
           - compileOnly: 编译时依赖
           - runtimeOnly: 运行时依赖
           - testImplementation: 测试依赖

        3. 任务生成：
           - compileJava: 编译主源码
           - compileTestJava: 编译测试源码
           - test: 运行测试
           - jar: 打包JAR
           - javadoc: 生成文档

        4. 生命周期管理：
           - 编译 -> 测试 -> 打包
           - 自动任务依赖
           - 增量构建支持

        5. 工具链支持：
           - 多JDK版本支持
           - 自动JDK检测
           - 工具链配置
        """
    }
}
```

### 6.2.2 Application插件使用

**Application插件配置：**

```groovy
// build.gradle - Application插件配置

plugins {
    id 'application'
    id 'java'
}

// 1. 应用程序配置
application {
    // 主类配置
    mainClass.set('com.example.MyApplication')

    // 应用程序名称
    applicationName = 'my-application'

    // 应用程序版本
    applicationDefaultJvmArgs = [
        '-Xmx2g',
        '-Xms512m',
        '-Dspring.profiles.active=default',
        '-Dfile.encoding=UTF-8'
    ]
}

// 2. 分发配置
distributions {
    main {
        distributionBaseName.set('my-app')
        contents {
            from('src/main/dist') {
                into 'bin'
            }
            from('docs') {
                into 'docs'
            }
        }
    }

    // 自定义分发
    custom {
        distributionBaseName.set('my-app-custom')
        contents {
            from('src/main/custom-dist') {
                into '.'
            }
        }
    }
}

// 3. 启动脚本定制
startScripts {
    // Unix脚本配置
    unixStartScriptGenerator.template = resources.text.fromFile('scripts/unix-start-template.sh')

    // Windows脚本配置
    windowsStartScriptGenerator.template = resources.text.fromFile('scripts/windows-start-template.bat')

    // 应用程序参数
    defaultJvmOpts = [
        '-Xmx1g',
        '-Dspring.profiles.active=prod'
    ]

    // 主类检查
    doLast {
        def mainClass = application.mainClass.get()
        println "Configured main class: $mainClass"
    }
}

// 4. 运行任务配置
tasks.named('run', JavaExec) {
    // JVM参数
    jvmArgs = [
        '-Xdebug',
        '-Xrunjdwp:transport=dt_socket,server=y,suspend=n,address=5005'

    // 系统属性

    systemProperty 'server.port', '8080'

    args = ['--spring.config.location=classpath:/application.yml']

    // 工作目录
    workingDir = projectDir

    // 输入重定向
    standardInput = System.in

    // 标准输出
    standardOutput = System.out

    // 错误输出
    errorOutput = System.err
}
```

### 6.2.3 War插件配置

**War插件配置详解：**

```groovy
// build.gradle - War插件配置

plugins {
    id 'war'
    id 'java'
}

// 1. War任务配置
tasks.named('war', War) {
    // Web应用程序名称
    archiveBaseName.set('my-webapp')
    archiveVersion.set(project.version)
    archiveClassifier.set('')

    // Web内容目录
    webAppDirName = 'src/main/webapp'

    // 包含内容
    from('src/main/webapp') {
        include '**/*.html'
        include '**/*.css'
        include '**/*.js'
    }

    // 静态资源处理
    webInf {
        from('src/main/webapp/WEB-INF') {
            include 'web.xml'
        }
    }

    // 类库处理
    classpath = sourceSets.main.output + configurations.runtimeClasspath

    // 排除特定依赖
    classpath = classpath.filter { file ->
        !file.name.startsWith('servlet-api-')
    }

    // War文件元数据
    manifest {
        attributes(
            'Implementation-Title': 'My Web Application',
            'Implementation-Version': project.version,
            'Build-Timestamp': new Date().format('yyyy-MM-dd HH:mm:ss')
        )
    }
}

// 2. Web应用程序配置
webAppDirName = 'src/main/webapp'

// 3. 容器配置（用于开发测试）
configurations {
    tomcat
    jetty
}

dependencies {
    // Servlet API（provided scope）
```
