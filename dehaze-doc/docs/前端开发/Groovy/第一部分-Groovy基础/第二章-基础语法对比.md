# 第二章：基础语法对比（Groovy vs Java）

> 对于Java开发者来说，Groovy最吸引人的地方就是它那熟悉又新颖的语法。你可以在几乎不改变编程习惯的情况下，享受到更简洁、更灵活的开发体验。

## 2.1 变量声明和数据类型

### 2.1.1 动态类型 vs 静态类型

**Java风格（静态类型）**
```java
// Java 代码
String name = "John Doe";
int age = 30;
List<String> hobbies = Arrays.asList("reading", "coding");

// 类型必须明确声明
Map<String, Object> person = new HashMap<>();
person.put("name", "John");
person.put("age", 30);
```

**Groovy动态类型**
```groovy
// Groovy 动态类型
def name = "John Doe"      // 自动推断为String
def age = 30              // 自动推断为Integer
def hobbies = ["reading", "coding"]  // List<String>

// 灵活的类型转换
age = "thirty years old"  // 可以改变类型
println age.toUpperCase() // 依然可以调用String方法
```

**Groovy静态类型**
```groovy
// 显式类型声明
String name = "John Doe"
int age = 30
List<String> hobbies = ["reading", "coding"]

// 编译时类型检查
@CompileStatic
class TypedExample {
    String process(String input) {
        return input.toUpperCase()
    }
}
```

### 2.1.2 类型推断对比

| 特性 | Java | Groovy |
|------|------|--------|
| `var`关键字 | Java 10+支持 | `def`关键字（更灵活） |
| 类型推断 | 局部变量推断 | 全局类型推断 |
| 运行时类型改变 | 不支持 | 支持 |
| 编译时检查 | 严格检查 | 可选检查 |

```groovy
// Groovy的类型推断示例
def numbers = [1, 2, 3]        // List<Integer>
def texts = ["a", "b", "c"]     // List<String>
def mixed = [1, "two", 3.0]     // List<Object>

// def vs 具体类型
def dynamicList = [1, 2, 3]
dynamicList.add("four")         // 可以，但类型不安全

List<Integer> staticList = [1, 2, 3]
// staticList.add("four")       // 编译错误
```

### 2.1.3 数据类型增强

**GString（Groovy字符串）**
```groovy
def name = "Groovy"
def version = 4.0

// 字符串插值（比Java的String.format更直观）
def greeting = "Welcome to ${name} ${version}"
println greeting

// 多行字符串
def multiLine = """
    This is a
    multiline string
    with ${name} inside
"""

// GString延迟计算
def lazy = "Current time: ${-> new Date()}"
println lazy  // 每次调用都重新计算时间
```

## 2.2 方法定义和调用

### 2.2.1 方法定义简化

**Java方式**
```java
public class Calculator {
    public int add(int a, int b) {
        return a + b;
    }

    public String greet(String name) {
        return "Hello, " + name + "!";
    }
}
```

**Groovy方式**
```groovy
class Calculator {
    // return关键字可选（最后一行自动返回）
    def add(a, b) { a + b }

    // 参数类型可选
    def greet(String name) {
        "Hello, ${name}!"  // 字符串插值
    }

    // 单行方法定义
    def multiply(a, b) = a * b

    // 默认参数
    def power(base, exponent = 2) {
        base ** exponent
    }

    // 可变参数
    def sum(Number... numbers) {
        numbers.sum()
    }
}
```

### 2.2.2 方法调用语法糖

**命名参数**
```groovy
class Person {
    String name
    int age
    String city

    // 构造函数支持命名参数
    Person(Map params) {
        name = params.name
        age = params.age
        city = params.city ?: "Unknown"
    }
}

// 使用命名参数创建对象
def person = new Person(name: "Alice", age: 25, city: "Beijing")
println "${person.name} is ${person.age} years old"
```

**方法调用括号省略**
```groovy
println "Hello World"              // 不需要括号
println "Hello", "World"           // 多参数也可以

// 链式调用更优雅
"  Groovy  ".trim().toUpperCase().substring(0, 3)

// 命令链模式
def result = "hello world"
    .toUpperCase()
    .split(" ")
    .join("-")
```

### 2.2.3 闭包作为参数

```groovy
// 传统方式
def numbers = [1, 2, 3, 4, 5]
def evenNumbers = numbers.findAll { it % 2 == 0 }

// 方法最后一个参数是闭包时，可以移出括号
def result = [1, 2, 3].inject(0) { acc, val -> acc + val }

// 多个闭包参数
def processData(data, filter, transformer) {
    data.findAll(filter).collect(transformer)
}

def result = processData([1, 2, 3, 4, 5],
    { it % 2 == 0 },           // filter闭包
    { it * 10 }                // transformer闭包
)
```

## 2.3 控制流语句

### 2.3.1 条件语句

**Java vs Groovy对比**
```java
// Java
String message;
if (score >= 90) {
    message = "Excellent";
} else if (score >= 80) {
    message = "Good";
} else if (score >= 60) {
    message = "Pass";
} else {
    message = "Fail";
}
```

```groovy
// Groovy更简洁
def score = 85
def message = score >= 90 ? "Excellent" :
             score >= 80 ? "Good" :
             score >= 60 ? "Pass" : "Fail"

// Groovy特有：switch语句更强大
def evaluateGrade(grade) {
    switch(grade) {
        case "A".."C": return "Pass"
        case { it.size() > 1 }: return "Invalid grade: ${grade}"
        case ~/[D-F]/: return "Fail"
        default: return "Unknown"
    }
}
```

### 2.3.2 循环语句

**增强的for循环**
```groovy
def names = ["Alice", "Bob", "Charlie"]

// 传统方式
for (int i = 0; i < names.size(); i++) {
    println names[i]
}

// Groovy增强方式
for (name in names) {
    println name
}

// each方法（函数式风格）
names.each { println it }

// 带索引的迭代
names.eachWithIndex { name, index ->
    println "${index + 1}. ${name}"
}
```

**数值循环**
```groovy
// 传统方式
for (int i = 0; i < 10; i++) {
    println i
}

// Groovy方式
0.upto(9) { println it }
10.times { println it }  // 0到9
(0..<10).each { println it }

// 步进循环
1.step(10, 2) { println it }  // 1, 3, 5, 7, 9
```

## 2.4 异常处理

### 2.4.1 简化的异常处理

**Java方式**
```java
try {
    // 可能抛出异常的代码
    String result = riskyOperation();
    System.out.println(result);
} catch (IOException e) {
    System.err.println("IO Error: " + e.getMessage());
} catch (Exception e) {
    System.err.println("General Error: " + e.getMessage());
} finally {
    System.out.println("Cleanup");
}
```

**Groovy方式**
```groovy
try {
    def result = riskyOperation()
    println result
} catch (IOException e) {
    println "IO Error: ${e.message}"
} catch (e) {  // 可以省略Exception类型
    println "Error: ${e.message}"
} finally {
    println "Cleanup"
}

// withStream自动资源管理
new File("test.txt").withStream { stream ->
    // stream会在结束时自动关闭
    stream.eachLine { println it }
}
```

### 2.4.2 安全操作符

**空值安全**
```groovy
def person = null

// 传统空值检查
if (person != null && person.getAddress() != null) {
    println person.getAddress().getCity()
}

// 安全导航操作符（?.）
println person?.address?.city  // 如果任何环节为null，返回null而不报错

// Elvis操作符（?:）
def city = person?.address?.city ?: "Unknown"  // 如果左边为null，使用右边值

// 方法调用安全
def result = person?.getName()?.toUpperCase()  // 不会抛出NullPointerException
```

## 2.5 类和对象定义

### 2.5.1 简化的类定义

**Java类定义**
```java
public class Person {
    private String name;
    private int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public int getAge() {
        return age;
    }

    public void setAge(int age) {
        this.age = age;
    }

    @Override
    public String toString() {
        return "Person{name='" + name + "', age=" + age + "}";
    }

    @Override
    public boolean equals(Object obj) {
        if (this == obj) return true;
        if (obj == null || getClass() != obj.getClass()) return false;
        Person person = (Person) obj;
        return age == person.age && Objects.equals(name, person.name);
    }
}
```

**Groovy类定义**
```groovy
@Canonical  // 自动生成toString、equals、hashCode
class Person {
    String name  // 自动生成getter/setter
    int age

    // 构造函数自动生成
    // 可以添加额外方法
    def isAdult() {
        age >= 18
    }
}

// 使用AST转换进一步简化
@ToString(includeNames=true)
@EqualsAndHashCode
class Student {
    String name
    int age
    List<String> courses

    // 自定义构造函数
    Student(String name, int age) {
        this.name = name
        this.age = age
        this.courses = []
    }

    def addCourse(String course) {
        courses << course
    }
}
```

### 2.5.2 Trait（接口增强）

```groovy
// Groovy的Trait比Java接口更强大
trait Flyable {
    def fly() {
        println "${this.class.simpleName} is flying!"
    }

    // 可以包含抽象方法
    abstract def getSpeed()

    // 可以包含具体实现
    def getFlightTime(distance) {
        distance / getSpeed()
    }
}

trait Swimmable {
    def swim() {
        println "${this.class.simpleName} is swimming!"
    }
}

// 类可以混入多个Trait
class Duck implements Flyable, Swimmable {
    def getSpeed() { 10 }

    def quack() {
        println "Quack!"
    }
}

def duck = new Duck()
duck.fly()
duck.swim()
println "Flight time for 100km: ${duck.getFlightTime(100)} hours"
```

## 2.6 集合操作对比

### 2.6.1 List操作

**Java方式**
```java
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");
List<Integer> lengths = new ArrayList<>();

for (String name : names) {
    lengths.add(name.length());
}

// 过滤
List<String> longNames = new ArrayList<>();
for (String name : names) {
    if (name.length() > 4) {
        longNames.add(name);
    }
}
```

**Groovy方式**
```groovy
def names = ["Alice", "Bob", "Charlie"]

// 映射操作
def lengths = names.collect { it.length() }

// 过滤操作
def longNames = names.findAll { it.length() > 4 }

// 查找操作
def found = names.find { it.startsWith("B") }

// 分组操作
def grouped = names.groupBy { it.length() }

// 累积操作
def totalLength = names.sum { it.length() }

// 链式操作
def result = names
    .findAll { it.length() > 3 }
    .collect { it.toUpperCase() }
    .sort()
    .join(", ")
```

## 2.8 操作符重载

### 2.8.1 自定义操作符

```groovy
class Money {
    BigDecimal amount
    String currency

    Money(amount, currency) {
        this.amount = amount
        this.currency = currency
    }

    // 重载加法操作符
    Money plus(Money other) {
        if (currency != other.currency) {
            throw new IllegalArgumentException("Currency mismatch")
        }
        new Money(amount + other.amount, currency)
    }

    // 重载比较操作符
    int compareTo(Money other) {
        amount.compareTo(other.amount)
    }

    // 重载toString
    String toString() {
        "${amount} ${currency}"
    }
}

def money1 = new Money(100.50, "USD")
def money2 = new Money(50.25, "USD")

// 使用重载的操作符
def total = money1 + money2  // 调用plus方法
println "Total: ${total}"

// 使用比较操作符
if (money1 > money2) {
    println "${money1} is greater than ${money2}"
}
```

## 2.10 性能考虑和最佳实践

### 2.10.1 编译时类型检查

```groovy
// 动态类型 - 灵活但有性能开销
def dynamicAdd(a, b) {
    a + b  // 运行时确定操作
}

// 静态编译 - 更好性能
@CompileStatic
def staticAdd(int a, int b) {
    a + b  // 编译时确定类型
}

// 混合模式 - 平衡灵活性和性能
@TypeChecked
def typeCheckedAdd(Number a, Number b) {
    a + b
}
```

### 2.10.2 避免常见陷阱

```groovy
// 1. 避免过度使用动态特性
class BadPractice {
    def process(data) {
        // 不好的实践：类型不明确
        data.each { item ->
            if (item.size > 5) {  // 可能导致运行时错误
                println item
            }
        }
    }
}

class GoodPractice {
    def process(List<String> data) {
        // 好的实践：明确类型
        data.each { String item ->
            if (item.size() > 5) {
                println item
            }
        }
    }
}

// 2. 合理使用GString
def avoidStringConcatenation(String name, int age) {
    // 好的实践：使用字符串插值
    "Name: ${name}, Age: ${age}"

    // 避免：字符串拼接
    // "Name: " + name + ", Age: " + age
}
```

## 2.11 实战案例：Java到Groovy的转换

### 2.11.1 工具类转换

**Java版本**
```java
public class StringUtils {
    public static boolean isEmpty(String str) {
        return str == null || str.isEmpty();
    }

    public static String capitalize(String str) {
        if (isEmpty(str)) {
            return str;
        }
        return str.substring(0, 1).toUpperCase() + str.substring(1);
    }

    public static List<String> splitAndTrim(String str, String delimiter) {
        if (isEmpty(str)) {
            return new ArrayList<>();
        }

        List<String> result = new ArrayList<>();
        String[] parts = str.split(delimiter);
        for (String part : parts) {
            result.add(part.trim());
        }
        return result;
    }
}
```

**Groovy版本**
```groovy
class StringUtils {
    static boolean isEmpty(String str) {
        !str  // Groovy真值判断
    }

    static String capitalize(String str) {
        str?.capitalize()  // 使用内置方法和安全操作符
    }

    static List<String> splitAndTrim(String str, String delimiter) {
        str?.split(delimiter)*.trim() ?: []  // 展开操作符和Elvis操作符
    }
}

// 或者使用Groovy扩展方法
String.metaClass.isEmpty = {
    !delegate || delegate.isEmpty()
}

String.metaClass.capitalizeAndTrim = {
    delegate?.trim()?.capitalize()
}
```

## 本章小结

通过本章的对比学习，我们看到Groovy在保持Java兼容性的同时，提供了更加简洁和灵活的语法：

### 主要优势回顾

1. **类型灵活性**：支持动态和静态两种类型系统
2. **语法简洁性**：减少样板代码，提高可读性
3. **表达力强**：支持闭包、操作符重载、GString等特性
4. **Java互操作**：无缝使用Java类库和代码
5. **开发效率**：更少的代码实现相同功能

### 学习要点

✅ **掌握动态类型系统**：理解`def`关键字和类型推断
✅ **熟悉方法调用简化**：命名参数、括号省略、闭包参数
✅ **学会集合操作**：使用Groovy的集合方法替代传统循环
✅ **理解安全操作符**：`?.`和`?:`的合理使用
✅ **了解性能权衡**：在灵活性和性能之间找到平衡

### 最佳实践建议

- **渐进式采用**：从简单脚本开始，逐步掌握高级特性
- **类型安全优先**：在可能的情况下使用静态类型
- **保持可读性**：简洁但不牺牲代码可读性
- **性能意识**：了解动态特性的性能影响
