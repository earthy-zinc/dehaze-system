## HTML DOM

### DOM简介

文档对象模型(Document Object Model, DOM)是HTML文档的编程接口。当网页加载时，浏览器会创建页面的DOM。通过DOM，JavaScript可以：

- 修改HTML元素和属性
- 修改CSS样式
- 对页面事件做出响应

### DOM操作

#### 查找元素

查找HTML元素是操作元素的前提：

1. 通过ID查找：`var x = document.getElementById("intro");`
2. 通过标签名查找：`var y = document.getElementsByTagName("p");`
3. 通过类名查找：`var z = document.getElementsByClassName("intro");`

DOM查找方法通常返回元素集合，类似于数组但不是数组。可以通过索引访问元素，使用length属性获取集合大小。

#### 修改元素

修改HTML元素包括修改内容、属性和样式：

1. 修改内容：`element.innerHTML = "新内容";`
2. 修改属性：`element.attribute = "新值";`
3. 修改样式：`element.style.property = "新样式";`

#### 添加和删除元素

JavaScript可以动态添加、删除或替换HTML元素。

### 事件处理

#### 事件分配方法

1. 直接在元素上添加事件属性：
   ```html
   <button onclick="displayDate()">点击</button>
   ```

2. 通过JavaScript分配事件：
   ```javascript
   document.getElementById("myButton").onclick = function() { /* 处理逻辑 */ };
   ```

#### 事件监听器

addEventListener()方法用于向元素添加事件监听器：

- 不会覆盖已存在的事件
- 可以为一个元素添加多个事件监听器
- 实现HTML与JavaScript分离，提高可读性

语法：`element.addEventListener(event, function, useCapture)`

参数说明：

- event：事件类型（不使用on前缀）
- function：事件触发后调用的函数
- useCapture：事件传递方式（可选）

#### 事件传递机制

1. **冒泡模式**：内部元素事件先触发，再触发外部元素事件
2. **捕获模式**：外部元素事件先触发，再触发内部元素事件

removeEventListener()方法用于移除通过addEventListener()添加的事件监听器。
